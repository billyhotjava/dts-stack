# DTS v2.2.0 P1 Issue 清单（稳定性与性能）

## 1. 使用说明
- 目标：完成 P0 后，提升运行稳定性、可观测性和用户体验。
- 结构：按四类拆分 `接口/API`、`前端/UI`、`数据库/DDL`、`回归/测试`。
- 状态字段：`todo` / `doing` / `done`。

## 2. 接口/API 类

### P1-API-001 增量审计分页与过滤能力
- 状态：`todo`
- 模块：`source/dts-ingestion`
- 目标：增量执行可按时间、执行批次、表名过滤。
- 改动点：
  - 审计查询支持 `taskId/executionId/from/to/tableName/status`。
  - 返回汇总指标：`before/after/advanced/unchanged`。
- 验收：
  - 单任务 10w+ 审计记录时，查询响应 < 2s（常规过滤）。

### P1-API-002 失败归因标准化
- 状态：`todo`
- 模块：`source/dts-ingestion`
- 目标：统一错误分类，减少“未知错误”。
- 改动点：
  - 归类：连接失败、权限失败、DDL 失败、DML 失败、数据质量失败。
  - 对外返回错误码与可读建议。
- 验收：
  - Top20 常见失败可归类命中率 > 95%。

### P1-API-003 日志聚合接口
- 状态：`todo`
- 模块：`source/dts-ingestion`
- 目标：任务日志聚合到单接口，支持关键字检索。
- 改动点：
  - 汇聚 Airflow DAG 日志 + 节点日志 + Addax 关键错误。
  - 支持分页与 `keyword` 过滤。
- 验收：
  - “查看日志”可一屏看到关键失败链路。

### P1-API-004 重试与补跑策略接口
- 状态：`todo`
- 模块：`source/dts-ingestion`
- 目标：失败后支持“从失败节点重试/整批重跑”。
- 改动点：
  - 新增 `retryMode=FAILED_ONLY|FULL_RERUN`。
  - 记录重试链路到审计表。
- 验收：
  - 重试操作可审计、可回放。

### P1-API-005 Admin 用户查询性能优化
- 状态：`todo`
- 模块：`source/dts-admin`
- 目标：800+ 用户查询卡顿改善。
- 改动点：
  - 检查用户查询 SQL、分页索引、排序字段白名单。
  - 增加后端最小过滤长度与结果上限保护。
- 验收：
  - 用户管理列表查询 P95 < 1.5s。

### P1-API-006 报表密级过滤校验
- 状态：`todo`
- 模块：`source/dts-platform`
- 目标：用户仅可见不高于自身密级的看板链接。
- 改动点：
  - 报表查询增加密级条件。
  - 非法访问返回统一权限码。
- 验收：
  - 不同密级账号交叉验证通过。

## 3. 前端/UI 类

### P1-UI-001 执行历史页增强
- 状态：`todo`
- 模块：`source/dts-platform-webapp`
- 目标：执行历史支持快速定位失败点。
- 改动点：
  - 增加失败分类筛选与关键词搜索。
  - 列表中显示“失败类型/建议动作”。
- 验收：
  - 失败任务 3 次点击内定位到具体节点。

### P1-UI-002 日志查看器增强
- 状态：`todo`
- 模块：`source/dts-platform-webapp`
- 目标：日志可读性提升。
- 改动点：
  - 支持“仅错误”“仅告警”“全部日志”切换。
  - 支持下载原始日志。
- 验收：
  - 用户可独立完成一次问题初步排查。

### P1-UI-003 Admin 用户检索体验优化
- 状态：`todo`
- 模块：`source/dts-admin-webapp`
- 目标：大用户量下界面不卡顿。
- 改动点：
  - 输入防抖（300~500ms）。
  - 分页参数与排序参数最小化请求。
- 验收：
  - 连续搜索无明显卡顿，渲染稳定。

### P1-UI-004 报表密级展示
- 状态：`todo`
- 模块：`source/dts-platform-webapp`
- 目标：报表列表可见密级标签与权限提示。
- 改动点：
  - 列表展示密级徽标。
  - 无权限内容隐藏，不展示可点击入口。
- 验收：
  - 普通员工仅看到可见级别内容。

## 4. 数据库/DDL 类

- 验收：

### P1-DB-003 报表密级字段与约束核查
- 状态：`todo`
- 模块：`source/dts-platform` Liquibase

- 验收：
