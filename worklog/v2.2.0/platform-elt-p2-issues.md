# DTS v2.2.0 P2 Issue 清单（产品化增强）

## 1. 使用说明
- 目标：完成可复用数据集与看板资产化闭环，降低对手工 SQL 的依赖。
- 结构：按四类拆分 `接口/API`、`前端/UI`、`数据库/DDL`、`回归/测试`。
- 状态字段：`todo` / `doing` / `done`。

## 2. 接口/API 类

### P2-API-001 查询结果保存为数据集
- 状态：`done`
- 模块：`source/dts-analytics` / `source/dts-platform`
- 目标：将即席查询结果沉淀为可复用数据集。
- 改动点：
  - 新增“保存为数据集”接口。
  - 保存 SQL、参数、数据源、执行策略、拥有者。
- 验收：
  - 保存后可在数据集列表找到并复跑。

### P2-API-002 数据集版本与发布策略
- 状态：`done`
- 模块：`source/dts-platform`
- 目标：支持数据集版本管理。
- 改动点：
  - `draft/published/archived` 生命周期。
  - 发布后看板绑定固定版本或跟随最新版本。
- 验收：
  - 发布回滚可控。

### P2-API-003 看板链接治理
- 状态：`done`
- 模块：`source/dts-platform`
- 目标：平台统一管理 BI 链接。
- 改动点：
  - 链接属性：密级、有效期、访问范围、审计日志。
  - 支持停用/启用，不做物理删除（保留审计）。
- 验收：
  - 链接访问可追踪，权限策略可验证。

### P2-API-004 项目包导入规范（一个 ZIP 一个项目）
- 状态：`doing`
- 模块：`source/dts-platform`
- 目标：支持外部生成模型的一键导入。
- 改动点：
  - 包级幂等、校验、冲突检测、审计记录。
  - 对已存在 SQL 项目给出风险警告并要求确认。
- 验收：
  - 重复导入同一包不产生脏数据。

### P2-API-005 外部 LLM 产物兼容导入
- 状态：`doing`
- 模块：`source/dts-platform`
- 目标：离线环境可通过导入方式复用外部 LLM 产物。
- 改动点：
  - 支持分层模型（DWD/DWS/ADS）及指标定义导入。
  - 导入报告包含成功/跳过/失败明细。
- 验收：
  - 外部生成产物可进入平台治理流程。

## 3. 前端/UI 类

### P2-UI-001 查询页“保存为数据集”入口
- 状态：`done`
- 模块：`source/dts-analytics-webapp/modern`
- 目标：查询后可一键沉淀数据集。
- 改动点：
  - 在查询结果页增加保存按钮。
  - 保存弹窗支持命名、描述、刷新策略。
- 验收：
  - 用户可不离开页面完成数据集创建。

### P2-UI-002 数据集管理页面
- 状态：`doing`
- 模块：`source/dts-platform-webapp`
- 目标：集中管理数据集资产。
- 改动点：
  - 列表、版本、发布记录、绑定看板关系。
- 验收：
  - 可追踪“哪个看板依赖哪个数据集版本”。

### P2-UI-003 看板中心链接管理增强
- 状态：`done`
- 模块：`source/dts-platform-webapp`
- 目标：加强链接治理能力。
- 改动点：
  - 支持密级、有效期、访问审计查看。
  - 仅管理员可编辑；普通员工只读访问。
- 验收：
  - 权限边界清晰，无越权操作。

### P2-UI-004 项目包导入向导
- 状态：`doing`
- 模块：`source/dts-platform-webapp`
- 目标：导入过程可视化。
- 改动点：
  - 步骤：上传 -> 校验 -> 冲突预览 -> 确认导入 -> 报告。
- 验收：
  - 失败可回滚并给出可复现报告。

## 4. 数据库/DDL 类

### P2-DB-001 数据集资产表设计
- 状态：`done`
- 模块：`source/dts-platform` Liquibase
- 目标：持久化查询数据集。
- 改动点：
  - 数据集主表、版本表、发布表、依赖表。
- 验收：
  - 可支持版本回滚与依赖追踪。

### P2-DB-002 看板链接治理字段补充
- 状态：`done`
- 模块：`source/dts-platform` Liquibase
- 目标：链接治理可审计。
- 改动点：
  - 增加密级、有效期、状态、最近访问时间。
- 验收：
  - 满足链接生命周期管理需求。

### P2-DB-003 包导入审计表
- 状态：`done`
- 模块：`source/dts-platform` Liquibase
- 目标：记录导入操作。
- 改动点：
  - 导入批次、文件摘要、冲突摘要、执行结果。
- 验收：
  - 可审计、可追责、可复盘。

## 5. 回归/测试类

### P2-QA-001 数据集闭环回归
- 状态：`todo`
- 场景：即席查询 -> 保存数据集 -> 绑定看板。
- 验收：
  - 全流程一次打通。

### P2-QA-002 版本与回滚回归
- 状态：`todo`
- 场景：发布两个版本并回滚。
- 验收：
  - 看板数据正确切换。

### P2-QA-003 包导入幂等回归
- 状态：`todo`
- 场景：同一 ZIP 连续导入 3 次。
- 验收：
  - 无重复模型、无脏元数据。

### P2-QA-004 权限与密级回归
- 状态：`todo`
- 场景：管理员/普通员工访问看板中心。
- 验收：
  - 仅允许角色执行对应操作。

## 6. Definition of Done
- 完成“查询 -> 数据集 -> 看板 -> 链接治理”闭环。
- 导入能力具备幂等、审计与冲突提示。
