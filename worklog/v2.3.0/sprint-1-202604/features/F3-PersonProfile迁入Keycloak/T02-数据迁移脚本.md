# T02: 数据迁移脚本（PersonProfile → Keycloak）

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标
编写一次性迁移脚本，将 PersonProfile 表中的有效数据写入 Keycloak user attributes。

## 技术设计

### 迁移逻辑

```
1. 查询 PersonProfile WHERE lifecycle_status = 'ACTIVE'
2. 对每个 profile:
   a. 通过 account/personCode 找到对应的 Keycloak user
   b. 读取当前 Keycloak user attributes
   c. 合并 PersonProfile 字段到 attributes（不覆盖已有值）
   d. 更新 Keycloak user
3. 记录迁移结果（成功/失败/跳过）
```

### 冲突处理

| 场景 | 处理 |
|------|------|
| Keycloak 已有值，PersonProfile 也有值 | 以 PersonProfile 为准（更新） |
| Keycloak 已有值，PersonProfile 为空 | 保持 Keycloak 值 |
| PersonProfile 有值，Keycloak 无对应用户 | 跳过，记录日志 |
| PersonProfile.account 为空 | 尝试用 personCode 匹配 |

### 实现方式

Spring Boot CommandLineRunner + 配置开关：
```yaml
dts:
  migration:
    person-profile-to-keycloak:
      enabled: false  # 手动开启执行
      dry-run: true   # 先试运行
      batch-size: 50
```

### 回滚方案

迁移前导出 PersonProfile 全量数据为 JSON 备份，如需回滚可重新导入。
