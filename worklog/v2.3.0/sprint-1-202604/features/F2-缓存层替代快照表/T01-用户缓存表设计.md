# T01: kc_user_cache 表设计与实现

**优先级**: P1
**状态**: READY
**依赖**: F1

## 目标
设计并实现用户缓存表，替代 AdminKeycloakUser 的快照功能。

## 技术设计

### 表结构

```sql
CREATE TABLE kc_user_cache (
    keycloak_id   VARCHAR(64) PRIMARY KEY,
    username      VARCHAR(64) NOT NULL,
    display_name  VARCHAR(128),
    email         VARCHAR(128),
    phone         VARCHAR(64),
    dept_code     VARCHAR(64),
    dept_name     VARCHAR(256),
    person_level  VARCHAR(32),
    enabled       BOOLEAN NOT NULL DEFAULT true,
    cached_at     TIMESTAMP NOT NULL DEFAULT now(),
    expires_at    TIMESTAMP NOT NULL,

    CONSTRAINT uk_kc_user_cache_username UNIQUE (username)
);
CREATE INDEX idx_kc_user_cache_expires ON kc_user_cache (expires_at);
```

### 缓存服务

```java
@Service
public class KcUserCacheService {

    @Value("${dts.admin.cache.user-ttl:5m}")
    private Duration ttl;

    @Value("${dts.admin.cache.user-grace:30m}")
    private Duration gracePeriod;

    // 单个查询
    public Optional<KcUserCache> findByUsername(String username) {
        var cached = repository.findByUsernameIgnoreCase(username);
        if (cached.isPresent() && !isExpired(cached.get())) {
            return cached;
        }
        // 尝试从 Keycloak 刷新
        try {
            return refreshFromKeycloak(username);
        } catch (Exception ex) {
            // Keycloak 不可用，返回过期缓存（宽限期内）
            if (cached.isPresent() && isWithinGrace(cached.get())) {
                return cached;
            }
            return Optional.empty();
        }
    }

    // 批量查询
    public Map<String, KcUserCache> findByUsernames(Collection<String> usernames);

    // 主动刷新（导入后调用）
    public void evict(String username);
    public void evictAll();
}
```
