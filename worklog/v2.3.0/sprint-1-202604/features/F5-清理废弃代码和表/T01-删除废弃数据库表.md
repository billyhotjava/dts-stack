# T01: 删除废弃数据库表

**优先级**: P2
**状态**: READY
**依赖**: F3, F4 完成并稳定运行

## 目标
DROP 已废弃的数据库表。

## 技术设计

### 待删除的表

| 表名 | 废弃原因 | 数据去向 |
|------|---------|---------|
| `person_profile` | 数据迁入 Keycloak attributes | Keycloak user attributes |
| `admin_keycloak_user` | 被 kc_user_cache 替代 | kc_user_cache |
| `organization_node` | 被 Keycloak groups + kc_org_cache 替代 | Keycloak groups |

### 保留的表

| 表名 | 原因 |
|------|------|
| `admin_custom_role` | 自定义角色定义，ABAC 模型需要 |
| `admin_role_assignment` | 业务权限分配，Keycloak 无法替代 |
| `admin_role_member` | 角色成员关系 |
| `person_import_batch` | 导入批次记录 |
| `person_import_record` | 导入明细记录 |
| `kc_user_cache` | 新增的缓存表 |
| `kc_org_cache` | 新增的缓存表 |

### Liquibase

```xml
<changeSet id="YYYYMMDD_01_drop_deprecated_tables">
    <preConditions onFail="MARK_RAN">
        <tableExists tableName="person_profile"/>
    </preConditions>
    <dropTable tableName="person_profile"/>
    <dropTable tableName="admin_keycloak_user"/>
    <dropTable tableName="organization_node"/>
</changeSet>
```

## 验证
