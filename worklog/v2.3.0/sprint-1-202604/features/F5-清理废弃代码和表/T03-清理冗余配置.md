# T03: 清理冗余配置和 InMemoryStore

**优先级**: P2
**状态**: READY
**依赖**: T01, T02

## 目标
清理与废弃表/同步逻辑相关的配置项和内存缓存。

## 技术设计

### 需要清理的配置

```yaml
# 删除
dts.admin.user-sync.enabled       # 定时同步已废弃
dts.admin.user-sync.interval      # 同步间隔已废弃
dts.mdm-gateway.*                 # MDM → PersonProfile 链路已废弃

# 保留
dts.admin.cache.user-ttl          # Phase 2 引入
dts.admin.cache.user-grace        # Phase 2 引入
dts.admin.cache.org-refresh-interval  # Phase 2 引入
```

### InMemoryStore 清理

`InMemoryStores` 中用户列表、组织树的内存缓存逻辑应删除，因为 kc_user_cache / kc_org_cache 已承担此职责。

保留的部分：角色列表等与 Keycloak 无关的内存缓存。

### 代码清理

- 删除 `AdminUserService` 中所有 `buildName()` 方法
- 删除 `AdminUserService` 中所有 `extractSingle()` 的多别名变体
- 删除 `KeycloakAuthResource` 中冗余的 `displayName`/`nickname` 字段写入

## 验证
- [ ] 应用启动无配置项缺失报错
- [ ] InMemoryStore 不再加载用户/组织数据
- [ ] 无废弃代码残留

## 完成标准
- [ ] 废弃配置项删除
- [ ] InMemoryStore 用户/组织部分清理
