# T03: 取消定时全量快照同步

**优先级**: P0
**状态**: READY
**依赖**: T01, T02

## 目标
移除 AdminKeycloakUser 的定时全量同步任务，改为按需查询 + TTL 缓存。

## 技术设计

### 当前定时同步

AdminUserService 中有定时任务定期从 Keycloak 拉取全量用户列表，逐个 upsert 到 AdminKeycloakUser 表。当用户数量增大（> 500）时出现性能问题。

### 改动

1. **禁用定时同步任务**: 注释或通过配置开关关闭 `@Scheduled` 同步
2. **AdminKeycloakUser 表暂时保留**: 作为 fallback 数据源（Phase 3 再删除）
3. **不再新增/更新 AdminKeycloakUser 记录**: 现有数据冻结，只读

### 配置开关

```yaml
dts:
  admin:
    user-sync:
      enabled: false  # 关闭定时同步
      # 以下为 Phase 2 缓存配置预留
      cache-ttl: 5m
      cache-max-size: 10000
```

## 影响范围

| 文件 | 改动 |
|------|------|
| `dts-admin/.../AdminUserService.java` | 禁用 syncSnapshot 定时任务 |
| `dts-admin/src/main/resources/config/application*.yml` | 添加配置开关 |

## 验证
- [ ] 应用启动后无定时同步任务执行日志
- [ ] AdminKeycloakUser 表无新增记录
- [ ] 用户查询接口仍正常工作（走 Keycloak API 或旧快照 fallback）

## 完成标准
- [ ] 定时同步任务禁用
- [ ] AdminKeycloakUser 表冻结为只读
- [ ] 现有查询不受影响（依赖 Phase 3 缓存层完全替代）
