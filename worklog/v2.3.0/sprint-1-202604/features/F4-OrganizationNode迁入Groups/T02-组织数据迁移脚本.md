# T02: 数据迁移脚本（OrganizationNode → Keycloak Groups）

**优先级**: P1
**状态**: READY
**依赖**: F1/T02

## 目标
将 OrganizationNode 表中的组织树数据迁入 Keycloak Groups（如果 F2/T02 的直写还没有覆盖全部历史数据）。

## 技术设计

### 迁移逻辑

```
1. 查询 OrganizationNode 全量树（从根节点递归）
2. 对每个节点:
   a. 查找 Keycloak group (by keycloakGroupId)
   b. 不存在 → 创建 group（名称、parent、attributes）
   c. 存在 → 更新 attributes（data_level、sort_order 等）
3. 处理父子关系（确保 parent group 先创建）
4. 记录迁移结果
```

### 注意事项

- 必须按树层级顺序迁移（先父后子）
- 已有 keycloakGroupId 的节点说明之前已同步过，只需更新 attributes
- 没有 keycloakGroupId 的节点需要新创建 group

### 实现方式

与 F4/T02 类似，使用 CommandLineRunner + 配置开关。
