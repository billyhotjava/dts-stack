# T07: 历史基线数据导入

**优先级**: P1
**状态**: READY
**依赖**: T04

## 目标
从历史 Excel / ODS 表中反向清洗主数据（project / dept / subsystem 等），合并别名，生成首版主数据基线并导入 MDM。

## 技术设计
详细技术方案在 F2 brainstorming 阶段产出，本文件仅占位。

## 影响范围
- 一次性脚本（清洗 + 导入）
- 导入结果需要业务 review

## 验证
- [ ] 基线导入后，现有 Excel 中的 99%+ 值可以匹配到主数据（未匹配的列出清单）

## 完成标准
- [ ] 基线导入报告 + 残差清单交付业务 review
