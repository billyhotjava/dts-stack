# T07: 历史基线数据导入（不含 person）

**优先级**: P1
**状态**: READY
**依赖**: T04

## 目标
从历史 Excel / ODS 表中反向清洗主数据（project / dept / subsystem / supplier / pbs 五类），合并别名，生成首版主数据基线并导入 MDM。每条基线记录打上 `classification` 标签（默认 `INTERNAL`，涉密数据业务 review 时标注）。**person 不导入**——由 admin/Keycloak 真源，MDM 代理查询。

## 技术设计
详细技术方案在 F2 brainstorming 阶段产出，本文件仅占位。

## 影响范围
- 一次性脚本（清洗 + 导入）
- 导入结果需要业务 review

## 验证
- [ ] 基线导入后，现有 Excel 中的 99%+ 值可以匹配到主数据（未匹配的列出清单）

## 完成标准
- [ ] 基线导入报告 + 残差清单交付业务 review
