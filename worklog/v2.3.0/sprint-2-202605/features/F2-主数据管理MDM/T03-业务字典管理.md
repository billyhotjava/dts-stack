# T03: 业务字典 + 密级字典只读视图

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
统一承载两类字典：

1. **业务字典**（可维护）：完成情况 / 节点类型 / 风险等级 / 更改类别 / 签署状态 / 跟进措施类别 / 闭环状态 / 闭环交付物类别 / 质量原因 / 归零状态 / 风险阶段 / 风险分类 —— 约 12 类，支持别名归一化（`source_code → standard_code`）
2. **密级字典**（**只读视图**）：
   - `mdm_dict_data_security_level`：4 项（PUBLIC / INTERNAL / SECRET / CONFIDENTIAL）
   - `mdm_dict_personnel_security_level`：3 项（GENERAL / IMPORTANT / CORE）
   - 数据由 **bootstrap 任务**从 `dts-common.SecurityLevelCatalog` 导入，UI 不可编辑；保证单一真源

## 技术设计
详细技术方案在 F2 brainstorming 阶段产出，本文件仅占位。

## 影响范围
- 新增 `mdm_dict_*` 表（业务字典）
- 新增 `mdm_dict_data_security_level` / `mdm_dict_personnel_security_level`（只读，bootstrap 导入）
- dbt 层 `dim_*_v2` 将在 F4 改为 MDM 的视图或物化副本
- 前端 `value-localization.ts` 硬编码映射改为调 MDM API
