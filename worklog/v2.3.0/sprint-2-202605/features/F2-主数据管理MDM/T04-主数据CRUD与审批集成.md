# T04: 主数据 CRUD 与审批集成

**优先级**: P0
**状态**: READY
**依赖**: T02, T03, F1

## 目标
新增 / 变更 / 停用 / 合并主数据时，提交审批单至 dts-approval，审批通过后由 MDM 订阅事件落库。

## 技术设计
详细技术方案在 F2 brainstorming 阶段产出，本文件仅占位。

## 影响范围
- MDM 内部 CRUD → 改为"提审批单 → 等待回调 → 落库"两段式
- dts-approval 定义 MDM 相关 `schema_key`

## 验证
- [ ] 未审批时主数据不入库
- [ ] 审批驳回后 payload 可在前端直接再次编辑提交

## 完成标准
- [ ] MDM 的写入路径 100% 经过审批
