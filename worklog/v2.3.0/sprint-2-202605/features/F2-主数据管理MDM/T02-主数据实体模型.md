# T02: 主数据实体模型（含 classification）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
设计 **5 类**主数据表：project / dept / subsystem / supplier / pbs。所有实体采用 ASCII 稳定代理码 + 多语言 label + 别名表 + `classification` 列。**person 不在此列**（由 T06 代理 admin/Keycloak）。

## 技术设计
详细技术方案在 F2 brainstorming 阶段产出，本文件仅占位。

核心约束：
- 每个实体表含 `code VARCHAR UNIQUE NOT NULL`（ASCII 稳定代理键）
- `classification VARCHAR(20) NOT NULL DEFAULT 'INTERNAL'`（引用 `SecurityLevelCatalog.DataSecurityLevel`）
- `valid_from TIMESTAMPTZ` / `valid_to TIMESTAMPTZ NULL`（时点查询）
- 别名表 `mdm_{entity}_alias(source_code, target_code)`

## 影响范围
- 新增 `mdm_project / mdm_dept / mdm_subsystem / mdm_supplier / mdm_pbs`
- 对应别名表
- 与 admin 的 organization 关系：`mdm_dept.admin_org_id` 外键引用（只读），不复制
