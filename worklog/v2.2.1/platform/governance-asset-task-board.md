# 数据治理中心 + 数据资产中心任务总览（v2.2.1）

目标：在现有技术架构（Spring Boot + JPA + Liquibase + React + Ant Design + 现有 API 网关）内，完成治理中心与资产中心能力补齐，不引入新中间件。

## 范围边界

- 仅完善 `dts-platform` / `dts-platform-webapp` 现有模块。
- 不新增独立微服务，不引入脚本驱动流程。
- 任务执行入口以平台页面与 API 为主。

## 任务拆分

### 数据治理中心

见：`worklog/v2.2.1/platform/governance-center/tasks/README.md`

### 数据资产中心

见：`worklog/v2.2.1/platform/asset-center/tasks/README.md`

## 联动任务（跨中心）

1. `P0-X01` 治理与资产统一术语、状态枚举、审计动作字典。
2. `P1-X01` 治理结果（规则/工单/指标）回写资产画像。
3. `P2-X01` 统一前端交互规范（筛选器、空状态、错误态、抽屉详情）。
4. `P3-X01` 联合回归清单（功能、权限、性能、可观测）。

## 里程碑

1. P0：信息架构与权限/查询基线稳定。
2. P1：核心业务闭环跑通（规则->问题->整改，资产->血缘->权限）。
3. P2：高级能力可用（指标版本、码表导入回滚、分级脱敏联动）。
4. P3：容量、回归、上线门禁完成。
