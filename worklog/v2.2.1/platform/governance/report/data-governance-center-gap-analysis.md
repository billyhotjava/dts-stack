# 数据治理中心差距分析（v2.2.1）

## 对齐目标（参考商业产品）

- 统一治理工作台：规则、巡检、问题、合规、指标全链路可视化。
- 统一口径字典：状态、严重性、优先级、生命周期统一枚举。
- 统一执行与报表：运行事实表与展示报表同源。
- 统一可观测：SLA、失败分类、闭环时效可追踪。

## 差距清单

| 领域 | 现状 | 差距 | 影响 |
|---|---|---|---|
| 质量报告 | 读 OpenMetadata 快照 | 未读治理运行事实 | 报告与执行结果不一致 |
| 巡检/合规/问题 UI | API 已具备 | 页面缺失或弱化 | 用户无法闭环操作 |
| 状态字典 | `ARCHIVED/DEPRECATED` 混用 | 枚举未统一 | 前后端状态映射错误 |
| 调度配置 | 存在双前缀 | 配置键不一致风险 | 计划任务不生效或难排障 |
| 回归体系 | 缺治理专项矩阵 | 自动化门禁不足 | 发布风险高 |

## 优先级建议

- P0：先做“口径和主链路一致性”，确保可用与可解释。
- P1：补齐治理主流程页面，保证端到端可操作。
- P2：补可观测与权限治理，提升生产稳定性。
- P3：补自动化门禁和性能基线，支撑规模化交付。
