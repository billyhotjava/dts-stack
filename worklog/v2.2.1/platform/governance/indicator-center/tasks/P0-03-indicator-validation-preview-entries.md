# P0-03 指标校验与预览入口

`status`: `completed`  
`priority`: `P0`

## 目标

在页面提供“发布预检/计算预览”入口，降低 SQL 调试与发布失败率。

## 范围

- 发布预检入口（publish-preview）
- 计算结果预览入口（preview）
- 结果摘要可视化（状态/message/样本行）

## 子任务

1. 前端补齐 API 客户端方法。
2. 增加按钮与结果弹窗。
3. 统一错误处理与提示文案。

## 验收标准

- 能在页面触发发布预检并查看问题列表。
- 能在页面触发计算预览并看到结果摘要。
- 失败场景可复现并定位。

## 风险与回滚

- 风险：预览 SQL 触发权限校验失败。  
- 回滚：仅保留后端接口，隐藏页面入口。
