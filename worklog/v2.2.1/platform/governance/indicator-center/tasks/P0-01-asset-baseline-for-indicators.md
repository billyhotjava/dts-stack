# P0-01 指标依赖底座对齐

`status`: `completed`  
`priority`: `P0`

## 目标

确保指标中心依赖的资产门户信息（数据集、权限、口径字段）可稳定使用，避免指标发布前后不一致。

## 范围

- 指标绑定数据集的可读性（名称/ID 对齐）
- 指标访问权限与部门上下文校验链路确认
- 指标与数据集映射的最小可追溯字段

## 子任务

1. 梳理指标 API 与资产数据集 API 的字段映射关系。
2. 在指标页面展示层避免 ID 裸露，优先显示名称。
3. 固化数据集权限校验失败的错误提示语义。

## 验收标准

- 指标列表和编辑框可稳定显示数据集名称。
- 访问受限时，错误提示可定位到“权限/部门上下文/数据集不存在”。
- 不引入跨模块行为回归。

## 风险与回滚

- 风险：资产数据集缓存与实时数据存在短暂不一致。  
- 回滚：仅回退前端展示层变更，不影响后端持久化结构。
