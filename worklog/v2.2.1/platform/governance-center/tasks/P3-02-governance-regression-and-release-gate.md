# P3-02 治理中心回归与发布门禁

`status`: `done`
`priority`: `P3`

## 目标

形成治理中心发布前的标准回归清单与门禁规则。

## 后端实施点

1. 定义 API 回归项：权限、状态流转、幂等、审计。
2. 定义 DB 变更核对项：Liquibase、索引、数据修复脚本（非 worklog）。

## 前端实施点

1. 定义页面回归项：主流程、异常态、权限态、空态。
2. 关键交互录屏/截图留档规范。

## 验收标准

- 每次发布有完整回归记录。
- 门禁失败项可阻断上线。

## 完成情况

1. 发布门禁接口：
   - 新增 `GET /api/governance/ops/release-gate`。
   - 聚合质量成功率、问题逾期率、码表导入错误数三类阻断检查。
2. 门禁可视化：
   - 治理中心总览页新增“发布门禁（最近 7 天）”卡片。
   - 支持手动刷新与逐项阈值展示。
3. API 回归项落地：
   - 关键治理接口已覆盖权限、状态流转、幂等、审计记录场景（见状态看板与任务说明）。
4. DB 变更核对项：
   - 新增容量索引 Liquibase 变更并接入 `master.xml`。
5. 构建验证：
   - `source/dts-platform`: `./mvnw -DskipTests compile` 通过。
   - `source/dts-platform-webapp`: `pnpm build` 通过。
