# P3-02 资产中心回归与数据一致性核对

`status`: `done`
`priority`: `P3`

## 完成内容

### 后端

1. 新增一致性核对接口：`GET /api/catalog/ops/reconciliation`（维护角色）  
   输出：
   - 资产/表/授权/质量运行/问题单计数概览
   - 标准化断言清单（通过/失败、严重级别、建议）
   - 孤儿记录样本（quality run / issue ticket）
   - 前端回归清单（含路由与说明）

2. 当前断言覆盖：
   - 资产目录非空
   - 质量运行无孤儿记录
   - 问题工单无孤儿记录
   - 启用资产存在快照时间
   - 资产负责人部门已维护
   - 失效资产占比可控

### 前端

1. 资产页新增“发布前回归与一致性核对”面板：
   - 断言总数、失败项、错误级、告警级
   - 失败断言明细与修复建议
   - 核心页面回归清单（可直接跳转页面）
   - 支持“重新核对”刷新

2. 对无权限场景采用非阻断展示：
   - 维护角色可看到核对结果
   - 其他角色显示空态提示，不弹错误风暴

## 验收结果

- 上线前可执行标准化核对（API + 页面）。
- 回归失败可定位到具体断言、建议和页面入口。
