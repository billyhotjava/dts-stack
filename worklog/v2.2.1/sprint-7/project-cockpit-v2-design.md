# 项目管理作战室 V2 设计文档

## 背景

V1版本存在三个核心问题：
1. 可视化组件单调（仅KPI数字+柱图+饼图）
2. 数据联动弱（仅月份/项目号筛选，无点击钻取）
3. 布局像Excel报表，缺乏专业感

## KPI指标带（5个 combo-chart）

每个KPI用combo-chart实现：主值文字(graphic) + 环比箭头 + 6期火花线(line系列)。

| 指标 | 条件着色 |
|------|---------|
| 完成率 | <60%红, 60-80%橙, ≥80%绿 |
| 准时率 | <70%红, 70-85%橙, ≥85%绿 |
| 超期率 | >30%红, 15-30%橙, <15%绿 |
| 未完成数 | >5红, 1-5橙, 0绿 |
| 高风险数 | >3红, 1-3橙, 0绿 |

环比通过SQL `LAG()` 窗口函数计算。

## 项目记分卡排行（table）

列：项目编号、完成率、准时率、超期数、高风险数、健康度、趋势。
健康度 = 完成率×40% + 准时率×30% + (1-超期率)×20% + (1-高风险率)×10%。
按健康度降序排列。点击行→设置v_project_no→联动下方所有面板。

## 中间三面板

### 进度漏斗（funnel-chart, 8/24列）
总计→已完成→进行中→超期未完→未启动，逐层收缩。
需新增funnel-chart数据映射器。

### 责任人任务分布（bar-chart, 8/24列）
横向堆叠柱状图，按责任人分组。
系列：已完成(绿)+进行中(蓝)+超期(红)+未启动(灰)。
已有bar-chart映射器。

### 风险气泡图（scatter-chart, 8/24列）
X=超期天数, Y=风险等级(1/2/3), 气泡大小=节点数。
需新增scatter-chart数据映射器。

## 甘特图增强

在现有基础上增加：
1. 里程碑菱形标记（renderItem判断type）
2. 分组间距（按node_type分组）
3. 未启动节点灰色虚线框

## 节点明细表（table）

完成状态用中文标签+emoji（✅按时完成/⚠超期完成/🔴未完成/⏳进行中）。
默认按风险等级降序→超期天数降序排序。

## 数据联动

```
月份筛选 ──→ v_plan_month ──→ 全部组件刷新
项目筛选 ──→ v_project_no ──→ 中间面板+甘特+明细刷新
记分卡行点击 ──→ v_project_no ──→ 同上
```
