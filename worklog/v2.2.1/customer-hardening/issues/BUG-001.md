# BUG-001

## Module

`source/dts-platform`

## Symptom

`mvn -f source/dts-platform/pom.xml -DskipTests compile` succeeds, but Maven enforcer reports dependency convergence violations during baseline verification.

## Reproduction

1. Run `mvn -f source/dts-platform/pom.xml -DskipTests compile`
2. Observe dependency convergence warnings from `enforcer`
3. Confirm the conflicts reference:
   - `commons-io`
   - `commons-compress`
   - `nimbus-jose-jwt`

## Expected Behavior

The baseline compile should complete without dependency convergence violations so future bug-fix work is not built on a noisy or unstable dependency graph.

## Candidate Fix Area

- `source/dts-platform/pom.xml`
- transitive dependency management for:
  - `easyexcel`
  - `liquibase-core`
  - `kerb-client`
  - `spring-boot-starter-oauth2-client`

## Verification Command

`mvn -f source/dts-platform/pom.xml -DskipTests compile`
