# 大屏设计器功能差距分析

> 对标产品: DataV (阿里), FineReport/FineBI (帆软), Grafana, Power BI Dashboard, Tableau Dashboard, 积木报表 (JimuReport)
>
> 分析日期: 2025-02-13
> 当前版本功能清单: 25 种组件, 5 套模板, 3 套主题, 拖拽/缩放/撤销/图层/数据绑定/钻取

---

## 一、需要优化的已有功能 (P0/P1)

### 1. 组件颜色不可定制

**现状**: 图表颜色由主题 token 统一控制 (colorPalette、barGradient 等), 用户无法在属性面板中修改单个图表的配色方案。number-card 的颜色也由主题统一控制, 不支持每个卡片独立设置。

**商业软件做法**: 每个图表组件都有独立的「系列颜色」配置, 用户可逐条修改; number-card 支持独立设置背景色/标题色/数值色。

**建议**:
- PropertyPanel 增加「颜色」分区, 提供 series 级别的颜色选择器
- number-card 增加 `titleColor` / `valueColor` / `backgroundColor` 配置项 (优先级 > 主题 token)
- 使用 `config.xxx || themeDefault` 的 fallback 模式, 无配置时走主题默认

### 2. 字体不可调整

**现状**: 仅 `title` 和 `datetime` 组件支持 fontSize/fontWeight/color。图表的标题字号固定 14px, 轴标签字号固定、number-card 标题 12px/数值 32px 均硬编码在 ComponentRenderer 中。

**商业软件做法**: 所有文字元素均可调整字体族、字号、粗细、颜色、行高、字间距。

**建议**:
- 为 number-card 增加 `titleFontSize` / `valueFontSize` / `titleFontWeight` / `valueFontWeight` 配置
- 为图表组件增加 `titleFontSize` / `axisFontSize` / `legendFontSize` 配置
- PropertyPanel 增加「字体」分区, 统一管理文字样式

### 3. 表格组件不可自定义表头

**现状**: scroll-board 的 header 在组件 config 中定义为固定数组, 仅在模板中预设。若数据源返回字段名为 `no`、`patent_name`, 无法在设计器中将其重命名为「序号」「专利名称」。

**商业软件做法**: 表格组件支持「字段映射」功能, 可设置显示名称、列宽、对齐方式、排序、格式化。

**建议**:
- PropertyPanel 中为 scroll-board 增加表头编辑器 (可逐列修改显示名)
- 数据绑定时在 `cardDataMapper` 中增加 `columnAlias` 映射: `{ "no": "序号", "patent_name": "专利名称" }`
- 支持列宽比例配置 (当前 DataV ScrollBoard 支持 `columnWidth` 数组)
- 支持对齐方式配置 (当前硬编码 `['center', 'center', 'center']`)

## 二、设计器核心能力差距 (P1)

### 4. 缺少对齐与分布工具

**现状**: 组件完全自由拖放, 无对齐辅助。多个 KPI 卡片要排成一行时只能手动输入坐标。

**商业软件做法**: 提供对齐按钮 (左/右/上/下/水平居中/垂直居中) + 等距分布 + 拖拽时智能辅助线 (snap to edge/center)。

**建议**:
- CanvasToolbar 增加对齐/分布按钮组
- 拖拽时显示智能辅助线 (检测与其他组件边缘/中心的距离, 距离 < 5px 时吸附)
- 等距分布: 选中多个组件后一键水平/垂直等距排列

### 5. 缺少组件分组

**现状**: 无法将多个组件组合为一个整体, 无法批量移动/缩放。

**商业软件做法**: 支持 Group/Ungroup, 组可嵌套, 组整体移动/缩放时子组件等比变换。

### 6. 缺少多选批量编辑

**现状**: 属性面板仅支持单选编辑。选中多个组件后属性面板显示空。

**商业软件做法**: 多选时显示共有属性 (位置/大小/颜色/字号), 修改后批量应用。

### 7. 缺少标尺与参考线

**现状**: 仅有网格线, 无标尺, 无手动参考线。

**商业软件做法**: 顶部/左侧标尺, 从标尺拖出参考线, 组件吸附到参考线。

### 8. 拖拽/缩放无 undo 记录

**现状**: Move/Resize 操作不记录到撤销历史 (注释: "Too many entries during drag")。

**建议**: 在 mouseup 时记录最终位置, 而非每帧记录, 平衡性能与可恢复性。

## 三、数据能力差距 (P1/P2)

### 9. 缺少 SQL 直连数据源

**现状**: 只能绑定已创建的 Card (问题卡片), 不能直接写 SQL 查询。

**商业软件做法**: 支持直接输入 SQL、选择数据库、实时预览结果。

**建议**: 增加 `dataSource.type = 'sql'`, 配置项包含 `databaseId` + `query`, 复用 analytics 平台的 dataset API。

### 10. 缺少数据过滤/转换

**现状**: 绑定 Card 后数据直接使用, 无法过滤、排序、聚合、计算列。

**商业软件做法**: 数据源绑定后可添加过滤条件、排序规则、字段公式 (如计算同比/环比)。

### 11. 缺少全局参数/筛选器

**现状**: 无全局筛选组件 (如日期范围选择器、下拉筛选器), 各组件独立。

**商业软件做法**: 支持「筛选器组件」(下拉框/日期选择/搜索框) 绑定到多个图表, 修改筛选值后所有关联图表联动刷新。

**建议**:
- 增加 `filter-select` / `filter-date-range` / `filter-input` 组件类型
- ScreenConfig 增加 `globalParams: Record<string, unknown>`
- 图表数据源可引用 `{{param.xxx}}` 作为查询参数

### 12. 缺少数据刷新策略

**现状**: 仅支持 `refreshInterval` (定时轮询), 无手动刷新按钮, 无 WebSocket 实时推送。

**商业软件做法**: 支持手动刷新、定时轮询、WebSocket 推送、事件触发刷新。

## 四、组件能力差距 (P2)

### 13. 缺少地图组件

**现状**: 无地图组件。

**商业软件做法**: 支持中国地图/世界地图/省级地图, 数据按区域着色, 支持下钻到省/市。

**建议**: 基于 ECharts `map` 系列, 注册 GeoJSON, 支持地图下钻。

### 14. 缺少表格组件 (非滚动)

**现状**: 仅有 DataV ScrollBoard (滚动表), 无静态分页表格。

**商业软件做法**: 支持标准表格组件: 分页、排序、搜索、冻结表头、列宽拖拽、条件格式 (单元格变色)。

### 15. 缺少富文本/Markdown 组件

**现状**: 仅有 `title` (单行文本)。

**商业软件做法**: 支持富文本编辑器 (多行、多样式、链接、列表), 或 Markdown 渲染。

### 16. 缺少形状/容器组件

**现状**: 无矩形/圆形/线条等基础形状, 无容器 (Panel) 组件。

**商业软件做法**: 支持矩形/圆角矩形/圆形/线条/箭头, 容器组件可包含子组件并设置内边距/边框/阴影。

### 17. 缺少 Tab/轮播 组件

**现状**: 无 Tab 切换组件, 无自动轮播组件。

**商业软件做法**: 支持 Tab 容器 (多页切换), 轮播容器 (自动/手动翻页), 图片轮播。

### 18. 缺少倒计时/跑马灯组件

**现状**: 仅有 `datetime` (实时时间)。

**商业软件做法**: 支持倒计时组件 (距目标时间), 跑马灯/滚动字幕组件。

## 五、交互与体验差距 (P2)

### 19. 缺少组件动画

**现状**: 仅 DataV 组件有内置动画, ECharts 有默认入场动画, 基础组件无动画。

**商业软件做法**: 支持组件入场动画 (淡入/飞入/缩放), 循环动画 (呼吸/闪烁/弹跳), 交互动画 (悬停放大)。

### 20. 缺少事件/交互配置

**现状**: 仅钻取 (drill-down) 支持点击交互, 其他组件无交互配置。

**商业软件做法**: 支持组件点击事件 (跳转链接/弹窗/联动其他组件/执行自定义 JS)。

### 21. 缺少条件样式

**现状**: 颜色统一, 无法根据数值动态变色 (如 < 60 显示红色, > 90 显示绿色)。

**商业软件做法**: 支持条件格式化: 根据数值区间、阈值、正则表达式动态改变颜色/字号/图标。

### 22. 右键菜单

**现状**: 无右键菜单, 操作需通过工具栏或键盘。

**商业软件做法**: 右键菜单包含: 复制/粘贴/删除/锁定/置顶/置底/对齐/分组 等常用操作。

### 23. 组件搜索与收藏

**现状**: 组件面板无搜索功能, 25 种组件需手动翻找。

**商业软件做法**: 组件库支持关键词搜索、收藏/常用、最近使用。

## 六、导出与协作差距 (P2/P3)

### 24. 缺少导出功能

**现状**: 无法导出为图片/PDF/JSON。

**商业软件做法**:
- 导出为 PNG/JPG (html2canvas 或 puppeteer 截图)
- 导出为 PDF (A4/自定义尺寸)
- 导出/导入 JSON 配置 (用于备份/迁移/版本管理)

### 25. 缺少版本历史

**现状**: 保存即覆盖, 无版本记录。

**商业软件做法**: 保存时自动创建版本快照, 可查看/回滚到历史版本, 显示修改时间和操作人。

### 26. 缺少移动端适配

**现状**: 固定画布尺寸 (1920x1080), 预览时等比缩放, 无移动端响应式布局。

**商业软件做法**: 支持多终端适配 (PC/平板/手机), 支持自适应布局模式。

### 27. 缺少协作功能

**现状**: 单用户编辑, 无协作机制。

**商业软件做法**: 支持多人协同编辑 (OT/CRDT), 权限管理 (查看/编辑/管理), 评论/批注。

## 八、当前功能现状总结

| 维度 | 已实现 | 差距 |
|------|--------|------|
| 组件种类 | 25 种 (含 DataV) | 缺地图/表格/富文本/形状/容器 |
| 数据绑定 | Card 绑定 + 自动映射 | 缺 SQL 直连/过滤/转换/全局参数 |
| 交互 | 钻取下钻 | 缺联动/事件/条件样式 |
| 主题 | 3 套主题 token | 缺组件级颜色覆盖 |
| 模板 | 5 套内置 | 够用, 可持续补充 |
| 编辑器 | 拖拽/缩放/撤销/图层/复制 | 缺对齐/分组/右键/标尺 |
| 导出 | 预览 + 公开链接 | 缺 PNG/PDF/JSON 导出 |
| 协作 | 无 | 缺多人协作/版本历史 |
