# P0-03 设计器生产力工具

`status`: `done`  
`priority`: `P0`  
`inspiration`: `DataEase(低门槛拖拽) + 专业设计器交互范式`

## 目标

提升设计效率，减少“靠手工拖坐标”的低效体验。

## 子任务

1. 对齐与分布
- 工具栏支持左/右/上/下/水平居中/垂直居中/等距分布。

2. 智能吸附
- 拖动时显示辅助线，5px 内自动吸附（边缘/中心）。

3. 分组能力
- 支持 `Group/Ungroup`，组整体移动与缩放。

4. 多选批量编辑
- 多选时属性面板显示共有属性并可批量改。

5. 撤销一致性
- Move/Resize 在 `mouseup` 记录历史，确保可撤销。

## 验收标准

- 选中 3 个组件可一键水平等距分布。
- 拖拽/缩放后可 `Ctrl+Z` 精确回退。
- 组合后可整体移动且子组件位置保持相对关系。

## 风险与回滚

- 风险：历史栈过大导致性能下降。  
- 回滚：限制历史长度并在复杂操作时合并 patch。

## 实现记录（2026-02-14）

- 已完成对齐与分布工具栏能力（左/右/上/下/居中/水平分布/垂直分布）。
- 已完成智能吸附（5px 容差，显示横/竖辅助线，边缘/中心对齐）。
- 已完成分组基础能力（Group/Ungroup，组成员联动移动）。
- 已完成组整体缩放（按组选区边界等比重算位置与尺寸）。
- 已完成多选批量编辑（统一宽高、锁定、可见）。
- 已完成撤销一致性：Move/Resize 在 `mouseup` 触发 `SNAPSHOT`，可 `Ctrl+Z` 回退。
