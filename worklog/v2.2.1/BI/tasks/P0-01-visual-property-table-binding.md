# P0-01 视觉属性与表格绑定补齐

`status`: `done`  
`priority`: `P0`  
`inspiration`: `DataEase(低代码属性面板) + 商业 BI 表格字段映射`

## 目标

先把“可视化设计最直观缺陷”补齐：颜色、字体、表格列标题与字段自由绑定，解决当前“可配置性弱、业务可读性差”的问题。

## 子任务

1. 颜色体系
- 属性面板新增「颜色」分组（标题色、数值色、背景色、系列色）。
- 组件配置采用 `component override > theme token > fallback`。

2. 字体体系
- 新增 `fontFamily/fontSize/fontWeight/lineHeight/letterSpacing` 通用字段。
- `number-card`、图表标题、坐标轴、图例统一走字体配置。

3. 表格字段自由绑定（重点）
- 表格支持 `columnBindings[]`：`sourceField/displayName/width/align/formatter/sortable`。
- 允许字段重命名、隐藏、排序、默认格式化（数字/百分比/日期）。

4. 预览一致性
- 设计器与预览页采用同一渲染配置，不允许“编辑态与预览态样式不一致”。

## 验收标准

- 新建表格组件后可把 `patent_name` 映射为“专利名称”，预览显示正确。
- 同一组件可独立设置颜色和字体，且不影响其他组件。
- 导出/保存后重新打开，配置不丢失。

## 风险与回滚

- 风险：旧配置字段缺失导致渲染异常。  
- 回滚：保留旧字段兼容读取逻辑，新增字段默认可空。
