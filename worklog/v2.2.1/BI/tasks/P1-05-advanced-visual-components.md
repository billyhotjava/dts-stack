# P1-05 高级可视化组件集

`status`: `in-progress`  
`priority`: `P1`  
`inspiration`: `DataEase(业务组件覆盖) + 商业大屏产品组件能力`

## 目标

补齐当前缺失的高频组件，达到可交付项目所需覆盖度。

## 子任务

1. 地图组件
- 中国/世界地图，支持区域下钻与着色映射。

2. 静态表格组件
- 分页、排序、冻结表头、条件格式。

3. 富文本与 Markdown
- 支持标题层级、列表、链接、内联样式。

4. 形状与容器
- 矩形/圆形/线条/箭头，容器可嵌套子组件。

5. 轮播与倒计时
- Tab/轮播容器、倒计时、跑马灯组件。

## 验收标准

- 地图组件支持最少一级下钻。
- 静态表格可完成排序和分页。
- 容器组件可成组拖动内部组件。

## 风险与回滚

- 风险：组件数增多导致面板难用。  
- 回滚：引入组件搜索、收藏、最近使用分组。

## 实现记录（2026-02-14）

- 已完成第一批高级组件落地：
  - 新增组件类型：`map-chart`、`markdown-text`、`shape`、`container`、`countdown`、`marquee`。
  - 组件库已新增对应入口与默认配置（地图/文本/形状容器分类）。

  - 组件库默认配置补齐（`enableSort/enablePagination/pageSize/freezeHeader/freezeFirstColumn/conditionalFormatting`），新建表格即可直接使用高级能力。
  - 属性面板 `TableConfig` 增加上述开关与参数配置。
  - 2026-02-16：字段绑定编辑器升级（增删列、上下调整顺序、自由切换绑定源、恢复默认/清空），提升业务表头编排效率。
- 文本与形状增强：
  - Markdown 支持标题/列表/链接/粗斜体（轻量解析）。
  - 形状支持矩形/圆形/线条/箭头；容器组件支持标题与视觉分区。
  - 新增倒计时与跑马灯组件。
