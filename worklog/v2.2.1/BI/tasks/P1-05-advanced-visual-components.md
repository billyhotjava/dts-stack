# P1-05 高级可视化组件集

`status`: `done`  
`priority`: `P1`  
`inspiration`: `DataEase(业务组件覆盖) + 商业大屏产品组件能力`

## 目标

补齐当前缺失的高频组件，达到可交付项目所需覆盖度。

## 子任务

1. 地图组件
- 中国/世界地图，支持区域下钻与着色映射。

2. 静态表格组件
- 分页、排序、冻结表头、条件格式。

3. 富文本与 Markdown
- 支持标题层级、列表、链接、内联样式。

4. 形状与容器
- 矩形/圆形/线条/箭头，容器可嵌套子组件。

5. 轮播与倒计时
- Tab/轮播容器、倒计时、跑马灯组件。

## 验收标准

- 地图组件支持最少一级下钻。
- 静态表格可完成排序和分页。
- 容器组件可成组拖动内部组件。

## 风险与回滚

- 风险：组件数增多导致面板难用。  
- 回滚：引入组件搜索、收藏、最近使用分组。
