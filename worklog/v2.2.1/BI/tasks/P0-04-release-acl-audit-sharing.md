# P0-04 发布、权限、审计、安全分享闭环

`status`: `done`  
`priority`: `P0`  
`inspiration`: `Metabase(发布与嵌入链路) + DataEase(企业权限治理)`

## 目标

建立“可上线”的治理闭环，降低客户现场风险。

## 子任务

1. 发布体系
- 草稿/发布双轨，发布生成版本号，可回滚。

2. ACL
- 大屏级权限：`read/edit/publish/manage`。

3. 分享安全
- 公开链接支持过期时间、访问口令、IP 白名单。

4. 审计日志
- 记录创建、编辑、发布、回滚、分享动作和操作者。

## 验收标准

- 未授权用户不可进入编辑页。
- 公开链接仅可访问发布版，不可访问草稿。
- 可按 `screenId` 查询完整操作链路。

## 风险与回滚

- 风险：权限模型与平台用户体系冲突。  
- 回滚：先做单租户 ACL 映射，再扩展组织维度。

## 实现记录（2026-02-14）

- 发布体系：草稿/发布双轨、版本号、回滚接口已接入并在编辑器可操作。
- ACL：已提供大屏级权限接口与前端管理面板（`read/edit/publish/manage`）。
- 分享安全：已支持过期时间、访问口令、IP 白名单、禁用开关，并提供分享策略面板。
- 审计日志：新增按 `screenId` 查询审计链路接口，前端提供审计查看面板。
- 审计面板可用性增强（2026-02-15）：
  - 新增动作筛选、关键字搜索、仅导出事件过滤；
  - 新增自动轮询刷新（可开关，支持间隔配置）；
  - 新增审计统计卡（总数/筛选后/导出事件），提升现场排障效率。
- 编辑权限拦截：编辑页加载时若 `canEdit=false`，前端直接拦截并跳转列表页。
- 列表页发布链路便捷化（2026-02-23）：
  - `ScreensPage` 卡片操作收口为“编辑/预览/分享 + 更多”，降低按钮密度；
  - “更多”菜单新增“复制预览链接”，发布后可直接复制并分发，不必再进入编辑器；
  - 卡片菜单支持外部点击关闭与 `ESC` 关闭，提升旧浏览器下的交互稳定性；
  - 卡片元信息新增“已发布/未发布 + 版本号 + 发布时间”状态标签，便于现场快速判断可分发状态。
- 大屏列表检索效率增强（2026-02-23）：
  - 列表页新增名称/描述搜索框、发布状态筛选与排序（更新时间/名称）；
  - 统计区新增“总计/已发布/未发布/当前筛选结果”即时计数；
  - 筛选无结果时提供“重置筛选”空态入口，降低现场排查时间；
  - 筛选条件（搜索词/发布状态/排序）本地记忆，刷新后保持现场工作上下文；
  - 列表工具条和卡片操作补移动端断点布局，减少窄屏现场设备下操作遮挡；
  - 页面标题、错误提示与 AI 弹窗标题去除装饰 emoji，统一商务化文案风格；
  - 工具条新增常驻“重置”按钮，支持一键恢复默认筛选与排序。
- 发布可见性与分发链路兜底（2026-02-23）：
  - 编辑页发布成功通知（预览/公开链接）增加本地持久化，页面刷新后仍可查看与复制；
  - 若本地无发布通知，编辑页会自动基于已发布版本回填一条只读发布信息（含预览链接），避免“刷新后看不到链接”；
  - 发布通知保留 `Analytics首页/大屏中心` 快速入口，缩短发布后跳转路径；
  - 大屏列表卡片“更多”菜单层级提升并改为不透明面板，修复被卡片裁切导致“点击无反应”的问题。
  - 已发布卡片新增“预览链接 + 复制”快捷入口，支持列表页直接分发链接，无需回到编辑页。
  - 列表卡片主按钮进一步收口为“编辑/预览/更多”，“分享链接”并入更多菜单，减少主操作区按钮密度。
  - 列表卡片新增定位上下文与更高菜单层级，避免“更多”弹层被相邻卡片遮挡导致误判为无响应。
- Analytics 首页发布入口补齐（2026-02-23）：
  - 首页新增“已发布大屏”卡片，展示最新发布条目与版本号；
  - 支持从首页直接打开发布预览链接，减少“发布后找不到入口”的反馈；
  - 空态提供“打开大屏中心”快捷入口，打通发布后分发路径。
