# P0-01 发布体系（草稿/发布/回滚）

## 目标
- 建立屏幕版本双轨：草稿可编辑、发布可访问、可回滚。

## 范围
- BE：`analytics_screen_version` 表、发布/回滚 API。
- FE：设计器 Header 发布入口、版本历史侧栏。
- QA：并发发布/回滚一致性回归。

## 交付物
- DDL + migration
- API 文档
- 前端版本流程

## 验收
- 连续发布 10 次后可回滚任意版本。
- 公开链接始终读取最新发布版。

## 回滚点
- 发布流程异常时可强制回退到上一个发布版本。
