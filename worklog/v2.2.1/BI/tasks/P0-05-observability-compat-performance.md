# P0-05 可观测、兼容、性能基线

`status`: `done`  
`priority`: `P0`  
`inspiration`: `Superset(可观测查询链路) + 现场交付稳定性要求`

## 目标

确保现场遇到 500/502 时可以快速定位，且旧版浏览器可用。

## 子任务

1. 统一错误观测
- 前后端统一 `requestId` 贯穿日志。
- API 错误暴露 `code/retryable`。

2. 缓存与预热
- 发布后支持关键组件预热。
- 缓存观测面板显示命中率、驱逐数、策略状态。

3. 浏览器兼容
- 最低支持 Chrome 95，回归 109 与最新版本。

4. 性能门槛
- 100 组件大屏首屏时间与交互延迟建立基线。

## 验收标准

- 任意错误可通过 `requestId` 定位到后端日志。
- Chrome 95 下核心编辑功能可用且无明显样式错乱。
- 缓存策略修改后可立即生效并可观测。

## 风险与回滚

- 风险：兼容补丁影响现代浏览器性能。  
- 回滚：按 capability 判断启用兼容路径，不全局降级。

## 实现记录（2026-02-14）

- 错误观测：后端 `ApiError` 新增 `retryable`，并输出 `X-Error-Code/X-Error-Retryable`；请求日志补充 `requestId`。
- 前端错误模型：`HttpError` 增加 `retryable` 解析，错误信息携带 `code/retryable/requestId`。
- 健康体检：新增 `/analytics/api/screens/{id}/health`，输出草稿/发布态组件复杂度、可预热源、100组件基线判定和建议。
- 设计器入口：新增“体检”面板，展示浏览器兼容（Chrome95+基线）与性能健康报告。
- 缓存观测与发布预热：沿用既有 `缓存观测` 面板与发布 warmup 汇总链路。
- Chrome 95 兼容补强（2026-02-15）：
  - 构建目标已固定支持 `chrome95`（`vite build` 默认 `LEGACY_BROWSER_BUILD=1`）。
  - 分享链接复制统一切换到 `writeTextToClipboard`（`navigator.clipboard` + `execCommand` fallback），覆盖非安全上下文与旧浏览器策略限制。
  - Modal 层级上调到 `z-index 20000+`，避免设计器高层元素遮挡导致弹窗“点击无响应/不可见”。
  - 修复实际 token 覆盖问题：`--z-modal-backdrop/--z-modal` 从 `300/400` 调整到 `20000/20001`，并补 `top/right/bottom/left` 定位兜底，解决“变量/缓存观测/合规点击后弹窗不显示”。
- 查询稳定性补强（2026-02-15）：
  - `CardResource.get` 明确改为 `@Transactional(propagation = NOT_SUPPORTED)`；
  - 避免读取卡片元数据时外部数据源异常污染事务状态并触发 `UnexpectedRollbackException`。
- 查询事务边界补强（2026-02-20）：
  - `CardResource` 移除类级 `@Transactional`，仅在 `create/update/delete` 写接口保留事务；
  - 读/查询接口不再被外层控制器事务包裹，降低外部数据源连接失败时触发 `rollback-only -> UnexpectedRollbackException` 的概率；
  - 与现有 `EXT_DB_*` 错误码链路配合，查询失败优先返回可诊断错误而非通用事务回滚 500。
- 设计器工具栏兼容收口（2026-02-22）：
  - 通过 `@media (max-width: 1440px)` 压缩工具栏按钮/间距/下拉控件尺寸；
  - 配合工具栏按钮归并，减少低分辨率与 Chrome 95 场景下“按钮显示不全/被挤出可视区”的风险。
- 小尺寸渲染稳态优化（2026-02-22）：
  - 新增可配置“小屏布局预设”与图例自动避让，减轻低分辨率/老浏览器缩放场景下的图例遮挡与轴标签重叠；
  - 默认保持向后兼容（手工配置优先），仅在未显式配置时启用启发式布局回退。
- 头部操作区密度优化（2026-02-22）：
  - 在 `max-width: 1440px` 下收紧 `screen-header` 间距与主操作按钮尺寸；
  - 降低“预览/发布/保存”按钮在低分辨率场景中的挤压换行风险。
- 图例文本兼容性优化（2026-02-22）：
  - 对长中文/长英文图例名称启用像素宽度估算 + 截断回退，降低 Chrome 95 及小尺寸容器下布局抖动；
  - 保持手工配置优先，启发式仅在自动模式生效。
- 图表动画降级策略（2026-02-22）：
  - 极小尺寸容器或大数据点场景自动关闭图表动画，降低预览态掉帧与卡顿风险；
  - 在现代浏览器与 Chrome 95 均可生效，不影响手工配置的布局参数。
- 手动精调与自动策略共存（2026-02-22）：
  - 新增图例偏移/文本宽度、标签最小角度/引导线长度等参数；
  - 执行顺序保持“手工覆盖 > 自动避让兜底”，避免现场调优后被启发式策略反向覆盖。
- 交互调优效率提升（2026-02-22）：
  - 新增设计态图例拖拽锚点，调优过程从“多次输入数值”降为“可视化拖拽 + 一次落参”。
- Chrome 95 菜单样式兼容修复（2026-02-23）：
  - 头部“更多”下拉面板去除 `backdrop-filter` 依赖，改为不透明主题底色；
  - 避免旧版浏览器出现黑底/半透明异常，确保菜单观感与主界面一致。
- 预览页滚动可达性修复（2026-02-23）：
  - 预览页与公开页容器改为显式双向滚动（`overflowX/overflowY`）；
  - 内容对齐从居中调整为左上锚点，避免大屏超出时顶部/左侧内容不可滚动到达。
- 预览画布边界扩展（2026-02-23）：
  - 预览页与公开页按组件真实边界自动扩展可视画布；
  - 当组件超出设计稿宽高时，仍可通过滚动条访问，避免被固定画布裁切导致“图表消失”。
- 下拉菜单黑底兼容兜底（2026-02-23）：
  - 头部菜单与工具栏菜单补纯色兜底背景（先白底再主题变量），并显式设置文本色；
  - 降低旧版浏览器变量解析异常时出现“菜单发黑/半透明”的概率。
  - 大屏列表页卡片“更多”菜单同步补齐白底/文本色/禁用滤镜兜底，确保列表与编辑器一致。
- 预览缩放交互增强（2026-02-23）：
  - 预览页/公开页新增 `Ctrl/Cmd + 鼠标滚轮` 连续缩放；
  - 与现有 `F/0/+/-` 快捷键共存，适配现场演示时快速调整视图比例。
  - 预览控制条新增“百分比直接输入”（20-200），支持快速跳转目标缩放比。
- 设计器主题变量兼容补齐（2026-02-23）：
  - 为大屏设计器作用域显式补齐 `surface/primary` 变量映射，避免变量缺失导致的透明/黑底回退；
  - “更多”菜单统一使用不透明面板底色，减少 Chrome 95 下菜单发黑和层次不清问题。
- 预览滚动可达性再补强（2026-02-23）：
  - 预览页与公开页改为基于组件包围盒计算可视边界（包含负坐标组件）；
  - 组件渲染坐标按包围盒偏移回正，确保超出设计稿边界的图表仍可通过滚动访问。
- 预览控件主题统一（2026-02-23）：
  - 预览缩放控制条改为主题变量配色，不再固定黑底；
  - 与白底商务模板和暗色模板保持一致可读性，降低现场环境色差引起的误判。
