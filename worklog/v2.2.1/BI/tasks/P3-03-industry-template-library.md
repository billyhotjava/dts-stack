# P3-03 行业模板库扩充

`status`: `done`
`priority`: `P3`
`sprint`: `Sprint 1 - 核心图表扩展`
`inspiration`: `DataEase(60+ 行业模板) + 现场交付"5 分钟出屏"需求`

## 目标

将内置模板从 5 个扩展到 20+ 个，覆盖 6 个核心行业场景，降低新用户上手门槛。

## 差距分析

| 行业 | DTS 当前 | DataEase | 目标数量 |
|------|:---:|:---:|:---:|
| 通用监控 | 1 | ~10 | 3 |
| 政务/智慧城市 | 0 | ~8 | 3 |
| 制造/能源 | 0 | ~6 | 3 |
| 零售/电商 | 0 | ~8 | 3 |
| 金融/风控 | 0 | ~5 | 3 |
| 教育/医疗 | 0 | ~5 | 2 |
| 空白模板 | 1 | 1 | 3（不同尺寸） |

## 子任务

### 1. 模板基础设施增强

**文件**: `screenTemplates.ts`

- 新增模板分类字段：`category: 'general' | 'government' | 'manufacturing' | 'retail' | 'finance' | 'education'`。
- 新增模板预览缩略图：`thumbnail` 字段从 emoji 升级为 SVG 预览图或截图 URL。
- 新增模板标签：`tags: string[]` 用于搜索过滤。
- 新增模板尺寸预设：`1920×1080`（标准）、`3840×2160`（4K）、`1280×720`（小屏）。

## 验收标准

- 模板库 ≥ 20 个，覆盖 6 个行业。
- 模板浏览器支持分类过滤和搜索。
- 从模板创建大屏后可立即预览，布局合理。
- 所有模板在 Chrome 95 下正常渲染。

## 风险与回滚

- 风险：模板数据过多导致 `screenTemplates.ts` 文件膨胀。
- 回滚：模板配置改为按需 import 的独立 JSON 文件（`templates/government/*.json`）。
