利用已有 NL2SQL / AI Copilot 基础设施，提供"数据 → 图表类型推荐"和"一键智能配色"能力，进一步降低建屏门槛。

- P2-01 已实现 AI 大屏 Copilot（NL → ScreenSpec 草稿）。
- P0-06/P0-07 已建立 NL2SQL 基线。
- 缺少：选定数据源后的图表类型推荐、配色方案推荐。

## 子任务

### 1. 图表类型推荐引擎

**后端新增**: `ChartRecommendService`

**输入**: 数据集元数据（列名、列类型、行数、唯一值数）
**输出**: 推荐图表类型列表（排序 + 理由）

**规则引擎（Phase 1 规则驱动）**:

| 数据特征 | 推荐图表 | 理由 |
|---------|---------|------|
| 1 维度(文本) + 1 度量 | 柱状图/饼图 | 类别对比 |
| 1 维度(日期) + 1 度量 | 折线图 | 时间趋势 |
| 1 维度(日期) + N 度量 | 组合图/多线图 | 多指标趋势对比 |
| 1 维度(地理) + 1 度量 | 地图 | 地理分布 |
| 2 度量 | 散点图 | 相关性分析 |
| N 维度(层级) + 1 度量 | 矩形树/旭日图 | 层级结构 |
| 阶段流程 + 度量 | 漏斗图 | 转化分析 |
| 单值 | 仪表盘/KPI 卡片 | 关键指标 |

**Phase 2（LLM 驱动）**: 调用 AI 接口分析数据语义给出推荐。

### 2. 前端推荐 UI

**文件**: 属性面板 或 组件创建向导

**触发**:
- 在空组件上绑定数据源后，自动展示推荐卡片。
- 推荐卡片：图表类型图标 + 推荐理由 + "使用此类型"按钮。
- 最多展示 3 个推荐。
- 点击"使用此类型"自动切换组件类型并应用字段映射。

### 3. 智能配色方案

**新增**: `utils/colorSchemes.ts`

**预置色板**:
- 商务蓝（默认）
- 科技紫
- 自然绿
- 暖色调
- 冷色调
- 高对比度（无障碍友好）

**一键应用**:
- 属性面板 → 样式 → "配色方案" 下拉选择。
- 选择后自动替换：
  - ECharts `color` 调色板
  - 背景色/边框色/文字色（保持主题协调）
  - 系列独立颜色

**智能推荐**:
- 根据当前主题自动推荐匹配的配色方案。
- 根据数据类型推荐（如地图推荐色阶渐变、饼图推荐高对比色）。

### 4. 数据概况面板

**新增**: 属性面板 → 数据源 → 展开"数据概况"

展示绑定数据的统计摘要：
- 行数、列数
- 各列类型、唯一值数、空值率
- 数值列的 min/max/avg
- 日期列的时间范围

此面板也为推荐引擎提供输入。

## Chrome 95 兼容性

- 推荐逻辑在后端或纯前端规则引擎，无 API 依赖 ✅。

## 验收标准

- 绑定数据源后自动展示 ≥1 个图表类型推荐。
- 推荐结果与数据特征匹配。
- 一键应用配色方案后图表颜色协调。
- 数据概况面板正确显示统计信息。

## 风险与回滚

- 风险：推荐结果不准确影响信任。
- 回滚：推荐仅为"建议"，用户随时可手动选择任意图表类型。
