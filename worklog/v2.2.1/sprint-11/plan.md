# 专题模板与动态数据绑定中心实施计划

> **目标**：把“项目管理专题专用绑定”升级为“专题模板 + 数据绑定中心 + 运行时 source/vars 编译”的平台能力。

> **默认假设**：第一阶段按环境级全局绑定实现，不按项目空间/工作区隔离。

## 执行顺序

### 1. 建立专题模板与绑定关系基础表

- 新增专题模板、逻辑实体、绑定关系的数据库结构
- 初始化 `project-management` 与 `plm-overview` 两个模板
- 为项目管理专题补上稳定逻辑实体定义

### 2. 补后端模板与绑定管理 API

- 提供模板查询
- 提供绑定创建、更新、删除、校验
- 提供“按专题生成运行时 source/vars”的编译接口

### 3. 打通 Excel/ODS 成功后的绑定动作

- 在入湖成功链路中记录当前 ODS 结果
- 支持将 ODS 结果绑定到某个专题逻辑实体
- 支持手工重新绑定

### 4. 改 dbt 运行前的 source/vars 编译

- 让 dbt 模型只依赖稳定逻辑 source
- 执行 compile/test/build 前根据当前绑定关系生成运行文件
- 缺失绑定时明确报错

### 5. 改建模与发布门禁

- 建模页展示当前绑定状态
- 发布门禁校验专题逻辑实体是否完整绑定
- 缺绑定时阻断并返回明确提示

### 6. 补前端专题绑定中心

- 专题模板列表
- 模板逻辑实体与绑定状态
- 绑定/换绑动作
- 最近批次和验证结果

### 7. 改 analytics 专题侧的绑定感知

- 项目管理专题读取绑定状态
- 空绑定时返回明确空态
- 口径支撑显示当前绑定来源

### 8. 做端到端验证

- Excel 入湖到 ODS
- 绑定到项目管理专题
- dbt compile/build
- analytics 项目看板读取正式结果
- `PLM` 模板最小验证

## 测试策略

### 后端

- 模板与绑定表结构测试
- 绑定 CRUD 与校验测试
- source/vars 编译测试
- 发布门禁专题绑定校验测试

### 前端

- 专题绑定中心页面构建与主要交互
- 入湖成功后的绑定交互
- 逻辑建模页绑定诊断显示

### 集成

- 项目管理专题全链路
- `PLM` 示例模板最小链路

## 完成标准

- 平台里存在正式的专题模板与绑定关系
- 项目管理专题不再依赖专题专用物理表名
- `PLM` 示例模板可以复用同一套机制
- dbt 在运行前能根据绑定关系生成稳定 source/vars
- 发布门禁能正确识别缺失绑定
- 平台有可操作的专题绑定中心页面
