# P0-02 密钥与脱敏策略（最新）

## 已落地

- 运维配置敏感字段统一脱敏显示（`******`）。
- 敏感配置提交时，若仍为 `******`，后端不覆盖原值。
- 审计日志对敏感配置按脱敏值记录。
- 集成配置沿用 `infra_service_settings` 的密文存储机制（ingestion 侧）。

## 约束

- 启动期参数（`config_scope=BOOTSTRAP`）禁止在 Admin 编辑。
- 高风险配置在前端提交前提示重启生效。

## 后续增强（v2.2.2 候选）

- `system_config` 增加可选密文列并迁移历史敏感值。
- 敏感字段变更增加二次确认与审批策略。
