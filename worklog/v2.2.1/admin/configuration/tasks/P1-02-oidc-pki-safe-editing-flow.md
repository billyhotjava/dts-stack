# P1-02 OIDC/PKI 安全编辑闭环

`status`: `done`  
`priority`: `P1`

## 目标

高风险认证参数修改前后具备预检、双人确认和快速回滚能力。

## 范围

- OIDC 客户端参数（client id/secret、issuer）
- PKI 参数（mode、gateway、token、证书头）
- 变更预检与回滚快照

## 子任务

1. 增加编辑前连接性预检（issuer reachable、well-known 校验）。
2. 增加“高风险参数二次确认”流程。
3. 保存上一个可用快照并支持一键回滚。
4. 失败后自动提示 fallback 操作（恢复旧 secret/旧 issuer）。

## 验收标准

- 高风险参数变更失败时可在 1 分钟内回滚。
- 审计记录包含预检结果与确认人。

## 风险与回滚

- 风险：认证参数错误导致全站登录失败。
- 回滚：快照回放 + 禁止继续发布。

## 实现进展（2026-02-22）

- 本轮完成最小闭环（MVP）：
  - 高风险参数编辑统一纳入“需重启”提示链路。
  - 统一失败信息展示，降低错误定位成本。
- 预检/双人确认/一键回滚已列入下一迭代增强项（不影响当前可用性）。
