# P2-01 非运行期参数防误改护栏

`status`: `done`  
`priority`: `P2`

## 目标

杜绝把编排/镜像/网络/底座初始化参数误放入业务后台改动。

## 范围

- `bootstrap-only` 参数黑名单
- Admin 编辑接口保护
- 前端展示策略（只读 + 说明）

## 子任务

1. 建立黑名单：`IMAGE_*`、`HOST_*`、`PG_SUPER_*`、`DEPLOY_MODE` 等。
2. 接口层禁止更新黑名单参数。
3. 前端仅展示说明，不提供编辑控件。
4. 审计记录拦截行为。

## 验收标准

- 黑名单参数无法通过 Admin 被修改。
- 非法修改尝试有明确错误与审计。

## 风险与回滚

- 风险：黑名单过宽影响正常运维。
- 回滚：支持灰度白名单放开单项参数。

## 实现进展（2026-02-22）

- 后端护栏已落地：`OpsConfigService.ensureMutable`
- 当 `config_scope=BOOTSTRAP` 时，更新/开关操作直接阻断并返回可读错误。
- 前端同步拦截并提示“请在 .env/compose 中维护”。
