# P1-01 重启生效标记与操作引导

`status`: `done`  
`priority`: `P1`

## 目标

避免“改了配置但不生效”的误判，给出明确的生效条件与操作路径。

## 范围

- Admin 配置页面
- 变更确认弹窗
- 运维操作提示文案

## 子任务

1. 为 `restartRequired=true` 参数添加统一标签。
2. 提交前弹窗提示“需重启服务/容器”。
3. 记录重启建议目标（admin/platform/ingestion/analytics）。
4. 在变更历史中标注“是否已执行重启”。

## 验收标准

- 用户可区分热生效与重启生效参数。
- 重启类参数提交后有明确后续动作提示。

## 风险与回滚

- 风险：重启建议错误导致额外停机。
- 回滚：先展示为“建议重启”，不做自动化重启。

## 实现进展（2026-02-22）

- `ops-config` 页面已展示 `需重启` 标签并在提交前二次确认。
- `infra-settings` 页面保存成功后增加重启建议提示。
- 元数据字段由后端统一下发，前端不写死业务判断。
