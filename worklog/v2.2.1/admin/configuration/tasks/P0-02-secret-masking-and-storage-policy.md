# P0-02 密钥与脱敏策略

`status`: `done`  
`priority`: `P0`

## 目标

确保可视化配置中的敏感参数可安全存储、展示脱敏、变更可审计。

## 范围

- `SystemConfig` / 集成配置中的密钥类字段
- UI 脱敏显示与“保持原值”语义
- 审计日志的敏感字段处理

## 子任务

1. 定义敏感字段判定规则（key pattern + 显式标注）。
2. 统一后端保存策略（加密存储/最小暴露）。
3. 前端提交策略：空值不覆盖、显式替换才更新。
4. 审计日志脱敏并保留变更行为证据。

## 验收标准

- 敏感字段在列表/API/审计中不出现明文。
- 配置更新后可正常生效且无明文泄露。

## 风险与回滚

- 风险：历史明文配置无法兼容读取。
- 回滚：双读兼容（先读新加密，失败回读旧值）后再迁移。

## 实现进展（2026-02-22）

- `OpsConfigService` 增加敏感占位值保护（`******` 不覆盖原值）。
- 审计脱敏逻辑统一使用 `isSensitive || keyPattern`。
- 新增策略文档：`worklog/v2.2.1/admin/configuration/report/p0-02-secret-policy-latest.md`。
