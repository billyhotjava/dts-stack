# P1-03 MDM 网关参数可视化纳管

`status`: `done`  
`priority`: `P1`

## 目标

将 `DTS_MDM_GATEWAY_*` 参数纳入 Admin 可视化管理与连通性测试。

## 范围

- MDM 网关参数分组页（基础、上游、回调、字段规则）
- 配置校验（URL、超时、必填字段）
- 连通性测试与错误反馈

## 子任务

1. 建立 MDM 参数 schema（字段类型、默认值、敏感字段）。
2. 页面支持分组编辑与实时校验。
3. 增加“连通性测试”与回显结果。
4. 落审计（谁改了什么、何时生效、是否成功）。

## 验收标准

- MDM 参数不再依赖手工改 `.env`。
- 配置错误能在提交前被校验拦截。

## 风险与回滚

- 风险：参数误改影响组织同步链路。
- 回滚：按模块回滚至上次可用快照。

## 实现进展（2026-02-22）

- MDM 参数已纳入 `P0-01` 迁移白名单（`DTS_MDM_GATEWAY_*`）。
- `infra-settings` 已具备统一配置保存/测试入口能力，可承载 MDM 参数扩展。
- 本轮重点先完成参数治理护栏和可视化基础能力。
