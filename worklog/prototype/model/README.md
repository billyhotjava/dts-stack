# DTS Model：数据建模工作台原型

这是一个只使用 mock 数据的独立 UI 原型，用来补齐低代码开发向导中缺失的专业数据建模链路。它不调用 DTS API，也不会修改生产前端。

## 运行

~~~
cd worklog/prototype/model
npm test
python3 -m http.server 4173
~~~

浏览器打开 http://127.0.0.1:4173/ 即可。

## 双入口演示

1. 原型默认进入独立的“数据建模 / 模型台账”，按项目空间筛选模型，查看分层、类型、标准登记、粒度声明和发布状态。
2. 在模型台账点击“返回低代码向导”，进入低代码平台的任务总览页。
3. 向导页只串联数据准备、业务对象确认、数据建模、指标设计四类任务，不承载专业编辑器。
4. 点击向导中的“进入数据建模”，跳回独立模型台账；其他缺口通过链接进入对应专业页面。

## 设计边界

- 前置条件：项目空间、主题域和数据源状态可追溯；数据标准目录已就绪。
- 页面职责：数据建模页面负责台账登记、状态汇总和专业页面跳转；低代码向导只负责任务 overview。
- 专业门禁：模型专业页负责标准绑定、字段、粒度、关系和发布校验。
- mock 数据：3 个模型、4 个项目空间、6 个数据标准、4 个登记维度、2 个来源数据集。
