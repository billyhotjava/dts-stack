# DTS 智能数据建模交互原型

该目录是根据已登录的 DataWorks「维度建模」真实页面制作的本地只读原型，目标是验证更紧凑的 DTS 建模交互，不连接 DataWorks，也不会修改任何线上数据。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory worklog/prototype
```

浏览器打开：

```text
http://127.0.0.1:4173/dataworks-kimball/
```

## 已覆盖的界面

- 首页：建模资产概览、最近模型、交付状态、待处理和快速入口。
- 数仓规划：业务分类、数仓分层、公共层（数据域、业务过程）、应用层（数据集市、主题域）、建模空间和系统管理；每个入口均有独立表单与列表。
- 数据标准：字段标准、标准代码、词根、命名词典和标准映射。
- 维度建模工作台：模块导航、分层切换、数据域树、模型标签页。
- 新建菜单：维度、贴源表、维度表、明细表、汇总表、应用表。
- 模型编辑：基础信息、字段管理、分区字段管理。
- 字段交互：插入/删除、字段显示设置、从表导入、字段关联、FML 代码模式。
- 数据指标：三栏指标工作台，覆盖复合指标、派生指标、原子指标、修饰词和时间周期；包含数据域目录、基本信息、业务口径与计算逻辑。
- 通用工具：模型导入导出、FML 校验、命名检查、数据字典和 Excel 字段识别。
- 关系图：规划、标准、模型和指标的关系画布及跨模块跳转。
- 逆向建模：入口页与四步向导第一页。
- 辅助界面：导入、导出、版本管理、发布记录、日志、质量规则。
- DTS 闭环：发布检查和生成物化任务合并在一个短流程弹窗中。

## 交互入口

- 左侧对象树上方 `＋` 打开六类新建菜单。
- 顶部导航可切换首页、数仓规划、数据标准、维度建模、数据指标、通用工具和关系图。
- 点击对象树模型进入对应模型编辑页。
- 点击顶部 `发布`，在弹窗中切换“发布模型 / 生成物化任务”。
- 点击“字段显示设置”“字段关联”“代码模式”查看对应弹层。
- 点击左侧“逆向建模”进入逆向向导。

真实页面截图与字段清单见上级目录的 [SCREEN-INVENTORY.md](../SCREEN-INVENTORY.md)。
