# T03: 数据产品（DataProducts）

**优先级**: P0
**状态**: READY
**依赖**: S1

## 目标

落地 `DataProductsPage`，把现网数据产品目录收进阶段③，列出由数据集封装的对外数据产品。

## 技术设计

- **文件**：`stages/assets/DataProductsPage.tsx`（对齐现网 `pages/catalog/DataProductsPage.tsx`）。
- **列表**：`CompactTable`（默认 10 条/页，切换刷新+重置首页），列含 产品名 / 关联数据集 / 域 / 负责人 / 状态（草稿/发布）/ 更新时间。可带关键词/状态过滤。
- **mock service**：复用现网 `dataProductsService`（返回 `Promise<Result<T>>` 契约）。若现网导出不足，新增轻量 `dataProductsService.list({ keyword, status, page, pageSize })`。样例项目「销售准备项目」含 1 个由 `ODS.宽表` 派生的数据产品。
- **Chrome 95**：表格/过滤区 flex 布局，HSL 状态色 token。

## 影响范围

- 文件：`stages/assets/DataProductsPage.tsx`
- mock：`mock/services/dataProductsService.ts`（复刻现网契约）
- 页面/路由：阶段③ slot 注册 `data-products` 路由
- 组件：复用 `ui/CompactTable`
