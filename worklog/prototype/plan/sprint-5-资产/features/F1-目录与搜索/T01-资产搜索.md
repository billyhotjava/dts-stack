# T01: 资产搜索（DataSearch，关键词+过滤）

**优先级**: P0
**状态**: READY
**依赖**: S1

## 目标

在阶段③落地 `DataSearchPage`，支持关键词检索 + 多维过滤（域/层/类型），结果以 CompactTable（默认 10 条/页）呈现并可跳转数据集详情。

## 技术设计

- **文件**：`stages/assets/DataSearchPage.tsx`（命名对齐现网 `pages/catalog/DataSearchPage.tsx`）。
- **搜索框 + 过滤区**：关键词 input；过滤项「数据域 / 数据分层（ODS/DWD/DWS/ADS）/ 资产类型（数据集/数据产品）」用 Select。过滤可用 URL search params 持久化（filters/sort/page 入 URL）。
- **mock service**：
  - `catalogDomainService.listDomains()` / `getDomainTree()`（现网已存在，返回 `Promise<Result<CatalogDomain[]>>`，`{ code, name, parentCode }`）供「数据域」过滤项。
  - 新增 `assetSearchService.search({ keyword, domain, layer, type, page, pageSize })` 返回 `Promise<Result<Paged<AssetSearchRow>>>`，内存 fixtures 含样例 `ODS.宽表`。
- **结果表**：`CompactTable`，列含 名称 / 类型 / 域 / 分层 / 负责人 / 更新时间；`defaultPageSize=10`，切换条数刷新并重置到第 1 页（`pageSize` 入受控分页 deps，注意 `pageNum` 基准）。
- **跳转**：点击行 → `DatasetDetailPage`（F1-T02）。
- **Chrome 95**：布局用 flex/grid 固定栏，禁 `:has()`/容器查询；状态色走 HSL token。

## 影响范围

- 文件：`stages/assets/DataSearchPage.tsx`
- mock：`mock/services/assetSearchService.ts`（新增）、复用 `catalogDomainService`
- 页面/路由：阶段③ slot 注册 `data-search` 路由
- 组件：复用 `ui/CompactTable`
