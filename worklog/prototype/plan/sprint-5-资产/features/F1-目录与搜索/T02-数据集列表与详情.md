# T02: 数据集列表 + 详情（Datasets/DatasetDetail）

**优先级**: P0
**状态**: READY
**依赖**: S1

## 目标

落地 `DatasetsPage`（列表）与 `DatasetDetailPage`（详情），让用户列出全部数据集、点开查看 schema/字段/标签，并从详情进入血缘与质量。

## 技术设计

- **文件**：`stages/assets/DatasetsPage.tsx`、`stages/assets/DatasetDetailPage.tsx`（对齐现网 `pages/catalog/DatasetsPage.tsx` / `DatasetDetailPage.tsx`）。
- **列表**：`CompactTable`（默认 10 条/页，切换刷新+重置首页），列含 名称 / 域 / 分层 / 字段数 / 行数 / 负责人 / 质量状态 / 更新时间。顶部可带域/层过滤（复用 `catalogDomainService`）。
- **详情**：Tab 或分区呈现 ①概览（描述/域/分层/负责人/行数）②Schema（字段表：列名/类型/注释/PII 标记，CompactTable）③标签 ④血缘入口（跳 F2 `LineageGraphPage`）⑤质量入口（跳 F3 `QualityReportPage`）。
- **mock service**：
  - 新增 `datasetsService.list({ domain, layer, page, pageSize })` → `Promise<Result<Paged<DatasetRow>>>`。
  - `datasetsService.detail(id)` → `Promise<Result<DatasetDetail>>`，含字段数组。样例 `ODS.宽表` 的字段来自 S4 画布去重/连接输出（PLM 订单 + ERP 客户合并列），保证黄金主线连贯。
- **Chrome 95**：详情 Tab/分区用 antd + flex，禁容器查询。

## 影响范围

- 文件：`stages/assets/DatasetsPage.tsx`、`stages/assets/DatasetDetailPage.tsx`
- mock：`mock/services/datasetsService.ts`（新增），复用 `catalogDomainService`
- 页面/路由：阶段③ slot 注册 `datasets`、`datasets/:id` 路由
- 关联：详情页提供 F2 血缘、F3 质量的跳转入口
