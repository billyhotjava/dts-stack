# T02: 资产权属/授权/我的授权（AssetOwnership/AssetGrant/MyGrants）

**优先级**: P1
**状态**: READY
**依赖**: S1, F1-T02

## 目标

落地资产权属、授权、我的授权三页，让用户为数据集标注负责人/权属、对人/角色发授权、并查看自己持有的授权，补齐 governance 资产权属能力进阶段③。

## 技术设计

- **文件**（对齐现网 `pages/catalog` 与 governance 资产权属）：
  - `stages/assets/AssetOwnershipPage.tsx`：资产权属——数据集 ↔ 负责人/团队/密级 映射列表，可编辑 owner。
  - `stages/assets/AssetGrantPage.tsx`：授权——对某资产给某用户/角色授予读/写/管理权限的授权列表 + 新建授权 modal（被授权主体、权限级别、有效期）。
  - `stages/assets/MyGrantsPage.tsx`：我的授权——当前用户持有的授权清单（资产/权限/到期）。
- **列表**：`CompactTable` 默认 10 条/页（切换刷新+重置首页）。
- **mock service**：新增 `assetGrantService`（命名对齐现网 `AssetGrant`/`AssetOwnership`）：
  - `ownership({ page, pageSize })` / `saveOwnership(o)` → `Promise<Result<...>>`
  - `grants({ assetId, page, pageSize })` / `createGrant(g)` / `revokeGrant(id)` → `Promise<Result<...>>`
  - `myGrants()` → `Promise<Result<MyGrantRow[]>>`
  - 样例 `ODS.宽表` 内置 owner（销售数据团队）+ ≥1 条授权。
- **入口**：F1-T02 数据集详情页可显示权属摘要并跳 `AssetOwnershipPage`/`AssetGrantPage`。
- **Chrome 95**：表格/modal flex 布局，禁容器查询；密级/权限用 HSL 语义色 token。

## 影响范围
