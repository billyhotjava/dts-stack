# T02: 列级血缘/影响分析/diff/导入（LineageColumns/Impact/Diff/Import）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

补齐血缘配套四视图：列级血缘、影响分析、版本 diff、血缘导入，均接 mock，与 T01 血缘图共享数据与导航。

## 技术设计

- **文件**（对齐现网 `pages/catalog`）：
  - `stages/assets/LineageColumnsPage.tsx`：列级血缘表（`ColumnLineage` 类型，复用 `columnLineageColumns`），展示字段→字段映射；CompactTable 默认 10 条/页。
  - `stages/assets/LineageImpactPage.tsx`：影响分析——给定资产，列出下游受影响资产/字段（`ImpactNode`/`ImpactEdge`/`ImpactStats`，复用 `nodeColumns`/`edgeColumns`），可与 G6 图联动高亮。
  - `stages/assets/LineageDiffPage.tsx`：两个血缘版本 diff（`LineageDiffResult`），新增/删除/变更边分组呈现。
  - `stages/assets/LineageImportPage.tsx`：血缘导入（粘贴/上传 SQL 或映射），mock 解析后回显待入图的节点/边。
- **共享**：`LineageSectionNav`（section 切换：graph/columns/impact/diff/import）+ `lineageSectionMeta`，与 T01 同一外壳，对齐现网 `lineageShared.tsx`。
- **mock service**：扩展 `lineageService`：
  - `columns({ datasetId })` → `Promise<Result<ColumnLineage[]>>`
  - `impact({ datasetId, direction })` → `Promise<Result<ImpactResult>>`
  - `diff({ fromVersion, toVersion })` → `Promise<Result<LineageDiffResult>>`
  - `import_({ payload })` → `Promise<Result<{ nodes; edges }>>`
- **Chrome 95**：表格 flex 布局；导入预览用 antd 组件，禁容器查询。

## 影响范围

- 文件：`LineageColumnsPage.tsx`、`LineageImpactPage.tsx`、`LineageDiffPage.tsx`、`LineageImportPage.tsx`
- mock：`mock/services/lineageService.ts`（扩展 columns/impact/diff/import）
- 页面/路由：阶段③ slot 注册 `lineage/columns`、`lineage/impact`、`lineage/diff`、`lineage/import`
- 共享：`lineageShared.tsx`（section nav / 类型 / columns 定义）
