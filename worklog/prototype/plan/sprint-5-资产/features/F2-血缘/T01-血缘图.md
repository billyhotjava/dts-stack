# T01: 血缘图（@antv/g6，节点=资产/任务，边=数据流）

**优先级**: P0
**状态**: READY
**依赖**: S1, F1-T02

## 目标

落地 `LineageGraphPage`，用 `@antv/g6` 渲染数据资产血缘关系图，节点为资产/任务、边为数据流向，在 Chrome 95 legacy 构建下可平移/缩放/选中节点。

## 技术设计

- **文件**：`stages/assets/LineageGraphPage.tsx` + 复用/移植现网 `components/lineage/LineageGraph.tsx`（封装 `@antv/g6`）。命名对齐现网 `pages/catalog/LineageGraphPage.tsx`。
- **@antv/g6 用法**（对齐现网 `LineageGraph.tsx` v4.x 写法）：
  - `import G6 from "@antv/g6";` `new G6.Graph({...})`。
  - 自定义节点 `G6.registerNode(...)` 区分「资产节点」（含 分层色 / 行数徽标 / 状态点）与「任务节点」（去重/连接/聚合等，含任务图标）。
  - 边用 `G6.Arrow.triangle(...)` 表数据流向；可按 relation 着色（参考现网 `lineageShared.tsx` 的 `relationStroke` / `layerColor`）。
  - 插件：`G6.Minimap` + `G6.ToolBar`（缩放/复位）。布局用分层布局（`applyLayeredLayout`，LR/TB 可切，参考 `lineageShared.tsx`）。
  - 容器尺寸用 `ResizeObserver` 驱动 `graph.changeSize(...)`，**不**用容器查询（Chrome 95 约束）。
- **节点/边类型**（复用 `lineageShared.tsx` 类型）：`ImpactNode` / `ImpactEdge`；方向 `UPSTREAM/DOWNSTREAM/BOTH`，布局方向 `LR/TB`。
- **mock service**：新增 `lineageService.graph({ datasetId, direction })` → `Promise<Result<ImpactResult>>`（`{ nodes, edges, stats }`）。样例 `ODS.宽表` 的 mock 图：上游 = `PLM.订单`(源表) + `ERP.客户`(源表) → `去重`(任务) / `连接`(任务) → `ODS.宽表`(资产)，连贯 S4 画布产出。
- **顶部过滤**：数据集选择 + 方向/层数 + 关键词高亮（复用 `LineageDataFilters` / `LineageSectionNav` / `useLineageData`）。
- **Chrome 95**：`@antv/g6` v4.x 现网 legacy 已验证可用；画布外壳 flex/grid 固定栏，禁 `:has()`/容器查询/subgrid。
