# T02: 语义发布/运行

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

在阶段④渲染 `SemanticPublishPage`（发布语义模型）与 `SemanticRunsPage`（运行/发布历史），发布即触发底层 dbt 自动生成（隐藏），接 mock。

## 技术设计

- 文件：`app/src/stages/metrics/SemanticPublishPage.tsx`、`app/src/stages/metrics/SemanticRunsPage.tsx`（命名对齐现网 `pages/modeling/semantic/SemanticPublishPage.tsx`、`SemanticRunsPage.tsx`）。
- 发布页：选择一个 T01 语义模型 → 发布表单（版本/说明占位）→ 提交。发布成功后：① 语义度量对 F1 指标可见；② **底层自动生成 dbt model**（隐藏引擎，mock 仅记录「已生成产物」标记，产物本身仅 F4 T01 抽屉可查）；③ 驱动左轨阶段④状态点（已发布指标 ≥ 1 → `✓`）。
- 运行页：`CompactTable` 呈现发布/运行历史，列含运行 ID、语义模型、状态（成功/失败/运行中，用 Swiss 状态点 token）、触发人、时间；默认 10 条/页、`pageSize` 收敛、切 size 重置第 1 页。状态/时长数值用 `tabular-nums` 对齐。
- mock service：`semanticModelingApi`（`publishModel` 返回 `Promise<Result<PublishResult>>`、`listRuns` 返回 `Promise<Result<SemanticRun[]>>`，复刻现网契约形状）。发布 mock 可返回成功/失败两态，失败显式提示。
- **dbt 隐藏（关键）**：发布流程文案与 UI **只字不提 dbt 操作**；「生成 dbt」是后台隐藏动作，仅在 F4 T01「查看生成的 dbt」只读抽屉里以产物形式呈现，且消费 S4 F4 的生成映射。发布页**不**给出任何 dbt 文件编辑/运行入口。

## 影响范围

- 新增 `app/src/stages/metrics/SemanticPublishPage.tsx`、`SemanticRunsPage.tsx`
- 扩展 `app/src/mock/services/semanticModelingApi.ts`（`publishModel`、`listRuns`）
- mock fixtures：销售准备项目「销售达成率」语义模型一条已发布记录 + 对应「已生成 dbt 产物」标记（供 F4 抽屉消费）
- 与左轨阶段④状态派生联动（依赖 S1 外壳状态机）
