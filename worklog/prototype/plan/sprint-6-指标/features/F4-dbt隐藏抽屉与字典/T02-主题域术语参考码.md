# T02: 主题域/术语/参考码

**优先级**: P1
**状态**: READY
**依赖**: S4

## 目标

在阶段④落地字典域：`SubjectAreasPage`（主题域）、`GlossaryPage`（术语表）、`ElementsPage`（数据元素）、`ReferenceCodesPage`（参考码/码表），作为指标（F1）与语义建模（F2）的术语支撑，接 mock。

## 技术设计

- 文件：`app/src/stages/metrics/SubjectAreasPage.tsx`、`GlossaryPage.tsx`、`ElementsPage.tsx`、`ReferenceCodesPage.tsx`（命名对齐现网 `pages/modeling/SubjectAreasPage.tsx` 等）。
- 主题域：业务主题树/列表，与 F2 语义主题(`SubjectsPage`)互相引用——主题域是术语层归组，语义主题是建模层归组，二者对齐。
- 术语表：业务术语 + 定义 + 关联指标/数据元，CompactTable 默认 10 条/页、`pageSize` 收敛、切 size 重置第 1 页。
- 数据元素：标准数据元（名称/类型/口径），可被术语与语义对象引用。
- 参考码：码表（code/label 对照，对齐 `dim-code-design` 的 ASCII 稳定码思路——展示 code 为稳定主键、label 为展示名），CompactTable 呈现。
- 数值/码值列用 `tabular-nums` 对齐；Swiss 12 列网格，固定栏 flex/grid + ResizeObserver，**禁容器查询/subgrid/`:has()`**。
- mock service：`glossaryService`（`listSubjectAreas` / `listGlossary` / `listElements` / `listReferenceCodes`，均返回 `Promise<Result<T>>`，复刻现网契约形状）。
- **dbt 隐藏**：字典域是纯业务术语/元数据层，**与 dbt 完全无关**——本就不应出现任何 dbt 入口；它为 F1 指标口径、F2 语义建模提供术语锚点，巩固"普通用户在业务语义层工作"的范式。
