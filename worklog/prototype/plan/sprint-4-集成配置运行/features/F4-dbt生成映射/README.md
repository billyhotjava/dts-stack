# F4: dbt 生成映射

**优先级**: P1
**状态**: READY

## 目标

产出"转换作业 → dbt model"的隐藏生成映射（mock 数据结构），供 **S6** 的"查看生成的 dbt"只读抽屉消费。普通用户全程不接触 dbt。

## 背景

设计 §3/§7：**dbt 下沉**——画布上搭转换 → 底层自动生成 dbt model；`DbtFileBrowser/ModelPipeline` 降级为阶段④的只读抽屉。本 sprint **只产出生成映射数据结构**，抽屉 UI 在 S6 实现。这是 S4→S6 的数据契约前置件。
