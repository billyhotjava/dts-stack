# T02: 列表视图（收编 Transform/Orchestration 表格）

**优先级**: P1
**状态**: READY
**依赖**: T01（视图切换 + 同一数据源）

## 目标

实现列表视图，以 `CompactTable`（10 条/页）展示转换作业，列收编现网 `TransformPage` / `OrchestrationPage` 表格，并支持行跳回画布。

## 技术设计

- 库/栈：`CompactTable`（Swiss，默认 10 条/页，切条数刷新）；`tabular-nums` 对齐数值列；行操作用 Ant Design `Button`/`Dropdown`。
- 文件：
  - `app/src/stages/integrate/list/JobListView.tsx`（列表主体）。
  - `app/src/stages/integrate/list/jobColumns.tsx`（列定义，收编现网 Transform/Orchestration 列）。
- 关键实现点：
  - 列对齐现网：作业名 / 类型(转换/编排) / 节点数 / 最近运行状态 / 最近运行时间 / 负责人 / 操作（打开画布 / 运行 / 查看历史）。
  - 数据来自 T01 同一转换作业数据源；列表分页统一约定（10 条/页，切条数重置第 1 页，`pageNum` 基准显式标注）。
  - "打开画布"行操作 → 切回画布视图（T01）并定位/打开该作业。
  - 状态用统一状态点 token（与 F2 一致）。
- mock service：`transformService.listJobs({ pageNum, pageSize }): Promise<Result<Page<JobSummary>>>`；复刻现网分页信封。

## 影响范围

- 新增 `app/src/stages/integrate/list/JobListView.tsx`、`jobColumns.tsx`。
- 扩展 `mock/services/transformService.ts`（listJobs + fixtures，与画布作业数据同源）。
- 收编现网 `TransformPage` / `OrchestrationPage` 列定义与语义。
