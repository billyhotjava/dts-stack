# T01: 画布⇄列表视图切换

**优先级**: P1
**状态**: READY
**依赖**: S3（转换作业数据模型 + 画布视图）

## 目标

在阶段② 顶部提供 `画布 | 列表` 切换控件，两视图共享同一份转换作业数据，切换不丢失、不复制数据。

## 技术设计

- 库/栈：Ant Design 5 `Segmented`（画布/列表二选一）；URL state 用 React Router search param（`?view=canvas|list`）持久化。
- 文件：
  - `app/src/stages/integrate/IntegrateStage.tsx`（阶段② 容器：根据 `view` 渲染画布或列表，二者读同一数据源）。
  - `app/src/stages/integrate/useIntegrateView.ts`（视图状态 hook，读写 URL search param）。
- 关键实现点：
  - 转换作业数据为单一事实源（S3 提供的作业模型 / store）；画布与列表都是其投影，**不**各存一份（遵守"不重复 server/client state"）。
  - 切换走 URL state（可分享、刷新保持）；默认 `canvas`。
  - 切换为纯视图变更，不触发数据重载（除非首次进入需 `transformService.listJobs`）。
- mock service：复用 `transformService.listJobs` / S3 作业数据；不新增写接口。

## 影响范围

- 新增/扩展 `app/src/stages/integrate/IntegrateStage.tsx`、`useIntegrateView.ts`。
- 接入 S3 画布视图与转换作业数据源。
- 接入路由 search param。

## 验证

- [ ] `画布 | 列表` 切换即时生效，无数据丢失/复制。
- [ ] 视图状态写入 URL，刷新保持；可分享链接还原视图。
- [ ] 两视图对同一作业的编辑相互可见（同一数据源）。

## 完成标准

- [ ] 单一事实源，视图为投影，无状态重复。
- [ ] URL 持久化视图状态。
- [ ] 切换控件 Chrome 95 安全。
