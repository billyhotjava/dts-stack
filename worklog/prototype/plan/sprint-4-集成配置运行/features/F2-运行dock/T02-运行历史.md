# T02: 运行历史（CompactTable 收编）

**优先级**: P0
**状态**: READY
**依赖**: T01（dock 外壳；运行结果回写历史）

## 目标

在 dock 内提供运行历史视图，以 `CompactTable`（10 条/页）展示，收编现网 `OrchestrationRunsTab` / `TransformExecutionHistoryPage` / `ExecutionHistoryTable` 的列与语义。

## 技术设计

- 库/栈：`CompactTable`（Swiss，默认 10 条/页，切换条数刷新；`tabular-nums` 对齐耗时/行数）。
- 文件：
  - `app/src/canvas/dock/RunHistoryTab.tsx`（或作为 RunTab 内子区/第四视图，取决于 T01 dock 信息架构）。
  - mock：`orchestrationService.listRuns({ jobId, pageNum, pageSize }): Promise<Result<Page<RunRecord>>>`。
- 关键实现点：
  - 列对齐现网执行历史：运行号 / 触发方式 / 状态 / 开始时间 / 耗时 / 处理行数 / 操作（查看日志→跳 LogTab）。
  - 分页统一约定：默认 10 条/页，切换条数重置第 1 页；注意 `pageNum` 基准（与现网一致，0/1-based 显式标注）。
  - 状态用统一状态点 token（成功/失败/运行中）；行数/耗时用 `tabular-nums`。
  - 新运行完成后（T01 回写）历史列表刷新或插入最新一条。
- mock service：`orchestrationService.listRuns` 复刻现网分页信封 `Page<T>`；`VITE_USE_MOCK` 默认开。

## 影响范围

- 新增 `app/src/canvas/dock/RunHistoryTab.tsx`。
- 扩展 `mock/services/orchestrationService.ts`（listRuns + 运行历史 fixtures）。
- 收编现网 `OrchestrationRunsTab` / `TransformExecutionHistoryPage` / `ExecutionHistoryTable` 列定义。
