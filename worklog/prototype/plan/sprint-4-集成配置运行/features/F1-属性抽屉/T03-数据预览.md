# T03: 数据预览（20 行 mock）

**优先级**: P0
**状态**: READY
**依赖**: T01（抽屉框架 footer 预览入口）

## 目标

在抽屉内提供"预览 20 行"：对选中节点的输出做 20 行 mock 结果预览，验证转换配置效果。

## 技术设计

- 库/栈：`CompactTable`（Swiss 设计系统，默认 10 条/页 → 20 行=2 页），`tabular-nums` 对齐数值列；加载态 `Skeleton`，空/错误态显式提示。
- 文件：
  - `app/src/canvas/inspector/PreviewPanel.tsx`（抽屉内可折叠区或弹层；触发按钮在 T01 footer）。
  - mock：`mock/services/transformService.ts` 新增 `previewNode(nodeId, { limit: 20 }): Promise<Result<PreviewResult>>`，`PreviewResult = { columns: ColumnSchema[]; rows: Row[] }`。
- 关键实现点：
  - 预览结果根据节点 `config`（T02）+ 上游 schema 由 mock 推导（如去重后行数变化、聚合后列变化），保证预览语义与配置一致。
  - 复刻现网 `Result<T>` 契约形状；带可调延迟（沿用 mock 框架延迟模拟）。
  - 列宽自适应，长文本省略 + tooltip；不使用 `:has()`/容器查询。
- mock service：`transformService.previewNode()` 复刻现网契约，`VITE_USE_MOCK` 默认开。

## 影响范围

- 新增 `app/src/canvas/inspector/PreviewPanel.tsx`。
- 扩展 `mock/services/transformService.ts`（previewNode + fixtures）。
- 接入 T01 抽屉 footer 预览触发。

- [ ] 加载态、空态、错误态均有显式 UI；无静默吞错。
