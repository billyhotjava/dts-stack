# T02: 各节点类型配置表单

**优先级**: P0
**状态**: READY
**依赖**: T01（抽屉框架 + 节点表单注册表）

## 目标

为五种节点类型实现各自的配置表单，字段覆盖：去重主键/策略、join 条件、聚合分组、过滤条件、字段映射。

## 技术设计

- 库/栈：Ant Design 5 `Form` + `Select` / `Input` / `Table`（映射用可编辑表格）；表单值通过 T01 `updateNodeData` 不可变写回。
- 文件（`app/src/canvas/inspector/forms/`）：
  - `SourceForm.tsx`（源表：选数据源/表，只读展示连通状态 + 行数；字段列表来自 mock schema）。
  - `CleanForm.tsx`（清洗·去重：主键多选 `dedupeKeys`、策略 `keepStrategy`=保留最新/保留最早/任意）。
  - `JoinForm.tsx`（连接：左右输入端 + join 类型 inner/left/right/full + ON 条件列对映射）。
  - `AggregateForm.tsx`（聚合：分组列 `groupBy` + 聚合度量列表 `{col, fn: sum/count/avg/min/max}`）。
  - `FilterForm.tsx`（过滤：条件行 `{col, op, value}`，op=eq/neq/gt/lt/in/like，AND/OR 组合）。
  - `MappingTable.tsx`（字段映射：源字段→目标字段+类型，输出节点与各表单共用）。
- 关键实现点：
  - 字段下拉项来自 `transformService.getNodeSchema(nodeId)` mock（上游节点输出列）。
  - 表单为受控；空配置给出合理默认值，校验在系统边界 fail-fast（如 join 必须有 ON 条件）。
  - 配置 = 转换语义来源，后续 F4 据此生成 dbt model 映射。
- mock service：`transformService.getNodeSchema()` 返回 `Promise<Result<ColumnSchema[]>>`。

## 影响范围
