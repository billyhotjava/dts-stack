# F1: 属性抽屉

**优先级**: P0
**状态**: READY

## 目标

为 S3 画布的选中节点提供右侧属性抽屉：随选中节点切换、按节点类型渲染配置表单、并对节点输出做 20 行 mock 数据预览。让画布从"能搭结构"升级为"能配置转换语义"。

## 背景

设计 §7 抽屉草图：选中"清洗·去重"→ 抽屉显示 主键 / 策略；其他节点类型（连接/聚合/过滤/输出）各有对应表单。收编现网 `TransformCreatePage` / `TransformDetailPage` 的配置/映射能力到画布抽屉里。

## 完成标准

- [ ] 选中任一画布节点，右侧 `Drawer` 打开并加载该节点配置；切换选中节点时抽屉内容随之切换；取消选中关闭抽屉。
- [ ] 五种节点类型（源表 / 清洗 / 连接 / 聚合 / 输出）各有对应配置表单，字段覆盖：去重主键+策略、join 条件、聚合分组、过滤条件、字段映射。
- [ ] 配置写回节点数据（不可变更新），同步反映到画布卡片与转换作业数据模型。
- [ ] "预览 20 行"按钮调用 `transformService` mock，返回 20 行结果以 `CompactTable` 展示。
- [ ] 抽屉布局 Chrome 95 安全（flex/grid + ResizeObserver，不用 `:has()`/容器查询）。
