# T01: 节点配置抽屉框架

**优先级**: P0
**状态**: READY
**依赖**: S3（画布内核：节点选中事件 + 节点类型枚举 + 转换作业数据模型）

## 目标

实现画布右侧属性抽屉外壳：监听选中节点，按节点类型路由到对应配置表单，并把表单变更不可变写回转换作业数据模型。

## 技术设计

- 库/栈：React 19 + TS + Ant Design 5 `Drawer`（`placement="right"`、`mask={false}` 内嵌、`getContainer` 指向画布容器）。`@xyflow/react` v12 选中状态（`useStore` 取 `selectedNodes` / `onSelectionChange`）。
- 文件：
  - `app/src/canvas/inspector/NodeInspectorDrawer.tsx`（抽屉外壳：标题=节点名+类型图标，body 渲染子表单 slot，footer 放"预览 20 行"入口 → T03）。
  - `app/src/canvas/inspector/nodeFormRegistry.ts`（节点类型 → 表单组件映射表；五类型 + 未知兜底）。
  - `app/src/canvas/inspector/useSelectedNode.ts`（从画布 store 派生当前选中节点，单选；多选时抽屉显示"请选择单个节点"）。
- 关键实现点：
  - 抽屉宽度固定（如 360px），随画布容器 ResizeObserver 调整，**不**用容器查询。
  - 表单变更通过 `updateNodeData(nodeId, patch)` 返回新节点对象（不可变），回写 reactflow `setNodes` + 转换作业数据模型。
  - 节点类型枚举复用 S3 定义（源表 `source` / 清洗 `clean` / 连接 `join` / 聚合 `aggregate` / 输出 `output`）。
- mock service：本 task 不直接调 service；为 T03 预留 footer 预览触发口。

## 影响范围

- 新增 `app/src/canvas/inspector/`（NodeInspectorDrawer / nodeFormRegistry / useSelectedNode）。
- 接入 S3 画布容器（在画布右侧挂载抽屉，画布区让出固定宽度）。
- 依赖 S3 节点数据模型与选中事件；不改动 S3 画布内核逻辑（只读选中 + 写回 data）。

## 验证

- [ ] 选中节点 → 抽屉打开并显示正确标题/类型；切换选中 → 内容切换；取消选中 → 关闭。
- [ ] 多选时抽屉显示占位提示，不崩。
- [ ] 表单 patch 以不可变方式写回，画布卡片同步反映。

## 完成标准

- [ ] 抽屉框架可承载五类型表单 slot，注册表可扩展。
- [ ] 布局 Chrome 95 安全（flex/grid + ResizeObserver）。
- [ ] 无对 S3 内核的破坏性改动；选中→抽屉链路稳定。
