# T02: 节点面板 + dnd-kit 拖入画布（含键盘 a11y 兜底）

**优先级**: P0
**状态**: READY
**依赖**: T01, T04

## 目标

实现左侧节点面板（源表/清洗/连接/聚合/输出），支持用 `@dnd-kit` 把节点拖到画布落点，并提供等效的键盘 a11y 兜底路径。

## 技术设计

- 库：`@dnd-kit/core`（面板项为 draggable，画布区为 droppable）。连线/平移/缩放仍走 reactflow 原生（dnd-kit 只负责"面板→画布"的落点）。
- 文件：
  - `app/src/canvas/NodePalette.tsx`：5 类节点的可拖拽项（图标+名称），每项可聚焦（`tabIndex`、`role="button"`、`aria-label`）。
  - `app/src/canvas/useNodeDrop.ts`：dnd-kit `onDragEnd` 把屏幕坐标经 `useReactFlow().screenToFlowPosition` 转画布坐标，调 store `addNode`。
  - 接入点：集成阶段页 `app/src/stages/integrate/IntegratePage.tsx`（或 `TransformPage` 对齐命名）用 `<DndContext>` 包裹面板 + 画布。
- 键盘 a11y 兜底（**必须**）：
  - 面板项可 Tab 聚焦、方向键移动焦点；Enter/Space 选中该节点类型。
  - 选中后出现"添加到画布"按钮（或直接 Enter 二次确认）→ 在画布默认落点（如视口中心 `screenToFlowPosition(中心)`）`addNode`，**无需鼠标拖拽即可完成落点**。
  - dnd-kit 配 `KeyboardSensor` 作为拖拽本身的键盘替代，并辅以上面的"选中→添加"按钮作为最稳的兜底。
  - 拖拽/落点动作通过 `aria-live` 区域播报（如"已添加 清洗 节点"）。
- 关键实现点：落点坐标转换必须用 reactflow v12 的 `screenToFlowPosition`；新节点 data 默认值取自节点类型常量（T01）。

## 影响范围

- 文件：`app/src/canvas/NodePalette.tsx`、`useNodeDrop.ts`、`app/src/stages/integrate/IntegratePage.tsx`
- 组件：`NodePalette`、`DndContext` 包裹层
- 依赖：T01（节点类型/EltCanvas）、T04（store.addNode）；mock 提供面板可用节点清单（可选）

## 验证

- [ ] 鼠标：从面板拖拽任一节点到画布，节点落在松手位置（坐标转换正确）。
- [ ] 键盘：仅用 Tab/方向键/Enter 选中节点类型 → "添加到画布"按钮 → 节点落到画布（**无需鼠标**）。
- [ ] 每类节点（5 种）拖入与键盘添加均可用。
- [ ] 落点动作有 `aria-live` 播报；面板项有 `aria-label` 与可见焦点环。

## 完成标准

- [ ] 键盘兜底完全脱离鼠标可完成落点（a11y 硬要求）。
- [ ] 坐标转换走 `screenToFlowPosition`，落点准确。
