# T03: 连线 / 平移 / 缩放 / 网格对齐 / 小地图

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

打通 reactflow 原生交互：节点间连线、画布平移、缩放、网格对齐（snap-to-grid）、小地图与控制器。

## 技术设计

- 库：`@xyflow/react` v12 原生能力，参考现网 `VisualFlowCanvas`（`Background` / `Controls` / `MiniMap`）。
- 文件：在 `app/src/canvas/EltCanvas.tsx`（T01）内接入：
  - 连线：`onConnect` 回调 → store `connect`（合法性校验由 F2-T02 接管，本 task 先建立连线通道）。
  - 平移/缩放：reactflow 默认开启；显式配 `minZoom` / `maxZoom` / `fitView`。
  - 网格对齐：`snapToGrid` + `snapGrid={[gx, gy]}`，配 `<Background variant="dots" gap=.../>` 视觉网格（8px 基线对齐 Swiss）。
  - 小地图：`<MiniMap nodeColor={...}/>`，颜色映射节点状态（走 token，禁 oklch）。
  - 控制器：`<Controls/>`（缩放/适配/锁定按钮）。
- 关键实现点：
  - 控制器/小地图为画布固定角元素，用绝对定位 + flex 固定栏，**不**用容器查询自适应。
  - 缩放/平移仅触发 transform，不引起布局抖动（性能约束）。
  - `onlyRenderVisibleElements` 与 T01 一致，保证缩放后视口外节点不渲染。

## 影响范围

- 文件：`app/src/canvas/EltCanvas.tsx`（扩展）、`app/src/canvas/canvasStyle.ts`（背景/小地图/控制器样式 token）
- 组件：`EltCanvas` 内的 `Background`/`Controls`/`MiniMap`
- 依赖：T01；连线落库依赖 T04 store.connect
