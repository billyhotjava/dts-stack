# T01: 5 类节点卡片渲染（类型图标 + 名称 + 状态点 + 行数徽标）

**优先级**: P0
**状态**: READY
**依赖**: F1-T01, F1-T04

## 目标

为源表/清洗/连接(join)/聚合/输出 5 类节点实现真实卡片渲染，替换 F1-T01 的占位。

## 技术设计

- 库：`@xyflow/react` v12 自定义节点（`Handle` 入/出连接点）+ AntD 原子（Tag/Badge）。
- 文件：
  - `app/src/canvas/nodes/EltNodeCard.tsx`：通用卡片骨架（图标槽 + 名称 + 状态点 + 行数徽标 + Handle）。
  - `app/src/canvas/nodes/{SourceNode,CleanNode,JoinNode,AggregateNode,OutputNode}.tsx`：5 类按 kind 复用骨架、各配图标与连接点规则（源表只出、输出只入）。
  - 接回 `app/src/canvas/nodeTypes.ts`（F1-T01）的 `nodeTypes` 映射。
- 关键实现点：
  - 卡片内容映射设计文档 §7：`类型图标 · 名称 · 状态点（●已连通/运行态）· 行数徽标（如 3.2万行）`。
  - 行数等数字用 **tabular-nums**（对齐 Swiss 数据区约定）。
  - 状态点颜色取统一状态 token（成功/警告/错误/信息），HSL/hex，禁 oklch。
  - 选中态高亮由 `canvasStore.selectedNodeId` 派生（点击卡片 → `select`）。
  - 卡片有 hover/focus/active 设计态（仅 transform/opacity 动效）。
  - 卡片为可聚焦元素，含 `aria-label`（类型+名称+状态），支撑 a11y。

## 影响范围

- 文件：`app/src/canvas/nodes/EltNodeCard.tsx` + 5 个节点组件、`nodeTypes.ts`（接线）
- 组件：5 类节点卡片
- 依赖：F1-T01（nodeTypes/types）、F1-T04（store 选中态/数据）
