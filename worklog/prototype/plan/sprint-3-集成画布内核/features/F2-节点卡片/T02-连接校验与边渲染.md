# T02: 节点连接校验与边渲染（数据流向、非法连接拦截）

**优先级**: P0
**状态**: READY
**依赖**: F2-T01, F1-T03

## 目标

实现连接合法性校验与带方向的边渲染：合法连接落库为有向边，非法连接被拦截并给出可见反馈。

## 技术设计

- 库：`@xyflow/react` v12 连线钩子（`isValidConnection` / `onConnect`），边类型用带箭头 marker 的 `default`/`smoothstep`。
- 文件：
  - `app/src/canvas/connectionRules.ts`：纯函数 `validateConnection(source, target, nodes, edges): Result<void>`（可单测）。
  - 接入 `EltCanvas`（F1）：`isValidConnection` 调规则做实时高亮、`onConnect` 调 store.connect（合法时）。
  - `app/src/canvas/edges/FlowEdge.tsx`（可选）：统一边样式 + 方向箭头 marker。
- 连接规则（数据流向语义）：
  - 源表节点不可作为 target（无入边）；输出节点不可作为 source（无出边）。
  - 禁止自环（source === target）。
  - 禁止重复边（同一对 source→target 已存在）。
  - 连接方向只能 上游→下游（出 Handle→入 Handle）。
- 关键实现点：
  - 非法连接**可见反馈**：拖拽时目标 Handle/边变红或禁用态 + 松手给 AntD `message`/`aria-live` 提示（不静默吞错）。
  - 边带方向箭头 marker，颜色走 token；边路径仅 transform 不引发布局抖动。
  - 校验为纯函数，便于 F1-T04 store 复用与单测。

## 影响范围

- 文件：`app/src/canvas/connectionRules.ts`、`EltCanvas.tsx`（接 isValidConnection/onConnect）、`app/src/canvas/edges/FlowEdge.tsx`
- 组件/逻辑：连接校验、边渲染
- 依赖：F2-T01（节点 Handle）、F1-T03（连线通道）、F1-T04（store.connect）

## 验证

- [ ] 合法连接（源表→清洗→输出方向）成功，边带方向箭头并落库到 store。
- [ ] 指向源表、从输出向外连、自环、重复边 → 全部被拦截。
- [ ] 非法连接有可见反馈（拖拽态高亮 + 松手提示/aria-live），不静默失败。
- [ ] 边颜色 token 化、无 oklch；连线交互无布局抖动。
- [ ] `validateConnection` 纯函数对各规则有单测覆盖。

## 完成标准

- [ ] 连接合法性规则全部生效且有可见反馈。
- [ ] 合法边按数据流向带箭头渲染并落库。
- [ ] 校验逻辑为可单测纯函数。
