# F2: 节点卡片

**优先级**: P0
**状态**: READY

## 目标

把 F1 注册的 5 类节点渲染为真实的 ELT 节点卡片（类型图标 + 名称 + 状态点 + 行数徽标），并实现边的数据流向渲染与连接合法性校验（非法连接拦截并给出可见反馈）。完成后画布从"占位方块"升级为"可读的 ELT 数据流图"。

## 背景

对应设计文档 §7 节点卡片图与"连线表数据流向"。卡片是用户在画布上识别每个步骤的主要载体；连接校验保证用户搭出的图在语义上合法（如：输出节点不能作为上游、源表不能有入边）。

## 完成标准

- [ ] 5 类节点卡片各有独立图标与状态语言（状态点 + 行数徽标），数字用 tabular-nums 对齐。
- [ ] 卡片走 reactflow `Handle`（入/出连接点），样式用 Swiss token，禁 oklch。
- [ ] 连接合法性规则生效：非法连接（如指向源表、输出节点向外连、自环、重复边）被拦截并给出可见反馈。
- [ ] 边按数据流向渲染（带方向箭头），合法边可成功落库到 store。
- [ ] "销售准备项目"样例图渲染后可读：每个节点显示正确类型/名称/状态/行数。
