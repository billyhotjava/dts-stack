# T01: 运维总览 / 实例 / 回填

**优先级**: P1
**状态**: READY
**依赖**: S1

## 目标

在旁路区「运维」域落地运维总览、实例列表、回填三页，骨架（总览概览卡 + 两张 CompactTable），接 `opsService`。

## 技术设计

- 文件：`app/src/platform/ops/OpsOverviewPage.tsx`、`InstancesPage.tsx`、`BackfillPage.tsx`（命名对齐现网 `pages/ops/*`）。
- 运维总览：概览卡骨架——运行中实例数、近 24h 告警数、回填任务数（数字用 `tabular-nums`）；旁路区先占位卡片即可。
- 实例列：实例名、关联作业、运行状态点（运行中/成功/失败/排队）、开始时间、耗时、操作（详情占位）。
- 回填列：回填任务名、目标区间、状态点（待执行/执行中/完成/失败）、进度、提交时间（`tabular-nums` 对齐）、操作（占位）。
- 表格：`CompactTable` 默认 10 条/页；切换条数刷新、`pageSize` 收敛、回第 1 页。
- mock service：`opsService`（`getOpsOverview`、`listInstances`、`listBackfills` 返回 `Promise<Result<T>>`，对齐 mock 契约约定）。

## 影响范围

- 新增 `app/src/platform/ops/OpsOverviewPage.tsx`、`InstancesPage.tsx`、`BackfillPage.tsx`
- 新增/扩展 `app/src/mock/services/opsService.ts`（`getOpsOverview`、`listInstances`、`listBackfills`）
- mock fixtures：运维概览 / 实例 / 回填样例（含多种运行状态点态）
- 左轨「平台·运维」入口注册；纳入全局搜索索引（F4-T02）
