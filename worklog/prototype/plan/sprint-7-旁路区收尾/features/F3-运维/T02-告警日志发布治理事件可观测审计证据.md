# T02: 告警 / 日志 / 发布治理 / 事件可观测 / 审计证据

**优先级**: P1
**状态**: READY
**依赖**: S1

## 目标

在旁路区「运维」域落地告警日志、日志中心、发布治理、平台事件可观测、审计证据五页，CompactTable mock 列表骨架，接 `opsService`。

## 技术设计

- 文件：`app/src/platform/ops/AlertLogPage.tsx`、`LogCenterPage.tsx`、`ReleaseGovernancePage.tsx`、`PlatformEventObservabilityPage.tsx`、`AuditEvidencePage.tsx`（命名对齐现网 `pages/ops/*`）。
- 告警日志列：告警级别状态点（严重/警告/信息）、来源、消息、触发时间（`tabular-nums`）、状态（已处理/未处理）。
- 日志中心列：时间、级别、来源模块、日志摘要、操作（详情占位）；可留筛选条骨架。
- 发布治理列：发布项、目标环境、发布状态点（待发布/发布中/成功/回滚）、发起人、时间、操作（占位）。
- 平台事件可观测列：事件名、事件类型、关联流程、状态点、发生时间；旁路区先占位列表即可。
- 审计证据列：证据项、关联审计、归档状态点、生成时间、操作（下载占位）。
- 表格：`CompactTable` 默认 10 条/页；切换条数刷新、`pageSize` 收敛、回第 1 页。
- mock service：`opsService`（`listAlerts`、`listLogs`、`listReleases`、`listPlatformEvents`、`listAuditEvidence` 返回 `Promise<Result<T>>`）。

## 影响范围

- 新增 `app/src/platform/ops/AlertLogPage.tsx`、`LogCenterPage.tsx`、`ReleaseGovernancePage.tsx`、`PlatformEventObservabilityPage.tsx`、`AuditEvidencePage.tsx`
- 新增/扩展 `app/src/mock/services/opsService.ts`（五个 list 方法）
- mock fixtures：告警 / 日志 / 发布 / 事件 / 审计证据样例（含多种状态点态）
- 左轨「平台·运维」入口注册；纳入全局搜索索引（F4-T02）
