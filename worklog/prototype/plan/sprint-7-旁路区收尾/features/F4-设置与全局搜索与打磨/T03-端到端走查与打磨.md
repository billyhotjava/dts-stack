## 目标

完成原型整体收尾：端到端黄金主线连贯性走查、Chrome 95 全量回归冒烟、视觉一致性核查，把分散交付的主线四阶段 + 旁路五域打磨成可交付整体。

## 技术设计

- **黄金主线连贯性走查**：以样例项目「销售准备项目」为载体，从项目门户「你的下一步」引导卡出发，连贯走完 连接→集成→资产→指标，验证左轨阶段状态点由项目数据正确派生（`✓`/`●`/`○`），项目上下文全程 scoped 一致。打磨阶段间衔接（引导卡指向、阶段切换、画布产物喂资产/指标的数据连续性）。
- **Chrome 95 全量回归冒烟**：legacy 构建产物在 Chrome 95 路径加载，逐一冒烟四阶段 + 五旁路域全量页面，核查无白屏 / 控制台致命报错；静态扫描源码无 `oklch(` / `:has(` / 容器查询 / `subgrid`（`legacy-css-fallbacks` 仅安全网）；画布平移/缩放/连线 + dnd-kit 键盘兜底正常；CompactTable 分页一致。
- **视觉一致性核查**：旁路区与主线共用 Swiss token（HSL/hex、Inter、8px 基线、12 列网格）、统一状态点语言、`tabular-nums` 数字对齐、动效仅 `transform/opacity`；修正旁路区可能出现的密度/间距/状态点漂移。
- **打磨**：收尾修复走查中暴露的断路由、占位页报错、命名漂移、空态缺失等问题。
- 不写后端、不接真服务；所有走查在 `VITE_USE_MOCK=1` + legacy 产物下进行。
