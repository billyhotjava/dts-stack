# F4: 设置 + 全局搜索 + 打磨

**优先级**: P0
**状态**: READY

## 目标

承担本 sprint 的 P0 收尾职责：落地旁路区「设置 Settings」域（settings/sys），实现全局搜索 ⌘K（跨四阶段 + 五旁路域，命中跳转），并完成端到端黄金主线走查与 Chrome 95 全量回归冒烟、视觉一致性核查。全局搜索是把整套 IA（主线 + 旁路）串成一张可达图的关键收口件；端到端走查是「黄金主线可走通」这一核心设计目标的最终兑现点。
