# T02: 全局搜索 ⌘K

**优先级**: P0
**状态**: READY
**依赖**: S1–S6

## 目标

实现全局搜索 ⌘K 命令面板，索引覆盖四阶段 + 五旁路域，命中后跳转到目标页面/阶段并保持项目上下文。这是把整套 IA（主线 + 旁路）串成一张可达图的收口件。

## 技术设计

- 文件：`app/src/shell/GlobalSearch.tsx`（挂在项目外壳顶栏 ⌘K 入口，对齐设计文档 §6 顶栏「⌘K 搜索」）。
- 唤起：`⌘K`（mac）/ `Ctrl+K`（win）全局快捷键唤起，`Esc` 关闭；用受控弹层（非 `:has()`，用状态控制显隐）。
- 索引来源：集中式 `searchIndex`——四阶段（连接/集成/资产/指标）页面 + 五旁路域（服务/治理/安全/运维/设置）页面元数据（标题、所属阶段/域、路由、关键词）。建议从各页面注册表派生，避免硬编码漂移。
- 结果：按「阶段 / 旁路域」分组展示，匹配标题 + 关键词；空态与无结果态。
- 跳转：回车 / 点击跳转到目标路由，保持当前项目上下文（顶栏项目切换器 scoped 不变）；旁路区命中跳转后自动展开左轨「平台」折叠区对应入口。
- a11y：键盘上下导航 + 回车选中，焦点可见（不依赖鼠标），符合 Chrome 95 兼容（无容器查询/`:has()`）。
- mock：搜索索引数据可来自各 `*Service.ts` 的页面注册或静态 `searchIndex` fixture；不强依赖后端。

## 影响范围

- 新增 `app/src/shell/GlobalSearch.tsx` 及 `app/src/shell/searchIndex.ts`
- 项目外壳顶栏接入 ⌘K 入口与全局快捷键监听
- 各阶段 / 旁路页面注册到 `searchIndex`（标题/路由/关键词/所属分组）
- 与左轨折叠区联动（旁路命中展开对应入口）
