# T01: 数据源列表

**优先级**: P0
**状态**: READY
**依赖**: S1

## 目标

在阶段①渲染 `DataSourcesPage` 数据源列表，CompactTable + 状态列，接 mock。

## 技术设计

- 文件：`app/src/stages/connect/DataSourcesPage.tsx`（命名对齐现网 `pages/foundation/DataSourcesPage.tsx`）。
- 表格：用 S1 提供的 `CompactTable` 原子组件，默认 10 条/页；切换每页条数后刷新、`pageSize` 收敛；分页受控 `useEffect` deps 含 `pageSize`，切 size 重置第 1 页（对齐分页统一约定）。
- 列：名称、类型（关系型/Excel 等）、连接状态（已连通/未连通/测试中，用 Swiss 状态点 token 渲染）、负责人、更新时间、操作（详情/编辑/连通测试入口）。
- 数据区数字列用 `tabular-nums` 等宽对齐。
- mock service：`dataSourcesService`（`listDataSources` 返回 `Promise<Result<InfraDataSource[]>>`，复刻现网契约形状；状态字段对齐 `ConnectionTestResult` 派生的连通态）。
- 行操作里的「连通测试」入口与 T04 联动；「详情」跳 T02，「编辑」开 T03 modal。

## 影响范围

- 新增 `app/src/stages/connect/DataSourcesPage.tsx`
- 新增/扩展 `app/src/mock/services/dataSourcesService.ts`（`listDataSources`）
- mock fixtures：销售准备项目的 PLM 订单、ERP 客户两条已连通样例
- 阶段① 路由 slot 注册（依赖 S1 外壳）
