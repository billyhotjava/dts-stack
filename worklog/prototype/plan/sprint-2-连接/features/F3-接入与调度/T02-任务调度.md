# T02: 任务调度

**优先级**: P1
**状态**: READY
**依赖**: F1-T01

## 目标

落地 `TaskSchedulingPage` 采集/同步调度列表，接 mock，可关联 F1 数据源。

## 技术设计

- 文件：`app/src/stages/connect/TaskSchedulingPage.tsx`（对齐现网 `pages/foundation/TaskSchedulingPage.tsx`）。
- 表格：CompactTable，默认 10 条/页；列：任务名、关联数据源（链接到 F1-T02 详情）、调度周期（cron/间隔，只读展示）、启用状态、上次运行状态、上次运行时间。
- 上次运行状态用统一运行状态点 token（成功/失败/运行中），与画布运行状态同源（设计文档 §8 状态语言）。
- 原型阶段不做真实调度，启用/暂停为 mock 反馈占位；运行历史指向后续 ② 集成的运行 dock（占位链接）。
- mock service：新增轻量 `taskSchedulingService`（`listSchedules`），关联数据源 id 取自 `dataSourcesService` 样例。

## 影响范围

- 新增 `app/src/stages/connect/TaskSchedulingPage.tsx`
- 新增 `app/src/mock/services/taskSchedulingService.ts`
- 阶段① 路由：`connect/task-scheduling`
- 弱依赖 F1 数据源样例（关联列跳转 T02 详情）
