# T01: 接入变更

**优先级**: P1
**状态**: READY
**依赖**: S1

## 目标

落地 `AccessChangesPage` 接入变更记录列表，接 mock。

## 技术设计

- 文件：`app/src/stages/connect/AccessChangesPage.tsx`（对齐现网 `pages/foundation/AccessChangesPage.tsx`）。
- 表格：CompactTable，默认 10 条/页；列：变更对象（数据源/连接器）、变更类型（新增/修改/下线）、申请人、状态（待审/通过/驳回）、时间。
- 状态点 token 与全局状态语言统一；行可展开/抽屉看只读详情（原型阶段不做审批动作，或仅 mock 通过/驳回反馈）。
- mock service：新增轻量 `accessChangesService`（`listAccessChanges` 返回 `Promise<Result<...>>`），契约形状对齐现网风格；与 F1 数据源 id 可弱关联。
- 过滤/筛选（按状态/类型）走 URL 查询参数（可分享状态，对齐 web patterns）。

## 影响范围

- 新增 `app/src/stages/connect/AccessChangesPage.tsx`
- 新增 `app/src/mock/services/accessChangesService.ts`
- 阶段① 路由：`connect/access-changes`
