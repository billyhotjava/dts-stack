# T02: 原子组件（Button/Card/Surface/StatusDot/SectionTitle）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

交付一组消费 token 的 Swiss 风格原子组件，供外壳与后续阶段页面复用。

## 技术设计

- **目录**：`src/ui/atoms/`，每个组件一目录或一文件 + 配套 css，桶文件 `src/ui/atoms/index.ts` 统一导出。
- **组件清单**：
  - `Button`：基于 AntD `Button` 薄封装或自绘，应用强调色/中性变体；hover/focus/active 状态明确，仅动 transform/opacity。
  - `Card`：内容卡，8px 内距刻度、边框/表面 token、可选标题区。
  - `Surface`：分层表面容器（`--color-surface` / `--color-surface-raised`），承载分区。
  - `StatusDot`：状态点（`complete ✓` / `active ●` / `pending ○` / `error`），复用 T01 状态色 token——F4 阶段轨与画布节点状态直接复用。
  - `SectionTitle`：分区标题，强字号层次 + 可选副标题/计数，体现 Swiss 排版层次。
- **Props 规范**：命名 PascalCase、props 显式 `interface`，不用 `React.FC`（对齐 TS 规则）。
- **回植友好**：组件 API 与现网相近命名，未来可平移进 `dts-platform-webapp`。

## 影响范围

- 新增 `src/ui/atoms/*` 及 `src/ui/atoms/index.ts`。
- 依赖 F2-T01 token；被 F4 外壳与后续阶段页面消费。

## 验证

- [ ] 各原子组件在预览页渲染，取色/间距全部来自 token（无硬编码颜色）。
- [ ] hover/focus/active 状态可见且仅用 transform/opacity 动效。
- [ ] StatusDot 四态（complete/active/pending/error）渲染正确，色值取自状态 token。
- [ ] 组件 props 有显式类型，导出经桶文件统一。

## 完成标准

- [ ] 五个原子组件齐备、风格统一、消费 token。
- [ ] 状态点可被 F4 阶段轨直接复用。
- [ ] 命名/API 对齐现网，回植成本低。
