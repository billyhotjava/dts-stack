# T01: Shell 布局（顶栏项目上下文 + 左侧阶段轨 + 内容区）

**优先级**: P0
**状态**: READY
**依赖**: F2-T02, F1-T01

## 目标

搭建项目外壳的三区布局骨架：顶栏（项目上下文）+ 左侧阶段轨 + 右侧内容区，全程 Chrome 95 安全的 flex/grid。

## 技术设计

对齐设计文档 §6 的外壳示意：

```
┌──────────────────────────────────────────────┐
│ DTS ▸ 项目 ▾   ⌘K 搜索    🔔  用户 ▾          │ 顶栏:项目上下文
├──────────┬─────────────────────────────────────┤
│ ✓ ① 连接 │  内容区（后续 sprint 阶段页面挂这里）  │
│ ● ② 集成 │                                       │
│ ○ ③ 资产 │                                       │
│ ○ ④ 指标 │                                       │
│ ──────── │                                       │
│ ▾ 平台   │                                       │
└──────────┴─────────────────────────────────────┘
```

- **文件**：`src/shell/AppShell.tsx`（外壳骨架）+ `src/shell/TopBar.tsx` + `src/shell/StageRail.tsx`（阶段轨容器，状态点逻辑留 T03）+ `src/shell/shell.css`。
- **布局**：CSS Grid / Flex 固定栏——顶栏固定高、左轨固定宽、内容区自适应。**禁用** `:has()`/容器查询/subgrid（Chrome 95）；需要尺寸响应时用 `ResizeObserver`，不用 `@container`。
- **左轨结构**：上段=黄金主线 4 阶段（连接/集成/资产/指标，状态点 T03 接入），分隔线，下段=折叠的"平台"旁路区（服务/治理/安全/运维/设置，本 sprint 占位即可）。
- **路由**：接入 `react-router`，内容区 `<Outlet/>` 承载阶段/门户路由；阶段路由本 sprint 用占位页。
- **复用 F2**：顶栏/轨用 Surface/SectionTitle/Button 等原子组件与 token。
- **dev 入口**：F3-T04"重置样例数据"挂在顶栏 dev-only 位置。

## 影响范围

- 新增 `src/shell/AppShell.tsx` / `TopBar.tsx` / `StageRail.tsx` / `shell.css`；`App.tsx` 接入路由 + Shell。
- 依赖 F2 原子组件/token；为 T02/T03/T04 提供挂载点。
