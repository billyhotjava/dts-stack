# T04: 项目门户"你的下一步"引导卡

**优先级**: P0
**状态**: READY
**依赖**: T03

## 目标

实现项目门户（替代工作台）的"你的下一步"引导卡，直接指向当前阶段的待办动作，解决现网"没有优先级/没有下一步"的核心病灶。

## 技术设计

对齐设计文档 §6（"你的下一步"引导卡）与 §5（项目门户收纳 LeaderOverview / Workbench / WorkflowCenter）：

- **文件**：`src/shell/ProjectPortal.tsx`（内容区默认路由 `/`），消费 F4-T03 派生的阶段状态。
- **下一步逻辑**：取主线上第一个非 `complete` 阶段为"当前阶段"，生成一条可执行引导文案，例如：
  - 连接未完成 → "① 连接：你还没有已连通的数据源 → 去添加数据源"
  - 集成进行中 → "② 集成：你有 1 个转换作业待跑通 → 去画布"
  - 资产/指标类似。
  文案 + 跳转目标由当前阶段派生（数据驱动，非硬编码单条）。
- **引导卡**：用 F2 `Card`/`Surface`/`Button`/`SectionTitle` 构建，强调当前阶段，点击 CTA 导航到对应阶段路由（本 sprint 占位页即可）。
- **门户其余区**：可放阶段进度概览（复用阶段轨状态）+ 项目摘要占位；本 sprint 以"下一步"卡为主交付，其余占位。
- **空/边界态**：项目无数据（理论上重置后仍有种子）时给出"从连接开始"的引导。

## 影响范围

- 新增 `src/shell/ProjectPortal.tsx`；接内容区默认路由。
- 依赖 F4-T03（阶段状态派生）、F2 原子组件、F4-T02（当前项目）。
