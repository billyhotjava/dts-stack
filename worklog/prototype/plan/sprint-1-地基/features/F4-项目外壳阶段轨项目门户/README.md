# F4: 项目外壳 + 阶段轨 + 项目门户

**优先级**: P0
**状态**: READY

## 目标

落地"项目/工作空间 + 阶段向导"范式的外壳：Shell 布局（顶栏项目上下文 + 左侧阶段轨 + 内容区）、项目切换器 + 项目上下文 store、由项目数据派生的阶段状态点、以及项目门户"你的下一步"引导卡。这是兑现"统一入口 + 优先级 + 下一步"的核心交付，后续阶段页面挂进内容区即可。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | Shell 布局（顶栏 + 阶段轨 + 内容区） | P0 | READY | F2-T02, F1-T01 |
| T02 | 项目切换器 + 项目上下文 store（zustand） | P0 | READY | T01, F3-T03 |
| T03 | 阶段状态派生 + 状态点 | P0 | READY | T02 |
| T04 | 项目门户"你的下一步"引导卡 | P0 | READY | T03 |

## 完成标准

- [ ] Shell 布局用 flex/grid 固定栏（不用 `:has`/容器查询/subgrid），顶栏含项目上下文、左侧阶段轨、右侧内容区。
- [ ] 项目切换器可切项目；项目上下文 store（zustand，对齐现网 `contextStore`）持久化当前项目，所有阶段数据 scoped 到当前项目。
- [ ] 阶段轨 4 阶段状态点（✓完成/●进行中/○待开始）由项目种子数据派生（连接/集成/资产/指标各自的派生规则），复用 F2 StatusDot。
- [ ] 项目门户"你的下一步"引导卡指向当前阶段的待办动作，点击可导航到该阶段（占位路由即可）。
