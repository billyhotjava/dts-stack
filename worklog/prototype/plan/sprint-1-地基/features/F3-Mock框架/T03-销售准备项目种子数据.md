# T03: "销售准备项目"种子数据骨架（贯穿 4 阶段）

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

填充一条端到端可走通的样例项目"销售准备项目"种子数据，贯穿连接→集成→资产→指标 4 阶段，使黄金主线可点可走、阶段状态可派生。

## 技术设计

对齐设计文档 §9，种子数据贯穿 4 阶段：

1. **① 连接**：两个已连通数据源——`PLM`（订单）+ `ERP`（客户）。fixtures 标记 `已连通` 状态。
2. **② 集成**：一个转换作业——`PLM.订单`/`ERP.客户` → 去重 → 连接(join)，含节点 + 连线 + 行数徽标（如订单 3.2 万行），作业状态"跑通≥1"。
3. **③ 资产**：一个发布数据集——`ODS.宽表`（订单×客户 join 结果），含基础元数据/行数。
4. **④ 指标**：一个发布指标——`销售达成率`，挂在 ODS 宽表上。

- **数据组织**：种子集中在 `src/mock/fixtures/seed/sales-prep-project.ts`，按域导出，供各域 fixtures 初始化引用。
- **派生友好**：种子结构需让阶段状态可派生（连接=已连通≥1 源、集成=作业跑通≥1、资产=发布数据集≥1、指标=发布指标≥1）——F4-T03 阶段状态点直接吃这份数据。
- **维度码稳定**（对齐 dim-code-design 习惯）：数据源/作业/数据集/指标的标识用稳定 ASCII code 作主键（如 `ds_plm`、`job_dedup_join`、`ds_ods_wide`、`metric_sales_rate`），不用中文名做键。
- **范围克制**：只放走通主线所需的最小字段，不追求现网全字段。
