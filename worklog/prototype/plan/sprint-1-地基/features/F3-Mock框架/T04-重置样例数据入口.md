# T04: "重置样例数据"开发入口

**优先级**: P1
**状态**: READY
**依赖**: T03

## 目标

提供一个开发态入口，把内存 fixtures 复位到初始种子，便于演示与反复验证黄金主线。

## 技术设计

- **复位逻辑**：`src/mock/resetSeed.ts` 暴露 `resetSeedData()`，把各域 fixtures 的内存可变状态重新从 `seed/sales-prep-project.ts` 深拷贝初始化（不可变复位，不就地改种子源）。
- **触发入口**（dev-only，`import.meta.env.DEV` 守门）：
  - 优先：外壳顶栏/页脚一个隐蔽的"重置样例数据"按钮；
  - 兜底：挂到 `window.__resetSeed()` 供控制台调用。
- **反馈**：复位后给一次轻量提示（AntD `message`），并触发相关 store/查询刷新（与 F4 store 协调）。
- **生产隔离**：生产构建不暴露该入口（DEV 守门 + 不进 prod bundle）。

## 影响范围

- 新增 `src/mock/resetSeed.ts`；外壳挂一个 dev-only 触发点（与 F4-T01 Shell 协调）。
- 依赖 F3-T03 种子；与 F4 store 刷新协调。

## 验证

- [ ] 改动内存数据后调用 `resetSeedData()`，fixtures 回到初始种子。
- [ ] dev 环境入口可见/可触发；生产构建不暴露。
- [ ] 复位后页面数据/状态刷新到初始态。

## 完成标准

- [ ] "重置样例数据"入口在 dev 可用、复位正确、不可变复位。
- [ ] 生产隔离到位。
- [ ] 演示/验证黄金主线可反复执行。
