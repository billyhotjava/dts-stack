# T01: 初始化 Vite+React19+TS+AntD5 工程骨架

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

在 `worklog/prototype/app` 建立可 `dev`/`build` 的 React19+TS+Vite+AntD5 最小工程骨架。

## 技术设计

- **栈对齐现网**（`source/dts-platform-webapp`）：React 19、TypeScript ~5.6、Vite 6、Ant Design 5（`antd ^5.22`）、`@fontsource-variable/inter`、`zustand ^4.5`。包管理用 pnpm。
- **目录骨架**（对齐设计文档 §4.1）：
  ```
  app/
  ├── src/
  │   ├── shell/        # 项目外壳（F4）
  │   ├── stages/       # 黄金主线阶段（后续 sprint）
  │   ├── platform/     # 旁路区（后续 sprint）
  │   ├── mock/         # mock API 层（F3）
  │   ├── ui/           # Swiss 设计系统（F2）
  │   ├── components/   # 通用组件（含 table/CompactTable，F2）
  │   ├── store/        # zustand store（F4）
  │   ├── App.tsx
  │   └── main.tsx
  ├── index.html
  ├── package.json
  ├── tsconfig.json
  └── vite.config.ts
  ```
- `main.tsx` 挂载 `ConfigProvider`（AntD）+ `App`；先放一个占位首页（"DTS 原型地基"标题）验证渲染链路。
- `@fontsource-variable/inter` 在入口导入，为 F2 排版做准备。
- 仅建骨架，不引入 legacy 工具链（留给 T02）、不引入业务页面。

## 影响范围

- 新建工程目录 `worklog/prototype/app/` 全部基础文件。
- 不触碰现网 `source/`；不接后端。

## 验证

- [ ] `pnpm install` 成功。
- [ ] `pnpm dev` 启动，浏览器渲染占位首页，控制台无报错。
- [ ] `pnpm build` 成功产出 `dist/`（此时未必含 legacy，T03 再验）。
- [ ] AntD 组件（如 `Button`）在占位页可正常渲染，样式生效。

## 完成标准

- [ ] 工程可 `dev`/`build`，目录骨架与设计文档 §4.1 一致。
- [ ] 核心依赖版本对齐现网，便于组件回植。
- [ ] 占位首页渲染正常，无控制台错误。
