# T01: 评分计算引擎（后端）

**优先级**: P1
**状态**: READY
**依赖**: F3

## 目标
实现按数据集维度的质量评分计算——综合评分 + 5 个维度评分（完整性/一致性/准确性/唯一性/及时性）。

## 技术设计

### 评分公式
```
权重：CRITICAL=4, HIGH=3, MEDIUM=2, LOW=1

单规则得分 = 通过率 × 100
  通过率 = (totalRows - failingRows) / totalRows

维度得分 = Σ(单规则得分 × 权重) / Σ权重
  按规则 type 分组：COMPLETENESS/CONSISTENCY/ACCURACY/UNIQUENESS/TIMELINESS

综合得分 = Σ(维度得分 × 维度权重) / Σ维度权重
  维度权重默认相等，后期可配置
```

### API
```
GET /api/governance/quality/score?datasetId={id}&period=7d
→ {
  overall: 87,
  overallDelta: +3,
  dimensions: [
    { type: "COMPLETENESS", score: 92, delta: +5 },
    { type: "CONSISTENCY", score: 81, delta: -2 },
    ...
  ],
  trend: [
    { date: "2026-04-01", overall: 84 },
    { date: "2026-04-02", overall: 86 },
    ...
  ]
}
```

### 计算时机
- 实时计算（每次请求时聚合最近 N 天的 QualityRun 结果）
- 不做预计算缓存（数据量可控：规则数 ×运行次数 ~千级）

### Delta 计算
当前周期平均得分 vs 上一周期平均得分
