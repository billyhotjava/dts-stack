# T04: 入湖自动触发链路

**优先级**: P1
**状态**: READY
**依赖**: T02

## 目标
入湖任务完成后，自动触发清洗 + 质量检测链路。

## 技术设计

### 触发时机
IngestionTask 执行状态变为 SUCCESS 后，通过 Spring 事务同步（`TransactionSynchronization.afterCommit`）触发：
1. 查询目标数据集绑定的清洗函数 → 执行 DataCleansingService
2. 查询目标数据集绑定的已发布规则 → 触发 QualityRunService（异步）

### 触发条件
- 入湖任务已关联目标数据集（datasetId 非空）
- 目标数据集有绑定的清洗函数或质量规则
- 入湖任务 `qualityPreCheckEnabled = false`（走预检链路的不重复触发）

## 影响范围
- `IngestionTaskService`：成功回调中增加清洗 + 质量触发
- `QualityRunService`：triggerType 增加 `INGESTION` 类型

## 验证
- [ ] 入湖成功后自动触发清洗
- [ ] 清洗完成后自动触发质量检测
- [ ] 预检链路不重复触发

## 完成标准
- [ ] 入湖→清洗→检测 全自动链路跑通
