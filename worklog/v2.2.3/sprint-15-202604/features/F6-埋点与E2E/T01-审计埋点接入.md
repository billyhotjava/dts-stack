# T01: 审计埋点接入 auditService

**优先级**: P0
**状态**: READY
**依赖**: F3/T05, F4/T03, F5/T04

## 目标

把 F3-F5 里的 `src/utils/audit.ts` 桩替换为真实的审计上报——通过项目既有 `auditService`（或 `/api/audit/events`）。保持 API 不变，切换实现。

## 技术设计

### 先定位既有 audit 通路

```bash
grep -rn "auditService\|/audit/events\|audit\." source/dts-platform-webapp/src/api/ | head -20
```

预期在 `src/api/services/` 找到 `auditService.ts` 或类似。如果找到：

```ts
// src/utils/audit.ts
import auditService from "@/api/services/auditService";

export function auditLog(event: string, payload: Record<string, unknown>): void {
  auditService.record({
    event,
    payload,
    source: "workbench.leader-overview",
    timestamp: new Date().toISOString(),
  }).catch((ex) => {
    // 埋点失败不阻塞主流程
    if (import.meta.env.DEV) {
      // eslint-disable-next-line no-console
      console.debug("[audit] failed", event, ex);
    }
  });
}
```

### 事件清单（本 sprint 新增）

| 事件 | 触发点 | payload 关键字段 |
|---|---|---|
| `WORKBENCH_OVERVIEW_VIEW` | 页面进入（F5/T04 已埋） | `role`, `deptCode` |
| `WORKBENCH_FILTER_CHANGE` | FilterBar 切换（F3/T05 已埋） | `dim` (dept/bizDomain/timeRange), `value`, `role` |
| `WORKBENCH_DOMAIN_DRILL` | 色块点击（F4/T03 已埋） | `domain` |
| `WORKBENCH_DOMAIN_API_FAIL` | 业务域下拉拉取失败（F3/T03 已埋） | `when` |
| `WORKBENCH_DOMAIN_API_EMPTY` | 业务域下拉空列表（F3/T03 已埋） | - |

### 后端落地

确认后端 `/api/audit/events` 或 `auditService.audit(...)` 能接收上述事件编码，不需要对每个事件写白名单。若需要注册 event code，到 `source/dts-platform/src/main/java/com/yuzhi/dts/platform/service/audit/AuditEventCodes.java`（或类似）里加常量。

### 不阻塞主流程

埋点失败永远 catch 并吞掉（DEV 下打印 debug），不能影响页面加载 / 用户操作。
