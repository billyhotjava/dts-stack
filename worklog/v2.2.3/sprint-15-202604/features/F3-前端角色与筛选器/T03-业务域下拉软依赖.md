# T03: 业务域下拉（软依赖降级）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

`BizDomainSelect` 子组件：

- 拉 `GET /api/catalog/domains` 的业务域列表，渲染为下拉。
- **失败 / 返回空** → 组件**整个隐藏**（不是禁用，也不是显示 "加载失败"）。
- 不显示红色 toast，只记录埋点 `WORKBENCH_DOMAIN_API_FAIL`。

## 技术设计

### 先确认接口

查看 `source/dts-platform-webapp/src/api/services/` 是否已有 `catalogDomainService` / `themeDomainService`。若无，在 `src/api/services/catalogDomainService.ts` 新增（仅本 sprint 用的最小 API）：

```ts
import apiClient from "../apiClient";

export interface CatalogDomain {
  code: string;
  name: string;
  parentCode?: string | null;
}

export default {
  list: () => apiClient.get<CatalogDomain[]>({ url: "/catalog/domains" }),
};
```

> **重要**：先 grep 确认不与既有服务命名冲突。若已存在则复用，不新建。

### 组件

```tsx
// src/pages/workbench/components/BizDomainSelect.tsx
import { Select } from "antd";
import { useEffect, useState } from "react";
import catalogDomainService, { type CatalogDomain } from "@/api/services/catalogDomainService";
import { auditLog } from "@/utils/audit"; // 项目既有 audit helper，若无则用 console.debug 桩

export interface BizDomainSelectProps {
  value: string | "ALL" | null;
  onChange: (value: string | "ALL") => void;
  onAvailabilityChange: (available: boolean) => void; // 告诉外层是否渲染
}

export function BizDomainSelect({ value, onChange, onAvailabilityChange }: BizDomainSelectProps) {
  const [domains, setDomains] = useState<CatalogDomain[] | null>(null);
  const [available, setAvailable] = useState(false);

  useEffect(() => {
    let cancelled = false;
    catalogDomainService.list()
      .then((list) => {
        if (cancelled) return;
        if (!Array.isArray(list) || list.length === 0) {
          setAvailable(false);
          onAvailabilityChange(false);
          return;
        }
        setDomains(list);
        setAvailable(true);
        onAvailabilityChange(true);
      })
      .catch(() => {
        if (cancelled) return;
        setAvailable(false);
        onAvailabilityChange(false);
        auditLog("WORKBENCH_DOMAIN_API_FAIL", { when: "fetch_list" });
      });
    return () => { cancelled = true; };
  }, [onAvailabilityChange]);

  if (!available || !domains) return null;

  const options = [
    { value: "ALL", label: "全部业务域" },
    ...domains.map((d) => ({ value: d.code, label: d.name })),
  ];

  return (
    <Select
      value={value ?? "ALL"}
      onChange={(v) => onChange((v as string) ?? "ALL")}
      options={options}
      style={{ minWidth: 200 }}
      showSearch
      optionFilterProp="label"
    />
  );
}
```

### 与外层联动

`WorkbenchFilterBar`（T05）通过 `onAvailabilityChange` 得知是否展示业务域那一格。同时 `DomainMatrix`（F4/T03）也需要这个可用性状态——从父层透传 `bizDomainAvailable: boolean` 即可。

### 埋点

- 加载失败 → `WORKBENCH_DOMAIN_API_FAIL`
- 加载成功但空 → `WORKBENCH_DOMAIN_API_EMPTY`
- 选择变更 → 由 `WorkbenchFilterBar` 统一打 `WORKBENCH_FILTER_CHANGE`（本 task 不打）
