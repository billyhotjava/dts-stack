# T05：实现结果回看、导航与失败重试

**优先级**: P0  
**状态**: READY  
**依赖**: F3/T04、T04

## 目标

提供可恢复的批次结果页和明确下一步，不用 toast 代替导入结果。

## 技术设计

- 展示 CREATED/UPDATED/REPLAYED/SKIPPED/FAILED 与逐项 issue。
- 成功项链接到 ModelSpec 详情；批次可返回当前计划/模型中心。
- 失败项支持仅重试，成功项不可重复选择。
- 页面刷新、深链和权限恢复后按 runId 读取服务端真值。

## 影响范围

- ImportResultStep 与 run detail route/state。
- 模型中心列表刷新和导航。

## 验证

- [ ] 部分失败结果可解释。
- [ ] retry 不重复成功项。
- [ ] 无权限、run 过期和结果加载失败有恢复动作。
- [ ] Chrome 95 与窄屏可用。

## 完成标准

- [ ] 每个已生成模型可从结果页直接打开。
- [ ] 结果与后端审计/数据库一致。
