# T03：实现上传与上下文映射步骤

**优先级**: P0  
**状态**: IN_PROGRESS
**依赖**: T01、T02

## 目标

完成向导前两步，让用户先看懂包，再明确业务分类和来源映射。

## 技术设计

- 上传只接受 dbt ZIP；客户端校验扩展名/size，服务端校验 archive 并自动生成内部模型包。
- 展示 ZIP 文件名、project、模型数和技术节点数；schemaVersion/checksum 仅放在技术详情。
- artifact ZIP 与现有 `models.tsv + SQL` ZIP 使用同一入口；缺少业务语义的候选由预检明确阻断。
- 计划锁定；domain/source 使用业务名称和 relation 映射，不展示 UUID。
- 缺失来源提供安全跳转，返回后恢复文件、映射和当前步骤。

## 影响范围

- 共享 ImportModelPackageWizard。
- upload/context mapping state 与 API client。

## 验证

- [ ] 错文件不进入下一步。

- [ ] 刷新/关闭后可通过 runId 恢复非敏感状态。
- [ ] 来源修复返回不清空用户选择。

## 完成标准

- [ ] 页面不要求用户复制 checksum、uniqueId 或 bindingId。
- [ ] 映射完成前不能执行 preview。
