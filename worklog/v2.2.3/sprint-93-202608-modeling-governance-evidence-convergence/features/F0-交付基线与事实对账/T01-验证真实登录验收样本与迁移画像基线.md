# T01：验证真实登录、验收样本与迁移画像基线

**优先级**：P0
**状态**：IN_PROGRESS
**依赖**：无

## 目标

把 `it/baseline.md` 的 P2～P8 GAP 转成可执行结论，并提供 F1～F6 唯一复用的样本和数据画像。

## 技术设计（Contract-first）

- **输入契约**：运行环境、xiezm 账号、当前数据库、`E2E_GOV_202608_*` 隔离前缀、只读统计 SQL、存量迁移 preview。
- **输出契约**：更新后的 `it/baseline.md`、`assets/domain-profile.md`；样本清单 `{modelSpecId,candidateId,datasetId,assetKey,qualityRuleVersionIds,bindingIds,runIds,manifestRef}`。
- **数据流**：真实登录 → 受保护 API → 只读 DB 对账 → migration preview → 建立隔离模型/质量/血缘样本 → 记录 ID 和清理边界。
- **错误路径**：登录/DNS/权限失败记 BLOCKED；preview 有歧义只记录 issue；字段 manifest 无法导入时保留 skip reason；不得用 fixture 代替真实证据。
- **复用点**：README 账本 L16～L22、Sprint-89/90 的 baseline 与现有测试账号。
- **实现范围**：只做探针、测试样本和文档更新；不改生产代码，不执行存量 apply。

## UI 交互规格

1. xiezm 登录平台。
2. 从真实菜单逐页访问模型、资产、元数据、血缘和质量。
3. 记录路由、HTTP、console、Network 和页面四态。
4. 使用 Chrome 95 重复最小 smoke；失败则保留 F5/F6 BLOCKED。

## 影响范围

`it/baseline.md`、`assets/domain-profile.md`、运行环境隔离测试数据；不修改现有业务数据。
