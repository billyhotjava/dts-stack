# T03：执行六道准入评分与跨库去重

**优先级**：P0  
**状态**：READY  
**依赖**：T02

## 目标

对 PJM 候选执行通用性、血缘、重复、命名、质量和客户适用性门禁，产出可审计结论。

## 技术设计

- 治理状态 DRAFT 或关键测试 warn 只能得到 CONDITIONAL/REJECT。
- 按稳定英文名+域、中文同义词、定义相似度、码表码值集合与 DTS 现有基线去重。
- 检测有损 many-to-one、上下文丢失、业务状态压缩为布尔等规则。
- 输出 ACCEPT/CONDITIONAL/REJECT、理由、目标包和所需修复。
- 人工批准必须保存审阅人、时间和版本，不能直接修改扫描结果。

## 影响范围

- 候选准入报告
- DTS 现有标准内容清单
- 内容 CI/审批记录

## 验证

- [ ] `dim_boolean_alias` 与有损风险分类映射被拒绝。
- [ ] 风险等级等 Canonical dim 仅进入项目管理候选。
- [ ] 项目号、金额等字段经过类型/定义/重复复核。

## 完成标准

- [ ] 未通过任一 Gate 的记录不会生成发布 CSV。
- [ ] 同一输入重复评估结果稳定。
