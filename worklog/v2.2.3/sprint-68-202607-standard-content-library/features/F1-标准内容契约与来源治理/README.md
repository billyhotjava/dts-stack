# F1：标准内容契约与来源治理

**优先级**：P0  
**状态**：READY

## 目标

冻结可独立发布的标准内容包和记录级溯源契约，确保每条内容回答“来自哪里、哪个版本、能否再分发、由哪个包管理”。

## 完成标准

- [ ] 现有五 CSV、安装、重复安装、回滚和强制 ACTIVE 等风险均有证据矩阵。
- [ ] manifest v2、稳定记录键、来源登记、许可证、依赖和 checksum 契约可自动校验。
