# T01：建立内容目录、画像与依赖解析 API

**优先级**：P0  
**状态**：READY  
**依赖**：F2-T03、F4-T05

## 目标

向实施人员提供统一内容目录、画像解析、安装状态、可升级版本和影响预览 API。

## 技术设计

- 列表返回包分类、版本、来源、许可结论、依赖、条目数、已安装版本和可升级状态。
- 画像解析返回依赖闭包、拓扑顺序、缺失/冲突和预计 diff。
- 安装、升级、回滚使用统一 run，区分 operation type。
- 远程目录不可用时使用离线目录，并标记目录来源。
- API 分页、过滤、错误码和权限与现有标准包接口兼容收敛。

## 影响范围

- StandardPackageResource/service/DTO
- 内容目录加载器
- platformApi
- 审计动作

## 验证

- [ ] 单包、画像、已安装、可升级列表契约。
- [ ] 依赖缺失/冲突/循环和离线回退。
- [ ] 无权限写请求由后端拒绝。

## 完成标准

- [ ] 页面不需要自行计算依赖和版本状态。
- [ ] 离线/远程目录行为可观测且确定。
