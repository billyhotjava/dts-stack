# T02：制作通用公共码表基础包

**优先级**：P0  
**状态**：READY  
**依赖**：T01

## 目标

按首批目录制作自然人、机构、区划、国际、行业经济和治理等高价值公共码表包。

## 技术设计

- 优先扩充当前性别、学历和省级区划包，但不手工臆造码值。
- 每张码表保存标准号/版本、父子关系、有效状态和来源登记。
- 行政区划默认到县级；国家地区、币种、语种、行业分类按独立包管理。
- DTS 自有枚举与外部标准码表分包，避免来源混淆。
- 码值删除改为弃用/替代，保持历史引用。

## 影响范围

- 内容仓库公共码表 CSV
- 来源登记和许可报告
- 码表 preview/apply/reference tests

## 验证

- [ ] 包内/跨包 code_type 和 parent_code 引用完整。
- [ ] 与现有 3 张内置码表升级兼容。
- [ ] 码值数量、来源版本、重复和弃用报告可审计。

## 完成标准

- [ ] 通用企业版获得高频码表覆盖。
- [ ] 无未经授权全文、乡村统计代码和手工猜测码值。
