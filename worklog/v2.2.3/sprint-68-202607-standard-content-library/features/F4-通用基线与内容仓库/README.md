# F4：通用基线与内容仓库

**优先级**：P0  
**状态**：READY

## 目标

把标准内容从应用 classpath 提升为可独立构建、签名、离线交付的内容仓库，并形成首批 10～12 个高价值基线包。

## 完成标准

- [ ] 内容仓库可重复构建签名 ZIP，不依赖运行环境生成。
- [ ] 首批基线包均有来源、许可、版本、依赖、checksum 和条目报告。
- [ ] 计量单位使用 `base_unit_code` 解析，跨量纲和循环引用被阻断。
- [ ] 参考术语不被强制 ACTIVE，通用数据元不伪填客户来源系统/责任部门。
- [ ] 通用企业版、最小治理版和项目管理版组合可确定性解析。
