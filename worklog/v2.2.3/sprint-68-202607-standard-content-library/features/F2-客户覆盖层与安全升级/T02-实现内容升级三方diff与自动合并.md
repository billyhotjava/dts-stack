# T02：实现内容升级三方 diff 与自动合并

**优先级**：P0  
**状态**：READY  
**依赖**：T01

## 目标

在 apply 前比较旧基线、新基线和客户生效值，自动处理无冲突变化并识别同字段冲突。

## 技术设计

- diff 分类：新增、上游更新、本地保留、可自动合并、冲突、弃用、替代。
- 以规范化字段值和基线 checksum 比较，忽略纯格式噪声。
- preview 保存确定性 diff 和待确认冲突，apply 只消费同一 snapshot。
- apply 前用 ETag/CAS 复验包版本和本地 override 未漂移。
- 相同输入重复 preview 产生等价结果。

## 影响范围

- 标准包 preview/apply
- 包 run/payload/diff DTO
- 冲突处理 API
- 前端预检报告

## 验证

- [ ] 覆盖三方比较全部分支。
- [ ] 不重叠字段自动合并，同字段冲突阻断。
- [ ] preview 后本地被修改时 apply 返回稳定 409。

## 完成标准

- [ ] 自动更新有明确规则，不依赖“整条记录覆盖”。
- [ ] 冲突报告能定位实体、字段、旧基线、新基线和本地值。
