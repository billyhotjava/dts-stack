# T03: 观测面板与告警规则

**优先级**: P1
**状态**: DRAFT
**依赖**: F4/T05

## 目标

为 API 接入提供面向数据开发和运维的观测视图，及时发现鉴权、限流、schema drift 和数据量异常。

## 范围

- 指标：成功率、失败率、请求耗时、记录量、重试次数、限流等待、checkpoint 延迟。
- 告警：连续 AUTH 失败、429 激增、schema drift、记录量突降、任务超时。
- 页面入口：任务详情、运行概览、日志抽屉。

## 完成标准

- [ ] 关键指标可按任务和数据源查看。
- [ ] 告警规则有默认阈值和关闭入口。
- [ ] 失败分类能聚合展示。
- [ ] 观测数据不包含敏感请求内容。
