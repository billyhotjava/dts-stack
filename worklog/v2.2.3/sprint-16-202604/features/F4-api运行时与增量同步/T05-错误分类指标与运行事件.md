# T05: 错误分类、指标与运行事件

**优先级**: P0
**状态**: DRAFT
**依赖**: T02, T03, T04

## 目标

建立 API 接入专用错误分类和运行指标，使问题能被运维快速定位。

## 范围

- 错误分类：AUTH、HTTP_4XX、HTTP_5XX、RATE_LIMIT、TIMEOUT、PARSE、PAGINATION、SCHEMA_DRIFT、ODS_WRITE。
- 指标：请求数、成功数、失败数、重试数、记录数、字节数、耗时、限流等待、checkpoint。
- 事件：preview、run start、page fetched、batch written、checkpoint updated、run failed。

## 完成标准

- [ ] 错误分类进入 execution history。
- [ ] 运行指标可被前端和运维接口查询。
- [ ] 日志不包含敏感 header、query secret 或响应敏感字段。
- [ ] 失败事件有可操作诊断。
