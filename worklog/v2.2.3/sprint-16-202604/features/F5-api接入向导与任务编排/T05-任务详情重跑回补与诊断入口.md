# T05: 任务详情、重跑、回补与诊断入口

**优先级**: P1
**状态**: DRAFT
**依赖**: F4/T04, F4/T05

## 目标

让 API 任务上线后具备可运维性，包括错误诊断、重跑、checkpoint reset 和时间回补。

## 范围

- 展示 HTTP 状态分布、请求数、记录数、重试、限流、checkpoint。
- 支持 retry last failed、full rerun、reset checkpoint、backfill window。
- 展示 schema drift 报告和用户处理入口。
- 链接到运行日志、ODS 表、dbt 任务和质量报告。

## 完成标准

- [ ] 失败任务能看出失败分类和建议动作。
- [ ] checkpoint 操作有权限和二次确认。
- [ ] 回补不会默认覆盖当前水位。
- [ ] 诊断页面不展示敏感请求信息。
