# T02: Provider 驱动的鉴权配置表单

**优先级**: P1
**状态**: DRAFT
**依赖**: F1/T02, F2/T04

## 目标

用后端 provider metadata 渲染鉴权配置，支持客户鉴权机制后续变化。

## 范围

- 根据 provider 显示非敏感字段和敏感字段输入。
- 敏感字段保存后只展示 masked display。
- 支持测试连接和更新 secret。
- 表单校验由 metadata 和前端基础规则共同完成。

## 完成标准

- [ ] 新 provider 不需要重写整页表单。
- [ ] secret 输入不会被前端状态长期保留或回显。
- [ ] 保存和测试连接反馈清晰。
- [ ] 权限不足用户不能查看或修改密钥。
