# F1: 角色成员用户查询契约

**优先级**: P0
**状态**: DONE

## 目标

新增或扩展后端分页查询契约，让角色编辑页可以按部门、姓名、用户名查询用户，并直接知道每个用户是否已经属于当前角色。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | 后端查询契约与测试 | P0 | DONE | - |
| T02 | 前端 API 类型与客户端封装 | P0 | DONE | T01 |
| T03 | 大数据量分页与角色状态一致性复核 | P0 | DONE | T01, T02 |

## 完成标准

- [x] 查询支持 `page`、`size`、`username`、`fullName`、`deptPath`。
- [x] 返回字段包含用户基础信息、部门信息和 `inRole`。
- [x] 查询结果不需要前端调用 `getAllAdminUsers()` 才能计算角色勾选状态。
- [x] 已在角色内、待新增、待移除的三类状态可以在前端稳定合成。
