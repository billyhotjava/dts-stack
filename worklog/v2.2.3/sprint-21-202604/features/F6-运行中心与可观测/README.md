# F6: 接入任务运行中心与可观测

**优先级**: P1
**状态**: IN_PROGRESS

## 目标

建设 DTS 自己的接入任务运行中心，让业务用户不依赖 Airflow UI 即可查看运行状态、日志、行数、错误摘要、重跑和血缘影响。
