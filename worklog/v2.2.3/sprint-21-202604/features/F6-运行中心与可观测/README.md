# F6: 接入任务运行中心与可观测

**优先级**: P1
**状态**: DONE

## 目标

建设 DTS 自己的接入任务运行中心，让业务用户不依赖 Airflow UI 即可查看运行状态、日志、行数、错误摘要、重跑和血缘影响。

## 完成标准

- [x] Run Center 展示任务名、数据源、目标表、状态、最近运行、耗时、行数。
- [x] 支持查看 Airflow/Addax 日志。
- [x] 失败有错误分类和建议。
- [x] 支持重跑、失败重试、按时间范围补数。
- [x] 支持跳转 Sprint-20 血缘影响分析。

## 当前落地

- 复用现有入湖任务中心作为 DTS Run Center，顶部展示 7 日执行、失败/运行中、调度状态和治理阻塞。
- 任务列表增加目标表、最近执行读写行数、耗时、错误分类和修复建议。
- 增加日志入口，读取最新 execution 的聚合日志并展示失败分类/建议。
- 增加血缘入口，可跳转 Sprint-20 lineage graph。
- 任务列表已提升最新失败执行的“失败重试”和最新终态执行的“整批重跑”入口，提交后复用异步执行进度弹窗轮询最新执行。
- 新增 `POST /api/ingestion/tasks/{id}/backfill`，支持按 `windowStart/windowEnd/column` 提交时间范围补数；执行记录写入 `BACKFILL_RANGE`、窗口字段和审计动作，Addax 运行时按表注入补数 where。
- 补数执行成功不会推进主增量 watermark，避免历史修复污染后续正常增量 checkpoint。
- Run Center 历史页新增“窗口回填”弹窗，支持选择回填窗口和可选增量列；执行记录展示回填窗口、回填列和“不推进检查点”标识。
- 任务列表对增量任务增加“回填”入口，进入执行历史页后可直接提交窗口回填，并继续查看 watermark 审计明细。
