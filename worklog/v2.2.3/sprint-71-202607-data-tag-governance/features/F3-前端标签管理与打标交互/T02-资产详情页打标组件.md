# T02: 资产详情页打标组件

**优先级**: P1
**状态**: READY
**依赖**: F2/T02

## 目标

在资产详情页提供打标交互，使用户可直接为资产添加/移除标签。

## 技术设计

新增可复用组件 `components/catalog/AssetTagPanel.tsx`，接收 `assetType` + `assetKey`，
内部完成标签查询、添加、移除，供多个详情页复用。

### 接入页面

- `pages/catalog/AssetDetailPage.tsx`（896 行，已有 source-contract 测试）
- `pages/catalog/DatasetDetailPage.tsx`（已有 `DatasetDetailPage.source-contract.test.ts`）

两页均已较大，组件须独立成文件，**不要在详情页内联展开**，避免文件继续膨胀（项目约定单文件 ≤800 行）。

### 交互

- 已打标签以 chip 形式展示，带分类色值，hover 显示分类名
- 「添加标签」下拉支持按分类分组 + 关键字搜索，仅列出 `enabled=true` 标签
- 移除标签需即时反馈，失败时回滚 UI 并提示（乐观更新 + 失败回滚）
- 无标签时展示引导态，而非空白

### 与密级标记区分

页面上已有 `ClassificationTag.tsx` 密级标记。数据标签 chip 在视觉上必须与密级标记明确区分
（不同形状/位置/色系），避免用户误将业务标签当作密级标识。这是合规相关的界面要求，不是纯美化。
