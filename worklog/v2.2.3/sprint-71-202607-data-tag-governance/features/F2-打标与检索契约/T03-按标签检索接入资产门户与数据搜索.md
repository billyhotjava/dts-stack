# T03: 按标签检索接入资产门户与数据搜索

**优先级**: P1
**状态**: READY
**依赖**: T02

## 目标

让资产门户与数据搜索支持按标签精确筛选，替代当前对自由文本 `tags` 字段的 `like` 模糊匹配。

## 技术设计

### 现状问题

`CatalogAssetPortalService:465` 当前对 `CatalogDataset.tags` 自由文本做 `like` 查询。
该方式无法区分「财务」与「非财务」这类子串包含关系，且无法跨资产类型检索。

### 改造

在 `CatalogAssetPortalService` 增加按标签过滤能力：

- 新增查询参数 `tagIds`（多值，多标签间语义为 **AND**，即同时具备全部所选标签）
- 通过 `catalog_asset_tag` 结构化 join 过滤，走 `idx_catalog_asset_tag_tag` 索引
- 保留既有 `tags` 自由文本 `like` 查询作为兼容路径，两者可并存（F4 迁移完成后再评估下线）

### 多标签语义

明确采用 **AND**（交集）语义：选中「财务」+「日更」返回同时具备两个标签的资产。
若后续需要 OR，另行扩展参数，不在本 task 隐式支持。

### 结果增强

资产列表响应中附带每个资产已打的标签列表，避免前端 N+1 请求。
须批量查询（一次 `in` 查询取回当页全部资产的标签），不可逐条查。

## 影响范围

- 修改 `.../service/catalog/CatalogAssetPortalService.java`
- 修改资产门户/数据搜索相关 REST 契约与 DTO
- 依赖 T02 的关联表与索引
