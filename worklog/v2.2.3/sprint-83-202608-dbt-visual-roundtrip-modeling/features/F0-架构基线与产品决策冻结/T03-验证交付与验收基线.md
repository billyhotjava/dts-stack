# T03：验证交付与验收基线

**优先级**：P0  
**状态**：DONE（83a PASS_WITH_GAPS）
**依赖**：T02

## 目标

在编码前按当前待拉取切片证明目标环境具备登录、API、PostgreSQL、Airflow control-plane 和 Chrome95 的可验收性；真实 dbt materialization 独立归 P8B/F0/T05，只阻断 S3。失败项转为明确阻断任务。

## Contract-first

- **输入**：`it/baseline.md` P1～P8B，以及当前切片实际消费的工程 fixture。
- **输出**：每个探针的命令、退出码、端点/页面、时间与证据路径。
- **失败路径**：当前切片所需的登录、schema、API、Airflow control-plane 或浏览器关键路径失败时，仅受影响切片保持 DRAFT/BLOCKED；P4B/P8B 后续 GAP 不反向阻断 83a。不把环境修复混入业务 Task。
- **边界**：只验证可验收性，不提前运行 Sprint 最终 E2E。

## Definition of Done

- [x] 当前待拉取切片所需探针为 PASS/PASS_WITH_GAPS；真实登录/上传/浏览器旅程按用户约束归最终 E2E，未冒充已验收。
- [x] P4B/P8B 保持具名 GAP/BLOCKED，均有 owner、适用切片和解除条件；最终证据目录固定为本 Sprint `it/`。
