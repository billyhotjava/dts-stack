# T03：验证交付与验收基线

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T02

## 目标

在编码前证明目标环境能完成登录、API、PostgreSQL、Airflow/dbt 和 Chrome95 验收；失败项转为明确阻断任务。

## Contract-first

- **输入**：`it/baseline.md` P1～P8、FX-01 artifact-rich。
- **输出**：每个探针的命令、退出码、端点/页面、时间与证据路径。
- **失败路径**：登录、schema、API、dbt/Airflow 或浏览器任一关键路径失败，受影响 Feature 保持 DRAFT/BLOCKED；不把环境修复混入业务 Task。
- **边界**：只验证可验收性，不提前运行 Sprint 最终 E2E。

## Definition of Done

- [ ] P1～P8 为 PASS/PASS_WITH_GAPS，所有 GAP 有归属。
- [ ] 最终验收账户、数据源、target 和证据目录冻结。
