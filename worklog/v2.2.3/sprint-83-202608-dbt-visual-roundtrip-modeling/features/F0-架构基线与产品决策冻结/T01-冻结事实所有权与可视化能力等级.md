# T01：冻结事实所有权与可视化能力等级

**优先级**：P0  
**状态**：DRAFT  
**依赖**：无

## 目标

由产品与架构共同确认 ModelSpec、dbt source、manifest/catalog 和 relation observation 的字段级所有权，以及 `FULL_EDITABLE/STRUCTURE_VIEW_ONLY/BLOCKED` 的准确含义。

## Contract-first

- **输入**：Sprint README ADR-83-01～03、decision D01～D03/D10～D11、账本 CL-01～CL-18。
- **输出**：被确认的 ownership matrix、capability enum/reason code 清单、允许编辑矩阵。
- **错误路径**：任一字段出现两个写 owner、任一 BLOCKED 情况会被 UI 猜测为成功时，评审不通过。
- **复用点**：现有 `DESIGNER_GENERATED/DBT_MANAGED`；不得新建 SQL model owner。

## 验证

- [ ] 对简单 SQL、动态 Jinja、source-only、artifact-rich 各走查一次所有权。
- [ ] 每个视图字段能追溯到 DECLARED/COMPILED/OBSERVED 来源。

## Definition of Done

- [ ] D01、D02、D10、D11 有明确结论。
- [ ] ADR 与 Feature 契约同步更新，无相互矛盾表述。
