# T01：冻结事实所有权与可视化能力等级

**优先级**：P0  
**状态**：DONE
**依赖**：无

## 目标

由产品与架构共同确认 ModelSpec、dbt source、manifest/catalog 和 relation observation 的字段级所有权，以及 `BUSINESS_VISUAL_EDIT/BUSINESS_VISUAL_READ/ADVANCED_DBT_IMPLEMENTATION/BLOCKED` 的准确含义。

## Contract-first

- **输入**：Sprint README ADR-83-01～03、ADR-83-15～16、decision D01～D03/D10～D11、账本 CL-01～CL-24。
- **输出**：被确认的 ownership matrix、capability enum/reason code 清单、允许编辑矩阵。
- **错误路径**：任一字段出现两个写 owner、任一 BLOCKED 情况会被 UI 猜测为成功时，评审不通过。
- **复用点**：现有 `DESIGNER_GENERATED/DBT_MANAGED`；不得新建 SQL model owner。

## 验证

- [x] 对简单 SQL、动态 Jinja、source-only、artifact-rich 各走查一次所有权；外部输入 ownership 始终为 `DBT_MANAGED`，可视化能力不反推 ownership。
- [x] 每个视图字段能追溯到 DECLARED/COMPILED/OBSERVED 来源；物理字段只来自 relation observation。

## Definition of Done

- [x] D01、D02 有明确结论。
- [x] D10、D11 已于 2026-08-02 确认；source-only 成功项固定 `DBT_MANAGED`，所有权转换延期。
- [x] ADR 与 Feature 契约同步更新，三轮独立架构/逆向/验收复核均为 PASS。
