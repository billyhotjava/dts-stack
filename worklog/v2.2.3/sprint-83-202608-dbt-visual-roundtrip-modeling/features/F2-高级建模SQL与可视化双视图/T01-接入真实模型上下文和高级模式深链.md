# T01：接入真实模型上下文和高级模式深链

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F1/T01

## 目标

把高级建模落入现有模型工作台，并以 URL 和上下文栏固定 model/implementation revision，而不是恢复旧模型列表。

## Contract-first

- **UI 入口**：模型行“高级模式”；深链 `/data-modeling/dimensions/workbench?modelSpecId={uuid}&mode=advanced&modelRevision={int}&implementationRevision={int}`。
- **读取**：`GET .../representations`；路由参数缺失时只选择服务端返回的 current head，并立即写回 URL。
- **错误路径**：404、403、revision conflict、无实施版本分别显示具名恢复动作，不降级到静态样例。
- **兼容**：`/studio/sql-modeling` 只重定向新深链/工作台，不恢复旧页面。

## 验证

- [ ] URL 刷新/复制后显示相同 checksum。
- [ ] 无权限、历史 revision、无实施版本四态 UI 测试。

## Definition of Done

- [ ] 一个模型列表、一个 selection context、一个发布状态源。
