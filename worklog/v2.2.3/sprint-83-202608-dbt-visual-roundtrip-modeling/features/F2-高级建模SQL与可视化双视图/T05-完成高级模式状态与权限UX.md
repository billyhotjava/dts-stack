# T05：完成高级模式状态、冲突与权限 UX

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T01～T04

## 目标

让用户能理解未保存、校验中、解析阻断、版本冲突、未物化、无权限和历史只读状态，并执行明确恢复动作。

## UI 交互规格

- **脏状态**：离开页面前确认；保存草稿不等于提交实施版本。
- **冲突**：显示 base/current checksum 和“重新载入/另存草稿”，禁止覆盖按钮。
- **BLOCKED**：展示 reasonCode、字段/文件位置、恢复建议和跳转 SQL。
- **未物化**：运行结果页显示“尚无物理证据”，提供受权限控制的候选工作台入口。
- **历史**：revision-pinned URL 全部只读，可复制和比较。
- **权限**：read/write 分开禁用并说明，不隐藏错误；本 Sprint 不渲染 ZIP 导出或所有权转换操作。
