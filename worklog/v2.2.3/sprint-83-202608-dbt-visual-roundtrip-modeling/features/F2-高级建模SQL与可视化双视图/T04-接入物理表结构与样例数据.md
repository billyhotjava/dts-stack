# T04：接入候选固定的物理表结构与样例数据

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F4/T02～T03、T01

## 目标

在运行结果视图中展示与指定 candidate/relation evidence 绑定的真实字段和有限样例数据，而不是读取共享 manifest 当前关系。

## Contract-first

- **输入**：modelSpecId、implementationRevision、candidateId、limit(1..500)。
- **输出**：relationRef、candidate/version/attempt、observedAt、columns、maskedRows、maskingSummary、drift。
- **错误路径**：未物化/失败/stale 409；relation 不存在 404；越权 403；密级或脱敏策略不可用 423/业务 BLOCKED；limit 超限 400。
- **查询**：relation identifier 必须来自服务端证据并安全引用；禁止客户端传任意 schema/table。

## 验证

- [ ] 500/501 边界、SQL 注入 identifier、跨租户、列脱敏测试。
- [ ] stale candidate 无法预览为成功。

## Definition of Done

- [ ] 页面将物理观测与逻辑/编译结构并列显示，不覆盖设计事实。
