# T04：实现可视化能力与三方漂移状态机

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T03

## 目标

基于 base/current/incoming checksum 与 ModelSpec/Implementation ETag，稳定输出 capability 和 drift，禁止双边变化时自动覆盖。

## Contract-first

- **输入**：base import snapshot、current ModelSpec/Implementation、incoming package/model。
- **输出**：`NO_CHANGE|EXTERNAL_ONLY|INTERNAL_ONLY|CONFLICT|STALE_RUNTIME`；action=`SKIP|UPDATE|CONFLICT|BLOCKED`；recoveryAction。
- **错误路径**：缺 base、身份碰撞、uniqueId 重命名/删除、动态依赖、发布中 revision 变更均 fail-closed。
- **并发**：ETag/CAS 单 winner；重复相同 checksum 为幂等 SKIP。
