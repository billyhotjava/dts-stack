# T05：实现技术三方漂移与语义映射状态机

**优先级**：P1  
**状态**：DRAFT  
**依赖**：T03、F3/T04

## 目标

基于 accepted base、current Implementation 和 incoming 技术 checksum 稳定输出 technical drift；ModelSpec revision/ETag 独立输出 semantic mapping 状态。禁止竞争性技术双边变化时自动覆盖，也禁止把正常业务语义修改误判为技术冲突。

## Contract-first

- **输入**：accepted merge checkpoint、current Implementation、current ModelSpec revision/ETag、incoming package/model。
- **输出**：`technicalDrift=NO_CHANGE|EXTERNAL_ONLY|INTERNAL_TECHNICAL_ONLY|CONVERGED|CONFLICT`，`semanticMappingStatus=VALID|STALE|BLOCKED_REMAP`，运行观测漂移独立为 `STALE_RUNTIME`；action=`SKIP|UPDATE|CONFLICT|BLOCKED`；稳定 reasonCode/recoveryAction。
- **错误路径**：缺 base、身份碰撞、uniqueId 重命名/删除、动态依赖、业务映射失效、发布中 revision 变更均 fail-closed。
- **并发**：ETag/CAS 单 winner；重复相同 checksum 为幂等 SKIP。

## 验证

- [ ] 三方差异参数化契约测试。
- [ ] ModelSpec 仅业务语义变化时不会产生技术 CONFLICT；映射仍有效则保留，映射失效则 BLOCKED_REMAP。
- [ ] 并发更新与重放 IT。
- [ ] BLOCKED 不产生 proposed editable graph。

## Definition of Done

- [ ] F2/F3 共用同一 drift/reason code，不在前端重复判断。
