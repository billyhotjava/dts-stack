# T03：回写运行、结构、血缘、质量与 Catalog 证据

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T02

## 目标

物化成功后，把固定运行产生的 manifest/catalog/relation/lineage/quality 证据投影到表示读模型和 Catalog，而不覆盖逻辑设计。

## Contract-first

- **输入**：candidate/version/attempt、artifact refs、relation evidence、quality evidence、source pins。
- **输出**：runtimeObservation、CatalogAssetKey、physicalAssetRef、lineage refs、evidence checksum。
- **错误路径**：relation 不存在、字段漂移、质量未通过、catalog sync 失败按既有发布策略处理；build-only 不能冒充可消费资产。
- **事务**：接受回执与状态 CAS、source pin 复核、relation evidence、audit 同事务；外部 Catalog sync 在事务外可重试。

## 验证

- [ ] declared/compiled/observed 字段差异可见。
- [ ] Catalog identity/quality binding 使用同一 asset key。

## Definition of Done

- [ ] 运行证据可由 F2/T04 安全预览和追溯。
