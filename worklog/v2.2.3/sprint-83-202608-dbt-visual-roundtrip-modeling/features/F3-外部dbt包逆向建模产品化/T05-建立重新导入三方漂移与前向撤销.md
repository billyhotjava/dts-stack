# T05：建立重新导入、三方漂移与前向撤销

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T04、D05/D07

## 目标

同一外部项目再次导入时，基于 base/current/incoming 判定 SKIP/UPDATE/CONFLICT，并用前向修订纠正已应用结果，不删除历史。

## Contract-first

- **稳定身份**：tenant + projectKey + dbtUniqueId；重命名必须作为显式 old→new 决策，不能靠名称猜。
- **单边变化**：用户确认后创建新 ModelSpec/Implementation revision。
- **双边变化**：CONFLICT，要求选择保留内部语义、接受外部技术实现或取消。
- **撤销**：记录目标 apply attempt/结果；创建恢复到 base 的前向修订与审计，不物理删除导入历史。
- **错误路径**：发布中/被下游 pin/目标 base 不存在时 BLOCKED，展示影响。
