# T02：建立计划、域、来源映射与语义补全预检

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T01、F1/T03

## 目标

让用户把外部项目绑定到现有 WarehousePlan、数据域和来源资产，并只人工补充无法从 dbt 推断的业务语义。

## Contract-first

- **输入**：package、planId、domainMappings、sourceMappings、selectedUniqueIds。
- **业务补全**：模型类型/分层、业务名称/定义、grain、字段 role/key、标准绑定；禁止按表名自动确认。
- **输出**：复用 preview response；每项包含 proposedModelSpec/proposedImplementation/issues。
- **错误路径**：plan/source/domain 不属于 tenant 403/404；缺业务主键/粒度/来源 422 BLOCKED；映射版本漂移 409。
- **UI**：批量默认值必须逐项可查看；推断值标“建议”，未经确认不得 apply。

## 验证

- [ ] source-only fixture 缺失语义时稳定 BLOCKED。
- [ ] 映射跨租户、已失效来源和版本漂移测试。

## Definition of Done

- [ ] preview 不修改 ModelSpec；用户能解释每个补充值来源。
