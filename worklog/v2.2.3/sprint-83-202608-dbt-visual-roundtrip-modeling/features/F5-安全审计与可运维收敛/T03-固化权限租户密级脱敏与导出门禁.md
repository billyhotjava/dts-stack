# T03：固化权限、租户、密级与脱敏门禁

**优先级**：P0  
**状态**：DRAFT  
**依赖**：当前切片对应的 F2/F3 契约

## 目标

确保 SQL、模型结构和物理数据按服务端身份、租户及现有 read/write 能力 fail-closed；不假设新的细粒度权限模型。

## Contract-first

- **read**：查看 ModelSpec/业务结构；允许的 SQL 仅在显式高级 dbt 实现中展示，普通业务可视化始终隐藏；历史 revision 同样校验。
- **write**：创建草稿、validate、commit、preview/apply/retry；同时沿用现有建模维护者 authority，不新增 action code 权限体系。
- **明确非目标**：ZIP 导出和 ownership conversion 不在 Sprint-83；现有 `export` 能力不扩展也不删除。
- **物理数据入口**：普通可视化只请求 current servingRef；成功未发布 candidate 仅现有建模维护者 authority 可请求并标记非正式；历史 revision 不返回样例行。不新增权限 action。候选预览只派生稳定 CatalogAssetKey，不登记 Catalog。
- **物理数据门禁**：tenant/model read → SERVING 的 Catalog 资产可读或 CANDIDATE 的维护者 authority → 表级 classification 许可 → 按稳定 CatalogAssetKey 解析列 ALLOW/MASK/DENY；DENY 整列移除，UNKNOWN/策略服务不可用阻断整次响应且返回 0 行。
- **数据最小化**：显式加载，默认 100/最大 500；`private, no-store`；样例不进入缓存、持久存储、日志或审计正文。本 Sprint 不增加样例分页、CSV/Excel/ZIP 导出或批量复制。
- **统一契约**：服务端行为和错误码遵循 [`assets/catalog-serving-and-preview-contract.md`](../../assets/catalog-serving-and-preview-contract.md)，普通与高级视图不得各写一套权限/脱敏逻辑。
- **旧 preview 旁路遏制**：S3 DONE 前，`GET /api/etl/dbt/preview` 对普通已认证用户和建模角色必须返回 403/404，或服务端委托到同一 evidence/classification/masking 契约；禁止继续返回 manifest relation 的原始行。物理删除可由 P2/F5-T05 完成，但安全遏制不能延期。

## 验证

- [ ] 双租户、现有角色矩阵、serving/candidate/history、未发布 candidate 不登记 Catalog、表级密级、ALLOW/MASK/DENY/UNKNOWN、策略失败、100/500/501、no-store 和无导出。
- [ ] 所有拒绝/阻断返回 0 行；审计、应用日志和浏览器持久存储中样例值为 0。
- [ ] 直接调用旧 `/api/etl/dbt/preview` 不能绕过 revision/evidence/密级/列策略；普通已认证用户和建模角色得到 403/404 或同一受控结果，原始行泄露为 0。
- [ ] 审计 IP 使用公共解析工具，不复制 header 逻辑。

## Definition of Done

- [ ] 客户端 tenant/project/model 参数不能扩大可见范围；`R-DBT-LEGACY-PREVIEW` 在 S3 GO 前已完成旁路遏制。
