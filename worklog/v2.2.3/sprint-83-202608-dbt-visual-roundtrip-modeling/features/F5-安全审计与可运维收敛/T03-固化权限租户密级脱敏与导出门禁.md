# T03：固化权限、租户、密级与脱敏门禁

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F2/F3 契约

## 目标

确保 SQL、模型结构和物理数据按服务端身份、租户及现有 read/write 能力 fail-closed；不假设新的细粒度权限模型。

## Contract-first

- **read**：查看 ModelSpec/结构/允许的 SQL；历史 revision 同样校验。
- **write**：创建草稿、validate、commit、preview/apply/retry；同时沿用现有建模维护者 authority，不新增 action code 权限体系。
- **明确非目标**：ZIP 导出和 ownership conversion 不在 Sprint-83；现有 `export` 能力不扩展也不删除。
- **物理数据**：CatalogAssetKey → classification/column policy/masking；策略不可用即阻断。

## 验证

- [ ] 双租户、现有角色矩阵、历史 revision、列脱敏、密级失败注入。
- [ ] 审计 IP 使用公共解析工具，不复制 header 逻辑。

## Definition of Done

- [ ] 客户端 tenant/project/model 参数不能扩大可见范围。
