# T02：补齐公共审计、outbox、correlation 与保留策略

**优先级**：P0
**状态**：CODE_COMPLETE
**依赖**：F1/T01

## 目标

对 inspect、preview、apply、retry、forward undo、checkpoint、commit、conflict、Catalog projection 和 physical preview 建立分类正确、脱敏、耐久的中央审计链。

## Contract-first

- **动作字典**：在 dts-admin 登记稳定 actionCode/category/stage；至少包含 `MODELING_DBT_IMPORT_FORWARD_UNDO`、`MODELING_CATALOG_PROJECTION`、`MODELING_PHYSICAL_PREVIEW`，不得伪装成其他动作。
- **payload**：tenant、actor、IP、model/revision、package/artifact checksum、run/attempt、item identity、CatalogAssetKey、candidate/evidence refs、requested/returned row count、column/mask/deny count、result、failureCode/failureStage/failureCategory、retryable、recoveryAction、correlationId。
- **PARTIAL**：公共审计保留 attempt 汇总及 FAILED/BLOCKED 逐项失败分类；状态直接使用服务端持久化结果，PARTIAL 不能归类为 SUCCESS，且 summary 必须满足统一状态代数。
- **禁止字段**：SQL、ZIP 内容、变量值、env、profiles、凭据、relation 连接信息、样例值和原始策略正文。
- **事务**：业务事实与 platform_audit_outbox 同事务；dispatcher 投递 dts-admin，失败重试/DLQ/replay。
- **保留**：import run/artifact/workspace/audit 的时限分别冻结；中央审计不由本 Sprint 删除。

## 验证

- [ ] 每个动作成功/拒绝/部分成功审计；dts-admin 非“未分类”。
- [ ] PARTIAL 的失败码、阶段、类别、恢复动作和 correlationId 可与 UI 明细逐项对应。
- [ ] `MODELING_DBT_IMPORT_FORWARD_UNDO` 覆盖 SUCCESS/PARTIAL/BLOCKED、CREATE 阻断、CAS 冲突、幂等 replay，敏感正文为 0。
- [ ] Catalog PUBLISHED/MATERIALIZED/SYNC_PENDING/FAILED 与 serving CAS 审计可串联；preview serving/candidate/blocked/timeout 均分类正确且样例值为 0。
- [ ] secret-key/value 与 SQL 片段均不出现。

## Definition of Done

- [ ] correlationId 可贯穿 inspect→apply→candidate→materialization。
