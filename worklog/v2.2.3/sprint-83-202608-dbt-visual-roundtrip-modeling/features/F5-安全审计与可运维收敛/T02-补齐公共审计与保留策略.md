# T02：补齐公共审计、outbox、correlation 与保留策略

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F1/T01

## 目标

对 inspect、preview、apply、retry、checkpoint、commit 和 conflict 建立分类正确、脱敏、耐久的中央审计链。

## Contract-first

- **动作字典**：在 dts-admin 登记稳定 actionCode/category/stage。
- **payload**：tenant、actor、IP、model/revision、package/artifact checksum、run/attempt、count、result、errorCode、correlationId。
- **禁止字段**：SQL、ZIP 内容、变量值、env、profiles、凭据、样例数据。
- **事务**：业务事实与 platform_audit_outbox 同事务；dispatcher 投递 dts-admin，失败重试/DLQ/replay。
- **保留**：import run/artifact/workspace/audit 的时限分别冻结；中央审计不由本 Sprint 删除。

## 验证

- [ ] 每个动作成功/拒绝/部分成功审计；dts-admin 非“未分类”。
- [ ] secret-key/value 与 SQL 片段均不出现。

## Definition of Done

- [ ] correlationId 可贯穿 inspect→apply→candidate→materialization。
