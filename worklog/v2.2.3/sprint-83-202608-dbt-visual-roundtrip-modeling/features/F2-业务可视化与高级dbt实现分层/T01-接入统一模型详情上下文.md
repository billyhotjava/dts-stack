# T01：接入统一模型详情上下文

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F1/T01

## 目标

把普通业务可视化和显式高级 dbt 实现落入同一个现有模型详情上下文，以 model/implementation revision 固定事实，同时不恢复旧模型列表或新增入口。

## Contract-first

- **UI 入口**：现有模型行进入模型详情；普通业务可视化默认打开。“数据实现”阶段根据 ownership 与权限显示显式“高级 dbt 实现”，不新增菜单或独立列表。
- **读取**：`GET .../representations`；历史视图固定 model/implementation revision，当前视图只选择服务端返回的 current head。
- **呈现边界**：普通可视化 DTO/组件不得渲染 source SQL、compiled SQL、macro、project path；高级视图与普通视图互斥挂载。
- **错误路径**：404、403、revision conflict、无实施版本分别显示具名恢复动作，不降级到静态样例。
- **兼容**：`/studio/sql-modeling` 只重定向新深链/工作台，不恢复旧页面。

## 验证

- [ ] 历史视图刷新/复制后显示相同 checksum。
- [ ] 无权限、历史 revision、无实施版本四态 UI 测试。
- [ ] 普通可视化 DOM/网络派生展示中不存在 SQL 正文。

## Definition of Done

- [ ] 一个模型列表、一个 selection context、一个发布状态源。
