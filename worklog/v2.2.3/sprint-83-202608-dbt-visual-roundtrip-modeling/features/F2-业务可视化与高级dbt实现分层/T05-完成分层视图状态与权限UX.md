# T05：完成分层视图状态、冲突与权限 UX

**优先级**：P1  
**状态**：DRAFT  
**依赖**：T01～T04

## 目标

让业务用户和技术维护者分别理解未保存、校验中、解析阻断、版本冲突、未物化、无权限和历史只读状态，同时保持普通可视化与高级 dbt 技术信息隔离。

## UI 交互规格

- **脏状态**：离开页面前确认；保存草稿不等于提交实施版本。
- **冲突**：显示 base/current checksum 和“重新载入/另存草稿”，禁止覆盖按钮。
- **BLOCKED**：普通可视化展示业务化 reasonCode 和恢复建议，不含 SQL/文件路径；具备权限的技术维护者可显式进入高级实现查看精确位置。
- **未物化**：运行结果页显示“尚无物理证据”，不显示“加载样例”；提供受权限控制的候选工作台入口。
- **候选预览**：只有成功 candidate 且当前用户为技术维护者时显示，始终带“候选结果，非正式资产”，不得混入普通 serving 结果。
- **历史**：revision-pinned URL 全部只读，可比较固定结构；历史视图始终不显示样例加载按钮，不用当前 relation 数据冒充历史行。
- **权限**：read/write 分开禁用并说明，不隐藏错误；本 Sprint 不渲染 ZIP 导出或所有权转换操作。
- **视图隔离**：普通可视化不因错误详情、diff、tooltip 或 toast 泄露 SQL/dbt 技术正文。
