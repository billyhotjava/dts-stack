# T03：实现发布与专业注册幂等重试

**优先级**：P0
**状态**：READY
**依赖**：T01、T02

## 目标

把发布与 Catalog、BI、Lineage 注册拆成可追踪步骤，支持 PARTIAL 后只重试失败步骤。

## 技术设计

- 发布命令先固化 candidate/version，再按 registration step 执行。
- 每步保存 idempotencyKey、attempt、externalRef、status、errorCode 和时间。
- 已成功步骤重复请求返回原结果；失败步骤可独立重试。
- PUBLISHED 仅在计划要求的步骤全部成功后产生。

## 影响范围

- `ModelLifecyclePublicationService.java`
- registration ports/adapters
- publication repository/contract
- partial/retry integration tests

## 实施步骤

1. 先写第二步失败、重复回调、超时未知和精确重试测试。
2. 实现步骤账本、幂等协调和 PARTIAL 投影。
3. 验证重试不重复创建已成功外部资产。

## 完成标准

- [ ] PARTIAL 的成功与失败步骤均清晰可见。
- [ ] 精确重试可恢复到 PUBLISHED，且所有 attempt 可审计。
- [ ] **UI 契约验收**：发布台账逐项展示 Catalog、BI、Lineage 的状态、attempt 和错误；PARTIAL 页面只对失败步骤提供“重试”。
