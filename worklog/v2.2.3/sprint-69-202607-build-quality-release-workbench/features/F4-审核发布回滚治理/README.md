# F4：审核发布回滚治理

**优先级**：P0
**状态**：READY

## 目标

将审核、批准、发布、专业注册、失败重试和回滚建成显式且可审计的状态迁移，并修正 StageProjection 第六步的完成真值。

## 完成标准

- [ ] 提交、批准、拒绝和发布均为独立命令，提交人不能批准自己的候选。
- [ ] Catalog、BI、Lineage 注册分步保存结果，PARTIAL 可只重试失败步骤。
- [ ] 回滚追加新事件并恢复产品状态，不删除历史证据。
- [ ] StageProjection 第六步只接受符合计划完成策略的真实 PUBLISHED 候选。
