# T03：实现构建质量证据详情

**优先级**：P0
**状态**：READY
**依赖**：T02、F2-T04、F3-T04

## 目标

在工作台中提供逐模型、逐 run、逐 artifact 和逐规则的证据详情与修复入口。

## 技术设计

- 构建区分别展示 artifact 和真实 run，不合并成一个“成功”标签。
- 质量区展示规则、阈值、实际值、严重度、样本摘要、新鲜度和修复建议。
- 失败项可过滤，支持精确重试与携带上下文跳转 SQL/dbt。
- 日志和样本按需加载，默认不拉取大内容。

## 影响范围

- 新增 `delivery/DeliveryEvidencePanel.tsx`
- 新增 `delivery/BuildEvidenceDrawer.tsx`
- 新增 `delivery/QualityEvidenceDrawer.tsx`
- 扩展 API types/hooks 与 component tests

## 实施步骤

1. 先写 artifact 成功/run 失败、质量过期和敏感样本不直出的组件测试。
2. 实现摘要、抽屉、过滤和修复路由。
3. 验证键盘、屏幕阅读器、Chrome 95 和 390px。

## 完成标准

- [ ] 用户不用查后台日志即可定位首个可执行修复点。
- [ ] 大证据按需加载，失败刷新后仍可恢复到同一候选和条目。
- [ ] **UI 实现验收**：构建/质量失败可筛选并逐项展开，键盘能够打开详情与触发修复；日志和样本加载失败有页内重试且不清空当前上下文。
