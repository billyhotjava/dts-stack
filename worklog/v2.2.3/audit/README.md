# DTS v2.2.3 架构审计

本目录记录 DTS 产品架构的分轮只读审计。产品代码、配置、数据库及部署保持不变；仅新增本目录下的报告。

## 审计约束

- 按当前源码、配置和运行快照取证，历史报告及领域技能只作线索。
- 明确区分源码事实、条件性风险、运行证据和待验证项。
- 用户要求：支持中英文，默认中文；中文界面的系统文案仅允许经确认的专业术语使用英文。
- “三元管理”本轮按系统管理员、安全保密／授权管理员、安全审计员三员分立理解；客户正式角色矩阵仍需核对。
- 单代理执行。审计不自动授权修复、构建、数据库操作、发布或运行环境迁移。

## 后续专题顺序

1. 三员管理与内部接口：完整角色—资源—动作矩阵、审批状态机、服务凭据与审计可见范围。
2. 中文默认与双语：有效菜单、登录页、平台／管理端／分析页、组件和错误消息的逐页追踪。
3. 数据主链：接入、建模、发布、治理、指标、BI、数据服务的生命周期和异常恢复。
4. 容量与可运维性：规模依据、资源隔离、并发调度、备份恢复及部署证据一致性。

顺序用于逐步深入同一架构审计，不表示上述专题已经完成。风险编号沿用首轮报告，后续补充证据或调整判断时记录依据。
