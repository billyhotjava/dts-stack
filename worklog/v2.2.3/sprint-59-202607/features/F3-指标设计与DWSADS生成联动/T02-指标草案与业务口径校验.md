# T02: 指标草案与业务口径校验

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

让低代码用户用业务语言定义指标草案，并由平台校验缺失维度、粒度、筛选条件、口径冲突和权限风险。

## 技术设计

- 指标草案字段：
  - 指标名称。
  - 业务解释。
  - 计算对象。
  - 聚合方式。
  - 统计周期。
  - 维度。
  - 筛选范围。
  - 负责人。
- 校验提示使用业务语言：
  - “缺少统计周期”。
  - “金额字段未确认口径”。
  - “该字段包含敏感信息，发布前需要授权”。
- 高级详情中可展示 SQL/dbt 编译信息，但默认折叠。

## 影响范围

- 指标工作台
- 指标管理页面
- 低代码向导
- 语义指标校验接口

## 验证

- [x] 普通指标草案不需要 SQL 输入。
- [x] 缺口提示能阻断 DWS/ADS 生成。
- [x] 现有指标编辑能力不退化。

## 完成标准

- [x] 指标草案能作为 DWS/ADS 候选生成输入。
