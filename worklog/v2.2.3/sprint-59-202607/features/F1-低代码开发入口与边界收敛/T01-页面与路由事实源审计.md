**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

盘点数据开发、工作台、数据接入、资产、指标建模、发布审核和任务运维的现有页面与路由，确认低代码向导应该复用哪些能力、不能复制哪些能力。

## 技术设计

- 从 `portal-menu-seed.json` 确认数据开发菜单现状。
- 从 `static-routes.tsx`、`dynamic-resolver.tsx` 确认可复用路由。
- 从工作台首张报表旅程确认 no-SQL 入口现状。
- 从指标工作台、模型管理、发布审核页面确认上下文承接点。
- 产出页面矩阵，标注“复用、深链、待补 API、禁止复制”四类。
