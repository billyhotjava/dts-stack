# T04: DWS/ADS 候选生成意图表单

**优先级**: P0
**状态**: DONE
**依赖**: T03

## 目标

用业务指标、维度、粒度、筛选条件和消费目标驱动 DWS/ADS 候选生成，而不是让用户手工写 SQL。

## 技术设计

- 表单字段包括：
  - 输出目标：报表、大屏、API、数据产品。
  - 统计对象：业务对象或明细模型。
  - 指标：已有指标或新建草案。
  - 维度：组织、时间、状态、分类等。
  - 粒度：日、月、项目、部门、供应商等。
  - 筛选范围：状态、时间范围、组织范围。
  - 更新频率：手动、每日、每月或跟随源表。
- 生成结果先为候选摘要：
  - DWS 候选用于复用汇总。
  - ADS 候选用于具体报表或服务输出。
- 复杂跨表或高风险口径提示进入高级建模。

## 影响范围

- 低代码向导页面
- 指标设计入口
- 模型管理或发布审核入口

## 验证

- [x] 表单不出现 SQL 编辑器。
- [x] 缺指标、缺维度、缺粒度时不能进入发布。
- [x] 能区分复用汇总模型和面向消费的数据集。

## 完成标准

- [x] DWS/ADS 候选来自业务意图，能进入指标和发布流程。
