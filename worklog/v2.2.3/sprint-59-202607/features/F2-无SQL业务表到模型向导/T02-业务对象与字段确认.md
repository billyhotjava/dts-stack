# T02: 业务对象与字段确认

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

让低代码用户确认业务表代表的业务对象，以及关键字段的业务含义，为后续指标和模型生成提供稳定输入。

## 技术设计

- 字段确认至少覆盖：
  - 字段中文名和业务含义。
  - 主键或唯一标识。
  - 业务时间字段。
  - 金额、数量、状态、组织、人员等常见字段类型。
  - 敏感字段和权限提示。
  - 主题域、负责人、所属部门。
- 可复用资产详情或元数据管理页面作为编辑落点。
- 向导中只呈现确认摘要和缺口，不复制完整资产编辑器。

## 影响范围

- 低代码向导页面
- `catalog` 资产详情或元数据管理入口
- 指标工作台上下文参数

## 验证

- [x] 缺主键、缺时间字段、缺 owner、缺主题域有明确提示。
- [x] 字段确认后能进入指标设计。
- [x] 敏感字段不默认进入报表数据集。

## 完成标准

- [x] 业务对象和字段含义能作为后续指标设计上下文。
