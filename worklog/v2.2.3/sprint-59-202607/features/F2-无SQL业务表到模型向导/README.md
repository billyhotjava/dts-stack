# F2: 无 SQL 业务表到模型向导

**优先级**: P0
**状态**: DONE

## 目标

把“选择业务表、确认字段含义、形成 DWD 草案、生成 DWS/ADS 候选”做成面向不懂 SQL 用户的连续流程，并在需要专业处理时明确交接给数据工程师。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | 数据准备与接入交接 | P0 | DONE | F1-T03 |
| T02 | 业务对象与字段确认 | P0 | DONE | T01 |
| T03 | DWD 草案边界与工程审核 | P0 | DONE | T02 |
| T04 | DWS/ADS 候选生成意图表单 | P0 | DONE | T03 |

## 完成标准

- [x] 用户能从已有数据表或接入需求开始。
- [x] 字段含义、主键、时间字段、敏感字段、负责人和主题域有确认动作。
- [x] DWD 只形成草案或审核事项，不直接让普通用户发布。
- [x] DWS/ADS 候选由指标、维度、粒度和消费目标驱动。
