## 目标

证明本 Sprint 能在真实认证、API、数据库和 Chrome95 环境验收，并把 GitNexus 更新到当前 HEAD。

## 技术设计 (Contract-first)

- **输入契约**: 当前 commit SHA、测试账号、运行环境地址、数据库只读访问、Chrome95 harness。
- **输出契约**: 更新后的 `it/baseline.md`；每个 P1～P8 为 PASS/GAP/BLOCKED，附命令、退出码和摘要。
- **数据流**: 登录 → 受保护页面 → 受保护 GET API → 数据库只读查询 → Chrome95 截图。
- **错误路径**: DNS、证书、账号、权限、迁移、浏览器任一关键链失败，登记 F0 阻断，不进入业务实现。
- **复用点**: 当前容器 healthcheck、现有 Chrome95 smoke 约定、GitNexus `s10-stack` 索引。
- **实现方案**:
  1. `npx gitnexus analyze` 后确认 index 与 HEAD 一致；
  2. 运行 P1～P8；
  3. 记录真实账号角色但不落凭据；
  4. 更新 Gate Registry。
