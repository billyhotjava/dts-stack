# T01: 重构创建向导与默认唯一实现

**优先级**: P0  
**状态**: DRAFT  
**依赖**: F3/T01、F3/T02

## 目标

创建维度表时只收集身份与范围，不要求实现细节；重复建设时返回现有模型而不是笼统错误。

## 技术设计 (Contract-first)

- **输入契约**: `CreateDimensionModelSpecCommand`。
- **输出契约**: 201 ModelSpec view；重复时 409 `DIMENSION_IMPLEMENTATION_ALREADY_EXISTS` + repairRoute。
- **数据流**: 维度目录/模型中心 → create drawer → plan/mart/definition resolver → ModelSpec head/revision。
- **错误路径**: definition 非 CURRENT、plan 未确认 domain/mart、scope 不匹配、并发重复均 fail closed。
- **复用点**: `ModelSpecCreateDrawer`、`ModelSpecApplicationService`、idempotency 和 stage gate。
- **实现方案**: 增加 dataMart/variant；数据库部分唯一索引或事务锁保证并发唯一；create 仍不接受来源/字段。

## UI 交互规格

- 从维度目录进入时预选并锁定 definition revision。
- 默认不显示 variantCode；检测到明确多实现需求后在高级区填写。
- 409 提供“打开已有维度表”主动作。
