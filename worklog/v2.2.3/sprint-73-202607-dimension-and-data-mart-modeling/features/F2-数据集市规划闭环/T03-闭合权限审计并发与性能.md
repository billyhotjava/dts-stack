# T03: 闭合权限、审计、并发与性能

**优先级**: P0  
**状态**: DRAFT  
**依赖**: T01、T02

## 目标

使 DataMart 在真实租户、权限、并发和目标数据量下满足生产门禁。

## 技术设计 (Contract-first)

- **输入契约**: DataMart REST/DB 契约和 NFR budget。
- **输出契约**: 审计动作分类、Security IT、并发 IT、查询计数和 10k/50k 基准结果。
- **数据流**: authenticated actor → visibility filter → service → audit。
- **错误路径**: 跨租户/不可见均 fail closed；下游人员目录超时不拖垮请求池。
- **复用点**: `CATALOG_MAINTAINER_EXPRESSION` 当前 write 粒度、现有 AuditService、tenant provider。
- **实现方案**: 注册审计字典；添加 403/404 区分；运行并发与性能夹具。

## 验证

- [ ] 跨租户不可读写
- [ ] 审计 action 非“未分类”
- [ ] 单页查询数 ≤5
- [ ] 10k/50k 夹具 P95 ≤800ms

## Definition of Done

- [ ] NFR 相关适应度函数全绿
- [ ] 性能测试可重复执行
- [ ] 证据入 `IT-01`
