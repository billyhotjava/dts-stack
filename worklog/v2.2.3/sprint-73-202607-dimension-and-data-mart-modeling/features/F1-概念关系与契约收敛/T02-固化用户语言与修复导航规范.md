# T02: 固化用户语言与修复导航规范

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

让用户在页面上能区分业务分类、数据集市、业务维度、维度表、命名规则、SCD 和保留期，并能从门禁直接到修复位置。

## 技术设计 (Contract-first)

- **输入契约**: `assets/dataworks-reference-review.md` 用户语言表。
- **输出契约**: `canonicalModelingLanguage` 扩展和 source-contract 断言；错误码→route/tab/field 映射。
- **数据流**: 门禁 issue code → `repairRoute` → 指定页面/Tab/字段 focus。
- **错误路径**: 未知 issue code 回模型概览并显示原始 code，不静默跳错页面。
- **复用点**: 现有 `warehousePlanViewModel`、`modelSpecGateGuidance`、canonical 词表。
- **实现方案**: 添加 DATA_MART 但不把“数据域/主题域”恢复成平行实体；增加四类策略解释。

## UI 交互规格

- “数据集市”出现在业务分类页的工作区 Tab 和计划“业务范围”区。
- “去修复”必须定位到 `data-marts/dimension-fields/implementation-policy/source` 对应区。
- Chrome95 下不依赖新语法。
