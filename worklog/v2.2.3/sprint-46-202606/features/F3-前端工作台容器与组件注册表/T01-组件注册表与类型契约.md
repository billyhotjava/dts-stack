# T01: 组件注册表与类型契约

**优先级**: P0  
**状态**: DONE  
**依赖**: F2-T03

## 目标

建立工作台首页组件注册表，所有可选组件必须先注册，再由后端偏好和权限决定是否渲染。

## 技术设计

新增或改造 `WorkbenchComponentDefinition`：

- `key`: 稳定组件 key。
- `title`: 客户可见名称。
- `description`: 抽屉中展示的说明。
- `section`: 首页锚点分组。
- `permissionKeys`: 菜单或能力权限依赖。
- `defaultRoles`: 默认模板角色。
- `render`: 真实 React 组件。
- `emptyState`: 无真实数据时的空态说明。

第一版注册组件必须与 `assets/workbench-ui-control-matrix.md` 保持一致：

- `leader-kpi`
- `top-reports`
- `core-assets`
- `screen-strip`
- `todo`
- `data-sources`
- `golden-chain`
- `governance-blockers`
- `bi-delivery`
- `api-services`
- `ops-health`
