# T03: 旧入口兼容跳转与锚点

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

旧入口不白屏、不 404、不继续形成独立首页，而是跳回唯一工作台并定位到相关组件。

## 技术设计

实现兼容策略：

- `/workbench/data-management` -> `/workbench?section=data-management`
- `/services/consumption` -> `/workbench?section=consumption`
- `/workbench?section=data-management` 渲染首页后滚动或高亮数据管理相关组件。
- 如果目标组件未启用，展示“可在自定义工作台中启用”的提示。

## 影响范围

- `source/dts-platform-webapp/src/routes/sections/dashboard/static-routes.tsx`
- `source/dts-platform-webapp/src/routes/sections/dashboard/dynamic-resolver.tsx`
- `source/dts-platform-webapp/src/pages/workbench/index.tsx`
- Playwright smoke 脚本/记录

- [x] 无数据、组件未启用时显示明确提示。

## 完成标准
