# T02: 菜单与角色默认项收敛

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

菜单层只保留“工作台”和“待办事项”，不再并列显示“数据管理工作台”。

## 技术设计

调整菜单 seed 和角色默认项：

- 保留 `workbench` 顶层入口。
- 保留 `workbench/todo`。
- 将 `workbench/data-management` 菜单项移除或标记隐藏。
- 角色默认菜单不再默认授予 `workbenchDataManagement` 作为独立叶子。
- 保留旧路由兼容，不破坏收藏/旧链接。

## 影响范围

- `source/dts-admin/src/main/resources/config/data/portal-menu-seed.json`
- `source/dts-admin/src/main/resources/config/data/role-menu-defaults.json`
- `source/dts-platform-webapp/src/locales/lang/zh_CN/sys.json`
- 菜单 source-contract 测试
