# F5: 发布治理与验收

**优先级**: P1
**状态**: PLANNED
**目标**: 为 ELT 与指标可视化补齐发布前检查、回归脚本和证据归档，避免只交付页面而没有企业级验收闭环。

## 任务

| Task | 状态 | 内容 |
|------|------|------|
| T01 | PLANNED | 定义 ELT 发布前检查清单：采集成功、dbt 成功、质量通过、血缘可查 |
| T02 | PLANNED | 定义指标发布前检查清单：定义完整、口径完整、运行成功、质量状态可见 |
| T03 | PLANNED | 新增 Sprint-27 smoke 脚本，覆盖 ELT/指标/审计核心路径 |
| T04 | PLANNED | 产出 evidence 目录结构和截图/响应归档规范 |
| T05 | PLANNED | 汇总剩余风险：Kafka 可选接入、审批待定、权限脱敏待定 |

## 验收标准

- 有明确的手工和脚本验收入口。
- evidence 能支撑客户演示和回归。
- 发布治理不阻塞当前功能上线，只作为检查和提示。

## 非目标

- 不引入新的 CI/CD 平台。
- 不强制审批阻断发布。
- 不做跨环境 promotion 自动化。
