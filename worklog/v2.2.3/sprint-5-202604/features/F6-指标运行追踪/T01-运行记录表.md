**优先级**: P1
**状态**: READY
**依赖**: F1/T01

## 目标
记录每次指标计算的运行结果。

## 技术设计

### 表结构
```sql
CREATE TABLE gov_indicator_run (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    indicator_id      UUID NOT NULL REFERENCES gov_indicator_definition(id),
    run_at            TIMESTAMP NOT NULL DEFAULT now(),
    status            VARCHAR(16) NOT NULL,  -- SUCCESS/FAILED/TIMEOUT/STALE
    computed_value    NUMERIC,
    previous_value    NUMERIC,
    change_rate       NUMERIC,               -- (current-previous)/previous
    rows_processed    INTEGER,
    duration_ms       INTEGER,
    threshold_hit     BOOLEAN DEFAULT false,
    alert_level       VARCHAR(8),            -- GREEN/YELLOW/RED
    error_message     TEXT,
    dbt_run_id        VARCHAR(64)            -- 关联 dbt 运行记录
);
CREATE INDEX idx_gir_indicator ON gov_indicator_run(indicator_id);
CREATE INDEX idx_gir_run_at ON gov_indicator_run(run_at);
```
