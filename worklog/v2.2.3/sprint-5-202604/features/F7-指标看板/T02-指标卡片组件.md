# T02: 指标卡片组件

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标
单个指标的可视化卡片：当前值、变化趋势、预警标识。

## 技术设计

### 组件
`source/dts-platform-webapp/src/pages/governance/components/IndicatorCard.tsx`

### 卡片布局
```
┌─────────────────────────────┐
│ 项目经费执行率          🟢  │  ← 名称 + 预警灯
│                             │
│      85.3%                  │  ← 当前值（大字）
│      ↑ 3.9% vs 上期        │  ← 变化率 + 方向箭头
│                             │
│  ▁▂▃▄▅▆▇█▇▆ (迷你趋势线)   │  ← 30天 sparkline
│                             │
│  阈值: ≥80%                 │  ← 阈值提示
└─────────────────────────────┘
```

### Props
```typescript
interface IndicatorCardProps {
  indicator: {
    code: string;
    name: string;
    unit: string;
    direction: string;
    currentValue: number | null;
    changeRate: number | null;
    alertLevel: 'GREEN' | 'YELLOW' | 'RED';
    thresholdMin?: number;
    thresholdMax?: number;
    trend: { date: string; value: number }[];
  };
  onClick?: () => void;
}
```

### 迷你趋势线
使用 CSS 实现简单 sparkline（不引入 ECharts，保持轻量）：
- 30 个 div 柱状图，高度按值比例
- 绿色/黄色/红色对应预警等级

### 看板页面
`source/dts-platform-webapp/src/pages/governance/IndicatorDashboardPage.tsx`
- 顶部：domain Tab 切换 + 预警汇总（红x个 黄x个 绿x个）
- 主体：指标卡片网格（响应式 grid）
- 点击卡片 → 跳转详情页
