# T01: gov_indicator_template 表 + Liquibase + 实体/Repository

**优先级**: P0
**状态**: READY
**依赖**: F1/T01

## 目标
创建指标模板存储表及 JPA 实体。

## 技术设计

### 表结构
```sql
CREATE TABLE gov_indicator_template (
    id                    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code                  VARCHAR(64) NOT NULL UNIQUE,
    name                  VARCHAR(200) NOT NULL,
    description           TEXT,
    domain                VARCHAR(32) NOT NULL,  -- FINANCE/PROJECT_MGMT/PLM/HR/GENERAL
    indicator_blueprints  JSONB NOT NULL,         -- 蓝图集合
    required_source_fields JSONB,                 -- [{name,type,description,required}]
    seed_tables           JSONB,                  -- 需要的映射表/对照表定义
    recommended_snapshot  BOOLEAN DEFAULT false,   -- 建议用 dbt snapshot
    builtin               BOOLEAN NOT NULL DEFAULT false,
    enabled               BOOLEAN NOT NULL DEFAULT true,
    display_order         INTEGER DEFAULT 0,
    created_by            VARCHAR(64),
    created_date          TIMESTAMP DEFAULT now(),
    last_modified_by      VARCHAR(64),
    last_modified_date    TIMESTAMP DEFAULT now()
);
CREATE INDEX idx_git_domain ON gov_indicator_template(domain);
```

### indicator_blueprints 格式
```json
[
  {
    "code": "budget_execution_rate",
    "name": "项目经费执行率",
    "aggregationType": "RATIO",
    "numeratorPlaceholder": "direct_expense",
    "denominatorPlaceholder": "direct_budget",
    "dimensionPlaceholders": ["project_name", "department"],
    "datePlaceholder": "report_month",
    "windowFunction": "YOY",
    "unit": "%",
    "precisionScale": 2,
    "direction": "HIGHER_BETTER",
    "thresholdMin": 0.8,
    "isDerived": false,
    "dependencyCodes": []
  }
]
```

### required_source_fields 格式
```json
[
  {"name": "direct_expense", "type": "numeric", "description": "直接支出金额", "required": true},
  {"name": "direct_budget", "type": "numeric", "description": "直接控制数", "required": true},
  {"name": "project_name", "type": "varchar", "description": "项目名称", "required": true},
  {"name": "report_month", "type": "date", "description": "报告月份", "required": true}
]
```
