# T04: 模板展开：蓝图→指标定义批量创建

**优先级**: P0
**状态**: READY
**依赖**: T03, F1/T03

## 目标
实施人员选择模板后，绑定源表和字段映射，系统批量创建 GovIndicatorDefinition 记录。

## 技术设计

### API 端点
```
POST /api/governance/indicator-templates/{templateId}/apply
```

### Request
```json
{
  "sourceTable": "ods_finance_budget",
  "sourceLayer": "ODS",
  "datasetId": "uuid-of-dataset",
  "fieldMapping": {
    "direct_expense": "zhijie_zhichu",
    "direct_budget": "zhijie_kongzhishu",
    "project_name": "xiangmu_mingcheng",
    "report_month": "baogao_yuefen"
  },
  "selectedBlueprints": ["budget_execution_rate", "direct_cost_rate"],
  "overrides": {
    "budget_execution_rate": {
      "thresholdMin": 0.7,
      "staticFilter": "is_deleted = false"
    }
  }
}
```

### 处理逻辑
```java
public List<GovIndicatorDefinition> applyTemplate(UUID templateId, TemplateApplyRequest req) {
    GovIndicatorTemplate tpl = templateRepo.findById(templateId).orElseThrow();
    List<Blueprint> blueprints = parseBlueprints(tpl.getIndicatorBlueprints());
    
    // 过滤选中的蓝图
    if (req.selectedBlueprints != null) {
        blueprints = blueprints.stream()
            .filter(b -> req.selectedBlueprints.contains(b.code()))
            .toList();
    }
    
    List<GovIndicatorDefinition> result = new ArrayList<>();
    for (Blueprint bp : blueprints) {
        GovIndicatorDefinition def = new GovIndicatorDefinition();
        def.setCode(bp.code());
        def.setName(bp.name());
        def.setTemplateId(templateId);
        def.setDomain(tpl.getDomain());
        def.setAggregationType(bp.aggregationType());
        def.setSourceTable(req.sourceTable());
        def.setSourceLayer(req.sourceLayer());
        def.setDatasetId(req.datasetId());
        
        // 字段映射：占位符 → 实际字段名
        def.setMeasureField(mapField(bp.measurePlaceholder(), req.fieldMapping()));
        def.setNumeratorExpression(mapExpression(bp.numeratorPlaceholder(), req.fieldMapping()));
        def.setDenominatorExpression(mapExpression(bp.denominatorPlaceholder(), req.fieldMapping()));
        def.setDimensionFields(mapDimensions(bp.dimensionPlaceholders(), req.fieldMapping()));
        def.setDateColumn(mapField(bp.datePlaceholder(), req.fieldMapping()));
        
        // 蓝图默认值
        def.setWindowFunction(bp.windowFunction());
        def.setUnit(bp.unit());
        def.setPrecisionScale(bp.precisionScale());
        def.setDirection(bp.direction());
        def.setThresholdMin(bp.thresholdMin());
        
        // 用户覆盖
        applyOverrides(def, req.overrides().get(bp.code()));
        
        // 目标模型名
        def.setTargetLayer("ADS");
        def.setTargetModelName("ind_" + bp.code());
        
        def.setStatus("DRAFT");
        result.add(indicatorRepo.save(def));
    }
    return result;
}
```

### 衍生指标处理
若蓝图 `isDerived=true`，设置 `dependencyIndicators` 为依赖的指标 code 列表。依赖指标必须在同一批或已存在。
