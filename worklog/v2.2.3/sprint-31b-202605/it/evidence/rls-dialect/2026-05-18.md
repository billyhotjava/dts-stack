# RLS Dialect IT Evidence

日期：2026-05-18

## 覆盖范围

- PostgreSQL：使用 Testcontainers 启动 `postgres:16-alpine`，实际执行由 dts-metrics 生成并渲染后的候选 SQL。
- Doris：使用最小方言编译器和 golden SQL，验证候选 SQL 不包含 dbt/Jinja 残留、不包含 PostgreSQL 专有 `::` / `nulls last` 语法，并对 masking 类型做 Doris 兼容渲染。
- 未授权路径：platform permission check 拒绝时，preview 不返回 artifact，错误信息不泄露源资产名。

## 验证命令

```bash
./mvnw -q -pl dts-metrics -Dtest=MetricArtifactGenerationIT test
```

## 结果

通过。

PostgreSQL 执行断言：

- 源表包含 `D01` 与 `D02` 两行；
- RLS predicate `dept_code = 'D01'` 生效后只返回 `D01` 聚合结果；
- `customer_phone` 被渲染为 `cast(null as varchar)`，结果为 `null`；
- `contract_amount` 聚合结果为 `100.00`。
