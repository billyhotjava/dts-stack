# T01: v2 TypeScript 类型定义 + 默认值

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

在前端导出 v2 所有类型，新建大屏能直接用这些类型构造默认配置。

## 技术设计

### 位置

`source/dts-platform-webapp/src/analytics/pages/screens/v2/types.ts`

### 核心类型

```ts
export interface ScreenConfigV2 {
  version: 2
  id?: string
  name?: string
  description?: string
  theme?: ScreenTheme
  backgroundColor?: string
  backgroundImage?: string
  layout: ScreenLayoutV2
  components: ComponentV2[]
  globalVariables?: GlobalVariableDefinition[]
  carouselConfig?: CarouselConfig
  // 可选：设计时的参考 viewport（便于再次编辑时回到近似 WYSIWYG）
  referenceViewport?: { width: number; height: number }
}

export interface ScreenLayoutV2 {
  cols: number          // 默认 12
  rowHeight: 'auto' | number  // 'auto' = viewport/rows；number = 固定 px
  gap: number           // 组件间距 px
}

export interface ComponentV2 {
  id: string
  type: string          // 与 v1 一致的组件 type
  layout: GridLayoutCell
  config: Record<string, unknown>  // 组件自身配置（与 v1 的 config 兼容）
  visible?: boolean
  static?: boolean      // 不可拖动/resize（编辑器用）
  visibleByDevice?: { pc?: boolean; tablet?: boolean; mobile?: boolean }
  zIndex?: number       // grid 本身不需要，极少情况用
}

export interface GridLayoutCell {
  x: number       // grid column start (0-based)
  y: number       // grid row start (0-based)
  w: number       // column span
  h: number       // row span
  minW?: number   // 可选：最小宽度（单位 col）
  minH?: number
  maxW?: number
  maxH?: number
}
```

### 默认值

```ts
export const DEFAULT_SCREEN_LAYOUT_V2: ScreenLayoutV2 = {
  cols: 12,
  rowHeight: 'auto',
  gap: 12,
}

export function createEmptyScreenV2(overrides?: Partial<ScreenConfigV2>): ScreenConfigV2 {
  return {
    version: 2,
    name: '新建大屏',
    theme: 'midnight',
    backgroundColor: '#1e1f26',
    layout: DEFAULT_SCREEN_LAYOUT_V2,
    components: [],
    ...overrides,
  }
}
```

### 类型 guard

```ts
export function isScreenConfigV2(s: unknown): s is ScreenConfigV2 {
  return typeof s === 'object' && s !== null && (s as any).version === 2
}
```

## 影响范围

- v1 的类型（`ScreenConfig` / `ScreenComponent`）保持不动
