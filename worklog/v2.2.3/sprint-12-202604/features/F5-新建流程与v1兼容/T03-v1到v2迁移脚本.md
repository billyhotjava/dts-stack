# T03: v1 → v2 迁移脚本（粗映射 + 警告）

**优先级**: P1
**状态**: READY
**依赖**: F2, F3

## 目标

给一个 v1 `ScreenConfig` 输出近似等价的 v2 `ScreenConfigV2`，组件位置按网格粗略映射。demo 期不要求精确，只要求**能跑起来**。

## 技术设计

### 映射算法

```ts
function migrateV1ToV2(v1: ScreenConfig): ScreenConfigV2 {
  const DESIGN_WIDTH = v1.width || 1920
  const DESIGN_HEIGHT = v1.height || 1080
  const COLS = 12
  const ROW_HEIGHT_PX = 40
  const ROWS = Math.ceil(DESIGN_HEIGHT / ROW_HEIGHT_PX)  // ~27

  const colWidth = DESIGN_WIDTH / COLS

  return {
    version: 2,
    id: v1.id,
    name: v1.name,
    description: v1.description,
    theme: v1.theme,
    backgroundColor: v1.backgroundColor,
    backgroundImage: v1.backgroundImage,
    layout: { cols: COLS, rowHeight: ROW_HEIGHT_PX, gap: 8 },
    components: v1.components.map((c) => ({
      id: c.id,
      type: c.type,
      layout: {
        x: Math.round(c.x / colWidth),
        y: Math.round(c.y / ROW_HEIGHT_PX),
        w: Math.max(1, Math.round(c.width / colWidth)),
        h: Math.max(1, Math.round(c.height / ROW_HEIGHT_PX)),
      },
      config: c.config,
      visible: c.visible ?? true,
      visibleByDevice: c.visibleByDevice,
    })),
    globalVariables: v1.globalVariables,
    carouselConfig: v1.carouselConfig,
    referenceViewport: { width: DESIGN_WIDTH, height: DESIGN_HEIGHT },
  }
}
```

### Edge cases

1. **组件重叠**：v1 允许 zIndex 叠放，v2 grid 允许但视觉上重叠 — 保留 zIndex 字段用于非 grid-layout 的 z 排序
2. **负坐标**：v1 偶尔有负 x/y — clamp 到 0
3. **超大尺寸**：`w > cols` → 裁到 cols
4. **非常小尺寸**：`w < 1 || h < 1` → 设为 1（避免 grid 绘制失败）

### warnings

对每个有损映射（如 clamp、裁剪）记 warning，迁移 UI 展示：

```
从 v1 转为 v2 时有 3 处调整：
- 组件 "KPI-销售额" 位置从 x=1830 调整到第 11 列（接近右边缘）
- 组件 "图表-趋势" 尺寸从 600x400 压缩到 4×10 网格
- 组件 "背景装饰" 负坐标 y=-20 调整为 y=0
```
