# T01: 新建大屏对话框简化

**优先级**: P0
**状态**: READY
**依赖**: F2-T01

## 目标

去掉"选固定像素尺寸"（1920×1080 / 2560×1440 / ...）作为新建大屏的必选步骤。新建大屏默认是 v2（响应式）。像素尺寸选项作为"高级"可选。

## 技术设计

### 定位

`source/dts-platform-webapp/src/analytics/pages/screens/components/NewScreenDialog.tsx`（或类似）— 先 grep 确定文件。

### UI 简化

**之前**：
```
名称：________
描述：________
尺寸：[1920×1080 ▾]  ← 必选
主题：[Midnight ▾]
[创建]
```

**之后**：
```
名称：________
描述：________
主题：[Midnight ▾]
> 高级（折叠）
  □ 使用固定像素布局（v1 兼容模式）
    尺寸：[1920×1080 ▾]  ← 只有勾选高级选项时显示
[创建]
```

默认行为：
- `version: 2`
- `layout: DEFAULT_SCREEN_LAYOUT_V2`（cols=12）
- 无 width/height 字段（或设为 `referenceViewport = { viewportWidth, viewportHeight }`）

### 创建调用

```ts
const config = createEmptyScreenV2({
  name,
  description,
  theme,
})
const created = await analyticsApi.createScreen(config)
navigate(`/analytics/screens/${created.id}/edit`)
```

## 影响范围

- 新建对话框组件
- 相关表单校验 / submit 逻辑
- 路由跳转不变

## 验证

- [ ] 新建对话框默认无像素尺寸字段
- [ ] 创建出的大屏 `version === 2`，`layout.cols === 12`
- [ ] "高级"勾选后仍能创建 v1 大屏（兼容路径）
- [ ] 创建后自动跳转到编辑器

## 完成标准

- [ ] UI 简化
- [ ] 默认 v2 大屏可创建并编辑
