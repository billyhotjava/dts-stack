# T04: 网格可视化 + 吸附反馈

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标

编辑态下画布显示 12 列网格线（淡色），组件拖动时显示"将落到"的预览占位（react-grid-layout 原生 placeholder），增强 WYSIWYG 感。

## 技术设计

### 网格背景

CSS 方式（纯 Chrome 95 兼容）：

```css
.designer-canvas-v2 {
  background-image:
    repeating-linear-gradient(
      to right,
      rgba(255, 255, 255, 0.06) 0,
      rgba(255, 255, 255, 0.06) 1px,
      transparent 1px,
      transparent calc(100% / var(--cols))
    );
  background-size: calc(100% / var(--cols)) 100%;
}
```

或者用 grid lines（CSS grid overlay）：

```tsx
<div
  className="designer-grid-overlay"
  style={{
    display: 'grid',
    gridTemplateColumns: `repeat(${cols}, 1fr)`,
    pointerEvents: 'none',
    position: 'absolute',
    inset: 0,
  }}
>
  {Array.from({ length: cols }).map((_, i) => (
    <div key={i} className="grid-col-guide" />
  ))}
</div>
```

### 拖动 placeholder

react-grid-layout 默认会渲染 `.react-grid-placeholder` — 自定义样式即可：

```css
.react-grid-placeholder {
  background: rgba(37, 99, 235, 0.15) !important;
  border: 1px dashed rgba(37, 99, 235, 0.6) !important;
  border-radius: 4px;
  transition: none;  /* Chrome 95 兼容 */
}
```

### 开关

属性面板顶部加 toggle "显示网格"，默认开。存为 editor preference（LocalStorage，不进 ScreenConfig）。

## 影响范围

- `v2/DesignerCanvasV2.tsx`
- `v2/designerCanvasV2.css`
- LocalStorage key `screen.designer.showGrid`
