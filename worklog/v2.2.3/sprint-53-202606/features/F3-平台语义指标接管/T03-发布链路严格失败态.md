# T03: 发布链路严格失败态

**优先级**: P0  
**状态**: DONE  
**依赖**: F0/T02

## 目标

修正发布链路中 `Promise.allSettled` 导致 BI/血缘注册失败仍提示全成功的问题。

## 技术设计

- `SemanticPublishPage`：
  - `publishSemanticModelToDbt`
  - `registerSemanticBiDataset`
  - `registerSemanticLineage`
  必须串行或显式检查结果。
- `MetricDetailPanel` 的“发布 dbt”保持同样语义。
- 如果 dbt 成功但 BI/血缘失败，给出部分成功状态和下一步重试入口，不提示“已全部注册”。

## 影响范围

- `source/dts-platform-webapp/src/pages/modeling/SemanticPublishPage.tsx`
- `source/dts-platform-webapp/src/pages/modeling/metric-workbench/MetricDetailPanel.tsx`
- `source/dts-platform-webapp/src/pages/modeling/metricWorkbench.source-contract.test.ts`

## 验证

- [x] source-contract 不再允许发布链路使用无检查的 `Promise.allSettled` 全成功提示。
- [x] 任一 register 失败时不会出现全成功 toast。

## 完成标准

- [x] 发布、BI 注册、血缘注册的客户可见状态可信。
