# T03: 标准管理页面联动承载重构

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

整理数据元和公共码表页面，让它们能清楚承担 dbt 模型字段标准来源和 dbt seeds 来源，而不是孤立治理页面。

## 技术设计

- `ElementsPage` 保持数据元维护主责，并把引用关系作为模型字段使用情况入口。
- `ReferenceCodesPage` 保持公共码表维护主责，并强化“更新 dbt Seeds”的同步反馈承载。
- 所有新增/编辑/删除/导入/同步按钮必须有权限态、失败态和成功反馈。
- 不在页面内置客户字段模板或演示场景。

## 影响范围
