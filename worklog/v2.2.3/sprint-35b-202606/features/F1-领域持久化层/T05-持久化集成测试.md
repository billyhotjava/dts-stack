# T05: 持久化集成测试（Testcontainers）

**优先级**: P0
**状态**: DONE（MetricLifecyclePersistenceIT 4/4 绿）
**依赖**: T03, T04

## 目标

用真实 postgres 证明持久化正确：重启不丢、并发版本锁生效。

## 技术设计

- Testcontainers `PostgreSQLContainer`，加载 Liquibase changelog。
- 用例：
  1. 创建 graph draft → 新建 Spring 上下文（模拟重启）→ 仍可读。
  2. 走完 generate→validate→publish 两轮 → 版本史含 v1/v2 → 重启 → 仍可读。
  3. 并发两线程 publish 同一 model → 仅一成功，另一 409 `metric_version_conflict`。
  4. publish→rollback → rollback_event 落库且可查。
- platform 远程调用用 stub（参考既有 `StubPlatformContractClient`）。
