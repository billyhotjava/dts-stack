# T01: 抽取共享安全组件 MetricSecurityPolicyService

**优先级**: P0
**状态**: READY
**依赖**: F1

## 目标

把 `MetricArtifactGenerationService` 里已验证的安全逻辑（requirePreviewPermission / requireDeclaredRlsPolicy / recordPolicyInjection / appendRlsWhere / securityPolicyJson）抽成可复用组件，供两条链路共用。

## 技术设计

- 新增 `MetricSecurityPolicyService`（或包私有协作类），封装：
  - `requirePermission(actor, asset, action)` → 调 `platformContractClient.checkPermission`。
  - `resolvePolicy(actor, asset)` → 调 `resolveRlsPolicy`，返回 `RlsPolicyResult`（含 policySource/predicateHash 真实值）。
  - `recordInjection(...)` → 调 `recordPolicyInjection`。
  - SQL 注入辅助：`appendRlsWhere` / masking 表达式（从 `MetricArtifactGenerationService` 迁移，保持 pack 链路行为不变）。
- `MetricArtifactGenerationService` 改为委托该组件（行为等价，回归测试守护）。
- **编辑 `MetricArtifactGenerationService` 前跑 `gitnexus_impact`。**

## 影响范围
- 新增 `service/MetricSecurityPolicyService`。
- `MetricArtifactGenerationService`（改为委托）。
