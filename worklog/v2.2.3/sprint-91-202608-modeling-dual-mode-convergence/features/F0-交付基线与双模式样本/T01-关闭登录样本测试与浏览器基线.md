# T01: 关闭登录、样本、测试与浏览器基线

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

用真实运行证据关闭 `it/baseline.md` 的 P2/P4/P5/P6/P7 缺口，使后续 UI Task 可以进入 READY。

## 技术设计 (Contract-first)

- **输入契约**: 当前 Docker 实例；四个不同 actor（维护、只读、独立评审、发布操作）；现有模型创建 API。
- **输出契约**: `it/baseline.md` 更新为可审计探针结果；新增两个 DESIGNER + 一个 DBT 的 `E2E_S91_*` 样本清单，不修改账本#13 中唯一 DESIGNER DRAFT。
- **数据流**: 登录 → 打开模型工作台 → 创建样本 → 读取 lifecycle/representation → 记录 revision/checksum → 运行测试 harness。
- **错误路径**: 登录/DNS/权限/build 任一失败，记录实际错误并保持依赖 UI Task 为 DRAFT，不把环境修复混入业务 Task。
- **复用点**: 复用当前模型创建、lifecycle 与 representation API；不写测试专用后端入口。

## 影响范围

- `it/baseline.md`
- `it/` 下真实探针输出
- 运行库中新增具名 `E2E_S91_*` 测试模型；不改现有业务模型
- 账号证据只记录 actor/authority/duty，不记录密码、token 或 cookie

## 验证

- [ ] 维护账号可进入工作台并读取 BUSINESS/TECHNICAL representation。
- [ ] 只读账号打开同一模型时所有写动作不可用，直接调用维护 API 返回 403。
- [ ] 维护者、评审人、发布操作员为三个不同 actor；分别能执行 submit review、approve、publish，越权交叉动作返回 403。
- [ ] 前端 source-contract/Vitest、`pnpm build`、后端 modeling focused tests 各成功一次。
- [ ] 浏览器 harness 可登录、截图并收集 console/network 错误。

## Definition of Done

- [ ] Gate G0 交付基线从 GAP 更新为 PASS。
- [ ] 三个样本、四类账号权限/duty 和验证命令均有实际证据，无占位内容。
- [ ] 未修改现有非 E2E 模型。
