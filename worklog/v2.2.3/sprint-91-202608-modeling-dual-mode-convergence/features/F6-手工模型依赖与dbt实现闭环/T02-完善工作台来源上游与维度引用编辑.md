# T02: 完善工作台来源、上游与维度引用编辑

**优先级**: P0
**状态**: CODE_COMPLETE / E2E_PENDING
**依赖**: F6/T01

## 目标

在同一模型编辑器中完整表达不同层级的输入关系，使手工建模不再依赖 ZIP 补来源：DIM 可选 ODS；FACT 可选 ODS 或上游事实作为基础输入并单独引用 DIM；DWS/ADS 可引用上游模型。

## UI/UX 契约

字段设计区的「实现绑定」拆为三个固定区块：

1. **基础来源**：`PHYSICAL_ASSET` 与 `UPSTREAM_MODEL` 二选一；显示固定版本、可用性和字段同步状态。
2. **维度引用**：可添加多个 `dimensionRefs`，每项显示模型、修订、checksum、关联键与角色；只对允许的对象类型开放。
3. **实现与依赖状态**：展示 dependency checksum、声明/实现对账状态以及阻断原因；不允许客户端编辑 checksum。

控件必须有空/加载/错误/成功四态；删除引用需二次确认并提示影响的字段映射/关联。

## 对象规则

| 对象 | 基础来源 | 维度引用 | 上游模型 |
|---|---|---|---|
| DWD DIMENSION | ODS physical source | 不适用 | 可选，按现有规则 |
| DWD FACT | ODS physical source 或上游 FACT | 0..n，固定修订 | 作为基础来源时 0..1 |
| DWS SUMMARY | 上游 DWD/DWS | 可选，仅明确业务需要时 | 1..n 通过既有 dependsOn |
| ADS APPLICATION | 上游 DWS/ADS | 默认不直接绑定 | 1..n 通过既有 dependsOn |

## API 与状态

- 复用现有 ModelSpec save/confirm/lifecycle API 和 ETag，不新增页面或独立“关系维护”保存入口。
- 保存命令携带 `sourceRefs/dependsOn/dimensionRefs` 的完整期望集合；服务端按 F6/T01 规则解析和钉定。
- 409/412 时保留未提交表单并提供「刷新依赖」；403 时完全隐藏写动作但保留只读关系。
- 选择器只返回当前用户可见、对象类型合法且具备可用 revision 的候选；服务端仍做同样校验。

## Feature 关联

- 上游：F1 工作台与 capability；F6/T01 resolver。
- 同级：F6/T03 用本 Task 保存的依赖初始化草稿。
- 下游：F7 的 join/aggregation 编辑器和 F8 的物化计划直接复用这些固定引用。
