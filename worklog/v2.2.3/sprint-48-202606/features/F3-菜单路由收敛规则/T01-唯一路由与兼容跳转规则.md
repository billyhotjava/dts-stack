# T01: 唯一路由与兼容跳转规则

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

定义每个用户工作流只能有一个 canonical route，旧路径保留兼容跳转或明确下线。

## 技术设计

示例规则：

- `/workbench` 是唯一工作台首页
- `/workbench/data-management` 只做兼容跳转
- `/services/consumption` 只做兼容跳转
- BI、指标、语义页必须明确是原生页、frame 还是外部集成
