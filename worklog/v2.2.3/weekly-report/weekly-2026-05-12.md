- ingestion 侧 `IngestionTask` 增加 graph DSL 字段，前后端具备保存编排图的基础契约。

### 2. 大屏设计器和运行时体验

本周大屏是客户可见面修复最多的区域：

- 增强画布交互、组件选中、缩放、图层、边界保护和拖拽体验。
- 重构/补强属性面板：位置尺寸、外观、快速操作、动画、行为、背景图、字段映射、跳转选择、表格/滚动榜配置等。
- 修复大屏编辑时报 `ReferenceError: node is not defined` 的运行时问题。
- 修复 platform-webapp Docker 构建中 `ComponentLibraryPanel`、`DesignerCanvas`、`LayerPanel`、`PropertyPanel`、`TableRenderer` 等 TypeScript 错误。
- 增加草稿恢复、保存发布、只读模式、图表源字段、ECharts 层级/饼图/通用 option builder 等测试覆盖。
- 隐藏不适合当前交付范围的财务大屏模板。
- 补充 GPMC v3 大屏实例配置，并对 PJM 大屏实例统一补登 `classification=INTERNAL`。

### 3. 大屏图片和资源上传

围绕背景图、图片上传和静态资源访问做了三轮修复：

- 修复大屏背景图上传 URL 解析和持久化问题。
- 加固上传大小、路径、来源字段和前端 schema 编辑器映射。
- 调整 nginx 配置，避免上传资源、shell 缓存和前端静态入口之间互相影响。
- 补充 `screenImageUpload`、`BackgroundImageRow`、`FieldEditor` 等 source-level 测试。

### 4. 大屏权限和密级体系

完成从“analytics 本地权限为主”向“platform 统一资产权限为主”的重要收敛：

- platform `AssetPermissionService` 支持 `SCREEN` 权限判定。
- `PUBLIC` 大屏无需显式授权即可只读。
- `INTERNAL`、`SECRET`、`CONFIDENTIAL` 大屏要求显式 grant，并校验人员密级。
- `levelOverride` 仅允许越级只读，不扩大为编辑/管理权限。
- analytics `ScreenPermissionService` 优先调用 platform，只有平台不可用或迁移缺口时才 fallback 到 `analytics_screen_access`，并记录 `analytics_permission_fallback` 告警。
- analytics `ScreenOwnershipService` 新增/撤销授权写 platform `asset_grant`，本地表只保留只读/应急 fallback。
- 修复角色共享后用户在大屏列表看不到报表、但“我的概览”能看到的问题。
- 修复“我的概览”把内部密级大屏当公开内容展示的问题，明确只有公开大屏可无授权展示，内部及以上密级受权限控制。

### 5. 指标语义建模和指标可视化中心

完成指标可视化方向的产品化推进：

- 新增/更新 `dts-metric-visualization-development` skill，用于指标体系、DWS/ADS、dbt SQL、BI Dataset 和大屏组件设计。
- 指标语义建模中心前端页面继续重构，包括主题域、业务对象、指标设计器、语义工作区等。
- 后端强化 default lake 数据集约束，避免语义建模绕过默认数据湖边界。
- SQL 建模、语义建模和治理护栏继续对齐，补充相关单测。

### 6. 数据接入、dbt 和模型包
