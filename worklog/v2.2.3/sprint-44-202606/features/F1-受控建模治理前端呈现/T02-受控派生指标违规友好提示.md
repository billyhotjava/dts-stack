# T02: 受控派生指标违规友好提示（422 unsafe_expression）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
受控模型定义/保存派生指标公式时，把后端 422 `unsafe_expression` 渲染为**内联、引导式**提示（说明受控白名单、禁原始 SQL），而非裸错误码，让用户知道怎么改。

## 技术设计
- **落点**：`src/pages/modeling/SemanticMetricsPage.tsx`（及其公式编辑组件）。
- 保存指标公式调 `/api/semantic/metrics`（或 generate-artifacts 预览）捕获响应：HTTP 422 + body `code=unsafe_expression` → 内联 `Form.Item` 校验态/Alert：
  - 文案："受控模式仅允许白名单函数（sum/count/count_distinct/avg/min/max/ratio/date_trunc/count_if/sum_if/case_when），不支持原始 SQL/自定义表达式。"
  - 可附后端 message（含具体原因）。
- 可选增强：受控模型下，公式类型选择器隐藏/禁用 `sql/custom/expression` 原始入口，仅留受控构造器（前端预防，减少往返）。
- permissive 模型：保持现状（允许原始表达式），不加限制。

## 影响范围
- `dts-platform-webapp`：`SemanticMetricsPage.tsx` + 公式编辑/错误处理；可能复用全局 ApiResponse 错误码解析。

## 验证
- [ ] 受控模型保存原始 SQL 公式 → 内联可读提示 + 白名单引导（非裸 toast）。
- [ ] 受控模型保存合法受控公式 → 成功。
- [ ] permissive 模型保存原始表达式 → 不受影响。

## 完成标准
- [ ] 422 unsafe_expression 引导式渲染、白名单可见、permissive 不变；构建通过。
