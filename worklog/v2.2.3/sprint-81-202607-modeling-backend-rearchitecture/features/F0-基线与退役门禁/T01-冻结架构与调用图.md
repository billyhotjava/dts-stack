# T01：冻结架构、调用图与退役清单

**优先级**：P0
**状态**：IN_PROGRESS
**依赖**：无

## 目标

为所有待改/待删 symbol 建立一次性影响账本，确认目标模块边界和每个旧运行面的真实调用方。

## 技术设计（Contract-first）

- **输入契约**：`assets/architecture-overview.md`、`assets/backend-retirement-matrix.md`；目标 route/symbol/table 列表。
- **输出契约**：`RetirementCallerManifest {target,kind,directCallers,totalCallers,processes,runtimeConsumers,risk,decision}`。
- **数据流**：GitNexus context/impact → 精确 source/config/test/OpenAPI 引用 → runtime usage/外部清单 → manifest。
- **错误路径**：GitNexus index stale 先重建；HIGH/CRITICAL 先告警并拆分；未知 external consumer 使目标保持 `NO_GO`。
- **复用点**：项目 GitNexus 索引和 Sprint-79/80 既有 owner/路由账本。
- **禁止**：全仓重复扫描、find-and-replace、在影响分析前改任何函数/类/方法。

## 影响范围

只读检查 `dts-platform`、webapp client、Airflow/dbt 作业和 schema；本 Task 不改源码或表。

## 验证

- [ ] 每个目标有 upstream impact、风险等级和 execution flow。
- [ ] `/api/semantic`、旧 plan、vNext、`/etl/dbt/run` 的 caller 数有精确清单。
- [ ] `modeling_sql_model`、`modeling_business_object`、legacy ledger 的 owner/FK/consumer 已列出。
- [ ] manifest 与 retirement matrix 一一对应，无无主删除项。

## Definition of Done

- [ ] F1～F5 Task 可只读本 manifest 开工，不再重复同一勘察。
- [ ] HIGH/CRITICAL 项已向用户告警并获得继续授权。
- [ ] 未知项明确关联 F0/T02，而非默认安全。
