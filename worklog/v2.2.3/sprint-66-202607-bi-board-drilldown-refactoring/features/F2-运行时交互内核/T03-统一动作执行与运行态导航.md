# T03：统一动作执行与运行态导航

**优先级**：P0
**状态**：DONE
**依赖**：T01、T02

## 目标

让组件动作共享同一映射结果，并完整接通 drill-down、drill-up、drill-view、panel 和 URL 的运行时行为。

## 技术设计

- 移除 `resolvePreferredDrillValue` 中的领域字段兜底。
- `drill-down` 将完整点击载荷交给通用下钻内核。
- 接通当前类型已声明但未执行的 `drill-view`，调用 `runtime.drillView.drillToView`。
- `set-variable`、panel、URL 和 intent 继续复用 `resolveActionMappingValues`。
- 柱、扇区、折线点、散点、漏斗、雷达、组合图、层级节点、地图区域统一输出 ECharts 数据项载荷；表格行和 KPI/卡片适配到相同 Record 形态。
- 扩展可下钻组件登记范围，覆盖地图、普通/滚动表格、KPI/数字卡/统计卡和仪表盘；装饰组件仍不提供数据点下钻。
- 过滤图例、坐标轴、空白区、表头、滚动条、分页和地图 pan/zoom 事件；加载期间对重复点击去重。
- 面包屑点击、上卷和回到根层均记录 runtime event。
