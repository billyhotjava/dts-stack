### 2. 路由注册

在 `routes/sections/dashboard/static-routes.tsx` 注册：

```tsx
const BiExplorePage = lazy(() => import("@/pages/bi/explore"));
const BiCardEditorPage = lazy(() => import("@/pages/bi/card/CardEditorPage"));
const BiVdsListPage = lazy(() => import("@/pages/bi/virtual-datasets/ListPage"));
const BiVdsEditorPage = lazy(() => import("@/pages/bi/virtual-datasets/EditorPage"));

// 追加到 STATIC_DASHBOARD_ROUTES
{ path: "bi/explore",                 element: <S><BiExplorePage /></S> },
{ path: "bi/card/new",                element: <S><BiCardEditorPage mode="create" /></S> },
{ path: "bi/card/:id/edit",           element: <S><BiCardEditorPage mode="edit" /></S> },
{ path: "bi/virtual-datasets",        element: <S><BiVdsListPage /></S> },
{ path: "bi/virtual-datasets/new",    element: <S><BiVdsEditorPage mode="create" /></S> },
{ path: "bi/virtual-datasets/:id",    element: <S><BiVdsEditorPage mode="edit" /></S> },
```

（不需要走 `dynamic-resolver.tsx` 的 PATH_COMPONENT_OVERRIDES，避免重蹈指标孤岛页的覆辙。）
