# T04: 派生指标公式编辑器

**优先级**: P0
**状态**: READY
**依赖**: T02, F4/T03

## 目标

在 CardEditor 的右栏实现**派生指标公式编辑器**：用户用 F1/T03 定义的 DSL 写公式，编辑器提供：
- 函数自动补全（来自 `/api/semantic/functions`）
- 指标/维度引用补全（来自 `/api/semantic/meta`）
- 语法高亮 + 实时错误标注
- 公式预览（展开成完整 SQL 片段给 Tooltip）

**明确边界**：这是公式编辑器，**不是 SQL 编辑器**。任何 raw SQL 尝试在语义层会拒绝。

## 技术选型

**CodeMirror v6**（轻量，可做自定义语言）。理由：
- 比 Monaco 小很多（~100KB vs 1MB）
- Lezer 语法树比较易集成 ANTLR grammar
- 可用 @codemirror/autocomplete 做语义补全

备用：Monaco + 自写 token provider，但体积劝退。

**另一种思路**：
- 用 block-based 编辑（类 Scratch 积木），用户只能拖 token 不能随意打字
- 优点：绝无法写出非法 token
- 缺点：高级用户嫌慢、写 `ratio(count_distinct(...), count(...))` 这种嵌套很累
- **折中**：本 Sprint 用 CodeMirror + 严格 autocomplete，block 留给 Sprint-14 可选

## 技术设计

### 1. 编辑器组件

```tsx
<FormulaEditor
  value={expression}
  onChange={onChange}
  context={{
    availableMetrics: ["revenue", "order_count", ...],
    availableDimensions: ["region", "order_date", ...],
    availableDerived: ["_custom_1"],
    functions: ["sum", "ratio", "growth", "if", ...]
  }}
  onValidationChange={(errors) => ...}
/>
```

### 2. 语法高亮

- Reference `[...]` — 紫色粗体
- Function name — 蓝色
- Operator — 灰色
- String literal — 绿色
- Number — 橙色
- 错误 token — 红色波浪线

### 3. 自动补全

触发：
- 输入 `[` → 列出所有 metric/dimension
- 输入 `]` 后 + 一个字母 → 列出匹配的 metric name（可继续 `.region` tab）
- 输入字母开头 → 列出匹配的函数 name
- 函数后 `(` → 展示签名 Tooltip（"ratio(numerator, denominator) → number"）

补全项带：
- icon（函数/指标/维度三色图标）
- 签名 / 描述
- 密级徽章

### 4. 实时校验

每 500ms debounce，调用后端 `POST /api/semantic/query/preview-sql` + `derived_metrics_only=true` 模式，或走客户端 ANTLR（两套都有时走客户端，节省服务器）。

**客户端 ANTLR**：
- 用 `antlr4ts` 从 F4/T01 的 `.g4` 生成 TS parser
- 客户端做 parse + function-whitelist + reference 存在性校验
- 类型校验 + 循环依赖校验留给后端

错误 inline 显示 + 底部错误面板：
```
⚠ DSL_E012 引用的指标 [nonexistent] 不存在
     行 1 列 8
     可用: [revenue], [order_count], [付费订单数]
```

### 5. 公式引用的变量高亮

当前公式里用到了哪些原子指标 → 在左栏指标树里给高亮 / 标记（"使用中 × 2"）。

### 6. 派生指标 CRUD

右栏顶部是派生指标列表：

```
派生指标
┌──────────────────────────────────────────┐
│ [+ 新增]                                  │
├──────────────────────────────────────────┤
│ 付费率          [revenue_paid]/[revenue] │
│ [编辑] [删除]                             │
├──────────────────────────────────────────┤
│ 客单价          ratio([revenue], [count])│
│ [编辑] [删除]                             │
└──────────────────────────────────────────┘
```

派生指标保存在 CardEditorState.derivedMetrics，本地状态，保存 Card / VDS 时一起持久化。

### 7. 函数文档面板

编辑器右边有可折叠的函数文档面板，从 `/api/semantic/functions` 拉，按类别分组（聚合 / 比例 / 条件 / 窗口 / 格式）。点函数名插入到编辑器。

### 8. 模板 / 示例

提供 5 个常用模板（一键插入）：

- 环比增长率
- 同比增长率
- 客单价
- 复购率
- 漏斗转化率

### 9. 只读模式

业务用户 / card 只读状态下：
- 编辑器只显示不能编辑
- 点击引用跳转到该指标的定义页
