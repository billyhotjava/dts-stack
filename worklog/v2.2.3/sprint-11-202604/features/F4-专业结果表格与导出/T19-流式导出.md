# T19: 流式导出（CSV / Excel / JSON）

**优先级**: P0
**状态**: READY
**依赖**: T16

## 目标

支持导出完整结果集（最多 100k 行），走服务端流式响应，不在前端内存累积；受频控约束防止数据外泄。

## 技术设计

### 导出端点

```
GET /api/sql/v2/executions/{id}/export?format=csv|xlsx|json
```

- 响应 `Content-Disposition: attachment`
- 用 `StreamingResponseBody`（Spring）或 `HttpServletResponse` 直写 OutputStream

### 格式实现

| 格式 | 实现 |
|---|---|
| **CSV** | 逐 chunk 读 `query_execution_chunk`，写 CSV 行；BOM + UTF-8；字段含逗号/换行自动引号 |
| **Excel** | [Apache POI SXSSFWorkbook](https://poi.apache.org/) 流式 xlsx 写入（内存仅保留 100 行窗口） |
| **JSON** | `[...chunk1...,...chunk2...]` 拼接，Jackson streaming API |

### 频控

- 单用户 10 分钟内最多 **5 次** 导出
- 用 Caffeine 或 Redis 计数（项目已有 Redis）
- 超限返回 429 + 提示 "导出频次已达上限，请稍后重试或联系管理员"

### 审计

- `SQL_RESULT_EXPORT` 动作
- 字段：`executionId`, `format`, `rowCount`, `bytesSent`
- 失败（超限/权限）也记录

### 前端 UI

- 结果区右上角 `Export ▾` 下拉：CSV / Excel / JSON
- 点击后显示进度提示（文件大时可能几秒）
- 浏览器直接下载

### 安全

- 再次走 `SecuritySqlRewriter` 校验用户是否仍有权限（防止查询后用户权限被降级）
- 导出文件名：`{tabTitle}_{executionId之前8位}.{ext}`

## 影响范围

- 新增 `SqlResultStreamService`（负责从 chunk 拉 + 流式写）
- 新增端点 `GET /api/sql/v2/executions/{id}/export`

- Apache POI 依赖（若未引入）
