# BI 驾驶舱大屏设计工作区

本目录用于沉淀 v4 版本的 BI 驾驶舱系列设计。目标是从领导层总览开始，逐级下钻到中层管理看板和底层明细看板，形成一套统一的信息架构、视觉语言和指标口径。

## 目录约定

- `dashboard-series-design.md`: 驾驶舱系列设计草案，包含页面分层、视觉规范、指标方向和实施步骤。
- `demo/`: HTML 原型、视觉样例和可运行 demo。

## 当前参考

- 视觉参考样例当前检测到位于 `../pjm/bi/demo/preview1.html`。
- 指标和下钻思想参考 `../pjm/screen-instances/`，但不沿用其杂乱装饰风格。

## 设计原则

- 领导层页面优先回答“当前是否可控、哪里需要决策、谁负责下一步”。
- 中层页面优先回答“某个专业域为什么异常、资源和责任如何分布、如何闭环”。
- 明细页面优先回答“具体项目、风险、质量问题、变更或任务的清单和追踪记录”。
- 全系列统一布局、颜色、字号、卡片、状态标签和下钻路径。
