# 数据管理平台数据模型设计文档（v4 重构版）

文档版本：V4.0  
文档状态：重构稿  
生成日期：2026-04-28  
适用范围：项目管控、用友 ERP 采购库存、考勤、专利、财务一体化数据平台

## 0. 本次重构结论

本版以 `worklog/v2.2.3/s10/v4/pjm/dbt_model` 为项目域唯一依据，替换原文中旧的 `dwd_progress_detail`、`dwd_quality_detail`、`dwd_risk_detail`、`dwd_tech_change_detail`、`dwd_project_full_info` 等项目域设计。v4 项目域已形成 `ODS -> STG -> DWD -> DWS -> ADS` 链路：9 张 ODS、4 张 STG、8 张 canonical 维表、10 张 alias 维表、4 张 DWD 事实、4 张 DWS 汇总、8 张 ADS 模型。

原文 ERP 部分使用了偏 NC 的表名（如 `bd_material_v`、`bd_supplier`、`bd_stordoc`、`pm_wbs`）。本版改为用友 U8 经典采购/库存体系补齐：`Inventory`、`Vendor`、`Warehouse`、`PO_Pomain/PO_Podetails`、`PU_ArrivalVouch/PU_ArrivalVouchs`、`RdRecord/RdRecords` 或按类型拆分的 `RdRecord01/RdRecords01`、`PurBillVouch/PurBillVouchs`、`CurrentStock` 等。实际落地前仍需用现场账套数据字典确认字段大小写、扩展字段和是否按单据类型拆分物理表。

全篇 SQL 统一改为 PostgreSQL 写法：注释使用 `COMMENT ON`，布尔用 `boolean`，时间用 `timestamp`，金额数量用 `numeric`，索引独立 `CREATE INDEX`，自增主键优先 `GENERATED ... AS IDENTITY`；项目域现有 ODS 脚本保留 `serial`，因为该脚本已是 PostgreSQL 可执行语法。

## 1. 核心设计原则

| 原则 | 说明 |
| --- | --- |
| 分层职责清晰 | ODS 原样落地，STG 做类型转换与字段收敛，DWD 做业务解释与维表归一，DWS/ADS 面向指标消费。 |
| 最新状态与追溯并存 | 项目域状态类事实在 DWD 输出当前业务解释，同时 STG/ODS 保留 source_row_id、source_table、imported_at 等追溯字段。 |
| 枚举归一由维表承担 | 别名表只负责原值到 canonical code 的映射，canonical dim 是业务分类唯一真值源。 |
| 指标保留分子分母 | ADS KPI 表保留原始计数和比率分子/分母，跨月查询通过 SUM 后重算，避免平均率误差。 |
| PostgreSQL 优先 | DDL、函数、索引、注释均使用 PostgreSQL 方言；不再使用 MySQL 内联 COMMENT、AUTO_INCREMENT、ON UPDATE CURRENT_TIMESTAMP。 |

## 3. PostgreSQL SQL 标准

### 3.1 MySQL 到 PostgreSQL 转换规则

| 场景 | 原 MySQL 写法 | PostgreSQL 写法 |
| --- | --- | --- |
| 字段注释 | `col varchar(50) COMMENT '说明'` | `col varchar(50); COMMENT ON COLUMN table.col IS '说明';` |
| 表注释 | `) COMMENT '表说明';` | `); COMMENT ON TABLE table IS '表说明';` |
| 自增主键 | `INT AUTO_INCREMENT PRIMARY KEY` | `bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` 或现有 ODS 的 `serial PRIMARY KEY` |
| 时间类型 | `DATETIME` | `timestamp without time zone`；如需时区明确则用 `timestamp with time zone` |
| 布尔类型 | `TINYINT(1)` / `TINYINT DEFAULT 1` | `boolean DEFAULT true`；确有 0-255 数值语义时用 `smallint` |
| 整数类型 | `INT` | `integer` |
| 金额/数量 | `DECIMAL(28,8)` | `numeric(28,8)` |
| 更新时间 | `ON UPDATE CURRENT_TIMESTAMP` | PostgreSQL 无列级 `ON UPDATE`，用 `BEFORE UPDATE` trigger 设置 `updated_at = now()` |
| 索引 | `INDEX idx_col (col)` 写在 CREATE TABLE 内 | `CREATE INDEX idx_table_col ON table_name (col);` |
| 唯一索引 | `UNIQUE KEY uk_name (a,b)` | `ALTER TABLE table_name ADD CONSTRAINT uk_name UNIQUE (a,b);` 或 `CREATE UNIQUE INDEX` |
| 字符串函数 | `IFNULL(a,b)` / `DATE_FORMAT(d, "%Y-%m")` | `COALESCE(a,b)` / `to_char(d, 'YYYY-MM')` |

### 3.2 PostgreSQL DDL 示例：组织部门

```sql
CREATE TABLE sys_department (
  dept_id varchar(50) PRIMARY KEY,
  dept_code varchar(50),
  dept_name varchar(100) NOT NULL,
  dept_short_name varchar(50),
  dept_alias text,
  parent_dept_id varchar(50),
  dept_level integer,
  dept_path varchar(500),
  dept_type varchar(20),
  leader_id varchar(50),
  leader_name varchar(50),
  sort_order integer DEFAULT 0,
  is_active boolean DEFAULT true,
  created_at timestamp without time zone DEFAULT now(),
  updated_at timestamp without time zone DEFAULT now()
);

COMMENT ON TABLE sys_department IS '科室信息表（平台业务模块复用）';
COMMENT ON COLUMN sys_department.dept_id IS '科室ID';
COMMENT ON COLUMN sys_department.dept_name IS '科室名称';
COMMENT ON COLUMN sys_department.is_active IS '是否有效';

CREATE INDEX idx_sys_department_parent ON sys_department (parent_dept_id);
CREATE INDEX idx_sys_department_code ON sys_department (dept_code);
CREATE INDEX idx_sys_department_active ON sys_department (is_active);
```

### 3.3 updated_at 触发器模板

```sql
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS trigger
LANGUAGE plpgsql
AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$;

CREATE TRIGGER trg_sys_department_updated_at
BEFORE UPDATE ON sys_department
FOR EACH ROW
EXECUTE FUNCTION set_updated_at();
```

## 4. 项目域 v4 模型

### 4.1 分层链路

```text
ODS -> STG -> DWD -> DWS -> ADS
```

| 层 | 材质化 | 职责 |
| --- | --- | --- |
| ODS | 物理表 | 原始 Excel 字段落地与追溯，不承载业务语义。 |
| STG | view | 类型转换、占位符归 NULL、空白收敛、字段改名、来源元数据；禁止业务分类和派生。 |
| DWD | table | 别名归一、canonical 维表打标、日期/月度/布尔等业务派生。 |
| DWS | table | 按项目/部门/月度等粒度汇总主题指标。 |
| ADS | table | 看板/API 直接消费的 KPI 与二次指标。 |
