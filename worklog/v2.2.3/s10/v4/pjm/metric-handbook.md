# GPMC 大屏指标说明手册 v1.0

> 口径冻结日期: **2026-05-18**
> 权威源: `v3/metrics/原始指标大表.xlsx` + `v3/metrics/二次指标大表.xlsx`

本手册收录大屏所有指标的业务定义、计算公式、阈值与数据来源。所有内容来自 Excel 指标大表,与大屏 ℹ️ 弹窗内容完全一致。

## 进度域 (16 个指标)

### 异常节点数  ·  `pjm_prog_abnormal_cnt`

| 项 | 内容 |
|---|---|
| 业务定义 | 处于异常状态(不正常待变更 + 超期未完成未变更)的节点数 |
| 计算公式 | 完成情况∈('不正常待变更','超期未完成未变更') 的节点计数 |
| 统计范围 | 受顶部时间筛选器控制,不含一般节点 |
| 单位 | 个 |
| 评价方向 | 越低越好 |
| 阈值 | 无 |
| 数据来源 | 进度信息汇总表 |
| 更新频率 | 每日 01:00 刷新 |
| 历史别名 | 异常 |
| Excel 出处 | 原始指标 #12 + #13 |

### 节点不正常率  ·  `pjm_prog_abnormal_rate`

| 项 | 内容 |
|---|---|
| 业务定义 | 已到时间节点中,处于危险状态但尚未走变更流程的节点占比 |
| 计算公式 | (不正常待变更 + 超期未完成未变更) ÷ 已到时间节点数 × 100% |
| 统计范围 | 不含一般节点 |
| 单位 | % |
| 评价方向 | 越低越好 |
| 阈值 | 关注线 ≥ 20.0%  ·  预警线 ≥ 30.0% |
| 数据来源 | 进度信息汇总表 |
| 更新频率 | 每日 01:00 刷新 |
| 历史别名 | 异常率, 不正常率 |
| Excel 出处 | 二次指标 #3 pjm_prog_abnormal_rate |

### 节点完成百分比  ·  `pjm_prog_completion_rate`

| 项 | 内容 |
|---|---|
| 业务定义 | 周期内已到时间的节点中,已完成节点的占比(含周期外完成) |
| 计算公式 | (按时完成节点数 + 超期完成节点数 + 周期外完成节点数) ÷ (已到时间节点数 + 周期外完成节点数) × 100% |
| 统计范围 | 已到时间节点 = 周期内总节点 - 正常待完成节点 |
| 单位 | % |
| 评价方向 | 越高越好 |
| 阈值 | 关注线 ≤ 85.0%  ·  预警线 ≤ 75.0% |
| 数据来源 | 进度信息汇总表 |
| 更新频率 | 每日 01:00 刷新 |
| 历史别名 | 项目完成率, 整体完成率, 完成率 |
| Excel 出处 | 原始指标 #9 节点完成百分比 |
