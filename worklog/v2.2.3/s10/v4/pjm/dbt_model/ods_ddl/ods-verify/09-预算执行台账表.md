# 预算执行台账表
ODS 表名: ods_budget


| # | 源表 字段名 |
|---|---------|
| 1 | 项目号 |
| 2 | 预算编号 |
| 3 | 所属子课题 |
| 4 | 研究室 |
| 5 | 预算金额（调整后） |
| 6 | 预付账款（未验收未报销、无发票） |
| 7 | 账面成本（已验收有发票） |
| 8 | 应付账款（有发票暂未付款） |


## 口径说明（科研经费"三本账"快照）

本表是**时点快照**，无业务日期列，反映当前预算执行状态。`_dts_import_time` 仅作入湖技术时间，不参与业务时间筛选。

| 概念 | 口径 | 来源字段 |
|------|------|----------|
| 预算总额 | 调整后批复预算 | `budget_amount_adjusted` |
| 预付账款 | 已付款、未验收未报销、无发票（在途资金） | `prepaid_amount` |
| 账面成本 | 已验收、有发票（已确认支出） | `book_cost_amount` |
| 应付账款 | 有发票、暂未付款（已确认未付） | `payable_amount` |
| **已执行/已占用** | **预付账款 + 账面成本 + 应付账款** | 派生（DWD） |
| 预算剩余可用 | 预算总额 − 已执行 | 派生（DWD） |
| 超支金额 | 单条 max(0, 已执行 − 预算) 之和 | 派生（DWD/DWS） |

## 粒度与维度

- 自然粒度：`项目号 × 预算编号 × 所属子课题 × 研究室`（一条预算明细一行）。
- 拆分维度：`研究室`（对齐其他域 dept，直接取值不走 dim 归一化）、`所属子课题`、`项目号`（关联 `biz_dwd_project_node_v2.project_no` 项目维度）。
- 无枚举/分类字段，**预算域不需要 canonical/alias dim**。

## 待确认
