# 财务域指标计算原理

## 数据流转

```
Excel → 入湖(Addax) → ODS 表(4张)
  → DWD(清洗+派生) → DWS(汇总) → ADS(KPI)
    → 查询卡片 → 大屏组件
```

---

## F1: 项目经费大屏

**ODS 表：** `fin_ods.project_fund`
**ADS 表：** `biz_ads_project_fund_kpi`
**查询卡片目录：** `screen-queries/f1-project-fund/`

### KPI 指标（5 个核心 + 3 个执行率）

| 指标 | 字段 | 计算公式 | 大屏组件 |
|------|------|---------|---------|
| 总经费合计 | `sum_total_fund` | SUM(total_fund) | KPI卡片 |
| 直接成本控制数 | `sum_direct_ctrl` | SUM(direct_ctrl) | KPI卡片 |
| 直接成本已支出 | `sum_direct_spent` | SUM(direct_ctrl × direct_rate / 100) | KPI卡片 |
| 预留间接费用 | `sum_reserve_indirect` | SUM(reserve_indirect) | KPI卡片 |
| 间接费用支出 | `sum_indirect_spent` | SUM(indirect_spent) | KPI卡片 |
| 总支出合计 | `sum_total_spent` | direct_spent + indirect_spent | 计算用 |
| 剩余经费 | `sum_remaining_fund` | total_fund - total_spent | KPI卡片 |
| **直接成本执行率** | `overall_direct_rate` / `_pct` | **SUM(直接支出) / SUM(直接控制数) × 100%** | 仪表盘 |
| **总经费执行率** | `overall_total_rate` / `_pct` | **SUM(总支出) / SUM(总经费) × 100%** | 仪表盘 |
| 间接费用执行率 | `overall_indirect_rate` / `_pct` | SUM(间接支出) / SUM(预留间接) × 100% | KPI卡片 |

### 派生字段（DWD 层计算）

```
direct_spent   = direct_ctrl × direct_rate / 100     ← ODS 只有控制数和执行率
total_spent    = direct_spent + indirect_spent
total_rate     = total_spent / total_fund × 100
indirect_rate  = indirect_spent / reserve_indirect × 100
```

### 大屏组件 → 查询卡片对照

| 组件 | 卡片文件 | 关键字段 |
|------|---------|---------|
| KPI 指标卡片（5个） | `01-kpi-经费总览.sql` | sum_total_fund, sum_direct_spent, sum_remaining_fund |
| 经费结构分布（堆叠柱状图） | `02-经费结构分布.sql` | project_id, direct_spent, indirect_spent, remaining |
| 直接成本执行率（仪表盘） | `04-直接成本执行率.sql` | overall_direct_rate, overall_direct_rate_pct |
| 总经费执行率（仪表盘） | `05-总经费执行率.sql` | overall_total_rate, overall_total_rate_pct |
| 经费明细表 | `03-经费明细表.sql` | 全字段 |

## F2: 辅助余额大屏

**ODS 表：** `fin_ods.aux_balance`
**ADS 表：** `biz_ads_aux_balance_kpi`
**查询卡片目录：** `screen-queries/f2-aux-balance/`

### KPI 指标（4 个）

| 指标 | 字段 | 计算公式 | 大屏组件 |
|------|------|---------|---------|
| 余额合计 | `total_balance` | SUM(balance) | KPI卡片（前端转万元） |
| 科目数量 | `subject_count` | COUNT(DISTINCT subject_code) | KPI卡片 |
| 有效合同数 | `contract_count` | COUNT(DISTINCT contract_name) WHERE has_contract=TRUE | KPI卡片 |
| 部门数量 | `dept_count` | COUNT(DISTINCT dept_name) | KPI卡片 |

### 派生字段（DWD 层计算）

```
expense_category = CASE
  WHEN subject_code LIKE '5001%' THEN '原材料/设备'
  WHEN subject_code LIKE '5101%' THEN '外协/服务'
  WHEN subject_code LIKE '5201%' THEN '折旧'
  WHEN subject_code LIKE '5301%' THEN '检测试验'
  WHEN subject_code LIKE '5401%' THEN '设计咨询'
  WHEN subject_code LIKE '5501%' THEN '租赁'
  WHEN subject_code LIKE '5601%' THEN '培训'
  ELSE '其他'
END

has_contract = contract_name IS NOT NULL AND contract_name != '—'
```

| 部门分布（环形图） | `03-部门分布.sql` | dept_name, dept_total_balance |
| 费用类别分布（树图） | `04-费用类别分布.sql` | label(类别), value(余额) |
| 明细表 | `05-余额明细表.sql` | 全字段 |

## F3: 个人辅助余额大屏

**ODS 表：** `fin_ods.aux_balance_personal`
**ADS 表：** `biz_ads_aux_balance_personal_kpi`
**查询卡片目录：** `screen-queries/f3-personal-balance/`

### KPI 指标（5 个）

| 指标 | 字段 | 计算公式 | 大屏组件 |
|------|------|---------|---------|
| 净余额 | `net_balance` | SUM(balance)，正=净借方 负=净贷方 | KPI卡片 |
| 借方合计 | `debit_total` | SUM(CASE WHEN balance > 0 THEN balance ELSE 0) | KPI卡片 |
| 贷方合计 | `credit_total` | SUM(CASE WHEN balance < 0 THEN ABS(balance) ELSE 0) | KPI卡片 |
| 涉及职工数 | `employee_count` | COUNT(DISTINCT employee_name) | KPI卡片 |
| 科目数量 | `subject_count` | COUNT(DISTINCT subject_code) | KPI卡片 |

### 余额方向说明

```
正数（借方/debit）= 应收/借款 — 员工欠单位的钱
负数（贷方/credit）= 应付/代扣 — 单位欠员工的钱
```

### 派生字段（DWD 层计算）

```
balance_direction = CASE
  WHEN balance > 0 THEN 'debit'    -- 借方
  WHEN balance < 0 THEN 'credit'   -- 贷方
  ELSE 'zero'
END

abs_balance = ABS(balance)

subject_category = CASE
  WHEN subject_code LIKE '1122%' THEN '其他应收-借款'
  WHEN subject_code LIKE '2211%' THEN '应付职工薪酬'
  ELSE '其他'
END
```

### 大屏组件 → 查询卡片对照

| 组件 | 卡片文件 | 关键字段 |
|------|---------|---------|
| KPI 指标卡片（5个） | `01-kpi-个人余额总览.sql` | net_balance, debit_total, credit_total |
| 职工分布（横条图） | `02-职工分布.sql` | label(姓名), value(净余额) |
| 部门分布（环形图） | `03-部门分布.sql` | dept_name, dept_abs_total |
| 科目类别分布 | `04-科目类别分布.sql` | label(类别), value(绝对值) |
| 明细表 | `05-个人余额明细表.sql` | 全字段 |
| 借款排名TOP8 | `06-借款排名TOP8.sql` | employee_name, total_balance（仅正数） |

## F4: 自有资金大屏

**ODS 表：** `fin_ods.own_fund`
**ADS 表：** `biz_ads_own_fund_kpi`
**查询卡片目录：** `screen-queries/f4-own-fund/`

### KPI 指标（每年 6 个）

| 指标 | 字段 | 计算公式 | 大屏组件 |
|------|------|---------|---------|
| 年初合计 | `opening_total` | period_type='opening' 的 total | KPI卡片 |
| 预计增加合计 | `increase_total` | period_type='increase' 的 total | KPI卡片 |
| 预计使用合计 | `usage_total` | period_type='usage' 的 total | KPI卡片 |
| 年末余额合计 | `balance_total` | period_type='balance' 的 total | KPI卡片 |
| **资金使用率** | `usage_rate` / `_pct` | **usage_total / (opening_total + increase_total) × 100%** | 仪表盘 |
| **余额增长率** | `growth_rate` / `_pct` | **(balance_total - opening_total) / opening_total × 100%** | 仪表盘 |

### 四种基金类型

| 基金 | 字段前缀 | 说明 |
|------|---------|------|
| 事业基金 | `career_*` | 主要资金来源 |
| 折旧基金 | `deprec_*` | 固定资产折旧 |
| 职工福利基金 | `welfare_*` | 员工福利 |
| 安全生产基金 | `safety_*` | 安全投入 |

### 四种期间类型

| 期间 | period_type | sort | 说明 |
|------|------------|:---:|------|
| 年初 | `opening` | 1 | 年初余额 |
| 预计增加 | `increase` | 2 | 当年预计增加 |
| 预计使用 | `usage` | 3 | 当年预计使用 |
| 年末余额 | `balance` | 4 | = 年初 + 增加 - 使用 |

### 派生字段（DWD 层计算）

```
period_year = 从 year_period 文本中提取年份（如 "2026年初" → 2026）
period_type = CASE
  WHEN year_period LIKE '%年初' THEN 'opening'
  WHEN year_period LIKE '%预计增加' THEN 'increase'
  WHEN year_period LIKE '%预计使用' THEN 'usage'
  WHEN year_period LIKE '%余额' THEN 'balance'
END
```

### 资金使用率告警规则

```
> 80% → 警惕，资金可能紧张
> 95% → 危险，需要补充资金来源
```

## 百分比字段说明

所有 `_rate` 结尾的字段都有两个版本：

| 字段 | 类型 | 用途 |
|------|------|------|
| `xxx_rate` | numeric | 原始数值，用于图表轴/排序/计算 |
| `xxx_rate_pct` | text | 带 % 的字符串（如 "72.40%"），用于表格/KPI卡片直接显示 |

finance 域的 rate 字段**已经是百分比**（0~100），pjm 域的 rate 字段是小数（0~1），pct 字段会自动处理差异。
