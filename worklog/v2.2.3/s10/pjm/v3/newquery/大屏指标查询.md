# 大屏指标 SQL 查询手册

> 9 个大屏（5 主屏 + 4 下钻）所有指标的可执行 SQL 查询。
> **每个指标对应一段独立 SQL，每段 SQL 只输出一个指标**（不做多指标 bundle）。

---

## 使用说明

### 1. 修改时间范围

所有 SQL 中只有两个日期常量需要修改：

| 占位符 | 含义 |
|---|---|
| `'2025-01-01'` | ★开始时间 |
| `'2025-12-31'` | ★结束时间 |

编辑器全局替换即可一次更新全部 SQL。

### 2. 数据源层

大屏走的是 **dbt 构建的 DWD/DWS 层**（不是直接查 ODS）。运行前需要先构建 dbt：

```bash
cd /path/to/dbt && dbt run --select +tag:project-management-v3
```

| 域 | DWS 表（汇总） | DWD 表（明细） |
|---|---|---|
| 进度 | `biz_dws_progress_monthly_v2` | `biz_dwd_project_node_v2` |
| 质量 | `biz_dws_quality_monthly_v2` | `biz_dwd_quality_issue_v2` |
| 技术状态 | `biz_dws_tech_state_monthly_v2` | `biz_dwd_tech_state_v2` |
| 风险 | `biz_dws_risk_monthly_v2` | `biz_dwd_risk_info_v2` |

### 3. 时间字段说明

- **DWS 层**：`plan_month` / `period_month` 是 TEXT 格式 `'YYYY-MM'`，过滤用 `to_char(date, 'YYYY-MM')` 比较
- **DWD 层**：`plan_date` / `issue_date` / `change_submit_time` / `risk_submit_date` 是 DATE 类型，直接 BETWEEN

### 4. 与原始指标的关系

每个大屏指标都标注了对应的原始指标编号（`#1` ~ `#67`）或二次指标编号（`二次#1` ~ `二次#18`）。
原始指标的定义和 ODS 直查 SQL 见 `原始指标查询.md`。

### 5. 与文档的差异提示 ⚠️

部分大屏指标在 `原始指标大表.xlsx` / `二次指标大表.xlsx` 中**没有定义**，是大屏开发时新增的派生指标。这些已在备注中标注 ⚠️。

# 一、综合 / 跨域指标

## 1.1 项目总数

**出现位置**：S1 战略大屏  
**含义**：在统计周期内有任意进度节点的项目数（按 project_no 去重）  
**对应原始指标**：⚠️ 文档中无定义，大屏新增派生指标

```sql
SELECT COUNT(DISTINCT project_no) AS "项目总数"
FROM biz_dws_progress_monthly_v2
WHERE plan_month >= to_char('2025-01-01'::date, 'YYYY-MM')
  AND plan_month <= to_char('2025-12-31'::date, 'YYYY-MM');
```

## 1.4 综合健康度

**出现位置**：S1 战略大屏（gauge）  
**含义**：进度健康度 × 0.4 + 质量健康度 × 0.3 + 技术状态健康度 × 0.3  
**对应指标**：二次#17

```sql
WITH p AS (
  SELECT
    SUM(due_cnt) AS due,
    SUM(on_time_cnt) AS on_time,
    SUM(milestone_on_time_cnt) AS ms_ot,
    SUM(milestone_total_cnt) AS ms_t,
    SUM(abnormal_pending_non_general_cnt) AS abn,
    SUM(overdue_incomplete_unchanged_non_general_cnt) AS ov_unc
  FROM biz_dws_progress_monthly_v2
  WHERE plan_month >= to_char('2025-01-01'::date, 'YYYY-MM')
    AND plan_month <= to_char('2025-12-31'::date, 'YYYY-MM')
), q AS (
  SELECT
    SUM(new_issue_cnt) AS n,
    SUM(open_issue_cnt) AS o,
    SUM(zero_completed_cnt) AS z,
    SUM(no_zero_plan_cnt) AS np
  FROM biz_dws_quality_monthly_v2
  WHERE period_month >= to_char('2025-01-01'::date, 'YYYY-MM')
    AND period_month <= to_char('2025-12-31'::date, 'YYYY-MM')
), t AS (
  SELECT
    SUM(total_change_cnt) AS total,
    SUM(order_signed_cnt) AS sgn,
    SUM(order_unsigned_cat_i) + SUM(order_unsigned_cat_ii) + SUM(order_unsigned_cat_iii) AS unsgn,
    SUM(reform_done_i_ii) AS rd,
    SUM(reform_pending_i_ii) AS rp
  FROM biz_dws_tech_state_monthly_v2
  WHERE period_month >= to_char('2025-01-01'::date, 'YYYY-MM')
    AND period_month <= to_char('2025-12-31'::date, 'YYYY-MM')
), prog_h AS (
  SELECT (
    (CASE WHEN p.due=0 THEN 0 ELSE p.on_time::numeric / p.due::numeric * 100 END) * 0.4
    + (CASE WHEN p.ms_t=0 THEN 0 ELSE p.ms_ot::numeric / p.ms_t::numeric * 100 END) * 0.3
    + (100 - (CASE WHEN p.due=0 THEN 0 ELSE (p.abn + p.ov_unc)::numeric / p.due::numeric * 100 END)) * 0.3
  ) AS h FROM p
), qual_h AS (
  SELECT (
    (CASE WHEN q.n=0 THEN 0 ELSE q.z::numeric / q.n::numeric * 100 END) * 0.5
    + (CASE WHEN q.n=0 THEN 0 ELSE (q.n - q.np)::numeric / q.n::numeric * 100 END) * 0.3
    + (100 - (CASE WHEN q.n=0 THEN 0 ELSE q.o::numeric / q.n::numeric * 100 END)) * 0.2
  ) AS h FROM q
), tech_h AS (
  SELECT (
    (CASE WHEN (t.sgn + t.unsgn) = 0 THEN 0
          ELSE t.sgn::numeric / (t.sgn + t.unsgn)::numeric * 100 END) * 0.4
    + (CASE WHEN (t.rd + t.rp) = 0 THEN 0
            ELSE t.rd::numeric / (t.rd + t.rp)::numeric * 100 END) * 0.4
    + (100 - (CASE WHEN t.total = 0 THEN 0
                   ELSE t.unsgn::numeric / t.total::numeric * 100 END)) * 0.2
  ) AS h FROM t
)
SELECT ROUND((prog_h.h * 0.4 + qual_h.h * 0.3 + tech_h.h * 0.3)::numeric, 2) AS "综合健康度"
FROM prog_h, qual_h, tech_h;
```

## 2.27 进度健康度 / 进度健康分

**出现位置**：S1 / S2 / D1  
**对应指标**：二次#6  
**公式**：按时完成率 × 0.4 + 里程碑按时率 × 0.3 + (100 - 异常率) × 0.3

```sql
WITH p AS (
  SELECT
    SUM(due_cnt) AS due,
    SUM(on_time_cnt) AS on_time,
    SUM(milestone_on_time_cnt) AS ms_ot,
    SUM(milestone_total_cnt) AS ms_t,
    SUM(abnormal_pending_non_general_cnt) AS abn,
    SUM(overdue_incomplete_unchanged_non_general_cnt) AS ov_unc
  FROM biz_dws_progress_monthly_v2
  WHERE plan_month >= to_char('2025-01-01'::date, 'YYYY-MM')
    AND plan_month <= to_char('2025-12-31'::date, 'YYYY-MM')
)
SELECT ROUND(
  (CASE WHEN p.due = 0 THEN 0 ELSE p.on_time::numeric / p.due::numeric * 100 END) * 0.4
  + (CASE WHEN p.ms_t = 0 THEN 0 ELSE p.ms_ot::numeric / p.ms_t::numeric * 100 END) * 0.3
  + (100 - (CASE WHEN p.due = 0 THEN 0
                 ELSE (p.abn + p.ov_unc)::numeric / p.due::numeric * 100 END)) * 0.3
, 2) AS "进度健康度"
FROM p;
```

## 2.35 任务执行甘特 (gantt 三层 UNION)

**出现位置**：S2  
**说明**：3 层结构 — 项目级 / 分系统级 / 节点级，UNION 后供甘特图渲染

```sql
-- 项目层
SELECT
  'project'::text AS level,
  project_no AS id,
  NULL::text AS parent_id,
  project_no AS "name",
  COUNT(*) AS "total_cnt",
  SUM(CASE WHEN is_completed THEN 1 ELSE 0 END) AS "completed_cnt",
  SUM(CASE WHEN is_incomplete THEN 1 ELSE 0 END) AS "incomplete_cnt",
  MIN(plan_date) AS "plan_date",
  MAX(plan_date) AS "plan_end",
  MAX(actual_date) AS "actual_date",
  CASE WHEN COUNT(*)=0 THEN 0
       ELSE ROUND(SUM(CASE WHEN is_completed THEN 1 ELSE 0 END)::numeric/COUNT(*)::numeric*100,2)
  END AS "completion_rate",
  NULL::text AS "node_type",
  NULL::text AS "completion_status",
  0 AS sort_order
FROM biz_dwd_project_node_v2

GROUP BY project_no

UNION ALL

-- 分系统层
SELECT
  'subsystem'::text,
  project_no || '|' || COALESCE(subsystem, '(无)'),
  project_no,
  COALESCE(subsystem, '(无分系统)'),
  COUNT(*),
  SUM(CASE WHEN is_completed THEN 1 ELSE 0 END),
  SUM(CASE WHEN is_incomplete THEN 1 ELSE 0 END),
  MIN(plan_date),
  MAX(plan_date),
  MAX(actual_date),
  CASE WHEN COUNT(*)=0 THEN 0
       ELSE ROUND(SUM(CASE WHEN is_completed THEN 1 ELSE 0 END)::numeric/COUNT(*)::numeric*100,2)
  END,
  NULL,
  NULL,
  1
FROM biz_dwd_project_node_v2
WHERE plan_date BETWEEN '2025-01-01'::date AND '2025-12-31'::date
GROUP BY project_no, subsystem

UNION ALL

-- 节点层
SELECT
  'node'::text,
  node_id,
  project_no || '|' || COALESCE(subsystem, '(无)'),
  node_task,
  1,
  CASE WHEN is_completed THEN 1 ELSE 0 END,
  CASE WHEN is_incomplete THEN 1 ELSE 0 END,
  plan_date,
  plan_date,
  actual_date,
  CASE WHEN is_completed THEN 100.00 ELSE 0.00 END,
  node_type,
  completion_status,
  2
FROM biz_dwd_project_node_v2
```

## 3.13 质量健康度 / 质量健康分

**出现位置**：S1 / S3 / D2  
**对应指标**：二次#11  
**公式**：归零率 × 0.5 + 计划提交率 × 0.3 + (100 - 现存率) × 0.2

```sql
WITH q AS (
  SELECT
    SUM(new_issue_cnt) AS n,
    SUM(open_issue_cnt) AS o,
    SUM(zero_completed_cnt) AS z,
    SUM(no_zero_plan_cnt) AS np
  FROM biz_dws_quality_monthly_v2
  WHERE period_month >= to_char('2025-01-01'::date, 'YYYY-MM')
    AND period_month <= to_char('2025-12-31'::date, 'YYYY-MM')
)
SELECT ROUND(
  (CASE WHEN q.n = 0 THEN 0 ELSE q.z::numeric / q.n::numeric * 100 END) * 0.5
  + (CASE WHEN q.n = 0 THEN 0 ELSE (q.n - q.np)::numeric / q.n::numeric * 100 END) * 0.3
  + (100 - (CASE WHEN q.n = 0 THEN 0 ELSE q.o::numeric / q.n::numeric * 100 END)) * 0.2
, 2) AS "质量健康度"
FROM q;
```

## 4.24 技术状态健康度 / 技术状态健康分

**出现位置**：S1 / S4 / D3  
**对应指标**：二次#16  
**公式**：签署完成率 × 0.4 + 整改完成率 × 0.4 + (100 - 未签署比率) × 0.2

```sql
WITH t AS (
  SELECT
    SUM(total_change_cnt) AS total,
    SUM(order_signed_cnt) AS sgn,
    SUM(order_unsigned_cat_i) + SUM(order_unsigned_cat_ii) + SUM(order_unsigned_cat_iii) AS unsgn,
    SUM(reform_done_i_ii) AS rd,
    SUM(reform_pending_i_ii) AS rp
  FROM biz_dws_tech_state_monthly_v2
  WHERE period_month >= to_char('2025-01-01'::date, 'YYYY-MM')
    AND period_month <= to_char('2025-12-31'::date, 'YYYY-MM')
)
SELECT ROUND(
  (CASE WHEN (t.sgn + t.unsgn) = 0 THEN 0
        ELSE t.sgn::numeric / (t.sgn + t.unsgn)::numeric * 100 END) * 0.4
  + (CASE WHEN (t.rd + t.rp) = 0 THEN 0
          ELSE t.rd::numeric / (t.rd + t.rp)::numeric * 100 END) * 0.4
  + (100 - (CASE WHEN t.total = 0 THEN 0
                 ELSE t.unsgn::numeric / t.total::numeric * 100 END)) * 0.2
, 2) AS "技术状态健康度"
FROM t;
```

## C. 常见问题排查

### Q1: 某个指标返回 NULL 而不是 0
原因：DWS 表中没有对应月份的行。SUM 在空集上返回 NULL。
解决：用 `COALESCE(SUM(...), 0)` 包一层。例如：

```sql
SELECT COALESCE(SUM(on_time_cnt), 0) AS "节点按时完成数" FROM ...
```

### Q2: 同一 KPI 在 S1 和 S2 数字不一致
查看 `worklog/v2.2.3/s10/pjm/v2/screen-instances/` 下两个 dashboard JSON 中相同 component title 的 SQL 是否一致。当前已知存在 2 处不一致，已通过本文档统一口径。

### Q3: 想看某个项目 / 部门的数据
所有 SQL 末尾添加：
```sql
... AND project_no = 'PJ-2025-001'
... AND dept = '电子室'
```

### Q4: 想按月细分 / 按项目细分
- 按月：在 SELECT 加 `plan_month` 或 `period_month`，末尾加 `GROUP BY plan_month ORDER BY plan_month`
- 按项目：在 SELECT 加 `project_no`，末尾加 `GROUP BY project_no`
