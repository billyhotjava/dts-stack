# 项目管理指标计算原理

## 数据流转

```
Excel → 入湖(Addax) → ODS 表(ods_project_subject_domain)
  → DWD(biz_dwd_project_node) → DWS(biz_dws_period_node_summary)
    → ADS(biz_ads_project_kpi_overview 等 4 张 KPI 表)
      → 查询卡片 → 大屏组件
```

## 关键枚举值

### 完成情况（7 种）

| 完成情况 | is_completed | is_on_time | is_overdue_completed | is_incomplete |
|---------|:---:|:---:|:---:|:---:|
| 正常待完成 | ✗ | ✗ | ✗ | ✗ |
| 按时完成 | ✓ | ✓ | ✗ | ✗ |
| 超期已完成已变更 | ✓ | ✗ | ✓ | ✗ |
| 超期已完成未变更 | ✓ | ✗ | ✓ | ✗ |
| 不正常待变更 | ✗ | ✗ | ✗ | ✓ |
| 超期未完成未变更 | ✗ | ✗ | ✗ | ✓ |
| 超期未完成已变更 | ✗ | ✗ | ✗ | ✓ |

### 节点类型（4 种）

| 节点类型 | is_general |
|---------|:---:|
| 一般节点 | ✓ |
| 重要节点 | ✗ |
| 重大节点 | ✗ |
| 里程碑节点 | ✗ |

### 风险等级

高、中、低

## 第一组：项目（含一般节点）— 14 个指标

**ADS 表：** `biz_ads_project_kpi_overview`
**查询卡片：** `card-execution-kpi-overview.sql`
**大屏：** S1 综合态势、S2 执行监控

| # | 指标 | 字段 | 计算公式 | 大屏组件 |
|---|------|------|---------|---------|
| 1 | 本周期节点总数 | `total_cnt` | 节点计划时间在周期内的节点 COUNT(*) | S1 KPI卡片、S2 KPI卡片 |
| 2 | 正常待完成 | `pending_normal_cnt` | 完成情况="正常待完成" 的节点数 | S2 KPI卡片 |
| 3 | 已到时间节点数 | `due_cnt` | **total_cnt - pending_normal_cnt** | 完成率分母的一部分 |
| 4 | 本周期以外完成数 | `outside_completed_cnt` | 实际完成时间在周期内，但计划时间不在周期内的已完成节点数 | 完成率分母的一部分 |
| 5 | 未完成总数 | `incomplete_cnt` | 完成情况∈{不正常待变更, 超期未完成未变更, 超期未完成已变更} | S2 KPI卡片 |
| 6 | 按时完成数 | `on_time_cnt` | 完成情况="按时完成" | S2 KPI卡片 |
| 7 | 超期完成数 | `overdue_completed_cnt` | 完成情况∈{超期已完成已变更, 超期已完成未变更} | S2 KPI卡片 |
| 8 | 完成总数 | `completed_total_cnt` | **on_time_cnt + overdue_completed_cnt + outside_completed_cnt** | S1 KPI卡片 |
| 9 | 完成百分比 | `completion_rate` | **completed_total_cnt / (due_cnt + outside_completed_cnt)** | S1 KPI"完成率"、S2 KPI"整体完成率" |
| 10 | 按时完成百分比 | `on_time_rate` | **on_time_cnt / (due_cnt + outside_completed_cnt)** | S2 图表 |
| 11 | 超期完成百分比 | `overdue_completion_rate` | **(overdue_completed_cnt + outside_completed_cnt) / (total_cnt + outside_completed_cnt)** | S2 图表 |
| 12 | 不正常待变更数 | `abnormal_pending_cnt` | 完成情况="不正常待变更" | S2 图表 |
| 13 | 超期未完成未变更数 | `overdue_incomplete_unchanged_cnt` | 完成情况="超期未完成未变更" | S2 图表 |
| 14 | 超期未完成已变更数 | `overdue_incomplete_changed_cnt` | 完成情况="超期未完成已变更" | S2 图表 |

### 核心公式图解

```
                         ┌─ 按时完成(on_time)
            ┌─ 已完成 ─┤
            │            └─ 超期完成(overdue_completed)
本周期节点 ─┤
            │            ┌─ 不正常待变更(abnormal)
            ├─ 未完成 ─┤─ 超期未完成未变更(unchanged)
            │            └─ 超期未完成已变更(changed)
            │
            └─ 正常待完成(pending_normal) ← 还没到期的节点

完成率分母 = 已到时间(due) + 以外完成(outside)
           = (总数 - 正常待完成) + 以外完成
```

## 第二组：项目（除一般节点）— 6 个指标

**ADS 表：** `biz_ads_project_non_general_kpi`
**查询卡片：** `card-non-general-kpi.sql`
**大屏：** S2 执行监控（阶段分布）

| # | 指标 | 字段 | 计算公式 | 大屏组件 |
|---|------|------|---------|---------|
| 15 | 不正常待变更数（除一般） | `abnormal_pending_cnt` | 排除 node_type="一般节点" 后统计 | S2 阶段分布图 |
| 16 | 超期未完成未变更（除一般） | `overdue_incomplete_unchanged_cnt` | 同上 | S2 阶段分布图 |
| 17 | 超期未完成已变更（除一般） | `overdue_incomplete_changed_cnt` | 同上 | S2 阶段分布图 |
| 18 | 超期已完成未变更（除一般） | `overdue_completed_unchanged_cnt` | 同上 | S2 阶段分布图 |
| 19 | 不正常待变更百分比 | `abnormal_rate` | **(abnormal + unchanged) / due_cnt_non_general** | S2 指标 |
| 20 | 节点超期百分比 | `overdue_rate` | **(unchanged + changed) / due_cnt_non_general** | S2 指标 |

其中 `due_cnt_non_general = total_cnt（除一般） - pending_normal_cnt（除一般）`

## 第四组：本周期内节点统计 — 11 个指标

**ADS 表：** `biz_ads_project_milestone_kpi`
**查询卡片：** `card-milestone-kpi.sql`
**大屏：** S2 执行监控

| # | 指标 | 字段 | 计算公式 | 大屏组件 |
|---|------|------|---------|---------|
| 26 | 里程碑按时完成数 | `milestone_on_time_cnt` | 里程碑节点 且 按时完成 | S2 KPI卡片"里程碑达成率" |
| 27 | 里程碑超期完成数 | `milestone_overdue_completed_cnt` | 里程碑节点 且 超期完成 | S2 图表 |
| 28 | 里程碑正常待完成数 | `milestone_pending_cnt` | 里程碑节点 且 正常待完成 | S2 图表 |
| 29 | 里程碑未完成数 | `milestone_incomplete_cnt` | 里程碑节点 且 is_incomplete | S2 图表 |
| 30 | 里程碑完成百分比 | `milestone_completion_rate` | **(on_time + overdue) / (incomplete + on_time + overdue)** | S2 KPI卡片 |
| 31 | 高风险节点数 | `high_risk_cnt` | risk_level="高"（不限完成状态） | S2 KPI卡片 |
| 32 | 中风险节点数 | `mid_risk_cnt` | risk_level="中" | S2 图表 |
| 33 | 里程碑节点总数 | `milestone_total_cnt` | node_type="里程碑节点" | S2 图表 |
| 34 | 重大节点总数 | `major_total_cnt` | node_type="重大节点" | S2 图表 |
| 35 | 重要节点总数 | `important_total_cnt` | node_type="重要节点" | S2 图表 |

### 里程碑完成率公式说明

```
分子 = 里程碑按时完成 + 里程碑超期完成
分母 = 里程碑未完成 + 里程碑按时完成 + 里程碑超期完成

注意：分母排除了"正常待完成"的里程碑节点
      即：只看已有结果（完成或未完成）的里程碑，不看还没到期的
```

## 项目概览指标

**ADS 表：** `biz_ads_major_project_overview`
**查询卡片：** `card-major-project-overview.sql`
**大屏：** S1 项目状态表、S1 健康度仪表盘

| 指标 | 字段 | 计算公式 | 大屏组件 |
|------|------|---------|---------|
| 节点总数 | `total_nodes` | 该项目下所有节点 COUNT | S1 状态表 |
| 已完成节点 | `completed_nodes` | is_completed=true | S1 状态表 |
| 超期未完成 | `overdue_open_nodes` | is_incomplete=true | S1 状态表 |
| 高风险节点 | `high_risk_nodes` | risk_level="高" | S1 状态表 |
| 平均健康度 | `avg_health_score` | 0-100分综合评分 | S1 健康度仪表盘 |
| 平均延期天数 | `avg_delay_days` | AVG(actual_date - plan_date) | S1 状态表 |
| 最大延期天数 | `max_delay_days` | MAX(delay_days) | S2 KPI"最大延期" |
| 完成率 | `completion_rate` | completed / total | S1 状态表 |
| 里程碑完成率 | `milestone_completion_rate` | 里程碑已完成 / 里程碑总数 | S1 状态表 |

## 延期原因趋势

**ADS 表：** `biz_ads_delay_reason_trend`
**查询卡片：** `card-delay-reason-trend.sql`
**大屏：** S1 延期TOP5、S2 延期TOP10、下钻-执行

| 指标 | 字段 | 计算公式 | 大屏组件 |
|------|------|---------|---------|
| 延期原因 | `delay_reason_category` | 自动分类（技术/质量/变更/协调/供方/试验/归档/正常） | S1 延期TOP5 |
| 延期节点数 | `delayed_node_count` | 该原因+该周的延期节点数 | S2 延期TOP10 |
| 高风险节点数 | `high_risk_node_count` | 该原因+该周的高风险节点数 | 下钻-执行 |
