# v2 指标计算原理

> 本文档对照 metrics/ 目录下的 Excel 指标定义，逐一说明每个指标在 dbt 模型中的实现方式。
> 数据流: ODS(原始表) → DWD(明细宽表) → DWS(月度聚合) → ADS(KPI/二次指标) → Card查询(大屏)

---

## 一、数据分层概览

| 层 | 表名 | 粒度 | 用途 |
|----|------|------|------|
| DWD | `biz_dwd_project_node_v2` | 每个节点 | 进度明细，关联 dim_completion_status / dim_node_type |
| DWD | `biz_dwd_quality_issue_v2` | 每个问题 | 质量明细，关联 dim_quality_status |
| DWD | `biz_dwd_tech_state_v2` | 每个更改项 | 技术状态明细 |
| DWD | `biz_dwd_risk_info_v2` | 每个风险 | 风险明细 |
| DWS | `biz_dws_progress_monthly_v2` | project_no × plan_month | 进度域月度聚合 (#1-33) |
| DWS | `biz_dws_quality_monthly_v2` | project_no × dept × issue_month | 质量域月度聚合 (#34-48) |
| DWS | `biz_dws_tech_state_monthly_v2` | project_no × dept × submit_month | 技术状态月度聚合 (#49-67) |
| DWS | `biz_dws_risk_monthly_v2` | project_no × dept × submit_month | 风险域月度聚合 |

## 二、关键维度表

### dim_completion_status_v2 — 完成情况枚举

| 完成情况 | is_completed | is_on_time | is_overdue_completed | is_incomplete |
|---------|:---:|:---:|:---:|:---:|
| 正常待完成 | - | - | - | - |
| 按时完成 | ✓ | ✓ | - | - |
| 超期已完成已变更 | ✓ | - | ✓ | - |
| 超期已完成未变更 | ✓ | - | ✓ | - |
| 不正常待变更 | - | - | - | ✓ |
| 超期未完成未变更 | - | - | - | ✓ |
| 超期未完成已变更 | - | - | - | ✓ |

> 注: "正常待完成"既不算完成也不算未完成（节点尚未到期）。

## 三、进度域原始指标 (#1-33)

**数据来源:** `biz_dws_progress_monthly_v2` ← `biz_dwd_project_node_v2`

### 项目（含一般节点）#1-11

| # | 指标名称 | Excel 定义 | DWS 字段 | SQL 实现 |
|---|---------|-----------|---------|---------|
| 1 | 项目本周期节点总数 | 节点计划时间在开始和结束时间内的项目节点总数 | `total_cnt` | `COUNT(*)` WHERE plan_month in range |
| 2 | 正常待完成 | 完成情况为"正常待完成"的节点数 | `pending_normal_cnt` | `SUM(CASE WHEN completion_status='正常待完成')` |
| 3 | 已到时间节点总数 | #1 - #2 | `due_cnt` | `COUNT(*) - SUM(正常待完成)` |
| 4 | 周期以外完成节点总数 | 实际完成时间在周期内但计划时间不在周期内的节点 | `outside_completed_cnt` | LEFT JOIN outside_completed CTE: actual_month在周期内 AND (plan_year≠actual_year OR plan_month≠actual_month) |
| 5 | 未完成总数 | 完成情况为"不正常待变更"+"超期未完成未变更"+"超期未完成已变更" | `incomplete_cnt` | `SUM(CASE WHEN is_incomplete)` |
| 6 | 按时完成数 | 完成情况为"按时完成" | `on_time_cnt` | `SUM(CASE WHEN is_on_time)` |
| 7 | 超期完成数 | 完成情况为"超期已完成已变更"+"超期已完成未变更" | `overdue_completed_cnt` | `SUM(CASE WHEN is_overdue_completed)` |
| 8 | 完成总数 | #4 + #6 + #7 | `completed_total_cnt` | `on_time_cnt + overdue_completed_cnt + outside_completed_cnt` |
| 9 | 完成百分比 | #8 / (#3 + #4) | Card 层计算 | `completed_total_cnt / (due_cnt + outside_completed_cnt) * 100` |
| 10 | 按时完成百分比 | #6 / (#3 + #4) | Card 层计算 | `on_time_cnt / (due_cnt + outside_completed_cnt) * 100` |
| 11 | 超期完成百分比 | (#7 + #4) / (#1 + #4) | Card 层计算 | `(overdue_completed_cnt + outside_completed_cnt) / (total_cnt + outside_completed_cnt) * 100` |

### 项目（除一般节点）#12-17

> 这些指标排除 `node_type='一般节点'` (is_general_node=true)。参见 TBD-1。

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 12 | 不正常待变更节点数 | `abnormal_pending_non_general_cnt` | `SUM(CASE WHEN completion_status='不正常待变更' AND NOT is_general_node)` |
| 13 | 超期未完成未变更 | `overdue_incomplete_unchanged_non_general_cnt` | `SUM(CASE WHEN completion_status='超期未完成未变更' AND NOT is_general_node)` |
| 14 | 超期未完成已变更 | `overdue_incomplete_changed_non_general_cnt` | `SUM(CASE WHEN completion_status='超期未完成已变更' AND NOT is_general_node)` |
| 15 | 超期已完成未变更 | `overdue_completed_unchanged_non_general_cnt` | `SUM(CASE WHEN completion_status='超期已完成未变更' AND NOT is_general_node)` |
| 16 | 异常率 | Card 层计算 | `(#12 + #13) / #3 * 100` |
| 17 | 超期率 | Card 层计算 | `(#13 + #14) / #3 * 100` |

### 未完成节点分类 #18-22

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 18 | 未完成高风险 | `incomplete_high_risk_cnt` | `SUM(CASE WHEN is_incomplete AND risk_level='高')` |
| 19 | 未完成中风险 | `incomplete_mid_risk_cnt` | `SUM(CASE WHEN is_incomplete AND risk_level='中')` |
| 20 | 未完成里程碑 | `incomplete_milestone_cnt` | `SUM(CASE WHEN is_incomplete AND node_type='里程碑节点')` |
| 21 | 未完成重大 | `incomplete_major_cnt` | `SUM(CASE WHEN is_incomplete AND node_type='重大节点')` |
| 22 | 未完成重要 | `incomplete_important_cnt` | `SUM(CASE WHEN is_incomplete AND node_type='重要节点')` |

### 里程碑与节点统计 #23-33

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 23 | 里程碑按时完成数 | `milestone_on_time_cnt` | `SUM(CASE WHEN node_type='里程碑节点' AND is_on_time)` |
| 24 | 里程碑超期完成数 | `milestone_overdue_completed_cnt` | `SUM(CASE WHEN node_type='里程碑节点' AND is_overdue_completed)` |
| 25 | 里程碑正常待完成 | `milestone_pending_cnt` | `SUM(CASE WHEN node_type='里程碑节点' AND completion_status='正常待完成')` |
| 26 | 里程碑完成率 | Card 层计算 | `(#23 + #24) / (#20 + #23 + #24) * 100` |
| 27 | 高风险节点数 | `high_risk_cnt` | `SUM(CASE WHEN risk_level='高')` — 全量，非仅未完成 |
| 28 | 中风险节点数 | `mid_risk_cnt` | `SUM(CASE WHEN risk_level='中')` |
| 29 | 里程碑总数 | `milestone_total_cnt` | `SUM(CASE WHEN node_type='里程碑节点')` |
| 30 | 重大节点总数 | `major_total_cnt` | `SUM(CASE WHEN node_type='重大节点')` |
| 31 | 重要节点总数 | `important_total_cnt` | `SUM(CASE WHEN node_type='重要节点')` |
| 32 | 里程碑按时完成率 | Card 层计算 | `#23 / #29 * 100` |
| 33 | 里程碑超期完成率 | Card 层计算 | `#24 / #29 * 100` |

### DWD 衍生字段

| 字段 | 计算逻辑 |
|------|---------|
| `delay_days` | 已完成: `actual_date - plan_date`; 未完成且已逾期: `current_date - plan_date` |
| `is_due` | `plan_date <= current_date` |
| `node_id` | `md5(project_no \| subsystem \| node_task \| plan_date)` |

## 四、质量域原始指标 (#34-48)

**数据来源:** `biz_dws_quality_monthly_v2` ← `biz_dwd_quality_issue_v2`

**聚合粒度:** project_no × dept × issue_month

| # | 指标名称 | Excel 定义 | DWS 字段 | SQL 实现 |
|---|---------|-----------|---------|---------|
| 34 | 新增质量问题数 | 发生时间在周期内的问题数 | `new_issue_cnt` | `COUNT(*)` |
| 35 | 现存质量问题数 | status='未完成归零' | `open_issue_cnt` | `SUM(CASE WHEN status='未完成归零')` |
| 36 | 已完成技术归零 | 技术归零且非双归零 | `tech_zero_cnt` | `SUM(CASE WHEN is_tech_zero AND NOT is_both_zero)` |
| 37 | 已完成管理归零 | 管理归零且非双归零 | `mgmt_zero_cnt` | `SUM(CASE WHEN is_mgmt_zero AND NOT is_both_zero)` |
| 38 | 已完成双归零 | 技术+管理同时归零 | `both_zero_cnt` | `SUM(CASE WHEN is_both_zero)` |
| 39 | 已完成归零合计 | #36 + #37 + #38 | `zero_completed_cnt` | `SUM(CASE WHEN is_zero_completed)` |
| 40 | 未提交归零计划 | 归零计划为空/"无" (TBD-2) | `no_zero_plan_cnt` | `SUM(CASE WHEN NOT has_zero_plan)` |

### 问题分类 #41-48 (限定 status='未完成归零', TBD-3)

| # | 分类 | DWS 字段 | SQL 实现 |
|---|------|---------|---------|
| 41 | 设计 | `open_cat_design` | `SUM(CASE WHEN status='未完成归零' AND issue_category='设计')` |
| 42 | 工艺 | `open_cat_process` | 同上，issue_category='工艺' |
| 43 | 管理 | `open_cat_management` | issue_category='管理' |
| 44 | 元器件 | `open_cat_component` | issue_category='元器件' |
| 45 | 操作 | `open_cat_operation` | issue_category='操作' |
| 46 | 外协外购 | `open_cat_outsource` | issue_category='外协外购' |
| 47 | 软件 | `open_cat_software` | issue_category='软件' |
| 48 | 其他 | `open_cat_other` | issue_category NOT IN 以上 7 类 |

### DWD 衍生字段

| 字段 | 计算逻辑 |
|------|---------|
| `has_zero_plan` | `zero_plan` 非空且不等于 "无" (TBD-2) |
| `pending_days` | 未归零: `current_date - issue_date`; 已归零: 0 |
| `is_zero_completed` / `is_tech_zero` / `is_mgmt_zero` / `is_both_zero` | 由 `dim_quality_status_v2` 维度表映射 |

## 五、技术状态域原始指标 (#49-67)

**数据来源:** `biz_dws_tech_state_monthly_v2` ← `biz_dwd_tech_state_v2`

**聚合粒度:** project_no × dept × submit_month

### 更改类别 #49-51

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 49 | 新增 I 类更改 | `new_cat_i` | `SUM(CASE WHEN change_category='I')` |
| 50 | 新增 II 类更改 | `new_cat_ii` | change_category='II' |
| 51 | 新增 III 类更改 | `new_cat_iii` | change_category='III' |

> DWD 层对 change_category 做了标准化: I/Ⅰ/I类/1/一 → 'I'

### 文件签署状态 #52-59 (TBD-4)

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 52 | 已提出未评审(I,II类) | `file_submitted_not_reviewed_i_ii` | `SUM(CASE WHEN change_category IN ('I','II') AND file_signature_status='已提出需求，未评估评审')` |
| 53 | 已评审未签署(I,II类) | `file_reviewed_not_signed_i_ii` | file_signature_status='已评估评审，未签署' |
| 54 | 已评审已签署(I,II类) | `file_reviewed_signed_i_ii` | file_signature_status='已评估评审，已签署' |
| 55 | 已提出未签署(III类) | `file_submitted_not_signed_iii` | change_category='III' AND file_signature_status='已提出需求，未签署' |
| 56 | 已提出已签署(III类) | `file_submitted_signed_iii` | file_signature_status='已提出需求，已签署' |
| 57 | 文件未签署(I,II类) | Card 层计算 | `#52 + #53` |
| 58 | 文件未签署(III类) | = #55 (TBD-5: 重复) | `#55` |
| 59 | 文件已签署(合计) | Card 层计算 | `#54 + #56` |

### 变更单签署 #60-64

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 60 | 变更单未签署(I类) | `order_unsigned_cat_i` | `SUM(CASE WHEN change_category='I' AND NOT is_signature_completed)` |
| 61 | 变更单未签署(II类) | `order_unsigned_cat_ii` | change_category='II' |
| 62 | 变更单未签署(III类) | `order_unsigned_cat_iii` | change_category='III' |
| 63 | 变更单未签署(合计) | Card 层计算 | `#60 + #61 + #62` |
| 64 | 变更单已签署 | `order_signed_cnt` | `SUM(CASE WHEN is_signature_completed)` |

> `is_signature_completed` = DWD 层判断: completion_signature = '是'

### 整改落实 #65-67

| # | 指标名称 | DWS 字段 | SQL 实现 |
|---|---------|---------|---------|
| 65 | 未落实整改(I,II类) | `reform_pending_i_ii` | `SUM(CASE WHEN change_category IN ('I','II') AND reform_status NOT IN ('已落实整改','不涉及',''))` |
| 66 | 已落实整改(I,II类) | `reform_done_i_ii` | reform_status='已落实整改' |
| 67 | 不涉及整改(III类) | `reform_na_iii` | change_category='III' AND reform_status='不涉及' |

## 六、风险域指标

**数据来源:** `biz_dws_risk_monthly_v2` ← `biz_dwd_risk_info_v2`

**聚合粒度:** project_no × dept × submit_month

| 指标名称 | DWS 字段 | SQL 实现 |
|---------|---------|---------|
| 风险总数 | `total_risk_cnt` | `COUNT(*)` |
| 高风险 | `high_cnt` | `SUM(CASE WHEN risk_level='高')` |
| 中风险 | `mid_cnt` | risk_level='中' |
| 低风险 | `low_cnt` | risk_level='低' |
| 已释放 | `released_cnt` | `SUM(CASE WHEN is_released)` |
| 未释放 | `open_cnt` | `SUM(CASE WHEN NOT is_released)` |
| 释放率 | Card 层计算 | `released_cnt / total_risk_cnt * 100` |

> DWD 层: `is_released` = risk_status = '已释放'
> DWD 层: `risk_rank` = 高→3, 中→2, 低→1 (用于排序)

## 七、二次指标 (Tier 2 / Derived)

> 二次指标从 DWS 层实时聚合计算（非读 ADS derived 表），以支持 project/dept 维度筛选。

### 进度域二次指标 (6 个)

| # | 指标名称 | 公式 | 预警阈值 |
|---|---------|------|---------|
| 二次#1 | 节点按时完成率 | `on_time / due * 100` | < 80% |
| 二次#2 | 节点超期率 | `(overdue_unchanged + overdue_changed) / due * 100` | > 15% |
| 二次#3 | 节点不正常率 | `(abnormal + overdue_unchanged) / due * 100` | > 20% |
| 二次#4 | 里程碑按时完成率 | `ms_on_time / ms_total * 100` | < 90% |
| 二次#5 | 高风险未完成占比 | `hi_incomplete / incomplete * 100` | > 30% |
| 二次#6 | 进度健康度 | `按时完成率*0.4 + 里程碑按时率*0.3 + (100-不正常率)*0.3` | < 70 |

### 质量域二次指标 (5 个)

| # | 指标名称 | 公式 | 预警阈值 |
|---|---------|------|---------|
| 二次#7 | 归零率 | `zero_cnt / new_cnt * 100` | < 60% |
| 二次#8 | 现存问题比率 | `open_cnt / new_cnt * 100` | > 50% |
| 二次#9 | 归零计划提交率 | `(new_cnt - no_plan_cnt) / new_cnt * 100` | < 80% |
| 二次#10 | 设计类问题占比 | `design_cnt / open_cnt * 100` | > 40% |
| 二次#11 | 质量健康度 | `归零率*0.5 + 计划提交率*0.3 + (100-现存比率)*0.2` | < 70 |

### 技术状态域二次指标 (5 个)

| # | 指标名称 | 公式 | 预警阈值 |
|---|---------|------|---------|
| 二次#12 | 签署完成率 | `signed / (signed + unsigned) * 100` | < 80% |
| 二次#13 | 整改完成率 | `reform_done / (reform_done + reform_pending) * 100` | < 80% |
| 二次#14 | I类更改占比 | `cat_i / total * 100` | > 30% |
| 二次#15 | 未签署比率 | `unsigned / total * 100` | > 20% |
| 二次#16 | 技术状态健康度 | `签署完成率*0.4 + 整改完成率*0.4 + (100-未签署率)*0.2` | < 70 |

### 综合域二次指标 (2 个)

| # | 指标名称 | 公式 | 预警阈值 |
|---|---------|------|---------|
| 二次#17 | 项目综合健康度 | `进度健康分*0.4 + 质量健康分*0.3 + 技术健康分*0.3` | <70红, <80黄 |
| 二次#18 | 风险预警指数 | `未完成里程碑*3 + 未完成高风险*2 + 超期未变更*1` | >10黄, >20红 |

## 八、健康度权重矩阵

```
综合健康度 = 进度(40%) + 质量(30%) + 技术状态(30%)

进度健康度 = 按时完成率(40%) + 里程碑按时率(30%) + (100-不正常率)(30%)
质量健康度 = 归零率(50%) + 计划提交率(30%) + (100-现存比率)(20%)
技术健康度 = 签署完成率(40%) + 整改完成率(40%) + (100-未签署率)(20%)
```

## 十、跨月查询语义 (TBD-7)

当查询范围跨多个月时 (如 2026-01 ~ 2026-03):

| 指标类型 | 聚合方式 | 说明 |
|---------|---------|------|
| 计数类 (total_cnt, on_time_cnt 等) | `SUM()` | 直接累加 |
| 比率类 (完成率、归零率等) | 重算 | `SUM(分子) / SUM(分母) * 100` |
| 状态类 (现存问题数 #35) | 取最新月快照 | 当前实现为 SUM，待确认 (TBD-7) |
