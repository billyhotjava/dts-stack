# T02: Addax 入湖功能回归

**优先级**: P0
**状态**: READY
**依赖**: F1, F2

## 目标

证明加密改造不影响 Addax 入湖：相同 Excel/CSV 在加密前后入湖到 ODS 的结果（行数、字段、类型、内容）完全一致。

## 测试先行（RED）

- 基线：用改造前版本（或明文对照）入湖一个标准样例，记录 ODS 表行数/列/抽样内容。
- 断言：改造后入湖同一文件，ODS 结果与基线逐项一致（行数相等、字段映射相同、抽样行内容相同）。
- 断言：多 sheet / 中文表头 / 含特殊字符 / 大文件（百万行评估）入湖均成功。
- 断言：DAG run 状态 success，无因解密引入的超时/失败；Addax 日志无明文路径泄露到 bind 日志。

## 技术设计（验证手段）

- 复用 `tests/` 既有入湖 E2E 框架（api-e2e / web-e2e）扩展加密样例用例。
- 对照表：加密前后 ODS 快照 diff。
- 证据归档 `it/evidence/addax-regression/`。

## 影响范围
