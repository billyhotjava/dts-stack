# T03: 异常与边界

**优先级**: P0
**状态**: READY
**依赖**: F1, F2

## 目标

覆盖密钥缺失、解密失败、大文件、并发入湖、作业失败等异常路径，确保任何情况下都不泄露/不残留明文、不绕过加密。

## 测试先行（RED）

- 密钥缺失：上传被 F1 拒绝（无文件落地）；若 env 漂移导致 runner 缺密钥，作业失败且无明文产出。
- 解密失败：损坏 `.enc`（截断/改字节）→ 作业失败，TMPDIR 与 bind 均无明文。
- 大文件：>100MB Excel/CSV 加密上传 + 解密入湖成功，tmpfs size 上限策略生效（超限明确报错，不溢出落盘）。
- 并发：多任务同时入湖，各自 tmpfs 明文互不串、各自作业结束即焚。
- 作业中断/失败：DAG 失败或容器被杀，明文不残留（容器 tmpfs 随 auto_remove 消失；bind 本就无明文）。

## 技术设计（验证手段）

- 异常用例脚本 `it/verify-edge-cases.sh`，在真实 compose 跑。
- 并发用例触发 N 个入湖任务，作业后扫描磁盘与残留容器。
- 证据归档 `it/evidence/edge-cases/`。
