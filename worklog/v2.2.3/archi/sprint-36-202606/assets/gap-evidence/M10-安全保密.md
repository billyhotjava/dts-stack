## 二、各子项核验

### 2.3.2.10-1 机密级安全保密设计开发 —— 🟡 部分

**已具备的技术构件(真实证据):**
- 密级数据隔离:`DataLevelSqlHelper.java`(行级密级过滤)、`dts-common/.../security/SecurityLevelCatalog.java`(密级目录,含「机密级」映射到 `DATA_CONFIDENTIAL/CORE/TOP_SECRET` 一档,line 112)。
- 错误屏蔽:`dts-platform/.../web/rest/errors/ExceptionTranslator.java`(RFC7807;`getCustomizedErrorDetails` 对含包名的运行时异常回落 "Unexpected runtime exception",`HttpMessageConversionException` 回落 "Unable to convert http message",避免堆栈/内部路径外泄);`dts-admin` 同款;`dts-ingestion/.../web/rest/ApiExceptionHandler.java`;`dts-analytics/.../errors/GlobalExceptionHandler.java`。
- 密钥/加密:`dts-platform/.../service/modeling/DataStandardCrypto.java`(AES/GCM/NoPadding,128/256 位密钥,SecureRandom IV)、`service/infra/InfraSecretService.java`(数据源密钥 AES-GCM,密钥取自 `dts.platform.infra.encryption-key` 配置)、`dts-ingestion/.../service/infra/InfraSettingsCryptoService.java`。
- TLS:`application-tls.yml` 配置 TLSv1.2 + ECDHE 套件 + HTTP/2。
- 会话控制:`dts-platform/.../security/session/PortalSessionInactivityFilter.java`、`PortalSessionRegistry.java`、`PortalSessionCookieService.java`;`dts-admin/.../web/filter/SessionInactivityFilter.java`、`security/session/AdminSessionRegistry.java`;超时 `application.yml:340 timeout-minutes=30`。

**缺口(对照 BMB17.x-2024 机密级):**
1. **无任何 BMB17.1/17.2-2024 设计符合性映射**:全仓 grep `BMB17 / BMB17.1 / BMB17.2 / 17.x-2024 / 分级保护 / 离线测评 / 在线测评 / 安全检测` 在 `source/` 与 `worklog/` 均**未命中机密级合规文档/控制项对照表**。`SecurityBaselineService` 的 6 项自查表面向「甲方安全基线」笼统描述,**未对齐 BMB17.x 机密级控制条款**。
2. **国密(GM/T)合规缺位**:传输用 TLSv1.2 国际套件(`application-tls.yml`),证书为 JHipster 自签 `keystore.p12`;数据加密为 AES-GCM。机密级涉密系统通常要求国密 SM2/SM3/SM4 与 GM TLS。**未见 SM2/SM3/SM4 落地**(PKI 验签经厂商 Koal SVS 网关可走 SM2,但平台自身存储/传输加密仍为国际算法)。
3. 密钥管理为单密钥 + 配置注入,`InfraSecretService` 在密钥未配置时**告警后明文落库**(`PLAINTEXT` 版本,line 47/65/68),无密钥轮换/分级/KMS。
