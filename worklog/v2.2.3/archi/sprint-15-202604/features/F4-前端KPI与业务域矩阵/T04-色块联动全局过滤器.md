# T04: 色块联动全局过滤器

**优先级**: P0
**状态**: READY
**依赖**: T03

## 目标

把 `DomainMatrix.onSelect` 接到 `WorkbenchFilterBar` 的同一 `value`/`onChange` 通路上，让色块点击等同于"业务域下拉切换"：整屏刷新、KPI 变更、TOP 报表变更、资产块变更。

## 技术设计

该 task 没有新组件，核心是**状态路由约定**：`LeaderOverviewPage`（F5/T04 的壳）持有 `filterState: WorkbenchFilterState`，DomainMatrix 的 onSelect 直接对接 `setFilterState`：

```tsx
// 伪代码（F5/T04 中实现，但本 task 约束接线方式）
const [filter, setFilter] = useState(initialFilterState(roleInfo));

<DomainMatrix
  visible={roleInfo.isInstLeader && filter.bizDomainAvailable}
  cells={data?.domainMatrix ?? []}
  activeDomain={filter.bizDomain}
  onSelect={(domain) => {
    setFilter((prev) => ({ ...prev, bizDomain: domain }));
  }}
/>
```

### 埋点

`DomainMatrix` 组件内部已经打了 `WORKBENCH_DOMAIN_DRILL`（T03）。本 task **不**再重复埋。

### 再次点击相同域 = 清空

- `DomainMatrix.onSelect` 在 active 状态再次点击当前格时传回 `null`（T03 已实现）。
- `setFilter((prev) => ({ ...prev, bizDomain: null }))` 即清空，`BizDomainSelect` 也跟着回到"全部业务域"。
- 双向绑定一致：下拉和色块永远看到同一值。

### 不刷新静态数据

切换 `bizDomain` 触发 `LeaderOverviewPage` refetch 整个 `leader-overview`；所有 KPI、TOP 报表、TOP 资产、矩阵跟着刷新，语义一致。
