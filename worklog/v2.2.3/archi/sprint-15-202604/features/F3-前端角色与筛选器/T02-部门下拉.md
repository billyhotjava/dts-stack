# T02: 部门下拉（含所领导层级）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

`DeptSelect` 子组件：

- 所领导：可选 `ALL` + 部门树（层级展开）。
- 部门领导 / 员工：锁定本部门 + 下拉禁用（显示文本 "本部门：{name}"）。
- `deptService` API 失败时，退化为"全所 / 本部门"两项（仅所领导；其他角色本就锁定，不受影响）。

## 技术设计

### 复用 `deptService`

读取：`source/dts-platform-webapp/src/api/services/deptService.ts` 确认现有接口与返回类型。预期提供：

```ts
interface DeptNode {
  code: string;
  name: string;
  parentCode?: string | null;
  children?: DeptNode[];
}
function listDeptTree(): Promise<DeptNode[]>;
```

若 API 只返回扁平列表，在 `DeptSelect` 里本地构树。

### 组件

```tsx
// src/pages/workbench/components/DeptSelect.tsx
import { TreeSelect } from "antd";
import { useEffect, useState } from "react";
import deptService from "@/api/services/deptService";
import { useWorkbenchRole } from "../hooks/useWorkbenchRole";

export interface DeptSelectProps {
  value: string | "ALL" | null;
  onChange: (value: string | "ALL") => void;
}

type DeptNode = {
  code: string;
  name: string;
  parentCode?: string | null;
  children?: DeptNode[];
};

export function DeptSelect({ value, onChange }: DeptSelectProps) {
  const { isInstLeader, deptCode, roleLabel } = useWorkbenchRole();
  const [tree, setTree] = useState<DeptNode[]>([]);
  const [apiFailed, setApiFailed] = useState(false);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    if (!isInstLeader) return;
    let cancelled = false;
    setLoading(true);
    deptService.listDeptTree()
      .then((list) => {
        if (cancelled) return;
        setTree(Array.isArray(list) ? list : []);
        setApiFailed(false);
      })
      .catch(() => {
        if (cancelled) return;
        setApiFailed(true);
        setTree([]);
      })
      .finally(() => !cancelled && setLoading(false));
    return () => { cancelled = true; };
  }, [isInstLeader]);

  if (!isInstLeader) {
    return (
      <div style={{ padding: "4px 11px", background: "#f5f5f5", borderRadius: 6 }}>
        本部门：{deptCode ?? "（未绑定）"}
      </div>
    );
  }

  const treeData = apiFailed
    ? [
        { value: "ALL", title: "全所（默认）" },
        ...(deptCode ? [{ value: deptCode, title: `本部门：${deptCode}` }] : []),
      ]
    : [
        { value: "ALL", title: "全所（默认）" },
        ...toTreeSelectData(tree),
      ];

  return (
    <TreeSelect
      value={value ?? "ALL"}
      onChange={(v) => onChange((v as string) ?? "ALL")}
      treeData={treeData}
      loading={loading}
      style={{ minWidth: 220 }}
      treeDefaultExpandAll
      showSearch
      filterTreeNode={(input, node) =>
        String(node.title).toLowerCase().includes(input.toLowerCase())
      }
    />
  );
}

function toTreeSelectData(nodes: DeptNode[]): Array<{ value: string; title: string; children?: any[] }> {
  return nodes.map((n) => ({
    value: n.code,
    title: n.name,
    children: n.children && n.children.length ? toTreeSelectData(n.children) : undefined,
  }));
}
```

### 不持久化

所领导每次刷新都以 `ALL` 为初始值，**不**持久化到 localStorage / URL。`WorkbenchFilterBar`（T05）里用局部 state 承载。
