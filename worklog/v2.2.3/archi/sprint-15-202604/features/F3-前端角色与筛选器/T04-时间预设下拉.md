# T04: 时间预设下拉

**优先级**: P1
**状态**: READY
**依赖**: 无

## 目标

`TimeRangeSelect` 子组件：本月 / 本季 / 本年 三选一，默认"本月"。

## 技术设计

```ts
// src/pages/workbench/components/TimeRangeSelect.tsx
import { Select } from "antd";

export type TimeRange = "MONTH" | "QUARTER" | "YEAR";

export const TIME_RANGE_OPTIONS: Array<{ value: TimeRange; label: string }> = [
  { value: "MONTH", label: "本月" },
  { value: "QUARTER", label: "本季" },
  { value: "YEAR", label: "本年" },
];

export function timeRangeLabel(range: TimeRange): string {
  return TIME_RANGE_OPTIONS.find((o) => o.value === range)?.label ?? "本期";
}

export interface TimeRangeSelectProps {
  value: TimeRange;
  onChange: (value: TimeRange) => void;
}

export function TimeRangeSelect({ value, onChange }: TimeRangeSelectProps) {
  return (
    <Select<TimeRange>
      value={value}
      onChange={onChange}
      options={TIME_RANGE_OPTIONS}
      style={{ minWidth: 120 }}
    />
  );
}
```

`timeRangeLabel` 导出给 KPI 文案复用（F4/T01）："本期访问" 在时间切到本季时读作"本季访问"等。

### 语义约束（写进 README / T05 使用时遵守）

- KPI 中"资产总数 / 核心资产（静态口径）"**不**随时间切换刷新。
- KPI 中"访问 / 新发布 / 新增资产"随时间切换刷新。
- TOP 报表、业务域矩阵 = 随时间刷新。

实现上：所有 period-dependent KPI 来自后端 `leader-overview`；时间变更 → 整体 refetch（简单可靠）；静态 KPI（资产总数）也包含在同一次聚合响应里，对后端一次查询的成本可接受。
