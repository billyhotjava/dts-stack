# T06: 聚合实现 · 业务域矩阵（仅 ALL）

**优先级**: P1
**状态**: READY
**依赖**: T03

## 目标

仅在 `scope=ALL` 时填充 `domainMatrix`：对每个业务域聚合当前过滤下的报表访问量，取前 6 名，剩余聚合为"其他"桶（`domain = "__OTHER__"`）。

## 技术设计

```java
private List<DomainCell> computeDomainMatrix(String scope, String deptCode, String bizDomain, TimeWindow w) {
    if (!"ALL".equals(scope)) {
        return List.of();
    }

    // 业务域过滤被选中时，矩阵意义不大——直接返回该域一格
    List<DomainAggregateRow> rows = visitRepo.aggregateByBizDomain(deptCode, bizDomain, w.start(), w.end());

    // 取前 6，其余折叠
    List<DomainAggregateRow> top6 = rows.stream()
        .sorted(Comparator.comparingLong(DomainAggregateRow::visits).reversed())
        .limit(6)
        .toList();

    long otherSum = rows.stream()
        .skip(6)
        .mapToLong(DomainAggregateRow::visits)
        .sum();

    List<DomainCell> cells = top6.stream()
        .map(r -> new DomainCell(
            r.bizDomain() != null ? r.bizDomain() : "__UNCATEGORIZED__",
            resolveDomainName(r.bizDomain()),
            r.visits()))
        .collect(Collectors.toCollection(ArrayList::new));

    if (otherSum > 0) {
        cells.add(new DomainCell("__OTHER__", "其他", otherSum));
    }

    return cells;
}
```


### 业务域名称解析

`resolveDomainName(String code)` 通过 `CatalogDomainRepository.findByCode(code)` 查中文名。因为是**软依赖**，此处的语义是：

- 查询失败 / 无 code → fallback 为 code 本身。
- `code = null`（未分类报表）→ 特判返回 `"未分类"`。
- `__OTHER__` / `__UNCATEGORIZED__` 常量在 Service 层统一处理。

为避免 N+1：在 `computeDomainMatrix` 里先 `catalogDomainRepo.findAll()` 一次性拉回 `code -> name` Map，本次聚合用这个 Map。
