# T03: 预警判定逻辑

**优先级**: P1
**状态**: READY
**依赖**: T02

## 目标
根据阈值和变化趋势，对每次指标运行做三级预警判定。

## 技术设计

### 判定规则
```java
public String determineAlertLevel(GovIndicatorDefinition def, GovIndicatorRun run) {
    BigDecimal value = run.getComputedValue();
    if (value == null) return "RED";  // 计算失败
    
    BigDecimal min = def.getThresholdMin();
    BigDecimal max = def.getThresholdMax();
    String direction = def.getDirection();
    
    // 1. 阈值判断
    boolean inRange = (min == null || value.compareTo(min) >= 0)
                   && (max == null || value.compareTo(max) <= 0);
    
    if (!inRange) {
        // 超出阈值多少？
        BigDecimal deviation = computeDeviation(value, min, max);
        if (deviation.abs().compareTo(new BigDecimal("0.1")) > 0) {
            return "RED";    // 超出 10% 以上
        }
        return "YELLOW";     // 超出 10% 以内
    }
    
    // 2. 趋势判断（连续 3 次同向偏移）
    List<GovIndicatorRun> recent = runRepo
        .findTop3ByIndicatorIdOrderByRunAtDesc(def.getId());
    if (isConsecutiveDrift(recent, direction)) {
        return "YELLOW";
    }
    
    return "GREEN";
}
```

### 在 captureOne 中调用
```java
run.setAlertLevel(determineAlertLevel(def, run));
run.setThresholdHit(!"GREEN".equals(run.getAlertLevel()));
```

### Repository 扩展
```java
List<GovIndicatorRun> findTop3ByIndicatorIdOrderByRunAtDesc(UUID indicatorId);

```
