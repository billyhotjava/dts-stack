# T03: 衍生指标拓扑排序 + 依赖解析

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标
衍生指标（is_derived=true）依赖其他指标，生成时必须按依赖顺序排列，确保 dbt ref() 引用正确。

## 技术设计

### 拓扑排序
```java
/**
 * 对指标列表做拓扑排序，基础指标在前，衍生指标在后
 * 检测循环依赖并报错
 */
public List<UUID> topologicalSort(List<UUID> indicatorIds) {
    // 1. 加载所有指标，构建 code → id 映射
    // 2. 构建邻接表：对每个 is_derived=true 的指标，
    //    dependency_indicators 中的 code → 被依赖的 id
    // 3. Kahn 算法（入度为 0 的先输出）
    // 4. 若排序后数量 < 输入数量 → 存在循环依赖，抛异常
}
```

### ref() 引用生成
衍生指标的 SQL 中，引用其他指标时使用 dbt 的 `{{ ref('ind_xxx') }}`：
```java
private String buildDerivedSourceRef(GovIndicatorDefinition def) {
    // 解析 dependency_indicators JSON
    List<String> deps = parseJsonArray(def.getDependencyIndicators());
    if (deps.size() == 1) {
        return "{{ ref('ind_" + deps.get(0) + "') }}";
    }
    // 多依赖：需要 JOIN
    // 生成 FROM ref('ind_dep1') AS d1 JOIN ref('ind_dep2') AS d2 ON ...
}
```

### 循环依赖检测
```
A → B → C → A  →  抛出 CircularDependencyException
前端展示依赖链，提示用户修正
```
