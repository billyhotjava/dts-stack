# T02: 内置模板初始化（财务+项目管理）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
初始化两个核心领域的内置指标模板，覆盖客户最常见的指标需求。

## 技术设计

### Liquibase seed 数据

#### 财务领域模板 (FINANCE)
```
code: TPL_FINANCE_BUDGET
name: 财务经费管理指标集
蓝图（8个指标）:
  - budget_execution_rate     项目经费执行率      RATIO    SUM(支出)/SUM(控制数)
  - direct_cost_rate          直接成本执行率      RATIO    SUM(直接支出)/SUM(直接控制数)
  - indirect_cost_rate        间接成本执行率      RATIO    SUM(间接支出)/SUM(间接控制数)
  - budget_balance            经费余额            CUSTOM   控制数-支出
  - budget_utilization_yoy    经费使用同比        RATIO+YOY
  - auxiliary_balance         辅助余额            SUM
  - personal_balance          个人余额            SUM
  - owned_funds               自有资金余额        SUM
```

#### 项目管理领域模板 (PROJECT_MGMT)
```
code: TPL_PROJECT_PROGRESS
name: 项目进度管理指标集
蓝图（6个指标）:
  - project_completion_rate   项目完成率          RATIO    COUNT(已完成)/COUNT(全部)
  - milestone_hit_rate        里程碑达成率        RATIO    COUNT(按时达成)/COUNT(全部里程碑)
  - node_delay_rate           节点延期率          RATIO    COUNT(延期节点)/COUNT(全部节点)
  - risk_release_rate         风险解除率          RATIO    COUNT(已解除)/COUNT(全部风险)
  - overdue_task_count        逾期任务数          COUNT    filter: status=OVERDUE
  - avg_task_duration         平均任务周期        AVG      天数
```
