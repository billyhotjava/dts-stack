### 修正后
```java
private Double computeRunScore(GovQualityRun run) {
    if (run.getRowsTotal() == null || run.getRowsTotal() == 0) {
        // 历史数据兼容：无 rowsTotal 的按状态判断
        return "SUCCEEDED".equals(run.getStatus()) ? 100.0 : 0.0;
    }
    
    int total = run.getRowsTotal();
    int failing = run.getFailingRowCount() != null ? run.getFailingRowCount() : 0;
    
    // 通过率 = (总行数 - 失败行数) / 总行数 × 100
    return Math.max(0.0, Math.min(100.0,
        (total - failing) * 100.0 / total
    ));
}
```
