# T04: 指标定义列表 + 编辑

**优先级**: P0
**状态**: READY
**依赖**: F1/T03

## 目标
展示所有指标定义，支持过滤、编辑、状态管理。

## 技术设计

### 页面
`source/dts-platform-webapp/src/pages/governance/IndicatorListPage.tsx`

### 列表 Table 列
| 列 | 字段 | 展示 |
|----|------|------|
| 编码 | code | 文本 |
| 名称 | name | 文本 |
| 领域 | domain | Tag |
| 聚合方式 | aggregationType | Tag(SUM/RATIO/...) |
| 源表 | sourceTable | 文本 |
| 状态 | status | Tag(DRAFT/COMMITTED/PUBLISHED) |
| 衍生 | isDerived | 是/否 |
| 方向 | direction | 箭头图标 |
| 隐私 | dataPrivacy | Tag(颜色区分) |
| 操作 | - | 编辑/预览/删除 |

### 过滤器
- domain 下拉
- status 下拉
- aggregationType 下拉
- 关键词搜索（code/name）

### 编辑 Drawer
点击编辑 → 右侧 Drawer 展示完整的指标定义表单：
- 基础信息 Tab
- 计算定义 Tab（根据 aggregationType 动态展示不同字段）
- 维度粒度 Tab
- 数据绑定 Tab
- 业务属性 Tab

### 批量操作
- 多选 → 批量生成
- 多选 → 批量删除（DRAFT 状态才可删）
