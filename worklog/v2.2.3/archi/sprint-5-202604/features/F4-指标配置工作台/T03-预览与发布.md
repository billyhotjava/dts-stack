# T03: SQL 预览 + 一键生成发布

**优先级**: P0
**状态**: READY
**依赖**: F3/T05, T02

## 目标
指标定义完成后，预览生成的 SQL，一键生成 dbt 模型并执行。

## 技术设计

### 预览功能
在指标定义列表中，每条指标有"预览 SQL"按钮：
- 调用 `POST /api/governance/indicators/{id}/preview-sql`
- Modal 展示生成的 SQL 和 schema.yml（代码高亮）
- 不写入文件

### 一键发布
选中多条指标 → 点击"生成并执行"按钮：
- 调用 `POST /api/governance/indicators/generate-and-run`
- 显示进度（生成中→编译中→执行中→完成）
- 完成后展示 GenerationResult：
  - 生成的文件列表
  - 编译状态
  - 执行状态
  - 每个指标的运行详情
  - 警告信息

### 状态流转
```
DRAFT → [生成] → COMMITTED → [执行成功] → PUBLISHED
                            → [执行失败] → COMMITTED（可重试）
```

### API 调用
```typescript

export const generateAndRunIndicators = (ids: string[]) => ...
```
