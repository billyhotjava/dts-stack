# T04: 预警面板

**优先级**: P1
**状态**: READY
**依赖**: F6/T03, T02

## 目标
集中展示所有预警指标，方便快速定位问题。

## 技术设计

### 在看板页面顶部展示预警汇总
```
⚠ 预警：2个异常(红) | 3个警告(黄) | 12个正常(绿)
```

### 点击展开预警面板
按严重程度排列：
- RED 指标卡片在最前
- YELLOW 其次
- 每张卡片显示告警原因（"超出阈值"/"连续下降"/"计算失败"）

### 预警原因文案
```java
// 在 IndicatorRunTracker 中记录 alert_reason
private String buildAlertReason(GovIndicatorDefinition def, GovIndicatorRun run) {
    if (run.getComputedValue() == null) return "计算失败: " + run.getErrorMessage();
    if (run.getThresholdHit()) {
        return String.format("当前值 %s 超出阈值范围 [%s, %s]",
            formatValue(run.getComputedValue(), def.getUnit()),
            def.getThresholdMin(), def.getThresholdMax());
    }
    return "连续 3 期同向偏移";
}
```

### gov_indicator_run 补充字段
```sql
ADD COLUMN alert_reason TEXT;
```
