# T03: 指标详情页（历史趋势+维度下钻）

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标
单个指标的完整详情：元数据、历史趋势图、维度下钻表格。

## 技术设计

### 页面
`source/dts-platform-webapp/src/pages/governance/IndicatorDetailPage.tsx`

### 布局
```
┌──────────────────────────────────────────────┐
│ ← 返回看板    项目经费执行率                    │
├──────────────────────────────────────────────┤
│ 指标信息                                      │
│ 领域: 财务  聚合: RATIO  粒度: MONTH          │
│ 公式: SUM(直接支出)/SUM(直接控制数)×100%       │
│ 阈值: ≥80%  方向: 越高越好  单位: %           │
├──────────────────────────────────────────────┤
│ 历史趋势 (30天)                               │
│ ┌──────────────────────────────────────┐     │
│ │  折线图（CSS 实现或简单 canvas）        │     │
│ │  标注阈值线                           │     │
│ └──────────────────────────────────────┘     │
├──────────────────────────────────────────────┤
│ 维度下钻                                      │
│ [部门 ▼] [项目 ▼] [时间 2026-03 ▼]           │
│ ┌────────┬──────┬──────┬───────┐            │
│ │ 部门    │ 值   │ 同比  │ 预警  │            │
│ ├────────┼──────┼──────┼───────┤            │
│ │ 研发部  │ 92%  │ +5%  │ 🟢   │            │
│ │ 生产部  │ 76%  │ -3%  │ 🔴   │            │
│ └────────┴──────┴──────┴───────┘            │
├──────────────────────────────────────────────┤
│ 运行历史                                      │
│ 时间 | 值 | 变化率 | 状态 | 预警               │
└──────────────────────────────────────────────┘
```

### 趋势图
用 CSS div 折线图或 antd 内置的简单图表，不引入 ECharts。
阈值线用虚线标注。

### 维度下钻
- 根据 `dimension_fields` 动态渲染 Select 选择器
- control_type 决定控件类型（dropdown/date_picker）
- 查询 `GET /api/governance/indicators/{id}/drilldown?dimension=...&period=...`
