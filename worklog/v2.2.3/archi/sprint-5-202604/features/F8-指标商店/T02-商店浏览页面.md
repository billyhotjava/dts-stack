# T02: 指标商店浏览页面

**优先级**: P2
**状态**: READY
**依赖**: T01

## 目标
客户浏览已发布的可用指标，按领域分类展示，支持订阅。

## 技术设计

### 页面
`source/dts-platform-webapp/src/pages/governance/IndicatorStorePage.tsx`

### 布局
- 顶部：领域 Tab（全部/财务/项目管理/PLM/人事）
- 搜索栏：关键词搜索指标名称
- 卡片列表：
  ```
  ┌─────────────────────────────┐
  │ 📊 项目经费执行率            │
  │ 财务 > 经费管理              │  ← 分类层级
  │                             │
  │ SUM(直接支出)/SUM(控制数)    │  ← 公式摘要
  │ 粒度: 月  维度: 项目、部门   │
  │                             │
  │ [订阅] / [已订阅 ✓]         │  ← 订阅按钮
  └─────────────────────────────┘
  ```
- 点击卡片 → 跳转到指标详情页

### 已订阅标记
已订阅的指标卡片带勾选标记，订阅按钮变为"取消订阅"。
