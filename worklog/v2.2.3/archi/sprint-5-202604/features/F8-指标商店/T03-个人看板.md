# T03: 个人看板 + 动态筛选

**优先级**: P2
**状态**: READY
**依赖**: T02, F7/T02

## 目标
客户的个人指标看板，只展示已订阅的指标，支持自定义筛选条件。

## 技术设计

### 页面
`source/dts-platform-webapp/src/pages/governance/MyIndicatorDashboard.tsx`

### 功能
- 与 IndicatorDashboardPage 类似，但数据源限定为用户已订阅的指标
- 支持拖拽排序（修改 subscription.display_order）
- 每张卡片有"筛选"图标：
  - 点击弹出 Popover，根据 `dynamic_filter_config` 渲染筛选控件
  - 保存到 subscription.filter_config
  - 看板数据按用户筛选条件过滤

### 动态筛选渲染
```typescript
// 根据 control_type 渲染不同控件
function renderFilterControl(dim: DimensionField) {
  switch (dim.controlType) {
    case 'dropdown': return <Select options={...} />;
    case 'date_picker': return <DatePicker />;
    case 'date_range': return <DatePicker.RangePicker />;
    case 'input': return <Input />;
  }
}
```
