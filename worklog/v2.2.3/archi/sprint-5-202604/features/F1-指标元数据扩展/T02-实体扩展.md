# T02: GovIndicatorDefinition 实体扩展

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
在 JPA 实体中添加所有新字段，保持与 Liquibase 一致。

## 技术设计

### 实体字段添加

在 `GovIndicatorDefinition.java` 中逐一添加：

- 计算定义: `aggregationType`, `measureField`, `numeratorExpression`, `denominatorExpression`, `staticFilter`, `dynamicFilterConfig`(JSONB→String), `isDerived`, `dependencyIndicators`(JSONB→String), `windowFunction`
- 维度粒度: `dimensionFields`(JSONB→String), `dateColumn`, `timeGrain`, `granularity`
- 数据绑定: `sourceTable`, `joinConfig`(JSONB→String), `sourceLayer`, `targetLayer`, `targetModelName`
- 业务属性: `unit`, `precisionScale`, `thresholdMin`(BigDecimal), `thresholdMax`(BigDecimal), `direction`, `businessOwner`, `dataPrivacy`
- LLM 预留: `llmGenerated`, `llmConfidence`(Float), `llmSourceRef`, `humanVerified`
- 管理: `domain`, `icon`, `displayOrder`, `templateId`(UUID)

### JSONB 字段处理
使用 `@Column(columnDefinition = "jsonb")` + `String` 类型，由 Service 层做 JSON 序列化/反序列化。与现有 `GovQualityRun.metricsJson` 风格一致。
