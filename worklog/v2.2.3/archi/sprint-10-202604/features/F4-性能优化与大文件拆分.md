# F4: 性能优化 + 大文件拆分

**状态**: READY
**依赖**: F1(Schema 架构), F2(10 图表), F3(CSS/SVG 装饰)均已完成

## 目标

把 3 个超大文件(PropertyPanel / ScreenHeader / EChartsRenderer)按职责拆分,每个文件控制在 500 行以内,提高可维护性。行为严格保持不变 — 纯重构,零功能改动。

## 拆分方案

### 1. PropertyPanel.tsx (4693 行 → 多个 ~300 行文件)

```
components/propertyPanel/
  PropertyPanel.tsx           主容器 + tabs 路由 (~300 行)
  PositionSizeSection.tsx     位置/尺寸 (~200 行)
  DataSourceSection.tsx       数据源配置 (~500 行)
  DrillDownSection.tsx        下钻配置 (~300 行)
  InteractionSection.tsx      交互/动作 (~500 行)
  AppearanceSection.tsx       通用外观 (~200 行)
  index.ts                    re-export
```

### 2. ScreenHeader.tsx (2715 行 → 多个 ~400 行文件)

```
components/screenHeader/
  ScreenHeader.tsx            主布局 + 状态 (~500 行)
  HeaderToolbar.tsx           工具栏按钮 (~300 行)
  HeaderMenus.tsx             下拉菜单 (~400 行)
  ThemeSelector.tsx           主题选择 (~100 行)
  usePublishFlow.ts           发布/版本 hooks (~300 行)
  useImportExport.ts          导入导出 hooks (~300 行)
  index.ts
```

### 3. EChartsRenderer.tsx (1588 行 → 按图表族拆分)

```
renderers/echarts/
  index.ts                    renderECharts 入口 (~150 行)
  axisCharts.ts               line/bar/scatter/combo/waterfall/candlestick/boxplot/pictorialBar (~500 行)
  pieCharts.ts                pie/gauge/funnel (~200 行)
  hierarchyCharts.ts          tree/treemap/sunburst/sankey (~200 行)
  specialCharts.ts            radar/wordcloud/heatmap/graph/parallel/calendar/themeRiver/gantt/map (~400 行)
  optionBuilders.ts           共享 option 工具 (~150 行)
```

## 约束

- **行为不变**:只改文件组织,不改任何输出
- **公开 API 不变**:外部引用 `{ PropertyPanel }` / `{ ScreenHeader }` 路径保持(通过 index.ts re-export)
- **渐进式**:每拆一个文件后单独验证 tsc 通过再继续
- **不碰 ComponentRenderer / componentLibrary / BasicRenderer / TableRenderer / DataVRenderer**(规模可接受)

## 验收标准

- [ ] 每个拆分后文件 ≤ 500 行
- [ ] TypeScript 编译 0 错误
- [ ] 外部 import 路径不变
- [ ] git diff 体现为 "文件移动 + 少量 glue",无逻辑改动
