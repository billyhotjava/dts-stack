# F3: 装饰组件升级 — 纯 CSS/SVG 替换 DataV

**状态**: READY
**依赖**: F1(Schema 基础设施,已完成)

## 目标

用纯 CSS/SVG 重写全部 DataV 装饰组件,删除 `@jiaminghi/data-view-react` 外部依赖。覆盖商务办公到展厅指挥中心全场景。现有大屏 JSON 配置无需修改(config 接口兼容)。

## 重写组件清单

| 组件 | 重写方式 |
|---|---|
| border-box (8 种) | 纯 CSS + SVG 动画 |
| decoration (8 种) | 纯 CSS + SVG 动画 |
| water-level | SVG 正弦波 + CSS 动画 |
| digital-flop | CSS 3D transform + transition |
| percent-pond | CSS gradient + 动画 |
| scroll-ranking | CSS transition 滚动 |
| scroll-board | 保留现有 TableRenderer 实现,不动 |
| flyline-chart | SVG path + stroke-dashoffset 动画 |

## 8 种 border-box 风格

| boxType | 名称 | 技术 | 场景 |
|---|---|---|---|
| 1 | 简约线框 | border + border-radius + 标题栏 | 办公室/BI |
| 2 | 渐变边框 | border-image: linear-gradient | 企业大屏 |
| 3 | 毛玻璃 | backdrop-filter: blur(12px) + 微边框 | 现代展厅 |
| 4 | 科技线框 | clip-path 斜角 + SVG stroke-dashoffset 扫描 | 指挥中心 |
| 5 | 霓虹发光 | 多层 box-shadow + @keyframes 脉冲 | 展厅 |
| 6 | 流光边框 | conic-gradient 旋转 + mask | 高端演示 |
| 7 | 卡片阴影 | border-radius: 12px + 多层 shadow | 办公室/报告 |
| 8 | 极简强调 | 仅 border-left/border-bottom 强调线 | BI 仪表盘 |

## 8 种 decoration 风格

| decorationType | 名称 | 技术 |
|---|---|---|
| 1 | 渐变分隔线 | linear-gradient + 两端淡出 |
| 2 | 光点扫描 | SVG circle + translateX 动画 |
| 3 | 脉冲圆环 | SVG circle + stroke-dasharray + scale |
| 4 | 角标装饰 | 四角 SVG 直角标 + 呼吸动画 |
| 5 | 条纹进度 | linear-gradient + background-size 滚动 |
| 6 | 波浪线 | SVG path 正弦波 + translateX |
| 8 | 旋转圆弧 | SVG circle 半弧 + rotate |
| 10 | 粒子散布 | 多个 SVG circle + 随机 opacity/position |

## 接口兼容

所有组件 config 接口不变,现有大屏 JSON 无需修改:
- border-box: `{ boxType: 1-8, color: string[], duration: number }`
- decoration: `{ decorationType: 1|2|3|4|5|6|8|10, color: string[], duration: number }`
- water-level: `{ value: number, shape: string }`
- digital-flop: `{ number: number, content: string, style: { fontSize, fill } }`
- percent-pond: `{ value: number, colors: string[], borderRadius, borderWidth }`
- scroll-ranking: 保持现有 config

## 主题适配

所有新组件通过 CSS 变量读取主题色:
- `var(--color-border)` / `var(--color-primary)` / `var(--color-text-primary)` 等
- config 里的 `color` 数组优先,未设置时 fallback 到主题变量
- 切换主题时通过 schema themeTokenKey 自动 patch(Phase 1 已实现)
