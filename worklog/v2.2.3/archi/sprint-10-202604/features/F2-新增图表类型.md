# F2: 新增 10 种图表类型

**状态**: READY
**依赖**: F1(Schema 基础设施,已完成)

## 目标

新增 10 种 ECharts 图表类型,补齐大屏编辑器的可视化能力,覆盖流向分析、热力矩阵、关系网络、金融K线、统计分布、多维对比、日历密度、层级结构、趋势河流、象形柱图等场景。

## 新增图表清单

| 类型 | 中文 | ECharts series.type | 坐标轴 | 默认尺寸 |
|---|---|---|---|---|
| `sankey-chart` | 桑基图 | sankey | ❌ | 520×360 |
| `heatmap-chart` | 热力图 | heatmap | ✅+visualMap | 480×360 |
| `graph-chart` | 关系图 | graph | ❌ | 480×400 |
| `candlestick-chart` | K线图 | candlestick | ✅ | 520×340 |
| `boxplot-chart` | 箱线图 | boxplot | ✅ | 420×320 |
| `parallel-chart` | 平行坐标 | parallel | ❌(parallelAxis) | 520×340 |
| `calendar-chart` | 日历热力图 | heatmap+calendar | ❌(calendar) | 520×220 |
| `tree-chart` | 树图 | tree | ❌ | 480×400 |
| `themeRiver-chart` | 主题河流 | themeRiver | ❌ | 520×300 |
| `pictorialBar-chart` | 象形柱图 | pictorialBar | ✅ | 420×320 |

## 每个图表的专有配置字段

### sankey-chart
- nodeAlign: select (left/right/justify)
- orient: radio (水平/垂直)
- draggable: boolean

### heatmap-chart
- visualMapMin: number
- visualMapMax: number
- visualMapColors: color-array

### graph-chart
- layout: select (force/circular/none)
- roam: boolean
- draggable: boolean
- repulsion: slider (50-500)
- symbolSize: slider (5-50)

### candlestick-chart
- upColor: color (默认 #ec0000)
- downColor: color (默认 #00da3c)
- showMA: boolean
- maPeriods: text (如 "5,10,20")

### boxplot-chart
- orient: radio (水平/垂直)
- showOutliers: boolean

### parallel-chart
- lineOpacity: slider (0-1, step 0.05)
- smooth: boolean

### calendar-chart
- cellSize: number (10-30, 默认 16)
- orient: radio (水平/垂直)
- yearRange: text (如 "2026")
- visualMapColors: color-array

### tree-chart
- layout: select (orthogonal/radial)
- orient: select (LR/RL/TB/BT)
- expandAndCollapse: boolean
- symbolSize: slider (5-30)

### themeRiver-chart
- 无专有字段,仅 ECHARTS_COMMON_FIELDS

### pictorialBar-chart
- symbol: select (circle/rect/roundRect/triangle/diamond/arrow)
- symbolRepeat: boolean
- barWidth: slider (10-60)

## 数据格式约定

| 类型 | 数据结构 |
|---|---|
| sankey | `[{ source, target, value }]` |
| heatmap | `[[xIndex, yIndex, value]]` |
| graph | `{ nodes: [{name, value?, category?}], links: [{source, target, value?}] }` |
| candlestick | `[[open, close, low, high]]` 按时间序 |
| boxplot | `[min, Q1, median, Q3, max]` 或原始数据 |
| parallel | `[[dim1, dim2, dim3, ...]]` |
| calendar | `[['2026-01-01', 42], ...]` |
| tree | `{ name, children: [{ name, children }] }` |
| themeRiver | `[[date, value, name]]` |
| pictorialBar | `[{ name, value }]` (同 bar) |
