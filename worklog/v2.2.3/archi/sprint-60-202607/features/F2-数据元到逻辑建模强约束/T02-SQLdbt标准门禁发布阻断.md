# T02: SQL/dbt 标准门禁发布阻断

**状态**: READY
**优先级**: P0

## 目标

标准门禁不只做按钮检查，还要进入模型发布动作。未绑定数据元、码表字段缺标准编码、标准版本漂移时，模型不能直接进入发布。

## 阻断规则

- DWD/DWS/ADS 受控模型字段缺数据元绑定。
- 数据元要求不可空，但模型字段可空。
- 字段类型与数据元类型不兼容。
- 数据元带 `codeSet`，但模型字段缺标准编码或缺 seed/test。
- 绑定状态为 `drift`。

## 验收

- [ ] `发布到 Analytics` 或模型发布动作读取标准门禁。
- [ ] 阻断信息在页面可见，不只在后端报错。
- [ ] PERMISSIVE / DRAFT 状态可以警告但不强阻断，避免影响现场探索。
