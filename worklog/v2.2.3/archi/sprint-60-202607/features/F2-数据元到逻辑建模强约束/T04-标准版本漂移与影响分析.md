# T04: 标准版本漂移与影响分析

**状态**: READY
**优先级**: P1

## 目标

标准变更后，系统能告诉用户影响哪些资产字段、模型字段、指标和报表，而不是只让用户人工阅读变更记录。

## 任务

- [ ] 数据元版本变化时标记引用模型字段为 drift。
- [ ] 标准删除/归档前展示引用对象并阻断高风险删除。
- [ ] 标准变更影响报表字段、指标、API、数据产品时给出 impactCount。
- [ ] 标准详情页展示“受影响对象”和修复入口。

## 验收

- [ ] 版本漂移可以被 SQL 标准门禁识别。
- [ ] 数据元详情能看到资产/模型/指标引用。
- [ ] 删除标准不会静默破坏已有模型。
