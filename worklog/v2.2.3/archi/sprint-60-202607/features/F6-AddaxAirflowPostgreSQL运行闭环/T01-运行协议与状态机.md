# T01: 运行协议与状态机

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: F3-T03

## 目标

统一 Addax、dbt、Airflow 和 DTS 的运行状态与外部标识。

## 技术设计

运行记录包含：`modelSpecRevision/sourceBatchId/addaxTaskId/airflowDagId/dbtRunId/dbtSelector/targetTable`。

状态：`QUEUED/RUNNING/SUCCEEDED/FAILED/CANCELLED/TIMED_OUT`，子步骤保存独立状态和日志链接。

## 影响范围

- `modeling_pipeline_run` 服务和 API。
- 运维中心状态映射。

## 验证

- [x] 状态只允许合法迁移，失败/取消/超时支持显式重试回队列。
- [x] 重复 callback 不会覆盖成功状态。
- [ ] 外部失败信息保存到 pipeline_run 并可定位（表结构已就绪，持久化 service 待补）。

## 完成标准

- [ ] 前端和后端使用同一状态枚举。
