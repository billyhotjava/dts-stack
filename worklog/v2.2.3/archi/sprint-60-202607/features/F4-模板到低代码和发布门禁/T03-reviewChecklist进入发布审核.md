# T03: reviewChecklist 进入发布审核

**状态**: READY
**优先级**: P1

## 目标

标准模板中的 `reviewChecklist` 进入模型发布审核和语义模型审核，成为可检查项。

## 任务

- [ ] 发布审核读取模型绑定的标准模板。
- [ ] 将 reviewChecklist 解析为审核项。
- [ ] 审核项支持通过、警告、阻断、例外说明。
- [ ] 审核结果写入运行证据或审计日志。

## 验收

- [ ] 发布审核不是单纯状态切换。
- [ ] 模板审核项可追踪到具体模型和审核人。
- [ ] 例外发布必须有理由和责任人。
