# T04: Sprint gate 与证据沉淀

**状态**: READY
**优先级**: P0

## 目标

为本 sprint 建立可重复验证的质量门禁，避免只交付页面文案或不可执行设计。

## Gate

- [ ] source-contract：标准页面、低代码向导、SQL 建模、指标工作台入口不退化。
- [ ] 后端 targeted tests：标准绑定、标准门禁、schema.yml、资产字段标准映射。
- [ ] 前端构建：`source/dts-platform-webapp` 生产构建。
- [ ] 浏览器 smoke：标准包、数据元、SQL 建模标准绑定、指标工作台。
- [ ] worklog evidence：记录命令、结果、截图和未覆盖风险。

## 验收

- [ ] 所有新增标准控制面能力都有测试或证据。
- [ ] 未跑的 live gate 必须明确原因和补证路径。
- [ ] 不能用“页面能打开”替代标准门禁验证。
