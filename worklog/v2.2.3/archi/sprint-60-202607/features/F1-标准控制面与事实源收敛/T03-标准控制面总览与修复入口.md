# T03: 标准控制面总览与修复入口

**状态**: READY
**优先级**: P1

## 目标

提供一个轻量控制面视图，让用户知道标准是否已经进入资产、模型、指标和发布流程。

## 页面原则

- 不新增孤立大页面，优先在标准包、数据元、业务术语详情中补充引用和缺口。
- 标准缺口必须有修复入口：
  - 缺业务术语 -> 术语详情/发布。
  - 缺数据元 -> 数据元维护。
  - 字段未落标 -> 资产字段或 SQL 建模页。
  - 指标无口径 -> 指标工作台。
  - 模型未门禁 -> SQL 建模标准门禁。

## 验收

- [ ] 标准控制面能定位到具体资产/模型/指标。
- [ ] 每个阻断项有 owner、原因和下一步动作。
- [ ] source-contract 覆盖入口、文案和关键路由。
