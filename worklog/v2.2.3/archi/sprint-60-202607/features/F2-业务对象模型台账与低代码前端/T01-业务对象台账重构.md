# T01: 业务对象台账重构

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: F1-T01

## 目标

把现有“业务对象”页面改造成真正的语义登记台账，而不是主表映射列表。

## 技术设计

页面列至少包括：对象名称、对象类型、业务过程、业务主键、粒度、来源模型、标准完成度、实现模式、状态和下一步。

详情分为业务定义、粒度与主键、来源与字段、下游模型四个区块。

## 影响范围

- `source/dts-platform-webapp/src/pages/modeling/SemanticObjectsPage.tsx`
- 新增 `BusinessObjectLedger` 组件及 source-contract。
- 新增 `/api/modeling/vnext/business-objects` 客户端封装；旧 `/api/semantic/business-objects` 继续兼容已有页面。
