# T04: 权限、审核、审计与兼容服务

**优先级**: P0
**状态**: READY
**依赖**: T02,T03

## 目标

为新版本模型建立权限、审核、审计和旧语义接口适配，保证可运营和可回滚。

## 技术设计

- 设计器生成的 DWD/DWS/ADS 均必须经过审核状态机。
- dbt 原生模型导入默认 `DBT_MANAGED`，可运行但未登记标准时不得进入 `GOVERNED` 发布态。
- 审计记录对象、ModelSpec revision、artifact checksum、操作者和外部运行 ID。
- 旧 API 适配层只转换 DTO，不复制业务校验。

## 影响范围

- 权限注解、审计 service、兼容 adapter。
- 后端单元和资源测试。

## 验证

- [ ] 未授权用户不能编译、发布或触发运行。
- [ ] 审核拒绝后可修订并重新提交。
- [ ] 旧页面仍能读取旧对象和模型。

## 完成标准

- [ ] 所有状态变化都有审计记录和可追踪 revision。
