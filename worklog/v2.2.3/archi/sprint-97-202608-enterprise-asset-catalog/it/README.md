# 集中验收清单

仅在 F1～F4 全部 DONE 后执行：

1. 使用 xiezm/sa 登录真实平台。
2. 从数据治理菜单进入数据资产目录，确认两个页签可发现且刷新保持。
3. 安装预置标签，创建一个临时自定义标签。
4. 分别检索数据表、模型、指标、分析数据集、看板、数据产品和 API 服务。
5. 给至少一个非 DATASET 资产关联标签，按标签筛选并从详情移除。
6. 查看模型到物理表、分析数据集到模型、看板到分析数据集的真实关系；不存在时为空而非伪造。
7. 验证质量状态只使用真实事实，缺失显示“暂无证据”。
8. 验证部门角色看不到越权资产（如测试账号可用）。
9. 检查关键请求无 403/500、控制台无错误，保存桌面和窄屏证据。
