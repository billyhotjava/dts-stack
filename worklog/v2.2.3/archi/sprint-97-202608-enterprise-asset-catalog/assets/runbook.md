# 运维手册（Gate G4）

**功能**：企业统一数据资产目录与数据标签  
**负责人**：xiezm  
**风险等级**：中

## 正常状态与依赖

该功能从数据表、模型、指标、分析数据集、看板、数据产品和数据服务的现有 owner 表只读聚合目录，不创建第二套资产主数据。依赖 `dts-platform`、目录数据库、现有标签服务和 `dts-platform-webapp`；任一 owner 无数据时对应家族如实为空，不补造记录。

## 关键观测

- API：`GET /api/catalog/assets-v2?assetFamily=ALL&page=0&size=10`
- 日志字段：用户、activeDept、assetFamily、returned、total、错误关联 ID。
- 数据核对：`catalog_tag_category`、`catalog_tag`、`catalog_asset_tag` 按资产类型计数。

| 检查项 | 检查方式 | 期望结果 |
|---|---|---|
| 服务健康 | `docker compose -f docker-compose-app.yml ps dts-platform dts-platform-webapp` | 两个服务均为运行/健康状态 |
| 旧目录兼容 | 使用已认证会话请求 `assets-v2?page=0&size=10` | 2xx，返回原 DATASET 分页结构 |
| 统一目录 | 使用已认证会话请求 `assets-v2?assetFamily=ALL&page=0&size=10` | 2xx，canonical type/key 非空 |
| 页面 | 数据治理 → 数据资产 → 数据资产目录 | “资产目录 / 数据标签”页签均可进入 |

## 告警建议

| 条件与阈值 | 级别 | 含义 | 处置 |
|---|---|---|---|
| 统一目录 5xx ≥3 次/5 分钟或错误率 ≥5%/5 分钟 | P1 | 用户无法浏览多类型资产 | 检查后端日志关联 ID和最新 owner schema；必要时回滚前后端 |
| 统一目录 p95 >2 秒持续 10 分钟 | P2 | owner 扫描或关系查询变慢 | 按 assetFamily 分查，检查候选量；超过预算时要求增加筛选 |
| 目录 422 ≥10 次/10 分钟 | P2 | 候选频繁超过 5000 | 引导按家族/数据域收窄并评估后续搜索索引，不提升硬上限 |
| 标签关联 403 ≥5 次/10 分钟且同一用户重复 | P2 | 权限或 canonical identity 不一致 | 核对角色、activeDept、资产类型和 key，禁止绕过 tag guard |

告警按“路由 + 状态码”聚合，同一关联 ID只计一次，避免重试风暴。

## 日志与审计

关键字段：请求/关联 ID、操作人、activeDept、assetFamily、returned、total、HTTP 状态和耗时。标签写入另走既有审计链。禁止记录密码、令牌、资产字段值或受密级保护的数据内容。

## 常见故障

| 现象 | 排查 | 处理 |
|---|---|---|
| 数据标签页为空 | 检查三张 tag 表和安装账本 | 有治理权限的用户通过 UI 安装预置标签 |
| 某资产家族为 0 | 检查对应 owner 表及有效状态 | 不在目录补造记录，修复 owner 数据或读取适配器 |
| 标签关联 403 | 检查 canonical key、身份解析和角色 | 不绕过 tag guard |
| 目录 422 | owner 聚合候选超过 5000 | 先选择更具体的资产家族；不得直接提高硬上限 |
| 质量显示暂无证据 | owner 未提供可靠验证事实 | 不将发布/同步状态映射为 PASSED |

## 故障处置

| 场景 | 症状 | 立即动作 | 恢复动作 | 可回滚 |
|---|---|---|---|---|
| owner 表/数据库不可用 | 统一目录 5xx | 切换到数据表家族确认旧链是否可用，保存关联 ID | 恢复数据库或回滚新 UI/后端 | 是 |
| owner 脏数据或身份缺失 | 单家族 5xx、详情 key 为空 | 定位家族和 owner 行，不在目录猜测补值 | 修复 owner 数据或适配器并重试只读请求 | 是 |
| 重复请求/前端卡住 | 同一查询连续发出、加载态不结束 | 刷新页面并核对网络请求序号 | 目录查询只读幂等；终止异常客户端请求后重试 | 不需要数据回滚 |

## 健康门槛

- 旧 DATASET API 与统一目录 API 均为 2xx。
- 目录返回资产身份无空值、无同身份重复。
- 浏览器无 403/500、无未处理 Promise、无控制台错误。

## 容量与禁止操作

- owner 聚合最多读取 5001 条溢出哨兵；有效候选超过 5000 返回 422；每页 1～200 条。
- 标签批量后端上限 500、UI 单次选择上限 100；关系按页固定批量查询，禁止逐资产查询。
- 不提高硬上限掩盖容量问题，不 truncate/reset owner 或标签表，不绕过密级/部门/tag guard，不把发布或物化成功改写成质量通过。
