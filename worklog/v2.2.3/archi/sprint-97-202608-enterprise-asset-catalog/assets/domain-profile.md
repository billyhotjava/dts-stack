# 领域画像与不变量

## 统一语言

| 术语 | 定义 |
|---|---|
| 数据资产 | 可被发现、治理和消费的数据表、模型、指标、分析数据集、看板、数据产品或数据服务 |
| 业务数据标签 | 用于业务检索和运营分组的可变标签，不承载密级含义 |
| 合规密级 | 权限判定输入，来自既有分类事实，不由标签推断 |
| 资产 owner | 创建并维护业务对象事实的原模块 |
| 目录投影 | 从 owner 读取并统一展示的只读视图 |
| 资产关系 | owner 已登记的模型物化、指标来源、BI/服务绑定等关系事实 |

## 不变量

1. 唯一资产身份为 `(CatalogAssetType, CatalogAssetKey)`。
2. 目录不得复制并成为第二业务 owner。
3. 标签、密级、数据域和生命周期为相互独立的治理维度。
4. 模型发布或物化不自动意味着质量通过，也不自动意味着资产上线。
5. 临时构建、候选版本、执行实例和审计记录不是独立数据资产。
6. 关系不存在时返回空集合，质量证据不存在时返回 `UNKNOWN`，禁止推断。

## 运行数据画像

- 目录候选总规模约 549 条，适合当前有界内存合并；超过 5000 候选时必须要求增加筛选条件。
- `catalog_asset_semantic_projection` 当前 309 条且均为 DATASET；它只承载物理资产语义，不扩作跨类型业务目录。
- 当前标签字典为空，但内置包预计创建 5 个分类和 20 个标签；安装必须走现有版本化安装账本。
- OpenMetadata 缓存当前为 0；统一目录仍复用既有 DATASET 服务，避免破坏后续 OM + legacy 合并。

## 权限边界

- 所级：`ROLE_ADMIN / ROLE_OP_ADMIN / ROLE_INST_DATA_OWNER / ROLE_INST_LEADER` 延续平台级读取；写标签仍走现有 tag guard。
- 部门级：延续责任部门和密级门禁；无权资产不得通过统一目录或标签筛选侧漏。
- 目录详情不取代 owner 页面的编辑权限。
