# T03：连接标准、资产、指标与服务

- **状态**：READY
- **优先级**：P0
- **依赖**：T01、T02
- **影响模块**：工作台摘要卡、跨模块 deep link、返回上下文

## 目标

让工作台用引用和深链串起专业模块，保持各模块数据所有权，并在处理后返回原计划和阶段。

## 实施内容

1. 为连接/接入、标准、资产、指标、服务和运行定义 `planId` 上下文参数。
2. 每个阶段只显示数量、状态、主问题和最近校验时间，正文在专业页面编辑。
3. 深链包含 planId、returnTo、target object 和必要筛选，校验开放重定向风险。
4. 专业页面保存后刷新 evidence projection，并返回相同计划。
5. 无权限时显示受限摘要，不泄露名称、字段或样例。

## 验收标准

- 工作台没有复制专业模块 CRUD；
- 从计划进入和返回不会丢上下文；
- URL 参数经过 allowlist 验证；
- 权限不因 plan 引用扩大；
- 下游引用失效时显示具体诊断。

## 验证证据

- deep-link contract tests；
- 返回上下文 E2E；
- 403/404/失效引用测试；
- 安全重定向测试。
