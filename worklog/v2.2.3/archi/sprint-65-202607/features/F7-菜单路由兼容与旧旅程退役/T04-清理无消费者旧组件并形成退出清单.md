# T04：清理无消费者旧组件并形成退出清单

- **状态**：READY
- **优先级**：P0
- **依赖**：T03
- **影响模块**：旧前端组件、route adapters、tests、退役登记表

## 目标

只清理已有零消费者证据且有替代物的旧前端组件和重复文案，并把旧 API/表登记为后续移除候选，不在本 Sprint 破坏性删库。

## 实施内容

1. 使用 route/menu/runtime audit 和 GitNexus 确认组件真实消费者。
2. 移除仅用于旧 redirect shell、重复概念卡和无入口测试夹具的代码。
3. 保留必要 adapter、旧 ID 映射和只读 API，标注删除条件与期限。
4. 更新文档、source-contract 和测试，禁止隐藏 orphan route。
5. 输出 REMOVAL_CANDIDATE 清单，包含调用统计、备份和专项审批要求。

## 验收标准

- 不因“搜索不到”单一证据删除运行时动态消费者；
- 清理后菜单、路由、权限和旧深链回归通过；
- 本 Sprint 不删除 `modeling_plan*` 表；
- adapter 有到期条件和所有者；
- `gitnexus_detect_changes` 只命中预期旅程。

## 验证证据

- 消费者审计；
- 删除前后 route/menu tests；
- GitNexus change report；
- removal candidate 审批清单。
