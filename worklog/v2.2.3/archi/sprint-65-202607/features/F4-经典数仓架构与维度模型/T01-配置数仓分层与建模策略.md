# T01：配置数仓分层与建模策略

- **状态**：READY
- **优先级**：P0
- **依赖**：F3-T04
- **影响模块**：WarehousePlan policy、ModelSpec 默认值、规划 UI

## 目标

在计划级定义可版本化的分层、命名、历史和时间策略，为后续模型提供统一约束而不绑定特定行业。

## 实施内容

1. 提供经典 ODS/DWD/DWS/ADS 默认策略，并允许受控增减 STG 等层。
2. 配置层间允许依赖、命名规则、主键/代理键、历史保留和默认时区。
3. 规则以 policyRef/version 绑定计划，避免复制标准正文。
4. 策略变更执行模型影响分析并要求新版本或复核。
5. UI 使用默认摘要 + 高级配置，不在首屏展示所有参数。

## 验收标准

- 默认策略可直接用于通用关系型业务系统；
- 层间红线有后台门禁；
- 计划内模型使用同一策略版本；
- 策略变化不会无提示重写模型；
- 行业模板只能预填策略，不创建新核心层级语义。

## 验证证据

- policy contract tests；
- 合法/非法层依赖测试；
- 版本和影响分析样例；
- 默认/高级 UI smoke。
