# T02：设计事实、维度、粒度与时间语义

- **状态**：READY
- **优先级**：P0
- **依赖**：T01
- **影响模块**：ModelingVNextContract、ModelSpec service、模型设计 UI

## 目标

扩展并约束 `ModelSpec`，支持事实、维度、汇总和应用模型，明确一行数据代表什么以及时间如何解释。

## 实施内容

1. 增加/收敛 `modelRole`、`factShape`、`objectNature` 和 `timeSemantics` 中性属性。
2. 事务事实要求事件时间和业务键；周期快照要求对象 + 周期；累积快照要求生命周期对象和里程碑日期。
3. 维度模型支持主数据、管理对象和参考对象，以及代理键/自然键/历史策略。
4. 粒度由结构化键和客户可读说明共同表达，并与模型字段校验。
5. 关系建模编辑主外键与基数，但保存到同一 ModelSpec/relationship 内核。

## 验收标准

- 三类事实形态都有合法和非法组合测试；
- 粒度字段不存在或类型不一致时不能发布；
- 过程形态只给建议，用户确认后进入模型；
- 关系视图和维度设计不产生两份模型；
- 现有 ModelSpec 通过兼容默认值可读取。

## 验证证据

- grain/factShape/timeSemantics 参数化测试；
- 旧模型兼容测试；
