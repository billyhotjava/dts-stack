# T03：绑定来源字段与数据标准

- **状态**：READY
- **优先级**：P0
- **依赖**：T02
- **影响模块**：ModelSpec source mapping、standard binding、drift/gate UI

## 目标

建立来源字段到模型字段的可追溯映射，并把数据元/标准及版本作为模型门禁引用。

## 实施内容

1. 将 SourceBinding 的表/字段映射到 ModelSpec 字段，支持转换说明和空值策略。
2. 复用标准管理 API 绑定数据元、代码集、格式、密级和版本。
3. 检查来源 Schema 漂移、标准版本漂移和字段类型冲突。
4. 对自动匹配只给候选置信度，人工确认后参与门禁。
5. 提供批量处理但保留逐字段差异和撤销能力。

## 验收标准

- 来源、标准正文不复制进模型表；
- 映射可追溯到来源版本和确认人；
- 漂移状态为 CURRENT/STALE/UNAVAILABLE 且不会误报完成；
- 密级和权限不会因规划引用被扩大；
- 发布门禁能指出具体冲突字段和修复入口。

## 验证证据

- 字段映射和标准 binding tests；
- Schema/standard drift tests；
- 批量确认/撤销 UI 测试；
- 权限和脱敏用例。
