# T04：建立实现所有权与发布门禁

- **状态**：READY
- **优先级**：P0
- **依赖**：T03
- **影响模块**：ModelSpec implementation mode、release gate、UI ownership switch

## 目标

以 `DESIGNER_GENERATED` 和 `DBT_MANAGED` 明确实现所有权，阻止无提示双向覆盖，并把所有权、漂移、编译、测试和运行纳入发布门禁。

## 实施内容

1. 每个 ModelSpec 只能有一个当前实现所有者。
2. 所有权切换显示影响、未提交差异和生成/覆盖策略，要求显式确认和审计。
3. 设计器生成模式禁止外部 dbt 写入覆盖；dbt 管理模式禁止设计器重生成文件。
4. 发布门禁聚合 grain、standard、source、drift、compile、test、quality 和权限证据。
5. 失败响应返回具体对象和修复路径，不只给布尔值。

## 验收标准

- 双写尝试返回 `IMPLEMENTATION_ARTIFACT_CONFLICT`；
- 所有权切换可审计且不丢历史版本；
- 门禁状态与 stage projection 一致；
- stale/unknown 关键证据不能发布；
- 设计器与 dbt 两条实现路径最终产生同一种交付引用。

## 验证证据

- ownership conflict tests；
- switch audit/version tests；
- release gate matrix；
- 两模式端到端发布证据。
