# T01：重构模型中心信息架构

- **状态**：READY
- **优先级**：P0
- **依赖**：F4-T02
- **影响模块**：模型中心菜单、模型列表/详情/设计页

## 目标

建立以计划和模型台账为中心的经典建模入口，统一事实、维度、汇总、应用模型及关系视图，不要求普通用户进入 dbt。

## 实施内容

1. 模型列表按 plan、layer、role、status 筛选，默认显示当前计划。
2. 模型详情组织为概览、粒度与字段、关系、来源与标准、实现、版本与影响。
3. 事实/维度设计提供结构化表单和高级关系视图。
4. ER 和分析关系概览共享 ModelSpec 数据，不维护额外关系正文。
5. 页面遵循一个主动作和渐进披露，移除重复概念卡与按钮。

## 验收标准

- “模型中心”不再跳到主题域管理；
- 普通用户可完成模型设计、验证和提交发布；
- 关系建模是可选 Tab 而不是并列产品模式；
- 计划上下文可切换并通过 URL 恢复；
- 现有 ModelSpec 可兼容展示。

## 验证证据

- route/menu tests；
- model list/detail component tests；
- 旧模型兼容截图；
- Chrome 95 主流程。
