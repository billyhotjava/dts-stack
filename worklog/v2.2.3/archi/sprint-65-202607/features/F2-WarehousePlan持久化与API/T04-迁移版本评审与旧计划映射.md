# T04：迁移版本评审与旧计划映射

- **状态**：READY
- **优先级**：P0
- **依赖**：T01、T02
- **影响模块**：迁移服务、计划版本/评审、旧 API adapter

## 目标

把旧计划、版本和评审安全映射到 canonical 聚合，提供 dry-run、幂等执行、冲突处理和旧 ID 解析。

## 实施内容

1. 实现 dry-run 清单：自动迁移、合并候选、人工冲突、不可迁移。
2. 迁移 `modeling_plan_version/review` 到 canonical 版本与评审结构，保留原 ID 和批次。
3. 为旧计划 ID、旧路由参数和旧 API 响应提供稳定映射。
4. 迁移过程使用幂等键和校验和，重复执行只更新同一映射。
5. 增加迁移批次审计、失败重试和部分成功恢复。

## 验收标准

- 每条旧计划有明确处置结果；
- 版本顺序、评审人、结论和时间不丢失；
- 旧 ID 可解析到唯一 canonical planId；
- 冲突不会自动覆盖；
- 回滚恢复旧读取但不删除新记录。

## 验证证据

- 脱敏迁移 dry-run；
- 首次/重复执行 diff；
- 旧 ID/版本/评审核对；
- 失败恢复和回滚日志。
