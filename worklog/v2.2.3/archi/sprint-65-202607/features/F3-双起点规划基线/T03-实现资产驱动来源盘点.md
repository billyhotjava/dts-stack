# T03：实现资产驱动来源盘点

- **状态**：READY
- **优先级**：P0
- **依赖**：T01
- **影响模块**：连接/目录引用、Excel/ODS/dbt 元数据、规划基线 UI/API

## 目标

让已有 Excel、ODS、数据库表或 dbt 项目的客户从存量资产开始，通过剖析和人工确认进入同一规划基线。

## 实施内容

1. 从连接、元数据目录、上传记录和 dbt artifact 选择来源引用。
2. 展示 Schema、字段、样例摘要、候选主键、时间字段、枚举、空值和更新方式。
3. Excel 按工作表建立 source binding，保留文件/工作表来源而不把每张表直接等同事实模型。
4. 名称/字段/manifest 推断只创建候选域、过程、对象和粒度。
5. 处理剖析失败、无权读取、Schema 漂移、重复来源和主动排除。

## 验收标准

- Excel、ODS、目录表和 dbt 节点使用同一种 SourceBinding 抽象；
- 原始数据和敏感样例遵循权限与脱敏；
- 推断结果未经确认不能进入正式模型；
- 来源失效或漂移显示诊断而非静默消失；
- 资产驱动完成后可进入业务范围 Tab 补齐同一 baseline。

## 验证证据

- 四类来源 contract fixtures；
- 权限/脱敏/漂移测试；
- 候选确认 UI 测试；
- Excel 多工作表示例截图。
