# T02：实现全局入口与完整帮助页

**优先级**：P0
**状态**：IN_PROGRESS
**依赖**：T01

## 技术设计

- Header 在 SearchBar 与账户之间渲染 `HelpCenter`。
- `HelpCenter` 使用现有 Sheet，读取当前路由主题并提供完整中心深链。
- `/settings/help?topic=:id&q=:query` 使用静态 Dashboard route。
- 不新增菜单，不新增权限动作，不请求 API。
- 未知主题回退 DTS 总览；窄屏 Sheet 全宽。

## UI 走查

1. 进入任意 Dashboard 页面。
2. 点击“帮助”图标。
3. 看到当前页面主题、前置条件、步骤与阻塞。
4. 点击“打开完整帮助中心”。
5. 在完整页面搜索并切换其他 DTS 主题。

## Definition of Done

- [x] Header 三种布局从共享 Header 获得同一入口。
- [x] Sheet 的按钮、Title、Description 与关闭结构完整。
- [x] 完整页面支持 topic/query 深链。
- [x] 不新增业务菜单。
- [ ] 有效登录后完成实际键盘、桌面和窄屏 UI 走查。
