# Sprint-77 领域画像

## 统一语言

| 术语 | 本 Sprint 定义 |
|---|---|
| 帮助主题 | 一个可独立定位、搜索和深链的 DTS 用户任务说明 |
| 当前页帮助 | 按当前 pathname/query 匹配到的首选帮助主题 |
| 完整帮助中心 | `/settings/help` 中可浏览、搜索全部主题的页面 |
| 通用说明 | 稳定的“是什么、为什么、完整流程”教程 |
| 运行态反馈 | 当前权限、错误、阻塞、版本、证据、恢复和下一动作 |

## 边界

- 内容覆盖整个 DTS 产品域，但首批只提供常用任务级主题。
- 不引入新的业务对象、API、表、权限动作或审计动作。
- 帮助主题按用户任务组织，不按前后端模块清单组织。
- 通用说明可迁移；运行态反馈必须留在业务页面。
