# T03: 执行详情与错误展示

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: F3-T02

## 目标

执行记录页面展示 API 执行特有信息：资源级成功/失败明细、分页进度、当前游标值、失败分类与建议、重试状态。

## 技术设计

- 执行详情抽屉/页面：资源明细表（resource/页数/行数/状态/错误）、checkpoint 当前值展示、failureCategory+advice 渲染（复用 JDBC 路径的失败分类展示组件）。
- 手动操作：重跑（沿用 checkpoint）、backfill（窗口选择器，透传 start/end）。
- 遵循 [[pagination-unification-convention]]：CompactTable 默认 10 条/页。

## 2026-06-12 进展

- 已在 API 执行器聚合资源级运行统计：`resourceId/pageCount/rowsRead/httpStatus/cursorValue/endpoint/status`，并复用 execution `sourceTables` JSON 字段随现有执行查询接口返回；raw landing 部分失败时对应资源标记为 `FAILED`。
- 已在前端 `ExecutionHistoryTable` 增加 “API资源” 列，展示资源、页数、读取行数、当前游标；悬浮可查看 HTTP 状态与端点。
- 失败分类与建议继续复用现有 `failureCategory/failureAdvice` 列和日志抽屉展示，不新增接口。

## 影响范围

- 执行查询接口扩展资源级明细字段（F3-T02 提供）
