# T04: 血缘与可观测

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: T02

## 目标

API 入湖接入血缘与指标：OpenLineage 事件（含行数 facets）由 Java 执行器发出，Micrometer 暴露任务级指标。

## 技术设计

- OpenLineage：执行器完成/失败时直接 POST platform `/internal/lineage/openlineage`（复用现有 endpoint 解析 `resolveOpenLineageUrl`，baseUrl 走配置不写死）；inputs=API 资源(namespace=数据源)、outputs=ODS 表；新增 rowCount facets（旧 Python 路径无行数）。
- Micrometer：`dts_api_ingestion_{records,pages,duration,failures{category}}` 任务标签维度；执行器内埋点。
- DAG 侧 OpenLineage 回调（旧 `make_openlineage_callback`）随瘦触发模板移除，避免双发。

## 影响范围

- `ApiIngestionExecutor`（事件+埋点）
- `IngestionOutboundPlatformProperties`（lineage URL 配置化）
