# T04: 分页与类型化游标

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

迁移并修复分页/游标逻辑：4 种分页 + Link 头；游标按类型比较（修复字符串比较 bug）；消费 `initialValue`/`lookbackSeconds`。

## 技术设计

- 分页：page/offset/token/nextUrl（迁移旧 `_build_url`/`_has_next_page` 语义）+ 新增 RFC 5988 `Link: rel="next"` 头解析；maxPages 可配（替代写死 1000）。
- **修复提前停**：`record_count < page_size` 不再作为唯一终止条件——token/nextUrl/Link 存在时优先以其为准；page/offset 模式增加「连续空页」终止保护。
- **类型化游标**：`CursorPolicy.type`（numeric/datetime/string）决定比较器，修复旧 `str("100")<str("99")` 错误；datetime 支持 epoch 秒/毫秒/ISO8601 自动识别。
- `initialValue`：首轮无 checkpoint 时的起始水位；`lookbackSeconds`：每轮起点回退重叠窗口防丢数（落地侧靠幂等键去重，T05）。
- 路径解析：保留点号路径，新增数组下标 `items[0].id` 支持；recordPath 解析失败给出明确错误。

## 影响范围

- 新增 `service/etl/api/CursorTracker.java`、`JsonPathLite.java`；分页驱动先落在 `ApiHttpEngine` 内，后续随 T05 raw landing 再判断是否抽出独立 `PaginationDriver`。
- 旧逻辑参照 `AirflowDagService.java:1292-1436`（迁移后随 F5-T02 删除）
