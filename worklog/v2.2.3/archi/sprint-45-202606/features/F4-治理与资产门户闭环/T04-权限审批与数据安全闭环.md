# T04: 权限审批与数据安全闭环

**状态**: DONE  
**优先级**: P0  
**涉及路由**: `/security/data-security`, `/security/dataset-access-approval`

## 目标

把资产权限申请、审批、数据安全分级、审计证据串成闭环，防止消费页面绕过治理。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 申请权限 | 主按钮 | 创建访问申请 |
| 批准 | 主按钮 | 审批通过并写入权限 |
| 驳回 | 危险按钮 | 填写原因后驳回 |
| 撤回申请 | 危险按钮 | 申请人撤回 |
| 新建分级 | 主按钮 | 创建数据分级/分类 |
| 查看审计 | 次按钮 | 打开权限审计记录 |

## 组件清单

- `AccessRequestForm`: 数据范围、用途、有效期、审批人。
- `ApprovalQueue`: 待审批列表。
- `ApprovalTimeline`: 申请、审批、授权、撤销时间线。
- `SecurityClassificationTree`: 分级分类树。
- `PolicyBindingTable`: 策略与资产绑定。
- `AuditEvidenceDrawer`: 权限变更证据。

## 数据约束

- 审批动作必须写入真实权限/审计记录。
- 权限范围必须展示资产、字段、行级范围或缺失说明。
- 有效期和用途不能只作为前端备注。

## 验收

- [x] 资产页面发起的权限申请能进入审批队列。
- [x] 审批通过后消费入口权限状态更新。
- [x] 驳回/撤回有原因和审计记录。
- [x] 数据安全策略能关联资产。
