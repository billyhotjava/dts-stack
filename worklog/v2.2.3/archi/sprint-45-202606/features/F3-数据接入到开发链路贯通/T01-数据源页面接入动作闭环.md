# T01: 数据源页面接入动作闭环

**状态**: DONE  
**优先级**: P0  
**涉及路由**: `/foundation/data-sources`

## 目标

让数据源页成为接入链路起点：新建数据源后能继续测试连接、发现表、创建入湖任务、进入黄金链路。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建数据源 | 主按钮 | 打开数据源创建向导 |
| 测试连接 | 次按钮 | 调用连接测试接口 |
| 发现表 | 次按钮 | 展示 Schema/Table 发现结果 |
| 创建入湖任务 | 主/次按钮 | 跳转入湖任务创建并带数据源 ID |
| 查看黄金链路 | 次按钮 | 跳转工作台链路详情 |
| 停用/删除 | 危险按钮 | 展示影响任务和资产后确认 |

## 组件清单

- `DataSourceTable`: 数据源列表。
- `DataSourceCreateWizard`: 类型、连接信息、凭据、测试、完成。
- `ConnectionTestResult`: 成功/失败/耗时/错误详情。
- `SchemaDiscoveryDrawer`: schema、table、字段、采样信息。
- `IngestionTaskCTA`: 入湖任务创建入口。
- `DataSourceImpactModal`: 停用/删除影响范围。

## 数据约束

- 连接测试和发现表必须使用真实接口。
- 凭据字段不能在页面回显明文。
- 创建入湖任务必须携带数据源上下文，不让用户重复选择。

## 验收

- [x] 新建完成后展示测试连接和发现表结果。
- [x] 创建入湖任务能进入真实任务页或展示接口缺失 blocker。
- [x] 删除/停用前展示影响范围。
- [x] 从数据源可回到工作台链路。
