# T03: 连接器、驱动和元数据页面组件统一

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/foundation/connectors`, `/foundation/jdbc-drivers`, `/catalog/metadata`

## 目标

把连接器、JDBC 驱动、元数据同步这类基础资源页从后台配置表改成可理解的接入支撑页面。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 启用/停用连接器 | 次/危险按钮 | 修改连接器可用状态 |
| 配置模板 | 次按钮 | 打开连接器配置模板 |
| 上传驱动 | 主按钮 | 上传 JDBC 驱动 |
| 校验驱动 | 次按钮 | 校验驱动类名和版本 |
| 同步元数据 | 主按钮 | 触发元数据同步 |
| 查看差异 | 次按钮 | 查看同步前后差异 |

## 组件清单

- `ConnectorCardGrid`: 连接器卡片。
- `ConnectorConfigDrawer`: 参数说明、示例、校验。
- `JdbcDriverTable`: 驱动表格。
- `DriverValidationResult`: 类名、版本、冲突结果。
- `MetadataSyncStatus`: 同步状态、最近运行、错误。
- `MetadataDiffTable`: 新增、变更、删除对象。

## 数据约束

- 上传驱动必须限制文件类型和大小。
- 元数据同步不能前端假进度；需要真实任务状态或明确轮询限制。

## 验收

- [x] 三类页面使用一致 PageHeader、表格、状态 Tag 和详情抽屉。
- [x] 每个页面都有空态下一步按钮。
- [x] 元数据同步结果能进入资产目录。
- [x] 错误状态有可读原因。
