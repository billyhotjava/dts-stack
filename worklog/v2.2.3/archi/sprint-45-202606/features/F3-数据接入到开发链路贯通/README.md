# F3: 数据接入到开发链路贯通

**状态**: DONE  
**优先级**: P0  
**目标**: 从数据源、入湖、转换、建模到任务编排形成连续操作流，避免接入页、开发页和运维页割裂。

## Task 列表

| ID | Task | 状态 | 验收重点 |
|----|------|------|----------|
| T01 | 数据源页面接入动作闭环 | DONE | 数据源能进入测试、发现表、入湖任务、链路 |
| T02 | ETL 转换与任务编排动作闭环 | DONE | 转换、调度、实例、日志、补数可串联 |
| T03 | 连接器、驱动和元数据页面组件统一 | DONE | 基础资源页有一致动作和状态 |
| T04 | Studio 建模上下文桥接 | DONE | 项目、SQL 建模、dbt 文件和发布门禁连起来 |

## 完成标准

- [x] 数据源创建后有明确下一步：发现表、创建入湖任务、进入建模。
- [x] 任务运行结果能回到运维实例和黄金链路状态。
- [x] 建模页面能识别来源数据源/项目/主题。
- [x] 基础资源页不再像孤立配置后台。
