# T02: ETL 转换与任务编排动作闭环

**状态**: DONE  
**优先级**: P0  
**涉及路由**: `/explore/etl/transform`, `/explore/etl/orchestration`, `/ops/instances`, `/ops/backfill`

## 目标

把转换、编排、实例、日志、补数连成一个操作闭环，让用户能从开发动作看到运行结果，也能从运维异常反查开发对象。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建转换 | 主按钮 | 创建转换任务 |
| 运行 | 主/次按钮 | 触发一次运行 |
| 停止 | 危险按钮 | 停止运行中实例 |
| 重跑 | 次按钮 | 重跑失败实例 |
| 补数 | 次按钮 | 打开补数参数 Drawer |
| 查看日志 | 次按钮 | 打开运行日志 |
| 查看源任务 | 次按钮 | 从实例跳回转换/编排定义 |

## 组件清单

- `TransformTaskList`: 转换任务列表。
- `OrchestrationDagList`: 编排/DAG 列表。
- `RunInstanceTable`: 最近运行实例。
- `RunLogDrawer`: 日志抽屉。
- `BackfillDrawer`: 补数参数、时间范围、影响说明。
- `TaskLineageMiniMap`: 上下游任务关系。

## 数据约束

- 运行和停止必须接真实任务接口。
- 补数要显示影响时间范围和目标表。
- 运行实例必须带回源任务 ID，用于反向跳转。

## 验收

- [x] 转换页能触发运行并看到实例入口。
- [x] 实例页能反查源任务。
- [x] 失败实例有重跑/查看日志按钮。
- [x] 补数动作有参数确认和影响说明。
