# T03: 数据大屏管理动作闭环

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/bi/screens`

## 目标

把数据大屏管理做成完整交付中心：新建、编辑、预览、发布、复制、导出、删除都有清晰状态和真实动作。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建大屏 | 主按钮 | 打开模板/空白新建 |
| 编辑 | 次按钮 | 进入设计器 |
| 预览 | 次按钮 | 打开预览 |
| 发布 | 主按钮 | 发布到可访问地址 |
| 复制 | 次按钮 | 复制大屏配置 |
| 导出 | 次按钮 | 导出配置或截图 |
| 删除/下线 | 危险按钮 | 二次确认并展示访问影响 |

## 组件清单

- `ScreensPage`: 大屏管理列表。
- `ScreenTemplatePicker`: 模板选择。
- `ScreenStatusTag`: 草稿、已发布、下线、异常。
- `ScreenPreviewDrawer`: 预览。
- `ScreenPublishModal`: 发布范围、权限、地址。
- `ScreenDeleteConfirm`: 删除/下线确认。

## 数据约束

- 发布必须关联真实数据集或展示门禁缺失。
- 预览失败不能显示静态假图；必须展示错误状态。

## 验收

- [x] 大屏列表有完整行操作。
- [x] 新建和编辑进入真实设计器或明确外链。
- [x] 发布后展示访问地址和权限状态。
- [x] 删除/下线有二次确认。
