# T01: 指标中心客户化壳层与命名

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/bi-apps/metrics/center`, `/bi-apps/metrics/assets`, `/bi-apps/metrics/semantic`, `/bi-apps/metrics/publish`

## 目标

指标中心即使暂时使用 iframe，也必须有平台产品壳层、客户化命名和加载/失败/权限状态。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建指标 | 主按钮 | 进入指标创建流程 |
| 发布指标 | 主按钮 | 进入发布门禁 |
| 查看血缘 | 次按钮 | 跳转指标/资产血缘 |
| 创建报表 | 次按钮 | 使用指标创建 BI 报表 |
| 返回工作台 | 次按钮 | 回到数据管理主题 |
| 刷新 | 次按钮 | 重新加载 iframe 或原生数据 |

## 组件清单

- `MetricsProductFrame`: 指标中心平台壳层。
- `IframeLoadingState`: 加载中。
- `IframeErrorState`: 加载失败、重试、打开新窗口。
- `MetricsContextHeader`: 指标主题、来源资产、发布状态。
- `MetricsActionBar`: 新建、发布、报表、血缘。

## 命名约束

- 客户页面显示“指标中心、指标资产、语义模型、发布管理”。
- 避免显示 Sprint、F1/F2、dts-metrics 内部模块名。

## 验收

- [x] 指标入口有平台 PageHeader 和返回入口。
- [x] iframe 加载失败有错误状态，不白屏。
- [x] 指标动作能回到资产/BI/工作台。
- [x] 客户可见文案无工程阶段名。
