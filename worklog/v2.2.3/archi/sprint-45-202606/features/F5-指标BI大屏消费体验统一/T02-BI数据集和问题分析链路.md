# T02: BI 数据集和问题分析链路

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/bi/data`, `/bi/questions`, `/bi/dashboards`

## 目标

让 BI 页面承接治理后的资产、指标和数据产品，用户能从资产创建报表、保存问题、发布看板。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 选择数据集 | 主按钮 | 打开数据集选择 |
| 预览数据 | 次按钮 | 展示样例数据 |
| 新建问题 | 主按钮 | 创建分析问题 |
| 运行 | 主按钮 | 执行查询/分析 |
| 保存为图表 | 次按钮 | 保存问题结果 |
| 新建看板 | 主按钮 | 创建看板 |
| 发布/分享 | 主按钮 | 发布看板或配置分享 |
| 删除图表 | 危险按钮 | 二次确认删除 |

## 组件清单

- `DatasetPicker`: 治理后数据集选择。
- `DatasetPreviewTable`: 数据预览。
- `QuestionBuilder`: 分析问题构建。
- `QueryResultPanel`: 表格/图表结果。
- `DashboardList`: 看板列表。
- `DashboardPublishPanel`: 发布、权限、分享设置。

## 数据约束

- 数据集必须来自已发布资产、指标或数据产品。
- 发布看板前检查权限和数据集可用性。

## 验收

- [x] 从资产或数据产品进入 BI 时自动带入数据集。
- [x] 问题运行失败有明确错误。
- [x] 看板发布后能回链到工作台/数据产品。
- [x] 删除图表需要二次确认。
