# T04: 增强分析工具归位

**状态**: DONE  
**优先级**: P2  
**涉及页面**: ReportFactory、MetricLens、NL2SQL、实验型分析页面

## 目标

把增强分析工具放到“辅助能力/高级分析”位置，不让实验页抢占数据中台默认主链路。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 进入高级分析 | 次按钮 | 打开增强分析工具集合 |
| 从资产生成分析 | 次按钮 | 带资产上下文进入工具 |
| 保存为报表 | 次按钮 | 将结果保存到 BI |
| 查看生成依据 | 次按钮 | 展示使用的数据集、字段、提示词 |
| 清空会话 | 危险按钮 | 二次确认清空本次分析 |

## 组件清单

- `AdvancedAnalyticsHub`: 高级分析工具入口。
- `ToolCard`: 工具卡片。
- `SourceContextPanel`: 来源资产/指标/数据产品。
- `GeneratedResultPanel`: 生成结果。
- `ProvenancePanel`: 生成依据和风险提示。

## 约束

- 工具页必须说明来源数据和权限状态。
- 生成结果不能自动发布，必须经过保存/发布动作。

## 验收

- [x] 增强工具不作为默认主菜单首屏。
- [x] 从资产进入工具时带上下文。
- [x] 生成结果保存到 BI 或数据产品有真实动作。
- [x] 生成依据可见。
