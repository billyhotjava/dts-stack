# T02: 黄金链路详情抽屉与证据组件

**状态**: DONE  
**优先级**: P0  
**涉及页面**: 工作台、资产、服务、运维

## 目标

任何主题或链路都能打开详情抽屉，看到从数据源到消费交付的证据，而不是只看到一个状态数字。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 查看链路详情 | 次按钮 | 打开黄金链路详情抽屉 |
| 查看源数据 | 次按钮 | 跳转数据源或源表 |
| 查看质量报告 | 次按钮 | 跳转质量报告 |
| 查看血缘 | 次按钮 | 跳转血缘图 |
| 导出验收证据 | 次按钮 | 导出或进入审计证据页面 |
| 关闭 | 次按钮 | 关闭抽屉并保持当前筛选 |

## 组件清单

- `GoldenChainDetailDrawer`: 链路详情。
- `ChainStageTimeline`: 阶段时间线。
- `EvidenceTagList`: 数据源、任务、模型、质量、权限、报表/API 证据 Tag。
- `BlockedReasonPanel`: 阻断原因、责任人、下一步。
- `ChainObjectLinks`: 源表、模型、资产、产品、API、报表链接。

## 数据约束

- 证据项必须带 `type`、`name`、`status`、`route` 或不可跳转原因。
- 导出证据若后端未具备，按钮禁用并指向 F6-T05。

## 验收

- [x] 工作台主题能打开链路详情。
- [x] 详情抽屉能跳转到至少数据源、资产、运维三类对象。
- [x] 阻断链路展示明确原因和下一步。
- [x] 已完成链路展示消费侧交付物。
