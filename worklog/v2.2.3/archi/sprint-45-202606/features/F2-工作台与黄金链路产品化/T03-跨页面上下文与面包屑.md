# T03: 跨页面上下文与面包屑

**状态**: DONE  
**优先级**: P0  
**涉及页面**: 工作台、数据源、治理、资产、BI、服务、运维

## 目标

用户从工作台进入任何模块后，页面都知道来源主题、链路或资产，避免像进入独立工具。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 返回工作台 | 次按钮 | 回到原主题/链路 |
| 查看关联资产 | 次按钮 | 跳转资产目录并保留上下文 |
| 查看关联任务 | 次按钮 | 跳转运维实例并保留上下文 |
| 清除上下文 | 次按钮 | 取消主题过滤，回到全局视图 |

## 组件清单

- `ContextBreadcrumb`: 工作台 > 主题 > 链路 > 当前对象。
- `ContextTagBar`: 当前主题、资产、链路、任务 Tag。
- `ReturnToWorkbenchButton`: 固定返回入口。
- `ContextQueryAdapter`: 统一 query 参数，如 `themeId`、`chainId`、`assetId`。

## 实现要点

- 统一跨页面 query 参数，不让每个页面自定义一套。
- PageHeader 展示当前上下文，表格筛选默认带入上下文。
- 清除上下文后保留用户所在页面，不强制跳走。

## 验收

- [x] 从工作台跳到数据源/资产/运维后面包屑可返回。
- [x] 上下文 Tag 与筛选条件一致。
- [x] 刷新页面后上下文仍可恢复。
- [x] 无效上下文不会导致白屏。
