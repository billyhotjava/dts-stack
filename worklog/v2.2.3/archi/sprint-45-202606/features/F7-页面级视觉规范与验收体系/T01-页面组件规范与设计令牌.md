# T01: 页面组件规范与设计令牌

**状态**: DONE  
**优先级**: P0  
**涉及模块**: `dts-platform-webapp`, `dts-analytics-webapp/modern`

## 目标

统一页面骨架、表格、抽屉、状态 Tag、确认弹窗和证据组件，减少每个页面各写一套。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 主要动作 | 主按钮 | 由 PageHeader 或 ActionPanel 管理 |
| 更多操作 | 图标/菜单按钮 | 展示低频动作 |
| 关闭抽屉 | 图标按钮 | 关闭 DetailDrawer |
| 确认 | 主按钮 | 提交 Modal/Drawer |
| 取消 | 次按钮 | 关闭不保存 |

## 组件清单

- `PageHeader`
- `ActionPanel`
- `CompactTable`
- `DetailDrawer`
- `EntityStatusTag`
- `ConfirmModal`
- `EmptyState`
- `ErrorState`
- `PermissionState`
- `LoadingState`
- `EvidencePanel`

## 设计约束

- 管理后台页面保持高信息密度，不做营销式大卡片堆叠。
- 卡片圆角控制在既有设计系统范围内。
- 表格、工具栏、按钮尺寸稳定，不因内容加载造成布局跳动。

## 验收

- [x] 核心页面复用统一组件或明确例外原因。
- [x] 表格行操作和详情抽屉行为一致。
- [x] 状态 Tag 文案和颜色一致。
- [x] 响应式下按钮不重叠、不溢出。
