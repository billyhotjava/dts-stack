# T02: 按钮图标文案规范

**状态**: DONE  
**优先级**: P0  
**涉及页面**: 所有核心业务页面

## 目标

统一按钮分级、图标、文案和禁用原因，让用户知道每个动作的后果。

## 按钮清单

| 类型 | 示例 | 规范 |
|------|------|------|
| 主按钮 | 新建数据源、处理阻断项、发布数据产品 | 每页最多 1 个主流程按钮 |
| 次按钮 | 查看链路、预览数据、查看日志、刷新 | 可多个，放在 ActionPanel 或行操作 |
| 危险按钮 | 删除、下线、撤销、终止 | 必须 ConfirmModal |
| 图标按钮 | 复制、编辑、下载、更多 | 必须 tooltip |
| 禁用按钮 | 发布、生成报表、启用 API | 必须说明缺少什么 |

## 组件清单

- `PrimaryActionButton`
- `SecondaryActionButton`
- `DangerActionButton`
- `IconTooltipButton`
- `DisabledReasonTooltip`
- `ActionOverflowMenu`

## 文案约束

- 使用客户语言：“发布数据产品”“申请权限”“查看血缘”“处理告警”。
- 避免“执行 artifact”“运行 F1”“打开 iframe”等内部表达。
- 危险动作使用明确动词：“下线”“撤销”“终止”“删除”。

## 验收

- [x] 页面主按钮数量符合规范。
- [x] 图标按钮有 tooltip。
- [x] 禁用按钮展示原因和下一步。
- [x] 危险按钮有二次确认和影响范围。
