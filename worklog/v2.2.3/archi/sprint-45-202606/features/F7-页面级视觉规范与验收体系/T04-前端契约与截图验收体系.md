# T04: 前端契约与截图验收体系

**状态**: DONE  
**优先级**: P0  
**涉及模块**: `dts-platform-webapp`, `dts-admin-webapp`, `dts-analytics-webapp/modern`

## 目标

建立自动化验收，防止“页面存在但按钮没动作、菜单指向空页面、接口用假数据”。

## 按钮清单

| 验收对象 | 必查按钮 |
|----------|----------|
| 工作台 | 处理阻断项、配置数据源、查看资产、发布 API |
| 数据源 | 新建、测试连接、发现表、创建入湖任务 |
| 建模 | 新建模型、预览、校验、发布 |
| 治理 | 运行质量、修复阻断、查看报告 |
| 资产 | 申请权限、查看血缘、创建报表、生成数据产品 |
| 大屏 | 新建、编辑、预览、发布、删除 |
| API/令牌 | 新建/测试/启用、生成/复制/撤销 |
| 运维 | 重试、补数、查看日志、查看源任务 |

## 组件清单

- `MenuRouteContractTest`
- `ButtonActionContractTest`
- `PageStateContractTest`
- `PlaywrightMenuSmoke`
- `ScreenshotEvidence`

## 验收命令

```bash
cd source/dts-platform-webapp

```

```bash
cd source/dts-analytics-webapp/modern
pnpm typecheck
pnpm build
```
