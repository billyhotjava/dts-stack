# T01: 菜单-路由-组件可达性契约

**状态**: DONE  
**优先级**: P0  
**涉及页面/文件**: `portal-menu-seed.json`, `role-menu-defaults.json`, `static-routes.tsx`, `dynamic-resolver.tsx`

## 目标

建立一张自动化契约表：每个客户可见菜单叶子必须能解析到真实页面组件、外部链接或明确下线记录。

## 按钮清单

| 按钮 | 页面位置 | 目标行为 |
|------|----------|----------|
| 刷新菜单 | 菜单契约调试/测试页或测试用例 | 重新读取菜单并验证 resolver |
| 返回工作台 | fallback/异常页 | 回到 `/workbench/data-management` |
| 申请权限 | 403/权限不足页 | 跳转权限申请或展示申请入口 |
| 查看详情 | 契约失败列表 | 展示失败菜单项、路由、期望组件 |

## 组件清单

- `NavigationShell`: 左侧菜单、顶部面包屑、当前模块高亮。
- `RouteContractGuard`: 捕获未注册路由、未知组件、外链缺失。
- `NotFoundState`: 404 页面必须展示返回按钮和问题说明。
- `PermissionState`: 权限不足不能伪装成空态。
- `RouteContractReport`: 测试中输出菜单项、path、component、owner、状态。

## 实现要点

- 从菜单 seed 提取所有 leaf item，覆盖 `externalLink`、`path`、`component`、`children`。
- 对照静态路由和动态 resolver，生成通过/失败清单。
- 对失败项分类：缺组件、缺路由、权限隐藏、计划下线、外链未配置。
- 把 `/workbench/todo`、`/studio/projects`、`/studio/sql-modeling` 标为 P0 失败项直到修复。

## 验收

- [x] source-contract 能列出所有菜单叶子及解析状态。
- [x] 失败项数量为 0，或每个失败项都有明确下线/延期记录。
- [x] 任一新增菜单叶子没有组件映射时测试失败。
- [x] Playwright smoke 点击全部一级/二级菜单不出现空白页。
