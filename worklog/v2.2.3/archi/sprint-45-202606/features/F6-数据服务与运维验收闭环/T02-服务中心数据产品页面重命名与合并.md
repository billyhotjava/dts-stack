# T02: 服务中心数据产品页面重命名与合并

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/services/products`

## 目标

修正服务中心“数据推送/数据产品”语义不一致问题，并与资产门户数据产品生命周期合并。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建数据产品 | 主按钮 | 创建统一数据产品 |
| 查看来源资产 | 次按钮 | 跳转资产详情 |
| 配置消费方式 | 次按钮 | API、BI、下载、令牌 |
| 发布 | 主按钮 | 通过门禁后发布 |
| 下线 | 危险按钮 | 下线并展示影响 |

## 组件清单

- `ServiceDataProductPage`: 服务视角产品页。
- `ProductSourceAssetPanel`: 来源资产。
- `ConsumptionConfigPanel`: 消费方式配置。
- `ProductLifecycleTimeline`: 创建、治理、发布、使用、下线。

## 收口要求

- 页面标题与菜单统一为“数据产品”或“数据产品服务”。
- 不再使用“数据推送”作为产品列表名。
- 与 `/catalog/data-products` 复用数据模型和详情组件。

## 验收

- [x] 服务中心产品页和资产产品页状态一致。
- [x] 菜单/标题/面包屑命名一致。
- [x] 发布和下线动作有门禁/影响说明。
