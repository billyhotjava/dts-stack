# T05: 事件审计发布治理入口显性化

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/ops/events`, `/ops/audit-evidence`, `/ops/release-governance`

## 目标

把已有但隐藏的事件、审计证据、发布治理路由纳入运维验收中心，形成客户交付证据。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 查看事件 | 次按钮 | 打开事件流 |
| 导出证据 | 主按钮 | 导出审计证据包 |
| 发布复核 | 主按钮 | 发起发布治理复核 |
| 查看关联链路 | 次按钮 | 跳转黄金链路详情 |
| 撤回发布 | 危险按钮 | 二次确认撤回发布申请 |

## 组件清单

- `OpsEvidenceNav`: 运维验收导航。
- `EventStreamTable`: 事件流。
- `AuditEvidencePackage`: 证据包。
- `ReleaseGovernancePanel`: 发布门禁与复核。
- `EvidenceExportModal`: 导出范围、格式、时间。

## 数据约束

- 事件和审计记录必须有时间、对象、操作人、结果。
- 导出证据若接口缺失，必须禁用并标记后端 blocker。

## 验收

- [x] 三个隐藏路由有菜单或明确入口。
- [x] 审计证据能按对象/时间筛选。
- [x] 发布复核能看到门禁结果。
- [x] 导出动作不使用静态文件假下载。
