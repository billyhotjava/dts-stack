# T01: 数据 API 管理动作闭环

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/services/apis`

## 目标

让数据 API 页面从接口列表升级为服务发布入口，覆盖创建、测试、启停、调用统计、审计和来源追溯。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建 API | 主按钮 | 从资产/数据产品创建 API |
| 测试调用 | 主/次按钮 | 打开请求参数并执行测试 |
| 启用 | 主按钮 | 发布 API |
| 禁用 | 危险按钮 | 停止 API 并展示影响调用方 |
| 复制地址 | 图标按钮 | 复制 API URL 并提示成功 |
| 查看调用 | 次按钮 | 打开调用统计 |
| 查看审计 | 次按钮 | 打开变更/调用审计 |

## 组件清单

- `ApiServiceTable`: API 列表。
- `ApiCreateWizard`: 来源资产、参数、权限、限流、发布。
- `ApiTestDrawer`: 请求参数、响应、错误。
- `ApiStatusTag`: 草稿、启用、禁用、异常。
- `ApiUsagePanel`: 调用量、失败率、最近调用。
- `ApiAuditDrawer`: 发布、禁用、调用审计。

## 数据约束

- 新建 API 必须绑定资产、数据产品或明确自定义来源。
- 启用前检查权限、质量、限流和责任人。

## 验收

- [x] API 能从资产/数据产品上下文创建。
- [x] 测试调用显示真实响应或错误。
- [x] 禁用前展示影响调用方。
- [x] 调用统计和审计入口可见。
