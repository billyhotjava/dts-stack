# T03: 共享交换令牌页面安全化

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/services/tokens`

## 目标

把“共享交换”页面明确为安全共享凭证管理，覆盖令牌生成、范围、有效期、一次复制、撤销和审计。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 生成令牌 | 主按钮 | 创建带范围和有效期的令牌 |
| 复制令牌 | 图标按钮 | 仅生成后一次性复制 |
| 续期 | 次按钮 | 调整有效期 |
| 撤销 | 危险按钮 | 立即失效令牌 |
| 查看审计 | 次按钮 | 查看生成、复制、调用、撤销记录 |

## 组件清单

- `TokenCreateModal`: 作用域、有效期、用途说明。
- `TokenSecretOncePanel`: 只展示一次的令牌值。
- `TokenScopeSelector`: 数据产品/API/资产范围。
- `TokenTable`: 名称、作用域、有效期、状态。
- `TokenAuditDrawer`: 安全审计。
- `RevokeTokenConfirm`: 撤销影响确认。

## 安全约束

- 令牌明文不能再次查询。
- 复制动作必须给出成功/失败反馈。
- 撤销必须二次确认并展示影响范围。

## 验收

- [x] 生成令牌必须选择作用域和有效期。
- [x] 明文只展示一次。
- [x] 撤销后状态立即更新。
- [x] 审计记录可见。
