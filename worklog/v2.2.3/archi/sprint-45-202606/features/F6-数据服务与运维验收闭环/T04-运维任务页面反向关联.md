# T04: 运维任务页面反向关联

**状态**: DONE  
**优先级**: P1  
**涉及路由**: `/ops/overview`, `/ops/instances`, `/ops/alerts`, `/ops/backfill`

## 目标

运维页面不仅展示运行状态，还能反向定位数据源、任务、模型、资产和黄金链路。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 查看源任务 | 次按钮 | 跳转转换/编排定义 |
| 查看数据源 | 次按钮 | 跳转数据源 |
| 查看资产 | 次按钮 | 跳转资产详情 |
| 重试 | 主/次按钮 | 重试失败实例 |
| 补数 | 次按钮 | 打开补数流程 |
| 查看日志 | 次按钮 | 打开日志抽屉 |
| 创建待办 | 次按钮 | 将告警转成待办 |
| 终止实例 | 危险按钮 | 二次确认终止 |

## 组件清单

- `OpsOverview`: 运行总览。
- `InstanceTable`: 任务实例表。
- `AlertList`: 告警列表。
- `BackfillRequestDrawer`: 补数申请。
- `RunLogDrawer`: 日志。
- `OpsObjectLinks`: 数据源、任务、模型、资产、链路链接。

## 数据约束

- 实例/告警必须带源任务或对象引用；没有时展示“来源缺失”并记录后端依赖。
- 重试/终止必须调用真实运行接口。

## 验收

- [x] 实例能回到源任务。
- [x] 告警能创建待办或进入关联对象。
- [x] 补数有时间范围和影响说明。
- [x] 终止实例有二次确认。
