# 按钮与组件清单

## 按钮分级

| 级别 | 用法 | 示例 | 约束 |
|------|------|------|------|
| 主按钮 | 页面最重要的下一步动作 | 新建数据源、创建入湖任务、发布数据产品 | 每页最多 1 个主按钮，必须有真实动作或禁用原因 |
| 次按钮 | 查看、预览、刷新、跳转 | 查看链路、预览数据、刷新状态 | 可多个，但不能替代主流程 |
| 危险按钮 | 删除、撤销、下线、停用 | 删除令牌、下线 API、禁用调度 | 必须二次确认，展示影响范围 |
| 图标按钮 | 表格行操作或工具栏 | 复制、下载、编辑、更多 | 使用统一图标和 tooltip |
| 禁用按钮 | 依赖未满足的动作 | 发布、生成报表、创建 API | 必须展示禁用原因和下一步 |

## 全局组件

| 组件 | 使用页面 | 必备状态 | 说明 |
|------|----------|----------|------|
| PageHeader | 所有业务页面 | 标题、说明、主按钮、面包屑、上下文 Tag | 不写内部 sprint 语言 |
| Breadcrumb | 跨模块跳转页面 | 来源主题、资产、链路、返回入口 | 保持用户知道自己从哪里来 |
| GoldenChainStepper | 工作台、资产、服务、运维 | 当前阶段、阻断原因、下一步 | 串起数据源到消费链路 |
| EntityStatusTag | 表格/卡片/详情 | 草稿、运行中、阻断、已发布、异常 | 统一颜色与文案 |
| ActionPanel | 工作台、详情页 | 主动作、辅助动作、禁用原因 | 防止按钮散落 |
| EmptyState | 所有列表/详情 | 首次使用、筛选无结果、权限为空 | 给出下一步按钮 |
| ErrorState | API 失败页面 | 重试、查看详情、返回 | 不吞掉接口错误 |
| PermissionState | 权限不足页面 | 申请权限、返回、联系管理员 | 不能显示假空态 |
| LoadingState | 首屏/抽屉/表格 | 骨架屏或明确加载 | 防止页面闪烁 |
| DetailDrawer | 资产、任务、API、令牌、告警 | 详情、血缘、审计、操作 | 表格行默认进入详情抽屉 |
| ConfirmModal | 删除/停用/下线 | 影响范围、确认输入、取消 | 危险动作必需 |
| EvidencePanel | 工作台、运维、发布治理 | 验收项、证据链接、导出 | 客户交付证据 |

## 页面按钮矩阵

| 页面组 | 主按钮 | 次按钮 | 危险按钮 | 行操作 | 禁用原因示例 |
|--------|--------|--------|----------|--------|--------------|
| 工作台 | 处理阻断项 | 查看链路、查看报表、查看运维 | 无 | 进入主题、进入资产 | 缺少数据源、质量未通过 |
| 数据源 | 新建数据源 | 测试连接、发现表、创建入湖任务 | 删除、停用 | 编辑、查看链路、查看任务 | 连接失败、权限不足 |
| ETL/编排 | 新建任务 | 运行、停止、重跑、补数、查看日志 | 删除任务、停用调度 | 查看实例、查看告警 | 上游数据源不可用 |
| Studio | 新建项目/模型 | 导入、预览、校验、生成 ODS | 归档、删除 | 进入 SQL 建模、发布 | 质量门禁未通过 |
| 治理 | 新建规则 | 运行质量、查看报告、修复阻断 | 删除规则、停用规则 | 查看影响资产 | 未绑定责任人 |
| 资产 | 申请权限 | 查看血缘、创建报表、生成数据产品 | 下线资产 | 查看详情、复制路径 | 未完成分级分类 |
| 数据产品 | 新建产品 | 发布、申请、查看消费、导出说明 | 下线、删除 | 查看审计、查看 API | 权限/质量/血缘缺失 |
| 指标/BI | 新建指标/看板 | 预览、运行、保存、分享 | 删除图表、下线看板 | 查看血缘、创建报表 | 语义模型未发布 |
| 大屏 | 新建大屏 | 编辑、预览、发布、复制、导出 | 删除、下线 | 查看投屏地址、查看审计 | 数据集不可用 |
| 数据 API | 新建 API | 测试、启用、复制地址、查看调用 | 禁用、删除 | 查看详情、查看审计 | 数据产品未发布 |
| 令牌 | 生成令牌 | 复制一次、续期、查看审计 | 撤销 | 查看范围、查看调用 | 缺少作用域 |
| 运维 | 处理告警 | 重试、补数、查看日志、查看源任务 | 终止实例 | 创建待办、导出证据 | 无可重试实例 |

## 组件验收清单

- PageHeader 的主按钮不得只是 `console.log`、静态链接或未注册路由。
- 表格行必须至少有“查看详情”，关键业务对象要有“编辑/发布/审计/血缘”中对应动作。
- 所有删除、停用、撤销、下线动作必须有 ConfirmModal。
- 所有复制密钥、复制 API 地址动作必须有成功/失败反馈；令牌只允许一次明文复制。
- 所有发布动作必须展示门禁结果：质量、分级、血缘、权限、责任人。
- 所有 iframe 页面必须有平台壳层：标题、返回、来源上下文、加载失败、权限失败。
- 所有空态必须提供真实下一步按钮，例如“新建数据源”“申请权限”“创建报表”。
