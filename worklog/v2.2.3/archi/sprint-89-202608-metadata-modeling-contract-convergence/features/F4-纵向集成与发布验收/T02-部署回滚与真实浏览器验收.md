**优先级**: P0
**状态**: BLOCKED_INPUT
**依赖**: F4/T01；G0 B01/B02/B04

## 发布安全

- 首选无 schema migration；若实现产生 migration，只允许 Expand，先在生产快照副本 dry-run，并完成 rollback rehearsal。
- 记录发布前镜像 digest/commit、数据库备份或“不涉及迁移”的证据、受影响服务和回滚命令。
- 只重建/部署 `dts-platform` 与 `dts-platform-webapp` 等实际受影响模块；不重启无关服务。
- 先健康检查与授权 API smoke，再执行唯一一次真实浏览器旅程。

## 真实验收

按 `it/README.md` IT-06/08：真实菜单点击、来源五态、diff、竞争 409、兼容继续、破坏阻断、修复重确认、反向建模、编译/发布/物化、Chrome 95 console/network。

## 可运维交付

runbook 至少包含：

- 健康信号：sync run 成功率、drift event 创建/积压、UNKNOWN/STALE/BREAKING binding 数。
- 日志字段：correlationId、runId、tenantId、sourceType、bindingId、assetKey、old/new version、result/reasonCode；不得记录凭据或业务行值。
- 初始告警：采集连续失败、OPEN breaking drift 超时、UNKNOWN 来源增长、重确认 409 激增；阈值由生产画像校准。
- 故障手册：采集不可达、误判 breaking、来源重现未恢复、发布门禁持续 stale、回滚后兼容读。
