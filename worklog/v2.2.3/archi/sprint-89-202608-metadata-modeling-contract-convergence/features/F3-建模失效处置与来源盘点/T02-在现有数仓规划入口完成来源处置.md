**状态**: BLOCKED_INPUT
**依赖**: F3/T01；G0 B01/B02/B04

## UI 规格

在现有 `/data-modeling/planning/spaces` 的 baseline 视图增加“来源盘点”tab，URL 使用 `tab=sources`。不新增一级/二级菜单。

### 页面结构

1. 页头：当前 plan、来源总数、待确认/阻断数量、刷新。
2. 筛选：状态、来源类型、关键词；分页。
3. 表格：来源名称、类型、确认版本、当前版本、变化摘要、状态、操作。
4. 差异抽屉：字段、before/after、单字段影响、是否被当前模型引用。
5. 确认弹窗：只对允许动作启用，明确说明对编译/发布的影响。

### 四态与权限

- loading：保留表格骨架，禁止写动作。
- empty：说明需先从数据资产选择来源，不伪造 demo 数据。
- error：显示稳定 reason code 对应的业务文案与重试。
- read-only：可查看状态/diff，不展示误导性可点击重确认按钮。

### Chrome 95

禁用仅新浏览器支持的 CSS/JS API；表格、抽屉、弹窗、分页、sticky/overflow 必须按 `dts-chrome95-regression` 在集中 E2E 验证。
