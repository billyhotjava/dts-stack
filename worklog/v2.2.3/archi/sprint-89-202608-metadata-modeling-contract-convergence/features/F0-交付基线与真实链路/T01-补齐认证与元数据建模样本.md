# T01: 补齐认证与元数据建模样本

**优先级**: P0
**状态**: BLOCKED_INPUT
**依赖**: 用户/现场提供 B01～B04
**产出**: 可复用的 G0 验收路径，不修改产品代码

## 最小输入

1. 可读 Catalog、可维护 WarehousePlan 来源的授权账号；只在验收工具中使用，不写入 worklog。
2. 一个非敏感测试 schema，允许新增/删除/修改字段并可恢复。
3. 客户侧脱敏量级和 drift 分布。
4. Chrome 95 或等效客户浏览器环境。

## 操作与证据

- 从真实菜单登录并进入数仓规划，记录入口、角色能力结果和 HTTP 状态，不记录身份/token。
- 触发一次采集，记录 runId、dataset/table/column ID 与 fingerprint。
- 通过真实 API/UI 把该表加入现有 WarehousePlan 并重载，确认绑定持久化。
- 将 `it/baseline.md` P2/P4/P5/P6 与 `assets/domain-profile.md` 生产画像补齐。
