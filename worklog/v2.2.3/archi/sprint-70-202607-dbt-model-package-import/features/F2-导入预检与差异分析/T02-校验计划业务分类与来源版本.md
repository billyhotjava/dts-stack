# T02：校验计划、业务分类与来源版本

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

把包内稳定业务标识解析到当前租户和计划的真实上下文，不接收客户端伪造引用。

## 技术设计

- 使用服务端 actor/tenant，校验计划生命周期和维护权限。
- domain 只允许当前计划已确认业务分类。
- dbt source relation 解析到 `CONFIRMED + CURRENT + AVAILABLE` SourceBinding。
- 返回已保存版本、当前版本和修复入口；不静默升级。

## 影响范围

- WarehousePlan/domain/source inventory 查询端口。
- preview context mapping。

## 验证

- [ ] 跨租户、归档计划、未确认分类和无权限均 fail closed。
- [ ] relation 同名歧义要求人工选择。
- [ ] 来源版本漂移在预检矩阵可见。

## 完成标准

- [ ] 包内不需要也不能直接指定目标环境 UUID 真值。
- [ ] apply 所需精确来源版本进入 previewHash。
