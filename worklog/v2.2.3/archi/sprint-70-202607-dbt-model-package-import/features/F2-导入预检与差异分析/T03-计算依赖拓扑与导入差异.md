# T03：计算依赖拓扑与导入差异

**优先级**: P0  
**状态**: DONE  
**依赖**: T01、T02

## 目标

将 dbt dependency 转换为可应用的 ModelSpec 拓扑，并计算逐项动作。

## 技术设计

- 保留 technical node 后压缩 canonical-to-canonical dependency。
- 检测缺失节点、循环、非法反向分层和跨计划引用。
- 根据 dbt uniqueId、现有 ownership、package checksum 和 ModelSpec checksum 判定：
  `CREATE / UPDATE / SKIP / CONFLICT / BLOCKED`。
- 更新只能创建新 revision，不覆盖已发布历史。

## 影响范围

- preview dependency/diff service。
- ModelSpec 候选与 ownership 查询。

## 验证

- [ ] 拓扑顺序稳定，STG 中转不会断开上下游。
- [ ] 循环和缺失依赖显示完整 chain。
- [ ] 同内容为 SKIP，内容变化为 UPDATE，所有权冲突为 CONFLICT。

## 完成标准

- [ ] 每个 action 有可复核依据。
- [ ] 不靠模型名称猜测同一性。
