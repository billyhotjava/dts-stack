# T01：建立预检运行与包解析服务

**优先级**: P0  
**状态**: DONE  
**依赖**: F1

## 目标

建立可恢复、严格零写入的导入预检运行。

## 技术设计

- 接收模型包与选定节点，服务端校验 schema、checksum、大小和权限。
- 保存 preview run、规范化请求、previewHash、逐项结果和过期时间。
- 解析器与 apply 解耦，不要求预先存在 ModelSpec/implementation。
- 预检不得写 ModelSpec、artifact、dbt workspace 或来源盘点。

## 影响范围

- `source/dts-platform` import run repository/service/resource。
- Liquibase 预检运行与逐项结果表。

## 验证

- [ ] 合法包产生可查询 preview run。
- [ ] 预检前后 canonical 表与 dbt artifact 表无变化。
- [ ] 大包、错 checksum 和非法 schema 在解析前阻断。

## 完成标准

- [ ] runId 可恢复同一预检结果。
- [ ] previewHash 可供 apply 防 TOCTOU。
