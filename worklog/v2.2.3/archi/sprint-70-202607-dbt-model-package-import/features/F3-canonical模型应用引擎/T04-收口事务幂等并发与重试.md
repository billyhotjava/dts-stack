# T04：收口事务、幂等、并发与重试

**优先级**: P0  
**状态**: IN_PROGRESS  
**依赖**: T01、T02、T03

## 目标

保证批量 apply 可解释、可重放，单个候选失败不留下半成品。

## 技术设计

- 每候选执行 `ModelSpec → implementation → artifact` 独立事务。
- 批次继续处理不依赖失败候选的其他分支；依赖失败的下游标记 BLOCKED。
- 使用 batch key + dbtUniqueId 派生候选幂等键。
- 同键异载荷、preview stale、CAS 漂移和并发 node claim fail closed。
- retry 只接受原 run 中失败且上下文未漂移的候选。

## 影响范围

- apply transaction coordinator。
- import run/result/audit repository。

## 验证

- [ ] 三步任一失败均回滚该候选。
- [ ] 并发 claim 只有一个成功。
- [ ] 同载荷 replay 不增加 revision/artifact。
- [ ] retry 不重复成功项。

## 完成标准

- [ ] 每项结果含稳定状态、modelSpecId/revision 和 issue。
- [ ] 审计可还原预检、确认、应用和重试链路。
