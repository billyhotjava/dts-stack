# T01：增加建模工作台计划级导入入口

**优先级**: P0  
**状态**: READY  
**依赖**: F2/T04

## 目标

在建模工作台当前计划上下文中提供清晰的“导入已有模型”入口。

## 技术设计

- 入口位于当前计划卡片动作区，作为次主按钮，不新增一级菜单。
- 自动携带并锁定 planId。
- 无计划、只读、发布中、已归档或上下文读取失败时禁用并解释原因。
- 与模型中心共用 route/state 和导入向导组件。

## 影响范围

- `ModelingWorkbenchPage.tsx`。
- 工作台阶段投影与权限状态。

## 验证

- [ ] 切换计划后入口使用最新 planId。
- [ ] 禁用原因可见且不能靠深链绕过。
- [ ] Chrome 95 下动作层级清楚，不挤压当前主动作。

## 完成标准

- [ ] 首次用户无需先进入高级 SQL/dbt 页面即可发现导入。
- [ ] 工作台不复制导入业务状态。
