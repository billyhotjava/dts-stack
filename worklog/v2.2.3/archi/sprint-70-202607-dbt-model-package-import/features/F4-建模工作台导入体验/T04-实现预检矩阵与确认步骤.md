# T04：实现预检矩阵与确认步骤

**优先级**: P0  
**状态**: READY  
**依赖**: F2/T04、T03

## 目标

用一张可操作矩阵展示导入动作、转换方式、依赖和阻断，并在确认前形成明确影响摘要。

## 技术设计

- 列出模型、类型/层、转换方式、来源/上游、action、issue。
- READY 默认选中；BLOCKED/CONFLICT 不可选。
- 行详情展示粒度、字段、revision pin、SQL/config 差异和修复入口。
- 确认页按新增/更新/跳过/阻断汇总，不把 preview 称为成功。
- preview stale 时保留选择并要求重新预检。

## 影响范围

- PreviewMatrix、CandidateDetail、ConfirmSummary 组件。
- preview API view model。

## 验证

- [ ] 大量模型支持搜索、过滤和稳定选择。
- [ ] 状态不只靠颜色表达。
- [ ] UPDATE 可看到新旧差异。

## 完成标准

- [ ] 用户能在提交前明确知道将创建和不会创建什么。
- [ ] apply 请求只包含当前 preview 可选候选。
