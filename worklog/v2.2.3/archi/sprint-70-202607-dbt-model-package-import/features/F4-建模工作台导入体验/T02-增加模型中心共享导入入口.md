# T02：增加模型中心共享导入入口

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

在模型中心提供就近导入入口，并与工作台共享完整上下文和流程。

## 技术设计

- 在“新建模型”旁增加“导入模型包”次按钮。
- 带 planId 时锁定；无 planId 时先明确选择计划。
- 导入完成后刷新当前计划模型列表并保留筛选。
- 旧 SQL/dbt 导入入口增加主线说明，但保持兼容。

## 影响范围

- `ModelCenterPage.tsx`。
- 路由 query/context helper。

## 验证

- [ ] 两个入口打开同一向导和同一 runId 状态。
- [ ] 无上下文时不能直接上传后隐式选择计划。
- [ ] 导入后只刷新相关列表。

## 完成标准

- [ ] 模型中心无第二套导入实现。
- [ ] 不新增菜单和重复台账。
