# T01: 数据源表单系统类型与连接器统一

**优先级**: P0  
**状态**: DONE  
**依赖**: F0

## 目标

让 `/foundation/data-sources` 的新增/编辑表单统一使用平台系统类型和连接器目录，避免页面内硬编码类型。

## 技术设计

- 系统类型优先读取 `/platform/dict/system-types`。
- 连接器优先读取 `/infra/connectors`。
- 选择连接器后可辅助推荐系统类型，但不得覆盖用户已有选择。
- API 不可用时显示可读空态和维护入口。

## 影响范围

- `source/dts-platform-webapp/src/pages/foundation/DataSourceFormModal.tsx`
- `source/dts-platform-webapp/src/api/services/dictionaryService.ts`
- `source/dts-platform-webapp/src/pages/foundation/DataSourcesPage.source-contract.test.ts`

## 实施记录

- 数据源表单新增系统类型字典加载，优先读取 `/platform/dict/system-types`。
- 接口 404、异常或返回空列表时保留内置类型作为兜底，页面显示可读告警和维护入口。
- 连接器目录仍通过现有 `/infra/connectors` 串到数据源创建表单，不新增菜单或 `/v2` 页面。
