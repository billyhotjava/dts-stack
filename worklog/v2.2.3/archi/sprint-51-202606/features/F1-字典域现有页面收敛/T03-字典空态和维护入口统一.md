# T03: 字典空态和维护入口统一

**优先级**: P1  
**状态**: READY  
**依赖**: T01 T02

## 目标

统一字典为空、接口不可用、权限不足时的页面反馈。

## 技术设计

- 空态要说明“暂无系统类型/参考码/术语”，并给出可维护页面。
- 权限不足要说明“联系管理员维护”，不显示假按钮。
- 接口失败要展示轻量错误提示，不阻断页面其它区域。

## 影响范围

- 数据源表单
- 标准管理三页
- SQL 建模页字段标准映射

## 验证

- [ ] source-contract 覆盖空态文案和按钮禁用原因。
- [ ] Chrome95 下空态布局不撑破表单/抽屉。

## 完成标准

- [ ] 客户不会看到无解释的空白下拉或空表格。
