# T02: 现有页面承载矩阵确认

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

逐页确认当前 v2.2.3 已有页面能承载哪些横切职责域，避免新菜单和重复页面。

## 技术设计

重点核对：

- `/foundation/data-sources`
- `/foundation/connectors`
- `/catalog/assets`
- `/catalog/datasets/:id`
- `/catalog/lineage/*`
- `/governance/standards/*`
- `/governance/quality`
- `/governance/asset-grants`
- `/studio/sql-modeling`
- `/workbench`

## 影响范围

- `assets/existing-page-cross-domain-matrix.md`

## 验证

- [ ] 每个 P0 页面有现有 route、主按钮、详情/抽屉或跳转落点。
- [ ] 无法承载的能力登记到 API/页面缺口，不直接新增页面。

## 完成标准

- [ ] 页面矩阵可以作为后续编码 source-contract 的输入。
