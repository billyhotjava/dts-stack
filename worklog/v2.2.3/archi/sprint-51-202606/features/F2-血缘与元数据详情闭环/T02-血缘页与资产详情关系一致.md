# T02: 血缘页与资产详情关系一致

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

资产详情里的血缘摘要与 `/catalog/lineage/*` 页面使用一致的数据来源和跳转上下文。

## 技术设计

- 资产详情优先使用 `/catalog/assets-v2/{id}/lineage`。
- 降级到 `/catalog/datasets/{id}/lineage` 时要明确展示“血缘信息可能不完整”。
- `/catalog/lineage/graph?datasetId=...` 可从资产详情跳转。

## 影响范围

- `DatasetDetailPage`
- `LineagePage` / `LineageGraphPage`
- `lineageShared.tsx`

## 验证

- [ ] 资产详情和血缘图页面对同一 datasetId 的节点/边数量一致或有明确降级说明。
- [ ] 无血缘时提供同步或诊断入口。

## 完成标准

- [ ] 客户可以从资产详情追到来源和下游。
