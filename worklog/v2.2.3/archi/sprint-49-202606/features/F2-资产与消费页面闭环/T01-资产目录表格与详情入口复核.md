# T01: 资产目录表格与详情入口复核

**优先级**: P0
**状态**: DONE
**依赖**: F1

## 目标

让 `/catalog/assets` 资产地图与台账能够承接资产详情、治理、血缘、报表、数据产品和数据 API 的真实下一步。

## 技术设计

- `DatasetsPage` 增加 `ASSET_TABLE_SCROLL_X=1760` 与 `ASSET_ACTION_COLUMN_WIDTH=640`。
- 台账表格设置 `tableLayout="fixed"` 与 `className="catalog-assets-table"`。
- 操作按钮区使用 `catalog-assets-actions`，禁止在 Chrome 95/1366x768 下换行。
