# T03: 业务消费入口语言与空态复核

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

保留唯一 `/workbench` 首页，把旧 `/services/consumption` 和数据产品消费入口收敛到工作台内的消费发布 section。

## 技术设计

- `WorkbenchPage` 同时识别 `section=data-management` 与 `section=consumption`。
- `DataManagementWorkbenchPage` 增加 `focus` 与 `productId`，在消费模式展示“消费发布”上下文。
- `static-routes` 与 `dynamic-resolver` 的 legacy redirect 保留 query 参数，避免丢失 `productId`。

- `source/dts-platform-webapp/src/pages/workbench/index.tsx`

- `source/dts-platform-webapp/src/routes/sections/dashboard/dynamic-resolver.tsx`
