# T02: 数据服务按钮闭环复核

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

让数据产品卡片上的发布、申请、查看消费、审计、合同、下线、编辑和删除按钮都有明确状态或交接路径。

## 技术设计

- `DataProductsPage` 增加 `DEFAULT_CONSUMER_ENTRY=/workbench?section=consumption`。
- 新增 `resolveConsumerEntryRoute(product)`，无专属消费入口时带 `productId` 进入唯一工作台。
- “发布”按钮增加 Tooltip，禁用时展示缺口原因。
- 删除“查看消费”对 `consumerEntry` 的硬禁用，改为默认交接到消费发布 section。
