# T01: 连接器目录表格布局修复

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

修复连接器目录页面中表格列宽错乱、能力标签被挤压、操作按钮换行堆叠的问题。

## 技术设计

- 在 `ConnectorRegistryPage` 内收敛页面级表格布局，不修改全局 `CompactTable` 默认行为。
- 为能力列、状态列、时间列、操作列定义稳定宽度。
- 操作列使用 nowrap 容器，避免 1366x768 下变成多行按钮堆叠。
- 能力标签在表格紧凑视图中不换行，只展示前 2 个能力和 `+N`，避免被固定操作列遮挡。
