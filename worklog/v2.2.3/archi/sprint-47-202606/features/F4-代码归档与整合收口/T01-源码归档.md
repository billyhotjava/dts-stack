# T01: 源码归档/移出构建

**优先级**: P1
**状态**: READY
**依赖**: F2, F3

## 目标
把 dts-metrics 源码移出构建，保留 git 历史可追溯（**不删历史**）。

## 技术设计
- 从根 `pom.xml`/构建 workspace 移除 `dts-metrics` 模块；前端 `dts-metrics-webapp` 移出构建/CI。
- 处置方式（择一，倾向 a）：
  - **a** 保留目录 + 加 `ARCHIVED.md`（说明退役原因/日期/能力去向=平台 SemanticModelingService），从构建排除。
  - **b** `git rm` 移除目录（历史仍在 git log/旧 tag 可追溯）。
- 确认无构建/CI 残留引用 dts-metrics（流水线、Dockerfile 列表）。

## 影响范围
- 根 `pom.xml`、CI 配置、`source/dts-metrics`、`source/dts-metrics-webapp`。

## 验证
- [ ] 全量构建（不含 dts-metrics）通过；CI 无 dts-metrics 残留任务。
- [ ] git 历史保留（log 可查）。

## 完成标准
- [ ] 移出构建、归档说明就位、历史可追溯、构建绿。
