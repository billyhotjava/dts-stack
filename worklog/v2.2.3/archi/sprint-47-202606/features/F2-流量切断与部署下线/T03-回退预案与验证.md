# T03: 回退预案与验证

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
提供切断各阶段的回退预案，并在切断后做回归验证。

## 技术设计
- **回退预案**（回退窗口内）：恢复 `dts-metrics-api`/`dts-metrics-ui` traefik labels + 重启 `dts-metrics` 服务（镜像未删）→ 恢复旧路径；前端灰度 flag 切回 iframe（SP-3 F3-T01 留的回退）。
- 形成简明 runbook（步骤 + 触发条件 + 责任人占位）。
- **切断后回归**：
  - `/metrics`、`/api/metrics` 无 503（重定向/收敛）。
  - 平台原生语义建模端到端（建模→受控指标→提交评审）正常。
  - 无平台侧报错（dts-metrics→平台调用消失不影响平台）。

## 影响范围
- 文档（runbook）+ 现场验证。

## 验证
- [ ] runbook 可操作；演练一次回退（非生产）。
- [ ] 切断后回归清单全过。

## 完成标准
- [ ] 回退 runbook 就绪 + 切断后回归通过。
