# T01: 依赖/流量审计

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标
清点 dts-metrics 的所有消费者与调用方向，确认退役不波及其他系统。

## 技术设计
- **入站消费者**：grep 全栈对 `/metrics`、`/api/metrics`、`8084`、`dts-metrics` 的引用——确认仅 SP-3 处理的 iframe（`MetricsServiceFrame`/`metricsServiceRoutes`）+ 现场旧链接。
- **出站方向**：dts-metrics → 平台 internal API（catalog/dbt/release/permission）是**单向**（metrics 调平台）；退役只是去掉调用方，不影响平台被调端。核对 `PlatformContractClient` 的调用方向。
- **流量**：若现场可观测（traefik access log / metrics），确认 `/metrics`、`/api/metrics` 实际流量趋零或仅来自 iframe。
- 产出消费者清单 + 风险点（旧链接靠 SP-3 F3-T01 重定向兜底）。

## 影响范围
- 仅审计，无改动。

## 验证
- [ ] 消费者清单完整；确认无 iframe 外的关键消费者。

## 完成标准
- [ ] 审计报告：消费者清单 + 调用方向 + 风险/兜底，记录在本任务。
