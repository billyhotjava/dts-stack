# T03: 平价确认与退役决策签发

**优先级**: P0
**状态**: READY
**依赖**: T01, T02；SP-3（Sprint-44 F2/F3）

## 目标
确认平台原生治理页已达工作台平价、路由已切原生，签发退役决策与回退窗口。

## 技术设计
- **平价核对**（对照 SP-3 Sprint-44）：F1 治理呈现（governanceMode/受控提示/分层诊断）✅、F2 图形工作台（画布 + 受控 DSL 构造器 + 字段树）✅、F3-T01 路由切原生（灰度 flag 在原生侧）✅。
- 列平价检查表：dts-metrics 工作台用户能做的，平台原生页都能做（建模/受控指标/分层准入/提交评审）。
- 签发：退役决策书（含 gate 结论）+ 回退窗口时长（如灰度切断后保留服务镜像 N 天）。
- 未达平价项 → 阻塞退役，回 SP-3 补齐。

## 影响范围
- 决策文档，无代码改动。

## 验证

## 完成标准
