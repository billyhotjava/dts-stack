# T02：完成迁移、发布、回滚与运维证据

**优先级**：P0  
**状态**：DONE
**依赖**：F5/T01

## 目标

确保 displayName、治理 policy 和 implementationPolicy 兼容改造可以分阶段上线、观测和回滚；本 Sprint 不包含 Layer 枚举扩展。

## 技术设计（Contract-first）

- **输入契约**：最终 changelog、compatibility flag、migration dry-run、F5/T01 报告。
- **输出契约**：`assets/release-plan.md`、`assets/runbook.md`、rollback rehearsal、Go/No-Go。
- **Expand**：先扩治理 policy/displayName/adapter，旧读与未修改字段 round-trip 仍可用；不新增 DIM 或五层策略。
- **Migrate**：只迁移 preview eligible 对象；分批、幂等、可暂停。
- **Contract**：零旧写、零消费者、用户审批后才考虑清理；本 Sprint 默认不删历史字段。
- **错误路径**：计数/checksum/权限漂移立即停止；回滚关闭新写、恢复旧读，不删新 revision。
- **复用点**：Liquibase master、现有 lifecycle/release metrics、domain-dts C/G。
- **实现方案**：实施期加载 release-safety/operability-pack，按真实环境生成而非预写成功结论。

## UI 交互规格

发布期间兼容模型可读；迁移冲突有明确状态和重试；不显示空白页或内部堆栈。

## 影响范围

Liquibase、feature flag/config、metrics/logging/audit、release docs、runbook。

## 验证（RED→GREEN）

- [x] clean DB + 存量 DB upgrade
- [x] dry-run/apply/幂等/rollback
- [x] 前后计数、checksum、权限和审计对账
- [x] production legacy build、旧 snapshot/API 兼容 smoke

## Definition of Done

- [x] 架构：expand/migrate/contract 有证据
- [x] UI：迁移 dry-run/未应用 rollback 后仍可访问
- [x] 切片：GitNexus detect_changes risk=LOW、0 affected process，Go
