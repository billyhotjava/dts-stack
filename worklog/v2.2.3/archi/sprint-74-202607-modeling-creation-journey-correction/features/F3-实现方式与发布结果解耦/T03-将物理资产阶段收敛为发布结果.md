# T03：将物理资产阶段收敛为发布结果

**优先级**：P0  
**状态**：DONE
**依赖**：F3/T01、F3/T02

## 目标

把第三阶段改为只读“发布结果”，准确展示真实资产和运行证据。

## 技术设计（Contract-first）

- **输入契约**：`ModelLifecycleTimeline`、ReleaseCandidate entry/evidence/registration。
- **输出契约**：`PublishedResultProjection {state, physicalAssets, artifacts, tests, registrations, lineage, actions}`。
- **状态**：EMPTY、IMPLEMENTING、READY_TO_RELEASE、PUBLISHED、PARTIAL、ROLLED_BACK、STALE。
- **导航规则**：无实现且无历史发布证据时禁用“发布结果”；存在任何历史发布证据时始终允许只读访问，即使当前 revision 尚未重新实现。
- **数据流**：model pin → lifecycle/release reads → projection → result cards。
- **错误路径**：任一读取失败保留已加载结果并显示重试；无真实 `physicalAssetRef` 不伪造资产。
- **复用点**：账本 L12/L13；Sprint-69 ReleaseCandidate。
- **实现方案**：对外 label 改“发布结果”；移除高级 dbt 按钮；提供“返回数据实现/进入发布工作台/重试登记”。

## UI 交互规格

- EMPTY 明示“逻辑模型尚未形成物理对象”；
- ephemeral STG 放“技术节点”而非“物理资产”；
- PUBLISHED 展示 catalog/schema/table/view、revision、checksum 和时间线；
- PARTIAL 提供精确重试步骤，不把部分成功显示成空。

## 影响范围

PhysicalAssetStage（可保留内部文件名兼容）、ModelSpecDetailPage label/navigation、lifecycle projection/tests。
