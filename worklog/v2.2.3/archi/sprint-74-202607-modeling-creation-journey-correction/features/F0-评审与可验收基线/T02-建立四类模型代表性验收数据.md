# T02：建立四类模型代表性验收数据

**优先级**：P0  
**状态**：DONE
**依赖**：F0/T01

## 目标

建立不污染用户“财务规划1”的隔离验收计划，覆盖四类逻辑模型、普通/dbt 实现和发布结果。

## 技术设计（Contract-first）

- **输入契约**：真实 API；隔离 tenant/plan；固定 idempotencyKey 前缀 `s74-it-*`。
- **输出契约**：DIMENSION、FACT、SUMMARY、APPLICATION 各至少 1 个；`DESIGNER_GENERATED`、`DBT_MANAGED` 各至少 1 个；至少 1 个 PUBLISHED 结果。
- **数据流**：创建计划/分类/维度定义 → 创建模型 → 保存逻辑 → 保存实现 → 构建/发布 → 证据。
- **错误路径**：重复 seed 幂等；部分失败列出已创建 ID；cleanup 只处理带测试前缀对象。
- **复用点**：账本 L13/L15，Sprint-67/69 canonical API。
- **实现方案**：用公开 API 创建 fixture，不直写业务表；cleanup 使用精确 ID，不做广泛删除。

## 影响范围

`it/fixtures/`、验收环境测试数据；不修改用户财务模型。
