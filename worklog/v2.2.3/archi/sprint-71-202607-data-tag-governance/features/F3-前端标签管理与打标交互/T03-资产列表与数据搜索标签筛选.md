# T03: 资产列表与数据搜索标签筛选

**优先级**: P1
**状态**: READY
**依赖**: F2/T03

## 目标

在资产列表与数据搜索页提供按标签筛选，让打标产生实际检索价值。

## 技术设计

### 接入页面

- `pages/catalog/DatasetsPage.tsx`（1002 行，已有 3 个 source-contract 测试，含 toolbar-consolidation）
- `pages/catalog/DataSearchPage.tsx`（446 行，已有 source-contract 测试）

`DatasetsPage` 已做过工具栏收敛（`DatasetsPage.toolbar-consolidation.source-contract.test.ts`），
新增筛选器须纳入既有工具栏结构，**不得另起一行控件破坏已收敛的布局**。

### 交互

- 标签筛选器为多选下拉，按分类分组
- 多选语义为 **AND**（与 F2/T03 后端一致），界面须明示「同时包含」而非让用户猜
- 筛选状态写入 URL query params（项目 URL-as-state 约定），保证可分享、可刷新保持
- 列表行内展示资产已打标签（复用 F3/T02 的 chip 样式，只读态）
- 清除筛选一键可用

## 影响范围

- 修改 `pages/catalog/DataSearchPage.tsx`
