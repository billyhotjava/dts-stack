# F4: 存量标签迁移与兼容

**优先级**: P2
**状态**: READY

## 目标

把存量 `CatalogDataset.tags` 自由文本安全迁移为结构化标签，且迁移过程可预览、可回滚。

## 为什么是 P2 而非 P1

新体系不依赖迁移即可独立工作（F1~F3 完成后标签功能已可交付）。
迁移是存量数据的收尾，风险高于价值，因此排在功能闭环之后，且必须可回滚。
