# T02: 重复页面治理决策表

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

形成重复菜单/页面的保留、合并、隐藏、跳转、退役决策表。

## 技术设计

决策规则：

- 同一用户、同一任务、不同名称：合并为一个页面
- 老客户链接可能存在：保留 redirect
- 技术配置页只给管理员：放入 admin/system 或 ops，不进入客户首页
- 客户场景：配置或现场定义，不内置 demo
- 无 handler/API/state：隐藏、禁用并说明原因，或拆 task 实现
