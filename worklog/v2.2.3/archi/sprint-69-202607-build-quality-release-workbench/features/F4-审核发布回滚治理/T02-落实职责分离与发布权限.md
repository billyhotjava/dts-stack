# T02：落实职责分离与发布权限

**优先级**：P0
**状态**：READY
**依赖**：T01

## 目标

在后端强制提交人与批准人分离，并将建模、审核、发布和回滚权限分开授权。

## 技术设计

- 定义 maintainer、reviewer、publisher、rollback operator 权限。
- reviewer 与 submitter 相同直接拒绝；管理员也需显式 break-glass 流程和原因。
- 所有命令同时校验 tenant、plan scope 和候选归属。
- 审计保存 actor、authority、requestId、reason 和结果。

## 影响范围

- Spring Security authority 配置
- lifecycle resource/service authorization
- 前端 capability contract
- security/tenant MockMvc tests

## 实施步骤

1. 先写同人审批、越权发布、跨租户和 break-glass 测试。
2. 实现 method/resource 双层授权与 actor 校验。
3. 验证前端隐藏按钮不能替代后端拒绝。

## 完成标准

- [ ] 同人审批、越权、跨租户和伪造 actor 均稳定失败。
- [ ] 权限不足时 UI 给出申请路径，后端不泄露候选详情。
- [ ] **UI 契约验收**：submitter、reviewer、publisher 和 forbidden 四类 capability fixture 覆盖按钮可见性、禁用原因和正式权限申请说明。
