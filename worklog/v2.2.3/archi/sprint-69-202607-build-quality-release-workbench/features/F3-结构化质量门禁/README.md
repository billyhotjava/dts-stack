# F3：结构化质量门禁

**优先级**：P0
**状态**：READY

## 目标

建立独立的质量运行与规则级结果，让发布门禁依据规则版本、阈值、数据快照和失败样本摘要判断，而不是复用单个 dbt TEST 布尔值。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|---|---|---|---|---|
| T01 | 建立 QualityRun 与 QualityCheckResult 契约 | P0 | READY | F1-T04 |
| T02 | 从 ModelSpec 生成默认质量规则包 | P0 | READY | T01 |
| T03 | 验证并落库规则级运行结果 | P0 | READY | T01、T02、F2-T02 |
| T04 | 实现质量门禁新鲜度与修复路由 | P0 | READY | T03 |

## 完成标准

- [ ] 每条质量结果可追溯到候选条目、规则版本、阈值、数据快照和执行 run。
- [ ] FACT、DIMENSION、SUMMARY、APPLICATION 具有可解释的默认规则包。
- [ ] 失败样本只保存脱敏摘要和受控引用，不把大结果集塞入生命周期 JSON。
- [ ] 规则变更、模型漂移或快照超期会使旧质量结论失效。
