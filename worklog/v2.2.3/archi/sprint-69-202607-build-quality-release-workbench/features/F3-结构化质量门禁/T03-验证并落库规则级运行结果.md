# T03：验证并落库规则级运行结果

**优先级**：P0
**状态**：READY
**依赖**：T01、T02、F2-T02

## 目标

校验 dbt test 或质量执行器返回的规则结果，并以当前候选版本和数据快照为单位原子落库。

## 技术设计

- 服务端校验 rule pack、invocation、模型 node、target、阈值和结果完整性。
- 运行从 RUNNING 到终态单向迁移；终态回调幂等。
- 缺规则、未知规则、重复结果、阈值篡改和 run 不匹配均拒绝。
- 先保存运行终态再计算门禁，失败时不产生质量通过事件。

## 影响范围

- `ModelLifecycleTestEvidencePort.java`
- quality result ingestion service/resource
- dbt test/quality adapter
- service/resource/fixture tests

## 实施步骤

1. 先写成功、失败、缺规则、重复、错 target 和旧 revision 测试。
2. 实现结果验证、事务落库和门禁投影。
3. 使用真实 dbt test 产物完成一次 ingestion。

## 完成标准

- [ ] 规则级结果与外部 run、candidate entry 和 snapshot 一致。
- [ ] 不完整或被篡改的结果无法产生 QUALITY_PASSED。
- [ ] **UI 契约验收**：质量运行进度只有在规则结果完整落库后显示通过；缺规则、重复、篡改和错 target 均映射为明确阻塞状态。
