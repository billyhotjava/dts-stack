# T02: 集成进建模与评审校验

**优先级**: P0
**状态**: DONE（输出层 gating 落地；源表层级/标准码 gating 依赖 SP-2，见落地说明）
**依赖**: T01, F1-T02

## 目标
受控模式下，在平台建模/业务对象校验与 `validateModelForReview` 调用 `EltLayerGate`，违规阻断。

## 技术设计
- 注入 `EltLayerGate`。
- 在 F1-T02 预留的校验挂载点：`isControlled(model)` 时对模型涉及的资产/节点层级执行 `gate.evaluate(...)`；有 ERROR 诊断则抛领域异常（T03 映射 400）。
- 挂载位置：业务对象 table-mappings 保存、模型创建/更新、`validateModelForReview`（提交评审前必过闸）。
- PERMISSIVE 模型跳过闸（绞杀者并存）。

## 影响范围
- `dts-platform`：`SemanticModelingService`（业务对象/模型校验、validateModelForReview）。

## 验证
- [ ] CONTROLLED 模型：ODS/STG 入口、DWD 缺 grain/码 → 被阻断（提交评审失败）。
- [ ] PERMISSIVE 模型：不受闸影响（既有测试不破）。

## 完成标准
- [x] 闸接入受控校验链（`validateModelForReview` 受控分支调 `enforceLayerGate`）、PERMISSIVE 不破、集成测试覆盖正反例（SemanticModelingServiceTest 12 例全绿）。

## 落地说明（重要边界）
- **本次落地**：对模型<b>输出层</b>（`model.type`）+ `model.grain` 受控 gating——受控模型须输出 DWS/ADS（或带 grain 的 DWD），ODS/STG 与无 grain 的 DWD 被拒。
- **依赖 SP-2 的部分**：平台语义模型<b>不携带源表层级与标准码</b>（层级在 catalog 按表名 keyed、标准码未建模）。故"禁止从 ODS/STG 源表建模"与 DWD 标准码强制，随 SP-2（语义富化：catalog 层级解析 + schema.yml meta 标准码）接入；当前 `enforceLayerGate` 对 hasStandardCode 置 true、connectsToPublish 置 false。
- EltLayerGate 组件本身已支持完整规则（含标准码/直连发布），等 SP-2 提供输入即自动生效。
