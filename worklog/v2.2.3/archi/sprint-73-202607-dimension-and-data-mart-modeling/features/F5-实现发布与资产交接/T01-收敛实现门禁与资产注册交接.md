# T01: 收敛实现门禁与资产注册交接

**优先级**: P0  
**状态**: DRAFT  
**依赖**: F4 全部

## 目标

以现有 ModelSpec/ReleaseCandidate/资产注册主线完成维度表的实现和资产交接，不建立平行发布路径。

## 技术设计 (Contract-first)

- **输入契约**: 当前 ModelSpec revision、definition revision、有效来源、implementation policy。
- **输出契约**: stage issues；ReleaseCandidate；资产注册结果 `SUCCESS|PARTIAL|FAILED`。
- **数据流**: ModelSpec gate → ReleaseCandidate → build/quality/review/publish → asset register → stage evidence。
- **错误路径**: 无来源、属性缺映射、名称/SCD/保留违规阻断候选；资产注册失败保持 PARTIAL 并可幂等重试。
- **复用点**: `ModelSpecStageGateService`、Sprint-69 发布工作台、统一资产标识。
- **实现方案**: 增加新 issue codes 的 repairRoute；注册资产记录 definition/mart/model revision lineage。

## UI 交互规格

- blocker panel 精确跳字段/来源/策略。
- 发布摘要同时显示业务维度和维度表，防止对象混淆。
- 资产台账详情可回跳 ModelSpec revision，但不允许在台账改建模正文。

## 验证

- [ ] DRAFT 不入资产台账
- [ ] PUBLISHED 一次且仅一次注册
- [ ] 重复注册幂等
- [ ] 外部注册超时≤10s、最多重试2次

## Definition of Done

- [ ] 发布/资产 IT 绿
- [ ] PARTIAL 可恢复
- [ ] 证据入 `IT-06-publish-ledger.md`
