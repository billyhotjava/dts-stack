# T01: 扩展维度范围、属性与版本契约

**优先级**: P0  
**状态**: DRAFT  
**依赖**: F0、F2/T01

## 目标

在现有 DimensionDefinition owner 上增加 DataMart 范围和语义属性，不创建第二套维度实体。

## 技术设计 (Contract-first)

- **输入契约**: `CreateDimensionDefinitionCommandV2`、ETag、DataMart CURRENT revision。
- **输出契约**: `DimensionDefinitionView` 增加 `scopeType/dataMartId/attributes`。
- **数据流**: Resource → existing ApplicationService → DataMart resolver/standard resolver → head+revision。
- **错误路径**: mart 非 CURRENT/不含 domain=422；属性重复=422；标准 revision stale=422；CAS=412。
- **复用点**: `DimensionDefinitionContract/ApplicationService/Repository`；标准/码表 revision resolver。
- **实现方案**:
  1. RED contract/service/Liquibase tests；
  2. expand 三列并同步 revision snapshot/checksum；
  3. 确认 CURRENT 时校验主键属性和层级引用；
  4. usageCount 保持批量聚合。

## 影响范围

DimensionDefinition 前后端契约、服务、数据库迁移和测试。
