# T02: 重构维度目录登记编辑体验

**优先级**: P0  
**状态**: DRAFT  
**依赖**: T01、F2/T02

## 目标

让用户在维度目录中完成范围、基本信息、语义属性和层级维护，并从现行维度直接进入维度表创建。

## 技术设计 (Contract-first)

- **输入契约**: DimensionDefinition V2 API、DataMart list。
- **输出契约**: URL `planId/domainId/dataMartId/status`；保存后重新 GET current head。
- **数据流**: 登记抽屉 → 保存 DRAFT → 详情编辑 → confirm CURRENT → 创建维度表。
- **错误路径**: DataMart 变化导致失效时保留输入并定位范围；CAS 冲突可加载最新；无权限只读。
- **复用点**: `DimensionCatalogPage`、现有 CreateDrawer、CAS/reload helper。
- **实现方案**: 基本信息抽屉保持轻量；属性/层级移到详情 Drawer/Panel；从人员目录选择 owner。

## UI 交互规格

- 范围选择：共享维度（DOMAIN）/集市维度（DATA_MART）。
- 属性表列：编码、名称、定义、主键、标准、码表、顺序。
- 层级选择只能引用已保存属性 code。
- CURRENT 有主动作“创建维度表”；RETIRED 只读。
