# T03: 迁移存量维度并闭合兼容

**优先级**: P0  
**状态**: DRAFT  
**依赖**: T01、F0/T02

## 目标

把现有维度安全扩展为 DOMAIN scope，并对未绑定维度定义的存量 DIMENSION ModelSpec 生成可审查清单。

## 技术设计 (Contract-first)

- **输入契约**: F0/T02 dry-run、现有 DimensionDefinition/ModelSpec。
- **输出契约**: `scope_type=DOMAIN`、`attributes_json=[]`；`unresolved[]` 清单；不自动猜测绑定。
- **数据流**: dry-run checksum → migration apply → count/checksum 对账。
- **错误路径**: source checksum 漂移即拒绝 apply；unresolved 非空不阻断读取，但阻断对应模型发布。
- **复用点**: Sprint-67 legacy map 和 forward-only migration 约定。
- **实现方案**: expand/backfill/check；旧 API 未传新字段时按 DOMAIN 兼容；删除列不在本 Sprint。

## 影响范围

Liquibase、compatibility reader、migration report、REST regression tests。

## 验证

- [ ] 现有 1 个 CURRENT 维度读取一致
- [ ] 未绑定 ModelSpec 被列出而非自动绑定
- [ ] 跨租户/不可见 domain 不泄露

## Definition of Done

- [ ] clean/upgrade/dry-run 三类迁移测试绿
- [ ] 兼容性回归绿
- [ ] 生产 apply 需单独 Go/No-Go
