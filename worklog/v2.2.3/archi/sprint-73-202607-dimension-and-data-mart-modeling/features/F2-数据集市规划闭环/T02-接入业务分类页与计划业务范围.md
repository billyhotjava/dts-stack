# T02: 接入业务分类页与计划业务范围

**优先级**: P0  
**状态**: DRAFT  
**依赖**: T01、F1/T02

## 目标

在不新增菜单的前提下完成 DataMart 管理和计划绑定的可操作 UI。

## 技术设计 (Contract-first)

- **输入契约**: DataMart API、计划 `/baseline/data-marts`。
- **输出契约**: URL 状态 `tab=data-marts&keyword=&page=`；计划响应 `dataMartBindings`。
- **数据流**: 页面控件 → API → 保存 → 重新 GET；禁止 session/localStorage 作为真值。
- **错误路径**: 列表失败可重试；CAS 冲突保留输入；不可见分类不显示；返回计划使用白名单 returnTo。
- **复用点**: `SubjectAreasPage`、`SubjectWorkspaceTabs`、`WarehousePlanDetailPage`、现有权限 hook。
- **实现方案**: 抽取 DataMart workspace 子组件，避免 SubjectAreasPage 超过 800 行；计划 Tab 文案改“业务范围”。

## UI 交互规格

- DataMart 表列：名称/编码、业务分类、负责人、状态、引用数、操作。
- 新建抽屉：编码、名称、用途、负责人目录、业务分类多选。
- 计划页：先业务分类，后数据集市；不兼容项在保存前逐条提示。
