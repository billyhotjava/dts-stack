# T02: 串起属性、字段、来源与冗余映射

**优先级**: P0  
**状态**: DRAFT  
**依赖**: T01

## 目标

让维度属性映射到物理字段，并可从已验证来源显式导入字段；导入不自动确认来源。

## 技术设计 (Contract-first)

- **输入契约**: CURRENT definition attributes、已确认 `sourceBindingId/resolvedVersion`、最多 500 个源字段。
- **输出契约**: `ModelSpecFieldV3[]`、`standardBindings[]`、`sourceRefs[]`。
- **数据流**: 选择来源 → 获取 schema/table/field → 选择字段 → 生成候选 → 映射 attribute code → 保存 revision。
- **错误路径**: 来源 revision 漂移、字段消失、类型冲突、超过 500 均停止导入并保留已保存设计。
- **复用点**: 现有来源解析、ModelSpecFieldsTab、standardBindings、字段血缘。
- **实现方案**: 属性映射列、显式“从已验证来源导入”；冗余字段保存 source lineage 和 `redundant=true`。

## UI 交互规格

- 无来源时显示“可继续概念设计；进入实现前补齐来源”。
- 导入四步：连接→Schema→表→字段，只有最后确认才写草稿。
- 未映射的必需属性在字段表顶部汇总，并可一键定位。
