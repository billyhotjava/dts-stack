# T02: Excel/CSV 文件与字段密级录入

**优先级**: P0
**状态**: IN_PROGRESS
**编码状态**: DONE（统一验证延后）
**依赖**: F1-T03

## 目标

上传离线文件时先确定文件密级，并允许在解析预览中对字段升密。

## 技术设计

- `prepare` 请求显式携带文件密级，不再静默写默认 INTERNAL。
- 文件密级传播到原文件、解析文件、错误文件、ODS 和字段。
- 字段选择低于文件密级时拒绝。
- 文件名内容检测只作为升密候选，不能替代用户声明和 seal。

## 影响范围

`ExcelImportService`、`InfraExternalExchangeFile`、上传 API/前端向导、清理任务。

## 验证

- [ ] xlsx/csv 文件级和字段级矩阵。
- [ ] 临时文件、错误文件和 ODS 密级一致。
- [ ] 解析重跑不制造新的较低事实。

## 完成标准

- [ ] 文件首次保存前已有密级事实。
- [ ] 文件生命周期事件可追踪。
