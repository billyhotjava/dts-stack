# T04: 血缘变更重算与可靠重试

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: T01,T02,T03

## 目标

处理上游升密、血缘增删和 Schema 漂移造成的下游重算，保证任务可恢复且不降级。

## 技术设计

- 以 classification event/outbox 扇出下游重算。
- 记录游标、批次、重试次数、最后错误和影响资产数。
- 血缘删除不自动降低 effectiveLevel；只更新来源解释并产生治理复核项。
- 提供按资产/批次重放。

## 影响范围

传播 worker、事件/outbox、运维重试和告警。

## 验证

- [ ] 中途失败、重复消费、顺序颠倒和大扇出。
- [ ] 删除高密上游后仍保留历史最高值。

## 完成标准

- [ ] 重试不会制造降级或重复副作用。
- [ ] 运维可定位失败到具体边和资产。
