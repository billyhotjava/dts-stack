# T01: 字段与资产最高密级传播引擎

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: F1-T03

## 目标

根据 `CatalogColumnLineage` 和 `CatalogDatasetLineage` 计算派生字段、表和数据集的最高有效密级。

## 技术设计

- 字段血缘优先；资产血缘作为保守 fallback。
- 派生字段取所有输入字段 max，资产取所有字段与上游资产 max。
- ODS/DWD/DIM/DWS/ADS 使用同一规则。
- 传播命令幂等并记录输入快照版本。

## 影响范围

catalog lineage repository/service、classification resolver、治理解释 API。

## 验证

- [ ] 一对一、多输入、join、聚合和无字段血缘矩阵。
- [ ] 重复传播不产生无意义事件。

## 完成标准

- [ ] 每个继承结果可列出上游来源。
- [ ] 不因分层、聚合或脱敏自动降密。
