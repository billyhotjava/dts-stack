# F3: 血缘传播与建模发布门禁

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）

## 完成标准

- [ ] 有字段血缘时精确传播，无字段血缘时保守传播资产最高值。

- [ ] 当前有效密级在传播失败时绝不回退。
