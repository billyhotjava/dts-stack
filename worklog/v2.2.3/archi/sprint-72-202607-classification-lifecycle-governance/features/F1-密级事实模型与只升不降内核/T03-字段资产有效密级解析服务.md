# T03: 字段资产有效密级解析服务

**优先级**: P0
**状态**: IN_PROGRESS
**编码状态**: DONE（统一验证延后）
**依赖**: T02

## 目标

提供唯一服务计算、查询、解释和升高字段/资产有效密级。

## 技术设计

- 实现 `effective=max(previous,declared,detected,manualFloor,upstreams)`。
- 使用 CAS/悲观锁保证并发只升不降。
- 提供 resolve、explain、seal、raiseFloor、inherit 命令；不提供 set/lower。
- 传播失败保留最后已知最高值。

## 影响范围

catalog service/API、权限和治理门禁的密级读取适配器。
