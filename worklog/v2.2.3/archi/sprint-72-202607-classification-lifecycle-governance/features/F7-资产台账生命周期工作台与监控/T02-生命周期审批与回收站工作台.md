# T02: 生命周期审批与回收站工作台

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: F4-T04

## 目标

在资产治理页面统一处理生命周期申请、审批、临时销毁和恢复。

## 技术设计

- 复用现有资产治理/生命周期入口，不新增一级菜单。
- 提供待审批、执行中、回收站、到期候选和失败重试视图。
- 高风险动作显示影响分析和不可逆边界。
- 恢复/永久销毁按钮由服务端能力与权限决定。

## 影响范围

GovernanceCenter/AssetDetail、lifecycle API、路由上下文。

## 验证

- [ ] 普通用户/owner/maintainer/审批人权限。
- [ ] Chrome 95 表格、抽屉和二次确认。

## 完成标准

- [ ] 各阶段动作可从具体资产回跳。
- [ ] 永久销毁无充分证据时按钮不可用。

## 编码进展

已在资产台账内增加密级与生命周期工作台，支持归档、临时销毁、恢复、永久销毁申请、
双重审批、驳回、失败重试及销毁证明展示；动作绑定当前密级快照。统一测试延后。
