# T04: 血缘密级影响与治理通知

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: F3-T05,F5-T04

## 目标

在血缘影响分析中可视化升密传播、待补血缘和受影响消费资产，并通知责任人。

## 技术设计

- 血缘边显示来源级别、传播级别和 snapshot version。
- 高亮导致当前有效密级的最高来源路径。
- unresolved/stale/propagation error 进入治理责任清单。
- 通知聚合到 owner/部门，提供具体修复入口。

## 影响范围

CatalogLineage/impact API、lineageShared 页面、消息中心和治理工单。

## 验证

- [ ] 多路径 max、循环、无权节点和大扇出。
- [ ] 通知去重和状态恢复。

## 完成标准

- [ ] 用户可从治理阻断定位到具体血缘缺口。
- [ ] 不泄露无权资产名称或结构。

## 编码进展

已在资产工作台展示上游/下游/阻断数量，并聚合血缘传播、消费重算和缓存失效问题；
列表仅返回脱敏资产引用，血缘问题关联责任人/部门及具体修复入口。统一测试延后。
