# T01: 资产台账密级事实与来源展示

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: F1-T03,F3-T01

## 目标

让资产台账和详情页显示密级事实，而不是一个可编辑的 classification 文本。

## 技术设计

- 列表显示 effective level、seal/传播状态和最高来源类型。
- 详情显示 declared/detected/manualFloor/upstream、版本和事件时间线。
- 字段契约页显示字段有效密级和继承来源。
- 数据标签与密级使用不同组件、字段和筛选器。

## 影响范围

AssetLedgerView、AssetDetail/DatasetDetail、catalog portal contract/API。

## 验证

- [ ] dataset/column/model/API/data product/screen 展示契约。
- [ ] 无权上游只显示脱敏摘要。

## 完成标准

- [ ] 用户能解释“为什么是这个密级”。
- [ ] UI 不提供降密编辑入口。

## 编码进展

已新增批量密级事实读取契约，台账显示有效密级、封存/传播状态和最高来源，资产详情显示
来源声明、识别、人工下限、事件版本及字段级继承事实；数据标签保持独立。统一测试延后。
