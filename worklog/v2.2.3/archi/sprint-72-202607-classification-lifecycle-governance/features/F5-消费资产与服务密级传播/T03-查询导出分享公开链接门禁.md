# T03: 查询、导出、分享和公开链接门禁

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01,T02

## 目标

让所有消费动作依据当前有效密级进行人员权限、审批和审计检查。

## 技术设计

- 查询编译前检查全部来源最高密级。
- 导出文件继承结果密级并创建文件密级事实。
- 分享/公开链接审批绑定 snapshot version；密级变化后重新评估。
- 缓存 key 包含有效密级版本，管理员旁路仍强审计。

## 影响范围

Explore/semantic query、export、AssetPermission、PublicLink、DashboardShare、审计。

## 验证

- [ ] 低密用户、过期授权、旧 URL、旧缓存和批量导出。
- [ ] 导出文件分类与来源一致。

## 完成标准

- [ ] 不存在 UI/API/缓存旁路。
- [ ] 拒绝响应不泄露高密资产详情。
