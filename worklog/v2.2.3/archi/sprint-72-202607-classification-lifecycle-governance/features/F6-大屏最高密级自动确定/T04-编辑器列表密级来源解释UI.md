# T04: 编辑器/列表密级来源解释 UI

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T02,T03

## 目标

让大屏 owner 看懂系统有效密级、人工下限、最高来源和发布阻断，而不是继续手工猜密级。

## 技术设计

- 编辑器显示只读“系统有效密级”和可升高的“人工下限”。
- 展示最高密级组件/数据源、未解析来源和上次计算时间。
- 列表 Tag 显示有效密级；stale/unresolved 另加治理状态，不混入标签。
- 上游升密通知提供影响来源和修复入口。

## 影响范围

ScreensPage、ScreenHeader/PropertyPanel/SharePanel、ClassificationTag/API types。

## 验证

- [ ] source-contract、交互测试和 Chrome 95。
- [ ] 多来源解释不泄露无权查看的资产名称。

## 完成标准

- [ ] 用户无法从 UI 发起降密。
- [ ] 发布阻断有业务可读提示。

## 编码进展

已在权限面板区分人工下限与有效密级，在列表展示有效密级及快照提示，并为 HTTP API
数据源增加规范资产键绑定入口和发布阻断说明。统一测试及 Chrome 95 验证延后。
