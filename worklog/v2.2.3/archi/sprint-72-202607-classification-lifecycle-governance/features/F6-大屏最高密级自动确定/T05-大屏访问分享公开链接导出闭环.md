# T05: 大屏访问、分享、公开链接和导出闭环

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T02,F5-T03

## 目标

保证大屏全部消费通道依据当前最高有效密级重新裁决。

## 技术设计

- ScreenPermission、DashboardAccessGuard 使用 effective level。
- share/public link/export 绑定 classification snapshot version。
- 上游升密自动暂停不再符合条件的 grant/link 并失效缓存。
- 越级授权保留审批和审计语义，但不能把资产密级改低。

## 影响范围

`dts-analytics` permission/public/export、`dts-platform` dashboard share/report sync、前端分享预览。

## 验证

- [ ] owner/viewer/public/export/level override 权限矩阵。
- [ ] 上游升密后旧链接、旧会话和旧缓存。

## 完成标准

- [ ] 不存在通过分享或导出绕过最高密级的路径。
- [ ] 访问拒绝与链接暂停均有审计。

## 编码进展

已接入当前快照访问检查、公开链接和授权快照绑定、上游升密失效，以及导出文件密级事实
封印和响应密级头。统一权限矩阵测试延后。
