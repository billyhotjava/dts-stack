# T03: 使用/共享审批统一接入

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: T01

## 目标

把现有数据访问和共享审批纳入生命周期视图，并在有效密级升高时重新评估。

## 技术设计

- 复用 `DatasetDataAccessApprovalService` 和授权表，不建立第二套授权。
- 使用、预览、查询、下载、共享分别形成 lifecycle event。
- 上游升密使原批准超出人员权限时暂停授权并通知，不静默继续。
- 公开链接不作为普通共享旁路。

## 影响范围

数据访问审批、AssetGrant、公开链接、权限服务、生命周期 projection。

## 验证

- [ ] APPROVED/REJECTED/REVOKED/EXPIRED 投影。
- [ ] 上游升密后的暂停、重新审批和审计。

## 完成标准

- [ ] 使用/共享动作先审批后执行。
- [ ] 旧授权不能绕过当前有效密级。
