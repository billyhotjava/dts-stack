# T06: 生命周期时间轴与销毁证明可视化

**优先级**: P0
**状态**: IN_PROGRESS
**编码状态**: DONE（待部署后 Chrome 95 页面 smoke）
**依赖**: T01,T05,F7-T02

## 目标

把后端已有的创建、存储、使用、共享、归档和销毁投影呈现为一条业务可读时间轴，并让永久销毁的双人审批和证明可直接核验。

## 技术设计

- 复用治理工作台 `lifecycle.stages`、`events` 和 `destructionProofs`，不新增后端接口。
- 工作台顶部展示六阶段时间轴，每个阶段显示最新状态、操作人和发生时间。
- “审批与回收站”展示完整生命周期事件，串起接入、存储、授权、共享、归档和销毁。
- 销毁证明以表格展示审批人、执行人、适配器、校验和、外部源触碰状态和执行结果。
- 证明详情只展示对象摘要，不展示已销毁业务数据。
- 使用兼容 Chrome 95 的 Grid/Flex 和 Ant Design Table，不使用新式浏览器 API。
