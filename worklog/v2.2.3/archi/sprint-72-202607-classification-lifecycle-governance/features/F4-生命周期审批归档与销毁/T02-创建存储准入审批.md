# T02: 创建/存储准入审批

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: T01,F2-T04

## 目标

把资产创建和首次生产存储纳入显式准入，审批通过后才能执行受控写入。

## 技术设计

- 接入 seal 作为 CREATE/STORE 阶段主要证据。
- 按密级、部门、来源类型选择既有工作流模板。
- 结构预检不等于生产存储批准。
- 审批通过后发放一次性/版本绑定执行令牌。

## 影响范围

接入准入、admin workflow config client、catalog lifecycle projection。

## 验证

- [ ] 低/高密级审批路由、拒绝、撤销、过期令牌。
- [ ] 未批准任务不能落盘。

## 完成标准

- [ ] 创建与存储审批、seal 和真实执行可对账。
- [ ] 任务内容变化后旧批准失效。
