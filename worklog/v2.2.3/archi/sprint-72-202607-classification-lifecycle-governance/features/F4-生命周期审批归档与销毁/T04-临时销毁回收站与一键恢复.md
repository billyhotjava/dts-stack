# T04: 临时销毁回收站与一键恢复

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: T01

## 目标

把当前单一 DISPOSE 软禁用升级为有保留期、可恢复、可审计的临时销毁。

## 技术设计

- 增加 TRASHED/RESTORE_REQUESTED/RESTORED 状态和回收站事实。
- 临时销毁撤销查询、共享、调度和公开链接，但保留可恢复副本。
- 恢复需审批并验证名称冲突、依赖和密级事实。
- 到期只生成永久销毁候选，不自动物理删除。

## 影响范围

`CatalogLifecycleRequestService`、dataset lifecycle、调度/授权停用、回收站 API/UI。

## 验证

- [ ] 入回收站、不可访问、恢复、重复恢复和到期候选。
- [ ] 恢复后密级不低于销毁前。

## 完成标准

- [ ] 临时销毁可一键发起恢复。
- [ ] 全过程有审批和审计。
