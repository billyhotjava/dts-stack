# T05: 永久销毁双人复核、适配器与证明

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: T04,F3-T05

## 目标

在完成下游影响分析和双人复核后，幂等销毁 DTS 管理的数据副本并生成不可逆证明。

## 技术设计

- 申请人和批准人分离，高密级可配置额外审批。
- 执行前冻结调度、撤销共享、检查下游、生成对象清单和 checksum。
- 为平台 PostgreSQL、文件/对象存储、dbt materialization 提供显式 adapter。
- 外部 JDBC 源只删除 DTS 副本和接入凭据引用，不 DROP 源表。
- 证明保存对象摘要、适配器、批准人、执行人、结果、时间和失败重试。

## 影响范围

生命周期服务、存储适配器、调度、血缘影响分析、审计和 destruction proof。

## 验证

- [ ] 双人复核、依赖阻断、部分失败、重试幂等和不可恢复。
- [ ] 外部源表保护测试。

## 完成标准

- [ ] 无审批或不受支持 adapter 时绝不执行。
- [ ] 业务数据销毁后仍能审计谁批准、谁执行、销毁了什么。
