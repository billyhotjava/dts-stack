# T01: 路由切换至原生页 + 旧链接兼容

**优先级**: P1
**状态**: READY
**依赖**: F2（原生页平价）

## 目标
把 iframe 路由切到平台原生治理页，旧 path 兼容重定向，支持灰度。

## 技术设计
- `static-routes.tsx`：`/modeling/semantic-center`(*)、`/bi-apps/metrics`(*)、`/bi/semantic-modeling` 的 `element` 从 `<MetricsServiceFrame/>` 改为平台原生治理页（pages/modeling 治理中心）。
- **灰度**：用 feature flag（如 `VITE_SEMANTIC_NATIVE` 或后端 capability）在原生页 vs iframe 间切，便于回退。
- **兼容**：旧 dts-metrics 深链（`/bi-apps/metrics/...`）→ 重定向到原生页对应路由，避免现场旧链接断开（参照 Sprint-40 对 `/services/consumption` 的兼容做法）。

## 影响范围
- `dts-platform-webapp`：`static-routes.tsx`、路由映射、（可选）feature flag。

## 验证
- [ ] flag 开 → 原生页；flag 关 → iframe（回退路径在）。
- [ ] 旧深链重定向不 404。

## 完成标准
- [ ] 路由可切原生页、灰度可回退、旧链接兼容、构建通过。
