# T02: 权限模型与审计事件

**优先级**: P0
**状态**: DRAFT
**依赖**: F2, F5

## 目标

定义 API 数据源和 API 接入任务的权限边界，保证密钥、连接测试、运行操作和 checkpoint 操作可审计。

## 范围

- 权限：查看数据源、编辑配置、更新密钥、测试连接、创建任务、运行任务、reset checkpoint。
- 审计事件：创建/更新数据源、更新密钥、preview、创建任务、执行、失败、重跑、回补、checkpoint reset。
- 审计 payload 脱敏规则。

## 完成标准

- [ ] 非授权用户无法读取或修改 secret。
- [ ] 高风险操作有审计记录。
- [ ] 审计 payload 不包含 token、secret、完整响应体。
- [ ] checkpoint reset 和 backfill 有二次确认和责任人。
