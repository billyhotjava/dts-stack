# T05: 错误分类、指标与运行事件

**优先级**: P0
**状态**: DRAFT
**依赖**: T02, T03, T04

## 目标

建立 API 接入专用错误分类和运行指标，使问题能被运维快速定位。

## 范围

- 错误分类（落库枚举 `IngestionApiErrorClass`，9 类）：`AUTH`、`HTTP_4XX`、`HTTP_5XX`、`RATE_LIMIT`、`TIMEOUT`、`PARSE`、`PAGINATION`、`SCHEMA_DRIFT`、`ODS_WRITE`。
- 指标（前缀 `dts_ingestion_api_`）：`requests_total{status}`、`retries_total{reason}`、`records_total`、`bytes_total`、`duration_seconds`、`rate_limit_wait_seconds`、`checkpoint_lag_seconds`。
- 事件（`ingestion_execution_event` 枚举）：`PREVIEW_OK`、`RUN_STARTED`、`PAGE_FETCHED`、`BATCH_WRITTEN`、`CHECKPOINT_UPDATED`、`RUN_FAILED`、`SCHEMA_DRIFT_DETECTED`。

## 完成标准

- [ ] 错误分类进入 execution history —— 验收口径：execution 详情接口返回 `errorClass ∈ 9 类枚举` + `errorMessage`，前端按枚举展示中文文案；contract test 覆盖 9 类枚举。
- [ ] 运行指标可被前端和运维接口查询 —— Prometheus scrape `/actuator/prometheus` 包含 `dts_ingestion_api_*` 系列；运维 API `/api/ingestion/executions/{id}/metrics` 返回上述指标当前值。
- [ ] 日志不包含敏感 header、query secret 或响应敏感字段 —— 验收口径：脱敏单测覆盖 `Authorization`、`X-Api-Key`、`?token=`、`?api_key=`、JSON body 中标记 `sensitive=true` 的字段；日志 fixture 测试 + grep 断言。
- [ ] 失败事件有可操作诊断 —— `RUN_FAILED` 事件 payload 含 `errorClass`、`httpStatus`、`requestId`、`recommendation`（如 RATE_LIMIT 给 retry-after 建议）。
