# T03: 分页、重试、限流与熔断

**优先级**: P0
**状态**: DRAFT
**依赖**: T02

## 目标

让 API 接入在真实客户系统上可控运行，避免拉取不完整、打爆对方接口或无限重试。

## 范围

- 支持 page number、offset/limit、next token、next URL。
- 支持 `Retry-After`、指数退避、最大重试次数。
- 支持 per-source、per-task、per-tenant 限流。
- 支持错误率熔断和手工恢复。

## 完成标准

- [ ] 分页终止条件明确。
- [ ] 429/503 按策略重试，不无限循环。
- [ ] 限流配置可观测。
- [ ] 熔断后任务状态和诊断清晰。
