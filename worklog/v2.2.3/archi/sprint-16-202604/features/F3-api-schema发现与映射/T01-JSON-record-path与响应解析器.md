# T01: JSON record path 与响应解析器

**优先级**: P0
**状态**: DRAFT
**依赖**: F2/T03

## 目标

支持从 API 响应中稳定提取记录集合，为字段推断和正式运行提供同一套解析逻辑。

## 范围

- 支持根数组、根对象、嵌套数组、分页响应中的 data/list/items。
- 定义 record path 表达式语法和限制。
- 返回命中数量、示例记录、未命中诊断。
- 对解析异常输出 PARSE 分类。

## 完成标准

- [ ] Preview 和正式运行复用同一解析器。
- [ ] record path 表达式可被服务端校验。
- [ ] 非 JSON 响应能明确拒绝或标记为不支持。
- [ ] 解析器有单元测试覆盖嵌套结构。
