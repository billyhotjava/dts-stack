# T01: 端到端验证

**优先级**: P0
**状态**: READY
**依赖**: F1, F2

## 目标

走通完整链路，留存证据。

## 步骤

1. 启动 dts-analytics（dts-bi 后端）
2. 启动 dts-platform（设置 `DTS_ANALYTICS_BASE_URL`、`DTS_ANALYTICS_INTERNAL_TOKEN`）
3. 在 dts-bi 创建至少 1 个新大屏（active）+ 1 个 archived
4. 启动 dts-platform-webapp，登录测试账号
5. 等 ≤60s，看 dts-platform 日志 `screen reconcile: created=2 updated=0 archived=0`
6. 数据库验证：
   ```sql
   SELECT code, title, enabled, source FROM bi_report_link WHERE source='SCREEN_SYNC';
   ```
   应有 2 行，archived 大屏 enabled=false。
7. 进 `/bi/screens/{id}/preview`，停留 4s
8. 网络面板看到 `POST /api/reports/visit` 200
9. 数据库验证：
   ```sql
   SELECT * FROM bi_report_visit WHERE user_login='<my>' ORDER BY visited_at DESC LIMIT 5;
   ```
   应多 1 行。
10. 回工作台，切换到"我的概览"，"我常用的报表" 列表应显示该大屏标题，按 `lastVisitedAt` 倒序
