### `ScreenReportLinkSyncServiceTest`（4 个用例）

mock `DtsAnalyticsClient` + `BiReportLinkRepository`：

```java
@ExtendWith(MockitoExtension.class)
class ScreenReportLinkSyncServiceTest {

    @Mock DtsAnalyticsClient client;
    @Mock BiReportLinkRepository repo;
    ScreenReportLinkSyncService service;

    @BeforeEach
    void setUp() { service = new ScreenReportLinkSyncService(client, repo); }

    @Test
    @DisplayName("creates new BiReportLink for new screen")
    void createsNew() { /* ... */ }

    @Test
    @DisplayName("updates existing link when name/classification changes")
    void updatesExisting() { /* ... */ }

    @Test
    @DisplayName("flips enabled=false when screen archived")
    void archivesScreen() { /* ... */ }

    @Test
    @DisplayName("does not touch rows whose source != SCREEN_SYNC")
    void preservesManualRows() {
        // findAllBySource("SCREEN_SYNC") 不返回 manual 行
        // service 不会调用 repo.save 任何 manual 行
    }

    @Test
    @DisplayName("returns skipped when client throws NotConfigured")
    void clientNotConfigured() {
        when(client.listScreens()).thenThrow(new NotConfiguredException());
        SyncResult r = service.reconcileOnce();
        assertThat(r.skipped()).isTrue();
        verifyNoInteractions(repo);
    }
}
```

### `DtsAnalyticsClientTest`（1 个集成）

用 `MockWebServer` (okhttp3) 或 Spring `RestClientTest` 启动 mock server：

```java
@RestClientTest(DtsAnalyticsClient.class)
class DtsAnalyticsClientIT {
    @Autowired DtsAnalyticsClient client;
    @Autowired MockRestServiceServer server;

    @Test
    void parsesScreensList() {
        server.expect(requestTo("/bi/api/screens"))
            .andRespond(withSuccess("[{\"id\":1,...}]", MediaType.APPLICATION_JSON));
        List<ScreenSummary> r = client.listScreens();
        assertThat(r).hasSize(1);
        assertThat(r.get(0).id()).isEqualTo(1L);
    }
}
```

如果项目已用 mock-webserver 模式，沿用既有 helper。
