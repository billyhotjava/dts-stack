# T02：发布运行态与菜单收敛

**优先级**：P0  
**状态**：DONE
**依赖**：F2/T01

## 目标

门户右侧永远读取当前发布版本；全局入口标准化为“数据门户”，同时保留原 menu ID、角色绑定和 `/bi/screens` 管理页。

## 技术设计

- Preview 输入：query `mode=draft|published`、`embed=0|1`；默认 draft 保持管理兼容。
- Preview published 输出：调用 `getScreen(id,{mode:'published',fallbackDraft:false})`；embed 隐藏预览控制 FAB，保留轮播/联动。
- Menu 输入：现有 `sys.nav.portal.biScreens` 行。
- Menu 输出：title=`数据门户`、externalLink=`/bi/portal`；role defaults 同步；migration 原位更新并同步 seed hash。
- 错误：无发布 409，不 fallback；迁移找不到或找到多条目标时 HALT；rollback 恢复 snapshot。
- 范围：`ScreenPreviewPage`、menu seed/default、单一 Liquibase changelog/master、contract tests。

## Definition of Done

- [x] draft 默认兼容与 published/embed fail-closed 契约、Mock E2E 同时通过。
- [x] 菜单测试证明无 `DELETE portal_menu_visibility/portal_menu`。
- [x] changelog 契约可解析、seed hash 精确、rollback 有快照。
