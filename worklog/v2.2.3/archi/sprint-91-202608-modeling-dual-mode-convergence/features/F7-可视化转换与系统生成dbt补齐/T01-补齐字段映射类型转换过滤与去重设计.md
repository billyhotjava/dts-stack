# T01: 补齐字段映射、类型转换、过滤与去重设计

**优先级**: P0
**状态**: CODE_COMPLETE / E2E_PENDING
**依赖**: F6/T01、F6/T02

## 目标

将当前只读取既有 `fieldMappings` 的实现绑定区升级为可编辑、可校验的单来源转换设计，使 DIM 和简单 DWD 模型无需写 SQL 即可形成真实 dbt 实现。

## 转换契约

```text
fieldMappings: [{sourceInputRef, sourceField, targetField}]
casts: {targetField: dataType}
filters: [{field, operator, valueType, value}]
deduplicateBy: [targetField]
```

- `sourceInputRef` 必须来自 F6 snapshot，字段必须来自已确认 schema。
- filter operator 白名单：`EQ/NE/GT/GTE/LT/LTE/IN/NOT_IN/IS_NULL/IS_NOT_NULL/BETWEEN`。
- valueType 白名单：`STRING/NUMBER/BOOLEAN/DATE/TIMESTAMP`；服务端按类型绑定/转义，不拼接原始表达式。
- cast 仅允许当前 adapter 支持的数据类型；非法或有损转换需明确告警并阻断提交。
- deduplicateBy 不能为空字段且必须是输出字段；顺序稳定进入 checksum。

## UI/UX 契约

- 在字段表提供「来源字段」「目标字段」「类型转换」列；支持按名称搜索和批量一一映射，但保存前逐项确认。
- 「过滤条件」「去重键」使用结构化行编辑器；显示空/加载/错误/成功和未保存状态。
- 实时预览只显示逻辑摘要；最终 SQL 预览沿用 F2，不另建 SQL 弹窗或执行入口。
- 切换代码模式不改变这些配置；显式接管后按 ADR-91-09 转为只读。

## Feature 关联

- 输入来自 F6/T02 保存的基础来源与 F6/T01 snapshot。
- 输出作为 F7/T02 编译器设置的一部分，并由 F7/T03 提交 implementation。
- F8/F5 不读取 UI draft，只读取已提交 implementation pins。
