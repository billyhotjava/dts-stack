# T02: 重构字段区模式切换并收敛重复入口

**优先级**: P0
**状态**: IN_PROGRESS（源码与聚焦自动化完成；真实浏览器 IT 待补）
**依赖**: F0/T01、F1/T01

## 目标

在字段与实现区域落地唯一的“可视化模式 / 代码模式”分段控件，并删除重复的“代码模式”“高级 dbt 工作区”按钮。

## 技术设计 (Contract-first)

- **输入契约**: F1/T01 的 `ModelingView`、`ModeAccess`；当前 ModelSpec draft、BUSINESS/TECHNICAL representation。
- **输出契约**: `view=visual` 渲染现有字段/实现表单；`view=code` 渲染代码模式容器；标题与实现摘要始终保留。
- **数据流**: 用户点击 Segmented → 更新 URL → 本地切换容器；已加载 capability 使用缓存，不增加 API 请求。
- **错误路径**: 不可用模式点击无动作并展示 reason；有未保存修改时弹出既有 discard prompt；取消后保持原模式和 URL。
- **复用点**: 复用 `AdvancedDbtWorkspace`、`RequestState`、`Status`、dirty blocker；删除两个重复入口，不保留别名按钮。
- **实现约束**: `ModelingWorkbenchPage.tsx` 已较大，新逻辑抽为子组件，避免继续扩大单文件。

## UI 交互规格

1. 用户选择模型，默认进入可视化模式。
2. 点击代码模式，URL 写入 `view=code`，模型标题和版本不变。
3. 再点可视化模式，若代码草稿 dirty 先确认；确认后切回，取消则不动。
4. 只读/不支持状态在控件旁直接说明原因。
