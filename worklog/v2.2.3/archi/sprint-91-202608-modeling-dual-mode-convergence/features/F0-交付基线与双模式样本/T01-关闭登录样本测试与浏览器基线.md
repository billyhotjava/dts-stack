# T01: 关闭登录、样本、测试与浏览器基线

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

用真实运行证据关闭 `it/baseline.md` 的 P2/P4/P5/P6/P7 缺口，使后续 UI Task 可以进入 READY。

## 技术设计 (Contract-first)

- **输入契约**: 当前 Docker 实例；所级数据管理员 `xiezm`；一个部门只读或受限账号；现有模型创建 API 与 command guard/duty 投影。
- **输出契约**: `it/baseline.md` 更新为可审计探针结果；新增两个 DESIGNER + 一个 DBT 的 `E2E_S91_*` 样本清单，不修改账本#13 中唯一 DESIGNER DRAFT。
- **数据流**: 登录 → 打开模型工作台 → 创建样本 → 读取 lifecycle/representation → 记录 revision/checksum → 运行测试 harness。
- **错误路径**: 登录/DNS/权限/build 任一失败，记录实际错误并保持依赖 UI Task 为 DRAFT，不把环境修复混入业务 Task。
- **复用点**: 复用当前模型创建、lifecycle 与 representation API；不写测试专用后端入口。

## Definition of Ready

- [x] 目标实例、受保护工作台、账号类型和证据目录已明确。
- [x] 样本命名与“不修改现有业务模型”边界已冻结。
- [ ] `xiezm` 与部门受限账号可在目标环境完成真实登录。

## 影响范围

- `it/baseline.md`
- `it/` 下真实探针输出
