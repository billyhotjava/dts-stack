# T02: 数据开发低代码入口设计与菜单契约

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

在数据开发菜单中建立低代码入口，建议命名为“低代码开发向导”或“业务表到指标向导”，并用菜单 seed 和前端 source-contract 固化入口位置。

## 技术设计

- 在 `portal-menu-seed.json` 的 `studio` 分组下新增低代码入口。
- 推荐路由：`/studio/low-code-development`。
- 推荐顺序：低代码开发向导、项目空间管理、逻辑建模（SQL）、脚本开发、任务编排、即席查询、项目文件浏览。
- `role-menu-defaults.json` 是否默认开放要显式决策：建议跟随数据开发基础角色可见，但不授予发布权限。
- 前端菜单契约测试断言：
  - 数据开发包含低代码入口。
  - 指标建模仍是独立一级分区。
  - SQL/脚本/任务编排未被删除。
  - 低代码入口文案不使用 SQL 作为主表达。
