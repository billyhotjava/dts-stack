# T03: 低代码向导页面骨架与状态总览

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

实现低代码向导的页面骨架，展示从业务表到指标和报表数据集的完整状态流，并提供到现有页面的真实跳转。

## 技术设计

- 新建页面组件，例如 `LowCodeDevelopmentPage.tsx`。
- 页面包含六个步骤：数据准备、业务对象确认、指标设计、汇总/应用模型、发布审核、运行证据。
- 每个步骤显示状态、责任人、下一步动作和关联页面。
- 没有后端数据时使用真实的“待接入/待审核/暂无结果”状态，不伪造完成。
- 页面顶部提供“从首张报表旅程继续”的入口，与工作台 no-SQL 旅程互相导流。
