# T01: 指标工作台上下文深链

**优先级**: P0
**状态**: DONE
**依赖**: F2-T02

## 目标

让低代码向导能带着业务对象、数据集、字段和消费目标进入指标工作台，指标工作台也能回到向导继续发布。

## 技术设计

- 设计稳定的上下文参数：
  - `sourceDatasetId`
  - `businessObjectId`
  - `journey=low-code-development`
  - `target=report|dashboard|api|product`
- 指标工作台读取上下文后：
  - 高亮相关业务对象。
  - 展示推荐字段和未绑定指标。
  - 提供“返回低代码向导”动作。
- 优先用前端 query/context contract 固化，后端上下文持久化作为后续增强。

## 影响范围

- 低代码向导页面
- 指标工作台页面
- 指标工作台 source-contract

## 验证

- [x] URL 带上下文进入指标工作台时页面不丢业务对象。
- [x] 指标工作台有返回向导动作。
- [x] 不破坏普通指标工作台入口。

## 完成标准

- [x] 低代码和指标工作台共享上下文，不再割裂。
