# T03: DWS/ADS 发布审核与消费出口

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

把 DWS/ADS 候选接入现有发布审核、治理门禁和消费出口，确保低代码生成结果最终能被报表、大屏、API 或数据产品使用。

## 技术设计

- 候选模型状态：
  - `candidate`: 已生成候选。
  - `blocked`: 质量、权限或口径阻断。
  - `reviewing`: 发布审核中。
  - `published`: 已发布。
  - `failed`: 构建或调度失败。
- 发布前必须检查：
  - owner。
  - 主题域。
  - 密级。
  - 指标口径。
  - 粒度。
  - 质量规则。
  - 权限范围。
- 发布后提供消费出口：
  - 报表数据集。
  - 大屏数据源。
  - API。
  - 数据产品。
  - 任务运维证据。

## 影响范围

- 模型管理页面
- 发布审核页面
- 数据消费入口
- 任务运维入口
- 低代码向导页面

## 验证

- [x] DWS/ADS 未通过门禁不能显示为已发布。
- [x] 发布后能看到消费入口和运行证据。
- [x] 报表数据集说明不泄漏 SQL/dbt。

## 完成标准

- [x] 低代码链路闭环到消费端，而不是停在模型草案。
