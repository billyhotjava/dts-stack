# T03: 浏览器端到端 smoke 与证据沉淀

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

用浏览器验证低代码向导不是静态文案页，而是能串联数据开发、工作台、指标建模、发布审核和任务运维的真实入口。

## 技术设计

- 桌面视口验证：
  - 数据开发菜单进入低代码向导。
  - 六步流程可见。
  - 从数据准备跳转数据源或资产。
  - 从指标设计跳转指标工作台并带上下文。
  - 从发布节点跳转模型管理或发布审核。
  - 从运行证据跳转任务运维。
- 移动或窄屏视口验证：
  - 步骤、按钮、标签不遮挡。
  - 主流程动作仍可见。
- 截图保存到 `assets/`，结果记录到 `it/README.md`。

## 影响范围

- 低代码向导页面
- 工作台首张报表旅程
- 指标工作台
- 发布审核
- 任务运维

## 验证

- [x] Playwright 或浏览器 smoke 通过。
- [x] 截图和命令证据写入 `it/README.md`。

## 完成标准

- [x] 用户能从数据开发低代码入口走到指标和消费出口。
