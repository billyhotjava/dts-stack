# Sprint-59: 低代码无 SQL 数据开发与指标设计一体化

**时间**: 2026-07
**状态**: DONE
**类型**: Product Journey / Frontend-first Implementation / ELT-Metrics Convergence
**目标**: 在数据开发区提供一条面向不懂 SQL 用户的低代码向导，把“接入业务表、确认业务对象、定义指标、生成 DWS/ADS、发布报表数据集”串成连续旅程，同时保留 SQL、脚本、任务编排作为高级开发入口。

## 背景

当前数据开发菜单已经有项目空间管理、逻辑建模（SQL）、脚本开发、任务编排、即席查询和 dbt 文件浏览，但这些入口默认面向数据工程师。对于没有 SQL 经验的新用户，真实目标通常不是“写 SQL 建数仓”，而是“把一张业务表变成可用指标或报表数据集”。

低代码能力不能脱离现有 ELT 和指标建模体系另起炉灶。本 sprint 采用“低代码表达业务意图，平台生成和校验工程产物”的边界：

- 数据接入、ODS、DWD 基座由数据工程师或数据管家保障，低代码用户可以发起需求和确认字段含义，但不直接发布基础层模型。
- DWS/ADS 是低代码主战场，由指标、维度、粒度、筛选条件和消费目标驱动生成。
- 指标设计是低代码开发的核心环节，不是后置的独立模块。
- 任务编排、dbt 文件、SQL/脚本入口继续作为高级开发和运维诊断入口。

## 产品边界

| 能力 | 低代码用户职责 | 专业用户职责 | 平台职责 |
|------|----------------|--------------|----------|
| 数据接入 | 发起业务表需求、说明用途、确认可见字段 | 配置数据源、账号、网络、增量策略、入湖任务 | 串联申请、状态、接入结果和错误提示 |
| DWD 明细层 | 确认业务对象、字段含义、主键、时间字段、敏感字段 | 审核 DWD 草案、补充标准码、发布基础模型 | 给出字段识别、标准映射、治理门禁和草案 |
| DWS 汇总层 | 选择指标、维度、粒度、统计周期 | 审核复杂聚合或跨表 Join | 根据指标意图生成 DWS 候选模型 |
| ADS 应用层 | 选择报表、大屏、API 或数据产品输出 | 审核发布和权限 | 生成可消费数据集、注册血缘和运行证据 |
| 指标设计 | 定义业务口径、计算范围、维度、筛选条件 | 审核复杂口径、处理异常数据 | 校验口径、阻断 SQL/dbt 泄漏、对接发布审核 |

## 编码总原则

- 新入口可以放在数据开发菜单，但实现必须是“编排页”，不要复制接入、治理、指标、编排页面的内部逻辑。
- 优先复用现有 `/workbench?section=data-management&journey=first-report`、数据接入、指标工作台、模型管理、发布审核、任务运维页面。
- 页面主文案使用业务语言，默认不出现 SQL、dbt、ODS/DWD/DWS/ADS；这些术语只出现在高级详情、开发者提示或审核证据中。
- 无 SQL 用户不直接创建 DWD 物理表；只能生成 DWD 草案或待审核事项。
- DWS/ADS 生成必须来自指标、维度、粒度和消费目标，不能变成自由拼 SQL。
- 指标建模与低代码向导共享业务对象、指标、维度、粒度、发布状态，不做两套概念。
- 所有菜单和路由变更必须以 `portal-menu-seed.json` 为事实源，并补 source-contract。

## 完成标准

- [x] 数据开发区有一个明确的低代码入口，能进入“接入业务表生成模型/报表数据集”的向导。
- [x] 低代码向导能从已有业务表或待接入数据源开始，并能清楚区分“可自助继续”和“需要工程师处理”的状态。
- [x] 向导能把业务对象、字段含义、指标、维度、粒度、消费目标串成同一条任务流。
- [x] DWD 草案、DWS/ADS 候选、指标草案、发布审核和任务运行证据之间有明确跳转和状态承接。
- [x] 指标工作台能从低代码向导带上下文进入，不再是孤立指标画布。
- [x] 普通用户路径不暴露 SQL/dbt 作为必填理解成本；高级开发入口仍可进入 SQL、脚本、dbt、任务编排。
- [x] 前端 source-contract、TypeScript、生产构建、后端菜单 seed 契约和浏览器 smoke 通过。

## 范围外

- 不在本 sprint 自研完整 SQL 生成器或可视化 ETL 引擎。
- 不让业务用户绕过治理门禁直接发布 DWD/DWS/ADS。
- 不迁移已有 SQL 建模、脚本开发、任务编排、指标管理页面。
- 不删除高级开发入口。
- 不把 OpenMetadata 或外部 catalog 改造成低代码主工作台。
