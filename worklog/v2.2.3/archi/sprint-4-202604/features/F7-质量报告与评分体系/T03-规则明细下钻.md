# T03: 规则明细下钻 + sparkline 趋势线

**优先级**: P1
**状态**: READY
**依赖**: T02

## 目标
规则明细表最右列展示最近 5 次执行的 sparkline 趋势线，点击规则行可展开查看执行历史和失败行分布。

## 技术设计

### Sparkline
- 数据：最近 5 次 QualityRun 的通过率
- 渲染：ECharts mini chart 或 SVG inline sparkline
- 尺寸：80px × 24px

### 展开行
点击规则行展开：
```
├─ 最近 10 次执行记录（时间、状态、通过率、失败行数）
├─ 失败行按列分布饼图
└─ [去修复] 按钮 → 跳转数据修复 Tab
```

### API
```
GET /api/governance/quality/rules/{id}/history?limit=10
→ { runs: [{ runId, time, status, passRate, failingRows }] }
```

## 影响范围
- 规则明细表增加展开行功能
- 新增 sparkline 组件（可复用于概览 Tab）
