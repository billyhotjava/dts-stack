# T02: 质量报告 Tab 前端

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标
按数据集维度展示质量评分卡片 + 30 天趋势图 + 规则明细表。

## 技术设计

### 布局
```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 综合 87分  │ 完整性92  │ 一致性81  │ 准确性88  │ 唯一性95  │
│ ↑3 较上周  │ ↑5       │ ↓2       │ ↑4       │ —        │
└──────────┴──────────┴──────────┴──────────┴──────────┘
┌─────────────────────────────────────────────────────────┐
│ 30天趋势图（ECharts 折线，5 维度 + 综合）                   │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ 规则明细表                                                │
│ 规则名称 | 类型 | 最近结果 | 通过率 | 失败行 | 趋势sparkline│
└─────────────────────────────────────────────────────────┘
```

### 筛选器
数据集下拉 + 时间范围（7d/30d/90d） + 规则类型

### 评分卡片
- 得分数字大号字体
- Delta 用绿色 ↑ 或红色 ↓
- 点击维度卡片 → 规则明细表自动筛选该维度

## 影响范围

- 复用项目 ECharts 配置模式
