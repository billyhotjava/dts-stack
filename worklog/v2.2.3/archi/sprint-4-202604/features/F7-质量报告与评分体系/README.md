## 评分规则
```
权重：CRITICAL=4, HIGH=3, MEDIUM=2, LOW=1
单规则得分 = 通过率 × 100
维度得分 = Σ(单规则得分 × 权重) / Σ权重
综合得分 = 所有维度得分的加权平均
```
