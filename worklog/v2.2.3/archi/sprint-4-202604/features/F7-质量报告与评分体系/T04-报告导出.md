# T04: 报告导出（PDF/Excel）

**优先级**: P2
**状态**: READY
**依赖**: T02

## 目标
支持将质量报告导出为 PDF 或 Excel，用于离线环境审计存档。

## 技术设计

### Excel 导出
```
Sheet 1 - 评分概览：综合 + 各维度得分
Sheet 2 - 规则明细：规则列表 + 最近通过率 + 失败行数
Sheet 3 - 趋势数据：日期 × 维度得分（用于客户自行画图）
```
使用 Apache POI 生成。

### PDF 导出
使用 iText 或 Flying Saucer（HTML→PDF），包含：
- 评分卡片（静态渲染）
- 趋势图（后端用 ECharts-Java 生成图片嵌入）
- 规则明细表

### API
```
GET /api/governance/quality/report/export?datasetId={id}&format=xlsx
GET /api/governance/quality/report/export?datasetId={id}&format=pdf
→ 文件下载
```

## 影响范围
- 新增 `QualityReportExportService.java`
- 依赖：Apache POI（已有）、iText 或 Flying Saucer（需引入）
