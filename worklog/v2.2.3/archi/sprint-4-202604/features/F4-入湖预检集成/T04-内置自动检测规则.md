# T04: 内置自动检测规则

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标
不管用户是否配置了质量规则，Excel 上传时始终执行一组内置检测，覆盖最常见的格式问题。

## 技术设计

### 内置检测项

| 检测项 | 实现方式 | 错误消息 |
|--------|---------|---------|
| 公式单元格 | POI 解析时标记（cell.getCellType() == FORMULA） | "此处为公式，请填入实际值" |
| 空行 | `WHERE 所有列 IS NULL` | "整行为空" |
| 重复行 | `GROUP BY 所有列 HAVING COUNT > 1` | "与第 X 行重复" |
| 列类型混乱 | 统计同列各类型占比，少数派标记 | "此列大多为日期格式，此行值不符" |
| 数字含单位 | `WHERE col ~ '[0-9]+[^\d.\s]'` | "数字列含非数字字符，如'100元'" |
| 日期格式混用 | 同列检测到多种日期格式 | "日期格式不统一，期望 yyyy-MM-dd" |

### 实现方式
- 内置规则不在 `gov_rule` 表中，硬编码在 `BuiltInRuleChecker.java`
- 检测结果与用户配置规则结果合并，写入暂存表 `_errors`
- 前端展示时区分来源：`[内置]` vs `[规则名]`

### 可配置性
内置规则不可禁用，但严重性固定为 MEDIUM（不阻断入湖，仅警告）。
用户配置的规则根据 `action_on_fail` 决定是否阻断。

## 影响范围
- 新增 `BuiltInRuleChecker.java` 在 dts-ingestion 模块
- 与 `ExcelParseService` 协作（公式检测在解析阶段，其余在暂存表阶段）
