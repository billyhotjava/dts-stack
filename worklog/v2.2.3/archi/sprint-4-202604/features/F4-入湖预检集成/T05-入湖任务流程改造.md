# T05: 入湖任务流程改造（API + 前端步骤）

**优先级**: P1
**状态**: READY
**依赖**: T03

## 目标
在现有入湖创建流程中增加"质量预检"步骤，作为可选环节。

## 技术设计

### 流程变更
```
现有：① 上传文件 → ② 列映射 → ③ 确认执行
改为：① 上传文件 → ② 列映射 → ③ 质量预检 → ④ 确认执行
```

### 入湖任务扩展字段
```sql
ALTER TABLE ingestion_task ADD COLUMN quality_pre_check_enabled BOOLEAN DEFAULT false;
ALTER TABLE ingestion_task ADD COLUMN staging_table_name VARCHAR(100);
ALTER TABLE ingestion_task ADD COLUMN pre_check_status VARCHAR(20); -- PENDING/CHECKING/PASSED/FAILED
```

### 新增 API
```
POST /api/ingestion/tasks/{id}/parse          → 全量解析，写入暂存表
POST /api/ingestion/tasks/{id}/pre-check      → 触发质量预检
PUT  /api/ingestion/tasks/{id}/staging/{rowNum} → 编辑暂存表单行
POST /api/ingestion/tasks/{id}/re-check       → 编辑后重新检查
POST /api/ingestion/tasks/{id}/submit         → 暂存表提交入湖
DELETE /api/ingestion/tasks/{id}/staging       → 取消，清理暂存表
```

### 前端改造
入湖任务创建表单增加：
```
☐ 启用质量预检
```
勾选后：
- 必须选择目标数据集（用于匹配规则）
- 上传完成后跳转预检步骤
- 预检失败 → 跳转数据修复 Tab（带 taskId + datasetId 参数）
- 预检通过或无绑定规则 → 直接到确认步骤

不勾选：走现有 Addax 直通链路。

## 影响范围
- `IngestionTaskResource.java`：新增 6 个端点
- `IngestionTaskService.java`：增加预检流程编排
- `ingestion_task` 表：3 个新字段（Liquibase changelog）
- 前端入湖创建页：增加预检步骤 + checkbox
