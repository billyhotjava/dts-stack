# T02: 质量规则 Tab（分步创建 + 模板内嵌）

**优先级**: P0
**状态**: READY
**依赖**: F1

## 目标
重构规则列表页，去掉底部执行历史，规则创建改为 3 步引导式表单，模板选择内嵌。

## 技术设计

### 规则列表精简
- 去掉底部"执行历史"区域（移到"检查任务"Tab）
- 操作列：常用外露（编辑、执行、禁用），低频收入"更多"下拉（查看历史、复制规则、删除）

### 3 步引导式创建
```
步骤指示器：  ① 选择方式  ──  ② 配置规则  ──  ③ 绑定数据集

第一步：从模板创建 / 自定义 SQL（卡片选择）
  └─ 选模板后展开模板卡片列表（10种）

第二步：规则名称 + 严重性 + 失败策略 + 模板参数（动态渲染）+ 失败修复（可选清洗函数链）

第三步：穿梭框选择绑定的数据集 + 每个绑定可配置作用字段和调度覆盖
```

### 模板参数动态渲染
读取 `GovQualityTemplate.paramSchema` JSON，前端根据类型渲染：
- `column_select` → 下拉框（从数据集列列表获取）
- `enum_list` → 多行输入
- `number` → 数字输入
- `date_format` → 格式选择器

### "发布"逻辑
- "保存草稿"：创建 DRAFT 版本
- "发布"：创建 PUBLISHED 版本，自动归档旧版本

## 影响范围

- 新增 `RuleCreateWizard.tsx`：3 步引导组件
