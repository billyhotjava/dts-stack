# T01: 清洗函数表 + 7 种内置函数初始化

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标
创建清洗函数管理表，初始化 7 种覆盖中文 Excel 常见问题的清洗函数。

## 技术设计

### 表结构
```sql
CREATE TABLE gov_cleansing_function (
    id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code             VARCHAR(64) NOT NULL UNIQUE,
    name             VARCHAR(200) NOT NULL,
    description      TEXT,
    sql_expression   TEXT NOT NULL,   -- 含 {{column}} 占位符的 SQL 表达式
    display_order    INTEGER DEFAULT 0,
    builtin          BOOLEAN NOT NULL DEFAULT false,
    enabled          BOOLEAN NOT NULL DEFAULT true,
    created_by       VARCHAR(64),
    created_date     TIMESTAMP DEFAULT now(),
    last_modified_by VARCHAR(64),
    last_modified_date TIMESTAMP DEFAULT now()
);
```

### 7 种内置清洗函数

| code | name | sql_expression |
|------|------|---------------|
| NORMALIZE_WIDTH | 全角转半角 | `translate({{column}}, '０１２３４５６７８９ａｂｃ...Ａ...', '0123456789abc...A...')` |
| TRIM_INVISIBLE | 去不可见字符 | `regexp_replace({{column}}, '[\x00-\x1f\x7f\u00a0\u200b\ufeff\t]', '', 'g')` |
| NORMALIZE_PUNCTUATION | 中文标点规范化 | `translate({{column}}, '，；：！？（）【】""''', ',;:!?()[]\"\"''''')` |
| NORMALIZE_DATE_CN | 中文日期转标准 | `regexp_replace({{column}}, '(\d{4})年(\d{1,2})月(\d{1,2})日?', '\1-\2-\3', 'g')` |
| STRIP_UNIT | 去除数值单位 | `regexp_replace({{column}}, '[万亿元％%件个台套]', '', 'g')` |
| REMOVE_MERGED_BLANKS | 清除合并单元格空行标记 | 检测关键列全空的行并标记（需配合表级策略） |
| TRIM_SPACES | 首尾及多余空格 | `regexp_replace(TRIM(BOTH FROM {{column}}), '\s{2,}', ' ', 'g')` |
