# T02: 清洗执行引擎

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
实现对指定 ODS 表执行清洗函数的引擎，按函数顺序对每列执行 UPDATE。

## 技术设计

### 核心类 `DataCleansingService`

```java
@Service
public class DataCleansingService {
    /**
     * 对指定表的 varchar/text 列执行所有启用的清洗函数
     */
    public CleansingResult cleanse(String tableName, UUID dataSourceId) {
        // 1. 获取表的列元数据（只处理 varchar/text 类型列）
        // 2. 获取所有 enabled 的清洗函数，按 display_order 排序
        // 3. 对每个函数、每个文本列，生成并执行 UPDATE SQL
        // 4. 记录影响行数
    }
}
```

### 生成的 SQL 示例
```sql
-- TRIM_SPACES 函数应用于 project_no 列
UPDATE ods_project_subject_domain
SET project_no = regexp_replace(TRIM(BOTH FROM project_no), '\s{2,}', ' ', 'g')
WHERE project_no IS NOT NULL
  AND project_no != regexp_replace(TRIM(BOTH FROM project_no), '\s{2,}', ' ', 'g');
```

### 性能考虑
- WHERE 条件避免无效 UPDATE（值未变则不更新）
- 大表分批处理（> 10000 行时分批 UPDATE）
- 清洗结果记录影响行数供审计

### 清洗函数绑定
- 默认对所有 ODS 表的所有文本列执行全部启用函数
- 后续可扩展为表级/列级绑定（当前不做）
