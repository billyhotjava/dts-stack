# T03: 新增清洗函数（DATE_NORMALIZE/STRIP_UNIT/ENUM_MAP/FILL_DEFAULT）

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
新增 4 种面向 Excel 入湖场景的清洗函数，补充现有 TRIM/UPPER_CASE 的不足。

## 技术设计

### 新增函数定义

| 函数 | 说明 | SQL 表达式 |
|------|------|-----------|
| `DATE_NORMALIZE` | 多格式日期统一为 yyyy-MM-dd | `TO_CHAR(TO_DATE({{column}}, auto_detect), 'YYYY-MM-DD')` |
| `STRIP_UNIT` | 去除数字中的文字单位 | `REGEXP_REPLACE({{column}}, '[^0-9.]', '', 'g')` |
| `ENUM_MAP` | 枚举值同义词映射 | `CASE WHEN {{column}} IN ({{aliases:csv}}) THEN {{target}} END` |
| `FILL_DEFAULT` | 空值填充默认值 | `COALESCE(NULLIF({{column}}, ''), {{default}})` |

### DATE_NORMALIZE 详细设计
需要处理的日期格式：
- `2024/1/1`, `2024/01/01`
- `2024年1月1日`
- `20240101`
- `Jan 1, 2024`, `1 Jan 2024`
- `2024-01-01`（已标准，跳过）

实现方式：PG 函数，依次尝试多种格式 `TO_DATE`，第一个成功即返回。
