# T02: 10 种内置模板数据初始化

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
通过 Liquibase 初始化 10 种内置规则模板，覆盖客户 Excel 入湖场景的所有质量检测需求。

## 技术设计

### 模板清单

| code | name | category | sql_template 核心 | 参数 |
|------|------|----------|------------------|------|
| NOT_NULL | 非空检查 | COMPLETENESS | `WHERE {{column}} IS NULL OR TRIM({{column}}) = ''` | table, column |
| ENUM_CHECK | 值域枚举 | ACCURACY | `WHERE {{column}} NOT IN ({{allowed_values}})` | table, column, allowed_values |
| DATE_FORMAT | 日期格式检查 | CONSISTENCY | `WHERE {{column}} !~ '^\d{4}-\d{2}-\d{2}$'` + 合法性 | table, column, format |
| NUMERIC_RANGE | 数值范围 | ACCURACY | `WHERE CAST({{column}} AS numeric) NOT BETWEEN {{min}} AND {{max}}` | table, column, min, max |
| UNIQUE_CHECK | 唯一性检查 | UNIQUENESS | `GROUP BY {{columns}} HAVING COUNT(*) > 1` | table, columns |
| CROSS_COLUMN | 跨列逻辑 | CONSISTENCY | `WHERE NOT ({{expression}})` | table, expression, description |
| CROSS_TABLE_REF | 跨表引用 | CONSISTENCY | `LEFT JOIN {{ref_table}} ... WHERE ref IS NULL` | table, column, ref_table, ref_column |
| AGGREGATE_THRESHOLD | 聚合阈值 | COMPLETENESS | 空值率/重复率计算 > threshold | table, column, metric(null_rate/dup_rate), threshold |
| REGEX_MATCH | 正则匹配 | ACCURACY | `WHERE {{column}} !~ '{{pattern}}'` | table, column, pattern |
| CUSTOM_SQL | 自定义SQL | COMPLETENESS | 用户自由输入 | sql |

### 实现方式
Liquibase INSERT changelog，builtin = true。

### 客户场景映射
- 项目管理 `project_no` 非空 → NOT_NULL
- `risk_level` ∈ {高/中/低} → ENUM_CHECK
- `plan_date` 格式 XXXX-XX-XX → DATE_FORMAT
- 财务 `direct_rate` 0~100 → NUMERIC_RANGE
- 项目编号+分系统不重复 → UNIQUE_CHECK
- 开始日期 ≤ 结束日期 → CROSS_COLUMN
- project_no 必须存在于主表 → CROSS_TABLE_REF
- 空值率不超过 5% → AGGREGATE_THRESHOLD
- 手机号/身份证格式 → REGEX_MATCH
