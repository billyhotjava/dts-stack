## 目标

## 技术设计

### 表结构
```sql
CREATE TABLE gov_quality_template (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code              VARCHAR(64) NOT NULL UNIQUE,
    name              VARCHAR(200) NOT NULL,
    category          VARCHAR(32) NOT NULL,  -- COMPLETENESS/ACCURACY/UNIQUENESS/CONSISTENCY/TIMELINESS
    description       TEXT,
    param_schema      JSONB,                 -- [{name, label, type, required, options, default}]
    sql_template      TEXT NOT NULL,
    severity_default  VARCHAR(16) DEFAULT 'MEDIUM',
    action_default    VARCHAR(16) DEFAULT 'ALERT',  -- ALERT/BLOCK
    dialect           VARCHAR(16) DEFAULT 'POSTGRESQL',
    builtin           BOOLEAN NOT NULL DEFAULT false,
    enabled           BOOLEAN NOT NULL DEFAULT true,
    created_by        VARCHAR(64),
    created_date      TIMESTAMP DEFAULT now(),
    last_modified_by  VARCHAR(64),
    last_modified_date TIMESTAMP DEFAULT now()
);
```

### param_schema 格式示例
```json
[
  {"name": "table", "label": "目标表", "type": "table_select", "required": true},
  {"name": "column", "label": "检查列", "type": "column_select", "required": true},
  {"name": "allowed_values", "label": "允许值列表", "type": "text_array", "required": true}
]
```
