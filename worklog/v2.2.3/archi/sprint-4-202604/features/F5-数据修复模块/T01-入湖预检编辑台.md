# T01: 入湖预检编辑台（前端）

**优先级**: P0
**状态**: READY
**依赖**: F4

## 目标
构建可编辑数据表格组件，展示暂存表数据，支持错误高亮、单格编辑、实时校验、提交入湖。

## 技术设计

### 核心组件：StagingDataEditor
```
props: { taskId, datasetId }

布局：
┌─ 检查结果摘要（指标卡片）
├─ 按错误类型分组统计
├─ 工具栏：☐只看错误行 | [自动清洗] [导出错误报告] [重新检查] [提交入湖🔒]
└─ 可编辑数据表格（分页，每页100行）
```

### 表格交互
- 错误行：行背景浅红
- 错误单元格：单元格边框红色 + ⚠ 图标
- 悬停错误单元格：tooltip 显示 "[规则名] 错误原因"
- 点击错误单元格：变为 input，失焦后调用 `PUT /staging/{rowNum}` + 单格校验
- 校验通过：去掉 ⚠，错误计数 -1
- 校验失败：保留 ⚠，更新 tooltip

### "提交入湖"按钮
- 错误数 > 0 时 disabled + tooltip "还有 N 个错误待修复"
- 错误数 = 0 时解锁
- 点击后调用 `POST /submit`，显示 loading

### "导出错误报告"
调用后端生成 Excel 下载：
- 错误单元格背景红色（Apache POI CellStyle）
- 批注写入错误原因
- 文件名：`{原文件名}_错误报告_{时间}.xlsx`

### 分页
`/api/ingestion/tasks/{id}/staging?errorsOnly=true&page=0&size=100`

## 影响范围
- 新增 `StagingDataEditor.tsx` 组件
- 新增 `stagingApi.ts` API 调用封装
- 数据修复 Tab 中引用此组件
