# T04: 审计日志表 + 自动记录

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标
所有数据修复操作（单格编辑、批量清洗、SQL 修复）统一记录审计日志。

## 技术设计

### 数据模型
```sql
CREATE TABLE gov_data_edit_log (
    id              UUID PRIMARY KEY,
    operation_type  VARCHAR(20) NOT NULL,  -- CELL_EDIT / BATCH_CLEANSE / SQL_REPAIR
    target_table    VARCHAR(100) NOT NULL,
    target_row      INTEGER,               -- 单格编辑时有值
    target_column   VARCHAR(100),           -- 单格编辑时有值
    old_value       TEXT,
    new_value       TEXT,
    sql_statement   TEXT,                   -- SQL 修复时有值
    affected_rows   INTEGER,
    quality_run_id  UUID,                   -- 关联的质量运行
    operator        VARCHAR(100) NOT NULL,
    operated_at     TIMESTAMP NOT NULL DEFAULT NOW()
);
```

### 记录时机
- `StagingTableService.updateCell()` → CELL_EDIT
- `DataCleansingService.applyFunction()` → BATCH_CLEANSE
- `SqlRepairService.execute()` → SQL_REPAIR

## 影响范围
- 新增 `GovDataEditLog` 实体 + Repository
- 新增 Liquibase changelog
- 3 个 Service 增加日志记录调用
