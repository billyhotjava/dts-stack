# T04: 模型管理页全分层呈现

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

修复前端与 API 契约的不一致：`SemanticModelsPage` 的筛选/表单/统计只有 DWS/ADS，而 `modelingApi.ModelSpec.layer` 支持全六层；改为消费分层注册表呈现完整数仓层级。

## 技术设计

- 类型筛选、新建表单 layer 下拉、统计卡、分层 Tag 颜色全部由 `warehouseLayerRegistry` 渲染，删除硬编码 `"DWS" | "ADS"` 常量。
- **客户视图五层**：贴源两层（ODS_RAW/ODS_STANDARDIZED）+ DWD/DWS/ADS 直接展示；**STG 为技术层默认折叠**（筛选"显示技术层"开关后可见）——与治理方案对客户的五层叙事保持口径一致。
- 页面描述文案与实际能力对齐（当前自称"统一登记 DWD/DWS/ADS"而 UI 只给两层）。

## 影响范围

- `src/pages/modeling/SemanticModelsPage.tsx` 及 source-contract 测试
- 消费 F2/T01 注册表，纯前端改动
