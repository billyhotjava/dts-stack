# T01: 业务对象台账瘦身与编码自动生成

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

业务对象台账只保留关键点、删除能删除的一切；对象编码由系统自动生成，杜绝手工编码带来的重复与写法漂移。

## 技术设计（已实现，2026-07-16 页面评审产出）

- **编码自动生成**：新增 `businessObjectCode.ts`，格式 `BO{YYYYMMDD}{三位序号}`——同日顺延、大小写/空白不敏感去重、补删除空号、单日超 999 退化时间戳后缀保唯一；创建表单编码改只读展示（"系统自动生成，无需填写"），提交时注入 payload。
- **页面瘦身**：
  - 统计卡 5→2（业务对象数、已配置主表）。
  - 台账 11 列→7 列：名称+编码合并一列；删业务过程（列表已按过程过滤）、来源模型、标准列。
  - 页面动作只留"新建业务对象"；删"业务过程目录/进入模型管理"按钮（工作台页签与上下文条已覆盖）。
  - 创建表单删主表/主键输入（物理映射在详情映射维护），只余名称+主题域。
  - SemanticWorkspaceFrame 删头部"治理主题域/任务运维中心"跨模块按钮（五个语义页同步减负；任务运维中心退役承接入口保留在 MetricDetailPanel，契约用例继续锁定）。
- **契约防回潮**：SemanticObjectsPage 契约新增两组断言（系统编码、无手工编码/主表/主键/冗余列与按钮）；metricWorkbench 契约 frame 用例更新为"不再承载跨模块导航"的新意图。
