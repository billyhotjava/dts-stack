# T02: 主题域页业务过程管理区

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

选中主题域后可查看/创建/删除业务过程，并从业务过程发起规划。

## 技术设计

- `SubjectAreasPage` 详情区新增"业务过程"列表（名称/描述/创建时间/发起规划按钮）。
- 创建表单内置三条 PJM 示例快捷项；空状态给"从示例创建"动作。
- 发起规划 = 现有规划卡逻辑 + processId 注入上下文。

## 影响范围

- `src/pages/governance/SubjectAreasPage.tsx` 及其 source-contract 测试

- [x] 不破坏主题域树既有交互。
