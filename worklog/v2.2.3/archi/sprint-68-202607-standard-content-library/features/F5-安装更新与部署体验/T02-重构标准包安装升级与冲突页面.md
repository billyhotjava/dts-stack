# T02：重构标准包安装、升级与冲突页面

**优先级**：P0  
**状态**：READY  
**依赖**：T01、F2-T02

## 目标

让管理员在同一页面完成目录浏览、画像选择、preview、冲突处理、apply 和历史回滚。

## 技术设计

- 将当前“内置标准包”升级为内容目录，按通用基线/国家参考/行业扩展分类。
- 卡片/列表显示版本、来源、依赖、许可、条目数和安装状态。
- preview 分组展示新增、更新、本地保留、冲突、弃用和错误。
- 冲突抽屉逐字段比较旧基线、新基线和本地值。
- 网络/API 失败显示重试，不以空列表代替；保持 Chrome 95 兼容。

## 影响范围

- `StandardPackagePage.tsx`
- platformApi 类型和 source-contract
- 路由/菜单与权限

## 验证

- [ ] 首装、升级、冲突和回滚 source-contract。
- [ ] Chrome 95 桌面/390px、只读用户和失败恢复。
- [ ] 大包预检分页/虚拟化不阻塞页面。

## 完成标准

- [ ] 用户能看懂“装了什么、会改什么、哪里冲突”。
- [ ] 分析性说明留在帮助/文档，不把评审文字堆进业务页面。
