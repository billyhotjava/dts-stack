# F5：安装更新与部署体验

**优先级**：P0  
**状态**：READY

## 目标

让实施人员在页面或离线部署流程中选择画像、预检依赖、安装/升级内容，并让客户管理员清楚看到来源、本地改写和冲突。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|---|---|---|---|---|
| T01 | 建立内容目录画像与依赖解析 API | P0 | READY | F2-T03、F4-T05 |
| T02 | 重构标准包安装升级与冲突页面 | P0 | READY | T01、F2-T02 |
| T03 | 接入离线部署画像与初始化流程 | P0 | READY | T01 |
| T04 | 完善客户改写来源追溯与恢复体验 | P1 | READY | T02、F2-T03 |

## 完成标准

- [ ] 页面/API 展示包分类、版本、依赖、来源、许可结论和条目统计。
- [ ] 安装/升级先 preview，冲突未解决时不可 apply。
- [ ] 断网部署可以从产品发布包选择画像并完成安装。
- [ ] 客户可查看基线值、本地值、生效值，恢复基线需明确确认。
- [ ] Chrome 95 桌面与 390px 可操作，API 失败不伪装为空数据。
