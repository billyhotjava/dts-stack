# T04：完善客户改写、来源追溯与恢复体验

**优先级**：P1  
**状态**：READY  
**依赖**：T02、F2-T03

## 目标

让客户管理员在术语、数据元、码表和计量单位页面理解记录来源，安全创建本地改写并恢复基线。

## 技术设计

- 列表/详情显示 DTS 基线、客户扩展、本地改写徽标和包版本。
- 编辑基线前提示将创建 override，不使用“直接修改官方数据”措辞。
- 来源区显示标准号、版本、来源链接/文号和许可证结论，不暴露未授权全文。
- 提供字段级“恢复基线”和整条 override 移除，均需影响预览。
- 被弃用记录显示替代项、引用影响和修复入口。

## 影响范围

- Glossary/Elements/ReferenceCodes/MeasurementUnits 页面
- owner navigation 与引用抽屉
- 来源/override API

## 验证

- [ ] 四类页面来源与改写状态一致。
- [ ] 恢复基线不会删除 Customer Extension。
- [ ] 被引用弃用记录仍可读且有替代提示。

## 完成标准

- [ ] 客户可以少量编辑而不破坏升级基线。
- [ ] 页面业务文案清晰，不暴露后端字段名。
