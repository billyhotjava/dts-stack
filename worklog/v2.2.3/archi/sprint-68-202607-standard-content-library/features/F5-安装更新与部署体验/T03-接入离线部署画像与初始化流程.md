# T03：接入离线部署画像与初始化流程

**优先级**：P0  
**状态**：READY  
**依赖**：T01

## 目标

让新环境在部署阶段选择标准内容画像，启动后即可编辑基线，而不依赖外网或人工逐包安装。

## 技术设计

- 为 init/compose 增加明确的内容画像配置，不覆盖现有 `.env` 用户值。
- 平台健康后由幂等 bootstrap 调用统一 preview/apply 管道。
- 默认画像和“跳过自动安装”可配置，失败不伪装为平台启动成功。
- 输出安装 runId、包版本、条目统计和修复命令。
- 升级部署默认只预检，不在无人确认时覆盖存在本地改写的环境。

## 影响范围

- `init.sh`、compose/env 配置
- dts-platform bootstrap
- 发布包内容目录
- 运维说明

## 验证

- [ ] 全新、重复执行、已有客户数据、断网和包错误场景。
- [ ] 不破坏 x86/dev/legacy compose 模式。
- [ ] 自动安装失败可重试且无半包数据。

## 完成标准

- [ ] 新部署完成后通用基线真实可查。
- [ ] 老环境升级不会因默认画像被静默改写。
