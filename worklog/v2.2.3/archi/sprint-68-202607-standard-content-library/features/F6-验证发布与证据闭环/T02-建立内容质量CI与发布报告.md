# T02：建立内容质量 CI 与发布报告

**优先级**：P0  
**状态**：READY  
**依赖**：F4-T01

## 目标

让内容包在不启动完整 DTS 的情况下完成来源、格式、语义、重复和垃圾数据门禁。

## 技术设计

- 校验 manifest/source/license/checksum/signature 和包依赖。
- 校验 CSV 头、编码、稳定键、空值、类型、父子关系、码表/单位引用。
- 扫描重复、近义、客户标识、测试值、技术字段、报表格式词和大段正文。
- PJM 包额外验证候选审批 ID、血缘索引和拒绝项不在制品中。
- 输出机器 JSON 和业务可读 Markdown 报告。

## 影响范围

- 内容仓库 CI 脚本
- builds/release gate
- IT content-ci evidence

## 验证

- [ ] 正常包通过，逐类坏包稳定失败。
- [ ] 同输入报告确定，包含包/文件/行/字段。
- [ ] 发布制品与报告 checksum 对齐。

## 完成标准

- [ ] CI 失败时不能生成“可发布”目录。
- [ ] 条目数量不掩盖许可、重复或质量失败。
