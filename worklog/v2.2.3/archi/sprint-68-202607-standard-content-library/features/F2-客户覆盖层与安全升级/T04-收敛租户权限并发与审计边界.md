# T04：收敛租户、权限、并发与审计边界

**优先级**：P0  
**状态**：READY  
**依赖**：T02

## 目标

保证内容安装、升级、本地覆盖和冲突选择不会跨租户、绕过角色或覆盖并发修改。

## 技术设计

- 安装/升级/冲突/回滚只允许标准维护角色。
- 所有包 run、baseline、override 和 effective 查询按租户隔离。
- 请求头只能缩小已认证范围，不能切换到无权租户/部门。
- 关键写入使用 ETag/CAS，审计记录操作者、包版本、diff 和选择。
- 读取来源元数据不泄露未授权标准全文或内部证据文件。

## 影响范围

- Spring Security/AccessChecker
- 标准包 REST/service/repository
- Audit catalog
- 前端权限与只读态

## 验证

- [ ] 维护者、查看者、无权限用户真实 filter-chain 测试。
- [ ] 跨租户读写、伪造请求头和旧 ETag 均 fail closed。
- [ ] 重复提交幂等，审计与业务事务一致。

## 完成标准

- [ ] 权限不依赖前端隐藏按钮。
- [ ] 审计能关联 tenant、runId、packageVersion 和冲突决定。
