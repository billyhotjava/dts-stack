# F2：客户覆盖层与安全升级

**优先级**：P0

## 目标

建立 DTS 基线、客户扩展和本地改写三层模型，通过三方 diff 和显式冲突处理保证内容升级不覆盖客户修改。

## 完成标准

- [ ] 页面/API 可区分基线、客户扩展、本地改写和最终生效值。
- [ ] 升级结果覆盖新增、无冲突更新、本地保留、冲突、弃用和替代。
- [ ] 冲突未确认时 fail closed，回滚不删除客户扩展或本地改写。
- [ ] 多租户、权限、CAS/ETag、幂等和审计均有后端事实证据。
