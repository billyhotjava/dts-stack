# T03：实现冲突、弃用、替代与可逆回滚

**优先级**：P0  
**状态**：READY  
**依赖**：T02

## 目标

让管理员显式处理冲突和上游弃用，并保证升级回滚不破坏客户层数据和既有引用。

## 技术设计

- 冲突选择支持采用上游、保留本地或填写新值，并记录选择理由。
- 弃用记录保持可引用只读状态，优先给出 `replaced_by` 修复路线。
- 引用存在时不物理删除基线记录。
- 回滚恢复旧基线 revision 和升级前 override 关系，不删除 Customer Extension。
- rollback 重复执行幂等，后续修改后的严格回滚按 checksum 冲突处理。

## 影响范围

- 标准包冲突/回滚服务
- 引用影响查询
- 标准详情和升级页面
- 审计动作目录

## 验证

- [ ] 三种冲突选择均有审计和数据库事实。
- [ ] 被引用记录弃用后消费者仍可读。
- [ ] 升级回滚保留客户扩展和本地改写。

## 完成标准

- [ ] 不以删除代替弃用。
- [ ] 任一升级 run 可说明回滚了什么、保留了什么、跳过了什么。
