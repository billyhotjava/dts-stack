# T04：建立来源许可与内容发布门禁

**优先级**：P0  
**状态**：READY  
**依赖**：T02

## 目标

防止未经授权的标准全文、码值或第三方内容进入 DTS 商业发布包。

## 技术设计

- `SOURCE-REGISTER.json` 记录来源机构、URL/文号、获取日期、版本、授权类型和证据位置。
- 许可证结论限定为 `APPROVED/REVIEW_REQUIRED/REJECTED`，仅 APPROVED 可发布。
- 区分标准题录、事实码值、DTS 自有定义和受版权保护正文。
- 内容 CI 扫描缺来源、未知许可、复制大段正文、客户/测试标识。
- 标准状态变化只触发候选更新，不在线自动覆盖客户环境。

## 影响范围

- 内容仓库元数据
- 内容构建/发布脚本
- 包目录 API
- 发布检查与合规文档

## 验证

- [ ] APPROVED 样例通过。
- [ ] REVIEW_REQUIRED/REJECTED、缺来源和来源版本不明均阻断。
- [ ] 发布报告列出每个包和上游来源的许可结论。

## 完成标准

- [ ] 没有“公开可看即允许内置”的隐含规则。
- [ ] 法务/产品审核结论能被机器门禁消费。
