# T04：构建 PJM 项目管理参考扩展包

**优先级**：P1  
**状态**：READY  
**依赖**：T03、F4-T01

## 目标

把人工批准的 PJM 候选构建为可选项目管理参考包，与 DTS 通用基线隔离。

## 技术设计

- 包编码固定为 `pjm-project-management-reference`，声明对通用枚举、单位、数据元包的依赖。
- Canonical dim 进入码表；安全 Alias 进入 `05-reference-code-mappings.csv`。
- 数据元和术语只保留去客户化、去报表化、类型已校准的记录。
- 指标只声明外部 metric registry 依赖，不复制公式到标准包。
- 生成准入摘要、拒绝清单和原 PJM 血缘索引。

## 影响范围

- 外置内容仓库 PJM 包
- 项目管理部署画像
- 内容目录与来源页面

## 验证

- [ ] 包内记录全部能回链到批准项。
- [ ] 无测试行、客户值、技术字段和被拒绝映射。
- [ ] 未安装 PJM 包的通用客户环境不出现项目管理专属词。

## 完成标准

- [ ] 包可 preview/apply/rollback，重复构建 checksum 稳定。
- [ ] PJM 第一阶段模型仅作为来源，不成为 DTS 核心事实源。
