# T01：建立 PJM 资产清单与垃圾硬排除

**优先级**：P0  
**状态**：READY  
**依赖**：F1-T01

## 目标

明确 PJM/dbt 中哪些文件是候选事实源，哪些属于测试、运行、生成或展示垃圾，并把排除规则自动化。

## 技术设计

- 白名单事实源：source/schema yml、STG/DWD SQL、治理文档、受控指标注册表。
- 硬排除：`target/`、`logs/`、`test/`、BI/看板 JSON/HTML/图片、ZIP、`.bak`、生成 SQL。
- ODS mapping 只作为候选字段证据，不读取任何测试/客户数据行。
- 输出文件级清单：路径、类型、用途、候选资格、拒绝原因、checksum。
- 扫描具体项目号、人员、部门、供应商、金额和测试标记。

## 影响范围

- `worklog/v2.2.3/s10/v4/pjm`
- 内容候选扫描器/报告
- Sprint-68 PJM 准入证据

## 验证

- [ ] 白名单文件全部可解释。
- [ ] 硬排除样例全部命中，不能被扩展名伪装绕过。
- [ ] 不读取测试 CSV/XLSX 的数据行构建候选。

## 完成标准

- [ ] 产出确定性资产清单和拒绝报告。
- [ ] 扫描器只读 PJM 目录，不修改其 dbt 模型或测试制品。
