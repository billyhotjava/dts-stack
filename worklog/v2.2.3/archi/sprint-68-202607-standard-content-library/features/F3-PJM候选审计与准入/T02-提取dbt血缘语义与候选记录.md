# T02：提取 dbt 血缘语义与候选记录

**优先级**：P0  
**状态**：READY  
**依赖**：T01、F1-T03

## 目标

从 PJM source→STG→DWD 受控链路提取术语、数据元、Canonical dim 和 Alias mapping 候选，而不是从看板文案或原始行猜测。

## 技术设计

- 解析 source/schema yml、`ref/source` 和模型字段，生成候选血缘图。
- Canonical dim 转码表候选；Alias dim 转来源映射候选，禁止混装。
- ODS/STG 全 varchar 不能直接决定最终数据元类型，优先使用 DWD 类型和显式业务定义。
- DWS/ADS 指标只建立到指标注册表的引用，不进入标准内容候选。
- 记录候选原始路径、模型、字段、定义、类型、上下游和治理状态。

## 影响范围

- PJM dbt 元数据解析
- 候选中间清单
- 内容准入服务/脚本

## 验证

- [ ] 进度、质量、技术状态、风险、预算五条链路可追溯。
- [ ] 跟进措施/物料等未完成链路不会冒充已验证候选。
- [ ] Canonical/Alias/metric/technical field 类型区分正确。

## 完成标准

- [ ] 每个候选都有来源模型和字段级血缘。
- [ ] 没有只因中文名称相似就自动创建标准内容。
