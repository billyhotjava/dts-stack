# T04：制作通用数据元与参考术语包

**优先级**：P0  
**状态**：READY  
**依赖**：T01、T02、T03

## 目标

形成自然人、机构、联系、地址、时间、金额、审计和治理等高频通用数据元与参考术语。

## 技术设计

- 数据元目标 300～500 条，按域分包并复用已安装码表/单位。
- 类型、长度、精度、nullable、安全等级必须有规则来源，不能照搬 ODS 全 varchar。
- 术语目标 150～300 条，定义采用 DTS 自有参考表达并保留来源。
- 术语默认 REFERENCE/DRAFT，由客户补责任部门/负责人后确认 ACTIVE。
- `source_system` 不伪填 MDM；客户责任、来源系统和本地标准在部署后维护。
- 与当前 15 个数据元和 3 个术语稳定键对账，避免重复。

## 影响范围

- 内容仓库术语/数据元 CSV
- MetadataStandard/Glossary 默认状态和导入契约
- 码表/单位引用验证

## 验证

- [ ] 中文名、英文名、类型、定义、码表/单位引用和安全等级完整。
- [ ] 重复、近义、客户专属词和报表格式词扫描。
- [ ] 参考术语安装后不自动成为客户正式口径。

## 完成标准

- [ ] 新客户可编辑现有内容而不是从空库创建。
- [ ] 条目规模与质量报告同时达标。
