# T05：建立默认画像与项目管理组合包

**优先级**：P1  
**状态**：READY  
**依赖**：T02、T03、T04、F3-T04

## 目标

把独立内容包组合成通用企业版、最小治理版和项目管理版，避免所有内容无差别默认安装。

## 技术设计

- 画像只引用 package code + version range，不复制包内容。
- 通用企业版覆盖通用码表、单位、数据元、术语和治理。
- 最小治理版用于资源受限或只做治理接入的客户。
- 项目管理版在通用企业版上增加 PJM 批准包。
- 解析依赖后展示安装顺序、总条目、预计影响和已有版本。

## 影响范围

- profile manifest
- 内容目录和依赖解析
- init/deployment config
- 标准内容库页面

## 验证

- [ ] 三种画像依赖闭包和安装顺序确定。
- [ ] 未选择项目管理版时不安装 PJM 专属内容。
- [ ] 版本不满足、包缺失和循环画像稳定失败。

## 完成标准

- [ ] 实施人员部署时选择画像，不需要逐包猜安装顺序。
- [ ] 默认画像可在发布说明中准确复现。
