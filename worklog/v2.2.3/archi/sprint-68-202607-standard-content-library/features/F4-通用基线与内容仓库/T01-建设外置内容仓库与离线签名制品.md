# T01：建设外置内容仓库与离线签名制品

**优先级**：P0  
**状态**：READY  
**依赖**：F1-T02、F1-T04

## 目标

让标准内容脱离 dts-platform classpath 独立构建、版本化和随产品离线交付。

## 技术设计

- 建立 repo-native 内容源目录、schema、构建脚本、制品目录和版本清单。
- 每包输出签名 ZIP、checksums、source register、license notice 和条目统计。
- dts-platform 优先读取外置离线目录，保留 v1 classpath 兼容回退。
- 内容构建可重复，不写入运行日志、target 或测试数据。
- 远程目录作为可选同步源，离线目录始终可用。

## 影响范围

- 新内容仓库/目录
- `builds/` 发布组装
- dts-platform 内容目录加载器
- 镜像/发布包配置

## 验证

- [ ] 同一输入两次构建 checksum 一致。
- [ ] 断网时可列出并读取随发布包交付的内容。
- [ ] 签名或 checksum 被篡改时 preview 阻断。

## 完成标准

- [ ] 更新内容不要求重建 Java 业务代码。
- [ ] 发布包明确记录所携带的内容目录版本。
