# T04: 待审批保护、空态和错误态

**优先级**: P1
**状态**: DONE
**依赖**: T03

## 目标

在新表格交互下保留现有待审批保护，并补齐空态、错误态和查询结果为空的友好提示。

## 技术设计

1. `hasPendingChange=true` 时保留顶部告警，并禁用提交。
2. 查询失败时不清空已选 delta，只提示当前页加载失败。
3. 查询结果为空时显示“未找到匹配用户”。
4. 只读详情页显示当前角色成员列表，不暴露选择框。
