# T03：冻结应用端口与公共审计边界

**优先级**：P0
**状态**：PLANNED
**依赖**：T01

## 目标

让 HTTP、作业和跨域调用只面向 canonical application ports，并保留公共 `AuditService.auditAction(...)` 为唯一审计入口。

## 技术设计（Contract-first）

- **建模端口**：PlanCommand/Query、ModelSpecCommand/Query、StageGate、Lifecycle、ReleaseCandidate、Materialization。
- **审计端口**：`auditAction(String actionCode, AuditStage stage, String resourceId, Object payload)`；action code 必须在 admin 字典登记。
- **调用规则**：resource 只做 auth/DTO/HTTP 映射；application service 拥有事务；repository 不被外层直接调用。
- **耐久化 seam**：AuditService 的提交适配为 F3 的 audit outbox；调用方签名不分裂为第二套 `ModelingAuditService`。
- **错误路径**：未知 actionCode 在测试/发布门禁失败，不能落“未分类”；无 actor/tenant/correlation 的高风险动作 fail-closed。

## 影响范围

canonical application port、HTTP adapter 与 AuditService forward seam；F3 实现 outbox。

## 验证

- [ ] resource→port、port→repository/adapter 的依赖测试。
- [ ] 旧 facade/service 不能成为 canonical port 实现。
- [ ] AuditService action/stage/resource contract 向后兼容。

## Definition of Done

- [ ] F2～F4 可只依赖冻结端口实施。
- [ ] 业务代码无直接 dts-admin client 调用。
- [ ] 审计入口唯一且为 durable adapter 留出事务边界。
