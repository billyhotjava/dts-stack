# T05: 快捷键体系（9 个 IDE 标准）

**优先级**: P0
**状态**: READY
**依赖**: T03

## 目标

在 Monaco 编辑器内注册 9 个 IDE 标准快捷键，提升专业用户效率，对标 DataGrip。

## 技术设计

| 快捷键 | 动作 | 实现 |
|---|---|---|
| `Ctrl+Enter` | 执行当前 SQL（选中则执行选中，否则执行光标所在语句） | 切分语句按分号，找光标所在块 |
| `Ctrl+Shift+Enter` | 执行并新开结果 Tab | 触发 `executeInNewTab` |
| `Ctrl+Alt+F` | 格式化整段 SQL | 调用 T06 的 formatter |
| `Ctrl+/` | 行注释 toggle | Monaco 内置 action `editor.action.commentLine` |
| `Ctrl+D` | 选中下一个相同词 | Monaco 内置 `editor.action.addSelectionToNextFindMatch` |
| `Alt+↑/↓` | 行上移/下移 | Monaco 内置 `editor.action.moveLinesUpAction` / `moveLinesDownAction` |
| `Ctrl+S` | 保存为 Saved Query | 拦截默认浏览器保存，弹对话框 |
| `F8` | 跳到下一个错误 | 读取当前 markers 遍历 |
| `Ctrl+\`` | 切换底部面板折叠 | 修改 Zustand UI store |

### 实现位置

```typescript
editor.addAction({

  label: 'Run Current SQL',
  keybindings: [monaco.KeyMod.CtrlCmd | monaco.KeyCode.Enter],
  run: (ed) => { onExecute?.(getCurrentStatement(ed)); },
});

```

### 语句切分

- 按分号分割 + 跳过字符串字面量内的分号
- 如有选中内容，优先使用选中
- 文件：`editor/statementSplitter.ts`
