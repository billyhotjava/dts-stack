# T01: 新建 sql-ide 组件目录与 SqlIdePage 路由

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

建立新版 SQL IDE 的前后端骨架目录，新增 `SqlIdePage` 路由入口，为后续 Feature 提供脚手架。

## 技术设计

### 前端目录

```
source/dts-platform-webapp/src/components/sql-ide/
├── SqlIde.tsx                   根组件，布局骨架（ActivityBar + SidePanel + Editor + BottomPanel）
├── layout/
│   ├── ActivityBar.tsx          最左侧 44px icon 栏
│   ├── SidePanel.tsx            左侧可折叠面板容器
│   └── BottomPanel.tsx          底部可拖拽高度面板
├── editor/{SqlEditor.tsx,...}   编辑器
├── tabs/{TabBar.tsx,useTabStore.ts}
├── schema/{SchemaTree.tsx,TableDetail.tsx}
├── result/{ResultGrid.tsx,...}
├── history/HistoryPanel.tsx
├── copilot/CopilotSlot.tsx
└── hooks/{useSqlExecution,useCatalog,useResultSet}.ts
```

### 页面入口

- 新建 `source/dts-platform-webapp/src/pages/explore/SqlIdePage.tsx`
- 路由注册与旧 `QueryWorkbenchPage` 并存，由 feature flag 决定挂载哪个

### 后端骨架

- 新建 `source/dts-platform/src/main/java/com/yuzhi/dts/platform/web/rest/sql/SqlIdeResource.java`，统一前缀 `/api/sql/v2/*`，暂只放 `GET /ping` 用于连通性测试
- 新建 `service/sql/SqlIdeTabService.java`、`SqlResultStreamService.java`、`SqlPlanService.java` 空骨架
- 新建 `domain/sql/SqlIdeTab.java` 空实体（实际字段在 T02/T07 定义）

## 影响范围

- 新增前端目录与文件（不动老代码）
- 新增后端类（不动老类）
- 路由注册处（通常是 `routes.tsx` 或等价文件）需新增条目

## 验证

- [ ] 前端 `import SqlIdePage from 'pages/explore/SqlIdePage'` 可正常编译
- [ ] 访问新路由（feature flag 开启时）能看到"SQL IDE v2 骨架"占位页
- [ ] 后端 `GET /api/sql/v2/ping` 返回 200
- [ ] 老 `QueryWorkbenchPage` 路由不受影响

## 完成标准

- [ ] 所有目录/文件按技术设计清单建立
- [ ] 前后端各自编译通过
- [ ] ping 端点可访问
