# T26: 简洁/高级模式切换与用户偏好持久化

**优先级**: P1
**状态**: READY
**依赖**: F1-F5

## 目标

实现 SQL IDE 的双模态切换（分析师默认简洁、开发者切高级），单组件用 `mode` 字段控制条件渲染，偏好存后端用户设置。

## 技术设计

### 模式差异矩阵

| 能力 | 简洁 | 高级 |
|---|---|---|
| 编辑器 minimap | ✗ | ✓ |
| ActivityBar icon | Schema/History/Saved（3个） | 全部 5 个 |
| 底部面板 Tab | Results / Chart / Log | + Pivot / Query Plan |
| 右键菜单项（SchemaTree 表） | 2 项（SELECT / Copy） | 4 项（+INSERT, DDL） |
| 右键菜单项（ResultGrid 列） | 仅 Copy / Pin | + Hide / Filter / Sort |
| 顶部工具栏 | Run / Format | + Explain / Validate / 引擎切换 |
| 快捷键提示 | 仅 Ctrl+Enter 气泡提示 | 完整 `⌨ Shortcuts` 面板 |
| Log 重写后 SQL | 隐藏 | 显示 |
| SQL 参数化 (:param) | 隐藏 | 显示 |

### 切换 UI

- 顶部右上角 toggle：`[简洁 ⇄ 高级]`
- 切换动画 200ms fade
- 切换后不需重载页面，所有组件响应 `mode` prop

### 偏好持久化

- 复用现有用户设置表（或新增 `user_preferences` 如无）
- 键：`sql_ide.mode`
- 值：`simple` / `advanced`
- 默认：首次进入为 `simple`，服务端返回

### 实现

```typescript
// 全局 Zustand
interface UiModeStore {
  mode: 'simple' | 'advanced';
  setMode(m: 'simple' | 'advanced'): Promise<void>;
  hydrate(): Promise<void>;
}

// 所有子组件
const mode = useUiModeStore(s => s.mode);
return mode === 'simple' ? <SimpleView/> : <AdvancedView/>;
```

> 注意：不搞两套组件，只在单组件内用 `mode` 条件渲染。

### 快捷键

- `Ctrl+Shift+M` 切换模式（高级用户）

## 影响范围

- 新增 `store/useUiModeStore.ts`
- 新增 `/api/user/preferences` 接口（若无）
- F1-F5 所有组件接 `mode` prop
