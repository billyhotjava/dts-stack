# T20: 全量审计埋点（执行/分页/导出/复制/二次查询/EXPLAIN/Tab/Saved/Catalog）

**优先级**: P0
**状态**: READY
**依赖**: T16, T17, T19

## 目标

落实三员分立体系下 SQL IDE 的全量审计要求：所有 SQL 执行与结果访问必须留痕，含重写前/后两份 SQL。

## 技术设计

### 审计动作点清单

| 动作 | 类型 | 关键字段 | 埋点位置 |
|---|---|---|---|
| **提交 SQL 执行** | `SQL_EXECUTE_SUBMIT` | `executionId, sqlText, rewrittenSql, engine, datasourceId, userId, deptCode, dataLevel` | `SqlExecutionService.submit()` |
| **取消执行** | `SQL_EXECUTE_CANCEL` | `executionId, reason` | `SqlExecutionService.cancel()` |
| **执行完成** | `SQL_EXECUTE_COMPLETE` | `executionId, status, rowCount, elapsedMs, bytesProcessed` | `SqlExecutionService.executeQueued()` 完成态分支 |
| **结果分页查看** | `SQL_RESULT_VIEW` | `executionId, page, pageSize` | `SqlIdeResource.getPage()` |
| **结果导出** | `SQL_RESULT_EXPORT` | `executionId, format, rowCount, bytesSent` | `SqlResultStreamService.export()` |
| **结果复制到剪贴板** | `SQL_RESULT_COPY` | `executionId, cellCount` | 前端调 `POST /api/sql/v2/audit/copy` 上报 |
| **二次查询创建临时视图** | `SQL_TEMP_VIEW_CREATE` | `executionId, tempViewName, rowCount` | `SqlResultStreamService.createTempView()` |
| **二次查询执行** | `SQL_SUBQUERY_EXECUTE` | `parentExecutionId, childExecutionId, sqlText` | 二次查询 service |
| **EXPLAIN 查询** | `SQL_PLAN_VIEW` | `sqlText, engine, datasourceId` | `SqlPlanService.explain()` |
| **Tab 持久化保存** | `SQL_IDE_TAB_SAVE` | `tabId, sqlTextHash` | `SqlIdeTabService.patch/batchUpsert` |
| **Saved Query 保存/加载/删除/分享** | `SAVED_QUERY_*` | `queryId, title` | `SavedQueryService` |
| **Schema 元数据访问** | `SQL_CATALOG_BROWSE` | `datasourceId, schema, table` | `SqlIdeResource.getTables/getColumns` |
| **执行历史查看** | `SQL_HISTORY_VIEW` | `filters` | `SqlIdeResource.getHistory` |

### 关键原则

1. **重写前后 SQL 都记** —— `SecuritySqlRewriter` 重写前是用户输入，重写后是真正执行的。两份独立存，便于出事回溯
2. **SQL 文本完整记录** —— 不截断，上限 1MB（与 Tab 一致）；但 Tab 持久化用 hash 防审计库膨胀
3. **导出/复制必须审计** —— 数据外泄的高风险点
4. **审计失败不阻断业务** —— 异步写入，异常只记 warn
5. **字段含三员信息** —— `userId`, `deptCode`, `dataLevel` 与现有权限体系一致

### 前端"复制到剪贴板"端点

```
POST /api/sql/v2/audit/copy
Body: { executionId: UUID, cellCount: int }
Response: 200 OK
```

- 前端在 Ctrl+C / 右键复制触发后调用
- 失败不影响复制本身（fire-and-forget）

### AuditService 扩展

- 现有 `AuditService` 已支持异步写，新增类型常量即可
- 若审计表 schema 不够记 1MB SQL，需扩展字段（查现有结构决定）

### 复用与新增

- 现有代码已有部分审计（提交/取消/完成），需**补全**缺失字段（`rewrittenSql`, `deptCode`, `dataLevel`）
- 其他 10 个动作点全部新增
