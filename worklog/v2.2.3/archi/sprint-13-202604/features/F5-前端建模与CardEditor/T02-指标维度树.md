# T02: 指标树 / 维度树 + 字段拖拽

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

在 CardEditor 左栏实现**指标树 + 维度树**，数据源为 F2 的 `/api/semantic/meta`。用户可以拖指标或维度到画布/属性面板完成选择。

## 技术设计

### 1. 树结构

```
📊 主题域：销售
├── 📦 销售日汇总 (ads_sales_daily)
│   ├── 📐 指标
│   │   ├── 💰 营收 (sum, 密级: INTERNAL)
│   │   ├── 🔢 订单数 (count_distinct)
│   │   └── 💵 平均客单 (派生, 可选)
│   ├── 📊 维度
│   │   ├── 🗓️ 下单日期 (time, granularities: [day, week, month, ...])
│   │   ├── 🏪 门店 (categorical, link_to: dim_store)
│   │   └── 🏷️ 渠道 (categorical)
│   └── 🔗 可 Join
│       ├── → dim_customer (M:1)
│       └── → dim_product (M:1, ⚠ 需审批)
└── 📦 客户主数据 (dim_customer)
    ├── 📐 指标 (无 — 只做维度来源)
    └── 📊 维度
        ├── 🌏 地区
        └── 🏅 客户等级
```

### 2. 组件拆分

```
<MetricDimensionTree>
  <SubjectAreaNode>
    <ModelNode>
      <MetricSection>
        <MetricNode draggable>
      <DimensionSection>
        <DimensionNode draggable>
      <JoinSection>
        <JoinTargetNode>
```

- 基于 antd `Tree` + 自定义 `titleRender`
- 每节点带 icon、密级徽章、类型徽章
- Tooltip 显示 `description`、`source_column`、`format`

### 3. 搜索过滤

顶部输入框：
- 按 label 模糊匹配
- 按类型过滤（全部 / 仅指标 / 仅维度）
- 按主题域过滤（下拉）
- 按密级过滤（下拉，仅显示不高于当前用户密级的）

### 4. 拖拽

用 `react-dnd`（或 HTML5 Drag API，权衡兼容性）。
拖拽目标：
- 画布（T03）
- 属性面板的"Measures"/"Dimensions"槽位

DnD payload：
```ts
type DraggedField = {
  kind: "measure" | "dimension" | "join_target";
  id: string;
  label: string;
  source_model: string;
  security_level: SecurityLevel;
  meta: {...};
};
```

拖拽时显示半透明预览 + 拖入目标高亮。

### 5. 只读与视觉

- 指标/维度都是**只读**（不可新建）
- 新建按钮的位置只有"新建派生指标"（走 T04）
- 树节点右键菜单：查看定义 / 查看上游 dbt SQL（跳 dbt docs 链接）/ 复制到剪贴板（id）

### 6. 密级处理

- 高于用户密级的字段置灰 + Tooltip 提示
- 拖不起来（onDragStart 拦截）
- 搜索不返回高密级项（除非用户有 OP_ADMIN）

### 7. 数据加载

```ts
const { data: meta, isLoading, error } = useSemanticMeta({ subjectArea, exposedOnly: true });
```

用 TanStack Query（现有栈），缓存 10 分钟，manifest 变化时手动失效（全局事件）。

### 8. 虚拟滚动

若 metric/dim 数量 > 500，使用 `antd` Tree 自带的 virtual 属性，避免卡顿。

### 9. 空状态

- manifest 未 ingest → 提示"等待数据管道同步，预计 5 分钟"+ 跳转链接到运维页
- 用户无任何可见 model → 提示"请联系数据管理员开放权限"

### 10. 已选字段回显

进入 edit 模式时，已选的指标/维度在树里高亮（checkbox 已勾），可再拖入取消。
