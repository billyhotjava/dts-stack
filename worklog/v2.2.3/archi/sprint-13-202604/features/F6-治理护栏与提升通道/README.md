# F6: 治理护栏与提升通道

**优先级**: P0
**状态**: READY
**依赖**: F3, F5

## 目标

给整个自助 BI 体系加上治理层——确保分析师自由度不失控：
- **白名单**强制（只读入口，不给创建原子指标的 UI 路径）
- **密级传导**（查询结果的密级 = 参与表的最高密级，超限拦截）
- **慢查询熔断**（防止 DB 被打满）
- **虚拟数据集提升到 dbt**（避免沙盒无限增长）

这 4 件事一起决定这套系统能不能长期可运营——不做这层，半年后就会变成"几千个无人管理的虚拟数据集 + 各种版本的营收指标"的灾难。
