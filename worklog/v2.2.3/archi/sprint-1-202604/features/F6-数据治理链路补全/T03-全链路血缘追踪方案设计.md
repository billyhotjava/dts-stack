# T03: 全链路血缘追踪方案设计

**优先级**: P2
**状态**: READY
**依赖**: T01

## 目标
设计覆盖从数据源到 BI 报表的全链路血缘追踪方案。

## 技术设计

### 现状
- dbt 模型血缘: 通过 manifest.json 解析，OpenMetadata 展示
- Addax 接入血缘: 部分依赖手动注册
- BI 报表血缘: 未覆盖
- 缺失链路: 数据源 -> ODS（Addax）、ADS -> BI 报表

### 设计要点
1. **血缘采集点**:
   - 数据接入层: Addax 任务自动注册 source -> ODS 血缘
   - 建模层: dbt manifest 解析（已有）
   - BI 层: 报表/看板引用的数据集追踪
2. **血缘模型**: OpenMetadata 的 lineage API 扩展
3. **列级血缘**: dbt 列级血缘 + SQL 解析
4. **血缘图谱**: 全链路可视化（前端组件）
5. **血缘应用**: 影响分析（上线变更前评估下游影响）
6. **血缘更新频率**: 实时 vs 批量刷新

## 影响范围
- `dts-ingestion`: Addax 任务完成后自动注册血缘
- `dts-platform`: 血缘查询和展示 API
- OpenMetadata: 血缘 API 调用
- 前端: 血缘图谱可视化组件
