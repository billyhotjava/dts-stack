# T02：全数据源参数执行链

**优先级**：P0
**状态**：DONE
**依赖**：T01

## 目标

让 DataLayer 直接消费下钻内核返回的有效数据源和参数，移除 Card 专用运行时限制。

## 技术设计

- `useDrillDown` 输入根 DataSourceConfig，而不是 rootCardId。
- `DataLayer` 将 effectiveDataSource 传给 `useCardDataSource` 现有统一适配入口。
- 运行变量 bindings 与下钻 queryParameters 按当前既有覆盖规则合并。
- 查询失败保留 stack 和面包屑，允许用户返回上一层。
- 不修改后端查询 API 和业务 SQL。

- `source/dts-platform-webapp/src/analytics/pages/screens/renderers/DataLayer.tsx`
- `source/dts-platform-webapp/src/analytics/pages/screens/hooks/useDrillDown.ts`
