# T02：跨数据源通用能力矩阵

**优先级**：P0
**状态**：DONE
**依赖**：F2-F3

## 目标

用中性测试数据证明 SQL、API、Card、Dataset、Metric 以及主要可视化组件通过同一配置和运行时内核完成下钻。

## 技术设计

- 测试 fixture 只使用 `keyA`、`keyB`、`label`、`amount` 等中性字段。
- 五类数据源复用同一个 mappings 和 stack 断言。
- 分别验证父参数继承、关闭继承、重复参数覆盖和缺失字段取消。
- 建立柱体、饼图扇区、折线点、散点、漏斗阶段、雷达系列、组合图数据项、层级图节点、地图区域、表格行和 KPI/卡片点击矩阵。
- 正向点击必须携带实际数据项载荷；空白区、图例、坐标轴、表头、滚动条、分页和地图缩放不得误触发。
- 快速连续点击只允许推进一级；查询失败必须保留返回和重置能力。
- 检查生产代码中不存在接入系统名称或领域字段专用判断。
