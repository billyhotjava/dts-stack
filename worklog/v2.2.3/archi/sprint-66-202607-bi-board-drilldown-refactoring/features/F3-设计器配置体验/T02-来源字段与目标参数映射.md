# T02：来源字段与目标参数映射

**优先级**：P0
**状态**：DONE
**依赖**：T01、F2/T01

## 目标

让每个下钻层级配置来源路径、目标参数、转换方式和上下文继承，不使用业务字段模板。

## 技术设计

- 复用动作配置现有 mapping 编辑模式，抽取可复用映射编辑单元。
- 来源路径候选来自组件点击载荷和当前数据列；仍允许手工输入嵌套路径。
- 目标参数为普通字符串键，保存前执行变量键格式校验。
- 默认继承父层上下文，允许逐层关闭。
- 空映射、空目标参数和重复目标参数在 UI 中即时提示。
