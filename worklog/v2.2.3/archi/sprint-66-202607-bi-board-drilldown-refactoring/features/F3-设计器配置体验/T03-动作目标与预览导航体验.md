# T03：动作目标与预览导航体验

**优先级**：P1
**状态**：DONE
**依赖**：T01、T02、F2/T03

## 目标

补齐 drill-view 配置入口，并在预览中提供清晰的面包屑、上卷和重置操作。

## 技术设计

- 动作下拉增加并正确保存 `drill-view`。
- 选择目标视图时使用当前 ScreenConfig 页面/视图列表，不手工填写业务地址。
- drill-view 支持 mappings 和通用 label。
- 面包屑显示配置 label 与映射值；提供“返回上一层”和“重置”入口。
- 使用现有主题 token 和旧浏览器兼容样式。
