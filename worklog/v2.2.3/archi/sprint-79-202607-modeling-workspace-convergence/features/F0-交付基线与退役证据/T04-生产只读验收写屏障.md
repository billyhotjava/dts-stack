# T04：生产只读验收写屏障

**优先级**：P0  
**状态**：IN_PROGRESS  
**依赖**：F0/T01

## 目标

任何经 Sprint-79 特权 wrapper 访问生产环境的 Playwright 旅程，都在首次导航前安装统一写请求屏障，并在结束时证明业务 API 写请求为 0。

## 技术设计（Contract-first）

- **输入契约**：允许执行的精确 spec 路径；请求方法与 URL。
- **输出契约**：GET/HEAD/OPTIONS 继续；命中 `/api/`、`/admin/api/`、`/analytics/api/`、`/bi/api/` 的 POST/PUT/PATCH/DELETE 被浏览器侧中止并记录。
- **数据流**：wrapper allowlist → shared read-only Playwright fixture → 页面旅程 → 零写断言。
- **错误路径**：任何写请求立即 `blockedbyclient`，旅程失败并输出方法与路径；不得依赖人工确认环境变量代替执行期保护。
- **复用点**：抽取现有 `sprint79-model-detail.spec.ts` 的屏障，不复制第二套方法分类。
