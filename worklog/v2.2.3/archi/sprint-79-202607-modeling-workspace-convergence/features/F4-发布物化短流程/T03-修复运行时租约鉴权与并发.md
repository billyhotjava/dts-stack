# T03：修复运行时租约鉴权与并发

**优先级**：P0  
**状态**：IN_PROGRESS  
**依赖**：F4/T02

## 目标

Airflow 可在严格服务鉴权下续租，数据库时间成为过期 CAS 的唯一时钟，并让 orphan 清理有界、批量且可恢复。

## 技术设计（Contract-first）

- **输入契约**：`POST /profile-leases/{uuid}/consume|renew`、`DELETE /profile-leases/{uuid}`；服务身份 `dts-airflow`。
- **输出契约**：规范 UUID 的 renew 被精确放行；错误 token、错误服务、额外路径段拒绝。
- **并发契约**：consume/renew 在同一 PostgreSQL `UPDATE` 中使用数据库当前时间判断；renew 返回数据库实际 `expires_at`。
- **恢复契约**：`viewActive` 使用锁后数据库时钟；文件在状态变更后消失时，以版本化 CAS 补偿为终态。
- **清理契约**：每轮 orphan 工作量有上限，租约状态批量读取，不产生目录数规模的 N+1。
- **错误路径**：租约状态冲突返回 409；存储/文件清理故障返回 5xx。
