# T03：修复关系图分页并拆分投影服务

**优先级**：P0  
**状态**：DONE  
**依赖**：F3/T02

## 目标

遍历全部 cursor 页面后得到完整、无重复的节点和关系，并把关系图投影实现拆分为职责清晰且每文件不超过 800 行的组件。

## 技术设计（Contract-first）

- **输入契约**：现有 `GET .../{planId}/relationship-graph` 参数 `kind/query/limit/cursor` 不变。
- **输出契约**：每页是可合并的稳定投影；跨页关系不会永久丢失；游标继续绑定 tenant/plan/department/filter/window。
- **数据流**：canonical owners 批量水合 → 稳定候选顺序 → 连通分页/端点上下文 → HMAC cursor。
- **入边索引**：`depends_on`、`dimension_refs` 使用可回滚的并发 GIN 索引；每页最多 500 个精确 `id+revision` 探针和 501 条 lookahead。
- **错误路径**：重排、篡改、跨 scope cursor 继续 fail-closed；上限不足时返回明确继续提示。
- **复用点**：继续使用既有 ModelSpec、Dimension、Standard、Indicator owner，不新增图谱表。
