# Sprint-78 非功能预算（G1）

| 属性 | 预算/目标 | 度量方式 | 关联 |
|---|---|---|---|
| 可恢复性 RPO | ≤ 24h（每日备份） | crontab 每日执行 + manifest 时间戳 | F3/T02 |
| 可恢复性 RTO（单库） | ≤ 1h（演练实测为准并记录） | 恢复演练报告计时 | F3/T3 |
| 备份产物安全 | 目录 700、文件 600；日志/manifest 无口令 | 权限检查 + grep | F3/T01 |
| 初始口令强度 | SecureRandom 16 字符（字母数字+安全符号），两次生成不相同 | 契约测试断言 | F1/T01 |
| 口令暴露面 | 明文仅存于执行响应内存；DB/日志/审计明细 0 命中 | 测试 + grep | F1/T01/T02 |
| 私钥暴露面 | `git ls-files` 0 个 p12；yml 无明文口令 | git/grep 校验 | F2/T01 |
| 外部攻击面 | hetu 代理路由 9 → 0 | compose/file provider grep + 路径行为矩阵 | F4/T01/T03 |
| 性能 | 备份窗口避开业务高峰（建议 03:17）；pg_dump 对业务影响不评估新指标，沿用单实例现状 | crontab 配置 | F3/T02 |
| 兼容性 | 默认 compose（无 tls profile）行为不变；历史 hetu 深链可重定向 | compose config + contract 测试 | F2/T02、F4/T02 |

预算说明：本 Sprint 不引入新服务、新端口、新持久化卷（备份目录为宿主机既有路径下的新子目录），容量面仅备份磁盘占用——按 10 库 × 14 天保留估算并写入 runbook 巡检项。
