# T01: 目标库连接配置解析器

**优先级**: P0
**状态**: DONE
**依赖**: F1

## 目标

让 `OpenMetadataAdapter` 能从当前接入任务配置中稳定解析目标库连接信息。

## 范围

- 支持 Addax writer 常见 nested `connection` 结构。
- 支持 `jdbcUrl` / `jdbc_url` / `url` 解析 host、port、database。
- 保留顶层 `host/port/database/username/password` 兼容。
- 对缺失字段输出结构化诊断，不打印密码。

## 完成标准

- [ ] PostgreSQL/MySQL 等 JDBC URL 可解析。
- [ ] nested connection 多表配置可解析目标库和目标表。
- [ ] 缺参时返回缺失字段列表。
- [ ] 单测覆盖成功和失败路径。
