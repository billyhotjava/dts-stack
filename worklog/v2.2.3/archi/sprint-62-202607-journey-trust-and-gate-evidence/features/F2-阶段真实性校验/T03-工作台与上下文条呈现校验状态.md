# T03: 工作台与上下文条呈现校验状态

**优先级**: P1
**状态**: DONE
**依赖**: T02

## 目标
把校验结果呈现给用户：无效对象红标可清除，未验真的完成态标"待确认"。

## 技术设计
- `DataManagementWorkbenchPage.tsx`：构造 mock validator 的 validations 传入 stage states；done+unverified 显示 Tag "已就绪·待确认"（tooltip 说明缺后端校验 API）；blocked(invalid) 阶段的恢复动作=移除该 query 参数后的当前 URL。
- `JourneyContextBar.tsx`：contextLabels 中 invalid 的参数加红色标识与"清除"小按钮（点击后跳转移除该参数的当前路由 URL）。
- 状态覆盖：valid/invalid/unknown/无参数四态在两处 UI 均有明确表现。
