# F2: DTS 治理扩展层

**优先级**: P0  
**状态**: DONE

## 目标

将 DTS 自定义治理属性从弱 catalog 技术表中解耦出来，挂载到 OpenMetadata 技术资产之上，保留 DTS 在权限、密级、审批、脱敏和审计上的产品能力。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | `catalog_asset_extension` 模型与字段定义 | P0 | DONE | - |
| T02 | 密级、归属部门、负责人、生命周期、主题域扩展 API | P0 | DONE | T01 |
| T03 | 治理状态机：待认领、待定级、待归域、已治理、停用 | P0 | DONE | T01 |
| T04 | 权限、脱敏、行过滤与 asset extension 关联 | P0 | DONE | T01 |
| T05 | 审计动作与变更日志 | P1 | DONE | T02-T04 |

## 完成标准

- [x] OM 技术资产可以挂载 DTS 密级、部门、负责人和生命周期。
- [x] 未治理资产可进入待治理队列。
- [x] 资产治理属性更新有权限控制和审计记录。
- [x] 现有授权、脱敏、行过滤规则可以继续关联资产。
- [x] 治理扩展不要求写回 OpenMetadata。
