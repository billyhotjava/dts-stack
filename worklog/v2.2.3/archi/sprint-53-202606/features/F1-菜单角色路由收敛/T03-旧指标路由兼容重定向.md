# T03: 旧指标路由兼容重定向

**优先级**: P0  
**状态**: DONE  
**依赖**: T02

## 目标

把旧指标服务路由从 iframe 改成平台内兼容 redirect，避免用户继续进入 dts-metrics 服务。

## 技术设计

- 删除或停止使用 `MetricsServiceFrame` iframe 作为默认兼容方式。
- 建立兼容映射：
  - `/bi-apps/metrics`、`/bi-apps/metrics/center` -> `/modeling/metric-workbench`
  - `/bi-apps/metrics/assets`、`/bi-apps/metrics/dictionary` -> `/modeling/semantic/metrics`
  - `/bi-apps/metrics/operations`、`/metrics/operations`、`/bi-apps/metrics/f5-security-it`、`/metrics/runs` -> `/modeling/semantic/runs`
  - `/bi-apps/metrics/semantic` -> `/modeling/semantic/models`
  - `/bi-apps/metrics/semantic/subjects` -> `/modeling/semantic/subjects`
  - `/bi-apps/metrics/semantic/objects` -> `/modeling/semantic/objects`
  - `/bi-apps/metrics/semantic/metrics` -> `/modeling/semantic/metrics`
  - `/bi-apps/metrics/semantic/models` -> `/modeling/semantic/models`
  - `/bi-apps/metrics/publish`、`/bi-apps/metrics/semantic/publish` -> `/modeling/semantic/publish`
  - `/modeling/semantic-center`、`/bi/semantic-modeling` -> `/modeling/semantic/models`
- 保留 query/hash。
- `dynamic-resolver.tsx` 与 `static-routes.tsx` 保持一致。

## 影响范围

- `source/dts-platform-webapp/src/routes/sections/dashboard/static-routes.tsx`
- `source/dts-platform-webapp/src/routes/sections/dashboard/dynamic-resolver.tsx`
- `source/dts-platform-webapp/src/routes/sections/dashboard/metricsServiceRoutes.ts`

## 验证

- [x] 旧路径 redirect 到平台页面，不再产生 `/metrics/*` iframe src。
- [x] 旧“指标运营台”路径显式跳转到平台运行监控页，不再 fallback 到指标工作台。
- [x] query/hash 在 redirect 后保留。

## 完成标准

- [x] 旧客户收藏链接能打开平台新页面。
- [x] 默认平台页面不再依赖 dts-metrics 服务可用性。
