# T02: 业务对象表映射编辑闭环

**优先级**: P0  
**状态**: DONE  
**依赖**: F0/T02

## 目标

补齐 Sprint-52 残留：`SemanticObjectsPage` 不仅能看 join 图，还能编辑并保存表映射。

## 技术设计

- 在 `SemanticObjectsPage.tsx` 中引入 `saveSemanticObjectTableMappings`。
- 选中对象后提供“编辑表映射” Drawer：
  - tableName
  - tableRole
  - joinExpression
  - sortOrder
- 保存成功后刷新 mappings 并重绘 `VisualFlowCanvas`。
- join 图主节点按 `main` / `primary` / `fact` 主表角色识别，避免排序变化后画到错误源节点。
- 预览/执行 SQL 与 dbt 生成共用主表角色语义，避免 UI 保存 `main` 后后端仍只认 `PRIMARY`。
- 空态展示“暂无表映射，去编辑”而不是空白画布。
