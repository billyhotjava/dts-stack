# T01: 当前入口与运行面基线审计

**优先级**: P0  
**状态**: DONE  
**依赖**: 无

## 目标

盘点 `dts-metrics` 在菜单、路由、compose、build、init、image、Maven 和平台配置中的所有默认入口。

## 技术设计

- 从 `portal-menu-seed.json`、`role-menu-defaults.json`、`static-routes.tsx`、`dynamic-resolver.tsx` 查客户可见入口。
- 从 `docker-compose-app.yml`、`init.sh`、`imgversion*.conf`、`builds/dts-build.sh`、`source/pom.xml` 查默认运行/构建入口。
- 从 `source/dts-platform/src/main/java/.../config/metrics` 查平台到 metrics 的能力配置。
- 输出到 `assets/dts-metrics-retirement-matrix.md`。

## 影响范围
