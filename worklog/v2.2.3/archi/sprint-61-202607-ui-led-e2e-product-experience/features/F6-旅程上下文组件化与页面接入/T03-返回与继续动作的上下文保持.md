# T03: 返回与继续动作的上下文保持

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

统一各阶段“返回工作台”和“继续下一步”的路由规则，保证 `sourceId`、`standardDraftId`、`modelId`、`metricId` 等上下文不在页面跳转中丢失。

## 技术设计

- 增加 `buildJourneyUrl` 工具，合并目标路由和当前 query。
- 明确参数白名单，避免把无关筛选项无限传递。
- 为每个阶段定义 primary/secondary/evidence 三类目标。
- 对无目标对象的情况给出下一步创建入口。

## 影响范围

- `source/dts-platform-webapp/src/routes`
- `source/dts-platform-webapp/src/pages/**`
- journey source-contract
