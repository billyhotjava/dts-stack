# T02: 核心页面接入上下文条

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

把旅程上下文条接入端到端链路的关键页面，让用户从工作台跳出后仍知道自己处在 DTS 数据产品交付的哪一步。

## 技术设计

- 第一批页面：`DataSourcesPage`、`StandardPackagePage`、`ElementsPage`、`LowCodeDevelopmentPage`、`SqlModelingPage`、`MetricWorkbenchPage`、`ApiServicesPage`、`OpsInstancesPage`。
- 页面顶部或主操作区域展示 `JourneyContextBar`，避免与现有 `PageHeader` 重叠。
- 每个页面配置自己的阶段编码和下一步动作。
- 无权限、无数据、后端 API 缺失时显示 blocker，而不是隐藏上下文条。

## 影响范围

- 指标、服务、运维页面
