# T03: 失败、补数、审计证据聚合入口

**优先级**: P1
**状态**: DONE
**依赖**: T02

## 目标

把失败处理、补数、审计证据作为数据产品旅程的最后一段，而不是独立运维后台。

## 技术设计

- 工作台证据卡显示失败实例、补数入口、审计事件、质量记录。
- `OpsBackfillPage` 和 `AuditEvidencePage` 支持 journey/model/service 参数。
- 缺少关联 API 时显示“证据聚合待补接口”的 blocker。

## 影响范围

- `OpsBackfillPage.tsx`
