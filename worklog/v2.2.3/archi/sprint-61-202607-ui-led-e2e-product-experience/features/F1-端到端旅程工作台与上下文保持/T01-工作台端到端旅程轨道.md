# T01: 工作台端到端旅程轨道

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

在工作台首屏提供端到端数据产品旅程轨道，覆盖集成、规划、标准、建模、指标、开发、服务和证据。

## 技术设计

- 在 `DataManagementWorkbenchPage.tsx` 增加 journey rail 数据结构。
- 每个阶段显示状态、owner、缺口、主按钮、证据按钮。
- 路由跳转统一携带 `journey=e2e-data-product`。
- 避免把分析说明放入 UI，页面文案只描述用户动作。
