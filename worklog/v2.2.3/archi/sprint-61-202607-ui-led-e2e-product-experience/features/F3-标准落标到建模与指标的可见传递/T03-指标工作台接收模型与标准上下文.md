# T03: 指标工作台接收模型与标准上下文

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

指标工作台能从模型和标准上下文进入，提示指标口径应绑定哪些业务对象、字段和标准。

## 技术设计

- 支持 `/modeling/metric-workbench?journey=e2e-data-product&modelId=...&standardDraftId=...`。
- 在 `MetricWorkbenchPage.tsx` 增加上下文提示卡：来源模型、标准字段数、待绑定指标。
- 指标创建入口预填模型/字段上下文；缺 API 时显示 blocker。

## 影响范围

- `MetricWorkbenchPage.tsx`
- `metricWorkbench.source-contract.test.ts`

## 验证

- [x] source-contract 断言 query 参数被页面识别。
- [ ] 指标创建按钮 disabled/error/success 状态可见。

## 完成标准

- [x] 标准和模型不止进入 SQL，也能进入指标口径设计。

## 实施证据

- 指标工作台识别 `journey`、`modelId`、`standardDraftId`、`metricId`，展示来源上下文并可返回 SQL 建模。
- `metricWorkbench.source-contract.test.ts` 已覆盖上下文识别；服务发布动作由本 Feature 的收口改动继续携带这些参数。
