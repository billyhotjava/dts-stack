# T02: v1 大屏只读打开 + "转为 v2"按钮

**优先级**: P0
**状态**: DONE
**依赖**: F1, F3

## 目标

旧 v1 大屏在编辑器里**能打开但不可编辑**（避免破坏），提供"转为 v2"按钮允许用户手动升级。预览/公开页照常显示（v1 渲染路径不变）。

## 技术设计

### 编辑器入口

```tsx
function ScreenDesignerPage() {
  const screen = useScreen(id)
  
  if (!screen) return <Loading />
  
  if (screen.version === 2) {
    return <DesignerV2 screen={screen} />
  }
  
  // v1 大屏
  return (
    <div>
      <Banner type="warning">
        这是旧版（v1）大屏。编辑器仅支持响应式（v2）大屏。
        <Button onClick={handleConvertToV2}>转为 v2 开始编辑</Button>
      </Banner>
      <LegacyDesignerReadOnly screen={screen} />
    </div>
  )
}
```

### LegacyDesignerReadOnly

直接复用 `DesignerCanvas` 但禁用所有交互（`isDraggable/isResizable=false`，组件不可选中）。

### handleConvertToV2

```ts
async function handleConvertToV2() {
  // 弹确认对话框：警告精确位置可能变化
  const ok = await confirm({
    title: '转换为 v2 响应式大屏？',
    content: '会把像素坐标映射到网格单元，组件位置可能有轻微调整。此操作会创建新大屏，原 v1 保留不删。',
  })
  if (!ok) return
  
  const v2 = migrateV1ToV2(screen)  // F5-T03 提供
  const created = await analyticsApi.createScreen({ ...v2, name: screen.name + ' (v2)' })
  navigate(`/analytics/screens/${created.id}/edit`)
}
```

### 策略讨论

**不自动原地转换**：原地转换会丢数据。**创建副本**更安全。

**demo 期可接受**：直接提示"请重新创建"也行（T03 迁移脚本做好才启用"转为 v2"按钮）。

## 影响范围

- `ScreenDesignerPage.tsx`
- 新增 `v2/LegacyDesignerReadOnly.tsx`（或直接复用 v1 canvas + readonly prop）
- 路由不变
