# T03: 维度候选前置门禁

**优先级**: P0  
**状态**: DONE

## 目标

在生成维度模型前明确检查规划、主题域和标准字段是否齐备。

## 技术设计

- 规则至少包含 planning context、domain、standardDraft 和字段数量。
- 检查结果区分 ready、missing、blocked，并提供对应修复路由。
- 不改变现有 SQL 发布门禁，作为模型候选前置门禁。

## 影响范围
