# T04：实现可视化能力判定

**优先级**：P0
**状态**：CODE_COMPLETE
**依赖**：T03

## 目标

基于固定 ModelSpec、Implementation 和规范化 projection 稳定输出 `BUSINESS_VISUAL_EDIT | BUSINESS_VISUAL_READ | ADVANCED_DBT_IMPLEMENTATION | BLOCKED` 及 reason code，让普通界面不依赖前端猜测能力。技术三方漂移与语义映射状态机拆到 P1/T05。

## Contract-first

- **输入**：固定 ModelSpec revision、Implementation revision、ownership、字段/依赖 provenance、解析 issues 和 runtime evidence 可用性。
- **输出**：`visualizationCapability`、稳定 `capabilityReasons[]`、可见分区与允许动作；能力与 ownership、运行状态互相独立。
- **错误路径**：证据缺失、动态依赖、字段不可信、跨 revision/checksum 或权限不足均 fail-closed 为 `BLOCKED` 或降级只读；不得返回可编辑图。

## 验证

- [ ] 四类 capability 与 reason code 参数化契约测试。
- [ ] capability 与 `DESIGNER_GENERATED|DBT_MANAGED` ownership 正交，外部安全 SQL 不会被静默改 ownership。
- [ ] BLOCKED 不产生 proposed editable graph。

## Definition of Done

- [ ] F2/F3 共用同一 capability/reason code，不在前端重复判断。
