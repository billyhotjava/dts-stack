# T03：回归候选、发布、物化与治理证据

**优先级**：P0  
**状态**：IMPLEMENTED  
**依赖**：T01、T02、F3/T03

## 目标

证明统一 authoring commit 只是创作入口收敛，不改变 release candidate、构建/质量/评审/发布、物化和 Sprint-93 稳定资产证据语义。

## 技术设计（Contract-first）

- **输入契约**：commit 回执 model/implementation/dependency pins；existing candidate/materialization APIs；Sprint-93 AssetKey/quality/lineage seams。
- **输出契约**：candidate pins 与 commit 完全一致；provenance 不进入 target selector/AssetKey；二次物化新增 attempt/observation 而不新建模型/实现/资产。
- **数据流**：authoring commit → candidate → compile/build/test → governance quality → review/publish → materialization plan/dispatch → catalog observe/lineage/serving。
- **错误路径**：旧 candidate pins stale 明确 BLOCK；不能用当前 head 覆盖历史；物化失败走既有 retry/rollback。
- **复用点**：Sprint-91 F5/F8、Sprint-93 F1～F6；不修改其台账 owner。

## 影响范围

以集成测试和最小 adapter 修复为主，可能涉及 release candidate pins、materialization planner 读取和 Sprint-93 evidence port；禁止新增候选、物化或资产表。

## 验证（RED→GREEN）

- [ ] integration test：三 provenance 各一条 candidate chain，pins/selector/AssetKey 等价。
- [ ] 首次与二次物化：模型/资产计数不增，attempt/observation 增加。
- [ ] 治理页面可从资产反查 model revision、implementation、candidate、quality、lineage。

## Definition of Done

- [ ] 发布/物化 API 和 UI 无 visual/code 分支。
- [ ] provenance 只在审计/详情显示，不改变治理消费资格。
- [ ] Sprint-93 final E2E 可复用本 Sprint 样本，无重复证据链。
