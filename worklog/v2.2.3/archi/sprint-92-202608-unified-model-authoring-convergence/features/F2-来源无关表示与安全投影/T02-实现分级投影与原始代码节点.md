# T02：实现分级投影与原始代码节点

**优先级**：P0  
**状态**：IMPLEMENTED  
**依赖**：T01

## 目标

把 validated bundle 投影为 FULL/PARTIAL/NONE 和逐节点 editability；无法无损结构化的逻辑以可定位 raw node 表达，不猜测转换。

## 技术设计（Contract-first）

- **输入契约**：validated bundle、target dbtUniqueId、ModelSpec fields/dependencies、managed aliases、账本 L15/L16。
- **输出契约**：`AuthoringProjection {coverage,lossless,managedPaths,rawNodes,reasons,nodes[]}`；node 字段见 Sprint README §4.3。
- **数据流**：static validator nodes → `DbtSqlProjectionParser`/classifier adapter → 与 ModelSpec 对账 → projection summary/checksum。
- **错误路径**：ambiguous column、dynamic ref/source、macro/package、无法定位表达式 → raw node + reason；不得产生虚假字段血缘或可编辑表单。
- **复用点**：既有 parser、classifier、validator；新增 adapter 只能组合结果，不复制 SQL grammar。
- **稳定性**：相同 bundle/ModelSpec pins 必须得到相同 projection checksum 和节点顺序。

## 影响范围

既有 SQL projection/parser adapter、conversion classifier、static validator 组合层及 golden tests；不修改 dbt runtime、发布或血缘主表。

## 验证（RED→GREEN）

- [ ] golden cases：平台生成 FULL、混合 SQL PARTIAL、动态宏 NONE。
- [ ] alias、歧义非限定列、CTE、join、aggregation、窗口函数按安全预期分类。
- [ ] 重复运行结构/checksum 确定性；输出不含不必要正文。

## Definition of Done

- [ ] FULL/PARTIAL/NONE 语义稳定且能解释 reasons。
- [ ] 任一不确定节点降级 raw，不静默删除。
- [ ] parser/validator/lineage 既有测试零回归，无第二 parser。
