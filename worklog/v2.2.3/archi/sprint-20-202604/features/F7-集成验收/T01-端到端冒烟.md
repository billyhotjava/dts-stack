# T01: 端到端冒烟（Addax → Airflow → dbt → 前端）

**优先级**: P0
**状态**: READY
**依赖**: F1~F5 全部 DONE

## 目标

用一个真实业务场景跑通整条链路，验证 lineage 信号在每个环节都正确产生与消费。

## 测试场景

**场景**：把 MySQL 业务库的 `orders` 表入湖到 ODS，dbt 加工到 DWD/DWS，最终在前端 LineagePage 看到完整链路并验证列级追溯。

## 执行步骤

### Step 1: Addax 入湖（验证 F1）

1. 在 dts-platform-webapp"数据接入中心"创建 MySQL 数据源 `mysql_demo`
2. 创建采集任务 `task_orders_to_ods`，tableMapping = `mysql_demo.shop.orders → inceptor.ods.ods_orders`
3. 触发执行 → 等待 SUCCESS
4. **验收点**：
   - [ ] `ingestion_execution` 表中 `source_tables` `target_tables` `lineage_event_id` 非空（F1.T01）
   - [ ] `catalog_dataset_lineage` 出现 `relation_type=ADDAX` 边（F1.T02/T03）
   - [ ] 边的 `last_run_status=SUCCESS, last_run_at` 正确（F2.T03）
   - [ ] `lineage_job` 出现一条 `ADDAX_TASK` 记录（F4.T03）
   - [ ] OpenMetadata 上对应 Pipeline 实体可查（F2.T04）

### Step 2: dbt 加工（验证 F2/F3）

1. 触发 dbt run（通过 Airflow DAG `dbt_dwd_orders`）
2. dbt 跑两个 model：
   - `dwd_orders` SELECT FROM ods_orders（含字段映射 `gross_amount AS amount`）
   - `dws_daily_revenue` 聚合 dwd_orders
3. **验收点**：
   - [ ] OpenLineage 事件成功回到 `/api/internal/lineage/openlineage`（F2.T03）
   - [ ] `catalog_dataset_lineage` 出现 dbt 边并带 `via_job_id`（F4.T03）
   - [ ] `catalog_dataset_lineage_column` 出现列边：
     - `ods_orders.gross_amount → dwd_orders.amount`（F3.T03）
     - `dwd_orders.amount → dws_daily_revenue.total_amount`（aggregate）

### Step 3: 前端可视化（验证 F5）

1. 访问 `/catalog/lineage`，搜 `dws_daily_revenue`
2. **验收点**：
   - [ ] 看到三段式链路：MySQL → ods_orders → addax_task → dwd_orders → dbt_model → dws_daily_revenue（F4 + F5.T02）
   - [ ] 节点形状/颜色/图标按类型区分（F5.T02）
   - [ ] 自动布局（dagre），节点不重叠（F5.T01）
   - [ ] minimap 在右下角，可点击导航（F5.T04）
3. 打开"列级"toggle：
   - [ ] 节点展开列清单
   - [ ] 看到 `gross_amount → amount → total_amount` 列链路（F5.T03）
4. 点击 `dwd_orders` 节点选"上游"高亮：
   - [ ] 上游节点正常色，下游灰色
5. 导出 PNG → 文件正确生成（F5.T04）
6. 切换 direction/depth → 命中缓存秒级响应（F5.T05）

### Step 4: 时间旅行（验证 F6）

1. 等 1 天后修改 dbt model（`dwd_orders` 加一个新列）→ 重新跑 dbt
2. 在 LineagePage 选"对比模式"：
   - 时间 A：昨天
   - 时间 B：现在
3. **验收点**：
   - [ ] 新增的列边显示绿色
   - [ ] 删除/改动的列边显示红色
   - [ ] 不变的边灰色
   - [ ] 顶部统计数字与图一致
