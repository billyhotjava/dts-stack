# T02: 性能与大图压测

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标

对 lineage 链路做性能基准测试，确认 500/1000/2000 节点场景下后端 API 与前端渲染都达标。

## 压测场景

### 后端 API（dts-platform）

| 场景 | 节点数 | 边数 | 期望 P95 |
|------|--------|------|----------|
| 小图（开发库） | 100 | 200 | < 200ms |
| 中图（典型项目） | 500 | 1500 | < 800ms |
| 大图（聚合多项目） | 1000 | 4000 | < 2s |
| 极大图（不推荐） | 2000 | 10000 | < 5s（带截断 warning） |
| `includeColumns=true`（中图） | 500 nodes / 5000 列边 | | < 1.5s |
| `at=<6 个月前>`（中图） | 500 | 1500 | < 1.5s（含归档表 union） |

工具：

- gatling 或 k6 写脚本
- 测试数据：用 `LineageBackfillRunner` + 模拟脚本生成

### 前端渲染（LineagePage）

| 场景 | FPS / 首屏时间 |
|------|----------------|
| 100 节点拖动 | FPS ≥ 60 |
| 500 节点拖动 | FPS ≥ 30 |
| 1000 节点 | 首屏 < 3s，可缩放 / 可拖动（FPS ≥ 20） |
| 列级展开 50 列 / 节点 × 100 节点 | 渲染 < 2s |
| Diff 模式 500 节点 | 比单视图慢 ≤ 50% |

工具：

- Chrome DevTools Performance 面板
- Lighthouse
- Playwright + 性能脚本

### 写入性能

| 场景 | 期望 |
|------|------|
| OpenLineage 事件接收 100 EPS 持续 5 min | 无积压，平均处理 < 50ms |
| dbt manifest 同步（100 model） | < 60s（含列级解析） |
| Addax lineage 回写 | < 100ms 端到端 |

## 输出

`it/performance-report.md`：

1. 测试环境（机器配置、数据库版本、数据规模）
2. 各场景实测结果对比期望
3. 不达标项的瓶颈分析（火焰图 / SQL EXPLAIN / Chrome perf trace）
4. 改进建议（如需要 P3 sprint 跟进）
