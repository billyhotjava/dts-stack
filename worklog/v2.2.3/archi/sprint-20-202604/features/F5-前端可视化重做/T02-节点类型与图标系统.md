# T02: 节点类型与图标系统

**优先级**: P0
**状态**: READY
**依赖**: F4.T02

## 目标

按节点 kind/jobType 渲染差异化图标、颜色、形状；前端 LineagePage 一眼区分 source / dataset / view / dbt model / Airflow DAG / Addax task。

## 技术设计

### 节点类型映射

| kind / jobType | 形状 | 颜色 | 图标 (solar:) |
|---|---|---|---|
| dataset (EXTERNAL_TABLE) | 矩形圆角 | 灰色 | database-bold-duotone |
| dataset (DATASET) | 矩形圆角 | layer 颜色 | layers-bold-duotone |
| dataset (VIEW) | 平行四边形 | 蓝色 | eye-bold-duotone |
| dataset (DATA_PRODUCT) | 六边形 | 紫色 | box-bold-duotone |
| job (DBT_MODEL) | 圆角矩形 | 橙色 | code-circle-bold-duotone |
| job (AIRFLOW_DAG) | 圆角矩形 | 青色 | refresh-circle-bold-duotone |
| job (ADDAX_TASK) | 圆角矩形 | 绿色 | upload-bold-duotone |
| job (VIEW_DEFINITION) | 圆角矩形 | 蓝色 | code-square-bold-duotone |

### 自定义节点

新增 `src/pages/catalog/lineage/nodes/`：

- `DatasetNode.tsx`
- `JobNode.tsx`
- `nodeTypes.ts`（reactflow `nodeTypes` 注册）

`DatasetNode.tsx` 例：

```tsx
export function DatasetNode({ data }: NodeProps<DatasetNodeData>) {
  const Icon = ICON_BY_ASSET_TYPE[data.assetType];
  return (
    <div className={cn(BASE, byLayer(data.layer))}>
      <Handle type="target" position={Position.Left} />
      <Icon className="text-lg" />
      <div className="flex flex-col">
        <div className="text-xs text-gray-500">{data.layer ?? data.assetType}</div>
        <div className="font-medium truncate max-w-[140px]">{data.name}</div>
      </div>
      {data.lastRunStatus && <StatusDot status={data.lastRunStatus} />}
      <Handle type="source" position={Position.Right} />
    </div>
  );
}
```

### 边样式

按 `relationType` 区分：

| relationType | 颜色 | 样式 |
|---|---|---|
| DBT | 橙色 | 实线 |
| AUTO_VIEW | 蓝色 | 实线 |
| ADDAX | 绿色 | 实线 |
| AIRFLOW | 青色 | 实线 |
| MANUAL | 灰色 | 虚线 |

边可显示 label（`relationType` 缩写），可在过滤器中开关。

### Hover 提示

每个节点 hover 显示：

- FQN
- owner
- 最近一次执行状态 + 时间
- 字段数（dataset）/ project（job）

### 图例 Legend

页面右上角加一个折叠的图例面板，列出所有形状/颜色/图标的含义。
