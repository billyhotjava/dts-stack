# T05: 缓存、虚拟化、体验优化

**优先级**: P1
**状态**: READY
**依赖**: T01, T02

## 目标

把 LineagePage 的数据流接到 TanStack Query 做 HTTP 缓存；大图启用虚拟化与 depth 自动收紧；解决高度写死、多次请求等遗留问题。

## 技术设计

### 1. TanStack Query 接管

替换现有 useState/useMemo 风格的请求：

```ts
// before（现状）
const [data, setData] = useState();
useEffect(() => {
  api.getLineageImpact(params).then(setData);
}, [params]);

// after
const { data, isLoading, error } = useQuery({
  queryKey: ['lineage-impact', params],
  queryFn: () => api.getLineageImpact(params),
  staleTime: 5 * 60 * 1000,    // 5 min
  gcTime: 30 * 60 * 1000,      // 30 min
  enabled: !!params.datasetId,
});
```

收益：

- 同参数复用缓存
- 切换 direction/depth 时如果之前请求过则瞬间响应
- 自带 isLoading/error 状态

### 2. depth 自动收紧

`useEffect` 监听返回的 `nodeCount`：

```ts
useEffect(() => {
  if (data?.nodeCount > 100 && depth > 3) {
    toast.warning('节点过多，已自动收紧深度到 3');
    setDepth(3);
  }
}, [data]);
```

### 3. 高度自适应

页面布局改为 flex column，图区 `flex-1`：

```tsx
<div className="flex flex-col h-[calc(100vh-180px)]">
  <FilterBar />
  <div className="flex-1 min-h-0">    {/* min-h-0 让 flex 子元素能收缩 */}
    <ReactFlow ... />
  </div>
</div>
```

去掉 `height: 500` 写死。

### 4. 节点虚拟化（reactflow 12 内置）

reactflow 12 提供 `nodesViewportLimit`，对超出视口的节点降级渲染：

```tsx
<ReactFlow
  onlyRenderVisibleElements
  ...
/>
```

500+ 节点时 FPS 提升明显。

### 5. URL 状态同步

把过滤参数写入 URL search params，刷新/分享 URL 时还原状态：

- `?ds=<datasetId>&dir=BOTH&depth=3&col=true`
- 用 react-router `useSearchParams`

### 6. 错误兜底

API 失败时显示带重试按钮的空态，不留白屏。

### 7. 加载体验

- 首次加载用 skeleton（左侧节点占位 + 右侧 controls 占位）
- 切换参数时 fetch 期间老图保留，加 30% 透明蒙层
