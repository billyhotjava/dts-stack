# T01: 列级表设计与迁移

**优先级**: P1
**状态**: READY
**依赖**: 无

## 目标

设计 `catalog_dataset_lineage_column` 表，承载 (上游 dataset, 上游列) → (下游 dataset, 下游列) 的细粒度血缘边。

## 技术设计

### 表结构

```sql
CREATE TABLE catalog_dataset_lineage_column (
    id UUID PRIMARY KEY,
    dataset_lineage_id UUID NOT NULL REFERENCES catalog_dataset_lineage(id) ON DELETE CASCADE,
    upstream_column VARCHAR(256) NOT NULL,
    downstream_column VARCHAR(256) NOT NULL,
    transform_type VARCHAR(32) NOT NULL DEFAULT 'IDENTITY',  -- IDENTITY/ALIAS/EXPRESSION/AGGREGATE/CASE
    transform_expression TEXT,                                -- 原始 SQL 表达式片段
    relation_type VARCHAR(32) NOT NULL,                       -- DBT/AUTO_VIEW/MANUAL（对齐父表）
    confidence VARCHAR(16) NOT NULL DEFAULT 'HIGH',           -- HIGH/MEDIUM/LOW（解析置信度）
    notes TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    valid_from TIMESTAMPTZ NOT NULL DEFAULT now(),
    valid_to TIMESTAMPTZ
);

CREATE UNIQUE INDEX uq_lineage_col_edge
  ON catalog_dataset_lineage_column(dataset_lineage_id, upstream_column, downstream_column)
  WHERE valid_to IS NULL;

CREATE INDEX idx_lineage_col_downstream
  ON catalog_dataset_lineage_column(downstream_column);

CREATE INDEX idx_lineage_col_upstream
  ON catalog_dataset_lineage_column(upstream_column);
```

### 设计要点

1. **依附 dataset 边**：列边一定从属于一条 dataset 边；删除 dataset 边时级联删列边
2. **transform_type 分类**：方便前端用不同样式渲染（实线=IDENTITY，虚线=EXPRESSION）
3. **valid_from/valid_to**：与 F6 时间旅行同形式，本 Task 先建字段不启用 SCD2 逻辑
4. **confidence**：解析器对模糊表达式（如 `*`、UDF 调用）打 LOW 置信度，前端可过滤
