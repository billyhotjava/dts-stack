# Workbench UI Control Matrix

## 首页顶部操作

| 控件 | 类型 | 行为 | 状态要求 | 验收 |
|------|------|------|----------|------|
| 自定义工作台 | 主按钮 | 打开右侧自定义抽屉 | loading 时禁用；无权限时隐藏或禁用并给原因 | 点击后抽屉打开，URL 可保留 `customize=1` |
| 恢复默认 | 次按钮 | 恢复角色默认模板 | 二次确认；请求中禁用 | 成功后首页按默认模板刷新 |
| 刷新 | 图标按钮 | 重新拉取偏好和组件数据 | 请求中展示加载态 | 不改变用户已保存配置 |

## 自定义抽屉操作

| 控件 | 类型 | 行为 | 状态要求 | 验收 |
|------|------|------|----------|------|
| 关闭 | 图标按钮 | 关闭抽屉 | 有未保存变更时二次确认 | 不保存临时变更 |
| 组件 checkbox | checkbox | 控制组件是否显示 | 不可用组件 disabled 并展示原因 | 勾选变化只影响草稿，保存后生效 |
| 上移 | 图标/文本按钮 | 当前组件与上一项交换顺序 | 第一项禁用；请求中禁用 | 保存后顺序持久化 |
| 下移 | 图标/文本按钮 | 当前组件与下一项交换顺序 | 最后一项禁用；请求中禁用 | 保存后顺序持久化 |
| 保存 | 主按钮 | 提交 `items` 到服务端 | 无变更时禁用；提交中 loading | 成功后首页立即按新配置渲染 |
| 取消 | 次按钮 | 放弃草稿并关闭抽屉 | 提交中禁用 | 首页不发生变化 |
| 恢复默认 | 危险/次按钮 | 调用 reset 接口 | 二次确认；提交中禁用 | 成功后草稿和首页回到角色模板 |

## 首页组件

| key | 组件 | 类型 | 真实来源 | 空态要求 |
|-----|------|------|----------|----------|
| `leader-kpi` | 概览指标 | 指标摘要 | 现有领导概览接口/组件 | 无数据时显示“暂无可展示指标” |
| `top-reports` | 常用大屏 | 入口列表 | 现有 `TopReportsBlock` | 无常用大屏时引导去大屏管理 |
| `core-assets` | 核心资产 | 入口列表 | 现有 `CoreAssetsBlock` | 无资产时引导去资产目录 |
| `screen-strip` | 已发布大屏 | 横向列表 | 现有 `ScreenStrip` | 无发布大屏时显示空态 |
| `todo` | 待办事项 | 摘要/入口 | `/workbench/todo` 或待办摘要接口 | 无待办时显示“暂无待办” |
| `data-sources` | 数据源接入 | 入口卡片 | `/foundation/data-sources` | 未接入时引导配置数据源 |
| `golden-chain` | 数据交付链路 | 链路摘要 | `/api/golden-chains` | 无链路时显示创建入口 |
| `governance-blockers` | 治理阻断 | 问题摘要 | 治理质量/发布门禁摘要 | 无阻断时显示健康空态 |
| `bi-delivery` | BI 与大屏成果 | 入口/摘要 | BI 看板/大屏页面 | 无成果时显示创建入口 |
| `api-services` | 数据 API 服务 | 入口/摘要 | `/services/apis` | 无服务时显示发布入口 |
| `ops-health` | 运行健康 | 状态摘要 | `/ops/overview` | 无权限或接口不可用时显示原因 |

## 禁止项

- 不出现客户业务 demo 场景卡片。
- 不显示编造统计值。
- 不使用拖拽手柄、自由栅格尺寸、组件自定义开发入口。
