# T01: 偏好表与领域模型

**优先级**: P0  
**状态**: DONE  
**依赖**: 无

## 目标

新增 `workbench_user_preference` 持久化结构，保存每个登录用户的工作台配置。

## 技术设计

新增 Liquibase 变更集和领域对象：

- 表字段：`id`, `username`, `version`, `layout_json`, `created_at`, `updated_at`。
- `username` 唯一。
- `layout_json` 保存组件 key、visible、order。
- 后端领域对象只接受当前登录用户，不暴露跨用户写入入口。

## 影响范围

- `source/dts-platform/src/main/resources/config/liquibase/**`
- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/domain/**`
- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/repository/**`
