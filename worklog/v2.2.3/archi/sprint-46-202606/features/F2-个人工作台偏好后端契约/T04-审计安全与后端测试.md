# T04: 审计安全与后端测试

**优先级**: P0  
**状态**: DONE  
**依赖**: T02/T03

## 目标

偏好保存和恢复默认具备审计记录，并补齐安全回归测试。

## 技术设计

审计事件：

- `WORKBENCH_PREFERENCE_SAVE`
- `WORKBENCH_PREFERENCE_RESET`
- 未知组件 key 拒绝时记录 warn 或安全审计。

测试覆盖：

- 用户 A 不能通过请求体写用户 B。
- 未知组件 key 被拒绝。
- 无权限组件不能保存为 visible。
- reset 后回到默认模板。
