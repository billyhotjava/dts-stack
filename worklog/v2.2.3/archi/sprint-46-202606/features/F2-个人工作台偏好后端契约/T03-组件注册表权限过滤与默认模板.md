# T03: 组件注册表权限过滤与默认模板

**优先级**: P0  
**状态**: DONE  
**依赖**: T02

## 目标

后端返回当前用户可选择的组件目录，并按角色提供默认模板。

## 技术设计

后端组件注册表定义：

- `key`
- `title`
- `description`
- `requiredRoutes`
- `defaultVisibleRoles`
- `disabledReason`

权限过滤规则：

- 无菜单/接口权限的组件不返回，或返回 disabled 且说明原因。
- 保存时未知 key 拒绝。
- 保存时无权限 key 不能 `visible=true`。
- 默认模板按角色生成，如普通用户、部门负责人、所领导、数据管理员、运维人员。
