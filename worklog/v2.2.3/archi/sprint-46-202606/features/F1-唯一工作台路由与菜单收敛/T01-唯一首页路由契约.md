# T01: 唯一首页路由契约

**优先级**: P0  
**状态**: DONE  
**依赖**: 无

## 目标

用 TDD 固化 `/workbench` 是唯一工作台首页，避免后续再出现多个并列首页。

## 技术设计

新增或更新 source-contract，断言：

- `/workbench` 指向工作台容器。
- `/workbench/data-management` 不再渲染独立首页。
- `/services/consumption` 不再渲染独立首页。
- 默认登录后 fallback 仍回 `/workbench`。
