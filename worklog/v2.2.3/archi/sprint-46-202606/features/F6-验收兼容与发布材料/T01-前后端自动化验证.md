# T01: 前后端自动化验证

**优先级**: P0  
**状态**: DONE  
**依赖**: F1-F5

## 目标

按 TDD 收口前端契约、前端构建和后端偏好 API 测试。

## 验证清单

- 前端 source-contract: 路由、菜单、组件注册表、按钮目标、防 demo。
- 前端单测: 抽屉 checkbox、上移/下移、保存、恢复默认、错误态。
- 前端构建: `pnpm build`。
- 后端单测: 偏好 API GET/PUT/reset、未知 key、权限过滤、当前用户绑定。
- 文档检查: task 状态、README 统计、IT 验收项一致。

## 命令

```bash
cd source/dts-platform-webapp
node --test --experimental-strip-types src/pages/workbench/*.source-contract.test.ts
pnpm build

cd ../dts-platform
npm run backend:unit:test
```
