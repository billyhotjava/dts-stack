# T03: 唯一工作台容器按配置渲染

**优先级**: P0  
**状态**: DONE  
**依赖**: T01/T02

## 目标

将 `/workbench` 渲染为唯一可配置容器，按后端返回的 `items` 顺序展示组件。

## 技术设计

容器职责：

- 读取偏好配置。
- 用 `availableComponents` 过滤不可见组件。
- 按 `items.order` 排序。
- 只渲染 `visible=true` 的组件。
- 支持 `section` query 定位到指定组件。
- 支持 `customize=1` 自动打开自定义抽屉。

首页状态：

- 加载态：保留标题和操作栏，内容区域展示骨架。
- 错误态：展示错误说明和“刷新”按钮。
- 全部取消：展示空态和“自定义工作台”“恢复默认”按钮。
- 单组件失败：组件内错误态，不拖垮整个首页。
