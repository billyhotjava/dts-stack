# T01: 数据源与黄金链路组件

**优先级**: P0  
**状态**: DONE  
**依赖**: F3

## 目标

把数据源接入和数据交付链路迁移成工作台可选组件，指向真实页面和接口。

## 技术设计

组件：

- `data-sources`: 展示数据源接入入口、已配置/待配置状态、主按钮“配置数据源”。
- `golden-chain`: 展示数据交付链路入口、链路状态、主按钮“查看链路”。

按钮：

- 配置数据源: 跳转 `/foundation/data-sources`。
- 查看链路: 跳转黄金链路页面或定位现有链路视图。
- 重新加载: 组件级错误时重新拉取。

数据规则：

- 有真实摘要接口则展示摘要。
- 没有稳定摘要接口时仅展示入口型卡片和空态。
- 不允许静态模拟条数。
