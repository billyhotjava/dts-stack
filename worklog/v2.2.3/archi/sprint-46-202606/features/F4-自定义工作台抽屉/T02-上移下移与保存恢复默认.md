# T02: 上移下移与保存恢复默认

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

用按钮完成显示顺序调整，并提供保存、取消、恢复默认的完整闭环。

## 技术设计

按钮清单：

- 上移: 第一项禁用，点击后与上一项交换。
- 下移: 最后一项禁用，点击后与下一项交换。
- 保存: 有变更时启用，提交 `items` 到服务端。
- 取消: 放弃草稿并关闭抽屉。
- 恢复默认: 二次确认后调用 reset 接口。
- 关闭: 无变更直接关闭，有变更时提示确认。

保存 payload：

- 只提交 `key`、`visible`、`order`。
- `order` 使用 10、20、30 这类稳定间隔值或保存前统一重排。
- 不提交 username。
