# T01：定义物理资产纳管矩阵

**优先级**：P0
**状态**：DONE
**依赖**：F1/T01、F1/T02

## 目标

让外部源表、ODS、持久化 STG、DWD/DWS/ADS、资产目录兼容 DIM 值和异常关系都有唯一、可审计的资产处理规则。

## 输入/输出契约

- 输入：账本 L05～L09/L14/L18～L20、当前 83 个数据集画像、现有 SOURCE/ODS/dbt 写入链、F1/T02 关系契约。
- 输出：资产纳管矩阵；ProducerRef/RegistrationEvidence/layer/正交状态轴字段候选；ModelSpec 语义资产与 physical locator 物理资产映射；兼容读写与回填规则；资产台账展示规则。完整候选见 [`assets/f2-f3-data-contract-pack.md`](../../assets/f2-f3-data-contract-pack.md)。
- 数据流：来源发现或候选物化观测 → 统一资产身份解析 → 幂等登记/刷新 → 归域/分层投影 → 治理和消费状态。
- 错误路径：无稳定 physical locator、临时对象、身份冲突、证据过期分别给出失败关闭行为。
- 复用点：CatalogAssetType/CatalogAssetKey、CatalogDataset、现有血缘与资产同步链。
