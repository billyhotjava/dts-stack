# T01：形成兼容迁移与实施拆分

**优先级**：P0
**状态**：DONE
**依赖**：F1/T01、F1/T02、F2/T01、F3/T01、F4/T01

## 目标

产出下一实施 Sprint 的可执行切片，使字段、API、页面和数据迁移能分阶段上线与回滚。

## 输入/输出契约

- 输入：全部已冻结 ADR、F1/T02 关系/E2E 契约、客户数据画像、最新影响分析、旧路由/字段消费清单。
- 输出：实施 Sprint README/Feature/Task；API/DTO/schema 兼容边界；迁移脚本策略；回滚与观测窗口；测试/E2E 矩阵。评审稿见 [`assets/implementation-roadmap.md`](../../assets/implementation-roadmap.md) 与 [`Sprint-87`](../../../sprint-87-202608-data-architecture-implementation/README.md)。
- 实施顺序候选：先 canonical read contract → 扩展字段 → 双写/回填 → consumer 切换 → UI/菜单收敛 → 观测 → 旧契约收缩。
- 错误路径：无法回填、旧消费者仍活跃、权限/审计缺失、真实登录基线失败时，相应切片保持 BLOCKED。
