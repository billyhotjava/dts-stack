# F4: 数据开发中心边界重构

**优先级**: P1
**状态**: DONE
**目标**: 将数据开发中心收敛为专业数据工程师使用的 ELT/dbt/SQL/调度工作台，避免和语义指标中心抢业务指标配置入口。

## 职责边界

数据开发中心负责:

- SQL/dbt 模型开发
- ODS -> DWD -> DWS -> ADS 工程加工
- 脚本开发
- 任务编排
- 调度运行
- 模型测试和发布
- 模型级血缘查看

数据开发中心不负责:

- 业务人员指标配置主入口
- 指标市场
- 业务口径审批
- BI 图表设计

## 任务

| Task | 状态 | 内容 |
|------|------|------|
| T01 | DONE | 盘点数据开发中心菜单和页面中指标/业务配置相关入口 |
| T02 | DONE | 将指标配置入口迁移到语义与指标中心 |
| T03 | DONE | 为 dbt/SQL 模型详情提供模型上下文血缘入口 |
| T04 | DONE | 明确 DWS/ADS 在数据开发中心是工程模型，在语义指标中心是业务消费数据集 |
| T05 | DONE | 开发中心页面文案固定“面向数据工程师” |

## 验收标准

- 数据开发中心不出现业务人员指标配置入口。
- SQL/dbt/调度能力仍完整可用。
- 数据工程师可以查看模型上下文血缘，但不进入全局血缘导入工作台。
