# F5: 数据治理中心边界重构

**优先级**: P1
**状态**: DONE
**目标**: 将数据治理中心收敛为标准、质量、安全、责任治理，不再承载独立指标中心。

## 职责边界

数据治理中心负责:

- 主题域
- 业务术语
- 数据元
- 公共码表
- 标准模板
- 质量规则
- 质量报告
- 分级分类
- 资产权属
- 权限审计

数据治理中心不负责:

- 指标定义主入口
- 指标可视化配置
- DWS/ADS 数据集设计
- dbt 模型开发

## 任务

| Task | 状态 | 内容 |
|------|------|------|
| T01 | DONE | 清理治理中心首页和菜单中的指标中心入口 |
| T02 | DONE | 保留治理主题域作为语义指标中心优先引用源 |
| T03 | DONE | 在语义指标主题域映射页说明“引用优先、非强制绑定” |
| T04 | DONE | 治理变更页展示影响范围，但不进入完整血缘工作台 |
| T05 | DONE | 检查指标字典旧标题和面包屑，统一到语义与指标中心 |

## 验收标准

- 数据治理中心页面不再出现“指标中心”主入口。
- 指标字典归属于语义与指标中心。
- 治理主题域仍能被语义指标中心引用。
