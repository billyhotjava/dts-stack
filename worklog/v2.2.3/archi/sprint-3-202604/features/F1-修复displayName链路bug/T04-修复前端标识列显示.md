# T04: 修复前端 ScreenAclPanel 标识列显示

**优先级**: P1
**状态**: DONE
**依赖**: 无

## 目标
大屏权限管理面板中，已有权限的"标识"列：用户显示姓名（displayName），角色显示中文名（description）。

## 技术设计

已完成。修改 `ScreenAclPanel.tsx` 的 `resolveGrantLabel()` 函数：

1. **用户**: 只显示 `displayName`，fallback 到 `username`（原来显示 `username / displayName`）
2. **角色**: 新增 `roleDisplayMap`，显示 `description`（如"研究所数据管理员"），fallback 到 `name`

## 影响范围

| 文件 | 改动 |
|------|------|
| `dts-platform-webapp/.../ScreenAclPanel.tsx` | 行 130-149: resolveGrantLabel + roleDisplayMap |
