# T02: 治理状态环形图与主题域条形图

**优先级**: P0
**状态**: READY
**依赖**: T01（消费其 `overviewCount` / `overviewPercent` 与补齐后的 `AssetOverview.byDomain` 类型）

## 目标

在 KPI 行下方并排渲染两个常规图表：治理状态环形图（中心显示已治理率，扇区可下钻）与主题域 Top6 堆叠横向条形图（条可下钻），两者均在空数据时以文案替代空图。

## 技术设计 (Contract-first)

### 输入契约

```ts
// AssetGovernanceDonut
interface AssetGovernanceDonutProps {
  counts?: Record<string, number>;   // overview.governanceStatusCounts，key 为大写状态码
  total: number;                     // overview.total，用于计算已治理率分母
  truncated?: boolean;
  loading?: boolean;
  onSliceClick: (status: string) => void;   // 传原始状态码，URL 拼装由页面负责
}

// AssetDomainBars
interface AssetDomainBarsProps {
  byDomain?: Record<string, { total: number; attention: number }>;  // 账本 #7：不含未归域
  domainNames: Map<string, string>;   // 由页面 domainMap 传入，与左侧导航同源
  unassigned?: { total: number; attention: number };  // 来自 domainStats.unassigned
  truncated?: boolean;
  loading?: boolean;
  onBarClick: (domainKey: string) => void;   // 域 uuid 或 UNASSIGNED_DOMAIN_KEY
}
```

### 输出契约

| testid | 内容 |
|--------|------|
| `asset-governance-donut` | 图表卡容器 |
| `asset-governance-donut-summary` | sr-only 数据摘要文本 |
| `asset-domain-bars` | 图表卡容器 |
| `asset-domain-bars-summary` | sr-only 数据摘要文本 |

`onSliceClick` 回传值域 = `counts` 的 key 原值（如 `PENDING_GOVERNANCE`）。
`onBarClick` 回传值域 = 域 uuid | `"__UNASSIGNED__"`。

### 数据流

**环形图**：`overview.governanceStatusCounts` → 按值倒序 → `resolveEnumLabel(GOVERNANCE_STATUS_DICT, status)` 取中文标签 → ECharts `pie` (`radius: ['58%','80%']`)。中心文字 = 已治理率 = `overviewPercent(counts.GOVERNED, total)`。

**条形图**：`overview.byDomain` 各项 + `unassigned`（键为 `__UNASSIGNED__`）→ 合并数组 → 按 `total` 倒序取前 6 → `domainNames.get(id)` 取名 → ECharts 横向 `bar`，两个 series 堆叠：`正常 = total - attention`、`待处置 = attention`。

`domainNames` 必须由页面从既有 `domainMap`（`AssetOverviewPage.tsx:133-143`）传入，与左侧导航同源；**禁止**在组件内另发请求取域名。

### 错误路径

| 情形 | 行为 |
|------|------|
| `counts` 为空 / 全 0 | 不渲染 `Chart`；显示「当前范围内暂无资产」+「切到全部资产」文字链 |
| `byDomain` 为空且 `unassigned.total = 0` | 同上 |
| `counts` 出现 `GOVERNANCE_STATUS_DICT` 未覆盖的 key（Sprint README 开放问题 1） | `resolveEnumLabel` 回落英文原值时，归入「其他」聚合项并累加计数；「其他」扇区**不可点**（无法确定单一 governance 参数），Tooltip 说明「含未识别状态 N 项」 |
| 单一域范围（左侧选中某域） | 条形图退化为 1 条，仍正常渲染，不显示「Top 6」后缀 |
| `truncated` | 图表标题右侧加 `*` 与 Tooltip「基于前 {scanned} 条可见资产」；数字沿用 `overviewCount` |
| ECharts 在 Chrome 95 渲染异常 | 降级：环形改 CSS `conic-gradient`，条形改 div 宽度百分比（见 F2 README §可访问性/兼容） |

### 复用点（禁止另造）

- `Chart` from `@/components/chart`（账本 #14）—— **不直接 import `echarts-for-react`**
- `resolveEnumLabel` / `GOVERNANCE_STATUS_DICT`（`assets/assetEnumLabels.ts`）
- `overviewCount` / `overviewPercent`（T01 新增）
- `UNASSIGNED_DOMAIN_KEY`

### 实现方案

1. 新建 `src/pages/catalog/assets/AssetGovernanceDonut.tsx`（≤ 120 行）
   - `useMemo` 构造 `EChartsOption`；`legend` 置右侧竖排，`label.show = false`（扇区上不打字，避免小扇区文字重叠）
   - 中心文字用 `graphic` 或 `title` 居中：大号百分比 + 小号「已治理」
   - `onEvents={{ click: (p) => onSliceClick(p.data.status) }}`，「其他」项的 `status` 为 `null` 时忽略点击
   - 卡底部输出 `<span className="sr-only" data-testid="asset-governance-donut-summary">`
2. 新建 `src/pages/catalog/assets/AssetDomainBars.tsx`（≤ 120 行）
   - `yAxis.type: 'category'`，`inverse: true`（大值在上）
   - 两 series `stack: 'total'`，颜色：正常 `#3b82f6`，待处置 `#f59e0b`
   - `grid.left` 用 `containLabel: true` 自适应长域名；域名超长在 `axisLabel.formatter` 截断至 8 字加省略号，完整名进 tooltip
   - 「未归域」条的 `axisLabel` 前缀 `⚠`
3. 两组件统一卡片外框：`rounded-xl border border-slate-200 bg-white p-4`，标题 `text-sm font-semibold text-slate-900`，`Chart height={260}`

## UI 交互规格

见 F2 README §UI/UX 规格（线框、四态、交互表、走查 6 步）。补充：

- 环形图 tooltip：`{状态中文名}：{数量}（{占比}%）`
- 条形图 tooltip：`{域名}\n总计 {total} · 待处置 {attention}`
- 图表卡右上角**不放**任何按钮（页面 chrome 只允许 1 主 CTA + 1 刷新 icon，见 ADR-88-05）
- legend 项与扇区同样可点，均触发 `onSliceClick`
