## 技术设计

### 实测 SQL（画像）

```sql
-- 边规模与有效性
select count(*) total,
       count(*) filter (where valid_to is null) current_edges
  from catalog_dataset_lineage;

-- 关系类型与核验状态分布（开放问题 Q3）
select relation_type, verification_status, count(*)
  from catalog_dataset_lineage
 where valid_to is null
 group by 1,2 order by 3 desc;

-- 字段血缘规模与"已失效仍会被查出"的实际影响面（验证账本#7）
select count(*) total,
       count(*) filter (where valid_to is not null) expired,
       count(*) filter (where confidence = 'INFERRED') inferred
  from catalog_column_lineage;

-- 最大扇出（决定 depth=5 最坏遍历规模）
select dataset_id, sum(c) fanout from (
  select upstream_dataset_id dataset_id, count(*) c from catalog_dataset_lineage where valid_to is null group by 1
  union all
  select downstream_dataset_id, count(*) from catalog_dataset_lineage where valid_to is null group by 1
) t group by 1 order by 2 desc limit 10;

-- 数据集总数（验证下拉 300 条上限是否已被击穿，账本#15）
select count(*) from catalog_dataset;

-- OpenLineage 是否有真实流入（开放问题 Q2）
select count(*), max(last_observed_at)
  from catalog_lineage_job where engine = 'AIRFLOW' or relation_type = 'AIRFLOW';
```

### 性能基线采集

对样本链路的下游数据集，分别以 `depth=3` 与 `depth=5`、`direction=BOTH`、`withJobs=true&withColumns=true` 调 `GET /api/catalog/lineage/impact`，各 10 次取 P95，记录同时产生的 SQL 条数（开 `spring.jpa.show-sql` 或用 DB 侧统计）。
