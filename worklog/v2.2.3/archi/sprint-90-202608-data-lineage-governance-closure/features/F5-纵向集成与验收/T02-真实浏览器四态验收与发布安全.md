### 发布安全（Gate G3 → `assets/release-plan.md`）

需产出并落盘：

| 项 | 内容 |
|---|---|
| 迁移策略 | `20260811_01_catalog_lineage_verification_actor.xml` 为 Expand-only（仅 addColumn），可先于代码发布 |
| 发布顺序 | 迁移 → 后端 → 前端（后端响应体为增量扩展，旧前端兼容） |
| 兼容性 | `DELETE /catalog/lineage/{id}` 返回体由 `Boolean` 改为对象——前端此前零消费（账本#6），无外部调用方；需确认无第三方集成 |

| 菜单变更 | `title` 改动通过 seed 重载生效；`key`/`externalLink` 未变，角色授权无需调整 |
