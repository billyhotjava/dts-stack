# T03: 数据集选择器服务端搜索分页

**优先级**: P1
**状态**: DRAFT（需先确认后端 `listDatasets` 是否已支持 keyword 搜索）
**依赖**: T01（选项加载已收敛到 `useLineageDatasetOptions`）

## 目标

血缘四页的数据集下拉不再受 300 条硬编码上限（账本#15）限制，在任意规模的目录下都能搜到并选中目标数据集。

## 技术设计 (Contract-first)

### 缺陷定位

`pages/catalog/lineageShared.tsx:75-81`：

```ts
const resp = await listDatasets({ page: 0, size: 300, enabledOnly: true });
```

`showSearch` 是 antd 的**前端过滤**，只能在这 300 条里搜。目录超过 300 条时，第 301 个数据集在血缘模块中永远不可达——整个模块对该数据集不可用。

> 现网 `catalog_dataset` 总数未知（开放问题 Q1）。若实测 < 300，本 Task 降级为 P2；但**不撤销**——上限存在即是定时炸弹。

### 前置确认（DRAFT 转 READY 的条件）

确认 `GET /api/catalog/datasets`（前端 `listDatasets`）是否支持 `keyword`/`q` 模糊搜索参数：

- **支持** → 纯前端改造，本 Task 保持 P1，无后端改动。
- **不支持** → 追加后端子任务：在既有 dataset 查询上补 `keyword` 条件（对 `name` / `hive_database` / `hive_table` 做 ILIKE），复用既有分页与鉴权，不新建接口。

结论须追加到 Sprint 账本作为新条目。

### 输入/输出契约

`useLineageDatasetOptions` 扩展为：

```ts
export function useLineageDatasetOptions(): {
  options: Array<{ label: string; value: string }>;
  loading: boolean;
  onSearch: (keyword: string) => void;   // 防抖 300ms
  reload: () => void;
};
```

- 首屏拉 `size=50`（NFR 预算：下拉首屏 ≤ 50）。
- `onSearch` 触发服务端查询，`queryKey` 含 keyword，`staleTime` 60s。
- **回显兜底**：URL 深链带 `datasetId` 但该数据集不在当前选项列表中时，单独按 id 拉一次并注入选项，避免下拉回显成裸 UUID。这是本 Task 的必做项——与数据搜索页主题域选择器的既有兜底同一模式（同类问题已在资产门户出现过，不重复踩）。

### 错误路径

| 场景 | 行为 |
|---|---|
| 搜索请求失败 | 下拉显示 `notFoundContent="数据集加载失败"` + 保留上次结果 |
| 深链 `datasetId` 不存在/无权限 | 选项显示 id 并标注「不可访问」，页面其余部分正常渲染空结果 |
| 空关键词 | 回到首屏 50 条，不发空查询风暴（防抖 + 相同 key 命中缓存） |

### 复用点

- `listDatasets` 既有 API，不新建接口。
- 防抖用项目既有 `useDebounce` 模式（`rules/typescript/patterns.md` 约定），不引依赖。

## UI 交互规格

| 项 | 规格 |
|---|---|
| 控件 | 四页共用的数据集 `Select`（`lineageShared.tsx:128` LineageDataFilters 内） |
| 交互 | `showSearch` + `filterOption={false}`（关闭前端过滤）+ `onSearch` 防抖 300ms |
| 加载态 | `loading` 属性 + `notFoundContent={<Spin size="small"/>}` |
| 空态 | 无匹配 → 「未找到匹配的数据集」 |
| 错误态 | 「数据集加载失败」+ 保留上次选项 |
| 成功态 | 选中后触发血缘查询 |

## 验证 (RED→GREEN)

- [ ] `search_hitsServer`：输入关键词 → 触发带 keyword 的请求（非前端过滤）
- [ ] `search_isDebounced`：连续输入 5 个字符 → 只发 1 次请求
- [ ] `firstPage_capsAt50`：首屏请求 `size === 50`
- [ ] `deepLink_backfillsMissingOption`：URL 带不在首屏 50 条中的 `datasetId` → 选项被补齐、回显为名称而非 UUID
- [ ] `deepLink_inaccessibleDataset_degradesGracefully`：不可访问 id → 标注「不可访问」，页面不崩

### UI 走查（需 >300 条数据集的环境，或造数）

1. 打开影响分析 → 下拉默认 50 条
2. 输入第 301 个数据集的名称片段 → 搜到并可选中
3. 选中后血缘正常渲染
4. 复制链接（含 `datasetId`）新开标签 → 下拉回显为**名称**
