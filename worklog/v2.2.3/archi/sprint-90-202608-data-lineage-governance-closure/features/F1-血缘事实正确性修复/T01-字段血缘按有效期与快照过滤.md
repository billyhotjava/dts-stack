# T01: 字段血缘按有效期与快照过滤

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

`GET /api/catalog/lineage/impact` 返回的 `columnLineages` 只包含在请求 `at`（缺省为 now）时刻有效的字段血缘，与同一响应里的表级边使用同一时刻语义。

## 技术设计 (Contract-first)

### 缺陷定位

账本#7：`CatalogLineageResource.java:504` 调用 `columnLineageRepo.findByDatasetLineageIdIn(edgeIds)`（`CatalogColumnLineageRepository.java:13`），该方法**只按 `dataset_lineage_id` 过滤**，没有任何有效期或快照条件。后果：

1. 已被 `DbtAssetSyncService.java:486` 置 `valid_to` 的过期字段关系仍会返回；
2. 用户传 `at=` 做时间旅行时，表级边走 `findByEitherSideAt`（正确），字段级走无过滤查询（错误）——同一页两套时间语义。

### 输入契约

- `edgeIds: Collection<UUID>` —— 已按 `snapshotAt` 过滤后的表级边 ID 集合（不变）
- `at: Instant` —— 复用 `impact` 方法中已计算出的 `snapshotAt`（`CatalogLineageResource.java` 内 `resolveSnapshotAt(at)` 的结果）

### 输出契约

`List<CatalogColumnLineage>`，满足 `(valid_from is null or valid_from <= :at) and (valid_to is null or valid_to > :at)`。

### 实现方案

1. 在 `CatalogColumnLineageRepository` 新增（**保留**原方法，避免影响 `CatalogClassificationPropagationService` 等既有调用方）：

```java
@Query("""
    select c from CatalogColumnLineage c
    where c.datasetLineageId in :datasetLineageIds
      and (c.validFrom is null or c.validFrom <= :at)
      and (c.validTo is null or c.validTo > :at)
    """)
List<CatalogColumnLineage> findByDatasetLineageIdInAt(
    @Param("datasetLineageIds") Collection<UUID> datasetLineageIds,
    @Param("at") Instant at
);
```

> 列名 `valid_from` / `valid_to` 已确认（账本#24），实体字段为 `validFrom` / `validTo`，与表级 `findByEitherSideAt`（账本#8）严格同构。

2. `loadColumnLineageDtos` 增加 `Instant at` 形参，改调新方法；`impact` 调用处传入已有的 `snapshotAt`。
3. 响应体增加 `columnLineageSnapshotAt`（= `snapshotAt.toString()`），使前端可自证两级时间一致。

### 错误路径

- `edgeIds` 为空 → 直接返回 `List.of()`（既有行为，保留）。
- `at` 为空不可能发生（`resolveSnapshotAt` 保证非空）；若未来放开，按 `Instant.now()` 兜底。

### 复用点

- 查询写法照抄 `CatalogDatasetLineageRepository.findByEitherSideAt`（账本#8），不另造时间语义。
- 不改 `CatalogColumnLineage` 实体、不加迁移。

### 不做

- 不改 `CatalogClassificationPropagationService` 现有的 `findByDatasetLineageIdIn` 调用（分类传播关注当前态，语义正确）。

## UI 交互规格

无新增控件。用户可见影响：字段血缘页行数在存在过期关系时会减少；F3/T02 的运营台需在文案中说明"仅展示当前有效字段血缘"。
