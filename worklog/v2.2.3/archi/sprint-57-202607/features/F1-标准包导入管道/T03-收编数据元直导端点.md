# T03: 收编数据元直导端点

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标

`POST /api/modeling/metadata-standards/import` 改为委托 StandardPackageImportService 的数据元校验/写入逻辑，消除两套校验漂移；响应结构保持兼容。

## 技术设计

- `MetadataStandardImportService.importCsv` 内部改为：构造单文件包上下文 → 复用 T01 抽取的行校验 → 直接 apply（保持原"一步入库"行为，不强制 preview，兼容既有前端调用）
- `MetadataStandardImportResultDto` 字段不变（imported/updated/errors）
- 同时为该路径也落 run 记录（source=LEGACY_SINGLE），使旧路径导入也可在 runs 历史中看到并回滚

## 影响范围

`MetadataStandardImportService`、`MetadataStandardResource` 不改签名；ElementsPage 现有导入调用零改动。

## 验证

- [ ] 既有单测/契约测试全绿（响应字段兼容）
- [ ] 旧端点导入后在 `GET /standard-packages/runs` 可见且可回滚

## 完成标准

- [ ] 数据元校验逻辑单一来源（grep 确认 ALLOWED_TYPES 等只存在一处）
