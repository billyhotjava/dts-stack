# T03: 三页面交互范式统一巡检

**优先级**: P2
**状态**: DONE
**依赖**: T01, T02

## 目标

数据元/术语/码表三页面按统一清单巡检修偏，形成基础数据模块一致体验。

## 技术设计

巡检清单（逐页核对）：
- 分页：CompactTable、默认 10 条/页、切 size 回第 1 页（memory: pagination-unification-convention）
- 空态：EmptyState 组件 + 引导动作（下载模板/新建）
- 加载/错误态：Spin + 错误提示不裸吞（coding-style 错误处理）
- 权限：useGovernanceManageAccess 语义一致（只读用户按钮隐藏 vs 置灰统一取一种）
- 搜索/筛选：关键字 + 状态筛选位置与交互一致
- 详情：统一 Drawer（宽度/字段布局/引用区块）

产出：`assets/foundation-pages-audit.md` 巡检记录 + 修偏 diff。

## 影响范围

ElementsPage / GlossaryPage / ReferenceCodesPage 小改。
