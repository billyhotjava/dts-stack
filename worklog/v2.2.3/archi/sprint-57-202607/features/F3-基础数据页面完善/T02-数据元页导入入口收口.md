# T02: 数据元页导入入口收口

**优先级**: P1
**状态**: DONE
**依赖**: F1-T04

## 目标

ElementsPage 的导入入口指向标准包向导，模板下载保留原位；旧单 CSV 导入 UI 移除（后端端点保留兼容）。

## 技术设计

- "导入"按钮 → navigate 到 `/foundation/standard-package`（携带 `?from=elements` 便于返回）
- 保留"下载标准包模板"按钮及 `governance-elements-template-download` 标识（source-contract 锁定，不得移除）
- 若页面存在旧的单文件上传 Modal，删除该 UI 与关联 state

## 实施记录

- 数据元页新增 `导入标准包` 入口，跳转 `/foundation/standard-package?from=elements`。
- 标准包页在 `from=elements` 场景显示 `返回数据元`，回到 `/governance/standards/elements`。
- 页面未引入旧单 CSV 上传 UI，后端兼容端点不改。

## 影响范围

ElementsPage.tsx、StandardPackagePage.tsx；不改后端。
