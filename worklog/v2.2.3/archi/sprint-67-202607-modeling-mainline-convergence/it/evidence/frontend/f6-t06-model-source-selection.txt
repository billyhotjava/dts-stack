Current boundary
- A connection alone is not a selectable model source. The concrete table/node must be metadata-synced, resolvable and confirmed in the current plan.
- An empty plan source inventory is repaired from the current model form. A completed confirmation reloads the current plan's selectable sources and then closes the embedded manager.
- Catalog assets remain in the embedded manager while still CANDIDATE; the user must confirm or exclude them. A source mutation cannot be interrupted by closing or destroying the Modal.
- Parent source refresh returns authoritative inventory or null. Refresh failure and stale retry responses cannot close or overwrite a newer manager session.
- ETL/ELT execution is not a prerequisite for model design. Implementation, quality and publication evidence remain later independent gates.
- A confirmed source version is never silently upgraded. The user must explicitly adopt the current version before a new ModelSpec revision can be saved.
- T06 remains IN_PROGRESS until real deployed Chrome 95/API/PostgreSQL evidence is attached.
