# T03: DTS 前端导出入口与状态展示

**优先级**: P1  
**状态**: READY  
**依赖**: T02

## 目标

在 DTS 平台提供训练快照导出入口，方便用户从 UI 触发并复制输出路径给 metro-stack。

## 技术设计

首版不做复杂任务中心，优先在数据开发/dbt 模型页面或地铁 App-Pack 菜单下增加动作：

- 选择模型：默认 `metro_dwd_lstm_training_snapshot`
- 选择格式：固定 `CSV`
- 输入快照 ID：默认按时间生成
- 触发导出
- 展示输出目录、行数、字段数、质量状态

## 影响范围

- `source/dts-platform-webapp`
- 后续可接入统一运行审计。

## 验证

- [ ] 前端构建通过。
- [ ] API 错误能在页面展示，不表现为登出。

## 完成标准

- [ ] 操作员能从 DTS UI 生成快照包并看到输出目录。
