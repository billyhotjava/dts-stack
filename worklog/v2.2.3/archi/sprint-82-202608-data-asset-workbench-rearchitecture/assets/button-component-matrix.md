# 按钮与组件收敛矩阵

## 1. 台账行操作

| 当前动作 | 重构后位置 | 处理 |
|---|---|---|
| 申请权限 | 治理工作台 → 权限申请 | 从行移除 |
| 详情 | 治理工作台 → 完整资产档案 | 从行移除 |
| 治理 | 治理资产 | 重命名为唯一主入口 |
| 更多 | 不保留 | 删除容器 |
| 分级分类 | 治理工作台推荐任务/完整档案 | 迁移 |
| 密级与生命周期 | 治理工作台上下文动作 | 迁移 |
| 查看血缘 | 治理工作台上下文动作 | 迁移 |
| 创建报表 | 真实能力存在时由完整档案进入 | 不在行平铺 |
| 生成数据产品 | 真实能力存在时由完整档案进入 | 不在行平铺 |
| 发布数据 API | 真实能力存在时由完整档案进入 | 不在行平铺 |

## 2. 新增/复用组件

| 组件 | 类型 | 职责 |
|---|---|---|
| AssetGovernanceWorkbenchDrawer | 新增 | 当前任务、推荐动作、概要事实、标签、上下文入口 |
| GovernedAssetTagPanel | 复用 | 单资产标签能力校验、绑定与解绑 |
| AssetTagsWorkspace | 新增轻包装 | 标签字典、查看关联资产、关联资产路由 |
| TagManagementTab | 扩展 | 增加查看资产和关联资产动作 |
| AssetLedgerView | 收敛 | 行只保留治理资产；支持标签批量关联模式 |
| DatasetDetailPage | 复用 | 完整资产档案，不复制 |

## 3. 推荐动作规则

| 条件 | 当前任务 | 主按钮目标 |
|---|---|---|
| 缺少主题域/责任人 | 补齐治理责任 | 完整档案-治理责任 |
| 缺少分类分级/密级事实 | 完成分类分级 | 完整档案-密级事实 |
| 标签缺失但不阻断 | 完善业务标签 | 工作台-数据标签 |
| 存在质量告警 | 查看质量证据 | 完整档案-质量与 SLA |
| 已 READY | 申请/核验访问或查看完整档案 | 完整档案对应页签 |
| 身份或映射不完整 | 修复资产映射 | 完整档案概览，禁止写入 |

## 4. 交互约束

- 每个状态只突出一个主按钮，其余入口使用次按钮或链接。
- 禁止“点击后再弹出同一组菜单”的伪收敛。
- 抽屉关闭后保留台账筛选和分页。
- 批量关联模式明确显示目标标签和已选数量，可随时取消。
- 所有按钮必须对应真实处理函数、路由或禁用原因。
