# F1：地图与台账职责收敛

**状态**：DONE  
**优先级**：P0

## 目标

冻结资产地图与资产台账的信息架构：地图只做概要聚合和下钻，台账成为具体资产检索、详情和治理的唯一入口。

## Tasks

| Task | 名称 | 状态 |
|---|---|---|
| T01 | 冻结页面职责与源契约 | DONE |
| T02 | 资产地图概要化与筛选下钻 | DONE |
| T03 | 资产台账导航与上下文保持 | DONE |
| T04 | 旧标签入口兼容迁移 | DONE |

## Feature 验收

- 地图没有标签字典和治理写操作。
- 地图聚合项可以携带筛选条件进入台账。
- 台账具有资产列表与数据标签两个明确工作区。
- 旧标签 URL 自动迁移且不形成重复页面。
