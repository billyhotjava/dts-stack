# T02：解析当前任务与推荐下一步

**状态**：DONE  
**依赖**：F2-T01

## 目标

把治理状态翻译为用户可执行的当前任务，并只突出一个推荐下一步。

## 实现

- 复用现有 resolveAssetReadiness 和治理原因。
- 按缺主题域、责任人、分类事实、质量告警、READY 等条件生成任务。
- 主按钮跳转真实存在的档案页签或工作台标签区。
- FALLBACK/身份不完整时禁止治理写入。

## 验收

- “治理阻断：缺少主题域”直接给出补齐治理责任的动作。
- READY 不显示阻断式文案。
- 每种状态只有一个主按钮，其他能力降为次级入口。
