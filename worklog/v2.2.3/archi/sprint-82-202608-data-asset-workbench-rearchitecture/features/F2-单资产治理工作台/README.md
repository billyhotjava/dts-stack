# F2：单资产治理工作台

**状态**：DONE  
**优先级**：P0

## 目标

将台账行 7～8 个分散动作收敛为一个“治理资产”入口，用当前治理任务和推荐下一步驱动用户完成治理，同时保持完整资产档案可达。

## Tasks

| Task | 名称 | 状态 |
|---|---|---|
| T01 | 建立治理工作台壳层 | DONE |
| T02 | 解析当前任务与推荐下一步 | DONE |
| T03 | 收敛台账行操作 | DONE |
| T04 | 重接完整档案与上下文能力 | DONE |
| T05 | 身份失败与可访问性交互 | DONE |

## Feature 验收

- 每行只有一个“治理资产”主按钮。
- 工作台显示身份、治理状态、阻断原因、当前任务和推荐下一步。
- 标签、密级与生命周期、血缘、权限和完整档案均可从工作台到达。
- 缺少资产身份或权限时失败关闭并提供可理解原因。
