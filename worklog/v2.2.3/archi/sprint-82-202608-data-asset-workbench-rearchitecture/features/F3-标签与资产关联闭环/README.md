# F3：标签与资产关联闭环

**状态**：DONE  
**优先级**：P0

## 目标

在资产台账内完成“维护标签 → 查看关联资产 → 选择资产 → 绑定/解绑 → 回查”的完整旅程，标签与分类分级、密级保持严格分离。

## Tasks

| Task | 名称 | 状态 |
|---|---|---|
| T01 | 迁移数据标签工作区 | DONE |
| T02 | 标签关联资产回查 | DONE |
| T03 | 台账批量关联模式 | DONE |
| T04 | 工作台单资产标签治理 | DONE |
| T05 | 权限性能与审计契约 | DONE |

## Feature 验收

- 标签分类和标签字典在台账维护。
- 标签行能查看关联资产并进入已过滤台账。
- 可从标签发起关联，选择当前页资产后批量绑定。
- 工作台可对当前资产绑定/解绑标签并立即回查。
- 标签操作复用现有能力校验、可见性过滤和审计。
