# T03: 画布与右侧详情业务化

**优先级**: P1  
**状态**: DONE  
**依赖**: T02

## 目标

让画布选中对象/指标后的右侧信息具备业务判断价值，并给出清晰下一步动作。

## 技术设计

- 业务对象详情展示主表、主键、挂载指标数。
- 指标详情展示公式类型、单位、状态、关联模型和发布入口。
- 运行记录入口指向任务运维中心。
