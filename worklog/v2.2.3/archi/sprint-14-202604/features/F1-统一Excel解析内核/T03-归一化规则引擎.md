# T03: 归一化规则引擎

**优先级**: P0
**状态**: READY
**依赖**: T01, T02

## 目标

把 Excel 导入里散落的格式修补逻辑收敛为一个显式规则层，至少统一处理：

- 非标准负数：`{900}`、`(900)`、`（88）`、全角/Unicode 负号
- 松散日期：`2026/1/2`、`2026年1月2日`、`2026-1-3 4:5:6`
- 公式值：display value / cached value / raw formula 的取值策略
- 全角字符、空白、千分位

## 完成标准

- [ ] 平台侧与 ingestion 都能复用同一套规则
- [ ] 规则可通过 fixtures 回归
- [ ] 新增 Excel 兼容问题优先通过此层扩展，而不是散落在 service 中
