# T03：将发布结果绑定真实输出资产与失败恢复

**优先级**：P0
**状态**：IN_PROGRESS（current PUBLISHED output ref、build-only/PARTIAL/rollback 隔离与资产深链 GREEN；统一上线/运行健康 DTO、external sync 与 Chrome95 待关闭）
**依赖**：F4/T03

## 目标

让模型详情“发布结果”只展示 current PUBLISHED 输出资产，并清晰区分 build-only、PARTIAL、PUBLISHED+DEPLOYING、online READY、运行 DEGRADED、ROLLED_BACK 和 relation missing；上线后追加计划 DAG 与最近计算的只读摘要。

## 技术设计（Contract-first）

- **数据源**：lifecycle timeline + registration steps + output physicalAssetRef + CatalogDataset；不根据输入 sourceBinding 或 artifact path 猜测。
- **空态**：
  - 未构建：返回数据实现；
  - BUILT 未发布：前往交付工作台完成治理；
  - PARTIAL：显示 mandatory local 失败项和重试入口，不展示任何可消费 entry；
  - ROLLED_BACK：显示当前无有效发布及历史记录。
- **成功卡**：database/schema/identifier、relation type、字段数、materialization、publishedAt、observedAt、run/invocation、资产台账/血缘深链。
- **运行摘要**：plan/environment、triggerPolicy、DAG deployment、最近成功/失败、下次运行；详细配置和触发动作深链到交付工作台。
- **健康退化**：PUBLISHED 后 inspector 健康检查发现缺失，显示“关系已失效”，不得仍标绿色成功。
- **上线投影**：只有 PUBLISHED + binding ACTIVE + relation healthy 显示“上线完成”；external sync DEGRADED、binding DEPLOYING/FAILED 和 relation missing 分别显示，不回推 Candidate 状态。
- **权限**：只读用户只能查看；写动作仍由交付工作台权限控制。
- **兼容**：无 physicalAssetRef 的历史 artifact 保持可读但不展示为物理资产。

## 已实现证据（2026-07-28）

- `ModelSpecPhysicalAssetStage` 只在当前 revision/checksum/implementation 对应的最后一个
  publication event 为 `RELEASE/PUBLISHED` 时读取 artifact `physicalAssetRef`；后续
  ROLLBACK、PARTIAL/PENDING 或 build-only 均不生成资产卡。
- 已发布资产使用后端输出 UUID 深链 `/catalog/datasets/:id`；页面不读取 source binding、
  artifact path、schema/table 猜测资产。
- 输出资产与 DDL/构建产物已拆分展示：build-only 可查看制品和 checksum，但不会看到
  资产台账入口；PARTIAL 明确“发布未完成、本地登记已回滚”，不再误报“发布已完成”。
- source-contract 2/2 GREEN，`pnpm exec tsc --noEmit` GREEN；未重复运行 Chrome95。
