# T02: 实例监控告警补数页面接入

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

将后端 ops 数据以客户可理解方式展示出来，支持筛选、查看详情和补数申请。

## 技术设计

- 新增 `GoldenChainOpsWorkCenterService`，把实例、告警和补数按 `chainKey/taskId` 关联为运维视图。
- 实例监控展示 task、artifact、externalRunId、status、duration、logPath。
- 告警记录展示质量失败、任务失败、发布失败和权限失败。
- 补数管理支持创建 backfill request，并关联链路实例。
