# T04: 客户场景验收包与演示数据

**优先级**: P1
**状态**: DONE
**依赖**: T01,T02,T03

## 目标

提供一个传统行业结构化数据客户可理解的验收包，证明平台从接入到报表/服务消费闭环可用。

## 技术设计

- 准备最小业务样例：客户/项目/订单/质量/进度等结构化表。
- 覆盖 JDBC/API/file 至少一种主路径，优先复用已有客户或 demo 数据。
- 输出验收脚本、截图清单、业务指标说明和失败恢复流程。
- 指标和报表解释使用业务语言，不出现 SQL。
- 新增 `GoldenChainCustomerScenarioPackageService`，校验客户验收步骤、证据引用、业务指标、报表发布、数据服务和消费权限都已就绪。
- 输出客户验收包 `assets/customer-demo-acceptance-package.md`。
