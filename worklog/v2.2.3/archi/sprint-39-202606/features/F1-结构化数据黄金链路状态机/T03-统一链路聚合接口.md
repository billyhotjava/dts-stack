# T03: 统一链路聚合接口

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

提供平台侧统一接口，返回黄金链路实例列表、详情、阶段状态、失败原因和可执行动作。

## 技术设计

- 新增或扩展 platform 聚合资源，例如 `/api/golden-chains`。
- 后端聚合 ingestion、catalog、modeling、metrics、services、ops 的状态摘要。
- 返回业务可读状态，不让前端理解每个子系统内部状态。
- 对敏感资产和无权限资产 fail-closed，不泄露资产名称或字段密级。

## 落地内容

- 新增 `GoldenChainQueryService`：按 enabled 链路聚合实例、阶段快照、阶段标签、失败原因和下一步动作。
- 新增 `GoldenChainSummaryResponse` / `GoldenChainDetailResponse` / `GoldenChainStageResponse`。
- 新增 `GoldenChainResource`：
  - `GET /api/golden-chains` 返回链路工作台列表。
  - `GET /api/golden-chains/{chainKey}` 返回链路详情和阶段快照。
- 未找到或不可见链路统一返回 404，避免泄露隐藏资产信息；真实资产权限硬门禁留给 F3 接入。
