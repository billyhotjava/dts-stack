# T01: 数据源入湖任务归一化

**优先级**: P0
**状态**: DONE
**依赖**: F1-T01

## 目标

统一 JDBC/API/file 入湖任务的产品状态、执行证据和 ODS 输出描述。

## 技术设计

- 梳理 `IngestionTaskResource`、`IngestionTaskProxyResource`、Sprint-38 API Java 执行器和文件/JDBC 路径差异。
- 统一任务类型、源表/资源、目标 ODS 表、checkpoint、执行证据字段。
- API/file 不能退回 env 明文或临时手工导入路径。

## 落地内容

- 新增 `GoldenChainIngestionTaskNormalizer`：支持从平台/ingestion 常见 task map 中识别 JDBC/API/file。
- 新增 `GoldenChainIngestionTaskView`：统一输出 taskRef、sourceRef、ODS 输出表、checkpoint、INGESTION 阶段快照。
- 失败执行统一映射为 `BLOCKED_INGESTION`，并保留业务可读阻断原因。
- 输出不包含 `destinationConfig` / `sourceConfig` 全量配置，避免泄露 password、secretRef 解析结果或临时路径。

## 影响范围

- `source/dts-ingestion`
- `source/dts-platform`
- `source/dts-platform-webapp`
