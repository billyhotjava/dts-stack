# T01: 资产身份统一与重复资产收口

**优先级**: P0
**状态**: DONE
**依赖**: F1-T02

## 目标

明确同一数据集、dbt 模型、BI 数据集、指标、API 服务、数据产品的资产身份规则，减少 OpenMetadata、本地 Catalog 和代码化资产重复。

## 技术设计

- 新增 `GoldenChainAssetIdentityResolver`，固化资产身份优先级：平台资产 ID > OpenMetadata FQN > code asset key > legacy fallback。
- 同一平台资产 ID 在资产门户和服务侧解析为同一个 `platform:{id}`。
- 无法解析资产身份或解析到多个 key 时进入 `PENDING_GOVERNANCE` 诊断，不默认合并。
