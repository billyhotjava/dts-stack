# Customer Demo Evidence

本目录用于存放 `assets/customer-demo-acceptance-package.md` 中列出的客户验收证据。

建议文件：

| 文件 | 证据内容 |
|------|----------|
| `01-source-ready.md` | 数据源接入中心截图或接口输出 |
| `02-ingestion-ready.md` | 入湖任务运行和目标数据就绪证据 |
| `03-governance-gate.md` | owner、分级、质量、血缘门禁证据 |
| `04-report-consumption.md` | 报表数据集和指标入口截图 |
| `05-api-service.md` | 数据服务订阅、授权、调用统计输出 |
| `06-ops-impact.md` | 运维概览、实例、告警、补数和影响范围证据 |

现场采证原则：

- 证据可以是截图、接口输出或脚本输出摘要。
- 客户可读材料只展示业务指标、维度、口径、权限状态和服务状态。
- 原始敏感凭据、token 明文和内部实现细节不得写入本目录。
