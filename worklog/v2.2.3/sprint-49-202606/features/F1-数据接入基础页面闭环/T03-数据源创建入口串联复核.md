# T03: 数据源创建入口串联复核

**优先级**: P0
**状态**: DONE
**依赖**: T01, T02

## 目标

让连接器目录的“创建数据源”不只跳到列表页，而是把连接器上下文带到数据源创建弹窗，形成从连接器目录到数据源登记的真实闭环。

## 技术设计

- 连接器目录通过 `/foundation/data-sources?create=1&connectorKey={key}` 传递创建意图和连接器 Key。
- 数据源页使用 `useSearchParams` 消费一次 `create=1`，打开新增数据源弹窗后清理 query。
- `DataSourceFormModal` 接收 `initialConnectorKey`，在新增态预选连接器并应用连接器默认源类型。
- 不新增菜单或页面，不改数据源保存接口。
