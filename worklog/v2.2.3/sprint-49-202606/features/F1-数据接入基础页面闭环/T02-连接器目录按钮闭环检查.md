# T02: 连接器目录按钮闭环检查

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

让连接器目录中的客户可见按钮具备明确行为：能跳转的按钮进入已有页面，不能执行的动作给出明确禁用原因，配置和模板不再共用无差别详情抽屉。

## 技术设计

- 不新增菜单或页面，复用 `/foundation/connectors` 和 `/foundation/data-sources`。
- 为连接器详情抽屉增加 `detail / config / template` 三种模式。
- “配置”打开配置要求，“查看模板”打开配置模板，抽屉底部提供“创建数据源”交接动作。
- “启用、停用”继续禁用，但通过 Tooltip 说明后端动作未开放，避免形成假按钮。
