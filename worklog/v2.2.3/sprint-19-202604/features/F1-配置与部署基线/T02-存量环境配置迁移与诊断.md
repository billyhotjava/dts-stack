# T02: 存量环境配置迁移与诊断

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

让已经生成坏 `.env` 的环境能被发现、修复，并留下升级说明。

## 范围

- 检测 `.env` 中 `DTS_PLATFORM_OPENMETADATA_TABLE_FQN_PATTERN={service` 或空值。
- 给出安全修复建议，避免覆盖用户自定义合法 pattern。
- 在发布说明中加入手动修复命令。
- 如已有初始化校验脚本，优先复用现有入口。

## 完成标准

- [ ] 坏 pattern 能被明确诊断。
- [ ] 合法自定义 pattern 不被误改。
- [ ] 升级文档包含修复前后示例。
- [ ] 现场验收能确认 platform 使用修复后的 pattern。
