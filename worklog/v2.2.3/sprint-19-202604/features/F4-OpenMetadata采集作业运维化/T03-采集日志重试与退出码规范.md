# T03: 采集日志、重试与退出码规范

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

让 OpenMetadata 采集作业的成功、失败、跳过和重试状态能被运维人员准确判断。

## 范围

- 定义脚本退出码或状态文本。
- 增加 OpenMetadata API 可达性预检查。
- 对短暂网络失败增加有限重试。
- 日志输出采集目标、配置文件、耗时和结果摘要。

## 完成标准

- [ ] 日志中能直接看到本次采集是否实际运行。
- [ ] OpenMetadata 不可达时不进入后续无效步骤。
- [ ] 重试次数和间隔可配置。
- [ ] 敏感配置脱敏。
