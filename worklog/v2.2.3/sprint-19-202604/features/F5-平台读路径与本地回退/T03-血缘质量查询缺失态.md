# T03: 血缘/质量查询缺失态

**优先级**: P1
**状态**: DONE
**依赖**: T01, T02

## 目标

让血缘和质量页面在 OpenMetadata 未命中或失败时呈现真实状态，而不是空白或误导性成功。

## 范围

- 梳理 lineage、quality、table detail 的 OpenMetadata 查询路径。
- 为未配置、未命中、失败、回退定义统一状态。
- 后端返回足够前端展示的信息。
- 避免将远端错误暴露为内部异常堆栈。

## 完成标准

- [x] OpenMetadata 未命中时页面能说明未采集或 FQN 未匹配。
- [x] 远端失败时页面能提示稍后重试或联系运维。
- [x] 本地 catalog 有数据时仍能展示基础信息。
- [x] 状态逻辑有单测或前端构建验证。

## 实现记录

- 血缘查询未命中时返回 `metadataSource` 与 `fallbackReason`，不再只有空 graph。
- 质量查询未命中时返回 `metadataSource` 与 `fallbackReason`，前端质量页展示当前数据来源和原因。
- 当前本地 catalog 可回退基础元数据详情；OpenMetadata 血缘/质量本身没有本地等价快照时显示缺失态。
- `pnpm build` 已验证相关前端类型和构建链路。
