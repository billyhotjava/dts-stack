# T03: 血缘/质量查询缺失态

**优先级**: P1  
**状态**: READY  
**依赖**: T01, T02

## 目标

让血缘和质量页面在 OpenMetadata 未命中或失败时呈现真实状态，而不是空白或误导性成功。

## 范围

- 梳理 lineage、quality、table detail 的 OpenMetadata 查询路径。
- 为未配置、未命中、失败、回退定义统一状态。
- 后端返回足够前端展示的信息。
- 避免将远端错误暴露为内部异常堆栈。

## 完成标准

- [ ] OpenMetadata 未命中时页面能说明未采集或 FQN 未匹配。
- [ ] 远端失败时页面能提示稍后重试或联系运维。
- [ ] 本地 catalog 有数据时仍能展示基础信息。
- [ ] 状态逻辑有单测或前端构建验证。
