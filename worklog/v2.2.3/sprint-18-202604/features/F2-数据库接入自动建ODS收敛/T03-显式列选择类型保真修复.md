# T03: 显式列选择类型保真修复

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

修复显式选择列时全部落成文本类型的问题，避免 ODS 类型承载过度退化。

## 范围

- 显式列选择时仍通过 JDBC metadata 获取真实字段类型。
- 只在源端无法发现 metadata 时降级为文本。
- 在降级时写入 precheck warning。

## 完成标准

- [ ] 选择部分列时 ODS 仍保留数字、日期、时间等基本类型。
- [ ] metadata 缺失时有可见警告。
- [ ] 单测覆盖显式列和 `*` 两种路径。
