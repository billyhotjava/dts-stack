# T01: TargetTableProvisioner 契约改造

**优先级**: P0  
**状态**: READY  
**依赖**: F1/T02

## 目标

让自动建表逻辑遵守 ODS 契约，统一创建源字段和 DTS 技术字段。

## 范围

- 建表字段来源优先改为 schema snapshot；缺失时才回退到 JDBC metadata。
- 生成 ODS DDL 时保留源字段顺序，使用 snapshot 中的 nullable/default/comment 元数据作为后续扩展输入。
- 追加 `_dts_*` 技术字段。
- 检测源字段与 `_dts_*` 重名并阻断。
- 保留必要目标库类型承载，不引入业务转换。

## 完成标准

- [ ] ODS 表包含源字段和技术字段。
- [ ] 源字段顺序稳定，技术字段追加在尾部。
- [ ] 建表逻辑不再自行做字段规范化判断，规范化规则只进入 stg。
- [ ] 字段冲突时任务创建或执行失败并给出明确错误。
