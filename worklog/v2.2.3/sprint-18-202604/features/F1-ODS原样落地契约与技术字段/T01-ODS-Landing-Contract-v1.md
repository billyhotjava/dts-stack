# T01: ODS Landing Contract v1

**优先级**: P0  
**状态**: READY  
**依赖**: 无

## 目标

定义 ODS 第一阶段稳定契约，避免“接入层”和“建模层”继续混在一起。

## 范围

- 明确 ODS 只做源数据原样落地。
- 明确源业务字段不得做清洗、翻译、派生和口径计算。
- 明确技术字段可追加，但不得覆盖源字段。
- 明确 stg 才是字段标准化、类型修正和业务规则入口。

## 完成标准

- [ ] 输出 ODS/stg 职责边界文档。
- [ ] 文档给出数据库、Excel、CSV 三类样例。
- [ ] 文档说明“100%复制”指源字段业务值不计算，不等于目标库 DDL 与源库逐字符一致。
