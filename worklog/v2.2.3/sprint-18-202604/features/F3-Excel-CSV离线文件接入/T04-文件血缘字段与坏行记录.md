# T04: 文件血缘字段与坏行记录

**优先级**: P0  
**状态**: READY  
**依赖**: T02, T03

## 目标

保证文件导入后的每一行 ODS 数据都能追溯到文件、sheet、行号和执行批次。

## 范围

- 写入 `_dts_source_file`、`_dts_source_sheet`、`_dts_file_hash`、`_dts_row_number`。
- 记录坏行文件和错误原因。
- 在 execution 详情展示文件统计、成功行、失败行。
- 支持坏行下载和重导入口。

## 完成标准

- [ ] 任意 ODS 文件行可回查原始文件和行号。
- [ ] 坏行不进入正式 ODS。
- [ ] execution 页面或 API 能返回坏行摘要。
