# T01: 文件接入契约与元数据模型

**优先级**: P0  
**状态**: READY  
**依赖**: F1

## 目标

定义 Excel/CSV 作为离线文件数据源的接入契约。

## 范围

- 定义 file source metadata：文件名、大小、hash、上传人、sheet、编码、分隔符。
- 定义 file schema snapshot：原始列名、安全列名、类型推断、样例值。
- 定义 file ODS mapping：目标 schema/table、字段映射、技术字段。
- 接入统一 `IngestionTask` 和 `IngestionExecution`。

## 完成标准

- [ ] 文件接入不绕过接入任务中心。
- [ ] 同一文件可通过 hash 去重或提示重复导入。
- [ ] 契约覆盖 Excel 多 sheet 和 CSV 单表。
