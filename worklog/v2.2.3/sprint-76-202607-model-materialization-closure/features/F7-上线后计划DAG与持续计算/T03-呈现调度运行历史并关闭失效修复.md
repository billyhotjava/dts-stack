# T03：呈现 Airflow 实际调度与运行历史并关闭失效修复

**优先级**：P0
**状态**：IN_PROGRESS（实现完成，等待 Chrome95/真实 Airflow 对账）
**依赖**：T02、F5/T02

## 目标

让计划维护者看到 Airflow 的实际 schedule、pause、最近/下次运行和平台业务结果，并在失败时进入唯一 owner 修复；不向普通建模用户暴露 DAG 技术必填项。

## 技术设计（Contract-first）

- **交付工作台**：显示 desired/effective schedule、`MANUAL_ONLY|CRON_ENABLED`、IANA timezone、Airflow paused、deployed checksum、最近/下次 DagRun、最近业务运行、耗时、失败 owner。
- **数据来源**：desired 配置来自 binding；actual schedule/nextRun/paused 来自 Airflow API；业务结果来自 pipeline run/observation。三者分栏显示，不相互伪造。
- **模型详情**：只读显示所属计划、上线状态、数据更新方式、最近成功/失败、下次运行和新鲜度；深链到工作台。
- **主动作**：ACTIVE 显示“立即运行”；DEPLOYING 显示等待；FAILED/STALE/UNKNOWN 显示唯一修复动作；DISABLED 只允许有权限用户启用。
- **四态**：未发布、已发布/部署中、上线完成、已发布/运行异常；运行子态另显示 queued/running/succeeded/failed/skipped。
- **错误映射**：release/scope drift、DAG parse/missing/paused、Airflow unavailable、CRON invalid、target/secret unavailable、run timeout、relation missing 均使用稳定中文错误码和 owner。
- **权限**：只读用户不能改 schedule、启停或触发；PROD schedule/enable/disable 只属于 RELEASE_OPERATOR。服务端 allowedActions 与 command authorization 共用 F4 domain duty resolver；Sprint-36/F3 policy 不可用、缺失、过期或本地接入未完成时显示生产权限 blocker，而不是可点击后失败。
- **安全**：DTO 不返回 credential、projectDir、selector、完整 DagRun conf 或临时 runtime token。
- **兼容**：Chrome95、窄屏、键盘；仅页面可见时轮询；Airflow unavailable 不用本地估算 nextRun。

## 影响范围

## 当前实现

- `PlanExecutionHealthService` 分别读取 binding desired/effective、Airflow actual、dispatch/pipeline run 和本次运行的全 scope relation aggregation，不互相伪造。
- 服务端依据 duty + plan access 计算 `RUN_NOW|REPAIR_DEPLOYMENT`；repair 使用 binding ETag/CAS，浏览器角色字段不参与授权。
- 计划交付页“上线计算”仅在页面可见且存在部署/运行中状态时轮询；展示下次运行只取 Airflow API，未知时显示 UNKNOWN。
- 页面/API 不返回 credential、runtime token、projectDir、selector 或完整 DagRun conf。
- 尚缺 Chrome95 真实点击“立即运行”并与同一 OPERATIONAL_RUN/DagRun/物理关系对账的验收证据。
