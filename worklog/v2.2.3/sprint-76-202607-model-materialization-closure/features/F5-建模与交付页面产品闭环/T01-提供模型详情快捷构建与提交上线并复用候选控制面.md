# T01：提供模型详情快捷构建、提交上线并复用候选控制面

**优先级**：P0
**状态**：DRAFT
**依赖**：F1/T01、F2/T01、F4/T01

## 目标

把模型详情中的实现验证、真实构建和上线治理彻底分开；IMPLEMENTATION_READY 后允许用户直接点击“构建”，BUILT 后点击“提交上线”，但底层只调用统一 Build/Publish Intent 并复用唯一 ReleaseCandidate，同时保留交付工作台人工审核/发布深链。

## 技术设计（Contract-first）

- **入口**：`/modeling/models/:id?activeStage=implementation`。
- **验证动作**：调用 implementation validate；用户明确选择 compile 时只生成 artifact，成功文案“构建制品已生成，尚未建表”。
- **构建动作**：调用 `POST .../build-intents`，body 只传 plan/environment，headers 带 If-Match/Idempotency-Key；不传 dagId/selector/target/profile/revision/checksum。响应 candidate/run 状态直接在本页呈现。
- **提交上线动作**：BUILT 时调用 Publish Intent，headers 带 candidate ETag/Idempotency-Key，body 只含 candidateId/reason；返回质量检查或等待审核状态，禁止本页自动 approve/publish。
- **稳定语义**：Publish Intent 不根据当前 allowedAction 任意推进；QUALITY_PASSED 自动提交审核后停止，REVIEW_PENDING/APPROVED/PUBLISHING 只显示 current projection。
- **高级页面**：有 ModelSpec 上下文时复用同一 Build/Publish Intent；无上下文时只允许技术构建，“提交上线”引导先导入/绑定 canonical ModelSpec。
- **深链**：`/modeling/plans/:planId/implementation?candidateId=:candidateId&modelSpecId=:id`；只用于查看批量 scope/证据/治理，不在 URL 携带 checksum 真值。
- **批量冲突**：`MODEL_ACTIVE_BATCH_CANDIDATE_CONFLICT` 显示“已在批量交付中”，只给“查看候选”动作，不提供“强制构建/自动移出”。
- **已发布**：相同 revision 已 PUBLISHED 时隐藏“构建”，显示“立即运行”，进入 OPERATIONAL_RUN。
- **禁用规则**：非 IMPLEMENTATION_READY、validation blockers、ARCHIVED、drift、无 plan context、executionTargetKey 非当前可用 target 或 active candidate 冲突时禁用并给唯一修复动作。
- **上线展示**：review pending=“等待审核”；approved=“等待发布操作”；published+deploying/failed=“已发布，运行计划部署中/异常”；onlineReadiness READY=“上线完成”。
- **四态**：lifecycle loading、validation error、ready、building/probing、build failed、BUILT、quality running/failed、review pending、approved、publishing、published/deploying、online ready、stale。
- **兼容**：不新增菜单/路由；Chrome95。

## 验证（RED→GREEN）

- [ ] 现有按钮只跳 SQL 的 RED contract。
- [ ] 验证实现不会产生 run/asset。
- [ ] 单击构建得到 canonical candidate/run，刷新后恢复同一状态。
- [ ] 普通/高级两页响应中的 candidate/run/allowedActions 完全一致。
- [ ] blocker/stale/archived/active scope conflict 不可构建。
- [ ] BATCH 冲突不可绕过，且工作台 deep link 指向正确 candidate。
- [ ] 已发布 current revision 不重复生成发布候选。
- [ ] build success 后不再发生页面自动 review/approve/publish。
- [ ] 点击一次“提交上线”只启动 quality 并在通过后提交审核；没有 reviewer/operator 越权动作。
- [ ] PUBLISHED 未 ACTIVE 不显示“上线完成”。

## Definition of Done

- [ ] 用户能读懂“制品”和“关系”的区别。
- [ ] 模型详情/高级页面没有第二个 START_BUILD 状态机。
- [ ] 单模型用户可在当前页面完成构建与显式提交上线，并读懂后续人工任务。
- [ ] UI 四态证据齐全。
