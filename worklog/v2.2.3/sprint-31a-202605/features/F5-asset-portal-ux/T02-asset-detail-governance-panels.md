# T02: 资产详情治理信息增强

**优先级**: P1
**状态**: DONE
**依赖**: F2, F3

## 目标

在资产详情页集中展示治理字段、来源证明、schema、血缘、质量和发布状态。

## 技术设计

- 新增或增强治理扩展、技术详情、来源证明、血缘影响面板。
- 缺字段显示修复入口或申请治理提示。
- 不把 OpenMetadata fallback 当作最终事实源暴露。
- 接入资产合同和 schema 合同，展示资产键、授权标识、字段来源、缺失治理字段。

## 影响范围

- DatasetDetailPage
- CatalogAssetPortalService

## 验证

- [x] 资产详情能解释数据从哪里来、谁负责、是否可信。
- [x] fallback 有清晰提示。

## 完成标准

- [x] 指标建模人员能基于详情判断是否可引用。
