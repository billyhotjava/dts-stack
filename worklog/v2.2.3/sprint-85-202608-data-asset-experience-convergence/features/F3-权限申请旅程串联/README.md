# F3：权限申请旅程串联

**优先级**：P0
**状态**：DESIGN_APPROVED / IMPLEMENTATION_PENDING

## 目标

把散在四个路由的权限能力串成一条旅程：资产任意入口 → 申请 → 审批 → 我的授权/审计，全部可达且深链参数真实消费。

## 契约

| UI | 行为 |
|---|---|
| 台账行级"申请权限" | 每行操作列新增"申请权限"→ `/security/dataset-access-approval?action=new&assetId={id}&assetType=dataset` |
| 资产概览"申请权限"入口 | → `?action=new`（承接 F0/T04） |
| 详情"权限申请"Tab | 保持，但新建申请跳转改为深链参数（替换 `buildAssetGrantUrl` 的旧跳转） |
| 审批页 | 统一标题"数据资产 · 权限申请与审批"；`?action=new&assetId=` 打开新建申请并预填资产；我的授权/权限审计作为页内侧边/快捷入口 |
| 申请成功路径 | 提交后进入"我的申请"并高亮新记录；审批通过后可跳"我的授权" |

## 完成标准

- 从台账/概览/详情任一入口都能发起申请且资产被预填。
- 申请→审批→我的授权→审计 全链路可导航。
- 深链参数未命中时页面给出显式提示，不静默。
