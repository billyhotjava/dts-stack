**状态**：DONE

## 目标

证明标签闭环没有绕过可见性、写权限、审计和批量性能边界。

## 实现

- 验证 list/search/capability/tag/untag/batch 契约。
- 验证关联资产查询经过可见性过滤。
- 验证台账标签水合使用批量接口而非逐行请求。
- 仅在现有 API 无法满足时新增后端 Task，并先做 GitNexus 影响分析。

## 验收

- 无新增 N+1。
- 无权限写入失败关闭。
- 现有后端审计仍覆盖标签写操作。
- 若未修改后端，交付记录明确说明复用的 canonical API。
