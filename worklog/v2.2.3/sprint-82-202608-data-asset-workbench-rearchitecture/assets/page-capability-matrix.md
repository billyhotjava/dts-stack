## 页面边界断言

1. 资产地图不得导入或渲染 TagManagementTab。
2. 数据标签页只存在于资产台账。
3. 台账资产行只存在一个治理主操作。
4. 治理工作台必须显示当前任务、阻断原因、推荐下一步和完整档案入口。
5. 完整资产档案继续承载详细事实，不复制到地图。
