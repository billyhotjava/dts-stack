# T02: ETL 任务资源隔离方案设计

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标
设计 ETL 任务的资源隔离和优先级调度方案，防止大任务耗尽系统资源。

## 技术设计

### 现状
- Addax 通过 DockerOperator 启动容器，无 CPU/Memory 限制
- 一个大型 ETL 任务可能耗尽主机资源，影响所有服务
- 无任务优先级机制，批量导入和交互式查询同等对待

### 设计要点
1. **Docker 资源限制**: DockerOperator 配置 `mem_limit` / `cpu_quota`
2. **任务分级**: 按数据量/紧急度定义任务优先级
3. **队列模型**: Airflow pool + queue 实现资源分组
4. **并发控制**: 最大并发任务数限制（全局 / 每队列）
5. **超时策略**: 任务级别的执行超时和 SLA
6. **资源监控**: 任务执行期间的资源使用追踪

## 影响范围
- Airflow DAG 模板: 资源限制参数
- `dts-ingestion`: 任务创建时携带资源需求
- DockerOperator 调用: 增加 resource 参数
