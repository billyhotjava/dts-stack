# 看板编排 UI 规格

## 视觉方向

主题是“治理分析编排台”：沿用 DTS 的冷灰页面、白色卡片和品牌蓝，只把 12 列工程网格作为识别性元素。选中组件使用品牌蓝描边和浅蓝标题条；不引入新字体、渐变或装饰动画。

```text
┌ 返回列表  看板名称   [未保存/已保存]  [预览] [校验] [发布] [保存草稿] ┐
├─────────────────────────────────────────────────────────────┤
│ ┌ 已发布分析 ─────┐ ┌ 12 列编排画布 ─────────────┐ ┌ 组件属性 ─────┐ │
│ │ 搜索分析         │ │ · · · · · · · · · · · · │ │ 治理状态       │ │
│ │ [▦ 项目综合分析] │ │ ┌────拖动卡片──────┐      │ │ X / Y / W / H  │ │
│ │   拖入或按添加   │ │ │ 图表             │ ◢    │ │ 参数映射/联动  │ │
│ │                  │ │ └──────────────────┘      │ │ 替换/打开/删除 │ │
│ └─────────────────┘ └───────────────────────────┘ └──────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

## 四态

- 空：画布提供“从左侧拖入已发布分析”；资源库空时提供“先创建并发布分析”。
- 加载：资源库和卡片分别显示骨架/Spin，不阻塞已加载布局编辑。
- 错误：目录、查询、保存、校验分别就地显示；不把英文 code 当主标题。
- 成功：拖放即更新本地布局；保存后显示时间并回填持久化组件 ID。

## 操作走查

1. 进入草稿编辑页，左侧只看到已发布治理分析。
2. 拖入画布或键盘点击“添加”，组件落到网格占位。
3. 拖标题条移动、拖右下角缩放；选中后右侧可精确调整布局。
4. 历史旧组件显示“需替换”，点击后选择已发布分析并保留原位置尺寸。
5. 点击“打开分析”进入 canonical 分析编辑器；返回后刷新引用信息。
6. 点击发布，系统先保存，再要求选择部门或角色，校验通过后确认发布。
