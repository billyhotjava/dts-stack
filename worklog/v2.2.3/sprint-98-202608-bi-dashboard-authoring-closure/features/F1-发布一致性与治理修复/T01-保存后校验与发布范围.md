# T01：保存后校验与发布范围

**优先级**：P0  **状态**：IN_PROGRESS  **依赖**：F0/T01

## 技术设计

- 输入：当前 `dashboard`、`dashcards`、`parameters` 和 `audience`。
- 数据流：点击发布 → 保存草稿 → 用响应刷新组件 ID/布局 → 打开抽屉 → 本地必填校验 → 服务端 validate → publish。
- 输出：校验结果只对应已保存草稿；保存后仍停留 `/bi/dashboards/{id}/edit`。
- 错误：保存失败不发起 validate；目录失败显示错误并允许重试；空受众仅显示中文表单错误。
- 复用：`analyticsApi.saveDashboard`、`/api/directory/orgs|roles`、既有 publication API。
