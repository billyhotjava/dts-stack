# T01：分析库拖入与网格编排

**优先级**：P0  **状态**：DONE  **依赖**：F1/T02

## 技术设计

- 左侧分析项 `draggable=true`，dataTransfer 保存 analysis ID；键盘用户使用“添加”。
- RGL 开启外部 drop，落位直接写 `row/col/size_x/size_y`；默认 `w=6,h=4,minW=3,minH=2`。
- 拖动仅从可见标题拖动条发起；按钮、链接和属性控件不触发拖动。
- 保存后用服务端 `ordered_cards` 回填持久化 ID。

## 验证（RED→GREEN）

- [x] source contract：`isDroppable/onDrop`、拖动 fallback、选中态存在。
- [x] Playwright：拖入后调整布局、保存并刷新，布局保持；RGL 移动/缩放继续复用同一布局回写路径。
