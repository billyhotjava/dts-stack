# T03: 空态异常权限加载状态

**状态**: DONE  
**优先级**: P0  
**涉及页面**: 所有菜单叶子页面

## 目标

所有页面必须有空态、异常态、权限态、加载态，不能用白屏、假数据或静态成功数值代替。

## 按钮清单

| 状态 | 按钮 | 目标行为 |
|------|------|----------|
| 空态 | 新建/导入/返回工作台 | 提供首次使用下一步 |
| 异常态 | 重试、查看详情、返回 | 允许恢复和定位问题 |
| 权限态 | 申请权限、返回 | 进入权限申请 |
| 加载态 | 无或取消 | 保持布局稳定 |

## 组件清单

- `EmptyState`
- `ErrorState`
- `PermissionState`
- `LoadingState`
- `SkeletonTable`
- `InlineErrorMessage`
- `RetryButton`

## 状态要求

- 空态不是“暂无数据”四个字，必须有下一步按钮。
- 权限不足不是空态，必须明确权限原因。
- API 失败展示错误码/业务原因，必要时隐藏敏感详情。
- 加载态保持页面尺寸稳定。

## 验收

- [x] 所有菜单叶子页面有四类状态设计或明确例外。
- [x] API 失败不会白屏。
- [x] 权限不足能申请权限。
- [x] 空态按钮跳转真实下一步。
