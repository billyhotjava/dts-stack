# T01: 数据管理工作台升级为主控台

**状态**: DONE  
**优先级**: P0  
**涉及路由**: `/workbench`, `/workbench/data-management`

## 目标

让数据管理工作台成为数据中台的第一屏：按业务主题展示链路状态，并把用户带到真实下一步。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 配置数据源 | 主按钮 | 跳转 `/foundation/data-sources` |
| 处理阻断项 | 主按钮 | 跳转 `/workbench/todo` 并过滤阻断 |
| 治理检查 | 次按钮 | 跳转治理质量或规则页面 |
| 查看资产 | 次按钮 | 跳转资产目录并带主题过滤 |
| 创建报表 | 次按钮 | 跳转 BI 数据/看板 |
| 发布数据 API | 次按钮 | 跳转服务 API 页面 |
| 查看运行 | 次按钮 | 跳转运维实例/告警 |

## 组件清单

- `WorkbenchProductShell`: 工作台产品壳。
- `BusinessThemeCard`: 经营分析、质量管理、项目交付、客户服务等主题。
- `GoldenChainStepper`: 数据源、入湖、建模、治理、资产、消费、运维。
- `NextActionPanel`: 主动作、次动作、禁用原因。
- `RiskSummaryList`: 阻断项、告警、待审批。
- `EvidencePanel`: 客户验收证据入口。

## 数据约束

- 主题状态优先来自 `/api/golden-chains` 或现有 workbench 聚合接口。
- 不允许硬编码“全部完成”或固定成功数量。

## 验收

- [x] 首屏展示业务主题和黄金链路状态。
- [x] 至少 6 类下一步动作能跳转真实页面。
- [x] 无链路时展示创建数据源/导入数据的空态。
- [x] 工作台不出现 sprint/F1/F2 等工程语言。
