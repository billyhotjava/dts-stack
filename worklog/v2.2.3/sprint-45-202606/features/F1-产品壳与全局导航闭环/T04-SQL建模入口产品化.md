# T04: SQL 建模入口产品化

**状态**: DONE  
**优先级**: P0  
**涉及路由**: `/studio/sql-modeling`

## 目标

让 SQL 建模入口指向真实建模工作台，承接从数据源/ODS 到 DWD/DWS/ADS 的建模动作。

## 按钮清单

| 按钮 | 类型 | 目标行为 |
|------|------|----------|
| 新建模型 | 主按钮 | 创建 SQL 模型草稿 |
| 预览数据 | 次按钮 | 执行预览查询并展示结果 |
| 校验模型 | 次按钮 | 触发语法、血缘、分层、质量门禁校验 |
| 生成 ODS | 次按钮 | 从源表生成 ODS 建议或任务 |
| 发布 | 主/门禁按钮 | 通过治理门禁后发布到资产/消费侧 |
| 删除草稿 | 危险按钮 | 二次确认后删除未发布草稿 |

## 组件清单

- `SqlModelingPage`: 建模页面主体。
- `SqlEditor`: SQL 编辑器。
- `SchemaExplorer`: 源表、字段、分层、标准码。
- `PreviewResultTable`: 预览结果。
- `ValidationPanel`: 语法、血缘、质量、分层诊断。
- `PublishGatePanel`: owner、分级、质量、权限、血缘门禁。
- `ModelLineagePreview`: 发布前血缘预览。

## 数据约束

- 预览、校验、发布必须接真实 API；未接通时按钮禁用并展示后端依赖。
- 发布动作必须回写资产、血缘或黄金链路状态，不能只改前端状态。

## 验收

- [x] `/studio/sql-modeling` 可达真实页面。
- [x] 新建、预览、校验、发布按钮状态完整。
- [x] 校验失败能展示字段级/规则级原因。
- [x] 发布成功后能跳到资产详情或数据管理工作台。
