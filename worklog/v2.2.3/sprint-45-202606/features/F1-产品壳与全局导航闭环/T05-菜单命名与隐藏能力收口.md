# T05: 菜单命名与隐藏能力收口

**状态**: DONE  
**优先级**: P0  
**涉及入口**: `/services/products`, `/services/tokens`, `/ops/events`, `/ops/audit-evidence`, `/ops/release-governance`, `/bi-apps/metrics/*`

## 目标

统一客户可见菜单语言，修正“页面能力”和“菜单名”不一致的问题，并决定隐藏能力是显性纳入产品还是下线。

## 按钮清单

| 按钮 | 页面位置 | 目标行为 |
|------|----------|----------|
| 查看数据产品 | 服务中心 | 进入统一数据产品页面 |
| 生成令牌 | 共享交换/令牌 | 进入安全令牌生成流程 |
| 查看事件 | 运维中心 | 进入事件流 |
| 导出审计证据 | 运维中心 | 导出客户验收证据包 |
| 发布复核 | 发布治理 | 发起发布门禁复核 |

## 组件清单

- `MenuLabelContract`: 菜单名、页面标题、面包屑一致性检查。
- `HiddenRouteInventory`: 静态路由但无菜单入口清单。
- `ServiceCenterTabs`: API、数据产品、安全共享、验收证据。
- `OpsEvidenceNav`: 实例、告警、补数、事件、审计、发布治理。

## 命名收口

- `/services/products`: 不再用“数据推送”描述数据产品；统一为“数据产品”或并入资产门户。
- `/services/tokens`: “共享交换”下必须明确这是“安全令牌/共享凭证”，不要误导为数据交换流程。
- `/bi-apps/metrics/*`: 客户侧菜单避免显示 sprint/F1/F2，改为“指标中心、指标资产、语义发布”。
- 隐藏运维路由若保留，纳入“运维验收”分组。

## 验收

- [x] 菜单名、页面标题、面包屑一致。
- [x] 静态路由无菜单入口的页面都有保留/下线决策。
- [x] 服务中心和运维中心不再出现误导性入口。
- [x] source-contract 覆盖命名一致性。
