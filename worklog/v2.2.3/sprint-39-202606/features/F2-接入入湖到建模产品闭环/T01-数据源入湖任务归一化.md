# T01: 数据源入湖任务归一化

**优先级**: P0
**状态**: READY
**依赖**: F1-T01

## 目标

统一 JDBC/API/file 入湖任务的产品状态、执行证据和 ODS 输出描述。

## 技术设计

- 梳理 `IngestionTaskResource`、`IngestionTaskProxyResource`、Sprint-38 API Java 执行器和文件/JDBC 路径差异。
- 统一任务类型、源表/资源、目标 ODS 表、checkpoint、执行证据字段。
- API/file 不能退回 env 明文或临时手工导入路径。

## 影响范围

- `source/dts-ingestion`
- `source/dts-platform`
- `source/dts-platform-webapp`

## 验证

- [ ] JDBC/API/file 的任务详情能映射到同一黄金链路阶段。
- [ ] Sprint-38 API 安全证据仍通过。

## 完成标准

- [ ] 入湖任务成为黄金链路的稳定阶段，而不是独立页面能力。
