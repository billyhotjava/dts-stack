# T04: 黄金链路运维视角联动

**优先级**: P1
**状态**: READY
**依赖**: T03

## 目标

从黄金链路详情能跳转到运维实例，从运维实例能回看链路上下游影响。

## 技术设计

- 运维实例带 chainId / artifactId / taskId。
- 链路详情展示最近运行、失败次数、MTTR、补数状态。
- 失败时提供影响分析：哪些资产、指标、报表、API/数据产品受影响。

## 影响范围

- `source/dts-platform` ops/catalog/golden chain 聚合
- `source/dts-platform-webapp`

## 验证

- [ ] 从失败实例能定位到受影响报表或 API。
- [ ] 从链路详情能打开最近运行日志。

## 完成标准

- [ ] 运维中心成为主链路的一部分，而不是旁路页面。
