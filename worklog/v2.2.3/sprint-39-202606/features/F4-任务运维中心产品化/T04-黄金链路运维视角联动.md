# T04: 黄金链路运维视角联动

**优先级**: P1
**状态**: DONE
**依赖**: T03

## 目标

从黄金链路详情能跳转到运维实例，从运维实例能回看链路上下游影响。

## 技术设计

- 新增 `GoldenChainOpsImpactService`，把运维实例、补数状态和消费影响汇总为黄金链路运维视角。
- 运维实例带 chainKey / taskId / instanceId。
- 链路详情展示最近运行、失败次数、MTTR、补数状态和日志入口。
- 失败时提供影响分析：哪些资产、报表、API/数据产品受影响。

## 影响范围

- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/service/goldenchain/ops/`
- `source/dts-platform/src/test/java/com/yuzhi/dts/platform/service/goldenchain/ops/`
