# T03: 运行日志错误分类与重试入口

**优先级**: P1
**状态**: READY
**依赖**: T02

## 目标

让运行失败原因可读、可分类、可恢复，减少现场排障依赖后台日志。

## 技术设计

- 错误分类：连接失败、凭据失败、数据质量失败、模型构建失败、血缘失败、权限失败、系统异常。
- 详情页展示日志位置、外部运行链接、最近重试、建议动作。
- 对可重试动作接入 ingestion retry/backfill 或模型重新发布入口。

## 影响范围

- `source/dts-platform` ops/external run log
- `source/dts-ingestion` execution logs
- `source/dts-platform-webapp`

## 验证

- [ ] API 入湖失败能显示 AUTH/NETWORK/DATA_QUALITY 等分类。
- [ ] 可重试任务能从页面触发重试或补数。

## 完成标准

- [ ] 运维闭环从“看状态”升级为“可恢复”。
