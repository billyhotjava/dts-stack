# T03: 运行日志错误分类与重试入口

**优先级**: P1
**状态**: DONE
**依赖**: T02

## 目标

让运行失败原因可读、可分类、可恢复，减少现场排障依赖后台日志。

## 技术设计

- 新增 `GoldenChainOpsErrorClassifier`，覆盖连接失败、凭据失败、数据质量失败、模型构建失败、血缘失败、权限失败、系统异常。
- 分类结果包含 `category`、`retryAction`、`recoverable` 和业务可读建议动作。
- 对可重试动作映射 ingestion retry/backfill、模型重新发布、血缘刷新或权限申请入口。
