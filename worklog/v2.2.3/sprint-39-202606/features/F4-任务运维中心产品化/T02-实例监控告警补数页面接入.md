# T02: 实例监控告警补数页面接入

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标

将后端 ops 数据以客户可理解方式展示出来，支持筛选、查看详情和补数申请。

## 技术设计

- 实例监控展示 task、artifact、externalRunId、status、duration、logPath。
- 告警记录展示质量失败、任务失败、发布失败和权限失败。
- 补数管理支持创建 backfill request，并关联链路实例。

## 影响范围

- `source/dts-platform/src/main/java/.../OpsResource.java`
- `source/dts-platform-webapp/src`

## 验证

- [ ] 失败任务能在实例列表和告警列表同时定位。
- [ ] 补数请求写入并可查询。

## 完成标准

- [ ] 运维人员能从页面完成定位和补数发起。
