# T04: 端到端证据采集脚本

**优先级**: P0
**状态**: DONE
**依赖**: T03

## 目标

建立黄金链路 IT 脚本和证据采集方式，让 sprint DONE 不是只看页面或单测。

## 技术设计

- 新建 `it/scripts/golden-chain-*.sh`，按 JDBC/API/file 拆分。
- 证据保存到 `it/evidence/`，包含接口输出、SQL 摘要、发布门禁结果和消费侧可见性。
- API 路径复用 Sprint-38 的安全断言，避免重复造脚本。
- 脚本默认 dry-run，`RUN_LIVE=1` 才触发真实环境动作。

## 落地内容

- `it/scripts/golden-chain-jdbc.sh`: IT-01 JDBC 黄金链路证据入口。
- `it/scripts/golden-chain-api.sh`: IT-02 API 黄金链路证据入口，显式复用 Sprint-38 API E2E 安全基线。
- `it/scripts/golden-chain-file.sh`: IT-03 file 黄金链路证据入口。
- `it/scripts/golden-chain-governance-permission-ops.sh`: IT-04/IT-05/IT-06 治理阻断、权限 fail-closed、运维 evidenceRef 证据入口。
- `it/scripts/golden-chain-lib.sh`: 公共 dry-run/live 采集逻辑。
- `it/evidence/README.md`: evidence 文件命名与字段模板。
