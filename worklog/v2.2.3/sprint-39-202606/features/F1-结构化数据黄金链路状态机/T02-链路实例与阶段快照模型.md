# T02: 链路实例与阶段快照模型

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

设计黄金链路实例的数据模型，串联数据源、入湖任务、ODS、dbt 模型、资产、指标、报表/API/数据产品。

## 技术设计

- 优先评估复用现有 `InfraExternalRunLog`、Catalog asset mapping、ingestion execution 与 metrics state。
- 若聚合不足，再新增轻量 `golden_chain_instance` / `golden_chain_stage_snapshot`。
- 每个阶段快照保留 `status`、`evidenceRef`、`owner`、`blockedReason`、`updatedAt`。
- 关联键优先使用现有 id，不引入和资产事实源冲突的新自然键。

## 落地内容

- 新增 `GoldenChainInstance`：保存链路 key、展示名、JDBC/API/file 类型、通用 sourceRef、当前阶段、生命周期状态、负责人。
- 新增 `GoldenChainStageSnapshotRecord`：保存阶段、阶段顺序、状态、负责人、证据引用、证据类型、通用 sourceRef、阻断码和阻断原因。
- 新增 `GoldenChainInstanceRepository` / `GoldenChainStageSnapshotRecordRepository`：支持按 chainKey、sourceRef、chainInstanceId + stage 查询。
- 新增 Liquibase changelog `20260614_01_golden_chain_instance.xml`，只新增轻量聚合表，不改现有资产、任务、指标事实表。

## 影响范围

- `source/dts-platform` domain/repository/service
- `source/dts-ingestion` execution/task DTO
- `source/dts-metrics` model lifecycle DTO
