# T02: 链路实例与阶段快照模型

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

设计黄金链路实例的数据模型，串联数据源、入湖任务、ODS、dbt 模型、资产、指标、报表/API/数据产品。

## 技术设计

- 优先评估复用现有 `InfraExternalRunLog`、Catalog asset mapping、ingestion execution 与 metrics state。
- 若聚合不足，再新增轻量 `golden_chain_instance` / `golden_chain_stage_snapshot`。
- 每个阶段快照保留 `status`、`evidenceRef`、`owner`、`blockedReason`、`updatedAt`。
- 关联键优先使用现有 id，不引入和资产事实源冲突的新自然键。

## 影响范围

- `source/dts-platform` domain/repository/service
- `source/dts-ingestion` execution/task DTO
- `source/dts-metrics` model lifecycle DTO

## 验证

- [ ] 一条 JDBC 样例链路能生成完整阶段快照。
- [ ] API 入湖 Sprint-38 样例能挂接到同一模型。

## 完成标准

- [ ] 模型设计不复制资产事实源，不破坏现有业务表。
