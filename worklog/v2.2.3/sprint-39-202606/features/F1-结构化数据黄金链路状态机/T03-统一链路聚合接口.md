# T03: 统一链路聚合接口

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

提供平台侧统一接口，返回黄金链路实例列表、详情、阶段状态、失败原因和可执行动作。

## 技术设计

- 新增或扩展 platform 聚合资源，例如 `/api/golden-chains`。
- 后端聚合 ingestion、catalog、modeling、metrics、services、ops 的状态摘要。
- 返回业务可读状态，不让前端理解每个子系统内部状态。
- 对敏感资产和无权限资产 fail-closed，不泄露资产名称或字段密级。

## 影响范围

- `source/dts-platform/src/main/java/.../web/rest`
- `source/dts-platform/src/main/java/.../service`
- `source/dts-platform-webapp/src`

## 验证

- [ ] 无权限用户看不到不可读资产的链路详情。
- [ ] 阶段失败时返回明确业务原因和下一步动作。

## 完成标准

- [ ] 前端可通过单一接口渲染链路工作台。
