# T01: 报表数据集发布和指标入口

**优先级**: P1
**状态**: DONE
**依赖**: F2-T03,F3-T04

## 目标

将通过门禁的 DWS/ADS 资产发布为 BI 数据集和指标入口，客户从业务字段选择指标/维度。

## 技术设计

- `dts-metrics` 默认从 DWS/ADS 读取资产和字段合同。
- platform 负责发布审批、BI Dataset 注册、权限、审计。
- 指标说明来自业务口径、单位、阈值、更新时间和 owner，不展示 SQL。
- 新增 `GoldenChainReportDatasetPublisherService`，将模型发布门禁、权限一致性和业务字段合同统一转换为 `CONSUMABLE` 阶段快照。
