# T01: 报表数据集发布和指标入口

**优先级**: P1
**状态**: READY
**依赖**: F2-T03,F3-T04

## 目标

将通过门禁的 DWS/ADS 资产发布为 BI 数据集和指标入口，客户从业务字段选择指标/维度。

## 技术设计

- `dts-metrics` 默认从 DWS/ADS 读取资产和字段合同。
- platform 负责发布审批、BI Dataset 注册、权限、审计。
- 指标说明来自业务口径、单位、阈值、更新时间和 owner，不展示 SQL。

## 影响范围

- `source/dts-metrics`
- `source/dts-platform`
- `source/dts-metrics-webapp`
- `source/dts-platform-webapp`

## 验证

- [ ] 无权限资产不出现在指标/报表选择器。
- [ ] 业务说明不包含 SQL。

## 完成标准

- [ ] 无 SQL 报表入口从治理后的 DWS/ADS 开始。
