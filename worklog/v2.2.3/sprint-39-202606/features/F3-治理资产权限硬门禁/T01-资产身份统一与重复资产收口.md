# T01: 资产身份统一与重复资产收口

**优先级**: P0
**状态**: READY
**依赖**: F1-T02

## 目标

明确同一数据集、dbt 模型、BI 数据集、指标、API 服务、数据产品的资产身份规则，减少 OpenMetadata、本地 Catalog 和代码化资产重复。

## 技术设计

- 复查 `CatalogAssetIdentityResolver`、`CatalogAssetPortalService`、code asset grant writer。
- 定义 asset key 优先级：平台资产 ID > OpenMetadata FQN > code asset key > legacy fallback。
- 重复资产进入 `PENDING_GOVERNANCE` 或诊断报告，不默认合并。

## 影响范围

- `source/dts-platform` catalog/permission/services

## 验证

- [ ] 同一 dbt 模型不会在资产门户和服务侧呈现两个互不关联资产。
- [ ] 无法解析资产身份时有诊断记录。

## 完成标准

- [ ] 黄金链路每个消费物都能指向唯一资产身份。
