# T03: 血缘失败待治理状态

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

让血缘失败从 best effort 日志变成可见的待治理状态，避免无血缘资产直接进入消费层。

## 技术设计

- OpenLineage、dbt manifest、Addax declared lineage 都写入统一诊断结果。
- 不可解析 source/target 时进入 `PENDING_GOVERNANCE`。
- 发布门禁读取血缘证据，不再只看任务成功。

## 影响范围

- `source/dts-platform` lineage/catalog
- `source/dts-ingestion` lineage snapshot

## 验证

- [ ] 血缘解析失败不会静默通过发布。
- [ ] 资产门户能展示失败原因和修复建议。

## 完成标准

- [ ] 血缘成为发布硬证据。
