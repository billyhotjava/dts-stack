# T03: 血缘失败待治理状态

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

让血缘失败从 best effort 日志变成可见的待治理状态，避免无血缘资产直接进入消费层。

## 技术设计

- 新增 `GoldenChainLineageGovernanceService`，统一 OpenLineage、dbt manifest、Addax declared lineage 的诊断口径。
- 不可解析 source/target、解析失败或缺少 evidenceRef 时进入 `PENDING_GOVERNANCE`。
- 发布门禁读取血缘证据，不再只看任务成功。

## 影响范围

- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/service/goldenchain/governance/`
- `source/dts-platform/src/test/java/com/yuzhi/dts/platform/service/goldenchain/governance/`
