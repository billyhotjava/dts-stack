# 客户场景验收包：项目订单结构化黄金链路

**面向对象**: 传统行业业务用户、数据管理员、运维人员
**场景目标**: 证明平台可把结构化客户、项目、订单数据从接入一路交付到报表、指标、数据 API 和运维视图。
**验收口径**: 客户只看到指标、维度、口径、更新时间、权限状态和服务状态，不默认展示底层实现细节。

## 最小业务样例

| 业务对象 | 关键字段 | 客户可读说明 |
|----------|----------|--------------|
| 客户 | 客户名称、所属区域、客户等级 | 用于按客户和区域查看业务表现 |
| 项目 | 项目名称、负责人、状态 | 用于跟踪项目进展和责任人 |
| 订单 | 订单日期、成交金额、交付状态 | 用于形成日报、指标和服务接口 |
| 质量 | 检查结果、问题类型、整改状态 | 用于质量看板和异常追踪 |

## 验收步骤

| 步骤 | 客户看到的结果 | 证据类型 | 建议证据路径 |
|------|----------------|----------|--------------|
| 1. 确认数据源 | 客户、项目、订单主数据出现在数据接入中心 | 截图 | `it/evidence/customer-demo/01-source-ready.md` |
| 2. 确认入湖结果 | 订单日数据可按业务日期追踪，入湖任务有运行记录 | 脚本输出 | `it/evidence/customer-demo/02-ingestion-ready.md` |
| 3. 确认治理门禁 | owner、分级、质量和血缘证据齐全，缺失时会被阻断 | 接口输出 | `it/evidence/customer-demo/03-governance-gate.md` |
| 4. 确认报表消费 | 业务用户可选择成交金额、客户名称、项目状态生成报表 | 截图 | `it/evidence/customer-demo/04-report-consumption.md` |
| 5. 确认数据服务 | 授权用户可查看订单 API 的订阅状态、调用次数和依赖资产 | 接口输出 | `it/evidence/customer-demo/05-api-service.md` |
| 6. 确认运维联动 | 任务失败时能看到失败原因、日志入口、补数状态和受影响报表/API | 截图或接口输出 | `it/evidence/customer-demo/06-ops-impact.md` |

## 业务指标说明

| 指标 | 维度 | 口径 | 单位 | 更新时间 | 负责人 |
|------|------|------|------|----------|--------|
| 成交金额 | 客户、区域、项目、日期 | 统计周期内完成交易的订单金额 | 元 | 每日 | sales-ops |
| 订单数 | 客户、项目、日期 | 统计周期内完成交易的订单数量 | 笔 | 每日 | sales-ops |
| 质量问题数 | 项目、问题类型、状态 | 统计周期内新增或未关闭的问题数量 | 个 | 每日 | quality-ops |

## 权限验收

| 消费入口 | 权限事实源 | 验收判断 |
|----------|------------|----------|
| 数据资产门户 | platform policy / RLS / masking | 无权限用户不可见资产详情 |
| 指标入口 | platform policy / RLS / masking | 无权限资产不进入指标选择器 |
| BI 报表 | platform policy / RLS / masking | 报表数据集与资产门户权限一致 |
| 数据大屏 | platform policy / RLS / masking | 大屏组件不使用本地孤立授权 |
| 数据 API | platform policy / RLS / masking + secretRef token | 未授权订阅不可调用受控服务 |
| 数据产品 | platform policy / RLS / masking | schema、SLA、刷新频率、授权状态可见 |

## 失败恢复

| 失败类型 | 客户可读原因 | 操作入口 |
|----------|--------------|----------|
| 数据源连接失败 | 数据源不可达或凭据不可用 | 数据接入中心 / 任务运维中心 |
| 入湖任务失败 | 本次同步未完成或目标表未写入 | 任务实例 / 补数管理 |
| 模型发布失败 | 模型构建或质量校验未通过 | 数据开发中心 / 治理中心 |
| 权限阻断 | 当前用户未获得资产授权 | 数据资产门户 / 审批入口 |
| 消费阻断 | 报表、指标或数据服务尚未发布完成 | 商业智能应用 / 数据服务中心 |

## 验收结论模板

- 黄金链路实例: `chain-orders`
- 报表数据集: `订单日汇总`
- 数据服务: `订单 API v1`
- 业务指标: `成交金额`、`订单数`、`质量问题数`
- 权限结果: 资产门户、指标、BI、大屏、API、数据产品一致
- 运维结果: 失败实例、告警、补数、日志和影响范围可追踪
