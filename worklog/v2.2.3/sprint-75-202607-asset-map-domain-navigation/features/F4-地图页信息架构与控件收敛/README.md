# F4：地图页信息架构与控件收敛

**优先级**：P1
**状态**：DRAFT

## 目标

把三处重复且互相矛盾的数字收敛为一个治理缺口面板，让矩阵在单域时不再空转，并把 chrome 按钮从 3 个降到 1 个 icon-only —— 地图页回归其文件注释已声明的"纯统计概览"职责。

## 契约定义

| 类型 | 契约 | 关键点 |
|---|---|---|
| 控件 | 地图页 chrome | 删除 `进入台账`、`去台账处置`；`刷新` 降级为 icon-only（ADR-75-09） |
| 导航 | 台账入口 | 保持全局菜单一级入口，**不升为 tab**（ADR-75-10） |
| 下钻 | `drillToLedger(layer?, domainKey?)` | 签名不变；触发点从按钮改为矩阵格子、缺口原因、Top 5 卡片、范围回显 |
| 配色 | 0 值语义 | 中性灰，不用绿色对勾（ADR-75-11） |
| 矩阵 | 退化策略 | 可见域 ≤1 不画矩阵；≥2 画表；列 = top 8 + 静态"其他 N 个域"（tooltip 列域名）（ADR-75-12） |
| 文案 | truncated 警告 | 反映真实原因，仅在 `scanned >= SCAN_CAP` 时出现 |

### 控件裁剪对照

| 控件 | 现状 | 改后 | 理由 |
|---|---|---|---|
| `进入台账` 按钮 | 有 | **删除** | 与全局菜单一级入口重复（L12） |
| `去台账处置` 按钮 | 有 | **删除** | Top 5 卡片已可点，是多余的第二触发点 |
| `刷新` 按钮 | 文字按钮 | icon-only，并入"统计更新于 HH:mm ⟳" | 保留能力，去掉视觉重量 |
| "统计概览视图：数字基于…"两行说明 | 有 | 压成一行 12px 辅助文本 | 删按钮后仍需一句边界提示，但不需要两行 |

### 信息去重

`待处置 360` / `未归域 360` / `治理状态分布 待归域 358 + 待认领 2` 三处收敛为一个面板：
- 左侧独立大数字卡 = 资产总量；
- 右侧单条堆叠进度条 = 待处置占比，四个原因按分色段展示并在下方成行；
- 待处置真为 0 时整条变绿，显示"当前范围无待处置资产"。

### 四态

| 态 | 表现 |
|---|---|
| 加载中 | 面板骨架 + 数字位 skeleton，不整页 spin |
| 当前范围零资产 | 空态文案内嵌行内链接（带 domain 进台账），保证零资产时仍有出口 |
| 统计截断 | 面板顶部一行提示真实原因，数字加 `≥` 前缀 |
| 健康（待处置 0） | 缺口条变绿，Top 5 区显示"当前范围没有待处置资产" |

### 操作走查

进入地图 → 读到"待处置 360 / 总量 360，100%" → 点"待归域 358" → 落到台账且已带 `domain=__UNASSIGNED__` + 治理状态筛选 → 处置完返回地图 → 缺口条百分比下降。
