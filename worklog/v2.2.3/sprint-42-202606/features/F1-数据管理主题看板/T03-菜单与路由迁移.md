# T03: 菜单与路由迁移

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

把主题看板挂到工作台一级菜单下，同时保留旧消费工作台路径兼容。

## 技术设计

- 新增 `/workbench/data-management` 静态路由。
- 动态菜单解析支持 `/workbench/data-management`。
- `portal-menu-seed.json` 在工作台下新增“数据管理工作台”。
- `role-menu-defaults.json` 新增默认可绑定项，不绑定默认角色。
- dts-admin seed component override 支持新菜单项，避免页面存在但菜单树不可渲染。

- `source/dts-platform-webapp/src/routes/sections/dashboard/static-routes.tsx`
- `source/dts-platform-webapp/src/routes/sections/dashboard/dynamic-resolver.tsx`
- `source/dts-platform-webapp/src/locales/lang/zh_CN/sys.json`
