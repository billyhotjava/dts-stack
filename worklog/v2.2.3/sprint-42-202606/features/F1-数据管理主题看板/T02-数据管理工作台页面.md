# T02: 数据管理工作台页面

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

新增数据管理工作台页面，把主题看板作为数据管理员的第一视图。

## 技术设计

- 新增 `DataManagementWorkbenchPage.tsx`。
- 页面通过 `goldenChainService.list()` 和 `goldenChainService.detail()` 获取真实链路状态。
- 页面展示主题卡片、主题交付状态、关联链路、下一步动作和客户可读空态。
- 页面避免 SQL/dbt/ODS/DWD/DWS/ADS 等默认技术词作为主表达。
