# T02: 受控模式判定与分流骨架

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
在 `SemanticModelingService` 建立统一的受控模式判定点，让 F2（DSL）/F3（分层闸）可挂载，且 PERMISSIVE 路径与现状字节不变。

## 技术设计
- 私有 `boolean isControlled(ModelDto model)` —— 读 `governanceMode`，CONTROLLED 为真。
- `buildMetricExpression` 改造为分流：CONTROLLED → 委托受控编译器（F2-T03 接入）；否则走现有 `safeMetricExpression`/switch 路径（不改）。本任务先建分流骨架 + 占位委托接口，F2 填实现。
- 模型/业务对象校验 + `validateModelForReview` 内预留受控分层校验挂载点（F3-T02 接入）。
- 绞杀者原则：所有改造对 PERMISSIVE 必须是 no-op；用现有 permissive 测试守护字节不变。

## 影响范围
- `dts-platform`：`SemanticModelingService`（buildMetricExpression、validateModelForReview、相关校验入口）。

## 验证
- [ ] PERMISSIVE 模型：generate-artifacts/preview/review 行为与改造前一致（既有测试全绿）。
- [ ] CONTROLLED 模型：进入受控分支（此任务可先抛"未实现"占位，由 F2/F3 落实）。

## 完成标准
- [ ] 分流骨架就位、PERMISSIVE 字节不变、受控挂载点清晰，既有测试不破。
