# T03: 错误码映射

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标
把分层闸的领域异常映射为对外 400 + 与 dts-metrics 对齐的 code，便于 SP-3 前端复用。

## 技术设计
- 闸的 ERROR 诊断 → 平台领域异常（携带 code）。
- controller/异常处理器映射：HTTP 400，body 含 `code` ∈ {`invalid_layer`, `grain_mismatch`, `standard_code_required`} + message + 定位（nodeId/资产）。
- 与平台现有错误响应风格统一（沿用平台 error envelope，不新造）。

## 影响范围
- `dts-platform`：异常类型/处理器、相关 controller。

## 验证
- [ ] 三类违规分别返回 400 + 正确 code。
- [ ] 错误体结构与平台既有约定一致；不泄露内部 SQL/栈。

## 完成标准
- [ ] 映射齐全、code 对齐 dts-metrics、Web 层测试覆盖。
