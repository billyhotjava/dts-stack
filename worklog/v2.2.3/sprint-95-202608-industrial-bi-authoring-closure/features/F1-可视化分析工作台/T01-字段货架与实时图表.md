# T01：字段货架与实时真实图表

**优先级**：P0  **状态**：IN_PROGRESS  **依赖**：F0/T01

## 技术设计

- 输入：contract dimensions/metrics、`AnalysisQuerySpec`、query state。
- 输出：幂等的 dimension/metric selection 与 `visualization.settings['graph.dimensions'|'graph.metrics']`。
- 数据流：原生 drag/drop 或按钮 → pure reducer → spec → debounce preview → `ChartRenderer`。
- 错误：空货架不查询；403/429/504/取消保留既有显式状态；陈旧请求不得覆盖新结果。
- 复用：AnalysisEditorPage、ChartRenderer、AnalysisQueryGateway；不加依赖。
