# T01：参数映射、定向联动与发布

**优先级**：P0  **状态**：READY  **依赖**：F1

## 技术设计

- `ParameterMappingPopover` 接入 DashboardEditorCard/Grid/Page，并把结果写回对应 dashcard。
- 新建小型 InteractionSettingsPopover；设置仍保存在 dashcard `visualization_settings`。
- 扩展 cross-filter state 携带 targetCardIds；无目标时不触发，来源卡不自筛。
- 看板查询改为最多 4 并发，generation 变化时丢弃旧结果。

## 验证

- [ ] hook/unit：定向、toggle、clear、无目标。
- [ ] source-contract：映射组件可达且保存 payload 包含映射。
- [ ] Playwright：配置 → 预览点击 → 仅目标重查 → 发布。
