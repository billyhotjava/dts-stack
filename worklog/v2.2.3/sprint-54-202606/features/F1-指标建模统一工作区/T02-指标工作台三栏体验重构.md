# T02: 指标工作台三栏体验重构

**优先级**: P0  
**状态**: DONE  
**依赖**: T01

## 目标

完善指标工作台左侧主题树、中央画布、右侧详情，让用户能从指标关系快速进入维护动作。

## 技术设计

- 左侧主题树改为业务节点和数量明确的分组展示。
- 中央画布增加状态摘要和更稳定的空态/加载态。
- 右侧详情提供公式、发布、模型和运维跳转，不复制运行监控页面。

## 影响范围

- `MetricWorkbenchPage.tsx`
- `metric-workbench/SubjectBrowserPanel.tsx`
