# T01：门户树、深链与四态

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F1/T01

## 目标

用户从 `/bi/portal` 看见按主题域分组的大屏名称，点击叶子后 URL 与右侧大屏同步。

## 技术设计

- 输入：published-only `ScreenListItem[]` + `DomainNode[]` + `screenId?`。
- 输出：Ant Tree 节点；大屏叶子键 `screen:{id}`；稳定中文名排序。
- 数据流：并行加载大屏/主题域 → domainId 分桶 → 搜索裁剪 → 默认/深链选择 → runtime URL。
- 错误：大屏 API 失败显式重试；domain API 失败平铺；0 条为空态；未知 screenId 不加载 iframe。
- 复用：`PageContainer`、`getDomainTree`、`ClassificationTag`、`resolveRouteForOpen`。
- 范围：新 `DataPortalPage`/helper/test、静态路由、Mock E2E。

## 操作走查

1. 打开数据门户。
2. 展开主题域，看到仅已发布且可读的大屏。
3. 搜索名称并点击叶子。
4. URL 变成 `/bi/portal/{id}`，右侧显示该大屏。
5. 刷新后仍选中该大屏；窄屏不遮挡菜单和管理按钮。
