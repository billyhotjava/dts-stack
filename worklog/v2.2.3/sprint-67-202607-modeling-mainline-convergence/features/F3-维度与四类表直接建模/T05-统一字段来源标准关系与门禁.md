# T05：统一字段、来源、标准、关系与门禁

**优先级**：P0
**状态**：READY
**依赖**：F3-T02、F3-T03、F3-T04

## 目标与用户结果

四类表共用一个字段设计和校验框架，但按模型类型只要求真正需要的信息；用户能看到草稿、实现、发布三个阶段分别缺什么。

## 范围与不做

- 范围：字段列表、来源映射、标准绑定、维度/指标/上游引用、分阶段 gate 和错误展示。
- 不做：不在模型模块编辑标准或指标正文，不用一个“大而全”表单一次收齐全部字段。

## 输入契约

每个字段包含 name、type、nullable、sourceFieldRef、role(KEY/ATTRIBUTE/TIME/MEASURE)、securityLevel。`standardBindings` 以 fieldName 关联 standardElementId/version、referenceCode/version、measurementUnitId/version，避免在字段和绑定数组各写一份标准真值。模型级引用包含 sourceRefs、dependsOn、dimensionRefs、metricRefs；SourceRef 对 JOIN 来源显式保存 role、alias、joinType、joinExpression、sortOrder，兼容期保留 legacyRawRole。

## 输出产物

- ModelSpec field contract/revision；
- StandardBinding、关系/依赖引用；
- DRAFT_SAVE、IMPLEMENTATION_READY、RELEASE_READY 三套 gate；
- 字段级 repair route。

## 详细设计

1. DRAFT_SAVE 只校验模型身份和该类型最小设计字段。
2. IMPLEMENTATION_READY 校验来源/上游、键、粒度、时间、字段映射和实现所有权。
3. RELEASE_READY 再校验标准、质量、权限、版本漂移、构建/测试产物。
4. 前端用一个 blocker panel 展示服务端结果；不复制验证逻辑决定是否发布。
5. 标准选择器读取标准模块并保存 ID/版本；指标选择器读取指标模块并保存引用。
6. 关系概览从 dimensionRefs/dependsOn/lineage 派生，不允许手工矩阵成为第二真值。

## 影响范围

- ModelSpec DTO/validation/application service
- model detail field editor 和 gate panel
- standards/metrics API clients
- standard binding、dependency、lineage tables
- release gate 和相关测试

## 异常与权限

- 外部引用不可用时状态 UNKNOWN/STALE，不当作未绑定。
- 无权字段只显示受限摘要；不得把受限标准/来源复制进错误消息。
- revision 变化后旧 gate 立即失效。
