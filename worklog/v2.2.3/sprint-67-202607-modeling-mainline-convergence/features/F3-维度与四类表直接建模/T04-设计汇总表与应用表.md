# T04：设计汇总表与应用表

**优先级**：P0
**状态**：DONE
**依赖**：F3-T01、F3-T03

## 目标与用户结果

用户通过选择上游模型、聚合粒度或消费场景直接创建汇总表和应用表，不重新登记过程或业务对象。

## 范围与不做

- 范围：SUMMARY/APPLICATION 创建表单、dependsOn、聚合/输出契约、层级建议和门禁。
- 不做：不在模型页重建指标编辑器、报表设计器或服务编排器。

## 输入契约

| 类型 | 创建必填 | 实现前补齐 | 默认层 |
|---|---|---|---|
| SUMMARY | planId、domainId、name、至少一个上游模型、聚合粒度 | group dimensions、measure/metric refs、周期、刷新策略 | DWS |
| APPLICATION | planId、domainId、name、消费场景、至少一个上游模型、输出粒度 | 输出字段契约、刷新/SLA、服务/报表引用 | ADS |

上游模型必须来自同计划或显式允许的已发布跨计划模型；业务活动从上游事实推导用于展示，不作为输入门禁。

## 输出产物

- SUMMARY/APPLICATION ModelSpec；
- dependency edges；
- 聚合/输出字段设计；
- 上游版本和漂移门禁。

## 详细设计

1. SUMMARY 表单以“从哪些明细/维度汇总、按什么粒度和周期”为核心。
2. APPLICATION 表单以“服务哪个报表/接口/场景、输出什么粒度”为核心。
3. dependsOn 写稳定 modelSpecId + version/revision pin；页面显示当前/漂移状态。兼容 reader 可读旧字符串 ID，新保存只写带 revision 的 v2 引用。
4. 指标只保存 metricRef；指标公式正文仍由指标模块持有。
5. businessActivityRef 若显示，只从上游投影汇总，不允许用户在下游制造新的过程事实。
6. 循环依赖、跨域无权引用和未发布外部上游在服务端阻断。

## 影响范围

- ModelSpec creation/detail components
- dependency API/lineage edge service
- drift/release gate
- DWS/ADS 旧 semantic model compatibility
- metric/BI handoff links

## 异常、权限与恢复

- 上游漂移：保存草稿但阻止发布，展示具体版本差异。
- 循环依赖：事务回滚并返回依赖路径。
- 消费目标不存在：引用状态 UNKNOWN，不静默删除。

## 实施与测试设计

1. 先写 SUMMARY/APPLICATION 必填、循环、跨域、漂移测试。
2. 实现条件表单和 dependency graph API。
3. 加入发布门禁和修复跳转。
4. 浏览器验证选择上游、刷新、版本漂移和返回。

## 实施结果（2026-07-19）

- SUMMARY/APPLICATION 均通过 revision-pinned `dependsOn` 建模，不接收业务对象或手工业务过程作为前置输入。
- SUMMARY 实现门禁要求 MEASURE 字段或 metricRefs；APPLICATION 要求 consumptionScenario 与输出字段契约，两类规则不混用。
- 服务端检查上游 revision 仍为当前版本；循环/跨计划/不可见引用沿用 canonical reference validation，指标正文不复制进 ModelSpec。

### 2026-07-20 复核补强

- 新增直接与间接 DFS 循环检测，异常稳定返回 `MODEL_SPEC_DEPENDENCY_CYCLE` 和完整依赖路径。
- 新增 `GET /api/modeling/model-specs/{id}/dependencies`，节点和边同时返回固定 revision、当前 revision 及 CURRENT/STALE/UNKNOWN。
- SUMMARY/APPLICATION 详情页直接从该图派生上游状态；受限引用只显示“受限上游”，不泄露名称、类型或状态。

### 2026-07-23 分层依赖收敛

F3-T07 将本 Task 的“默认建议层”提升为服务端不变量：

- SUMMARY 目标层固定 DWS，至少依赖一个锁定 revision 的 DIMENSION/FACT@DWD 或 SUMMARY@DWS；
- APPLICATION 目标层固定 ADS，至少依赖一个锁定 revision 的任意合法 DWD/DWS/ADS 四类 ModelSpec；
- SUMMARY 不接受直接物理 sourceRefs 或 APPLICATION@ADS 上游；DWS 同层派生允许，但必须 CURRENT、无环；
- APPLICATION 不接受直接物理 sourceRefs；ADS 同层派生允许，但必须 CURRENT、无环；
- targetLayer 不匹配、上游层不允许、未锁 revision 和 revision 漂移分别返回稳定 blocker。

ODS_RAW/ODS_STANDARDIZED/STG 由接入/技术链持有，不作为 SUMMARY/APPLICATION 的创建输入；历史 ODS/STG ModelSpec 的专属只读分类与候选排除仍待 F3-T07 实现。
