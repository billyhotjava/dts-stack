# T10：重构轻量新建与三阶段模型详情页

**优先级**：P0
**状态**：READY
**依赖**：F3-T08、F3-T09、F4-T02/T03/T04

## 目标

把当前同时混排概念、逻辑、来源和实现的长抽屉拆为“轻量新建 + 逻辑设计 / 数据实现 / 物理资产三阶段详情”，让首次用户能够判断当前输入、阻塞和下一步。

## 范围

- 维度目录只管理 `DimensionDefinition`，不显示来源和物化字段；
- 新建模型抽屉只创建最小 DRAFT；
- DIMENSION 新建时选择业务维度，不在同一操作中重新登记维度正文；
- 模型详情拆为逻辑设计、数据实现、物理资产三个阶段；
- 每个状态只展示一个主动作；
- 数据库未同步、API 未落地、来源漂移分别提供可恢复入口；
- 受控 returnTo 携带 planId/modelSpecId 并返回原阶段；
- 保留 Chrome 95 和 390px 兼容。

## 页面主动作

```text
保存逻辑设计 → 配置数据实现 → 验证实现 → 生成并发布
```
