## 详细设计

1. MetricWorkbench 从 business object node 改为 model/field anchor；指标引用已发布 FACT/SUMMARY/APPLICATION 和度量字段。
2. 指标包移除 `business_objects` 必填文件和 `businessObjectCode`，改用 modelRef/datasetRef/metricRef。
3. Sprint27 console 读取新的 model/metric projection；不再直接注入 SemanticModelingService。
4. 反转当前锁死旧链的 source-contract：断言对象页面是 redirect、旧 context consumer=0、新菜单无退役词。
5. 删除无消费者 SemanticWorkspaceFrame、SemanticModelingCenterPage、业务对象 helper；迁移/compatibility 文件有明确 sunset owner。
6. `/bi/api/semantic` 通过独立测试保证未被误删。
