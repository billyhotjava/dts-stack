# T04：重算阶段投影与唯一下一步

**优先级**：P0
**状态**：IN_PROGRESS
**依赖**：F2-T02、F2-T03

## 目标与用户结果

无论用户从哪个菜单进入，都能看到同一个当前阻塞和一个下一步；业务对象退役后不会留下指向旧页面的动作。

## 范围与不做

- 范围：九站 StageProjection 的证据、blocker、actionPath 和页面消费。
- 不做：不新增四阶段/六阶段状态机，不根据页面访问记录计算完成度。

## 输入契约

| 证据 | 所有者 | 投影用途 |
|---|---|---|
| 数据连接/来源 | 接入与 WarehousePlan | DATA_CONNECTION/SOURCE_INVENTORY |
| 分类/分层基线 | WarehousePlan | WAREHOUSE_PLANNING |
| 标准绑定 | 标准模块/ModelSpec | DATA_STANDARD |
| ModelSpec | modeling | MODEL_DESIGN |
| artifact/quality/release | modeling/dbt/quality | BUILD_QUALITY_RELEASE |
| asset/metric/service/run | 专业模块 | 后三站 |

## 输出产物

- 每站 StageView；
- currentStage、primaryBlocker、nextAction；
- actionPath 参数白名单；
- 旧 business-object blocker/action 的删除清单。

## 详细设计

1. WAREHOUSE_PLANNING 仅基于分类、策略和来源阶段规则，不再读取对象/过程确认。
2. MODEL_DESIGN 基于至少一个有效 ModelSpec 及其角色门禁；没有模型时指向 `/modeling/models?planId=...`。
3. DATA_STANDARD 指向具体 modelSpec 的字段标准 Tab，而不是低代码向导。
4. DATA_CONNECTION 当前错误路径统一到真实 `/foundation/data-sources`。
5. 工作台显示九站总览和唯一动作；计划详情显示 compact 阻塞/下一步；专业页只显示返回计划链接，不重复旅程条。
6. UNKNOWN/STALE 优先于 COMPLETE，后端证据读取失败不得产生假完成。

## 影响范围

## 异常与权限

- actionPath 只指向用户有权页面；无权限时提供申请/返回，不循环跳转。
- evidence provider 失败时当前站为 UNKNOWN 并提供重试，不写完成状态。
