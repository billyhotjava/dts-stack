# T01: 双栈切换与灰度开关设计

**优先级**: P1
**状态**: READY
**依赖**: F2/T01,F4/T01

## 目标
让新旧会话链路能够短期并行，支持分阶段灰度和快速回滚。

## 技术设计
- 设计 platform cookie session 和旧 portal token 机制的切换开关
- 设计 analytics bearer fallback 和 forward-auth 单通道的切换开关
- 明确配置项、默认值、生效顺序和环境差异
- 规定灰度顺序: 测试环境 -> 预发 -> 小流量生产 -> 全量生产
- 输出切换前后检查项和冻结窗口要求

## 影响范围
- `source/dts-platform/src/main/resources/config/application*.yml`
- `source/dts-analytics/src/main/resources/config/`
- `docker-compose*.yml`
- `services/dts-proxy/`
- `docs/` 或 `worklog/` 下的发布记录

## 验证
- [ ] 每个开关都能独立启停并可观测
- [ ] 灰度环境完成正向切换和回滚演练
- [ ] 切换后核心登录和大屏路径可用

## 完成标准
- [ ] 形成明确的双栈切换说明
- [ ] 开关项可支撑阶段性上线和回退
