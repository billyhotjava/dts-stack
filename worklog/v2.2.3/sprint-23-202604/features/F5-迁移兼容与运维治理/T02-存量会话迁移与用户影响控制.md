# T02: 存量会话迁移与用户影响控制

**优先级**: P1
**状态**: READY
**依赖**: F1/T02,T01

## 目标
明确切换窗口内现有登录用户如何处理，避免上线瞬间出现大规模未知状态。

## 技术设计
- 定义存量 `portal_sessions` 的处理策略: 强制失效重登或按 TTL 自然出清
- 设计前端兼容文案和用户提示，明确何时需要重新登录
- 设计对大屏、驻场页面、无人值守页面的特殊处理流程
- 明确 session 数据迁移时的 SQL、批处理、审计记录要求
- 为值班人员准备用户影响说明和应急 FAQ

## 影响范围
- `source/dts-platform/src/main/resources/config/liquibase/changelog/`
- `source/dts-platform-webapp/src/components/auth/`
- `source/dts-admin-webapp/src/components/auth/`
