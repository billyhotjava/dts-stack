# T01: 多 tab 与跨浏览器会话矩阵验证

**优先级**: P1
**状态**: READY
**依赖**: F2/T03,F3/T03,F4/T03

## 目标
用矩阵化方式验证这次重构是否真正满足“同浏览器多 tab 共存，跨浏览器和跨机器不共存”。

## 技术设计
- 设计至少 9 组场景矩阵，覆盖 Chrome 双 tab、Chrome 双窗口、Chrome 与 Edge、不同机器、无痕窗口等
- 明确每组场景的预期行为、服务端状态、前端提示、日志证据
- 为大屏预览与普通页面分别验证同浏览器并发能力
- 产出标准化验证记录模板，便于后续版本复用
