# T01: 浏览器作用域会话规则定稿

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: 无

## 目标
冻结会话规则，明确同浏览器、跨浏览器、跨机器三类并发语义，避免后续实现阶段再反复改边界。

## 技术设计
- 定义 `portal_session` 为服务端主会话，使用 `HttpOnly + Secure + SameSite` cookie 传递
- 定义 `browser_id` 为浏览器实例标识，由服务端签发并长期保存，同一浏览器的所有 tab 共用
- 定义 `tab_id` 为前端本地诊断标识，仅用于 UI 协调和日志，不参与鉴权
- 约束活跃会话唯一性为 `normalized_username + browser_id`
- 规定新浏览器登录为 takeover 事件，旧浏览器整组 session 失效并收到统一 reason code
- 明确 Keycloak 只负责身份认证，不再承担浏览器端运行时 session 协调
