# T03: 会话状态机与接管语义统一

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
把当前分散在后端 header、前端 toast、redirect、日志里的会话语义统一成一个状态机。

## 技术设计
- 定义核心状态: `ACTIVE`、`IDLE_EXPIRED`、`ABSOLUTE_EXPIRED`、`TAKEN_OVER`、`LOGGED_OUT`、`REVOKED`
- 定义统一 reason code: `session_expired`、`session_taken_over`、`session_idle_timeout`、`session_logged_out`
- 统一 `X-Session-*` header、API 错误体、审计事件、前端提示语之间的映射
- 规定“同浏览器多 tab”不触发冲突提示，只同步会话状态
- 为 takeover 事件定义审计字段和运维日志模板
