# T01：收敛任务级实例查询与深链

**优先级**：P0
**状态**：`IMPLEMENTED_AND_DEPLOYED`
**依赖**：F2/T02 的 ACTIVE revision、owned DAG 与 plan checksum

## 目标

用户只查看当前任务的执行实例，列表、筛选和深链均由 task/execution 业务身份驱动，不暴露任意 Airflow DAG 控制面。

## 技术设计（Contract-first）

- **输入**：`taskId`、`page=0`、`size=10`、可选 `revisionNumber, status, startedFrom, startedTo`、可选 `executionId` 深链。
- **输出**：`executionId, taskId, revisionNumber, planChecksum, destination.assetRef, dagRunId(diagnostic), status, startedAt, finishedAt, sourceExecutionId, qualityEvidenceRef, correlationId`。
- **数据流**：Runs Tab → platform task-scoped proxy → ingestion execution repository/sync → platform DTO。
- **权限**：task/department 服务端过滤；不存在与无权限采用 F0 冻结的防枚举策略。
- **性能**：平台 execution 账本为查询真源；Airflow 用于同步/补偿，禁止逐 DAG 请求 latest run。
- **兼容**：通用 ETL Airflow API 保留为运维接口，但从业务页调用链移除。

## UI 交互规格

- `OrchestrationRunsTab` 接收必填 taskId；URL 采用 `taskId + executionId`。
- 默认查询当前受控 `revisionNumber`，用户显式选择“全部历史版本”时才移除版本范围；两种范围都保持 task-scoped。
- 默认每页 10 条；改变 pageSize 刷新并回到第 1 页。
- 刷新、前进后退、从回填/告警页返回时保留 taskId 和选中实例。
- 空、加载、错误、成功状态不显示其他任务的上次缓存。
- 列表只展示精简质量摘要；实例详情分别展示接入状态、trigger/evidence/quality 状态，并提供按权限控制的目标资产与 workflow/run 深链。
