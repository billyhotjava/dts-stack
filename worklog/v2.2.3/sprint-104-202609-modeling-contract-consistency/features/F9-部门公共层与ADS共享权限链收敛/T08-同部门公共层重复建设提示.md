# T08：同部门公共层重复建设提示

**优先级**：P2
**状态**：DRAFT
**依赖**：T04（部门公共层与可见范围）

## 目标

在同一部门公共层内新建 ODS/DWD/DWS 时，若已有业务过程、来源表集合或粒度键相同的模型，保存设计前提示并给出可打开的已有模型；用户可以忽略并继续保存。

## 使用场景

- **S15**：部门甲已有 DWD“项目任务快照明细”（业务过程=项目任务，来源=`biadmin.public.project_task`，粒度键=`task_id, snapshot_month`）。B 新建 DWD，选择相同业务过程与来源并设置相同粒度键，点“保存设计” → 弹出提示“部门甲公共层已有相似模型”，列出该模型、层级、状态与相同项；B 点“打开”跳到已有模型，或点“仍然保存”继续。
- **不提示**：B 在部门甲新建 ADS；或部门乙存在相同 DWD（跨部门不可见，不提示）。

## 技术设计与契约

- **契约引用**：C78、C80、K76、K85。
- **输入**：`GET /api/modeling/model-specs/similar?planId={UUID}&modelType={FACT|DIMENSION|SUMMARY|SOURCE}&businessProcessId={UUID?}&sourceKeys={string[]}&grainKeys={string[]}`。
- **输出**：`ApiResponse<[{modelSpecId, name, layer, status, matchReasons:["BUSINESS_PROCESS"|"SOURCE_SET"|"GRAIN_KEYS"]}]>`，最多 10 条，按命中项数降序；只含调用者可见的同计划模型，排除当前编辑中的模型与已归档模型。
- **匹配规则**：业务过程 ID 相等；来源集合按规范化 `source/schema/table` 集合相等；粒度键按字段名集合相等（顺序无关）；命中任一项即返回，UI 以命中项数决定提示强度。
- **数据流**：保存设计按钮 → 前端先调 `similar`（超时 2 秒或失败则直接保存，不阻断）→ 有结果弹提示 → 用户选择打开或继续 → 既有保存接口。
- **错误路径**：无角色 403 沿用 T03；计划不可见 404；查询失败不影响保存，只记录前端日志。
- **复用点**：既有模型列表查询与计划可见范围守卫（T04）；不新增索引表。
- **实现方案**：只读查询服务 → 接口 → 前端保存前钩子与提示对话框。

## UI 交互

- 提示对话框：标题“部门公共层已有相似模型”；列表显示名称、层级、状态、相同项标签；按钮“打开”（新标签页打开已有模型工作台）与“仍然保存”（主按钮为“仍然保存”以免阻断）。
- 四态：查询中保存按钮显示加载且不可重复点击；查询失败直接保存；无结果直接保存；有结果显示对话框。

## 影响范围

新只读查询服务与 `ModelSpecResource` 接口；前端保存设计流程与提示组件。

## 验证与验收

- 三类命中各一例；ADS 不提示；跨部门不提示；查询失败不阻断保存；200 个模型的计划中查询耗时记录。
