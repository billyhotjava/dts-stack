# T08：同部门公共层重复建设提示

**优先级**：P2
**状态**：IN_PROGRESS
**类型/责任**：辅助查询与前端提示；平台/前端负责人待排定。
**依赖**：T01 冻结 K85；T04 可见范围与公共层上下文。

## 目标与边界

S15：新建 ODS/DWD/DWS 时提示同部门已有相似模型，支持打开复用或继续保存。T04 保证公共层上下文唯一，本任务减少重复建模，不承诺判定业务语义完全重复、不新增强制唯一规则。

## 设计与实施

- [K85](../../assests/F9-permission-chain-contract.md)：GET `.../model-specs/similar` 入参 planId/modelType/businessProcessId/sourceKeys/grainKeys/可选 excludeModelSpecId；服务端校验当前身份和计划范围、exclude ID 属于同计划，不能绕过 K76。
- 返回 `ApiResponse<[{modelSpecId,name,layer,status,matchReasons}]>`，最多 10 条，按命中数降序并稳定排序；仅可见同部门同计划、公共层、未归档模型，排除当前模型。
- 业务过程 ID 相等、规范来源资产集合相等、粒度字段集合相等；每一项必须双方非空才命中，不把空集合=空集合当重复。不跨部门搜索，也不因缺权限返回他部门计数。
- 保存前调用，2 秒超时或普通查询故障可跳过提示继续走正常保存权限；401/403/404 不当作普通故障忽略，提示权限/身份变化并保留输入。保存接口自身必须重新授权，提示结果不是保存许可。
- 提示列表“打开”“仍然保存”；查询中防重复点击，错误保留输入；ADS 不提示。使用既有查询与索引，不新建相似模型台账。

## 验证与完成标准

- Ready：K85 样例与空值/排除/失败规则冻结，T04 已提供范围查询。
- IT-63：三类非空匹配、空值不匹配、ADS/跨部门不提示、当前模型排除、超时继续保存、身份错误保留输入、200 模型耗时和可见范围。
- Done：接口/组件专项与 Chrome 95 四态留证；不以本任务完成宣称全部门零重复。
- 可独立排期与分批验收；如果调出本期，保留 T08 和 IT-63 原标识并显式同步范围，不静默删掉。
