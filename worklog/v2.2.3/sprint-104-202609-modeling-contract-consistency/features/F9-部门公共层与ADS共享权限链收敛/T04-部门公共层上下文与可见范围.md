# T04：部门公共层上下文与可见范围

**优先级**：P0
**状态**：DRAFT
**依赖**：T01（K74/K76 冻结、测试环境计数）、T03（角色集合）。建模为本版本新增，现场无存量，迁移只建结构

## 目标

每个部门有且只有一个可写公共层；建模人员首次建模自动落到本部门公共层；部门角色只能看到本部门的计划与模型定义，所级角色可按部门切换查看全部。

## 使用场景

- **S01**：部门甲尚无公共层，数据管理员 A 新建 DWD 并保存设计 → 服务端在同一事务内建立部门甲公共层并保存模型；页面不出现规划初始化提示。
- **S01 并发**：部门甲 A、B 同时首次保存 → 只产生一个部门甲公共层，两个模型都归属它。
- **S09**：所级数据管理员 I 在工作台选择“部门乙”后新建模型 → 模型落到部门乙公共层；未选择部门直接保存 → 400 `MODELING_DEPARTMENT_REQUIRED`。
- **S13**：A 调岗到部门乙后重新登录 → 工作台只显示部门乙公共层；通过旧链接打开部门甲模型 → 404。
- **S16**：存量租户默认上下文按 T01 结论归属部门；无法判定时迁移中止并输出清单。

## 技术设计与契约

- **契约引用**：C71、C77、C78、C79、C88、C92、K74、K76、K84；替代 F7 契约 §4/§5 与 `creation-context` 响应。
- **输入**：JWT `dept_code`、角色；`GET /api/modeling/model-specs/creation-context?departmentCode=`；`POST /api/modeling/model-specs/draft-operations` 的可选 `create.departmentCode`。
- **输出**：
  - `creation-context` → `{planId:UUID|null, departmentCode:string, writable:boolean}`；GET 不初始化。
  - 首次保存：部门公共层幂等键 `modeling-context:dept:{deptCode}:v1`，锁 `modeling-context:{tenant}:{deptCode}`，与模型保存同事务；审计 `MODELING_CONTEXT_DEPARTMENT_INITIALIZED`。
  - 计划列表/详情、模型列表/详情：所级角色全部；部门角色 `owner_department_id` 与 JWT 部门匹配；不可见返回 404。
  - 迁移：`modeling_warehouse_plan` 部分唯一索引 `(tenant_id, owner_department_id) where lifecycle_status <> 'ARCHIVED'`；changeSet 前置条件为预检 SQL 结果为 0，否则 HALT 并输出重复/无部门清单；租户默认记录的幂等键改为其部门键。现场无建模存量（C92），本迁移实际在空表或测试环境少量数据上执行，不设计跨部门归并方案。
- **数据流**：工作台打开 → `creation-context`（部门角色取 JWT 部门；所级角色取所选部门）→ 保存 → `ModelingContextInitializationService` 按部门查找或加锁创建 → `WarehousePlanApplicationService.create` → 模型保存 → 审计。
- **错误路径**：部门角色传入他部门 403 `MODELING_DEPARTMENT_SCOPE_DENIED`；JWT 无部门 403 `MODELING_DEPARTMENT_UNRESOLVED`；所级角色未选部门 400 `MODELING_DEPARTMENT_REQUIRED`；部门公共层已归档 409 沿用只读错误；初始化任一步失败整体回滚。
- **复用点**：F7 的事务锁、失败回滚与 `creation-context` 只读语义；`WarehousePlanAuthorizationGuard` 作为可见范围唯一判定点，`DepartmentUtils.matches` 作为部门匹配。
- **实现方案**：初始化服务改为部门键 → `creation-context` 扩展参数与响应 → 可见范围守卫按角色与部门判定并替换恒真逻辑 → 模型列表按可见计划过滤 → 迁移预检与部分唯一索引 → 前端工作台加部门选择（仅所级角色）。

## UI 交互

- 部门角色：工作台标题右侧显示“公共层：{部门名称}”，不可切换。
- 所级角色：显示部门下拉，默认为上次选择（本地记忆，失败时为空并要求选择）；切换部门刷新列表，未保存编辑时沿用既有离开保护。
- 四态：部门无模型显示“新建模型”；加载保留当前部门；读取失败显示重试且不清空部门选择；无部门声明显示“账号未配置部门，请联系授权管理员”。
