## 目标与边界

部门数据管理员/领导在本部门公共层共同维护 ODS/DWD/DWS；所级角色可选部门管理。ADS 归稳定创建人，同部门他人默认只读，可共享编辑权，部门领导与所级保留管理权。普通员工只消费既有授权资产与大屏；模型编辑权不产生数据访问权或审核权。

每部门一个稳定公共层上下文，通过相似模型提示减少重复建设；不把提示等同于业务模型绝对唯一。任何用户入口不能降低资产密级。跨部门引用及 ADS 编辑共享在审核建设前暂停，包括所级通过目录表/dbt 等形式引用其他部门受治理产出的路径。

复用既有计划、模型、草稿、资产身份、来源解析/血缘、发布状态机、目录、审计和大屏。建模现场无存量；目录、角色/菜单、门户会话与大屏是既有功能。F9 不新增菜单/页面、权限配置平台或平行资产台账，不修改大屏 ACL/密级/越级规则。

## 完整权限设计

```text
权威身份（ID、启停、角色、部门、人员密级） → 建模请求内当前上下文
  ├─ 角色能力 × 租户/部门范围 × ADS 对象权 × 动作职责 × 状态/版本
  ├─ 来源/数据访问与密级（独立判定，不由 EDITOR 放行）
  └─ 实际批量范围 / USER 后台重新授权 / SYSTEM 已部署绑定
结果 → allowedActions 与明确错误 → 审计
菜单只作导航；大屏例外只在既有展示出口生效。
```

技术上仍在现有平台/目录/会话扩展点集中复用判定，不建设第二套权限服务。为避免影响其他产品，门户会话保留旧 sub/username，新增稳定身份只供 F9 使用；当前属性复核只作用建模受保护边界，非建模入口进行兼容回归。

## 端到端路径与 UI

工作台沿用 `/data-modeling/dimensions/workbench`；资产编辑沿用目录/数据集详情页。

```text
模型工作台     公共层：[部门甲 ▼]     [新建模型]
名称          层级    归属       我的权限
项目明细      DWD     部门公共层 可编辑
项目月报      ADS     张三       只读（编辑需授权）

ADS 工具栏 [共享] （仅 canManage）
成员：搜索本部门有效建模用户/部门级角色 → 添加/撤销
固定管理权：本部门领导、所级角色
[申请跨部门共享（待开放）]

上游选择器：仅返回本次可见候选
[申请跨部门引用（待开放）] （通用禁用入口，不绑定隐藏目标）
```

- 部门角色不可切换；所级/兼容管理角色选择有效部门，不伪装成该部门人员。未选择时不得新建，切换遵守未保存离开保护。
- 共享抽屉空/加载/错误/成功与权限变化均有反馈；非管理员不返回授权名单。撤销提交后下一次写入拒绝，输入保留。
- 401 要求重新登录、403 提示无能力/编辑权、不可见 404、目录依赖故障 503；不把 503 展示为“没有数据”或允许继续写入。允许动作来自服务端。
- 密级只列不低于当前值；降级拒绝恢复当前密级并保留其他输入。帮助放既有右上角入口。
- Chrome 95、1366×768、键盘可达；所有具名控件覆盖空、加载、错误、成功与无权限状态。

主走查：A 首次保存 DWD → B 同部门维护 → A 创建 ADS → B 只读 → A 授权 → B 编辑/运行其有权范围 → 撤销后旧页面保存拒绝 → D 不见他部门模型 → 所级 I 能管理但不能跨部门引用 → 普通员工不能建模 → 降密级拒绝 → 大屏既有越级消费不扩散。详细正反向场景见 S01–S26。

## 数据、错误与迁移约束

- 真正业务 owner、操作人、授权对象均使用明确身份语义；服务端按 stable ID 与当前权威属性处理，不能信任前端给出的 actor/角色/部门。
- 计划/模型不可见优先 404；已知可见但无写权 403；可见跨部门引用 422；CAS/密级/公共层状态冲突 409。批量拒绝不产生新执行；错误不能泄露隐藏目标。
- 前向迁移包括会话稳定 ID、计划规范部门/唯一约束、模型稳定 owner、授权表、审计字典；测试预检未知 ID/部门/重复时 HALT。模型现场无存量，不重写历史修订或删除产出。
- 构建/编译型测试在 /data/dts-stack 经 Git 同步后执行；部署由正式部署目录管理；本轮已执行统一源码测试和前端构建，正式包与部署未执行。
