# T01：权限链基线与契约冻结

**优先级**：P0
**状态**：DRAFT
**类型/责任**：架构与测试设计；主代理维护本轮文档，实施负责人/容量待排定。
**依赖**：既有产品决策、当前源码与可用的只读证据；现场访问只阻塞对应现场采集项。

## 目标与输出

将 [K73–K92](../../assests/F9-permission-chain-contract.md) 按消费依赖分组冻结，产出 `assests/F9-baseline-{日期}.md` 和接口/调用覆盖矩阵，使开发 Task 的输入充分。当前文档完善不等于本任务执行完成。

## 工作内容

1. 复用 C71–C100；记录源码 SHA。测试库只采计划/部门/旧上下文/来源/pin/ADS r1 创建人计数；现场建模无存量，不设计归并。现场目录历史降级、角色菜单和既有会话画像单列，未访问标 NOT_RUN。
2. **优先冻结密级子集**：全部用户写 classification 的入口、K78、审计字典、事务/CAS与空值错误；输出供 T02 使用，不等待 Q5 历史恢复决定。
3. **身份与角色子集**：核对已认证登录可取得的稳定目录 ID、现有会话实体扩展位置、旧会话拒绝策略、opadmin 实时目录依赖与既有恢复边界、K86 精确 ID 查询和启停/角色/部门/人员密级字段、2 秒超时及当前身份进入方法准入的扩展点。按 K90 固定平台与 admin 维护/审核/执行矩阵，不从 MODEL_AUTHORS 推导全部职责。
4. **资源与操作子集**：权威部门规范编码与 K92 精确比较；K91 创建/转移/整体归档/只读重试的正常与异常路径；四类来源到既有规范资产/血缘的映射（Q10）。不得用 DepartmentUtils.matches 或新增平行解析器。
5. 固定 K88/K89 调用表：每个 API、service、批量候选、导入、幂等重放、worker、调度、回调的认证主体、实际读/写/执行集、职责、K75/K81 落点、错误/审计、测试编号。C76“约 23 处”仅为起点，不能当完整清单；含 PlanExecutionBinding、PlanOperationalRun、quality、serving 和类型转换。
6. 冻结 K79/K80 稳定身份、授权 CRUD、候选人搜索、授权管理与编辑差异、撤销并发、调岗/停用、模型生命周期及批量范围。K76 不可见统一 404；K77 仅对可见违规上游回 422，响应不能枚举目标。
7. 每组给出请求/响应/错误样例、迁移预检与测试夹具；[IT-55–IT-63](../../it/F9-权限链验收.md) 中 S01–S26 的期望值均有契约来源。可写入设计样例，不得把样例写成运行证据。

## Ready 与完成标准

- Ready：产品问题、方案、源码入口明确；只读访问缺口按受影响采集项记录。
- Done：各契约分组有冻结记录/版本/证据和消费 Task；调用矩阵、错误样例、迁移预检与用例映射齐全。
- 现场未采集项保留 GAP 和具体后续责任，不以测试环境替代；Q5 可转跟踪项，但不能据此解除现场历史风险结论的限制。
- 验证映射 IT-55；本任务是设计与基线，不要求运行所有 Feature 页面后才能交付设计。
