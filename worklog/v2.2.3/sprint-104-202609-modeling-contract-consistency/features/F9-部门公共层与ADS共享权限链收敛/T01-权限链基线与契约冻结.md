# T01：权限链基线与契约冻结

**优先级**：P0
**状态**：DRAFT
**依赖**：无；复用 C71–C88，不重复全仓勘察

## 目标

关闭剩余开放问题 Q5，把 K73–K86 从拟定改为 FROZEN，并取得测试环境只读基线与现场在用角色画像，使 T02–T08 可以按确定的角色集合、错误码与迁移规则开工。Q1–Q4、Q6、Q7 已于 2026-09-12 关闭。

## 使用场景

本任务不改变用户行为，产出的是 S01–S16 的前置条件：每个场景的角色账号、样例数据、期望请求/响应与迁移前计数都在本任务固定。

## 技术设计与契约

- **契约引用**：D1–D9、功能新旧与存量边界、C71–C92、K73–K86、Q1–Q7，见 [F9 权限链契约](../../assests/F9-permission-chain-contract.md)。
- **存量前提**：建模（计划、模型、ADS）为本版本新增，现场无存量（C92），本任务不采集现场建模数据，也不设计跨部门归并方案；大屏与资产目录为既有功能，其存量仍在采集范围内。
- **通用契约**：见 [任务通用契约](README.md#任务通用契约)。
- **输入**：开发目录 HEAD、客户现场与测试环境只读数据库访问、dts-admin 角色与菜单配置、审计日志。
- **输出**：
  1. 契约文件第 6 节逐条标 FROZEN，补齐每个接口的请求/响应/错误 JSON 样例。
  2. 契约文件第 7 节 Q1–Q7 写入用户确认结论或测试确认事实。
  3. `assests/F9-baseline-{日期}.md`：测试环境只读计数，加现场既有功能（目录密级、角色与菜单绑定）画像。
  4. `it/F9-权限链验收.md` 中 IT-55–IT-63 的账号、样例与期望值。
- **只读采集项**：

| 项 | 查询口径 | 用途 |
|---|---|---|
| 每部门计划数（仅测试环境） | `modeling_warehouse_plan` 按 `tenant_id, owner_department_id, lifecycle_status` 分组 | T04 部分唯一约束预检 |
| 无部门计划 | `owner_department_id is null` | T04 迁移中止清单 |
| 租户默认上下文 | `idempotency_key = 'modeling-context:default:v1'` 或旧 `modeling-context:` 前缀 | T04 迁移归属 |
| 模型按层与部门分布 | 模型 join 计划，按 `layer, owner_department_id` | T05/T06 影响面 |
| 跨部门存量引用 | `depends_on`、`dimension_refs` 展开后上下游计划部门不同 | T05 存量保留清单 |
| ADS 创建人 | APPLICATION 模型 r1 `created_by` 为空的数量 | T06 回填可行性 |
| 历史降密级（现场，既有功能） | `CATALOG_ASSET_EDIT` 审计前后快照中 classification 下降的记录 | T02 Q5 清单 |
| 角色人数与菜单绑定（现场，既有功能） | dts-admin 用户角色分配；`portal_menu_visibility` 建模菜单角色码 | T03 收紧影响 |
| 大屏密级派生（已核实，仅补样例） | 大屏引用数据集密级与大屏密级对比，确认取最大值（C89） | T07/T09 走查 |

- **错误路径**：现场不可访问时只标 NOT_RUN 并注明影响任务；既有功能的现场结论不得用测试环境替代，建模侧则明确记为“本版本新增、无现场存量”。
- **复用点**：只读 SQL 在 `default_transaction_read_only = on` 会话执行；不写任何业务表。
- **实现方案**：Q1–Q4、Q6、Q7 已确认并写入契约，本任务只执行 Q5 扫描、补齐 K73–K86 的请求/响应样例，并冻结 C76 中切换到模型级判定的调用清单 复用入口（目录授权创建时解析被授权人部门的服务端代码位置补入账本 C89 起）。
