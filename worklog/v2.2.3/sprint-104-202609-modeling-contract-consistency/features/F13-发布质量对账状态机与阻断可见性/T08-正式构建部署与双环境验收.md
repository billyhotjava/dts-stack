## 技术设计

- **构建**：开发目录 commit & push → `/data/dts-stack` `git pull --ff-only`，核对 SHA → `builds/dts-build.sh --image dts-platform dts-platform-webapp` → 记录镜像 ID/digest。禁止容器内补丁、`docker cp`、开发目录挂载。
- **迁移**：确认 `20260924_01_release_quality_reconcile_state.xml` 在两套环境都执行（`databasechangelog` 记录）。
- **部署**：
  - 本机：按部署目录正式 compose 流程更新 `dts-platform`、`dts-platform-webapp`。
  - openEuler：**须用户单独确认**后，经 Windows 中转上传交付包，按 `bin/dts-upgrade-lite` 升级；长任务 `setsid nohup` 后台执行。
- **一致性记录**：两套环境的提交 SHA、镜像 digest、迁移记录、交付包校验和写入 `it/F13-发布质量对账验收.md` 头部。
- **回退**：新表只增不改；回退即部署上一版镜像，状态表保留不影响旧版（旧版不读此表）。回退演练在本机执行一次。
