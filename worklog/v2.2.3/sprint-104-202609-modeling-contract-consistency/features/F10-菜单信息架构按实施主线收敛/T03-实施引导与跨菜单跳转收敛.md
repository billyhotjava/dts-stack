# T03：实施引导与跨菜单跳转收敛

**优先级**：P1
**状态**：IN_PROGRESS
**依赖**：T01 冻结 K100、K101；可与 T02 并行

## 目标

工作台实施引导与菜单顺序一致；模型构建完成后配置质量只需一次跨菜单直达，并能一次返回原模型；其余跨菜单链接都直达目标对象。

## 使用场景

- 新用户按工作台引导实施：先到数仓规划，再到数据集成，与菜单顺序一致。
- 数据管理员在模型工作台完成构建，点“配置质量规则”，直接进入该资产的数据运维面板，质量配置已展开，焦点在规则区。
- 质量不通过时，在面板上点“返回模型”回到原模型；修改并重新构建后，再点一次“配置质量规则”回到同一资产。
- 资产尚未登记时，点入口看到“资产登记完成后可配置质量”，不会落到空白页。

## 技术设计与契约

- **契约引用**：C113、C118、C120–C124；K100、K101；契约第 6、7 节。
- **实施引导（K100）**：
  - `webapp/components/journey/journeyContext.ts`：阶段顺序改为 规划、标准、集成、建模、指标、开发、服务、证据；只调整相邻阶段的 `nextRoute` 与 `nextLabel`，各阶段 `currentRoute`、上下文参数、证据路由不变。
  - `webapp/components/journey/journeyStageState.ts`：规划阶段不再以“缺少数据源”为门槛，改为“缺少主题域或分层”；集成阶段文案改为“规划已就绪，接入业务表来源”。
  - `webapp/pages/workbench/DataManagementWorkbenchPage.tsx`：引导文案与按钮顺序改为 规划、标准、集成、建模、指标、开发、服务。
- **质量直达（K101）**：
  - `webapp/pages/data-modeling/prototype/ModelAssetDeliveryResult.tsx`：资产入口由数据集详情首页改为资产目录的数据运维面板，携带模型标识、资产标识与展开质量配置参数（参数名以 T01 冻结为准），并附带返回原模型的 `returnTo`。
  - `webapp/pages/catalog/DataSearchPage.tsx` 与 `webapp/pages/catalog/assets/ModelDataOperationsPanel.tsx`：读取展开参数后自动打开质量配置并聚焦；显示“返回模型”入口，地址经既有 `returnTo` 清洗规则校验，只允许回到建模工作台。
  - 资产未登记（`QUALITY_DATASET_REGISTRATION_MISSING`）、无维护权限、资产不存在三种情况分别给出提示，不自动跳到其他菜单。
- **链接核对**：按契约第 6 节逐条核对 C124 中已有的跨菜单链接，凡落到菜单首页或需再次查找的，改为带对象标识直达；核对结果写入实施记录。
- **复用点**：复用资产侧已有质量配置面板与打开请求机制（C122），不新增质量入口或页面。
- **错误路径**：`returnTo` 非法时不显示返回按钮；参数缺失时按普通资产目录打开，不报错。

## UI 交互

- 按钮文字保持“配置质量规则”；目标面板加载中显示骨架，成功后展开质量区并聚焦名称输入框。
- “返回模型”位于面板标题右侧，键盘可达。
- Chrome 95、1366×768 下不截断、不遮挡。
