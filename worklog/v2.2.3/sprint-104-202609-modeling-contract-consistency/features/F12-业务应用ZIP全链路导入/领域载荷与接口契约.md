# F12 领域载荷与接口契约

版本：v1设计基线，2026-09-22。本文规定新增导入协议；已有普通创建API不能直接视为具备幂等、CAS或暂存能力。T03–T06必须用契约测试落实适配，不直接跨库写数据。

## 当前代码证据与适配边界

| 领域 | 已有入口/代码 | 新增适配要求 |
|---|---|---|
| 模型 | ModelSpecImportPreviewService、Apply服务 | 保留inspectionProof、模型/实现pins；T08补有效代际和重置 |
| 查询数据集 | analyticsApi.createSemanticVirtualDataset；/bi/api/semantic/virtual-datasets | v1 QUERY_DATASET明确为分析侧语义虚拟数据集，不是ODS目录表或dbt模型；绑定目标语义模型，增加领域导入幂等/CAS |
| 卡片 | CardResource.create/update；/bi/api/card | 当前创建要求dataset_query.database且计算结果元数据；上游未就绪时不得直接调用，新增引用转换及幂等/CAS命令 |

前端路由只是现有消费证据，不作为编排器跨服务公开API。新增领域端口 `previewImport/executeImport/getOperation/retireImported` 在各领域内部封装现有服务；如现有写接口没有原子CAS，必须在领域事务中补齐，不能用GET后PUT假装无并发冲突。

## 公共载荷规范

UTF-8 JSON，拒绝重复键及未知schemaVersion。标识localKey为ASCII `[A-Za-z][A-Za-z0-9_.:-]{0,127}`；kind枚举固定，名称1–128字符，描述最多4000字符。业务配置JSON采用指定schema白名单，不能承载任意脚本。v1每种载荷均带schemaVersion、name、description、references；禁止目标租户、用户、连接密码和原环境ID参与写入。

Ref = `{localKey, kind}` 或 `{requireKey, kind}`，二者互斥；前者必须出现在objects中，后者必须出现在requires中。外部依赖用requireKey:string、kind、stableCode、versionConstraint（v1仅精确版本或CURRENT）表示；CURRENT在preview解析并固定到具体版本，apply再校验。每个引用均可定位fieldPath（JSON Pointer），替换只发生于schema声明位置，不对SQL/JSON全文做字符串替换。

contentChecksum：SHA256，对该对象载荷执行RFC8785规范化；字符串不隐式trim、数组顺序保留、拒绝非有限数字。文件sha256计算原始字节；模型项校验和使用现有规范化模型契约。源码ZIP hash与业务内容hash不同，ZIP重压不应引发业务UPDATE。packageVersion为SemVer，旧schema不支持时拒绝并返回支持列表，版本升级通过显式迁移器，不能猜测字段。

## 各类对象

| kind / payloadSchemaVersion | 必需字段 | 可选字段及约束 |
|---|---|---|
| MODEL / dts.dbt-model-ref/v1 | manifest对象中的dbtUniqueId:string、payloadPath=`models/dbt-project.zip` | manifest对象payloadPath指向同一嵌套ZIP，dbtUniqueId必须唯一对应其中业务模型；模型详情沿用已有dbt契约，技术节点只作为依赖随包保存 |
| QUERY_DATASET / dts.query-dataset/v1 | baseModel:Ref(MODEL)、query:{dimensions:FieldRef[],measures:MeasureRef[],filters:Filter[],orderBy:Order[],limit:int} | parameters:Parameter[]；仅语义查询，v1不支持任意原生SQL，遇到原生SQL导出明确报不支持，禁止静默丢失 |
| CARD / dts.analysis-card/v1 | dataset:Ref(QUERY_DATASET)、display:string、visualization:object | parameterBindings、description；display及visualization必须通过目标版本已注册图表schema，未知图表阻断 |
| SCREEN / dts.screen/v1 | canvas:{width:int,height:int}、components:Component[] | backgroundResource:ResourceRef、theme:object、filters、interactions；使用目标ScreenSpec schema校验，不能直接导入未验证spec |

FieldRef=`{model:Ref(MODEL),fieldCode:string}`；MeasureRef=`{field:FieldRef,aggregation:SUM|COUNT|COUNT_DISTINCT|AVG|MIN|MAX}`；Filter=`{field,op:EQ|NE|GT|GE|LT|LE|IN|BETWEEN|IS_NULL,value?:JSON,parameterKey?:string}`，值与参数互斥，按op校验元数/类型；Order=`{field,direction:ASC|DESC}`；limit为1–10000。跨模型关系必须是已确认语义关系，v1不接受任意join SQL。字段不存在、聚合不兼容、关系不唯一均预览阻断。

Parameter=`{key:string,type:STRING|NUMBER|BOOLEAN|DATE|DATETIME,required:boolean,default?:JSON}`；日期ISO8601、时区显式沿用目标工作区，参数仅绑定值、不拼接标识符。parameterBindings为对象局部参数key到数据集参数key的映射，类型必须一致。

Component=`{key:string,type:CARD|TEXT|IMAGE,frame:{x:number,y:number,width:number,height:number},card?:Ref(CARD),resource?:ResourceRef,text?:string,settings?:object}`；坐标非负且在canvas内，尺寸为正；按type恰好一个内容字段。v1仅支持这三类组件，其他组件由导出预检查列出并阻断完整包导出，不能声称无损支持所有大屏。过滤器/联动使用组件key、参数key和FieldRef；只允许已注册的filter/drill动作，不导入任意URL跳转或脚本。

ResourceRef=`{path:string,sha256:string}`，path必须出现在manifest.files。首版允许PNG/JPEG/WebP，按实际文件头验证、单张≤10MiB且宽高≤8192，禁止SVG/HTML/JS/字体和外部URL自动下载。相同hash只可在同租户权限范围去重；导入者确认具有使用权。资源由领域服务存储并返回目标resourceId/受控URL，包中路径不可直接作为网页URL。

## manifest最小范例

```json
{
  "schemaVersion":"dts.application-package/v1",
  "packageId":"74221ed4-41a0-4d18-a9eb-f173448ef938",
  "packageVersion":"1.0.0",
  "objects":[
    {"localKey":"budget.model","kind":"MODEL","payloadPath":"models/dbt-project.zip","payloadSchemaVersion":"dts.dbt-model-ref/v1","dbtUniqueId":"model.pm_analytics_v3.biz_ads_budget_kpi_v2","dependsOn":[],"contentChecksum":"<64位小写十六进制>"},
    {"localKey":"budget.dataset","kind":"QUERY_DATASET","payloadPath":"datasets/budget.json","payloadSchemaVersion":"dts.query-dataset/v1","dependsOn":["budget.model"],"contentChecksum":"<64位小写十六进制>"}
  ],
  "files":[
    {"path":"models/dbt-project.zip","size":1,"sha256":"<实际文件hash>"},
    {"path":"datasets/budget.json","size":1,"sha256":"<实际文件hash>"}
  ],
  "requires":[]
}
```

范例为结构说明，size/hash占位不能作为验收包。T03必须交付真实可校验的完整夹具及机器可执行JSON Schema；任何依赖和references推导出的边必须与dependsOn一致，否则拒绝。一个完整包的业务模型依赖必须全部列入objects或requires；嵌套ZIP内隐式补入业务模型须先规范化展示并获得选择确认。

## 领域命令与权限

ImportCommand必需：operationKey:string、actorContextRef（服务器生成）、targetContextId、identity:{packageId,kind,localKey,generation}、action:CREATE|UPDATE|REUSE、payload、resolvedReferences[]、expectedTargetPin（UPDATE/REUSE必需）、confirmedGovernance。TargetPin={targetId:string,revision:string,checksum:string}，不强迫所有领域使用同一版本类型。

返回 OperationReceipt={operationKey,status:SUCCEEDED|BLOCKED|FAILED,targetPin?,dependencyPins[],error?}。同键同请求返回原回执；同键异请求409；创建对象与成功回执必须同领域事务。GET operationKey可确认超时结果。REUSE也验权限和pin。服务间使用现有可信身份传播，不复用浏览器Cookie到后台作业，不向调用者泄露不可见对象详情。

治理包含目标部门、数据域、工作区/集合的显式映射及密级；owner由当前执行者和领域规则决定。卡片/大屏有效密级不得低于依赖最大密级；整包设置只能提高或保持，不能降级绕过治理。公开链接、共享授权、原owner和角色绑定不随包迁移。发布、物化、对外共享均为独立用户动作，导入不自动执行。

错误码基线：PACKAGE_SCHEMA_UNSUPPORTED、REFERENCE_UNRESOLVED、FIELD_MAPPING_INVALID、TARGET_VERSION_CONFLICT、PERMISSION_DENIED、UPSTREAM_NOT_READY、RESOURCE_UNSUPPORTED、RESET_REQUIRED。统一响应带fieldPath/localKey、影响项、中文建议和correlationId；领域原始码保留于折叠诊断，不作为主要页面提示。
