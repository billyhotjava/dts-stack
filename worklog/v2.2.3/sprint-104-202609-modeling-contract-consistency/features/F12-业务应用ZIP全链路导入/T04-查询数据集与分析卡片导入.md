## 原 DoR 缺口（历史发现，修订结果见文末）

按[目标契约实测对照](领域载荷与接口契约.md#目标契约实测对照2026-09-22-源码核对)，本任务**未通过 Definition of Ready，保持 DRAFT**，缺口逐项点名：

1. **聚合表达无处落位**：v1 `MeasureRef{field,aggregation}` 与目标 `SemanticQueryBody.measures:string[]`（`source/dts-platform-webapp/src/analytics/api/analyticsApi.ts:186`）不同构，目标只接受语义层已注册度量 id。须先决定：改为引用已注册度量（不支持的聚合导出期阻断），还是在导入期创建度量（涉及 F6 口径，范围扩大）。
2. **参数落点未定**：v1 `parameters:Parameter[]` 在目标 `SemanticQueryBody` 中无对应字段。须确认落到 `globalVariables`、调用期传参，还是 v1 不支持。未定前该字段不得进入 T03 的 JSON Schema。
3. **卡片 database 解析路径缺失**：`CardResource` 创建强制 `dataset_query.database`（`source/dts-analytics/.../CardResource.java:184`–`:186`），即卡片绑定数据库 id 而非数据集 id。须补"QUERY_DATASET 目标对象 → 其底层 database + 已保存查询体"的解析接口；该接口当前不存在。
4. **未覆盖的目标能力**：`indicatorRefs`、`timeRange`、`derived_metrics`、`joins`、`dimensions.granularity`、`filters.value_to` 在 v1 中均无对应。须逐项标注 v1 支持/阻断，不得留白。
5. **字段改名**：v1 `visualization` → 目标 `visualization_settings`；v1 `orderBy` → 目标 `order_by`。映射层显式转换。

上述 1–4 解决并回写载荷契约后方可转 READY。转 READY 时须附字段级映射表（v1 字段 → 目标字段 → 转换规则 → 不支持时的阻断码）。
