## 环境、数据和判定

- 编码/测试阶段另行开始后，按仓库正式流程从 `/data/dts-stack` 的已拉取 SHA 构建测试；正式部署环境执行真实页面用例。本轮不创建夹具、不启动环境、不执行用例。
- 真实服务包括平台、分析、数据库、资源存储和授权；除显式故障注入外不得 mock 领域写入、权限或查询。浏览器和 API 双向核对；“HTTP 200”不等于业务成功。
- 账号分为导入者、同部门编辑者、异部门无权者；服务身份另行配置。凭据不入包、文档、截图或日志。使用隔离规划与命名空间，不改现有用户数据。
- 每个用例保留受测 SHA、正式制品/镜像、包 SHA256、租户部门/角色、基线对象和来源清单、操作时间、run/reset/operation ID、预期与实际、PASS/FAIL/BLOCKED/NOT_RUN、证据路径及缺陷号。缺环境/夹具记 BLOCKED，不能跳过后记 PASS。
- 清理统一通过领域受控退役/重置或隔离测试环境恢复快照，保留审计；清理未实现时保留带归属的测试数据并登记，禁止 SQL 直删/禁触发器/删 ODS。每例核对包外对象及来源基线不变；故障例恢复网络、worker、时钟和开关。
