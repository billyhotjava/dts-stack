# F12 测试与验收设计

所有全链路用例初始 NOT_RUN；本轮模型代码验证单独记录，不替代真实用户验收。样本：仓库 PJM 原包（43 业务模型、10 ODS）、专利纯维度包、100 模型批量夹具、完整包（2 模型、1 查询数据集、2 卡片、1 大屏、2 静态资源）。不得为通过测试直接改业务库确认状态。

| 编号 | 场景/执行层 | 预期及证据 |
|---|---|---|
| F12-IT-01 | 无模型首次导入 PJM/真实页面 | 当前环境直接登记10来源、映射、43模型草稿成功；记录runId/ID与数量 |
| F12-IT-02 | 100模型统一配置/组件+浏览器 | 常量次数配置；字段/粒度保留；单项覆盖、恢复继承、取消/全选正确 |
| F12-IT-03 | 返回上一步、切换环境、重新上传/组件 | 返回保留选择与配置；切换撤销旧来源/规划ID；重传无残留 |
| F12-IT-04 | 来源同名不同库、过期、不可见/服务+页面 | 歧义不自动匹配；无权/过期明确提示；手动映射不被建议覆盖 |
| F12-IT-05 | 旧模型包、完整包往返/契约+集成 | 兼容旧proof/hash；导出→导入规范化内容和引用一致 |
| F12-IT-06 | 依赖顺序与跨环境ID/集成 | 每条卡片/大屏引用指向目标ID和精确版本，无原环境残留 |
| F12-IT-07 | 草稿成功但未物化/真实页面 | WAITING_UPSTREAM明确；物化与数据集发布后才READY并能查询 |
| F12-IT-08 | 重复apply、超时、进程中断/故障注入 | 幂等不重复、可恢复日志，刷新继续、成功项不重建 |
| F12-IT-09 | 冲突和并发编辑/集成 | expectedRevision失败无覆盖；更新/复用/跳过影响范围明确 |
| F12-IT-10 | 部分失败和前向撤销/集成 | 只补偿本次可撤销对象，保护复用/ODS及他人新修订 |
| F12-IT-11 | ZIP越界、炸弹、恶意资源/安全 | 检查阶段拒绝、无对象写入和宏执行，不泄露凭据 |
| F12-IT-12 | 部门隔离、撤权、后台恢复/权限 | 按当前身份重新验权，批量无越权，日志归属完整 |
| F12-IT-13 | 1366/768、Chrome95/浏览器 | 无白屏、遮挡、控件裁切，中文错误与根因聚合 |
| F12-IT-14 | 100+20+3性能/负载 | 符合契约预算，记录机器、数据量、P50/P95/失败率 |
| F12-IT-15 | 在线/离线包一致性与恢复/运维 | SHA、image ID、包校验和一致，无现场补丁；回退演练有结果 |

准入：明确受测SHA、正式制品、目标租户/部门、操作权限、测试对象归属及恢复路径；ODS只读核对。现有用户数据不得被夹具覆盖。单测覆盖合并优先级/依赖图/身份映射/幂等；组件测向导状态；集成测领域适配器及故障恢复；真实页面测完整业务效果。

完成口径分别报告源码测试、正式构建/交付包、容器部署、真实账号页面、数据查询及恢复证据。任一必要项未执行，Feature 不标 DONE。密码与token仅会话使用，不进入截图、文档或仓库。
