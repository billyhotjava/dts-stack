# F12 业务应用 ZIP 全链路导入

- 优先级：P1。状态：IN_PROGRESS（建模首切片）；全链路实现尚未开始。
- 需求依据：2026-09-21 用户要求先闭合 PJM ZIP 建模，再以一个 ZIP 导入模型、分析卡片和数据大屏；100 个模型不得逐个重复设置。
- 本次文档交付：功能、架构/契约草案、任务、验收设计。2026-09-22已补齐重置、身份、领域载荷及恢复设计；文档完成不等于全链路 Feature DONE。
- 业务中心在本需求中明确指“业务过程”，不等同于数据集市、主题域。

## 目标与范围

数据实施人员在一个向导里完成“包识别 → 整包配置 → 来源登记和映射 → 依赖与冲突预览 → 创建草稿 → 跟踪就绪”。同一包内可含模型、查询数据集定义、分析卡片、大屏及静态资源。纯模型 ZIP 保持可用。100 个模型共享配置一次，单项覆盖显式保留。来源登记独立于模型存在，不要求先创建占位模型。

依赖顺序：ODS 来源 → 模型/实现 → 物理资产和可查询数据集 → 分析卡片 → 数据大屏。资产采集完成、模型草稿创建、模型物化成功、查询数据集发布和大屏可用是不同事实，不得混用。

本期分片：A 建模导入闭环；B 模型与查询数据集、卡片导入；C 卡片与大屏全链路及恢复。先 A 后 B/C；当前授权仅 review/完善文档和单元、系统测试用例，不编码、不执行测试。全链路导出器列入 T03，避免仅有手工包而无可验证生产者。

不包含：业务明细数据搬迁、自动执行包内 ODS DROP/DDL、替换 dbt 引擎、导入任意脚本/插件、跳过权限与安全确认、上传后自动发布或物化。

## 用户流程与界面

1. 沿用逆向建模入口，识别纯模型包或业务应用包；大屏入口后续可进入同一向导并预选范围，保留大屏一级菜单。
2. 展示各对象数量、依赖图和包兼容性；明确区分“包结构通过”与“目标环境就绪”。
3. 选择建模环境，整包设置数据域、业务过程；应用表统一设置数据集市和主题域；用户明确确认发布密级。默认全选可导入模型，保留取消全选和逐项选择。
4. 单个模型修改后标记自定义，不被整包修改覆盖；恢复继承后使用当前整包值。整包不覆盖业务名称、字段口径、粒度等对象固有定义。切换环境清除原环境来源和规划归属，保留包内容。
5. 在本页登记已存在 ODS 资产并确认版本，立即刷新来源选项。按表名建议只接受唯一且可见的已确认匹配，同名多库不得猜测；不覆盖手动映射。
6. 预览创建/更新/复用/跳过/阻断项。按根因合并来源问题，显示受影响对象，不把 1 个根因重复输出 100 行。依赖缺失必须解决或明确排除整个依赖分支。
7. 显式确认后创建模型草稿；分析对象上游未就绪时暂存并显示数量，不能算已创建。物化由用户触发，领域事实就绪且授权有效后继续处理下游；刷新可恢复运行。
8. 结果页/导入历史提供“重置本次新建对象”，预览影响范围、引用及保留项；保留审计，成功后同一规划可重新上传同包并生成新模型ID。失败或部分失败不得称已清空。

空、加载、无权限、无可用来源、结构变化、同名冲突、部分失败、恢复中、完成分别有中文状态。按钮不因加载抖动；1366×768 和 768 宽度可操作，Chrome 95 兼容。无凭据错误不得伪装为空数据。

## 核心验收

- 首次导入无模型时，可以在导入页登记并确认 10 个 PJM 来源，完成 43 个业务模型预览和草稿导入；技术节点不作为业务模型重复创建。
- 100 个模型公共配置次数不随模型数增长；修改 1 个模型后再更改整包设置，该模型保持自定义，其余继承；恢复后统一。
- 一个完整包导入后，下游引用指向本次目标对象 ID/版本，而非原环境 ID；模型未物化时卡片和大屏明确等待上游，不宣称可查询。
- 相同包重复导入、网络超时重试、浏览器刷新恢复均无重复创建；更新有版本冲突校验，不静默覆盖他人修改。
- 权限、包校验、依赖循环和越界路径失败均无未授权业务写入。重置只处理本次CREATE且版本未漂移、未发布、无外部引用对象；UPDATE另走前向恢复，不删除ODS/复用资产或历史回执。
- 同一规划同一ZIP完成“43 CREATE→重置→43 CREATE”，两次模型ID不同，首次记录可查；并发重导不重复创建。
