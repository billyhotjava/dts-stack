# F15-T03：业务语言与错误去重呈现

**状态**：DRAFT（依赖评审 D3 错误码目录）；**优先级**：P0；**依赖**：T01、D3

## 目标
界面只说业务语言；同一原因只出现一次；技术细节可展开。

## 技术设计
- 取值映射：计划列（依赖角色、计划动作、目标关系）、候选状态、阶段状态统一走 `customerDisplayLabels`，新增缺失项；UPSTREAM/TARGET/BUILD/REUSE/状态码不直接上屏。
- 原因来源优先级：`primaryBlocker.message` → 错误码目录用户文案 → 通用"该步骤未完成，请查看技术详情"。`failureMessage`、错误码、执行编号、计划校验码、发布单 ID 进入 `<details>技术详情</details>`。
- 删除：`dl.dmx-summary-list` 中"主要阻断"、`ModelReleaseScopeSummary` 的 blocker 行、与阶段原因重复的顶部 failure 横幅（非阶段性读取失败保留在状态条）。
- 错误码目录未覆盖的码：显示通用文案 + 技术详情，并在前端穷举测试中列为待补。

## 验证
- 快照/断言：每个失败场景页面中原因文本出现次数 = 1；页面文本不含 `UPSTREAM|BUILD|REUSE|QUALITY_PASSED|BUILDING`（技术详情折叠区除外）。
