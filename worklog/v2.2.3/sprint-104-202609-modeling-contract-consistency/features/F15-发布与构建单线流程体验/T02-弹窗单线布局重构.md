# F15-T02：弹窗单线布局重构

**状态**：DRAFT（待 T01）；**优先级**：P0；**依赖**：T01

## 目标
`ModelPublishDialog` 去掉「生成构建任务 / 发布模型」两个页签，改为顶部固定状态条 + 纵向阶段列表（当前阶段展开，其余折叠）。

## 技术设计
- 新组件：`ReleaseJourneyHeader`（状态条：阶段序号+名称、原因、主/次动作）、`ReleaseJourneyStage`（折叠行 + 展开内容插槽）。
- 阶段内容：precheck=模型范围+目标数仓卡片+计划表+高级设置（执行环境、依赖策略，默认折叠）；build=`ModelBuildProgressNotice`+逐表证据；registration=`ModelAssetDeliveryResult`（从顶部移入）；engineering/governance=`ModelReleaseWorkflowPanel` 中对应内容；publish=动作说明输入（按动作决定是否显示/必填）；online=运行绑定操作。
- 打开即预览计划；高级设置变更后自动重新预览（300ms 防抖，进行中的旧请求结果丢弃）。
- 状态条 `position: sticky`，1366×768 首屏可见；Chrome95 不使用 `:has()`、`gap` 于 flex 之外的新特性前先核对现有样式约定。
- `embedded` 模式只渲染 `journey.current` 阶段内容，保持 `ModelWizardFrame` 行为。
- 保持既有写操作函数与 busy 防重逻辑不变。

## 验证
- 组件测试：无页签；当前阶段展开；失败阶段之后为等待；主按钮点击调用原写函数；读失败保留旧数据。
- `ModelWorkbenchDialog.release.test.tsx`、`ModelReleaseWorkflowPanel.governance-quality.test.tsx` 按新结构更新断言（不删除行为断言）。
