# F15-T05：工程检查随构建自动执行（后端）

**状态**：DRAFT（等待决策 D1）；**优先级**：P0；**依赖**：F14-T03 / T04

## 范围
发布单进入 BUILT 后，由服务端自动发起工程检查（复用现有 `runReleaseCandidateQuality` 的服务端路径，不另建调度），结果写回同一个发布单：
- 检查通过 → 构建结果为成功；检查失败 → 构建结果为失败，原因是具体的检查项；
- 幂等：同一轮构建只发起一次；重新构建后重新检查；
- 用户不再看到「运行工程验证」按钮；`RUN_QUALITY` 动作只保留给恢复路径使用。

## 验证
后端集成测试覆盖：构建完成后自动检查、检查失败回写、重复回调不重复检查、重新构建后重新检查。
