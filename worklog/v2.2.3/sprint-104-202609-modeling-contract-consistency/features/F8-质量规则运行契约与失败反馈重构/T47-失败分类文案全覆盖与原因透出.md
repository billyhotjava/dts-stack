# T47：失败分类文案全覆盖与原因透出

**优先级**：P1
**状态**：DRAFT
**依赖**：T44、T46

## 目标

运行详情直接说明失败原因与改法，不再出现笼统兜底句。

## 技术设计与契约

- **契约引用**：C66、C70；K72，见 [统一契约与账本](../../assests/F8-quality-rule-execution-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：入参为 `errorCategory` 与语句级 `reasonCode/detail`；出参为分区展示的业务结论、执行状态、具体原因与可执行建议。
- **方案**：补齐 `safeRunMessage` 的分类映射，覆盖 T44 冻结的全集（含 RESULT_ID_REQUIRED、EXECUTION_ERROR、UNKNOWN、DISPATCH_REJECTED）；无映射的新分类回落到 reasonCode 原文而非兜底句（C66）。运行详情按 K70 分区，展示 C70 已结构化的 reasonCode 与 detail，并给出对应改法。错误信息不得泄露绑定资产以外对象的存在性。
- **本任务差异**：纯展示与文案层，不改执行语义；不得用前端兜底掩盖后端未返回的分类或原因。

## UI 交互与影响范围

QualityRunQueryService.safeRunMessage、运行详情页、customerDisplayLabels。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

每个已知分类都有专属文案且不落兜底；未知分类显示 reasonCode 原文；函数越界时页面点名函数并列出允许清单；越权与跨表场景的提示不暴露对象存在性；四态与 Chrome95 走查。

映射 **IT-51**，见 [F8 验收清单](../../it/F8-质量规则闭环验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
