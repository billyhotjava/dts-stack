# T45：失败行统计去除 id 硬依赖

**优先级**：P0
**状态**：IN_PROGRESS
**依赖**：T44

## 目标

表没有 id 列时，规则查出的违规行数能正常统计，整次运行不再因统计步骤失败。

## 技术设计与契约

- **契约引用**：C60、C61、C62、C69；K69，见 [统一契约与账本](../../assests/F8-quality-rule-execution-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：入参为已判定失败的语句集合；出参为失败行数与是否去重的标注，运行结论不再受统计失败影响。
- **方案**：单语句时直接复用 countFailures 已得出的计数，不再执行 `SELECT quality_statement.id` 去重查询（C60）；多语句时按 T44 冻结规则探测结果集是否含 id，无则按语句求和并标注未去重。任何情况下统计失败都退化为统计缺失加警告，不得使整次运行判失败。失败样本落库路径不变（C69）。
- **本任务差异**：取消去重查询后单语句规则的运行 SQL 次数有违规时由 4 降为 3（包含总行数查询），需在验收中记录实际语句数；`RESULT_ID_REQUIRED` 取值保留供历史记录解释，但新运行不再产生。

## UI 交互与影响范围

QualityDatasetStatementExecutor（countFailures、countDistinctFailureRows、execute）。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

无 id 列的表查出违规行时运行成功且失败行数正确；有 id 列时结果与修复前一致；多语句未去重场景带警告；构造统计异常时运行结论仍保留、不判失败；既有 18 项执行器断言不回归。

映射 **IT-49**，见 [F8 验收清单](../../it/F8-质量规则闭环验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
