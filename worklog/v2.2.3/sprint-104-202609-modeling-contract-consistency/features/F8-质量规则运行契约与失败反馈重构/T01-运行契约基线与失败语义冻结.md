# T01：运行契约基线与失败语义冻结

**优先级**：P0
**状态**：DONE
**依赖**：无；复用 C56–C70，不继承其他 Feature 验收状态

## 目标

取得存量规则的真实可运行性画像，冻结静态校验、失败统计、结论分离与文案覆盖的全部契约，形成可开工基线。

## 技术设计与契约

- **契约引用**：C56–C70；K67–K72，见 [统一契约与账本](../../assests/F8-quality-rule-execution-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：本任务不新增业务接口、不落 schema 变更。产出物是冻结契约与基线画像本身，其余 Task 的 DoR 引用它。
- **方案**：统计存量规则中在现行约束下不可运行的条数，按无 id 列/函数越界/跨表引用/无法解析分类，附查询语句与执行时间；统计多语句规则占比与历史 RESULT_ID_REQUIRED 运行数。核对试跑接口 C68 的权限表达式与规则编辑页实际角色是否一致。据此冻结 K67 的精确路径与 DTO、K68 对存量规则的处置（拦截/告警/仅新保存生效）、K69 的多语句退化规则、K70 的两个维度取值集合、K71 的工单准入判据、K72 的分类文案全集。不得用直接改库构造样本。
- **本任务差异**：四项开放问题全部关闭才算完成，其中存量不可运行计数与多语句占比为具名交付物；缺此计数不得冻结 K68 与 K69。

## UI 交互与影响范围

QualityRuleService、QualityDatasetStatementExecutor、QualityRunOutcomeSemantics、QualityRunQueryService、RuleEditorPage、GovernanceResource 试跑入口。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

基线覆盖：无 id 列且有违规行的表、含越界函数的 SQL、跨表引用、单语句与多语句规则各一、已存在的 RESULT_ID_REQUIRED 历史运行。真实数据画像记录来源、数量、粒度、时间、权限与脱敏方式。

映射 **IT-48**，见 [F8 验收清单](../../it/F8-质量规则闭环验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
