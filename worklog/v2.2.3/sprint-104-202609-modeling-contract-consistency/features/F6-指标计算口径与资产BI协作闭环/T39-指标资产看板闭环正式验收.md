## 技术设计与契约

- **契约引用**：K61–K66；IT-36–IT-43，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务产出**：验收与交付证据（提交 SHA、镜像 digest、清单、包校验和、请求响应与截图），不新增业务接口、不改契约。
- **方案**：在 deploy 核对干净工作区、分支并 ff-only 到已推送 SHA，执行正式检查/测试/构建/交付；按实际影响部署，不从开发目录构建。记录 SHA、镜像 digest、清单与包校验和；如有迁移验证旧数据兼容、前向应用和回退方案。上线前记录查询失败/注册失败排障入口与超时、延迟、版本追溯日志。
- **本任务差异**：不实现契约，只验证；如有迁移须验证旧数据兼容、前向应用与回退方案。所有编译/构建/部署在 deploy 目录经 ff-only 后执行。

## 验证与验收

外部 Chrome 验收完整资产→指标→两张卡片→看板筛选链；另列 Chrome95；正式包/部署/源码/页面结果分开。旧指标/旧卡片、权限撤销、注册重试与预算边界均留证；离线目标不可用则明确待验。

补验分组缺失/时间错位、v1 可用而 v2 失败、乱序响应与独立指标发布，并核对模型级状态与指标版本级结果各自正确。

映射 **IT-43**，见 [F6 验收清单](../../it/F6-指标资产BI验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
