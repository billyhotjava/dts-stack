## 目标与边界

业务人员能从既有模型/资产定义公共指标，明确固定版本、执行方式与统计范围，在 BI 创建两张复用同一口径的卡片并组合看板；可从卡片追溯指标版本和来源资产。建模完成仍遵循 F3，指标与 BI 故障不回退模型成功状态。

复用当前 `/data-modeling/metrics/atomic|derived|composite|modifiers|periods` 页面、平台指标 owner、CatalogAssetKey、分析注册与查询网关；不新增顶级菜单、平行指标台账、资产标识体系或查询引擎。直接资产明细分析保留，不强制全部转为公共指标。不新增调度平台、任意跨源查询、全量指标商店或独立指标微服务。

## Review 完善与决策

- 实现模型版本丢失和公式依赖版本丢失分为两个缺陷，不以修好一处宣称版本闭环。
- 派生结果取 MAX 只有在已证明目标粒度唯一且语义允许时才成立；不得把物化字段统一当成可聚合指标。
- 定义版本固定保证口径稳定，不保证源数据永久不变；历史复现需记录运行与数据时间信息。
- 空结果、零分母、权限拒绝、查询失败分别表达，禁止返回零伪装成功。
- BI 同步链已核实存在（C48）：platform serving 投影 worker→命令服务→载荷工厂→只读指标适配器→analytics，带持久化状态与受控重试（C53）。T32 不再核实"链路是否存在"，改为冻结三处结构缺口：派生/复合零通路（C50）、wire 契约无版本位（C51）、指标发布不触发同步（C52）。
- `dts-metrics` 的注册类在 platform 侧零调用点（C54），是平行原型链。本 Feature 不作为 owner、不接为主链、不新增调用。
- 依赖解析按 ID+版本，不按 code 全局取首条（C55）；该缺陷同时是版本漂移和归属越界，按后者定严重度。
- 既有数据的兼容默认必须有证据；不能自动把历史指标改为公式或把旧卡片升级到最新版本。

## 任务通用契约

以下四项对 T32–T39 统一生效，Task 文件不再逐份复制，只写本任务的差异与覆盖项。

- **数据流与复用**：现有指标页面触发 → 平台指标 API/发布 owner → 固定模型与指标快照/查询网关 → 既有存储；涉及 BI 时经 C48 的 serving 投影链 → 卡片语义查询 → 看板。每个 Task 只承担其对应段。
- **错误路径**：输入非法 400；未认证/越权沿用 401/403；不可见对象按已有防枚举策略处理；固定版本/发布冲突 409；查询超时与下游故障沿用网关协议。精确错误码由 T32 冻结。失败不得显示成功、替换版本或清空用户输入。
- **存储与兼容**：定义与运行复用 `gov_indicator_definition`、`gov_indicator_reference`、`gov_indicator_run` 及既有版本快照存储；投影状态复用 `modeling_catalog_model_serving_projection`（C53）。新增字段与索引仅按 T32 冻结内容落地；禁止双写形成第二事实源。
- **UI 落点**：按下文 UI/UX 规格使用现有页面与深链，不另建工具页面；每个 Task 的具名控制项必须有空、加载、错误、成功及无权限反馈。T32/T39 的界面工作限于只读走查与证据记录。

## UI/UX 规格

沿用既有分类列表与详情，以 `indicatorId` 深链定位。原子：来源模型版本→度量→聚合；派生/复合：上游版本→执行方式→公式或预计算来源→修饰词/时间/维度。修饰词作为可复用限定规则，时间周期单独维护。

```text
指标详情：名称 / 当前版本 / 定义状态
[业务口径] [来源与版本] [计算规则] [计算记录] [分析使用]
执行方式：公式计算 | 预计算结果
统计范围：时间字段 / 时区 / 时间范围 / 筛选 / 分组
[保存草稿或发布新版本] [校验] [试算] [发布] [去 BI 分析]
分析准备：未准备 / 处理中 / 可用 / 失败（原因、重试）
```

以上是既有详情内的功能分区，不要求新增五个页面。试算使用冻结后的查询协议，原“提交计算”保留兼容且显示其真实范围。查询/注册期间显示进度，空数据给出范围与说明，失败保留配置并允许重试，无权限禁用并明确原因，成功展示结果、版本和追溯链接。历史加载失败不能显示为空；离开未保存编辑必须提醒。仅“分析可用”时引导创建 BI 卡片。Chrome95、键盘操作及公共组件样式沿用现有约束。

走查：资产可用→创建原子指标→组合完成率→固定版本发布→选择时间与地区试算→BI 建两张卡片→加入看板联动→回查指标及资产→发布新版本→旧卡片不变、显式升级。
