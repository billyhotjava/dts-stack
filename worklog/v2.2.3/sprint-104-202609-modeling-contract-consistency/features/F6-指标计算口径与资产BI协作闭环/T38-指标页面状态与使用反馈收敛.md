# T38：指标页面状态与使用反馈收敛

**优先级**：P2  
**状态**：DRAFT  
**依赖**：T32、T33、T34、T35、T36、T37

## 目标

现有指标页面准确表达定义、计算、分析可用状态和操作结果。

## 技术设计与契约

- **契约引用**：C43、C49；K61–K66，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：只消费 K61–K66 的既有出参渲染状态，不新增请求字段；本任务不改后端契约。
- **方案**：保留现有分类菜单与兼容入口；详情展示来源版本/执行方式/时间范围/质量及分析准备状态。根据草稿/发布/归档状态显示保存或发布新版本，保留失败输入与未保存离开提醒；历史请求失败不伪装无记录；数仓分层来自实际模型或明确不适用，删除固定公共层。移除与实际公式能力矛盾的旧说明及内部兼容术语。
- **本任务差异**：纯前端，无存储与迁移；不得用前端兜底掩盖后端未返回的版本或状态字段。

## UI 交互与影响范围

MetricsPage、MetricEditor、MetricDefinitionBindingFields、ModifierDefinitionEditor、相关帮助与已有组件测试。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

空、加载、错误、成功、只读状态均走查；指标定义发布与 BI 就绪分开展示；历史失败可重试；新版本操作不会误保存；分类切换不会静默丢草稿；键盘与 Chrome95 检查。

映射 **IT-42**，见 [F6 验收清单](../../it/F6-指标资产BI验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
