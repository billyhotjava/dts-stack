# T33：指标实现模型精确版本绑定

**优先级**：P1  
**状态**：DRAFT  
**依赖**：T32

## 目标

用户选择的模型 ID、修订、字段在保存、重开及发布后保持一致。

## 技术设计与契约

- **契约引用**：C44；K61，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：入参 K61 的 `{modelSpecId,modelRevision,fieldName}` 完整三元组，经既有 model-field-drafts 创建与 rebind；出参回显服务端锚点 `{id}@{revision}#{field}`，不回退为模型名。
- **方案**：将选择器完整 modelSpecId/modelRevision/fieldName 传到既有 model-field-drafts 创建与 rebind；不再按同名模型选最新修订。保存响应回显服务端锚点；历史记录优先还原 MODEL_SPEC_FIELD，缺失或歧义则显式重新绑定，不自动升级。新增字段的持久化位置由 T32 冻结。
- **本任务差异**：写入落 `gov_indicator_reference` 的 `MODEL_SPEC_FIELD` refTarget；模型字段型历史缺失或歧义走显式重绑；合法公式型不强制新增实现引用，不自动升版。派生路径不再按同名取最新发布修订（C44）。

## UI 交互与影响范围

MetricDefinitionBindingFields.tsx、indicatorDefinitionBindingService.ts、indicatorProjectionService.ts、ModelFieldIndicatorDraftService。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

选择 r1→发布 r2→保存仍为 r1；同名不同 ID 不串绑；重开旧指标正确回显；不可访问或缺失字段阻断且保留输入。

映射 **IT-37**，见 [F6 验收清单](../../it/F6-指标资产BI验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
