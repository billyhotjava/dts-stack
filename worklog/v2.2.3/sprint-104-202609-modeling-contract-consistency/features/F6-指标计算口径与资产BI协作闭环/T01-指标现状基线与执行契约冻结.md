# T01：指标现状基线与执行契约冻结

**优先级**：P1
**状态**：IN_PROGRESS
**依赖**：无；复用 F2-T05、F5 已有证据，不继承其验收状态

## 目标

核实实际发布与计算路径，冻结版本、执行方式和 BI 映射协议，形成可开工契约。

## 技术设计与契约

- **契约引用**：C43–C55；K61–K66，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务产出**：冻结协议、错误码、并发/幂等约定与真实基线画像，不新增业务接口、不落任何 schema 变更。产出物是可开工契约本身，其他 Task 的 DoR 引用它。
- **方案**：从现有三个指标分类各选可访问样本，记录页面请求、模型引用、指标版本和查询结果；投影链已在 C48 核实存在，本任务不重扫源码链，但须验证当前运行可达性，改为冻结 C50–C52 三处结构缺口的处理方案；dts-metrics 侧不在范围内（C54）。不得用直接改库构造成功。补齐现有 DTO/JSON/表列、索引、并发写与迁移文件名；按原 owner 冻结 API 路径及错误码，未冻结项不得交给实现任务。
- **本任务差异**：错误码与并发/幂等协议由本任务定义而非引用；[开工缺口](../../assests/F6-metric-asset-bi-contract.md#t32-必须关闭的开工缺口) 五项全部关闭才算完成，其中存量分类统计、版本级投影存储与宿主方案、多维分组对齐规则、当前运行关联证据为具名交付物。

## UI 交互与影响范围

MetricsPage、indicatorProjectionService、IndicatorCalculationService、IndicatorService、CatalogModelSemanticSyncCommandService、CatalogModelSemanticPayloadFactory、CatalogModelSemanticIndicatorReadAdapter、SemanticQueryService（dts-metrics 不在范围，C54）。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

基线包含两个地区且分母不同、零分母、空数据和至少两版指标；真实数据画像记录来源、数量、粒度、时间、权限和脱敏方式；另附按计算模式/引用完整性四组分类的已发布指标数量与占比，再按原子/派生/复合分列，合法公式型不计入强制重绑（含查询语句、分母和执行时间）。核实允许使用的隔离样本与外部 Chrome 登录。

映射 **IT-36**，见 [F6 验收清单](../../it/F6-指标资产BI验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
