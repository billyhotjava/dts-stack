# T36：修饰词时间与多维查询贯通

**优先级**：P2  
**状态**：DRAFT  
**依赖**：T32、T34、T35

## 目标

从派生指标选择修饰词和时间范围，并按允许维度查询，结果范围明确。

## 技术设计与契约

- **契约引用**：C47；K63、K64，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：入参 K63 受控谓词与 K64 的时间/维度/筛选；出参 `columns/rows/resolvedVersions/queryId/dataAsOf/warnings`。查询无状态，不写指标定义。
- **方案**：修饰词采用字段、操作符、类型化值的受控谓词，绑定源模型字段；时间周期与业务修饰词分开。首批单一已绑定事实粒度及既有关联，不新增任意跨源 JOIN。UI 展示时间字段、时区、区间和分组维度；保留旧最新值调用但明确 LATEST_PERIOD，不以缺省条件偷偷取最新周期。
- **本任务差异**：K63/K64 不写 `gov_indicator_run` 的定义列；修饰词与时间周期沿用其既有 owner 存储。行数/维度/超时上限在服务端强制，不靠前端约束。严格执行 K62–K64 增量的公共维度/时间映射、聚合后全键对齐、缺组策略、快照一致性和最终结果截断规则。

## UI 交互与影响范围

ModifierDefinitionEditor、MetricDefinitionBindingFields、MetricsPage、IndicatorCalculationService、现有语义查询与查询网关。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

当期/本年及地区筛选产生对应结果；累计与普通过滤语义分别验证；非法字段、运算符、越权维度拒绝；分页/行数上限、空数据、null 和查询失败区分；不适用的修饰词不可选。

分子缺组/分母缺组默认 null，显式允许零补齐时才为零；公共时间映射不兼容拒绝；聚合后重复键拒绝；外部筛选一致传递且不得覆盖指标修饰词；超限不截断依赖结果后继续运算。

映射 **IT-40**，见 [F6 验收清单](../../it/F6-指标资产BI验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
