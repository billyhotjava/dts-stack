# T35：上游指标版本解析与运行追溯

**优先级**：P1  
**状态**：DRAFT  
**依赖**：T32、T34

## 目标

下游始终计算所选上游版本，运行记录能还原依赖版本和口径。

## 技术设计与契约

- **契约引用**：C46、C55；K61、K62，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：入参 K61 的 `sourceRefs[INDICATOR_VERSION]`；运行输出 `indicatorVersion` 与 `dependencyVersions`，另记 `dataAsOf` 区分口径固定与数据变化。
- **方案**：依 sourceRefs 的 INDICATOR_VERSION 解析快照；编码只用于公式符号，不能代替身份/版本。递归去重键包括指标 ID 和版本，校验循环、缺失版本和当前访问权限；版本固定不等于数据快照，记录查询时间/数据新鲜度。运行存储字段和迁移由 T32 冻结。
- **本任务差异**：`gov_indicator_run` 当前无版本与依赖版本列，需按 T32 冻结的新增列落地；依赖解析改为按 ID+版本，废止 `findFirstByCodeIgnoreCase` 的全局首条匹配（C55）。

## UI 交互与影响范围

IndicatorCalculationService、IndicatorReferenceService、IndicatorService 及既有版本快照仓储、GovIndicatorRun。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

上游 v2 发布后下游仍按 v1 定义计算；上游当前草稿不覆盖旧发布快照；同 code 跨部门/租户的上游不被误取（C55）；版本被撤销、权限收回按冻结规则拒绝；循环和依赖深度错误准确；历史结果展示版本及来源。

映射 **IT-39**，见 [F6 验收清单](../../it/F6-指标资产BI验收.md)。实现任务先用对应缺陷场景建立失败证据，再进行一次成组验证，不重复全仓检查。编译性测试只在 deploy 经 Git 同步后执行；验收样本仅用于隔离测试，不预置为客户页面演示数据。
