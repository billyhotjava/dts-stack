# T03：派生计算方式与结果粒度一致

**优先级**：P1
**状态**：IN_PROGRESS
**依赖**：T01、T02

## 目标

公式与预计算两种方式执行结果明确，去除派生类无条件 MAX。

## 技术设计与契约

- **契约引用**：C45；K62，见 [统一契约与账本](../../assests/F6-metric-asset-bi-contract.md)。
- **通用契约**：数据流与复用、错误路径、存储与兼容、UI 落点见 [任务通用契约](README.md#任务通用契约)；本文件只写差异。
- **本任务输入/输出**：入参 K62 的 `executionMode`、`expression`、`resultGrain`、`allowedAggregations`；运行输出补 `sourceMode`、`value`、`nullReason`，零分母与空结果分别表达。
- **方案**：公式模式消费 T04 的固定版本解析协议，阶段实现不得退回当前版本；T03 可先验证聚合与空值规则，完整固定版本验收由 T04 补齐。公式模式使用固定上游指标结果，不要求实现结果字段；预计算模式必须有固定模型字段及结果粒度，按允许聚合规则读取。比率按分子分母聚合后相除，禁止无权重平均或 MAX 冒充总值；预计算若仅有比率且跨粒度无法重算，拒绝该查询并说明支持范围。旧模式不得猜测，发布前提示补充配置。
- **本任务差异**：`executionMode`/`resultGrain`/`allowedAggregations` 的持久化列由 T01 冻结后落地；旧数据模式为空时发布前提示补充，不猜测、不默认公式。

## UI 交互与影响范围

MetricDefinitionBindingFields.tsx、IndicatorCalculationService、ControlledIndicatorDerivationCompiler、IndicatorPublishPreviewService。本任务具名控制项的状态反馈要求见 [任务通用契约](README.md#任务通用契约)。

## 验证与验收

20/100 与 80/1000 的总体结果为 100/1100；单地区正确；改公式只在公式模式影响结果；预计算多行违背声明粒度时失败；零分母返回 null 与解释，不标数据库故障。
