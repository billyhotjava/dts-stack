## 四步向导界面决策

模型设计→实现配置→构建与检查→发布与交付，每步一个独立内容页，共用工作区和模型身份；每页最多一个主按钮。顶部步骤条只导航，不重复执行按钮。可回看/回改，可依据有效证据跨步查看；生命周期写操作始终校验全部前置条件。

W3 质量准备不得隐式完成 W4 发布；已发布模型修改通过新草稿/修订，原发布结果保留。具体动作、导航、失效及异常分支均以共享契约为准，不能在页面重新定义业务规则。
