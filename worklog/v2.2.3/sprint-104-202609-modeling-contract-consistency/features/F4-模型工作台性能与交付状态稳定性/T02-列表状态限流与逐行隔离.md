# T22-列表状态限流与逐行隔离

**优先级**：P0  **状态**：IN_PROGRESS
**依赖**：见 F4 README Task 表。

## 目标
单行失败不扩大为整页失败，状态逐行展示。

## 输入、输出与数据流
继承 [F4冻结契约](README.md)：工作台列表/编辑入口 → 既有 GET/modeling 与模型上下文服务 → 原仓储。请求与响应字段、分页10条、权限/候选/版本绑定均保持。无新表/字段/迁移/事件。

## 技术设计
在既有列表effect内最多2个工作循环；Map保存成功数据，Set保存失败/等待模型；page+id+revision+checksum绑定结果代次，失效时停止派发；刷新触发状态重读。延迟Promise测试并发、部分失败、失效请求。

## UI交互与错误路径
沿用 F4 四态和操作走查；加载/失败不能误报业务未完成或成功；401/403/候选冲突沿用原语义；刷新重新取数，切换模型或页面不得回填过期结果。

## 影响范围
