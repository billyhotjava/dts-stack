# T03-首屏与编辑辅助加载分离

**优先级**：P1  **状态**：IN_PROGRESS
**依赖**：见 F4 README Task 表。

## 目标
列表不等待编辑专用辅助数据。

## 输入、输出与数据流
继承 [F4冻结契约](README.md)：工作台列表/编辑入口 → 既有 GET/modeling 与模型上下文服务 → 原仓储。请求与响应字段、分页10条、权限/候选/版本绑定均保持。无新表/字段/迁移/事件。

## 技术设计
沿用 ModelWorkbenchContext DTO；拆分列表必需的 domains/models/dimensions 和 standards/dataMarts/subjectDomains/warehouseLayers/sources/implementationCapabilities。编辑/新建入口等待辅助数据完成，失败显式展示并可刷新；不得空默认值覆盖保存。精确内部函数签名及状态机须在实施前补充到本任务，若需要改变共享编辑契约则保持未开工。

## UI交互与错误路径
沿用 F4 四态和操作走查；加载/失败不能误报业务未完成或成功；401/403/候选冲突沿用原语义；刷新重新取数，切换模型或页面不得回填过期结果。

## 影响范围
modelWorkbenchService.ts、ModelingWorkbenchPage.tsx 及其测试。不修改全局池、超时、安全和数据写入规则。

## 实施前冻结补充
内部签名：loadModelWorkbenchContext(onCatalogReady?: (catalog: ModelWorkbenchCatalogContext) => void): Promise<ModelWorkbenchContext>；ModelWorkbenchCatalogContext = Pick<ModelWorkbenchContext, "domains" | "models" | "dimensions">。回调仅交付列表资料，最终Promise仍返回完整原契约。列表三接口不再等待默认规划/来源/编辑辅助。页面独立catalogContext，旧epoch回调丢弃；deep-link编辑继续等待完整资料。列表新增可选detailsReady:boolean，默认true兼容其它调用；false禁编辑/新建/物化等详情动作，但保留筛选/分页/刷新。辅助错误展示原错误消息并保留列表，不把空值合并进完整context。
