# F11 测试执行与缺陷记录模板

本文件为模板，尚无实际执行记录。复制到本次受控证据目录或后续 `test/runs/{runId}.md` 后填写；不存在的文件、截图、日志不得填成链接或证据。

## 一次运行的基线

| 字段 | 实际值 |
|---|---|
| runId、执行人/代理、业务见证人 | 待填写；代理执行不等于客户签认 |
| 开始/结束时间、时区 | 待填写 |
| 切片与完整用例 ID 清单 | 待填写；参数化子项分别列出 |
| 应用 SHA、测试源码 SHA | 待填写；设计参考 SHA 不替代受测版本 |
| 旧版本（升级/回退用例） | 待填写或有理由的 N/A |
| 正式包校验和、镜像 ID/digest、运行容器版本 | 待填写；UT 不涉及制品时说明层次 |
| 环境/服务 URL、数据库版本、realm、配置版本 | 待填写；不填服务密钥 |
| 字段源/目录/授权/政策版本 | 待填写；缺口关联 Q 编号 |
| 真实依赖与替身/故障注入点 | 待填写；逐依赖声明，不只写“集成环境” |
| Chrome 实际版本、profile 别名、视口 | 系统用例必须填写；UA 模拟不算 Chrome 95 |
| 账号/资源清单及 PKI 基线受控位置 | 只写别名与证据索引，不填密码、token、私钥 |
| 命令/页面操作路径与证据根目录 | 待填写；记录实际执行内容而非计划命令 |

## 单条用例结果

| 完整用例 ID / 子项 | 前置与数据 | 预期 | 实际 | 状态 | 证据/缺陷 |
|---|---|---|---|---|---|
| 待填写 | 待填写 | 引用具体断言 | 尚未执行 | NOT_RUN | 无 |

允许状态：`NOT_RUN`、`PASS`、`FAIL`、`BLOCKED`。确实不适用的项单列 N/A 原因及确认范围，不混入通过数。组内任何未完成/阻断子项不得被成功子项覆盖；版本修复后保留原 FAIL 和新执行记录，不覆盖历史。

Chrome 用例每个关键步骤追加：序号、实际点击/输入、页面 URL、观察到的状态、截图索引、脱敏 requestId/响应状态。不能只贴最终首页截图。下载记录文件摘要与允许行列核验；拒绝类补无新写入/派发证据。

## 缺陷记录

| 字段 | 内容 |
|---|---|
| 缺陷 ID / 关联用例、Task、IT 验收组 | 待填写 |
| 严重程度及实际影响 | 身份串用/越权/数据丢失/功能或兼容问题等，描述已证实范围 |
| 受测版本与前置 | 具体 SHA、环境、角色、对象与状态 |
| 最小复现 | Chrome 缺陷写人工可重复步骤；集成缺陷写命令及必要关联号 |
| 预期与实际 | 各自独立描述，引用冻结规则；未决政策不能伪装实现缺陷 |
| 证据与根因边界 | 已知证据、未验证推测分别列出，不暴露密钥/个人完整信息 |
| 修复版本、确认结果、影响回归 | 后续填写；提交修复不等于确认通过 |

## 分阶段汇总

| 证据阶段 | 计划 / PASS / FAIL / BLOCKED / NOT_RUN | 结论与剩余范围 |
|---|---|---|
| UT/组件 | 待本次范围确定 | 未执行 |
| 真实集成 | 待本次范围确定 | 未执行 |
| 正式构建/交付包 | 独立阶段 | 未执行 |
| 容器部署/迁移 | 独立阶段 | 未执行 |
| Chrome 页面 | 待本次范围确定 | 未执行 |
| PKI 兼容 | 单列实际完成的正反例 | 未执行 |
| 性能/故障恢复/运维 | 单列场景与实测门槛 | 未执行 |
| 业务方验收 | 记录真实签认人和范围 | 未完成，不由代理代签 |

记录故障控制恢复、测试数据清理、剩余风险、不可执行原因和后续责任；不得因文档检查或自动化命令退出码为 0 就将其他阶段填 PASS。
