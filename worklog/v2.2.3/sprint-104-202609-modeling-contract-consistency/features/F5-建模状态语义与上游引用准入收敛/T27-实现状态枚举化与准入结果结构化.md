# T27-实现状态枚举化与准入结果结构化

**优先级**：P0  **状态**：DRAFT
**依赖**：T25（消费其枚举集合、准入矩阵与错误码映射）。

## 目标

上游被拒时，接口能指明是哪个上游、缺什么条件；实现状态从裸字符串改为类型安全的枚举。

## 输入、输出与数据流

**输入契约**：不变。`PUT /api/modeling/model-specs/{id}/implementation` 与创作草稿保存、提交的请求体保持现状，本任务不改请求形状（请求侧的六元组直发由 T29 承担）。

**输出契约**：拒绝响应由无主体的单一错误码，改为携带明细。响应体 `detail` 追加 `{modelSpecId UUID, reason string, expected object|null, actual object|null}`，`reason` 取 T25 冻结集合。HTTP 状态维持 409。成功路径响应不变。

**数据流**：`ModelLifecycleService` → `ModelImplementationInputPolicy.validate` → 结构化结果 → Resource 层转错误响应。不新增服务，不改调用拓扑。

**错误路径**：一次请求存在多个不合格上游时，返回全部条目而非首个，使用户一次看清。上限 50 条，超出截断并标注。

## 技术设计

### 1. 结果结构化

`ValidationResult(boolean valid, String code)`:249 结构上装不下上游标识，这是"拒绝信息无法定位"的直接原因。改为携带 `modelSpecId`、`reason`、`expected`、`actual` 的结构，并由 `validate` 返回不合格条目列表而非单个结果。

`validateUpstream`:132–169 现有 12 个失败分支全部返回同一个 `MODEL_IMPLEMENTATION_INPUT_STALE`，需按 T25 映射逐分支落到具体 `reason`：上游不存在、设计修订漂移、设计校验和漂移、未携带锁定、实现修订漂移、实现校验和漂移、dbt 标识漂移、跨规划未发布、分层不允许、自引用、成环。`currentImplementation`:171–194 的"无实现记录"与"实现非 ACTIVE"必须分开，二者对用户的下一步动作完全不同。

明细精度以 `ModelImplementationDependencyService.resolvePlan`:366 已有的形状为基准，该处已携带 modelSpecId 与 revision，本任务是把同一精度补到保存与提交阶段。

### 2. 实现状态枚举化

新增 `ImplementationStatus` 枚举，成员由 T25 采样冻结。`ImplementationView.status`:771 改为该类型，替换全仓 27 处 `"ACTIVE".equals` 比较。持久层读写做双向映射，遇到枚举外取值按 T25 结论处理，不得静默降级为 ACTIVE。

`ImplementationView` 被 31 个文件引用，属中等爆炸半径。按机械替换执行，禁止顺带调整语义或重构相邻逻辑（domain-dts A2：不用查找替换改名，涉及重命名走 `gitnexus_rename`）。开工前对 `ImplementationView` 与 `ModelImplementationInputPolicy` 各跑一次 `gitnexus_impact`，结果记入本文档「本轮进度」。已知 `ModelImplementationInputPolicy` 上游仅 1 个直接调用方，风险 LOW。

### 3. 错误码收敛

按 T25 映射统一三阶段 `reason` 取值。外层错误码保留各阶段现名以免破坏既有前端处理，`reason` 成为跨阶段一致的判定依据。不删除现有错误码，避免影响 Sprint-104 已留证的历史用例。

## UI交互与错误路径

本任务不改界面，但产出的 `reason` 与 `detail` 是 T28 文案的唯一数据源。需保证每个 `reason` 都能映射到一句用户可执行的中文说明，若某个 `reason` 无法给出下一步动作，说明分支划分过细，回到 T25 合并。

## 影响范围

`ModelImplementationInputPolicy.java`；`ModelLifecycleContract.java`（枚举与 `ImplementationView`）；`ModelLifecycleService.java`；`ModelLifecycleResource.java` 与 `ModelAuthoringDraftResource.java` 的错误转换；27 处字符串比较所在文件；对应单元测试。无表结构与迁移变更。
