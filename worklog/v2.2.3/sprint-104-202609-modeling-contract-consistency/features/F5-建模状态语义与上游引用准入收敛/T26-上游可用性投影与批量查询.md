# T26-上游可用性投影与批量查询

**优先级**：P0  **状态**：DRAFT
**依赖**：T25（消费其实现状态枚举集合与准入矩阵）。

## 目标

前端在渲染上游候选列表时能一次拿到每个候选的实现可用性，不再需要选中并保存才知道能否引用。

## 输入、输出与数据流

**输入契约**：`POST /api/modeling/model-specs/upstream-availability`，body `{ownerModelSpecId: UUID, modelSpecIds: UUID[]}`。`modelSpecIds` 去重后上限 200，超限返回 400；空数组返回空列表而非错误。选用 POST 而非 GET，因候选集合随模型规模增长会超出 URL 长度，形状对齐既有批量查询 `getModelServingSyncStatuses`（`modelSpecApi.ts`:337）。

**输出契约**：`ApiResponse<List<UpstreamAvailabilityView>>`，元素为
`{modelSpecId UUID, revision int, checksum string, implementationState enum(NONE|DRAFT|ACTIVE|UNKNOWN), implementationRevision int|null, dbtUniqueId string|null, selectable boolean, blockReason string|null}`。
按 `modelSpecId` 升序返回，保证前端渲染稳定。请求中不可读或不存在的 id 返回 `UNKNOWN` 条目而非省略，避免前端把越权误判为"不存在"。

**数据流**：Resource → 新增只读查询服务 → `ModelLifecycleRepository.findImplementation`（账本 C08，`:196`）批量形态 + `ModelSpecRepository.findCurrent`。一次查询覆盖全部 id，禁止在循环内逐个查库。

**错误路径**：未登录 401；无 owner 模型读权限 403；owner 不存在 404；超限 400。单个候选不可读不影响整体响应码。

**复用点**：实现读取 owner 仍为 `ModelLifecycleRepository`，不新建实现台账；`selectable` 的判定必须直接调用 T27 结构化后的准入判定，不得在本服务内复写一份规则。这是本任务最重要的约束——两处规则一旦分叉，界面显示可用而保存被拒的问题会以新形态复现。

## 技术设计

`selectable` 为 `implementationState == ACTIVE` 且该实现满足 `ModelImplementationInputPolicy` 中除六元组比对外的全部前置条件（分层允许、非自引用、跨规划已发布）。六元组比对依赖前端尚未提交的选择，不在本投影内判定。

`blockReason` 取 T25 冻结的 `reason` 值，与保存期拒绝使用同一取值集合，使界面提示与后续报错措辞一致。

临时实现视图（`ModelImplementationDependencyService.provisionalImplementation`:421，校验和为 64 个零）不得进入本投影。该对象是物化计划内部占位，若泄漏到可用性投影会把无实现的模型显示为可选。本任务需显式排除并加断言。

## UI交互与错误路径

本任务只交付契约与后端实现，界面消费由 T28 完成。需提供可被 T28 直接调用的前端 API 封装 `listUpstreamAvailability`，置于 `modelSpecApi.ts`，沿用 `_skipErrorToast` 约定，失败由调用方就地展示。

## 影响范围

`ModelSpecResource.java`（新增端点）；新增只读查询服务与 `UpstreamAvailabilityView`；`ModelLifecycleRepository.java`（新增批量读方法）；`modelSpecApi.ts`（新增封装与类型）。无表结构、索引、事件或权限变更。

## 验证与DoD

- [ ] RED→GREEN 契约测试：断言响应字段名与类型、排序、不可读返回 UNKNOWN、超限 400、空数组返回空列表。
- [ ] 批量查询次数断言：N 个候选下数据库查询次数不随 N 线性增长。
- [ ] 临时实现视图排除断言：构造全零校验和实现，确认不出现在投影中且不被判为 selectable。
- [ ] 规则一致性测试：同一候选在本投影判 selectable 为 false 时，走保存路径必被 T27 判定拒绝，反之亦然。
- [ ] 权限回归：跨租户与无域读权限的候选返回 UNKNOWN，不泄漏名称或版本。
