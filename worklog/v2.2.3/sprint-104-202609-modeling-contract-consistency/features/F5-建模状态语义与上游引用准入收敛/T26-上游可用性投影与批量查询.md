# T26-上游可用性投影与批量查询

**优先级**：P0  **状态**：IN_PROGRESS  **依赖**：T25、T27

## 目标与输入契约

候选可用性和已选引用漂移一次读取，以 T27 的纯判定为唯一规则源。

`POST /api/modeling/model-specs/upstream-availability`

请求：`{ownerModelSpecId: UUID, ownerRevision: int, ownerChecksum: string, modelSpecIds: UUID[], selectedInputs?: UpstreamPin[]}`。owner 为已保存的使用方模型；模型尚未保存时实现步骤沿用原流程先保存设计。selectedInputs 为前端当前完整锁定；省略时读取 owner 已提交实现中的锁定，传空数组表示尚无锁定。首次三字段选择仍走 T28 的兼容路径，不伪造为完整 pin。

modelSpecIds 与 selectedInputs 的 ID 并集去重上限 200；超限 400，空集合返回空 items。候选更多时按可见页分批，不能截断已选引用而不提示。owner revision/checksum 不匹配返回既有版本冲突 409。

## 响应契约

`ApiResponse<{ownerModelSpecId: UUID, ownerRevision: int, ownerChecksum: string, observedAt: ISO8601, items: UpstreamAvailabilityView[]}>`

每项：

`{modelSpecId: UUID, revision: int|null, checksum: string|null, implementationState: NONE|ACTIVE|INACTIVE|UNKNOWN, currentPin: UpstreamPin|null, selectable: boolean, blockReason: string|null, referenceState: UNSELECTED|CURRENT|DESIGN_DRIFT|IMPLEMENTATION_DRIFT|UNAVAILABLE, selectedPin: UpstreamPin|null, referenceReason: string|null}`。

UpstreamPin 六字段定义见 F5，包含 implementationChecksum。revision/checksum 表示当前可读设计；currentPin 仅在存在匹配设计的完整已提交实现时返回。存在完整 pin 仍可能因 owner 层级/权限/循环约束而 selectable=false，前端不能据非空 pin 自行放行。

不可读和不存在统一 UNKNOWN、selectable=false、blockReason=NOT_AVAILABLE，除请求 ID 外所有版本/pin=null。referenceState 在有引用时为 UNAVAILABLE，否则 UNSELECTED；不返回名称。不将权限未知与网络查询失败混成同一 DTO 状态。

## 数据流、判定与预算

ModelInputInspectionResource → 只读投影服务 → T27 AdmissionContext 批量 loader → 同一纯判定 → 按 ID 排序响应。新候选必须检查当前设计与实现对应关系；已选引用比较完整六字段，设计不变的实现升级返回 IMPLEMENTATION_DRIFT。相同快照下投影与保存判断一致；提交仍重新判定并保留 CAS。

候选、实现、权限与闭包使用集合查询，禁止循环调用 findImplementation/findCurrent/reachesOwner。目标每批最多 8 次数据读取语句（含 owner、候选、实现、权限与闭包，不含登录鉴权），候选数量由 20 增为 200 时不按行增加。闭包上限 2000 节点、32 层，超限返回可定位的 CONTEXT_LIMIT_EXCEEDED，不使用不完整闭包判可用；端到端查询超时预算 3 秒，不能取消前端等待后让后台无限运行。T25/T27 若证明现有 owner 无法满足预算，先修订实现设计，不直接降低校验。

接口无业务写入、无状态推进、无物化/质量/发布查询副作用。无缓存跨用户共享；读取事务不包外部 HTTP 或长流程。临时 provisionalImplementation 和全零 checksum 不可当作已提交有效实现。

## 错误与 UI

未登录 401；owner 不存在/无读取权限遵循原资源防枚举策略，不自行泄漏 owner 存在性；超限 400；版本漂移 409；其余沿用实际错误包装。单候选不可读不失败整批。modelSpecApi.ts 新增封装，沿用 _skipErrorToast，由 T28 就地展示。
