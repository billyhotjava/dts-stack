# S10DC-111：汇总表配置聚合后仍报“需声明汇总字段”

## 根因

汇总表第一次提交可视化加工配置后，`implementation_mode` 由 `DESIGNER_GENERATED` 切换为 `DBT_MANAGED`（后端 IMPORT 提交的既有设计）。前序修复 `5a3ecace4` 只在 `DESIGNER_GENERATED` 时把聚合结果标为 MEASURE，切换后失效；`DbtModelFieldProjector` 又沿用快照中的旧角色，聚合字段一直是 ATTRIBUTE，`ModelSpecStageGateService` 持续返回 `MODEL_SPEC_SUMMARY_MEASURE_REQUIRED`。

现场证据（openEuler，“风险类别统计”）：r2 `DESIGNER_GENERATED` + `COUNT→risk_count` 但 `risk_count=ATTRIBUTE`；r3 起 `DBT_MANAGED`；17:32 在修复版前端上的再次提交仍为 ATTRIBUTE，证明判断条件本身错误。

## 修复

提交 `7a2072c61`：
- 前端 `summaryMeasureFields`：汇总表存在可视化聚合即打 MEASURE，不看实现方式；`codeAuthoritative` 的只读参考不参与。
- 后端 `DbtModelFieldProjector.withAggregateMeasures`：提交时按可视化聚合把 SUMMARY 中 ATTRIBUTE 的聚合目标投影为 MEASURE；KEY/TIME 不变，保证粒度契约。
