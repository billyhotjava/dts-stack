# F12 非功能预算（G1 产物，2026-09-22）

本文把散落在 F12 设计文档中的非功能指标收口为一张可验证的预算表。**全部数值为初版预算，尚未实测；未实测前不是性能承诺。** 由 F12-T07 以标准夹具压测校准，校准结果回写本表并保留调优记录。

标准性能夹具：100 模型 + 20 卡片 + 3 大屏。测量须同时记录机器规格、数据量、P50/P95 与失败率。

## 延迟与吞吐

| 指标 | 预算 | 适配函数（T07 执行） | 状态 |
|---|---|---|---|
| preview P95 | ≤ 10 秒 | 标准夹具连续 20 次预览取 P95 | 未实测 |
| 导入草稿 P95 | ≤ 60 秒 | 标准夹具 apply 到全部对象写入完成；**排除模型物化与外部采集** | 未实测 |
| 主动执行时间与等待用户物化时间 | 分开报告 | 不得用"排除所有等待"的数字冒充端到端耗时 | 规则已定 |
| worker 并发 | 每服务/租户初始 2 | 超出返回可恢复排队，不丢任务 | 未实测 |
| 恢复扫描 | 60 秒周期，每次 ≤ 100 项 | 索引 `(status,nextCheckAt)` 分页，租户公平调度 | 未实测 |

## 包与解压预算

| 项 | 预算 | 说明 |
|---|---|---|
| 旧模型 ZIP 上传上限 | 32 MiB | 保持现状不变 |
| 完整应用包上传上限 | 32 MiB | 首版与旧包一致 |
| 解压后总大小 | ≤ 256 MiB | 跨层累计 |
| 文件数 | ≤ 5000 | 跨层累计 |
| 目录层级 | ≤ 12 | 嵌套 dbt 包只允许一层 |
| 压缩比 | ≤ 100 | 超出判为解压炸弹 |
| 单张静态资源 | ≤ 10 MiB，宽高 ≤ 8192 | 仅 PNG/JPEG/WebP，按文件头验证 |

注意：不能只放宽 Nginx 上传限制而忽略应用层与解析层预算，三者须同时满足。

## 可靠性

| 指标 | 预算 |
|---|---|
| 网络/5xx 自动重试 | 最多 5 次，指数退避 2/4/8/16/32 秒加抖动 |
| 权限/语义/版本冲突 | 不自动重试，直接转人工 |
| worker 租约 | 30 秒租约，每 10 秒续约，过期由扫描器接管 |
| 续建授权有效期 | 24 小时，后台每次执行仍重新验权 |
| 预览有效期 | 15 分钟（重置预览同） |

## 保留策略

| 对象 | 保留 |
|---|---|
| 未 apply 的检查包 | 7 天过期；运行中的包与暂存载荷不受检查缓存清理影响 |
| 运行完成的临时上传文件 | 7 天后可清理 |
| 终止的暂存载荷 | 30 天供排障；过期后只清载荷，保留 hash、结果与错误 |
| 审计、重置记录、身份代际、操作回执 | 不由临时清理任务删除 |

## 告警阈值（初版，T07 压测确认）

| 告警 | 阈值 |
|---|---|
| 可执行项排队 | > 5 分钟 |
| 租约连续失效 | 3 次 |
| 恢复失败率 | 5 分钟窗口内 ≥ 5 次且 > 5% |
| 等待上游 | > 24 小时（标记"需重新确认"，不盲目重试或删除） |
| reset PARTIAL_FAILED 持续 | > 5 分钟 |

`correlationId` / `runId` / `itemKey` / `operationKey` / `actorId` / `departmentId` / `packageHash` / `targetPin` / `errorCode` / `retryCount`。**不记录凭据、令牌、密码或完整 SQL 参数。**

## 门禁

F12-IT-14 为性能门禁用例。不达标时按预算修实现，不放宽承诺；若确需调整预算，须在本表记录调整原因、实测数据与批准人。

## 测量口径与边界补充

MiB=1048576字节；大小/数量/层级均为含等号上限，边界测试取上限与上限+1。路径深度按规范化后从包根起的目录段计数（文件名不计）；内层 dbt 包单独限制目录深度，同时仍只有一层嵌套。文件数统计非目录条目，嵌套ZIP条目自身及内部文件均计入；展开大小按各层实际流出字节累计，含内层ZIP自身字节及展开内容。压缩比按每条目和全包实际解压/压缩字节分别校验，任一超100拒绝；零压缩字节而非空输出拒绝，不信任目录头声明大小。

IT-14 的 READY 组在上游真实可用且无外部等待时测全部写入；WAITING组另报暂存完成、等待上游、续建和端到端时间，不能剔除等待后称端到端60秒。20次独立成功/失败样本均保留，P95采用排序后的第19个样本（nearest-rank），失败率另报且任何功能失败不因延迟合格而通过。PERF夹具须登记查询数据集数量。计数/租约/重试等规则有 UT-08/09/34–36 边界用例，真实预算由 IT-11/14/28验证；本文仍未实测。
