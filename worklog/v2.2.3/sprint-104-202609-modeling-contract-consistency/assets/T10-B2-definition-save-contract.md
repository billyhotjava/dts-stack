# T10-B2：首次保存模型设计契约

范围：新建手工模型 W1 定义保存。已有模型仍使用现有实现编辑入口，完整四阶段向导尚未交付。

- 页面仅填写业务归属、名称、定义、粒度、字段及适用的维度／时间／应用语义；数据来源、加工和物理表配置进入后续实现阶段。
- 唯一主操作为“保存设计并继续”。失败保留输入和创建操作标识，成功取得模型标识后进入 implementation 上下文。保存定义不代表实现或发布成功。
- 原子接口 POST /api/modeling/model-specs/draft-operations 增加可选 saveMode：DEFINITION_ONLY / WITH_IMPLEMENTATION，缺省沿用原模式。定义模式 implementation 必须为空。
- 定义模式仅延后缺少上游这一实现阶段条件，其他字段、引用、租户、修订约束保留。原普通更新、实现和发布校验不放宽。
- 定义操作使用独立幂等键命名空间，重复提交不得重复创建；不同内容同键冲突。创建与定义更新同事务，不新建状态机。
- 验证：定义模式汇总／应用无上游可保存；无效逻辑字段／引用拒绝；完整模式仍要求实现；重复请求无副作用；新建页面不显示实现控件且仅一个主操作。
- 按开发目录提交推送、部署目录拉取同 SHA 后测试构建；容器部署及 Chrome 95 验收另记实际证据。
