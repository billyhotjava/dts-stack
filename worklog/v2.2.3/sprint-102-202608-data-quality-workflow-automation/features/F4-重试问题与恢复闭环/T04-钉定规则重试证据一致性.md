# T04：钉定规则重试证据一致性

**优先级**：P1  
**状态**：DONE  
**依赖**：F3/T04

## 目标

模型质量工作流重试必须复用原候选钉定的规则版本与绑定，不能因规则后续发布而改变发布证据口径。

## 技术设计（Contract-first）

- 通用重试识别 `MODEL_RELEASE` 上下文并解析完整钉定数组。
- 新工作流登记 `retryOfId` 和递增 `attemptNo`，触发类型为 `RETRY`，规则执行仍使用原 `ruleVersionId/bindingId`。
- 兼容 Sprint-102 早期单规则 `{ruleVersionId,bindingId}` 上下文。

## 验证（RED→GREEN）

- [x] 发布新规则版本后重试仍调用原版本。
- [x] 多规则重试保持规则数量和绑定集合一致。
- [x] 上下文损坏时返回稳定错误，不退化为当前版本执行。
