# T03：终态聚合、查询、权限与审计

## 实现

- 聚合器把子运行收敛为 `RUNNING/PASSED/FAILED/BLOCKED`，并更新完成/通过/失败计数。
- 提供列表、详情和子运行查询；列表上限 200，读取逐资产 fail-closed。
