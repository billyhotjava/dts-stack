# T02：幂等编排命令与规则运行关联

**状态**：DONE  
**依赖**：F1/T01。

## 实现

- `QualityWorkflowOrchestrator.start` 是唯一工作流 command boundary。
- 解析已启用、已发布、已绑定规则；单工作流最多 100 条。
- 调用 `QualityRunService` 新增的内部 workflow 入口，并写入同一 `job_id`。
- 重复幂等键返回原工作流；不创建新的子运行。

## 测试 / DoD

- [x] 重复启动、跨范围复用幂等键、无规则、超过上限、部分分发失败均有测试。
- [x] 所有子运行共用 workflowId，原人工/调度/候选执行测试不回归。
