# T04：正式人工入口与策略维护权限收口

**优先级**：P1  
**状态**：DONE  
**依赖**：F1/T04

## 目标

规则列表、运行策略和兼容 API 的正式人工执行全部进入唯一工作流命令边界；所级与部门级数据管理员按对象权限维护策略。

## 技术设计（Contract-first）

- 新入口 `POST /api/governance/quality/workflows/trigger`，请求沿用 `QualityRunTriggerRequest`，返回完整 `QualityWorkflowRunDto`。
- 旧 `POST /api/governance/quality/runs` 响应保持 `List<QualityRunDto>`，但非 dry-run 人工调用内部委托工作流编排并返回其 `ruleRuns`。
- `DELETE /api/governance/quality/tasks/{id}` 复用 governance maintainer guard；服务层按 `X-Active-Dept` 校验策略资产可见性。

## 验证（RED→GREEN）

- [x] 人工规则执行产生 workflowId，规则运行的 `jobId` 指向该工作流。
- [x] 旧接口兼容返回规则运行，但不再产生 legacy run。
- [x] `ROLE_INST_DATA_OWNER` 可删除；部门角色只能删除本部门可见资产的策略。
