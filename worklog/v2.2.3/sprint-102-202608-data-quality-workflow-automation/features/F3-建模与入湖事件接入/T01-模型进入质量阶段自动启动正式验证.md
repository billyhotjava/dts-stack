# T01：模型进入质量阶段自动启动正式验证

**状态**：DONE

- 用户在既有交付状态机中进入质量检查阶段后，以 candidate、规则版本和绑定快照生成幂等键，自动启动钉定规则版本的工作流。
- 不在构建完成时暗中跨越 `BUILT → QUALITY_RUNNING`；构建和质量阶段仍可被用户理解、重试和审计。
- `ModelPublicationQualityReconciler` 继续消费正式治理运行证据，不创建第二套质量结果。
- FAILED/BLOCKED 阻断未发布候选；PASSED 提供发布证据。
- 模型页面显示状态、证据和重试入口；单条运行可继续跳转到完整验证工作流，不复制规则配置。
