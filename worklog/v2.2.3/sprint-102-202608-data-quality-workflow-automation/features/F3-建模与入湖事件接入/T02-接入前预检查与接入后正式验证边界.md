# T02：接入前预检查与接入后正式验证边界

**状态**：DONE

- 文件暂存预检查只验证待提交数据并驱动接入决策，不写入正式资产质量工作流，也不冒充发布门禁证据。
- API/Airflow 数据接入成功后，按执行时冻结的 `qualityPolicyRef` 经平台 workflow/`QualityRunService` 启动正式资产验证；是否启用过暂存预检查都不能跳过。
- 以 dataset + ingestion execution 生成稳定幂等键，并在 `ingestion_execution` 同时保存 `quality_workflow_id` 与代表性 `quality_run_id`。
- 接入已完成后的质量失败不回写接入成功事实，由工作流登记问题并形成后续治理闭环。
