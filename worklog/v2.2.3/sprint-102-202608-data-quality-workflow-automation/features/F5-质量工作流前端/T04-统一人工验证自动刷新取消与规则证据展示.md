# T04：统一人工验证、自动刷新、取消与规则证据展示

**优先级**：P1  
**状态**：DONE  
**依赖**：F1/T04、F2/T04、F3/T04、F4/T04

## 目标

用户从规则列表执行后直接看到工作流；活动状态自动刷新，可取消等待，并能按规则名称定位失败证据。

## UI 交互规格

- 规则列表“执行”调用 `/quality/workflows/trigger`，成功后打开“运行记录”并以 `workflowId` 展开详情。
- 工作流存在 `QUEUED/RUNNING` 时每 5 秒静默刷新列表和已打开详情；终态后停止。
- 工作流详情展示规则名称，无法解析名称时显示规则 ID，不再只显示“第 N 条规则”。
- 活动工作流提供“取消验证”并二次确认；状态筛选包含“已取消”。
- “重新验证”以来源工作流 ID 作为请求幂等边界，连续点击或网络重放不会创建重复流程；再次重试应从新生成的失败流程发起。
- 模型自动启动失败显示服务端稳定错误和“重新验证”入口；接入触发失败显示“系统将自动补偿”。
