# 非功能预算（Gate G1）

**依据**：`assets/domain-profile.md` 与现有质量执行器容量  
**适用范围**：工作流实例、运行策略、统一触发 API、聚合查询和前端列表。

| 维度 | 预算 | 可执行适应度函数 | Task |
|---|---|---|---|
| 批量上限 | 单工作流最多 100 个规则运行 | 单测：101 条可执行绑定返回 `QUALITY_WORKFLOW_RULE_LIMIT_EXCEEDED` | F1/T02 |
| 幂等 | 同一幂等键只产生 1 个工作流 | 唯一约束 + 并发/重复调用 IT | F1/T01、T02 |
| 并发 | 同一策略默认 `SKIP` 已在运行实例 | 服务测试断言第二次启动返回已有实例/阻断，不并发复制 | F2/T01 |
| 查询 | 列表最大 200 条，详情批量读取子运行，禁 N+1 | API 参数上限测试 + repository 聚焦测试 | F1/T03、F5/T02 |
| 索引 | 幂等键唯一；状态、策略+时间、资产+时间、父重试均有索引 | Liquibase 测试断言索引名 | F1/T01 |
| 重试 | 默认最多 1 次；策略上限 5 次；仅可重试终态 | 边界值与状态转换单测 | F2/T01、F4/T01 |
| 调度 | 领取与创建工作流原子化；时间槽幂等 | 两次 tick 只产生 1 个 workflow 的测试 | F2/T02 |
| 聚合延迟 | 子运行完成后 10 秒内形成工作流终态 | 聚合器测试 + 配置断言 `delay<=10000ms` | F1/T03 |
| 审计 | START/RETRY/FINALIZE 必须分类且含 workflowId | dts-admin 迁移测试 + service audit test | F1/T03、F4/T01 |
| 权限 | 越权读取/重试返回 403，列表 fail-closed | Resource/Service 权限测试 | F1/T03、F5/T02 |
| 兼容性 | Chrome 95 语法/CSS 基线；旧 `/quality/tasks`、单次运行 API 保留 | 前端构建 + Chrome95 集中 smoke | F5、F6 |
| 故障模式 | 无规则、资产不可见、执行器拒绝、审计失败均有稳定 blocker/error code | 参数化服务测试 | F1/T02、F4 |
