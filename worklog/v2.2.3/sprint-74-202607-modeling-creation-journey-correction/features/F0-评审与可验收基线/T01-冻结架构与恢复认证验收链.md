## 目标

冻结实施基线，并证明自动化可通过用户名密码登录访问真实建模 API 和页面。

## 技术设计（Contract-first）

- **输入契约**：当前 branch/HEAD、`git status --short`、Sprint-73 owning files、`dts.local` 路由、测试账号引用。
- **输出契约**：`it/baseline.md` P1/P2/P5/P6/P7=PASS；记录基线 commit 和冲突文件，不保存密码。
- **数据流**：DNS/hosts → Traefik → Keycloak 用户名密码 → authenticated storage state → `/api/modeling/model-specs` → `/modeling/models`。
- **错误路径**：DNS 失败、证书失败、登录失败、403、API timeout 分别记录；不得用关闭认证替代。
- **复用点**：账本 L18；既有用户名密码测试使能方案和 Chrome95 harness。
- **实现方案**：先只读影响审计，再固定 host mapping、测试账号来源和 storage-state 生成脚本；重新执行 P1～P7。
