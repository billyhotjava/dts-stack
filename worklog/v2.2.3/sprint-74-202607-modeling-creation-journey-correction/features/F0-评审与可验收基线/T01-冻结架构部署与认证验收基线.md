## 技术设计（Contract-first）

- **输入契约**：当前 branch/HEAD、`git status --short`、Sprint-73 基线提交 `645ea2800`、运行镜像创建时间、`databasechangelog`、`dts.local` 路由和测试账号引用。

- **错误路径**：镜像落后、迁移缺失、DNS 失败、证书失败、登录失败、403、API timeout 分别记录；任一失败均不得用旧镜像、直写数据库或关闭认证替代。

- **实现方案**：先更新 GitNexus 并完成 owning symbol 影响审计；保留无关 dirty 文件；再构建/部署当前提交、核对 Sprint-73 迁移，最后固定 host mapping、测试账号来源和 storage-state 生成脚本并重跑 P1～P7。
