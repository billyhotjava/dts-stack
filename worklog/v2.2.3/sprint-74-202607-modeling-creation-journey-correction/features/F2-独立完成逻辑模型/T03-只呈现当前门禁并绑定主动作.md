# T03：只呈现当前门禁并绑定主动作

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F2/T02

## 目标

让页面主动作和待修复数量完全由当前服务端 gate 决定，不再一次展示未来发布缺口。

## 技术设计（Contract-first）

- **输入契约**：`ModelSpecStageGate[]` + activeStage + current revision/checksum。
- **输出契约**：`CurrentGateProjection {gate, blockerCount, primaryAction, futureGates}`。
- **映射**：logical→DESIGNED；implementation→IMPLEMENTATION_READY；physical/result→RELEASE_READY/发布状态。
- **数据流**：load model + gates → 丢弃 revision/checksum 不匹配结果 → projection → blocker card/primary action。
- **错误路径**：gate API 失败时主动作 fail closed、保留已填表单、显示重新检查；不得回退前端猜测。
- **复用点**：账本 L07/L08；现有 stageProjection、BlockerPanel。
- **实现方案**：给 `getModelSpecDetailStageProjection` 传 current blocker；默认渲染单 gate；未来 gate 进入 Collapse。

## UI 交互规格

- 顶卡标题改“当前任务”；
- blocker 数量只计当前 gate；
- “查看以后阶段要求”展开后显示未来 gate，但标记“以后处理”；
- 已 DESIGNED 时主动作是“配置数据实现”，不是逻辑 blocker；
- 网络失败时主动作禁用并说明原因。

## 影响范围

ModelSpecDetailPage、stageProjection、BlockerPanel、guidance、source-contract tests。
