# T02：将治理必填收敛到计划发布策略

**优先级**：P0  
**状态**：DONE
**依赖**：F2、Sprint-72、Sprint-69

## 目标

把字段标准、质量和密级要求放在正确的发布阶段，并准确告诉用户哪些字段需要处理。

## 技术设计（Contract-first）

- **输入契约**：WarehousePlanPolicy CAS、标准/质量策略和 Sprint-72 当前密级传播证据。
- **Policy 扩展**：
  - `standardCoverage:"NONE"|"KEY_AND_MEASURE"|"ALL_FIELDS"`
  - `qualityGate:"ADVISORY"|"BLOCKING"`
- **迁移默认**：已有计划 backfill `ALL_FIELDS/BLOCKING` 保持旧行为；新计划默认 `KEY_AND_MEASURE/BLOCKING`。
- **旧客户端兼容**：PlanningPolicyCommand 新字段为 nullable；旧客户端 PUT 省略字段时保留数据库现值，不把已配置策略重置为默认。
- **输出契约**：Policy response 始终返回解析后的 standardCoverage/qualityGate；RELEASE_READY 只返回策略命中的 blocker。
- **密级契约**：不提供 OFF；复用 `ModelClassificationPublishGate`，显式/继承/传播任一可信证据可满足。
- **Gate 规则**：DRAFT_SAVE/DESIGNED 不检查；IMPLEMENTATION_READY 不检查发布证据；RELEASE_READY 按 policy 检查。
- **错误路径**：policy 不可读时 RELEASE_READY fail closed；不影响逻辑保存。
- **复用点**：账本 L14；Sprint-69 质量证据、Sprint-72 密级 gate、WarehousePlan policy CAS。
- **实现方案**：扩 policy 表/DTO/UI；release gate 返回字段级 repair list；禁止再次读取 UI 本地规则推导。

## UI 交互规格

逻辑页“治理要求”显示“当前可选，发布策略要求 X”；发布门禁只列策略命中的字段；继承密级显示来源，不要求重复手填。

## 影响范围

WarehousePlanPolicy migration/contract/UI、ModelSpecStageGateService、standard/classification/quality evidence tests。
