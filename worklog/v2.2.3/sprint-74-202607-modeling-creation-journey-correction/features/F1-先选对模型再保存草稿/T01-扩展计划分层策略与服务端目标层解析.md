# T01：扩展计划分层策略与服务端目标层解析

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F0

## 目标

让 modelType 与 layer 解耦，并按建设计划策略稳定解析目标层。

## 技术设计（Contract-first）

- **输入契约**：`WarehousePlanPolicy.layerScheme`=`CLASSIC_ODS_DWD_DWS_ADS | DATAWORKS_5_LAYER_V1`，`ModelType` 四类。
- **输出契约**：`ModelLayerPolicyResolver.resolve(planId, modelType): Layer`；映射严格采用 README §7.1。
- **数据契约**：扩展 Layer 枚举 `DIM`；复用 `modeling_warehouse_plan_policy.layer_policy_code`，不新建表。
- **错误路径**：策略缺失/未知返回 `MODEL_LAYER_POLICY_NOT_READY`；客户端提交 layer 不匹配返回 422；已存在实现/发布结果的计划切换返回 409。
- **复用点**：账本 L03/L04；既有 policy CAS。
- **实现方案**：先扩 enum/read compatibility，再新增 resolver，再切换 create/update/import 共同使用；禁止各调用点复制映射表。

## UI 交互规格

建设计划策略页新增 DataWorks 方案选项，并在切换前显示影响预检；模型创建页只读展示“目标层由计划策略决定”。

## 影响范围

WarehousePlan contract/service/UI、ModelSpec contract/service、dbt import layer validation、tests、Liquibase enum/check 约束（如存在）。
