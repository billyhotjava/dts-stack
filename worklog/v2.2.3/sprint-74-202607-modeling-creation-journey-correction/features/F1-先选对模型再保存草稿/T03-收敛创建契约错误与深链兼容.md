# T03：收敛创建契约、错误与深链兼容

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F1/T01、F1/T02

## 目标

保证页面、API、服务端 layer 解析和旧深链对同一次创建给出一致结果。

## 技术设计（Contract-first）

- **输入契约**：Create v2 字段白名单；合法 `modelType` query 可预选；非法 query 忽略并保持未选择。
- **输出契约**：201/200 返回 canonical view 和 ETag；`layer` 必须等于服务端 policy resolver。
- **错误路径**：
  - 400：未知字段/非法类型；
  - 409：幂等键冲突、维度实现变体冲突；
  - 422：计划策略未就绪/分类不属于计划/维度定义无效；
  - 403：无维护权限。
- **复用点**：账本 L02/L04；既有 decoder、idempotency、repairRoute。
- **实现方案**：更新前后端同构校验和 source-contract；错误返回保留表单草稿；深链来源可见。

## UI 交互规格

错误提示放对应字段；冲突提供“查看已有模型”；无权只读不显示可提交主动作。

## 影响范围

ModelSpecCreateRequestDecoder、ModelSpecApplicationService、ModelSpecCreateDrawer、API types/tests。

## 验证（RED→GREEN）

- [ ] 前后端 create field 白名单一致
- [ ] 同 idempotencyKey 重放不重复
- [ ] 非法深链不默认 FACT
- [ ] policy layer 与响应一致

## Definition of Done

- [ ] 架构：UI/API/service/data 链一致
- [ ] UI：错误不清空输入且修复入口有效
- [ ] 切片：真实 create journey 通过
