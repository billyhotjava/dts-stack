# T01: 资产详情治理健康摘要

**优先级**: P0  
**状态**: READY  
**依赖**: F0

## 目标

在资产详情中集中展示质量规则、质量运行、治理缺口、授权状态和下一步入口。

## 技术设计

- 优先复用 `/catalog/datasets/{id}/governance-health`。
- 质量明细跳 `/governance/quality`。
- 授权明细跳 `/governance/asset-grants`。
- 治理缺口跳资产台账对应筛选或详情 tab。

## 影响范围

- `DatasetDetailPage`
- `DatasetsPage`
- `AssetGrantPage`
- `QualityReportPage`

## 验证

- [ ] 治理健康摘要有成功/预警/阻断三种状态。
- [ ] 每个状态都有下一步按钮或不可操作原因。

## 完成标准

- [ ] 资产可信度不用离开详情页才能判断。
