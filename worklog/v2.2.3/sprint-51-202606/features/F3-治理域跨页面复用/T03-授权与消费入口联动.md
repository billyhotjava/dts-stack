# T03: 授权与消费入口联动

**优先级**: P1  
**状态**: READY  
**依赖**: T01

## 目标

让资产消费、API 发布、BI 报表入口能解释授权不足或治理未完成的原因。

## 技术设计

- 资产操作列展示“申请授权 / 查看授权 / 发布服务”状态。
- 数据产品和 API 页面保留 assetId/productId 上下文。
- 无权限时跳转到授权申请或审计页，不显示假成功。

## 影响范围

- `DatasetsPage`
- `DataProductsPage`
- `ApiServicesPage`
- `AssetGrantPage`

## 验证

- [ ] 无授权时按钮禁用原因明确。
- [ ] 有授权时进入消费/服务页面保留上下文。

## 完成标准

- [ ] 消费链路和治理授权能互相解释。
