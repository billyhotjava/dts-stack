# T02: 指标/SQL 建模页显示质量与门禁状态

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

让指标或 SQL 模型在发布前能看到关联数据集的质量、标准映射和门禁结果。

## 技术设计

- SQL 建模页延续 Sprint-50 标准门禁。
- 增加关联数据集质量摘要和血缘状态。
- 若缺少 API，优先使用现有质量报告/资产详情跳转。

## 影响范围

- `SqlModelingPage`
- 指标相关治理页面
- 标准门禁 source-contract

## 验证

- [ ] 发布按钮旁可见门禁状态。
- [ ] 门禁失败时有明确修复入口。

## 完成标准

- [ ] 建模发布不再只看 SQL/dbt 成功。
