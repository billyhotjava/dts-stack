# T01：形成目标导航与页面蓝图

**优先级**：P1
**状态**：DONE
**依赖**：F1/T01、F1/T02、F2/T01、F3/T01

## 目标

让用户从菜单即可理解“在哪里定义架构、在哪里建模型、在哪里找资产、在哪里管指标和质量”，并明确模型批量物化的操作落点。

## 输入/输出契约

- 输入：现有菜单种子、七个建模入口、资产概览/台账、`/governance/subjects` 独有能力、全部活深链和 E2E-A～C。
- 输出：目标菜单树；页面能力矩阵；旧→新路由映射；关键页面线框；批量物化交互说明。完整候选见 [`assets/information-architecture-blueprint.md`](../../assets/information-architecture-blueprint.md)。
- 错误路径：任何旧能力无承接页面、深链参数不被目标页消费、批量选择状态不可恢复时，蓝图不通过。
- 复用点：既有页面/路由/菜单种子与 Sprint-85 URL filter protocol；不新建平行页面。

## Definition of Ready

- [x] F1～F3 已提供 owner、关系、资产状态、指标上下文和批量候选语义
- [x] 旧页面、Tab、按钮、路由、菜单种子、source-contract 和活深链输入清单已形成
- [x] ADR-86-09/15 与 NFR-86-03～07 已有候选、错误路径和超规模降级要求
- [x] `SEARCH_THRESHOLD = 8` 已明确只控制搜索框可见性，不被误用为页面形态阈值
- [x] IT-05 已登记真实参与者、目标日期和蓝图验收项

## 操作走查候选

1. 架构管理员维护业务分类/数据域，资产和指标选择器同步可见。
2. 建模人员在模型 Table 筛选某域，多选已具备候选条件的模型，创建批量物化候选并看到逐项状态。
   **（RF-86-10）** 原子失败/显式排除策略本身由 F1/T02 冻结（ADR-86-15）；本 Task 只设计该策略的交互呈现与失败可见性，不反向定义语义。
3. 资产治理人员可从“全部资产”或“未归域”进入台账，不选域也能看到未归域资产；完成归域后再按域导航。
4. 指标管理员选择业务分类→数据域→业务过程，类型单独选择。
5. **（RF-86-03 补充）** 治理人员筛出未归域资产 → 多选 → 批量归域 → 查看逐项成功/失败与审计 → 域计数刷新；该路径与“全部资产/按域浏览”并存。
6. 建模人员打开已发布模型，分别看到模型 revision、候选/物化状态、语义资产和物理关系状态，不把任一状态合并成单一“已物化”。
7. 建模人员再次物化同一批模型，界面显示新 attempt、依赖拓扑和逐项结果；旧运行/观测仍可查看，新 revision 不复用旧 candidate entry。
