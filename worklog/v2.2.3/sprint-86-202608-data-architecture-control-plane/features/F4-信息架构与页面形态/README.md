# F4：信息架构与页面形态

**优先级**：P1
**状态**：DONE（Architecture）

## 目标

形成数据架构、建模、资产、指标、质量的目标导航与页面职责蓝图，决定何处使用树、Table、详情编辑器和批量操作。

## UI/UX 候选规格

- 数据架构：层级架构字典采用树/分组 + Table，**按客户口径（10～50、两层）单一形态设计**；平面台账采用搜索 + Table + 抽屉。不承诺双形态自适应（RF-86-14）。
- 数据建模：模型清单采用可多选 Table；详情进入编辑器；树仅作为分组/筛选，不承担批量选择。
- 数据资产：台账继续搜索 + Table；“全部/未归域/按域”均可达，域树只作范围导航，不拥有域 CRUD；批量归域是独立一等操作。
- 指标/质量：业务上下文只读选择，管理入口回链数据架构。
- 四态、Chrome 95 和 source-contract 由下一实施 Sprint 钉死。
