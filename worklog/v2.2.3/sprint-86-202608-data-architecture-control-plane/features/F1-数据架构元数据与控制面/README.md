# F1：数据架构元数据与控制面

**优先级**：P0
**状态**：DRAFT

## 目标

冻结平台全局的统一语言、canonical owner、关键实体关系和生命周期，回答哪些能力属于数据架构字典、哪些属于建模项目范围，并与后续业务主数据管理划清边界。

## 契约定义

| 类型 | 候选契约 | 待冻结内容 |
|---|---|---|
| 数据 | `catalog_domain`、业务过程、分层、集市、主题域、计划表 | 全局作用域、稳定 ID、类型/层级、状态与版本；计划与架构字典分离 |
| API | `/api/catalog/domains*` 与规划资源 | 唯一维护入口、consumer read port、兼容路由 |
| 权限/审计 | 现有 read/write/export + 公共审计 | 数据架构管理员边界与每个写动作 |

## Definition of Ready

- [ ] 数据架构一级入口是否成立已决定
- [ ] 数仓计划、集市、主题域的 owner 边界已决定
- [ ] 平台全局与未来 tenant 兼容规则已决定
- [ ] 每个实体的 ID、层级、状态和版本契约已钉死
- [ ] E2E-A～D 的关系、owner、状态传播和失败路径已评审
- [ ] “数据架构元数据”与“业务主数据（MDM）”边界已冻结
