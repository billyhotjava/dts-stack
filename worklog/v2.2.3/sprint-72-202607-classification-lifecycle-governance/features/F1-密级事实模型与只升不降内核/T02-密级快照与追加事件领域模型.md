# T02: 密级快照与追加事件领域模型

**优先级**: P0
**状态**: IN_PROGRESS
**编码状态**: DONE（统一验证延后）
**依赖**: T01

## 目标

为资产、字段、文件和消费组件建立统一密级快照与不可变事件事实。

## 技术设计

- 新建 `catalog_classification_snapshot` 和 `catalog_classification_event`。
- 复用 `CatalogAssetType + CatalogAssetKey`；字段使用稳定 column key。
- 保存 declared/detected/manualFloor/effective/origin/seal/version/checksum/status。
- 事件仅追加，禁止业务 UPDATE/DELETE。

## 影响范围

`dts-platform` domain/repository/Liquibase，审计动作目录。

## 验证

- [ ] 唯一键、四级 check、事件只追加和审计字段测试。
- [ ] 同一 subject 重复 seal 幂等，冲突 checksum 被拒绝。

## 完成标准

- [ ] 任一有效密级都能解释到来源证据。
- [ ] 数据库层阻止非法密级编码。
