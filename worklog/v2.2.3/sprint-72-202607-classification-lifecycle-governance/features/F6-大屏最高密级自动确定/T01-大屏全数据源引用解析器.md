# T01: 大屏全数据源引用解析器

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: F5-T01,F5-T02

## 目标

从大屏 JSON 中提取所有真实数据依赖并解析到可查询的密级事实。

## 技术设计

- 遍历 `components/pages/v2Spec` 和全部 drill levels。
- 支持 card、metric、dataset、sql/database、api；static 不提高密级。
- SQL 解析到 catalog dataset/column，API 解析到已登记 SvcApi。
- 自定义插件必须声明数据源；任意 URL 或未知 SQL 形成 unresolved evidence。

## 影响范围

`dts-analytics` ScreenSpec/Resource/service、platform classification internal API、插件契约。

## 验证

- [ ] 六类来源、多页面、隐藏组件、多级下钻、自定义插件。
- [ ] 未知和恶意 JSON 不绕过解析。

## 完成标准

- [ ] 返回 resolved/unresolved 来源清单和各自密级。
- [ ] 解析结果可稳定计算 checksum。

## 编码进展

已实现全量 JSON 递归解析，覆盖 card、metric、table/dataset、database、API 规范资产键及
显式密级主体；API 缺少规范资产键时形成 unresolved 阻断。统一测试延后。
