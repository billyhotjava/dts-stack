# T02: 保存、发布和运行时最高密级裁决

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01

## 目标

大屏在保存、发布和访问时都由服务端计算并校验当前最高有效密级。

## 技术设计

- 草稿保存记录解析结果；unresolved 可保存但标记治理阻断。
- 发布前要求全部来源 resolved，写 classification snapshot/version。
- 有效密级为 `max(manualFloor, allDisplayedSources)`。
- 运行时读取当前上游最高值，防止旧发布版本继续低密访问。

## 影响范围

`AnalyticsScreen`/version、ScreenResource publish/save/read、platform sync。

## 验证

- [ ] 保存、发布、上游升密后访问和旧版本回放。
- [ ] 客户端提交较低 classification 不生效。

## 完成标准

- [ ] 服务端是大屏密级最终裁决方。
- [ ] 大屏详情能返回计算时间、版本和来源摘要。

## 编码进展

已实现保存后派生、发布/回滚/预览/导出当前快照检查，以及有效密级、快照版本、计算时间
和证据摘要投影。统一测试延后。
