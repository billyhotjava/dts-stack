# T05: 资产详情人工密级下限与审批入口收敛

**优先级**: P0
**状态**: IN_PROGRESS
**编码状态**: DONE（待部署后 Chrome 95 页面 smoke）
**依赖**: F1-T03,F4-T06

## 目标

消除资产详情仍可直接编辑“密级”和“生命周期”的错误产品语义，让有效密级只读、人工值只能升高，并把生命周期变更统一导向审批工作台。

## 技术设计

- 资产详情页头增加“密级与生命周期”直接入口，复用现有工作台 Drawer。
- OpenMetadata 治理扩展表单移除普通 `classification`、`lifecycleStatus` 和 `enabled` 写入口。
- 单独展示来源声明、人工下限和当前有效密级；人工下限调用不可降级 `manual-floor` API。
- 低于当前有效密级的选项禁用，人工下限不能清空或降低。
- 生命周期状态只读，并明确提示归档、销毁和恢复必须从审批工作台执行。
- 保留仓库分层、归属部门、业务负责人和安全策略引用等普通治理扩展。
