# T03: 生命周期密级统计与趋势

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: F4-T01

## 目标

按密级统计在用、共享、归档、回收站、永久销毁的数据数量、数据量和趋势。

## 技术设计

- 统计来源为生命周期 projection 和密级快照，不扫业务数据内容。
- 支持部门、主题域、资产类型、密级、时间范围过滤。
- 数量与数据量分开，未知 size 明确标注，不伪造 0。
- 永久销毁统计取 destruction proof，不依赖已删除对象。

## 影响范围

governance ops metrics、catalog lifecycle API、治理监控 UI。

## 验证

- [ ] 各状态聚合、权限过滤和未知数据量。
- [ ] 归档/恢复/销毁后趋势更新。

## 完成标准

- [ ] 满足生命周期专项监控要求。
- [ ] 指标可追溯到统计口径和事实表。

## 编码进展

已基于生命周期事件、回收站事实、销毁证明和访问绑定，按阶段与有效密级统计资产数量、
已知数据量和未知数据量，并提供 30 天事件趋势；不扫描业务数据内容。统一测试延后。
