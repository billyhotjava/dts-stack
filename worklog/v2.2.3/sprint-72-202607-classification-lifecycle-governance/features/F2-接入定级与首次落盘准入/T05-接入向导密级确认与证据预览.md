# T05: 接入向导密级确认与证据预览

**优先级**: P0
**状态**: IN_PROGRESS
**编码状态**: DONE（统一验证延后）
**依赖**: T01,T02,T03

## 目标

在现有接入向导中提供表/文件/字段密级确认、冲突说明和 seal 证据预览。

## 技术设计

- 不新增一级菜单，接入配置阶段增加“密级与准入”步骤。
- 展示源声明、平台映射、文件下限、字段升密和最终资产密级。
- 未确认时明确显示只能预检，不能生产落盘。
- UI 不允许选择低于来源/文件下限的值。

## 影响范围

`dts-platform-webapp` 数据接入、Excel/CSV 上传、API 接入向导及 API 类型。

## 验证

- [ ] JDBC、文件、API 三条 UI source-contract。
- [ ] Chrome 95 下大字段表格、错误提示和确认动作可用。

## 完成标准

- [ ] 用户能在执行前看懂最终密级及来源。
- [ ] 服务端仍是最终门禁，绕过 UI 也不能落盘。
