# T01: 六阶段生命周期统一投影

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: F1-T02

## 目标

在不物理合并稳定审批表的前提下，统一展示创建、存储、使用、共享、归档和销毁状态与事件。

## 技术设计

- 复用 `CatalogLifecycleRequest`、数据访问审批、授权和审计事实。
- 新建 lifecycle projection/read model，不复制业务正文。
- 每阶段返回状态、申请、批准、执行证据、密级快照和数据量。
- 统一状态词表和稳定 API。

## 影响范围

catalog lifecycle service/resource、访问审批、授权、审计和 DTO。

## 验证

- [ ] 七类事件投影排序、权限和部门隔离。
- [ ] 重放投影结果一致。

## 完成标准

- [ ] 一个资产可查看完整生命周期时间线。
- [ ] 既有审批 API 保持兼容。
