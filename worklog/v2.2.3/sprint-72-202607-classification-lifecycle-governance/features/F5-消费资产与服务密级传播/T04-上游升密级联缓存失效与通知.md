# T04: 上游升密级联、缓存失效与通知

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01,T02,T03

## 目标

上游升密后立即升级消费资产、失效缓存、暂停不再合格的授权并通知 owner。

## 技术设计

- 消费资产注册为 classification dependency。
- 事件驱动重算并按资产类型失效缓存。
- 暂停分享/公开链接/导出令牌，写明原因和来源。
- 通知只聚合高价值变更，避免大扇出产生消息风暴。

## 影响范围

classification event worker、metrics/analytics/platform cache、权限和消息中心。

## 验证

- [ ] 单级/多级扇出、重复事件、部分失败和通知聚合。
- [ ] 旧访问在重算窗口内也读取最高已知值。

## 完成标准

- [ ] 上游升密后不存在继续按旧低密级消费的窗口。
- [ ] owner 可查看受影响资产清单。
