# T05: 缺失/循环血缘阻断与影响解释

**优先级**: P0
**状态**: IN_PROGRESS

**编码状态**: DONE（统一验证延后）
**依赖**: T04

## 目标

对无法证明安全的缺失或循环血缘 fail closed，并向治理人员解释阻断范围。

## 技术设计

- 缺字段血缘退化到资产最高值；连资产血缘也缺失时标记 `PENDING_LINEAGE`。
- 检测环路并保留环内最高已知值。
- 发布/共享/公开链接使用稳定阻断码。
- 复用血缘影响分析展示上游、下游和待补证据。

## 影响范围

传播引擎、发布 gate、catalog lineage/impact API 和前端提示。

## 验证

- [ ] 自环、多节点环、孤儿资产和未知 SQL。
- [ ] 当前有效密级不因错误回退。

## 完成标准

- [ ] 阻断原因可由用户在治理页面定位。
- [ ] 修复血缘后可重放并自动解除阻断。
