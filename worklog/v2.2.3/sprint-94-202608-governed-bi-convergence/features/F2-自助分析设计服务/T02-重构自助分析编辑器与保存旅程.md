# T02：重构自助分析编辑器与保存旅程

**优先级**：P0
**状态**：DRAFT
**依赖**：T01、F1/T02

## 用户可测试目标

A1 从 `/bi/data` 进入唯一分析编辑器，完成字段/指标/筛选/时间/图表配置、预览和保存；刷新后草稿一致，校验与发布保持独立，任何契约漂移或语义错误均可定位且不丢当前编辑。

## UI 组件与状态

先从 `SemanticCardEditorPage.tsx` 抽取：

- `AnalysisDatasetSummary`：数据集名称、版本、checksum、owner、密级，支持只读详情。
- `AnalysisFieldPanel`：可搜索维度/指标、类型/aggregation/策略标识。
- `AnalysisConfigPanel`：筛选、时间、排序、派生指标、图表设置。
- `AnalysisPreviewCanvas`：表/图切换、rowCount/truncated/duration、取消运行。
- `AnalysisValidationPanel`：字段级 blockers/warnings、correlationId。

原页面只负责 route/load/orchestration，不得超过当前 1137 行；API 按 `analysisClient` 抽取，保留兼容 facade。

**拆分前置条件**：该页面同时是 `bi/card/new`、`bi/card/:id/edit`、`bi/virtual-datasets/new`、`bi/virtual-datasets/:id` 四条冻结路由的宿主。动刀前必须先补这四条路由（尤其 VDS 两条）的回归测试，抽取后行为零变化。见 F2 README「共享组件风险」与 ADR-94-14。

状态机：`loading contract → editing dirty/clean → preview queued/running/success/error → saving → saved DRAFT`。409 保留本地草稿并提供“刷新契约摘要/基于新版本创建草稿”；422 聚焦对应控件；403 不显示空图表；504/429 保留配置可重试。

## 交互约束

- canonical 路由为 `/bi/questions/new` 与 `/bi/questions/{id}/edit`（ADR-94-13）；后者保留 `CardEditorRoutePage` 作为类型分流器，新增 `card_type='analysis'` → Analysis editor 分支，semantic legacy 与其他 legacy Card 保持现有兼容行为。
- 新链接只接受 datasetId/version/checksum；旧 dbId/vds/base 进入兼容 adapter。**本 Sprint 不做 redirect**（属退役 S2）。
- autosave 如沿用必须只保存 DRAFT，失败可见；绝不隐式 validate/publish。
- 所有表单键盘可达，drawer/dialog 焦点回收；错误与控件通过 aria 描述关联。
- 文案统一“分析、数据集、维度、指标、保存、校验、发布”，不显示 Question/Card/MBQL/raw JSON。

## RED → GREEN

1. RED：现有创建参数无法被编辑器读取；1137 行 owner 混合状态/布局/API。
2. GREEN component tests：五组件四态、边界 validation、dirty/saved 行为。
3. GREEN route/source contract：canonical 参数、旧 link 兼容、新 client，无超大文件增长。
3b. GREEN 冻结路由回归：`bi/card/new`、`bi/card/:id/edit`、`bi/virtual-datasets/new`、`bi/virtual-datasets/:id` 拆分前后行为一致（拆分的前置 RED）。
4. GREEN focused E2E：配置→预览→保存→刷新，Network payload 为 v1 且无 raw SQL。
5. GREEN Chrome95：布局不裁剪、键盘/焦点/console/Network 通过。

## 影响范围与先决 impact

预计组件：`SemanticCardEditorPage`、`CardEditorRoutePage`、route resolver、API client、i18n、旧 editor adapter。每个 symbol 先 fresh impact；若 legacy route 调用范围 HIGH，收窄为兼容分支 contract，不删除、不新增 redirect。

## Definition of Done

- [ ] 主页面职责已拆分，超大文件不增长，未新增依赖。
- [ ] 四条冻结路由（含 VDS 两条）行为零回归，有测试证据。
- [ ] canonical `/bi/questions/{new,:id/edit}` 生效；`CardEditorRoutePage` 三类分支有聚焦测试，且**未对任何旧路由添加重定向**。
- [ ] 五类配置、预览、保存、刷新和错误恢复通过组件/浏览器测试。
- [ ] 保存不推进 validate/publish，A3 无法消费 DRAFT。
- [ ] Chrome 95 四态、键盘、焦点、布局、console/Network 通过。
- [ ] 新 UI 不调用旧 Card write/MBQL/raw JSON 编辑入口。
