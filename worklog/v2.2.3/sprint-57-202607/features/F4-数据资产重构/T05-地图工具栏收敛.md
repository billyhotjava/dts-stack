# T05: 地图工具栏收敛（用户反馈追加）

**优先级**: P0
**状态**: DONE
**依赖**: T04

## 背景（2026-07-04 用户反馈）

资产地图顶部按钮过多（进入台账/刷新资产/同步OpenMetadata/刷新核对/映射诊断/解析失败 6 个 + 5 筛选控件 + 搜索框），且"进入台账"在页面出现 3 次；同步OpenMetadata/刷新核对/映射诊断/解析失败四个按钮用户不知道干什么、怎么测试。

## 设计

1. **主操作收敛为 3 项**：`进入台账`（主 CTA，primary）、`刷新`、`同步与诊断` Dropdown。
2. **诊断动作进菜单**，每项带一行说明文案（解决"不知道怎么操作"）：
   - 同步 OpenMetadata —— 从元数据平台拉取最新资产清单（耗时较长，完成后自动刷新）
   - 映射诊断 —— 统计已映射/未匹配/待人工确认数量
   - 解析失败记录 —— 查看资产身份解析失败明细
   - 发布前核对 —— 刷新发布前回归断言结果（页面底部展开查看）
3. **筛选折叠**：默认只显示搜索框 + `筛选` 开关（Badge 显示激活筛选数）+ 条件性`重置`；展开显示 4 个 Select。
4. **进入台账去重**：删除分层 Tabs 行与链路总览头部的重复按钮，仅保留工具栏主 CTA（矩阵格下钻不受影响）。

## 实施备注

- 入口按钮不用 loading 态（挂载时自动核对会短暂灰死吞点击），改为菜单项各自 disabled + "进行中…"文案。
- "进入台账"从 3 处收敛为工具栏唯一主 CTA（primary ghost）；矩阵格下钻不受影响。
