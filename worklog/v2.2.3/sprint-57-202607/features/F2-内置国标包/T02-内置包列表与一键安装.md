# T02: 内置包列表与一键安装

**优先级**: P0
**状态**: READY
**依赖**: F1-T02, F2-T01

## 目标

后端暴露内置包清单与安装端点，前端"内置标准包"面板一键安装。

## 技术设计

**后端**（StandardPackageResource 追加）：
- `GET /api/modeling/standard-packages/builtin` — 读 classpath manifest + 对照 runs 表标注已安装（source=BUILTIN 且 status=APPLIED 且 package_code 匹配）
- `POST /builtin/{code}/install` — classpath 目录内 CSV 直接进 StandardPackageImportService（免 zip 环节），preview 无阻塞错误则自动 apply，返回与 apply 一致的摘要；有错误返回报告（理论上不应发生，视为资源缺陷）
- run 记录 source=BUILTIN, package_name=标准号

**前端**：StandardPackagePage 增加"内置标准包"Tab：卡片列表（名称/标准号/条目数/状态徽标），"安装"按钮 → 结果摘要弹窗；已安装显示"重新安装"（幂等）。

## 影响范围

StandardPackageResource、StandardPackagePage；无新表。
