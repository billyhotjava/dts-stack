# T01: 国标包资源制作

**优先级**: P0
**状态**: READY
**依赖**: F1-T01（CSV 契约冻结后制作）

## 目标

制作首批内置标准包资源文件，与客户上传包完全同构。

## 技术设计

**位置**：`dts-platform/src/main/resources/standard-packages/`
- `manifest.json` — 包目录：code, name, standardNo, description, category, entryCounts
- `gbt-2261-gender/`（5 CSV 明文目录，构建期或运行期打包，避免二进制 zip 进 git）
- 同构其余包

**首批内容**：
| 包 code | 标准 | 内容 |
|---------|------|------|
| gbt-2261-gender | GB/T 2261.1-2003 | 性别代码（0/1/2/9） |
| gbt-4658-education | GB/T 4658-2006 | 学历代码（节选常用 ~30 条） |
| gbt-2260-region | GB/T 2260-2007 | 行政区划：省级 34 + 地级市 ~333（不含区县，控制体积） |
| common-data-elements | 参照 GB/T 18391 风格 | 常用数据元 ~20 条：身份证号、手机号、统一社会信用代码、邮箱、金额、日期等，含类型/长度/security_level，code_set 关联上述码表 |

**规则**：
- 03 目录行 `std_level=NATIONAL`、`owner_dept` 留空（安装时归当前部门或公共）
- 04 码值 `sort_num` 按标准原序；行政区划用 `parent_code` 表达省→市层级
- 数据字典来源以国标文本为准，逐条核对码值（不臆造）

## 影响范围
