# T04: 前端标准包导入向导

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

在"数据基础"下提供标准包导入向导：上传 zip → 校验报告 → 确认应用 → 结果与历史（可回滚）。

## 技术设计

**新增**：
- `src/pages/foundation/StandardPackagePage.tsx` — 三步 Steps 向导 + 导入历史 Tab
  - 步骤 1 上传：Upload.Dragger（.zip，≤20MB），旁置"下载标准包模板"按钮（复用 `downloadDataStandardPackageTemplate`）
  - 步骤 2 校验报告：按 5 文件分 Tab，每 Tab 显示 新增/更新/错误 统计徽标 + 错误行表格（行号/字段/原因，标红）；有错误时"应用"置灰，提供"下载错误报告 CSV"（前端拼 blob）
  - 步骤 3 结果：入库摘要 + 跳转链接（数据元/码表/术语页）
  - 历史 Tab：CompactTable（默认 10 条/页），行操作"查看明细/回滚"（Popconfirm）
- `src/api/platformApi.ts` 追加：`previewStandardPackageImport` / `applyStandardPackageImport` / `listStandardPackageRuns` / `rollbackStandardPackageRun`

**路由与菜单**：
- static-routes 加 `foundation/standard-package`；dynamic-resolver `PATH_COMPONENT_OVERRIDES` 加 `/foundation/standard-package`
- portal-menu-seed：数据基础 → 标准管理下加"标准包导入"（externalLink 模式，同 Sprint-56 做法）；DB 手动 upsert 同步

**约束**：Chrome 95 兼容；分页约定（memory: pagination-unification-convention）。

## 影响范围

dts-platform-webapp 新页面 + platformApi + 路由 + admin seed。
