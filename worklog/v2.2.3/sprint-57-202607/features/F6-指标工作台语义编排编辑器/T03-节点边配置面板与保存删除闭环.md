# T03: 节点/边配置面板与保存删除闭环

**优先级**: P0  
**状态**: DONE
**依赖**: T01,T02

## 目标

把底部属性区扩展为 Dify 风格配置面板：选中指标节点时编辑指标公式和依赖摘要，选中关系边时编辑关系说明、派生表达式并保存或删除关系。

## 技术设计

- `MetricDetailPanel` 支持新的选中对象模型：
  - 节点选择：业务对象或指标。
  - 边选择：`OBJECT_METRIC` 或 `METRIC_DERIVES`。
  - 预检选择：问题列表。
- 指标节点配置补充：
  - 当前业务对象。
  - 上游依赖指标。
  - 下游派生指标。
  - 现有公式类型、公式 JSON、单位。
- 边配置：
  - 展示来源节点、目标节点、关系类型。
  - `METRIC_DERIVES` 可编辑派生表达式和关系说明。
  - 保存时调用 `updateSemanticMetric` 写回目标指标 `formulaJson`。
  - 删除 `OBJECT_METRIC` 时将目标指标 `objectId` 置空。
  - 删除 `METRIC_DERIVES` 时从目标指标 `formulaJson.dependsOnMetricIds` 移除来源指标。
