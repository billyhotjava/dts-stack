# T01：建立主题契约与路由映射

**优先级**：P0
**状态**：DONE

## 技术设计

- 输入：`pathname`、可选 query。
- 输出：确定性的 `HelpTopic`；未知路由返回 `getting-started`。
- 数据流：Header/帮助页/SearchBar 只读取同一 `HELP_TOPICS`。
- 错误路径：未知 id、空搜索、重复 id 均 fail-safe；不执行 HTML。
- 复用点：React Router `matchPath`。
- 范围：新增 `src/features/help-center/helpTopics.ts` 及契约测试。
