# F1: 数据资产元数据管理

**优先级**: P0
**状态**: DONE

## 目标

为数据资产菜单组新增“元数据管理”模块，让资产管理员在一个页面内看到资产语义元数据缺口，并能进入资产详情补齐治理扩展。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | Sprint 与契约测试骨架 | P0 | DONE | 无 |
| T02 | 后端菜单 seed 与角色默认入口 | P0 | DONE | T01 |
| T03 | 前端路由与元数据管理页面 | P0 | DONE | T02 |
| T04 | 集成验证与 IT 证据 | P0 | DONE | T03 |

## 页面能力

- 资产元数据健康总览：总资产、待补齐、缺负责人、缺密级、缺主题域、仅 OpenMetadata 未映射。
- 语义元数据清单：表/资产名、业务描述、负责人、部门、密级、主题域、生命周期、字段数、元数据来源、最后同步时间。
- 工作流动作：进入治理页、进入字段契约页、打开数据源结构采集、同步 OpenMetadata。
- 管理提示：明确“采集在数据集成完成，管理在数据资产完成”。
