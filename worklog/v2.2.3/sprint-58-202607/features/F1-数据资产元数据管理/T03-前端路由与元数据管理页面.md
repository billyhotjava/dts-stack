# T03: 前端路由与元数据管理页面

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

实现 `/catalog/metadata-management` 页面，让资产管理员集中查看语义元数据缺口并进入资产详情治理页。

## 技术设计

- 新建 `MetadataManagementPage.tsx`。
- 在 `static-routes.tsx` 注册静态路由。
- 在 `dynamic-resolver.tsx` 增加路径到组件映射。
- 页面复用现有 API：
  - `listCatalogAssetsV2`
  - `getCatalogAssetsV2GovernanceGaps`
  - `syncCatalogAssetsV2`
- 页面不新增后端业务接口。

## 页面结构

- 页面头：标题“元数据管理”，操作“同步 OpenMetadata”“数据源结构采集”。
- 指标区：总资产、待补齐、缺负责人、缺密级、缺主题域、OpenMetadata 未映射。
- 筛选区：关键字、密级、治理状态、映射状态。
- 清单区：资产名、描述、负责人、部门、密级、主题域、生命周期、来源、最后同步、操作。
- 操作区：
  - 治理属性：跳转 `/catalog/datasets/{id}?tab=governance`
  - 字段契约：跳转 `/catalog/datasets/{id}?tab=schema-contract`
  - 结构采集：跳转 `/catalog/metadata`
