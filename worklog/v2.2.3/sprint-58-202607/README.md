# Sprint-58: 数据资产元数据管理入口重构

**时间**: 2026-07
**状态**: DONE
**类型**: Implementation
**目标**: 在数据资产菜单组新增“元数据管理”模块，把资产业务语义治理与数据源结构采集拆成两个清晰入口。

## 背景

当前 `/catalog/metadata` 已定位为“数据源结构采集”，主要面向接入和平台运维，承载采集任务、运行历史、Schema 漂移与采集结果预览。数据资产侧仍缺少一个面向资产管理员/数据管家的“元数据管理”入口，用于集中识别哪些资产缺少业务描述、负责人、归属部门、密级、主题域、生命周期和 OpenMetadata 映射。

本 Sprint 采用“双入口、一份资产事实”的边界：

- 数据集成 / 数据源结构采集：负责技术结构扫描、采集触发、运行诊断。
- 数据资产 / 元数据管理：负责资产语义元数据补齐、治理缺口分派、跳转资产详情治理页。
