# T02：嵌入规划与标准面板

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T01

## 目标

数仓规划和数据标准在工作台内可浏览/编辑，保留现有 API、CAS、权限和深链。

## 技术设计

- **输入**：`WorkspacePanelProps.planId`；规划继续消费 baseline/categories/sources/policy/stage-projection。
- **输出**：保存沿用 `If-Match` token；成功只刷新当前面板投影。
- **数据流**：PlanningPanel → `warehousePlanApi` → WarehousePlan services/tables。
- **标准面板**：复用词汇、字段标准、参考数据、计量单位现有页面能力；通过 panel adapter 去除重复页头。
- **错误路径**：409/412 保留用户输入并提示刷新差异；403 只读；超时提供重试。
- **分页**：列表默认 10 条，pageSize 改变回第 1 页。

## UI

规划左树沿用业务分类/数据域/过程/集市结构；标准作为工作台 Tab，不复制标准字典。高级配置用抽屉，不占主画布。

## 验证

- [ ] CAS 冲突、权限、空/加载/错误/成功测试。
- [ ] 旧 `/modeling/plans` 和标准深链仍可打开。
- [ ] 不产生新的计划/标准 API 或表。

## Definition of Done

- [ ] IT-01 规划/标准段通过。
- [ ] 现有页面业务逻辑已抽为可复用面板，旧页仅负责布局/兼容。
