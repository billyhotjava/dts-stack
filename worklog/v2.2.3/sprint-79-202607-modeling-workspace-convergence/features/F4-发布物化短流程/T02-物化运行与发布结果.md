# T02：物化运行与发布结果

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T01；Sprint-76 DEV 可运行链

## 目标

发布后在同一弹窗创建/运行物化任务，并以真实 relation/Catalog 证据展示结果。

## 技术设计

- **读取**：release candidate workspace + plan execution workspace。
- **运行**：`POST .../execution-bindings/{bindingId}/runs`，header `Idempotency-Key`。
- **前置**：Candidate PUBLISHED、binding ACTIVE、目标/secret 可用；否则禁用并显示 server blocker。
- **结果**：区分 BUILDING、BUILD_FAILED、PUBLISHED_DEPLOYING、READY、DEGRADED；relation EXISTS 才可 READY。
- **错误路径**：Airflow timeout/unknown 进入可对账状态，禁止自动重试和伪成功。
- **安全**：UI/日志不显示 profile、secret、selector 技术字段。

## UI

第二步展示目标、最近运行、relation 和 Catalog 状态；失败提供“重试登记/修复 binding/进入运维”的明确动作。
