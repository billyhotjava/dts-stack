# T02：只读关系图投影

**优先级**：P1  
**状态**：PASS_WITH_GAPS（源码、定向测试与审查通过；PostgreSQL IT、部署和浏览器 IT-04 待执行）
**依赖**：F1/T01、F2/T03、F0/T02

## 目标

按计划展示规划、维度、模型、标准和指标的关系，不建立第二套图谱数据。

## 技术设计

- **GET** `/api/modeling/warehouse-plans/{planId}/relationship-graph?kind=&query=&limit=500&cursor=`。
- **响应**：`{planId,nodes:[{id,kind,label,status,route}],edges:[{source,target,kind,label}],truncated:boolean,nextHint?:string,nextCursor?:string}`。
- **来源**：WarehousePlan bindings、DimensionDefinition revision、ModelSpec refs/dependencies、Indicator references；只读事务内投影。
- **限制**：500 nodes/1000 edges；超限返回 `truncated=true`，不做无界全图。
- **游标**：根模型 UUID keyset + 窗口内节点位置；token 绑定 tenant/plan/department/kind/query、完整窗口指纹，并使用 `DTS_MODEL_RUNTIME_SPEC_SIGNING_KEY` 域隔离派生的 HMAC-SHA256 签名。窗口变化返回 `RELATIONSHIP_GRAPH_CURSOR_STALE`；签名密钥不可用返回 503。
- **权限**：逐节点复用现有 read policy；无权节点和连边不返回。
- **错误路径**：plan 404、403；投影超时返回 503/明确 code，不回退假数据。

## UI

类型筛选、搜索、图例、适应画布。节点点击使用其 `route` 回到工作台对应 module/asset；无数据提供“去创建模型”单动作。
