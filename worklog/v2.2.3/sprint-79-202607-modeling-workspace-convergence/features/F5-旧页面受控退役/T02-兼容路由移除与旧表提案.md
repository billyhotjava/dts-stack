# T02：兼容路由移除与旧表退役提案

**优先级**：P0  
**状态**：BLOCKED_BY_OBSERVATION（未满足两版本零访问、客户画像和审批门禁，禁止删除）
**依赖**：T01、F0/T02、至少两版本观测

## 目标

删除满足门禁的 8 条旧兼容路由；对 legacy API/表只提交可审计的退役提案。

## 技术设计

- **route gate**：每个 tenant/route 两版本 count=0、last_seen 早于阈值；旧对象映射 unresolved=0。
- **删除范围**：static routes、dynamic resolver、compatibility page/route helper、对应 source-contract、帮助/收藏映射。
- **菜单**：验证相应行已软删除且无角色默认入口；migration 可 rollback。
- **旧表提案**：表行数/读写调用者/备份/dry-run/回滚/审批清单；不在本 Task drop table。
- **错误路径**：任一路由出现访问或 unresolved object，该项保持 COMPATIBLE，其他项可独立推进。
