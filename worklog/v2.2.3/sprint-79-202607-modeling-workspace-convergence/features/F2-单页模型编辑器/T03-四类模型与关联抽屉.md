# T03：四类模型与关联抽屉

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T01、T02

## 目标

在同一编辑器覆盖 DIMENSION/FACT/SUMMARY/APPLICATION，并将标准、指标、关系、质量、日志放入短工具栏/抽屉。

## 技术设计

- **类型**：保持 DIMENSION/FACT→DWD、SUMMARY→DWS、APPLICATION→ADS。
- **贴源动作**：调用计划 source registration / model-candidate preview，不创建新 ModelSpecType。
- **关联**：复用 `standardBindings`、`dimensionRefs`、`metricRefs`、`dependsOn`；关联抽屉写回同一 ModelSpec revision。
- **FML/代码模式**：仅作为高级 SQL/dbt 深链或受控转换，不成为另一模型正文。
- **错误路径**：类型/层不匹配、引用 revision 失效、循环依赖和无权限均 fail-closed。

## UI

`＋` 菜单展示“业务维度、注册来源、维度表、明细表、汇总表、应用表”。关联抽屉用 tabs 展示维度/标准/指标/上游，成功后回到字段行。
