# T02：收敛业务维度与字段映射

**优先级**：P0  
**状态**：DRAFT  
**依赖**：T01

## 目标

业务维度只维护定义和属性；模型字段一次完成属性映射与 KEY 选择，避免“维度系统编码不可填”和顶部笼统报错。

## 技术设计

- **Dimension create 输入**：`name,definition,domainId,ownerId,reuseScope,scopeType,dataMartId?,attributes[],hierarchies[]`；不提交 systemCode/dataType。
- **Dimension 输出**：服务端生成 `systemCode`，返回 id/revision/checksum/status。
- **字段映射**：DIMENSION ModelSpec 的 `fields[].dimensionAttributeCode` 精确引用属性；主键字段 `role="KEY"`。
- **门禁**：被引用 DimensionDefinition 必须 CURRENT 且 revision 固定；属性编码不存在返回字段级 blocker。
- **错误路径**：重复属性码、缺 KEY、KEY 未映射、维度 revision 过期分别定位到字段表。
- **并发**：Dimension/ModelSpec 分别使用自己的 ETag，不做跨 owner 双写。

## UI

维度创建抽屉隐藏系统编码和数据类型；保存后只读展示编码。字段表的“维度属性”和“字段作用”并列，主键无需到另一个页面重复配置。
