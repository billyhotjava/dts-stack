# T01：重组模型详情为单页画布

**优先级**：P0  
**状态**：DRAFT  
**依赖**：F1/T01

## 目标

把 `ModelSpecDetailPage` 三阶段布局改为紧凑编辑画布，同时保留所有服务端门禁和命令。

## 技术设计

- **输入**：`GET /modeling/model-specs/{id}` 与 `/stage-gates`；query `panel`。
- **输出**：`PUT /modeling/model-specs/{id}` 仍提交完整 `UpdateModelSpecCommand` + ModelSpec ETag。
- **数据流**：ModelEditorCanvas → existing editor sections → modelSpecApi → ModelSpecApplicationService。
- **错误路径**：400 字段 blocker 映射到 row/path；412 显示版本冲突；403 只读；网络失败保留草稿。
- **复用**：`ModelSpecLogicalDesignStage` 内字段/标准子组件、BlockerPanel、dependency/implementation/physical panels。
- **实现约束**：先抽纯组件，避免在 981 行详情页继续增长；阶段组件改为面板/抽屉，不复制命令。

## UI

顶部只显示当前状态、下一门禁和三个主动作。逻辑设计默认展开；数据实现、发布结果按需抽屉。红色摘要可点击滚动到字段。
