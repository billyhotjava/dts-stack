# T02: 指标绑定术语与口径版本

**状态**: READY
**优先级**: P0

## 目标

指标管理不仅维护 `code/name/formula/unit/status`，还要维护业务口径来源和版本。

## 任务

- [ ] `SemanticMetric` 增加术语绑定字段。
- [ ] 指标创建/编辑抽屉增加业务术语选择和口径说明。
- [ ] 指标列表展示术语状态和口径版本。
- [ ] 指标引用的术语归档或变更时，指标进入 drift 或 review_required。

## 验收

- [ ] 指标不能只靠自由文本名称作为口径来源。
- [ ] 指标 ACTIVE 前必须绑定 ACTIVE 业务术语或通过例外审批。
- [ ] 指标详情能展示口径定义和版本。
