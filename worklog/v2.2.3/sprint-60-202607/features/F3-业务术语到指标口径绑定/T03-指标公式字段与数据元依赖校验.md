# T03: 指标公式字段与数据元依赖校验

**状态**: READY
**优先级**: P0

## 目标

指标公式里的字段、维度、筛选条件必须能追溯到数据元和码表，避免指标口径和字段标准脱节。

## 任务

- [ ] 指标公式预检输出依赖字段清单。
- [ ] 依赖字段映射到语义维度 / 模型字段 / 数据元。
- [ ] 筛选字段若有 `codeSet`，指标筛选值必须来自公共码表。
- [ ] 预检问题显示在指标工作台，不只后端日志可见。

## 验收

- [ ] 指标公式缺字段标准时，预检可见。
- [ ] 枚举筛选值不允许使用未标准化来源码值。
- [ ] 指标工作台能定位到需要修复的数据元或模型字段。
