# T02: 标准包就绪度与引用图设计

**状态**: READY
**优先级**: P0

## 目标

标准包导入后，不只显示“新增/更新多少条”，还要显示这些标准是否已经能支撑建模和指标发布。

## 设计要点

- 标准包对象统计：业务术语、数据元、码表目录、码值、映射。
- 就绪度：
  - 业务术语是否 ACTIVE。
  - 数据元是否具备类型、可空、domain、sourceSystem。
  - 枚举型数据元是否配置 codeSet。
  - codeSet 是否存在码值和来源系统映射。
  - 标准模板是否引用了有效数据元。
- 引用图：
  - 数据元 -> 资产字段。
  - 数据元 -> SQL/dbt 模型字段。
  - 业务术语 -> 业务对象/指标。
  - 码表 -> 数据元/schema.yml tests。

## 验收

- [ ] 标准包运行记录能作为标准闭环入口。
- [ ] 坏标准包不能沉默进入后续建模。
- [ ] 就绪度结果能产生下一步修复入口。
