# T01: 标准管理事实源审计

**状态**: READY
**优先级**: P0

## 目标

盘点当前标准管理能力在页面、API、后端服务和测试中的真实状态，确认哪些已经是可执行契约，哪些仍是治理资料。

## 范围

- 业务术语：列表、版本、评审、引用关系。
- 数据元：字段名、类型、可空、码表、密级、引用关系。
- 公共码表：目录、码值、来源系统映射、dbt seed 同步。
- 标准模板：命名规则、字段模板、metadataStandardIds、reviewChecklist。
- 标准包：导入预检、应用、回滚、内置包、运行记录。

## 交付物

- [ ] 标准能力矩阵。
- [ ] 页面到 API 的事实源映射。
- [ ] 已打通链路和未打通链路清单。
- [ ] 不应继续作为“说明文档”的字段清单。

## 验收

- [ ] 结论必须能落到具体页面、API、服务和测试。
- [ ] 不用“应该已支持”这类推测表述。
- [ ] 标准和建模/指标的断点要能转成后续 task。
