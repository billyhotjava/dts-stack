# T02: 对象、规划模型服务与校验

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01

## 目标

实现 BusinessObject、WarehousePlan、StandardBinding 的持久化和领域校验。

## 技术设计

- 业务对象必须绑定业务过程和业务粒度。
- DWD FACT/DIMENSION 必须声明业务键或技术键。
- 标准绑定字段必须存在于来源模型或待确认字段集。
- 项目空间不作为必填条件；没有项目空间也能完成正常建模。

## 影响范围

- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/service/modeling/**`
- Resource、repository/query、单元测试。

- [x] 未启用项目空间的对象和模型校验不要求 projectSpaceId。
- [ ] 领域校验接入 PostgreSQL repository/service。
