# T02：接入标准 CRUD 和导入

**状态**：DONE

- 新建/编辑/归档接既有 CRUD；导入必须先 preview 再 apply，并显示逐项结果/失败原因。
- 写入成功刷新目录；冲突和权限失败不乐观伪成功。
- 服务端已有 owner 的审计为唯一审计来源。

## 验收证据

- 字段标准：新建、编辑、归档；标准代码：新建、编辑、废弃状态归档；命名词典：新建、编辑。
- 缺少契约的词根维护、映射写入和术语归档没有伪造成功按钮，均显示禁用原因。
- 标准包仅接收 zip，预检返回 `runId` 且无 blocking 后才可应用；失败原因按文件和行展示。
- 保存、归档和应用成功后刷新真实目录；API 异常保留错误和重试入口，不乐观写本地记录。
