# T01：组合真实关系投影

**状态**：CODE_COMPLETE（部署/E2E 待 F5/T02）  
**文件**：`RelationshipGraphWorkspace.tsx`、关系 adapter、聚焦测试。

- 组合 WarehousePlan relationship graph、标准引用、指标依赖和 Catalog lineage。
- 刷新、类型筛选、布局和节点跳转有真实 handler；超大图或无权限 fail-closed。
- 导出只有现有受控契约时保留，否则删除控件。

## 已实现契约

- UI 入口：`/data-modeling/graphs/{models|standards|metrics}`。
- 计划上下文：`listWarehousePlans()`，页面不保存计划或图副本。
- 图读取：`getWarehousePlanRelationshipGraph(planId, { kind, query, limit: 40, cursor })`；标准视图使用 `STANDARD`，指标视图使用 `INDICATOR`，模型视图读取统一投影后仅展示计划/维度/模型节点。
- 标准绑定和指标依赖由 WarehousePlan relationship graph 服务端统一投影；Catalog lineage 尚无可证明的 ModelSpec→CatalogAsset 键映射，本任务未做前端猜测拼接。
- 服务端返回的旧 `/modeling/workbench` 节点地址在 service bridge 内受控转换为 `/data-modeling/**` 深链；外部地址 fail-closed。
- 投影分页使用服务端 `nextCursor`；前端最多渲染 120 个节点，超限明确要求用户使用检索或类型筛选缩小范围。
- 无统一受控导出 API，已物理删除“导出关系”控件。

## 七态与交互

- default：真实建设计划选择、搜索和节点类型筛选。
- loading：计划/图读取期间禁用相关动作并显示读取状态。
- empty：分别处理“无建设计划”和“当前筛选无关系”。
- disabled reason：无节点时重新布局、无计划时查询、节点无安全详情路由均给出原因。
- error/retry：请求失败显示错误并提供“重新加载”。
- permission：401/403 显示“无权访问关系图”，不回退演示数据。
- success：展示权威节点数、关系数和最近读取时间；节点跳转使用真实详情地址。
