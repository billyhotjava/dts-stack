# T03: 验收包导出与分享入口

**优先级**: P2
**状态**: DONE
**依赖**: T02

## 目标

提供客户验收包的复制、下载或分享入口，让实施人员能把当前数据产品交付状态带到验收会议。

## 技术设计

- 先支持复制 Markdown 摘要或下载 JSON。
- 摘要包含产品名称、来源系统、模型、指标、服务、质量、权限、运行、审计链接。
- 导出时标注缺失项，不生成“全部通过”的误导文本。
- 后续可接入正式报告导出 API。

## 影响范围

- 工作台验收包区域
- 前端下载/剪贴板工具
- source-contract

## 验证

- [x] source-contract 断言导出内容包含缺失项。
- [ ] Playwright smoke 覆盖复制或下载按钮状态。

## 完成标准

- [x] 实施人员可以把验收摘要带出系统。
- [x] 导出内容可追溯到具体页面证据。
- [x] 缺失项在导出内容里可见。

## 当前剩余

- 待可登录 Playwright smoke 点击 `复制验收摘要` 与 `下载 JSON`，并沉淀截图/下载行为证据。
