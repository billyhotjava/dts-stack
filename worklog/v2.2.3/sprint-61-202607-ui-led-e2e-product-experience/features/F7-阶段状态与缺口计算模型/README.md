# F7: 阶段状态与缺口计算模型

## 目标

让工作台和子页面的阶段状态从真实上下文和可用证据推导，而不是靠静态文案判断“完成/缺口/下一步”。

## 完成标准

- [x] 每个阶段有统一状态：`not_started`、`blocked`、`ready`、`in_progress`、`done`。
- [x] 缺口和下一步动作来自规则或 API 响应，不在页面里散落硬编码。
- [x] API 缺失时显示明确 blocker。
- [x] source-contract 覆盖阶段状态、缺口文案和下一步路由。
