# T02: 缺口与下一步动作计算器

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

把“当前缺口”和“下一步动作”从静态说明变成可计算结果，让用户看到的动作与真实上下文一致。

## 技术设计

- 增加 `resolveJourneyGap` 和 `resolveJourneyNextAction`。
- 根据 `sourceId`、`standardDraftId`、`modelId`、`metricId`、`serviceId` 推导缺口。
- 当后端 API 缺失时返回 `blocker` 状态和需要补充的 API 名称。
- 支持页面覆盖少量业务文案，但规则来源集中。

## 影响范围

- 工作台阶段卡
- `JourneyContextBar`
- 标准、建模、指标、服务页面

## 验证

- [x] source-contract 覆盖缺少数据源、缺少标准草稿、缺少模型、缺少服务的四类缺口。
- [x] source-contract 断言 blocker 不显示为成功态。

## 完成标准

- [x] 阶段缺口能够随着 query context 改变。
- [x] 下一步按钮和缺口说明一致。
- [x] 不存在“按钮可点但上下文缺失”的假成功。
