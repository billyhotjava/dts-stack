# T03：冻结旧会话事实源与旧入口

- **状态**：READY
- **优先级**：P0
- **依赖**：T02
- **影响模块**：warehousePlanningContext、modeling journey、旧页面写操作、Feature Flag

## 目标

将 sessionStorage 和页面访问顺序从业务事实源降为一次性迁移输入，冻结旧写入口并让新 API 成为唯一真值。

## 实施内容

1. 首次进入时解析可用旧 context，映射到已有或待迁移 plan，并标记已处理。
2. 之后所有状态从 WarehousePlan/StageProjection API 读取，不再双写 session。
3. 旧页面在兼容期 redirect 或只读，写动作代理到 canonical 命令或明确阻止。
4. 将 `DBT_NATIVE` 映射为实现方式，不再参与规划模式选择。
5. 通过 Feature Flag 控制切换并记录 fallback 使用。

## 验收标准

- 清空浏览器存储不会丢失计划状态；
- 不同设备登录看到相同后台事实；
- 页面访问不能改变阶段完成；
- 旧 context 迁移幂等且不创建重复计划；
- fallback 可回滚入口但不会恢复旧双写。

## 验证证据

- local/session storage 清理 E2E；
- 跨会话恢复测试；
- 旧 context migration tests；
- Flag on/off 回滚演练。
