# T02：构建数据建设工作台

- **状态**：READY
- **优先级**：P0
- **依赖**：T01
- **影响模块**：dts-platform-webapp 工作台、菜单首页、plan selector

## 目标

构建真实的数据建设工作台，围绕当前计划展示当前阶段、一个主阻塞、一个下一步动作和可追溯成果，而不是展示大段教学文案。

## 实施内容

1. 顶部提供计划选择、负责人和生命周期摘要。
2. 主工作区展示 current stage、primary blocker 和唯一主 CTA。
3. 次要缺口、概念解释和历史证据默认折叠或置于侧栏。
4. 展示阶段轨迹但不允许点击直接标记完成。
5. 支持最近计划恢复、空计划引导、权限态和跨端刷新。

## 验收标准

- 进入工作台不会跳到主题域管理；
- 无计划时只显示“新建规划”一个主动作；
- 有计划时主动作来自 StageProjection；
- 页面顶部不出现多层统计/引导卡堆叠；
- 熟手可深链专业页面，新手能理解下一步。

## 验证证据

- UI component tests；
- 一主动作断言；
- empty/blocked/complete/unknown 截图；
- Chrome 95 视觉和交互 smoke。
