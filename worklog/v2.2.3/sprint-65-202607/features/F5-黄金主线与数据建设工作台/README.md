- 工作台状态全部可追溯到真实后端证据；
- 页面访问、步骤序号或 session 不会产生完成状态；
- 主屏只有一个当前主要动作；
- 专业模块不可用时显示 UNKNOWN/STALE；
- 失败能定位到责任模型、标准、测试或运行并返回原计划。
