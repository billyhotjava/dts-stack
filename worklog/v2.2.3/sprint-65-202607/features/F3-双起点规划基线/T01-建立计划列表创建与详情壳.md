# T01：建立计划列表、创建与详情壳

- **状态**：READY
- **优先级**：P0
- **依赖**：F2-T03
- **影响模块**：dts-platform-webapp 路由、页面、API client

## 目标

提供真实计划列表、新建选择和六阶段计划详情，使“建模工作台”不再重定向到主题域管理。

## 实施内容

1. 建立计划列表，支持状态、负责人和关键词筛选；唯一主动作是“新建规划”。
2. 新建时选择 BUSINESS_FIRST 或 ASSET_FIRST，并提交同一个 Create API。
3. 建立六阶段详情 shell：概览、基线、架构、事实与维度、实现与验证、发布成果。
4. 使用 URL `planId` 作为稳定上下文，刷新、深链和多 Tab 不依赖 session。
5. 实现 loading、empty、403、404、409 和下游不可用状态。

## 验收标准

- 两种起点进入同一个详情组件和 API；
- 页面首屏只有一个主要动作；
- 计划切换不会串租户或串状态；
- 刷新和复制 URL 可恢复同一计划；
- Chrome 95 无语法和布局阻断。
