## 完成标准

- 两种起点创建同一 DTO、同一表和同一计划详情；
- 推荐与导入默认是候选，不能自动确认；
- 未映射来源有明确排除或修复路径；
- 基线完成完全由后台事实计算；
- 切换、刷新和深链不丢 planId 或确认状态。
