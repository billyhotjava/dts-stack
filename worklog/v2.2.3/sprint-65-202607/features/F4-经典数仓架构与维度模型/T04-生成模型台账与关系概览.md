# T04：生成模型台账与关系概览

- **状态**：READY
- **优先级**：P0
- **依赖**：T02、T03
- **影响模块**：模型台账、依赖图、ER/分析关系概览、发布状态

## 目标

把已确认设计写入统一模型台账，并从模型关系派生 ER 和事实-维度分析概览，替代独立可写矩阵事实源。

## 实施内容

1. 计划内统一展示事实、维度、汇总、应用模型及其版本/状态。
2. 从主外键和依赖生成 ER 概览，从事实维度引用生成分析关系概览。
3. 将旧总线矩阵关系映射为模型关系候选，核对后确认。
4. 关系修改回写 ModelSpec relationship，并触发粒度、依赖和影响校验。
5. 提供模型详情深链、来源/标准/下游引用和发布状态。

## 验收标准

- 台账是唯一逻辑模型清单；
- 两种关系概览可由模型数据重建；
- 旧矩阵迁移不产生重复或相反关系；
- 分析关系概览不是规划强制步骤；
- 修改关系后门禁和血缘同步刷新。

## 验证证据

- 模型台账 contract tests；
- ER/分析关系派生快照测试；
- 旧矩阵迁移核对；
- 关系变更影响测试。
