# T01：完成后端契约与迁移回归

- **状态**：READY
- **优先级**：P0
- **依赖**：F2-F6
- **影响模块**：dts-platform tests、PostgreSQL/Liquibase、跨模块集成

## 目标

验证领域不变量、API、租户、并发、证据投影、dbt 回写和旧计划迁移在空库与存量库均可靠。

## 实施内容

1. 执行 WarehousePlan/PlanningBaseline/ModelSpec 领域和 API 契约测试。
2. 执行多租户、权限、乐观锁、归档、版本和评审测试。
3. 执行 Liquibase 空库、存量库、重复升级和 backfill 核对。
4. 执行旧计划 dry-run、迁移、幂等、冲突、部分失败恢复和回滚。
5. 执行 stage projection 降级、dbt artifact/run/lineage 回写一致性测试。

## 验收标准

- 所有 P0 backend/contract 测试通过；
- 迁移前后记录、引用、版本和评审可核对；
- 无跨租户读取或写入；
- 重跑不产生重复数据；
- 测试日志和报告保存到 IT 证据目录。

## 验证证据

- JUnit/contract reports；
- Liquibase logs/schema diff；
- migration/retry/rollback reports；
- 失败用例和修复 commit。
