# T03：汇总交付证据与发布决策

- **状态**：READY
- **优先级**：P0
- **依赖**：T01、T02
- **影响模块**：Sprint IT、发布说明、退役登记、回滚手册

## 目标

把代码、测试、迁移、浏览器、运行、权限和退役证据聚合为可审计的 Go/No-Go 决策，不以 Task 状态替代真实结果。

## 实施内容

1. 对照 Sprint README、IT-01 至 IT-15 和 30 个 Task 完成标准建立追踪矩阵。
2. 记录 commit、镜像、配置、数据库版本、Feature Flag 和执行环境。
3. 汇总未解决风险、已知限制、数据冲突和 REMOVAL_CANDIDATE。
4. 编写上线、监控、回滚和故障联系人清单。
5. 只有所有 P0 门禁有证据时给出 Go，否则给出 No-Go 和后续任务。

## 验收标准

- 每个“通过”结论都有可打开的证据；
- BLOCKED/UNKNOWN 项没有被统计为完成；
- 回滚步骤经过演练且不会丢 canonical 数据；
- 旧资产状态与真实切换一致；
- 发布说明面向运维和产品双方可理解。

## 验证证据

- acceptance traceability matrix；
- release/rollback rehearsal；
- final risk register；
- 签署的 Go/No-Go 记录。
