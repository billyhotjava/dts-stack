# T02：实现领域聚合与不变量

- **状态**：IN_PROGRESS
- **优先级**：P0
- **依赖**：T01
- **影响模块**：dts-platform modeling domain/application service

## 目标

实现 `WarehousePlan`、`PlanningBaseline`、绑定和值对象，集中执行生命周期、确认、租户、并发、归档和引用不变量。

## 实施内容

1. 定义聚合和值对象，避免资源层直接拼装 SQL 状态。
2. 实现 DRAFT 到 PUBLISHED/ARCHIVED 的合法状态转换。
3. 实现 baseline 完整性计算和候选/确认分离。
4. 对所有命令执行租户、权限、审计和编辑单元级乐观锁校验；状态转换额外校验 plan-head 并复核子资源版本。
5. 对已发布修改、被引用删除、重复 code 和跨计划绑定返回稳定领域错误。

## 验收标准

- 前端不能直接写 lifecycle 或 stage 完成状态；
- 两种起点使用同一聚合和状态机；
- 并发冲突返回当前版本且不覆盖；
- 归档保留模型、成果和证据引用；
- 领域单元测试覆盖成功、边界和失败路径。

## 验证证据

- 聚合单元测试；
- 状态转换参数化测试；
- tenantId 作用域、同资源冲突、跨资源并发和状态转换竞争测试；
- 审计事件样例。
