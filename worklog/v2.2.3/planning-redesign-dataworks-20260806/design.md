日期：2026-08-06

范围：数据建模 → 数仓规划工作区（方案 1 闭环）；不含数据标准/维度建模/指标/关系图/通用工具

## 已确认决策

1. 数据域 → 业务分类：**单父级**（沿用 `catalog_domain.parent_id` 树；数据域可多业务分类列为后续扩展，不破坏资产地图/标准/安全策略共享树语义）。
2. 数据集市：**对齐 DataWorks**，改挂业务分类（当前误挂数据域 `domainIds`，且前端下拉混列业务分类与数据域）。
3. 建模空间：**不设计**；默认单空间、不在 UI 显示、保留占位，有明确需求再扩展。

## 关系模型

```
业务链A（生产/明细侧）          业务链B（消费/应用侧）
业务分类 ──1:n──> 数据域         业务分类 ──1:n──> 数据集市
数据域 ──1:n──> 业务过程         数据集市 ──1:n──> 主题域

技术链（正交贯穿）：数仓分层（归属：贴源/公共/应用）→ 模型类型约束
模型定位 = 业务分类 + 数据域 + 分层（应用表为 主题域 + 分层）
```

| 关系 | DataWorks | DTS 决策 | 落点 |
|---|---|---|---|
| 业务分类 ↔ 数据域 | 可多分类 | v1 单父级 | 现有 `catalog_domain` 树 |
| 数据域 ↔ 业务过程 | 1:n | 对齐（现状） | 过程台账补英文名/状态 |
| 业务分类 ↔ 数据集市 | 集市是业务分类细化 | 改挂业务分类 | `DataMart` 契约 `domainIds` → `businessCategoryIds` |
| 数据集市 ↔ 主题域 | 1:n | 新增主题域台账 | 新表 + CRUD + 审计 |
| 数仓分层 ↔ 模型类型 | 归属+模型类型，创建后不可变 | 对齐 | 扩展 `modeling_warehouse_layer` 与系统分层字典 |
| 数仓分层 ↔ 业务链 | 层级贯穿 | 正交贯穿 | 模型创建按 (分层, 业务分类, 数据域) 校验 |

## 数仓分层归属映射（复用现有 6 个系统类型）

| 归属 | 系统分层 | 模型类型 |
|---|---|---|
| 贴源层 STAGING | `ODS_RAW` / `ODS_STANDARDIZED` / `STG` | 仅规划展示，不可建模 |
| 公共层 COMMON | `DWD` | 维度 DIMENSION / 维度表 / 明细表 FACT |
| 公共层 COMMON | `DWS` | 汇总表 SUMMARY |
| 应用层 APPLICATION | `ADS` | 应用表 APPLICATION / 维度表 |

自定义分层：创建时必选 归属 + 模型类型；创建后不可变更；删除时存在模型引用则失败关闭（沿用既有设计）。

## UI 信息架构

- 左侧对象树：业务分类 / 数仓分层 / 公共层（数据域、业务过程）/ 应用层（数据集市、主题域）/ 系统管理；建模空间不显示。
- 数仓分层页按归属分组展示（贴源/公共/应用），支持平铺。
- 每页统一“列表 + 抽屉编辑”；业务分类/数据域/业务过程补英文名与状态，集市改选业务分类，主题域挂集市。
