# T01: 盘点关键后端服务当前健康检查能力

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标
确认 admin、platform、ingestion、analytics 当前是否暴露可用于 compose 的健康检查端点。

## 技术设计
- 检查 Spring Boot actuator、`/management/health` 安全放行和已有 docker healthcheck 配置
- 标记哪些服务可直接接入 healthcheck，哪些需要先补支持

## 影响范围
- `docker-compose*.yml`
- `source/dts-admin`
- `source/dts-platform`
- `source/dts-ingestion`
- `source/dts-analytics`
