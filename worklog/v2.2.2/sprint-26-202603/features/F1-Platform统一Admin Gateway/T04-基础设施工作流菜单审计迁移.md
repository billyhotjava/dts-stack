# T04: 基础设施工作流菜单审计迁移

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

把剩余的 admin 直连域迁入统一 gateway，消除散落 transport。

## 技术设计

- 建立 `infra/workflow/menu/audit` gateway
- 原有业务 service/resource 继续保留，但不再自己拼接 admin 调用
- 审计日志导出继续保留平台代理语义
