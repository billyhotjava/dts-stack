# T02: 资产权限判定服务 (AssetPermissionService)

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

实现核心权限判定逻辑，作为全系统唯一的权限判定入口。

## 技术设计

### 判定逻辑（优先级从高到低）

```
check(user, roles, deptCode, asset):
  1. if roles ∩ {SYS_ADMIN, OP_ADMIN}      → MANAGE
  2. if roles ∩ {INST_LEADER}               → READ
  3. if roles ∩ {INST_DATA_OWNER}           → MANAGE
  4. ownership = findOwnership(asset)
     if ownership.deptCode == deptCode:
       if roles ∩ {DEPT_LEADER}             → READ
       if roles ∩ {DEPT_DATA_OWNER}         → MANAGE
  5. grants = findActiveGrants(asset, user, roles, deptCode)
     // 检查 grantee_type = USER (匹配 username)
     // 检查 grantee_type = ROLE (匹配用户角色列表)
     // 检查 grantee_type = DEPT (匹配用户部门)
     if grants.notEmpty() → max(grants.permission)
  6. → DENY
```

### 关键方法

```java
public class AssetPermissionService {
    PermissionResult check(String username, List<String> roles, String deptCode, AssetRef asset);
    Map<AssetRef, PermissionResult> batchCheck(String username, List<String> roles, String deptCode, List<AssetRef> assets);
    AccessibleAssetsResult listAccessibleAssetIds(String username, List<String> roles, String deptCode, String assetType, Pageable pageable);
}
```

### accessible-ids 优化

对于全局角色（SYS_ADMIN, OP_ADMIN, INST_DATA_OWNER, INST_LEADER），返回 `scope: "ALL"` 哨兵值，analytics 侧跳过 `WHERE IN` 过滤。

### PermissionResult

```java
public record PermissionResult(boolean allowed, String permission, String reason) {}
public record AccessibleAssetsResult(List<String> assetIds, long total, String scope) {}
// scope = "ALL" | "FILTERED"
```
