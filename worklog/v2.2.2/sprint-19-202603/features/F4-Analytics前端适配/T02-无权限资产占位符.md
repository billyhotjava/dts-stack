# T02: 无权限资产占位符

**优先级**: P1
**状态**: READY
**依赖**: F2/T02

## 目标

仪表盘/大屏中无权查看的卡片/组件显示友好占位符而非报错。

## 技术设计

### 场景

用户有仪表盘 READ 权限，但仪表盘内某些卡片引用了无权访问的数据。后端对该卡片返回 403。

### 前端处理

```tsx
// 卡片渲染组件
if (cardLoadError?.status === 403) {
  return (
    <PermissionPlaceholder>
      无权查看此卡片，如需访问请联系管理员
    </PermissionPlaceholder>
  );
}
```

### 占位符样式

- 灰色背景 + 锁图标
- 文字提示: "无权查看此内容"
- 不显示数据摘要或标题（避免信息泄漏）

### 大屏场景

同理，无权组件显示遮罩层。
