# T01: 派生资产创建增加部门选择器

**优先级**: P0
**状态**: READY
**依赖**: F1/T04

## 目标

卡片、仪表盘、大屏创建对话框中增加"归属部门"选择器。

## 技术设计

### 改造点

- 创建卡片保存对话框: 新增部门选择器
- 创建仪表盘对话框: 新增部门选择器
- 创建大屏对话框: 新增部门选择器
- 默认值: 当前用户所在部门（从 platform session 获取）

### 部门列表获取

调用 platform API: `GET /api/organizations/departments`
- 院级角色返回所有部门
- 部门角色仅返回本部门

### 创建时传参

资产创建 API 增加 `ownerDeptCode` 参数，analytics 后端创建资产后同时调用 platform 创建 asset_ownership 记录。

## 影响范围

- `source/dts-analytics-webapp/modern/src/` — 卡片/仪表盘/大屏创建组件
- `source/dts-analytics/src/main/java/com/yuzhi/dts/analytics/web/rest/` — 创建端点增加参数

## 验证

- [ ] 创建时部门选择器正常显示
- [ ] 默认值为当前用户部门
- [ ] 创建后 asset_ownership 记录正确生成
