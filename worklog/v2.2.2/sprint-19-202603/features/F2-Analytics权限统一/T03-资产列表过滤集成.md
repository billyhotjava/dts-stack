# T03: 资产列表过滤集成

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

改造 analytics 资产列表查询，只返回用户有权访问的资产。

## 技术设计

### 策略

1. 调用 `PlatformPermissionClient.listAccessibleAssetIds()` 获取可见 ID 列表
2. 如果 `scope=ALL`（全局角色），跳过过滤，查全量
3. 如果 `scope=FILTERED`，用 `WHERE id IN (...)` 过滤

### 改造点

| 现有接口 | 改造方式 |
|----------|---------|
| `GET /api/card` (卡片列表) | CardResource 注入 ID 过滤 |
| `GET /api/dashboard` (仪表盘列表) | DashboardResource 注入 ID 过滤 |
| `GET /api/screen` (大屏列表) | ScreenResource 注入 ID 过滤 |
| `GET /api/collection/{id}/items` (集合内资产) | CollectionResource 按类型分别过滤 |

### 分页处理

- platform 返回的 assetIds 已分页
- analytics 侧用 `WHERE id IN (...)` 查询，保持原有排序

## 影响范围

- `source/dts-analytics/src/main/java/com/yuzhi/dts/analytics/web/rest/` — CardResource, DashboardResource, ScreenResource, CollectionResource
- `source/dts-analytics/src/main/java/com/yuzhi/dts/analytics/repository/` — 相关 Repository 增加 IN 查询方法
