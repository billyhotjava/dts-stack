# T04: 清理遗留权限代码

**优先级**: P1
**状态**: READY
**依赖**: T02, T03

## 目标

移除 analytics 中不再使用的 Metabase 遗留权限机制。

## 技术设计

### 移除清单

| 类别 | 文件/表 | 说明 |
|------|---------|------|
| Permissions Graph | `AnalyticsPermissionsGraph.java` | 实体 |
| | `AnalyticsPermissionsGraphRepository.java` | Repository |
| | `analytics_permissions_graph` 表 | Liquibase 标记废弃 |
| Group 权限 | `AnalyticsGroup.java` | 实体 |
| | `AnalyticsGroupMembership.java` | 实体 |
| | `PermissionsResource.java` | REST controller |
| | 相关 Repository | |
| Query 权限 | `QueryPermissionService.java` | 三级权限判定 |
| Screen ACL | `AnalyticsScreenAcl.java` | 实体 |
| | `ScreenAclService.java` | 服务 |
| | `analytics_screen_acl` 表 | Liquibase 标记废弃 |
| 手动检查 | `MetabaseAuth.requireSuperuser()` 调用点 | 替换为 filter 已处理 |

### 不删除（保留兼容）

- `analytics_group` / `analytics_group_membership` 表 — Liquibase 中标记 deprecated 但不 DROP（迁移期保留）
- `AnalyticsUser.isSuperuser` 字段 — 保留用于 PlatformTrustedUserService 桥接

### 策略

分步清理：先注释标记 `@Deprecated`，验证无回退后再物理删除。

## 影响范围

- `source/dts-analytics/src/main/java/com/yuzhi/dts/analytics/` — 多个 domain/service/web/repository 文件
- 需逐个检查 controller 中的 `MetabaseAuth` 调用点

## 验证

- [ ] 编译通过，无遗留引用
- [ ] 所有现有功能不受影响（卡片查询、仪表盘渲染等）
- [ ] PermissionsResource 端点返回 404（已移除）

## 完成标准

- [ ] 遗留代码全部标记废弃或删除
- [ ] 无编译错误、无运行时异常
