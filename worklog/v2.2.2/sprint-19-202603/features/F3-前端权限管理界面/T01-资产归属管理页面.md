# T01: 资产归属管理页面

**优先级**: P0
**状态**: READY
**依赖**: F1/T04

## 目标

院级管理员可查看和管理所有资产的部门归属。

## 技术设计

### 路由

`/governance/asset-ownership` — 可见角色: INST_DATA_OWNER, SYS_ADMIN, OP_ADMIN

### 页面布局

```
┌──────────────────────────────────────────────────────────┐
│ 筛选: [部门▼] [资产类型▼] [数据源▼] [搜索...]            │
├──────────────────────────────────────────────────────────┤
│ ☐ 资产名称         类型       归属部门    数据源   操作   │
│ ☐ ods_hr_salary    TABLE      人力部     HR系统   [编辑] │
│ ☐ ods_fin_budget   TABLE      财务部     财务系统 [编辑] │
│ ☐ 月度营收看板     DASHBOARD  财务部     -        [编辑] │
├──────────────────────────────────────────────────────────┤
│ [批量修改归属部门]                                        │
└──────────────────────────────────────────────────────────┘
```

### 组件

- 表格: antd `<Table>` + 服务端分页
- 部门选择器: 复用 `OrganizationNode` 树形选择
- 批量操作: 勾选 → 批量修改弹窗

## 影响范围

- `source/dts-platform-webapp/src/pages/governance/` — 新增页面
- `source/dts-platform-webapp/src/routes/` — 新增路由
- `source/dts-platform-webapp/src/api/` — 新增 API 调用
