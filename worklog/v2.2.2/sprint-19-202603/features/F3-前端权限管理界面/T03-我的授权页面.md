# T03: 我的授权页面

**优先级**: P1
**状态**: READY
**依赖**: F1/T05

## 目标

所有登录用户可查看自己被授权的资产列表和授出的授权列表。

## 技术设计

### 路由

`/my/asset-grants` — 可见角色: 所有登录用户

### 页面布局

两个 Tab:
1. **我被授权的** — 调用 `GET /api/asset-grants/my`
2. **我授出的** — 调用 `GET /api/asset-grants/granted-by-me`

### 表格列

| 列 | 说明 |
|----|------|
| 资产名称 | 点击跳转到资产详情 |
| 资产类型 | TABLE/CARD/DASHBOARD/SCREEN/MODEL |
| 归属部门 | |
| 权限 | READ/EDIT/MANAGE |
| 有效期 | 永久 或 截止日期（即将过期标红） |
| 授权人/被授权人 | |

## 影响范围

- `source/dts-platform-webapp/src/pages/my/` — 新增页面

## 验证

- [ ] 两个 Tab 数据正确
- [ ] 资产名称可点击跳转
- [ ] 即将过期（7天内）的授权高亮显示
