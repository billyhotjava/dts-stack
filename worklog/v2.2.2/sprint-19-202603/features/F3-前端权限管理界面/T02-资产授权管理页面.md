# T02: 资产授权管理页面

**优先级**: P0
**状态**: READY
**依赖**: F1/T05

## 目标

部门数据管理员可管理本部门资产授权，院级管理员可跨部门授权。

## 技术设计

### 路由

`/governance/asset-grants` — 可见角色: DEPT_DATA_OWNER 及以上

### 页面布局

两个 Tab:
1. **按资产查看** — 选择资产 → 查看/管理其授权列表
2. **按用户查看** — 选择用户 → 查看其被授权的资产列表

### 授权对话框

```
┌──────────────────────────────────────────┐
│ 新增授权                                  │
│                                          │
│ 资产: [已选资产名称]                       │
│ 授权对象: ○用户 ○角色 ○部门               │
│ 选择: [搜索用户/角色/部门...]              │
│ 权限: ○READ ○EDIT ○MANAGE               │
│ 有效期: ○永久 ○至 [日期选择]              │
│ 备注/OA单号: [____________]              │
│                                          │
│              [取消] [确认授权]             │
└──────────────────────────────────────────┘
```

### 权限限制

- DEPT_DATA_OWNER: 用户搜索限本部门，资产限本部门
- INST_DATA_OWNER/SYS_ADMIN/OP_ADMIN: 全部可见
