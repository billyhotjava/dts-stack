# T04: 授权审计日志页面

**优先级**: P1
**状态**: READY
**依赖**: F1/T05

## 目标

安全审计员和系统管理员可查看所有权限变更的审计日志。

## 技术设计

### 路由

`/governance/permission-audit` — 可见角色: SECURITY_AUDITOR, SYS_ADMIN

### 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 筛选: [操作类型▼] [操作人] [目标用户] [日期范围] [OA单号]     │
├──────────────────────────────────────────────────────────────┤
│ 时间         操作    资产         目标用户  权限  操作人 OA单号│
│ 03-28 14:30  GRANT   月度营收看板  张三     READ  李四   OA-123│
│ 03-28 14:25  REVOKE  ods_hr表     王五     EDIT  李四   -     │
│ 03-28 14:20  CHANGE  ods_fin表    -        -     admin  -     │
└──────────────────────────────────────────────────────────────┘
```

### 后端 API

```
GET /api/asset-permission-audit?action=&operator=&targetUser=&dateFrom=&dateTo=&oaReference=&page=&size=
```

Authorization: SECURITY_AUDITOR, SYS_ADMIN
