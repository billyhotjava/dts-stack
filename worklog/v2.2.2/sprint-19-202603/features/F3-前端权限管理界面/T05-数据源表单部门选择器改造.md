# T05: 数据源表单部门选择器改造

**优先级**: P0
**状态**: READY
**依赖**: F1/T01

## 目标

数据源创建/编辑表单增加必填的"归属部门"字段。

## 技术设计

### 改造点

- 数据源创建表单: 新增"归属部门"下拉选择器（必填）
- 数据源编辑表单: 显示并可修改"归属部门"
- 部门选择器: 复用 `OrganizationNode` 树形组件

### 后端

- `InfraDataSourceResource` 的 create/update DTO 新增 `ownerDeptId` 字段
- create 时必填校验
- update 时修改归属同时更新该数据源下所有表的 asset_ownership（可选，弹窗确认）

## 影响范围

- `source/dts-platform-webapp/src/pages/` — 数据源管理相关页面
- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/web/rest/InfraDataSourceResource.java`
- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/domain/InfraDataSource.java`

## 验证

- [ ] 创建数据源时必须选择部门
- [ ] 编辑数据源时可修改部门
- [ ] 修改部门时提示"是否同步更新该源下所有表的归属"

## 完成标准

- [ ] 表单改造完成，后端校验生效
