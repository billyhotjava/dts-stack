# Sprint-20: 逻辑建模批量删除与文件浏览器重构

**时间**: 2026-03
**状态**: DONE
**目标**: 在逻辑建模工作区补齐企业级批量删除能力，并将左侧项目目录升级为支持多选的专业文件浏览器

## 背景

当前逻辑建模工作区存在两个直接影响使用效率的问题：

1. 左侧项目目录只能单选浏览，不支持企业级批量操作
2. 模型治理、平铺列表、左树三处选择状态割裂，无法统一执行批量删除

这导致建模人员在模型清理、治理收敛和工作区维护时，需要重复逐个删除模型，效率低且容易误操作。现有页面结构已经具备“左侧目录树 + 中间编辑器 + 顶部工具栏 + 模型治理弹窗”的工作台基础，需要在不破坏当前单模型编辑流的前提下，引入一套统一的批量选择和批量删除能力。

## 完成标准

- [x] 左侧项目目录升级为支持 checkbox、多选、半选和搜索工具条的文件浏览器
