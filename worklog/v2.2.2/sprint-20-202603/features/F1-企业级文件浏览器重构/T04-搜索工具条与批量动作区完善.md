# T04: 搜索工具条与批量动作区完善

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: T03

## 目标

为左侧文件浏览器补齐企业级搜索与批量动作工具条，使批量操作具备明确入口和反馈。

## 技术设计

- 在搜索框下新增轻量工具条
- 展示：
  - 已选数量
  - 全选当前结果
  - 清空选择
  - 删除所选入口
- 搜索结果与勾选范围联动，支持“全选当前搜索结果”

## 影响范围

- `source/dts-platform-webapp/src/pages/modeling/components/ModelFileBrowser.tsx`
- `source/dts-platform-webapp/src/pages/modeling/SqlModelingPage.tsx`

## 验证

- [ ] 搜索后可只对当前结果批量选择
- [ ] 工具条状态与勾选状态同步
- [ ] 删除所选入口只在有选择时可用

## 完成标准

- [ ] 文件浏览器具备专业级批量工具条
- [ ] 搜索与多选协同可用
