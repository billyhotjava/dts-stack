# T02: 编辑态与批量选择态分离

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01

## 目标

将“当前正在编辑的模型”和“当前批量勾选的模型”拆成两套独立状态，避免交互污染。

## 技术设计

- 保留 `activeModelKey` 作为编辑态
- 新增统一 `bulkSelection` 状态，承载批量勾选模型 ID 集合
- 明确交互规则：
  - 点击节点正文只改变 `activeModelKey`
  - 点击 checkbox 只改变 `bulkSelection`
- 删除后如果当前编辑模型被删，自动切换到下一个可编辑模型或清空编辑区

## 影响范围

- `source/dts-platform-webapp/src/pages/modeling/SqlModelingPage.tsx`
- `source/dts-platform-webapp/src/pages/modeling/sqlModeling.types.ts`
