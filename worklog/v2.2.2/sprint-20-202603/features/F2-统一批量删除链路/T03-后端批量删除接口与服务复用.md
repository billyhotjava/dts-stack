# T03: 后端批量删除接口与服务复用

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01

## 目标

在 platform 后端补齐批量删除接口，并复用现有单删/治理删除规则，避免多套语义并存。

## 技术设计

- 保留现有单删接口
- 新增批量删除 API，接收模型 ID 列表和删除选项
- Service 层复用现有删除规则：
  - 记录删除
  - 文件删除
  - 权限校验
  - 审计记录
- 返回逐条执行结果，支持部分失败

- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/web/rest/ModelingSqlModelResource.java`
- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/service/modeling/ModelingSqlModelService.java`
- `source/dts-platform/src/main/java/com/yuzhi/dts/platform/service/modeling/ModelGenerationService.java`

## 验证

- [ ] 批量删除 API 可用
- [ ] 部分删除失败时返回明细
- [ ] 单删和治理删除行为不回归

- [ ] 后端提供统一批量删除能力
- [ ] 删除规则只维护一份
