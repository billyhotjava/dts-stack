# T02: 批量删除前端确认与结果反馈

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01

## 目标

为批量删除补齐专业的确认、执行中、成功/失败结果反馈。

## 技术设计

- 顶部工具栏与左侧文件浏览器都可触发批量删除
- 删除前弹出确认框，展示：
  - 选中模型数
  - 涉及分层
  - 是否同步删除 dbt 文件
  - 失败风险提示
- 删除后反馈：
  - 成功条数
  - 失败条数
  - 失败明细

## 影响范围

- `source/dts-platform-webapp/src/pages/modeling/SqlModelingPage.tsx`
- `source/dts-platform-webapp/src/pages/modeling/modelingToolbar.helpers.ts`
- 可能新增批量删除确认/结果组件

## 验证

- [ ] 可从顶部和左侧两处进入批量删除
- [ ] 删除结果能区分成功与失败
- [ ] 当前编辑模型被删后 UI 状态正常

## 完成标准

- [ ] 用户可清楚知道删除范围和删除结果
- [ ] 无“点删除即直接消失”的黑盒体验
