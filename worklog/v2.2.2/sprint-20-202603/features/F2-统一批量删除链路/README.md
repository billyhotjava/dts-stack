# F2: 统一批量删除链路

**优先级**: P0
**状态**: DONE

## 目标

补齐逻辑建模页面的批量删除能力，并将左树、治理弹窗、平铺列表三类选择来源统一到同一条删除执行链路。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | 统一 bulkSelection 状态模型 | P0 | DONE | - |
| T02 | 批量删除前端确认与结果反馈 | P0 | DONE | T01 |
| T03 | 后端批量删除接口与服务复用 | P0 | DONE | T01 |
| T04 | 治理弹窗与平铺列表接入统一批删 | P1 | DONE | T02,T03 |

## 完成标准

- [x] 左树、治理弹窗、平铺列表共用同一份批量选择状态
- [x] 支持批量删除前确认与删除结果回执
- [x] 后端提供稳定的批量删除入口，复用现有删除规则
- [x] 支持部分失败明细反馈，不因单条失败中断整批执行
