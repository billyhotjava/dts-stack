# Sprint-21: 统一产品入口与UI框架

**时间**: 2026-03
**状态**: READY
**目标**: 将 DTS 平台从"专业工具优先"转为"BI分析优先"，通过门户页 + 统一外壳 + 组件迁移，让两个 app 形成统一的产品体验。

## 背景

DTS 平台面向非专业业务人员使用，但当前登录后默认进入的是面向专业人士的 platform-webapp（大数据平台），BI 分析功能（analytics-webapp）反而需要多步跳转才能到达。同时两个 webapp 维护两套独立的 UI 组件库（platform 用 antd，analytics 用自定义 UI），长期维护成本高。

本 Sprint 的核心改变：
1. 新增门户选择页，登录后让用户选择"BI分析"或"大数据平台(专业版)"
2. analytics-webapp 全面迁移到 antd，消除双 UI 框架维护负担
3. 统一两个 app 的外壳（Header/侧边导航），形成一致的产品体验

## 关键决策

| 决策项 | 结论 | 理由 |
|--------|------|------|
| 门户页位置 | platform-webapp 内 `/portal` | 登录流程不动，改动最小 |
| 记住选择 | localStorage，可切换 | 业务人员不想每次多点一步 |
| 卡片风格 | 极简双卡片 | 产品初期，大多数用户只看一次 |
| 切换入口 | Header 固定按钮 | 高频操作一键可达 |
| Header 统一策略 | analytics Layout 层迁移到 antd | 渐进式统一的起点 |
| antd 引入方式 | 完整引入 | 离线环境友好，一步到位 |
| 权限控制 | 不做 | 数据资产已有权限控制 |
