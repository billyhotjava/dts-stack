# T01: 财务插件基础层与组件注册

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标

新增财务组件族的 renderer plugin 基础层，并把它们接入 analytics 大屏的插件注册与组件库。

## 技术设计

- 在 `plugins/custom/` 下新增 `finance__*` 插件适配器文件
- 抽取共享财务视觉 token 与基础块渲染工具
- 通过 `builtinPluginAdapters.tsx` 注册插件
- 在 `componentLibrary.ts` 增加“财务组件”分类

## 影响范围

- `source/dts-analytics-webapp/modern/src/pages/screens/plugins/builtinPluginAdapters.tsx`
- `source/dts-analytics-webapp/modern/src/pages/screens/componentLibrary.ts`
- `source/dts-analytics-webapp/modern/src/pages/screens/plugins/custom/*`
- `source/dts-analytics-webapp/modern/src/pages/screens/plugins/custom/financePluginAdapters.test.tsx`
