# T02: 财务组件属性面板与设计器契约

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

保证财务组件在设计器中可编辑、可保存、可再次打开，不沦为整屏黑盒。

## 技术设计

- 复用现有 property schema 机制驱动属性面板
- 确保 `specV2` 能稳定保留财务组件配置
- 对财务组件配置做最小规范化，避免 runtime/preview 因缺省字段崩溃
