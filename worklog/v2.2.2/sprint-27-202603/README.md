# Sprint-27: 财务大屏模板族插件化重构

**时间**: 2026-03
**状态**: READY
**目标**: 为 analytics 大屏系统建立财务组件族，并重构四套财务大屏模板，保留设计器可编辑和二次拖拽能力

## 背景

当前四套财务大屏已经内置到 `screenTemplates.ts`，但只是低保真模板映射版，和需求原型在视觉语言、信息结构、图表类型与财务说明区块上偏差较大。简单继续改模板无法解决复用和可维护性问题，因此需要在大屏引擎内补一层财务专用组件体系。
