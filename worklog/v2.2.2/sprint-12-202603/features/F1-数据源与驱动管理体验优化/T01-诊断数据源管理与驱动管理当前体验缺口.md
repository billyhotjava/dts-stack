## 目标

## 技术设计

基于源码读取，当前主要问题有：

- [DataSourcesPage.tsx](/opt/prod/s10/s10-stack/source/dts-platform-webapp/src/pages/foundation/DataSourcesPage.tsx) 同时承载：
  - 列表
  - 新增 / 编辑表单
  - 测试连接
  - Excel 解析
  - 回滚影响提示
- 驱动能力与数据源类型的关系主要通过表单字段隐式表达，用户难以快速理解“什么时候需要 JDBC 驱动”。
- 列表首屏对“空状态 / 刷新 / admin 托管数据源 / 文件型数据源”没有明显产品分层。
