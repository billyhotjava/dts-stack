# T03: 完善文件型数据源导入与校验反馈

**优先级**: P1
**状态**: READY
**依赖**: T02

## 目标
优化 Excel/CSV 等文件型数据源导入时的解析、预览和报错反馈，降低现场配置成本。

## 技术设计

- 收紧 Excel 预解析弹窗的反馈语义
- 改善 Sheet、Header Row、Data Start Row 等参数的默认值和错误提示
- 评估导入成功后与入湖任务创建的联动提示

## 影响范围

- 相关 Excel 解析 API 封装
