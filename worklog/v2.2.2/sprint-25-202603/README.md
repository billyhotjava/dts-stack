# Sprint-25: 分析看板编辑器

**时间**: 2026-03
**状态**: DONE
**目标**: 构建面向业务分析师的看板编辑器，支持卡片拖拽布局、筛选器参数联动、交叉过滤与下钻

## 背景

当前分析看板（DashboardEditorPage）仅提供下拉选卡片+列表展示，缺乏可视化布局编辑能力：
- 无法拖拽调整卡片位置和大小
- 无法预览卡片渲染效果
- 无筛选器参数配置 UI
- 已有的 cross-filter 和 drill-through 能力（Sprint-17）未集成到看板

与大屏编辑器的定位差异：
| 维度 | 大屏编辑器 | 看板编辑器 |
|------|-----------|-----------|
| 布局 | 绝对定位（px级自由画布） | 网格布局（12列自适应） |
| 组件 | 装饰+图表+DataV+文本+媒体 | 仅分析卡片 |
| 主题 | 暗色为主 | 跟随系统主题 |
| 交互 | 变量+action系统 | 参数+交叉过滤 |
| 用户 | 设计师/开发者 | 业务分析师 |
