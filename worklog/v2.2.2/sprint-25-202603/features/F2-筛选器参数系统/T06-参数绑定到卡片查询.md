# T06: 参数绑定到卡片查询

**优先级**: P0
**状态**: READY
**依赖**: T05

## 目标
筛选器参数值变化时，绑定的卡片自动重新查询

## 技术设计

### 绑定机制
每个 DashboardCard 有 `parameter_mappings`:
```typescript
type ParameterMapping = {
  parameter_id: string;   // 看板参数 ID
  card_id: number;        // 卡片 ID
  target: {
    type: "variable";     // 绑定到 native query 模板变量
    id: string;           // 变量名
  } | {
    type: "dimension";    // 绑定到 MBQL filter 维度
    id: string[];         // ["field", fieldName, null]
  };
};
```

### 查询流程
1. 用户更改筛选器值 → 更新 paramValues state
2. paramValues 变化 → 触发 useEffect
3. 对每张绑定了参数的卡片重新调用 queryDashcard(dashId, dcId, cardId, { parameters })
4. 未绑定参数的卡片不重新查询

### 编辑模式下的绑定配置
每张卡片的操作栏增加"参数绑定"按钮：
- 点击弹出 Popover，显示当前看板的参数列表
- 勾选要绑定的参数，选择目标变量/维度
