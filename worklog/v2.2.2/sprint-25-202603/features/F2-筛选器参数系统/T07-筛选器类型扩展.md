# T07: 筛选器类型扩展

**优先级**: P1
**状态**: READY
**依赖**: T06

## 目标
支持日期范围、下拉选择、文本输入三种筛选器类型

## 技术设计

### 类型渲染
| 类型 | 编辑控件 | 说明 |
|------|---------|------|
| date | AntD DatePicker.RangePicker | 日期范围选择 |
| category | AntD Select（动态加载选项） | 下拉选择，选项从绑定字段的 distinct 值加载 |
| string | AntD Input | 自由文本输入 |

### 选项加载
category 类型的筛选器，选项来源：
- 调用 `analyticsApi.listDashboardParamValues(dashId, paramId, query)` 获取 distinct 值
- 支持搜索过滤

## 影响范围
- 修改: `DashboardFilterBar.tsx` — 按类型渲染不同控件
- 修改: `DashboardDetailPage.tsx` — 同步支持三种类型
