# T08: 看板交叉过滤集成

**优先级**: P0
**状态**: READY
**依赖**: F1-T03

## 目标
将 useDashboardCrossFilter（Sprint-17 已实现）集成到看板编辑器的 Grid 布局中

## 技术设计

### 复用
- `useDashboardCrossFilter` hook 已在 DashboardDetailPage 中使用
- 需要在 DashboardEditorGrid 的预览模式中也启用
- 每个 DashboardEditorCard 的 ChartRenderer 接收 onSeriesClick

### 交互流程
1. 用户在预览模式下点击卡片A的柱状图某个 bar
2. 触发 crossFilter.setFilter({ sourceCardId, column, value })
3. 其他卡片检测到 activeFilter 变化，重新查询（带 filter 参数）
4. 源卡片高亮边框 + 顶部显示过滤指示条
5. 点击"清除过滤"恢复

### 视觉反馈
- 源卡片: 蓝色边框 + "交叉过滤源" badge
- 被过滤卡片: 右上角小 filter icon
- 过滤指示条: "正在按 [字段] = [值] 过滤" + 清除按钮

## 影响范围
- 修改: `DashboardEditorPage.tsx` — 引入 useDashboardCrossFilter
- 修改: `DashboardEditorCard.tsx` — 传递 onSeriesClick + 显示过滤状态
