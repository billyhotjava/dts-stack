# T10: 维度粒度切换

**优先级**: P2
**状态**: READY
**依赖**: T09

## 目标
时间维度卡片支持粒度切换（日/周/月/季/年），无需重新编辑查询

## 技术设计

### 交互
卡片标题栏右侧增加粒度选择器:
```
┌──────────────────────────────────┐
│ 月度营收趋势    [日|周|月|季|年] │
│ ───────────────────────────────  │
│         📈 图表内容              │
└──────────────────────────────────┘
```

### 实现
1. 检测卡片的 dataset_query 是否包含 temporal-unit breakout
2. 如果有，显示粒度选择器
3. 用户切换粒度 → 修改 dataset_query 中的 temporal-unit → 重新查询
4. 不修改原始保存的查询，只在运行时覆盖

### 支持的粒度
- day → 日
- week → 周
- month → 月
- quarter → 季
- year → 年

## 影响范围
- 修改: `DashboardEditorCard.tsx` — 添加粒度选择器
- 新增: `src/pages/dashboard/useTimeGranularity.ts` — 检测+切换逻辑
