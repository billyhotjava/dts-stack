# T09: 卡片下钻/上卷集成

**优先级**: P1
**状态**: READY
**依赖**: T08

## 目标
看板中的卡片支持下钻（查看明细记录）和上卷（返回聚合视图）

## 技术设计

### 复用
- `useDrillFilter` hook（Sprint-17 已实现）提供 drill-through 和 drill-to-detail
- 每张卡片独立维护自己的 drill 状态

### 交互
- 点击卡片图表 → 出现选项菜单: "按此值过滤" / "查看明细"
- "按此值过滤": 卡片内添加 filter，图表重新渲染（带 filter 的聚合结果）
- "查看明细": 卡片切换为 table 视图，显示去掉聚合的原始记录
- 面包屑导航: 卡片顶部显示 drill 路径，可点击回退

### 卡片内状态
```typescript
// 每张卡片维护独立的 drill state
const drillState = useDrillFilter();
// drill filter 变化时重新查询
useEffect(() => {
  const query = drillState.applyToDatasetQuery(baseQuery);
  queryCard(query);
}, [drillState.filters]);
```
