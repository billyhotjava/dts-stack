# T04: 编辑/预览模式切换

**优先级**: P1
**状态**: READY
**依赖**: T03

## 目标
支持编辑模式（可拖拽/删除/添加）和预览模式（只读浏览）之间切换

## 技术设计

### 模式定义
- **编辑模式**: Grid 可拖拽，卡片有操作按钮（删除），顶栏显示编辑工具
- **预览模式**: Grid 锁定，卡片只读，顶栏显示"编辑"按钮

### 实现
- `isEditing` state 控制 react-grid-layout 的 `isDraggable` / `isResizable`
- 编辑模式: 卡片有半透明操作栏（删除按钮 + 拖拽手柄提示）
- 预览模式: 卡片纯渲染，无操作栏，鼠标样式为 pointer（可点击查看详情）

### 路由
- `/dashboards/:id/edit` → 编辑模式
- `/dashboards/:id` → DashboardDetailPage（已有查看页）

## 影响范围
- 修改: `DashboardEditorPage.tsx` — 添加模式切换
- 修改: `DashboardEditorCard.tsx` — 根据模式显隐操作栏

## 验证
- [ ] 编辑模式下可拖拽、可删除卡片
- [ ] 预览模式下不可拖拽，卡片只读

## 完成标准
- [ ] 模式切换流畅，状态一致
