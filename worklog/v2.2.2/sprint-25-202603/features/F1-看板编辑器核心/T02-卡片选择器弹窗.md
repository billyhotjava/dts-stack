# T02: 卡片选择器弹窗

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
提供弹窗式卡片选择器，支持搜索、预览、批量添加分析卡片到看板

## 技术设计

### 弹窗布局
```
┌─────────────────────────────────────┐
│ 添加分析卡片                [×]      │
├─────────────────────────────────────┤
│ [🔍 搜索卡片名称...]               │
│ [类型: 全部 ▾]                      │
├─────────────────────────────────────┤
│ ☑ 月度营收趋势     折线  2026-03-28 │
│ ☐ 产品销量排行     柱状  2026-03-27 │
│ ☑ 用户增长率       数字  2026-03-26 │
│ ☐ 地区分布         饼图  2026-03-25 │
├─────────────────────────────────────┤
│ 已选 2 个               [添加到看板] │
└─────────────────────────────────────┘
```

### 实现
- AntD Modal + Table（可选择行）
- 加载 analyticsApi.listCards("question") 获取全部卡片
- 过滤掉已在看板中的卡片
- 支持按名称搜索和按图表类型过滤
- 批量选择后点击"添加"，计算放置位置（依次往下排）

## 影响范围
