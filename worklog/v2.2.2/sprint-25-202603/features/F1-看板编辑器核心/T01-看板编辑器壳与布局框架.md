# T01: 看板编辑器壳与布局框架

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标
重写 DashboardEditorPage 为完整的看板编辑器，包含顶栏、网格布局区、侧边操作区

## 技术设计

### 页面结构
```
┌─────────────────────────────────────────────────┐
│ 顶栏: [← 返回] [看板名称(可编辑)] [添加卡片] [保存] │
├─────────────────────────────────────────────────┤
│ 筛选器栏: (F2 实现)                               │
├─────────────────────────────────────────────────┤
│                                                 │
│  Grid 布局区（react-grid-layout）                 │
│  ┌────────┐ ┌────────┐ ┌────────┐              │
│  │ Card 1 │ │ Card 2 │ │ Card 3 │              │
│  └────────┘ └────────┘ └────────┘              │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 状态管理
- `dashcards: DashboardCard[]` — 卡片列表（含 row/col/size_x/size_y）
- `layout: Layout[]` — react-grid-layout 的布局数组（与 dashcards 双向同步）
- `isEditing: boolean` — 编辑/预览模式

### 关键转换
- DashboardCard `{ row, col, size_x, size_y }` ↔ react-grid-layout `{ x, y, w, h }`
- 12 列网格（而非当前 24 列），每行高度 = 80px

### 组件拆分
- `DashboardEditorPage.tsx` — 页面壳 + 状态 + 保存逻辑
- `DashboardEditorGrid.tsx` (新) — react-grid-layout 包装
- `DashboardEditorCard.tsx` (新) — 单个卡片渲染容器（含标题栏+删除按钮+ChartRenderer）

## 影响范围

- 新增: `src/pages/dashboard/DashboardEditorCard.tsx`
