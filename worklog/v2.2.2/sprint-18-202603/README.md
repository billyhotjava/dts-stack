# Sprint-18: 大屏编辑器导入导出功能完善

**时间**: 2026-03
**状态**: DONE
**目标**: 全面完善大屏编辑器与模板市场的导入导出体验，支持资源内联、导入预览、操作选择

## 背景

当前大屏编辑器的导出功能已较完善（PNG/PDF/JSON），但导入功能非常简陋（30行代码，无预览、无选择、直接覆盖），且入口隐蔽（藏在多级菜单中）。模板市场的"导入""导出"按钮行为待实现。需要：

1. **导出增强** — JSON 导出时将图片资源内联为 Base64，实现跨机器不失真的自包含导出
2. **导入增强** — 新增 ImportPreviewModal（摘要预览 + 操作选择），支持"替换当前"或"创建新大屏"
3. **UI 改进** — 编辑器中新增"导入导出"一级菜单，聚合所有导入导出操作
4. **模板市场** — 完善"导入"（注册为模板 / 创建为大屏）和"导出"（导出选中模板为自包含 JSON）

## 完成标准
- [ ] 编辑器内导出 JSON 包含内联 Base64 资源
- [ ] 编辑器内导入弹出预览 Modal，支持"替换当前"和"创建新大屏"
- [ ] 编辑器 ScreenHeader 有独立的"导入导出"一级菜单
- [ ] 模板市场"导入"按钮可导入 JSON 为模板或大屏
- [ ] 模板市场"导出"按钮可导出选中模板为自包含 JSON
- [ ] 导入含内联资源的 JSON 时，自动上传还原资源 URL
