# T06: 模板市场导出功能

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标

完善模板市场"导出"按钮，导出选中模板为含内联资源和模板元数据的自包含 JSON。

## 技术设计

**触发条件:** 用户在模板市场中选中一个模板后点击"导出"按钮。

**流程:**
1. 获取选中模板的 screenSpec
2. 调用 `inlineResources(spec)` 内联图片资源
3. 构建导出 payload，包含 `templateMeta`:
```json
{
  "schema": "dts.screen.spec",
  "schemaVersion": 2,
  "exportedAt": "...",
  "resourcesInlined": true,
  "templateMeta": {
    "name": "模板名称",
    "description": "模板描述",
    "category": "分类",
    "tags": ["标签1", "标签2"]
  },
  "screenSpec": { ... }
}
```
4. 下载为 `{模板名}-template.json`

**未选中模板时:** "导出"按钮 disabled 或点击时提示"请先选择一个模板"。
