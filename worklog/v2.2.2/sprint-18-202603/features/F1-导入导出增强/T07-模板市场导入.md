# T07: 模板市场导入功能

**优先级**: P1
**状态**: READY
**依赖**: T02, T03

## 目标

完善模板市场"导入"按钮，支持导入 JSON 文件并选择"注册为模板"或"创建为大屏"。

## 技术设计

**流程:**
1. 点击"导入" → 文件选择（`.json`）
2. 解析 JSON → normalizeScreenConfig → validateScreenPayload
3. 提取 templateMeta（如果有）
4. 打开 ImportPreviewModal(mode="marketplace")
5. 用户选择:
   - "注册为模板" → restoreResources → 调用模板创建 API → 刷新模板列表
   - "创建为大屏" → restoreResources → createScreen → navigate 到编辑页

**templateMeta 回填:**
- 如果导入的 JSON 包含 `templateMeta`，预览 Modal 显示模板名称、分类、标签
- 如果没有（编辑器导出的纯大屏 JSON），用 screenSpec.name 作为默认值
