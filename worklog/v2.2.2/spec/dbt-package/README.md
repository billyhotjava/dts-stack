# dbt Package Spec

本目录固化 `v2.2.2` 的 dbt 离线交付方案，目标是让总部离线产出的 dbt 专题包可以在现场安装、运行、回滚，而不默认污染平台的 `项目空间 / 逻辑建模` 元数据。

文档分工：

- `01-design.md`
  说明整体目标、边界、四段式生命周期和元数据隔离原则。
- `02-cli.md`
  说明命令契约、参数、默认行为、返回码和禁止的隐式动作。
- `03-sop.md`
  说明现场安装、升级、回滚、可选注册和验收步骤。
- `04-gaps.md`
  说明平台当前需要补齐的 P0/P1/P2 欠账。

阅读顺序建议：

1. 先读 `01-design.md`
2. 再读 `02-cli.md`
3. 现场实施时使用 `03-sop.md`
4. 研发实现时对照 `04-gaps.md`
