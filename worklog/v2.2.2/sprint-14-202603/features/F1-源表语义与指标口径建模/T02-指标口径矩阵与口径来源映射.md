# T02: 指标口径矩阵与口径来源映射

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标
把战略层和管控层的核心指标统一成一张口径矩阵，并标明字段来源和 Excel 参考口径。

## 口径来源优先级
1. `project3.xlsx` 与 `project_ref.xlsx/数据指标表`
   - 作为执行域的优先口径来源
2. `project_ref.xlsx/质量统计表`
   - 作为质量域的优先口径来源
3. `project2.xlsx`
   - 作为状态枚举、风险等级、闭环状态、签署状态等字典来源
4. `project_ref.xlsx/系统信息字典汇总表` 与 `风险跟进表`
   - 作为字段定义与跟进措施字段来源
5. 用户明确给出的逻辑表名
   - 成本域当前字段字典未完全展开，第一版以最小字段契约建模

| 项目本周期节点未完成总数 | 进度跟进措施表 | 项目 / 周期 | 完成情况为“不正常待变更/超期未完成未变更/超期未完成已变更”的节点数 | `project3.xlsx`、`project2.xlsx` |
| 节点按时完成数 | 进度跟进措施表 | 项目 / 周期 | 完成情况为“按时完成”的节点数 | `project3.xlsx` |

## 当前口径缺口与约束
- 成本核算基本表的字段字典尚未在 `req/s10` 中展开，第一版先按最小契约建模：
  - `项目编号`
  - `统计周期`
  - `预算金额`
  - `实际金额`
  - `责任科室/部门`
  - `项目名称`
- 风险矩阵若缺少“概率”“影响”两个显式字段，第一版需要退化为：
  - 风险等级 × 所属分系统 / 责任科室
- 技术状态域目前缺少独立统计口径表，第一版按 `project2.xlsx` 字典 + 用户业务目标定义。

## 统一口径约束
- 同一个指标只允许有一套定义，页面不得自行二次解释。
- 战略层大屏使用的指标必须来自管控层指标的汇总，不另起一套口径。
- 执行层下钻页不做新的汇总口径，只展示管控层对象的明细和措施明细。
