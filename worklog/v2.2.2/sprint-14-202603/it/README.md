# IT: Sprint-14

本目录用于沉淀 GPMC Phase 2 的集成验证与验收资产。

本 sprint 的最小集成验证入口固定为：

## 语义建模验收
- 源表到主题域映射检查
- 指标口径矩阵抽查
- 页面级 view model 清单检查

## 业务页验收
- 战略层大屏可访问
- 5 个管控层看板结构完整
- 至少 1 条执行层只读 drill 链路可走通

## 模板层验收
- 6 套模板可见
- 6 套模板可新建
- 模板变量可编辑
- 模板布局可调整并保存
- 模板 `jump-url` 可跳对应业务页或 drill 页

## 一致性验收
- 页面与模板使用同一套变量键
- 页面与模板使用同一套指标名称
- 页面与模板不出现双口径
