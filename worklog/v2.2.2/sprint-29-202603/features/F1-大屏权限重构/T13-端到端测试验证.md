# T13: 端到端测试验证

**优先级**: P0
**状态**: READY
**依赖**: T08, T09, T11, T12

## 目标
验证重构后的大屏权限系统在所有场景下正确工作

## 测试矩阵

### 场景 1: 大屏生命周期
- [ ] opadmin 创建大屏 → platform asset_ownership 有记录
- [ ] opadmin 编辑大屏 → 正常保存
- [ ] opadmin 发布大屏 → 可选密级，正确保存
- [ ] opadmin 删除大屏 → platform ownership 已清理

### 场景 2: 角色基线权限
- [ ] OP_ADMIN → 看到所有大屏，可编辑所有
- [ ] INST_DATA_OWNER → 看到所有大屏，可编辑所有
- [ ] INST_LEADER → 看到所有大屏，可编辑所有
- [ ] DEPT_DATA_OWNER → 看到本部门大屏可编辑，其他部门看不到
- [ ] DEPT_LEADER → 看到本部门大屏可编辑，其他部门看不到
- [ ] EMPLOYEE → 无基线，看不到任何大屏

### 场景 3: 显式授权
- [ ] 授权 USER + READ → 用户可查看，不可编辑
- [ ] 授权 USER + EDIT → 用户可查看和编辑
- [ ] 授权 DEPT + READ → 该部门所有人可查看
- [ ] 授权 ROLE + EDIT → 该角色所有人可编辑
- [ ] 撤销授权 → 用户立即失去访问权限

### 场景 4: 权限叠加
- [ ] EMPLOYEE 被授权 READ + 角色基线无权 → 可查看
- [ ] DEPT_LEADER 本部门大屏 + 被授权其他部门大屏 → 都可看

### 场景 5: 分享面板
- [ ] OWNER 可打开分享面板
- [ ] 可搜索并添加用户/部门/角色
- [ ] 可修改权限级别（只读↔可编辑）
- [ ] 可撤销授权
- [ ] 非 OWNER 看不到分享按钮（OP_ADMIN 除外）

### 场景 6: 密级（当前仅存储）
- [ ] 发布时可选择密级
- [ ] 密级保存到数据库
- [ ] 不选密级时为 null
- [ ] 大屏列表/详情中返回 classification 字段
