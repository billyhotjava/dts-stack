# T07: 列表/详情端点用 platform 权限过滤

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
大屏列表和详情端点使用 ScreenPermissionService 做权限过滤，替代旧逻辑

## 技术设计

### 列表端点 GET /api/screens

```java
// 方案：先获取可访问 ID 列表，再批量查询
List<String> accessibleIds = screenPermissionService.listAccessibleScreenIds(user, context);
// accessibleIds = "ALL" 对 superuser/INST 级角色
// 否则为具体 ID 列表（合并角色基线 + platform grant）

List<AnalyticsScreen> screens;
if (accessibleIds == ALL) {
    screens = screenRepository.findAllByArchivedFalseOrderByIdDesc();
} else {
    screens = screenRepository.findAllByIdInAndArchivedFalse(accessibleIds);
}
// 对每个 screen 附加 canEdit/isOwner 标志
```

### 详情端点 GET /api/screens/{id}

```java
PermissionSnapshot perms = screenPermissionService.snapshot(screen, user, context);
if (!perms.canRead()) {
    return forbidden();
}
// 返回 screen 详情 + 权限标志
```

### listAccessibleScreenIds 实现

```java
// 1. superuser → 返回 ALL
// 2. INST 级角色 → 返回 ALL
// 3. DEPT 级角色 → 本部门大屏 ID + platform grant 中的 ID
// 4. EMPLOYEE → 仅 platform grant 中的 ID
```

## 影响范围
- 修改: `ScreenResource.list()` — 使用新过滤逻辑
- 修改: `ScreenResource.get()` — 使用 ScreenPermissionService.snapshot()
- 新增: `ScreenPermissionService.listAccessibleScreenIds()`
- 可能新增: `AnalyticsScreenRepository.findAllByIdInAndArchivedFalse()`
