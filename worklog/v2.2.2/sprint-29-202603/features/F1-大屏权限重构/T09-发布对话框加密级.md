# T09: ScreenHeader 改造（发布对话框加密级选择）

**优先级**: P1
**状态**: READY
**依赖**: T06

## 目标
在大屏发布对话框中添加密级选择下拉，发布时将 classification 传给后端

## 技术设计

修改 ScreenHeader 中的发布确认对话框，添加 Select 组件：

```tsx
<Select value={classification} onChange={setClassification}>
    <Option value="PUBLIC">公开</Option>
    <Option value="INTERNAL">内部</Option>
    <Option value="SECRET">秘密</Option>
    <Option value="CONFIDENTIAL">机密</Option>
</Select>
```

发布时传入：
```ts
analyticsApi.publishScreen(id, { description, classification })
```

默认值：读取 screen 已有的 classification，没有则默认 null（不选）。

## 影响范围
- 修改: `ScreenHeader.tsx` — 发布对话框 UI
- 修改: `analyticsApi.ts` — publishScreen 方法添加 classification 参数
