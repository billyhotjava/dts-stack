# T05: 滑动窗口会话策略确认

**模块**: Platform 后端
**文件**: `source/dts-platform/src/main/java/com/yuzhi/dts/platform/security/session/PortalSessionActivityService.java`

## 问题

`touch()` 方法每次调用都延长 `expiresAt`（滑动窗口），活跃用户会话永不过期。
涉密/政务部署通常要求绝对最大会话时长（如 8 小时）。

## 修复方案

需与产品确认：是否需要添加绝对最大会话时长限制？

如需添加：
```java
// 在 touch() 中增加绝对超时检查
Instant absoluteMax = entity.getCreatedDate().plus(maxAbsoluteSessionDuration);
Instant slidingExpiry = effectiveNow.plus(sessionTtl);
entity.setExpiresAt(slidingExpiry.isBefore(absoluteMax) ? slidingExpiry : absoluteMax);
```
