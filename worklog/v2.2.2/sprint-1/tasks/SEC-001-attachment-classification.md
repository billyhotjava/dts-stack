# SEC-001: 附件密级管控

- **优先级**: P0
- **状态**: TODO

## 需求

1. **非密模块**: 禁止上传文件名或内容含"机密"字样的附件
2. **机密模块**: 判断用户密级 ≥ 附件密级才允许上传

## 设计要点

- 文件名检测：前端即可拦截
- 内容检测：需要后端读取文件头/元数据判断（PDF 属性、Office 文档属性）
- 密级层次：非密 < 秘密 < 机密，需要定义枚举
- 用户密级：从用户 profile 或组织节点获取

## 涉及范围

- platform-webapp、admin-webapp 所有文件上传组件
- 后端上传 API 增加密级校验中间件

## 交付标准

- [ ] 非密模块上传含"机密"字样文件被拦截，提示原因
- [ ] 机密模块上传时校验用户密级
- [ ] 密级不足时拒绝上传并提示
