# T03: 统一页面内部导航与公开分享路由边界

**优先级**: P0  
**状态**: READY  
**依赖**: T01,T02

## 目标

清理 analytics 页面内部所有旧绝对路径跳转，并修正公开分享页的匿名访问边界。

## 技术设计

- 引入 BI route helper，统一生成页面内链接；
- 收口 `src/analytics/**` 中的旧根路径；
- 将 `public card/dashboard/screen` 路由从登录守卫下剥离。

## 影响范围

- `source/dts-platform-webapp/src/analytics/pages/**`
- `source/dts-platform-webapp/src/analytics/routes/**`
- `source/dts-platform-webapp/src/routes/sections/**`

## 验证

- [ ] 页面内跳转不再离开 canonical route 空间
- [ ] 分享链接匿名可访问
- [ ] 不再出现 `/questions`、`/screens` 等旧根路径残留

## 完成标准

- [ ] 页面内部导航统一从 helper 生成
- [ ] 公开分享页访问语义恢复正确
