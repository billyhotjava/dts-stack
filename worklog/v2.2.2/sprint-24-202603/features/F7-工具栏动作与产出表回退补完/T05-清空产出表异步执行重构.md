# T05: 清空产出表异步执行重构

**优先级**: P0
**状态**: DONE
**依赖**: T03

## 目标

把 `清空产出表` 从 `dts-platform` 直连目标数仓的同步执行模型，重构为统一的 dbt / Airflow 后台任务模式。

## 技术设计

- 前端确认清空后不再请求平台直连 JDBC 分析接口
- 后端改为提交 `dbt run-operation truncate_relation` 到 Airflow DAG
- 在 dbt workspace 中新增 `truncate_relation` 宏，由 dbt 容器侧执行 relation 检查和 `TRUNCATE`
- 页面反馈统一为“任务已提交 + 运行状态/日志跟踪”，不再要求 HTTP 请求内同步完成
