# T06: 修复上线提交同步阻塞与按钮长时间转圈

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

让逻辑建模页 `上线` 弹窗中的 `提交` 动作快速返回，不再因为后端同步预处理导致按钮长时间转圈。

## 技术设计

- 保留 DAG 就绪检查、质量门禁、发布门禁和 Airflow 触发逻辑
- 从 `DbtReleaseSubmissionService` 中移除同步 `refreshOdsSources()`，避免在 HTTP 请求线程里做额外 workspace 文件刷新
- 让 `release submit` 与其它异步任务提交动作保持一致：请求只负责校验和提交，不承担耗时准备工作
