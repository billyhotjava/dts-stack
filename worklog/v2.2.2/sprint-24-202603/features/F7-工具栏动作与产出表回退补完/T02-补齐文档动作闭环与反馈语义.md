# T02: 补齐文档动作闭环与反馈语义

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

让 `文档` 按钮从“仅提交 docs generate”变成可理解、可验收的用户动作。

## 技术设计

- 明确文档按钮是生成文档产物，还是生成后提供浏览入口
- 如果暂不做浏览页，至少补清晰反馈和验收定义
- 若条件允许，补最小文档访问入口
