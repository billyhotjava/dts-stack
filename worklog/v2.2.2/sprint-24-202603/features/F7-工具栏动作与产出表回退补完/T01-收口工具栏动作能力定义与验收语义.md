# T01: 收口工具栏动作能力定义与验收语义

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

把 `提交变更`、`同步模型`、`文档`、`回退` 的产品语义和当前实现对齐，避免名称和真实能力不一致。

## 技术设计

- 梳理前端按钮点击链路与后端接口落点
- 明确 `提交变更` 是 Git commit，不是审批流
- 明确 `同步模型` 是 manifest 资产同步
- 明确 `文档` 当前是 docs generate 还是 docs 浏览
