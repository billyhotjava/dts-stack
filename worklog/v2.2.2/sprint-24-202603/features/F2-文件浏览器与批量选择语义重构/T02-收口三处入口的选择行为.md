# T02: 收口三处入口的选择行为

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

统一左树、治理弹窗、未归档列表三处入口的勾选、全选、清空和执行语义。

## 技术设计

- 左树只负责 `tree` source bucket
- 治理弹窗只负责 `governance` source bucket
- 未归档列表只负责 `list` source bucket
- 删除/归档/治理执行时默认使用并集，但 UI 要显示来源组成

## 影响范围

- `GovernanceModal.tsx`
- `ModelFileBrowser.tsx`
