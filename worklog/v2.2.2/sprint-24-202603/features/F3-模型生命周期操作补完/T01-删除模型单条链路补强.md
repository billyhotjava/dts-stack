# T01: 删除模型单条链路补强

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标

补强单模型删除的确认、执行、失败反馈和当前编辑态回收逻辑。

## 技术设计

- 收口单删与批删的反馈语义
- 删除当前编辑模型后自动回收编辑态

## 影响范围

- `SqlModelingPage.tsx`
- `ModelingSqlModelService.java`

## 验证

- [x] 删除链路测试

## 完成标准

- [x] 单删反馈和状态回收稳定

## 实现说明

- 单删前端入口改为复用 `/batch-delete` 结果结构，不再单独维护第二套删除回执语义
- 删除当前编辑模型后，继续沿用 `applyDeletedModelSelection` 回收编辑态
- 删除结果统一通过 `BatchDeleteResultModal` 展示成功/失败明细
