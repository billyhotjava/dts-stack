# T03: 模型治理执行链与批删语义对齐

**优先级**: P0
**状态**: DONE
**依赖**: T02

## 目标

使模型治理的删除执行链与批量删除保持一致的结果语义和回执能力。

## 技术设计

- 治理执行结果按成功/跳过/失败拆分
- 与批删的选择和反馈逻辑对齐

## 影响范围

- `SqlModelingPage.tsx`
- `GovernanceModal.tsx`
- `ModelGenerationService.java`

## 验证

- [x] 治理执行测试

## 完成标准

- [x] 治理执行结果可解释

## 实现说明

- 后端 `SqlModelGovernanceExecuteResult` 增加 `failed` 计数
- `executeGovernance` 现在会显式返回 `DELETED / FAILED / SKIPPED` 三类 item，而不是把所有未删除项都折叠成 `skipped`
- 前端新增 `buildSqlModelGovernanceDetail`，并复用统一结果弹窗展示治理成功/失败/跳过明细
