# T03: 现场验收与集成检查

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标
给离线现场一套升级后必查项，重点覆盖 `.env`、legacy compose 和 PostgreSQL。

## 技术设计
- 现场最小验收清单至少包括：
  - 容器全部启动且关键容器 health 为 `healthy`
  - `.env` 中现场自定义值仍然存在
  - legacy 环境实际按 `docker-compose.legacy.yml` 启动
  - normal 环境实际按 `docker-compose.yml` / `docker-compose-app.yml` 启动
  - PostgreSQL 成功使用旧数据目录启动
  - 关键业务库可连接，核心表数量和升级前一致
  - `logs/upgrade-*.log` 与 `logs/upgrade-*.summary.md` 已生成
- 对 legacy 现场额外检查：
  - `docker compose -f docker-compose.legacy.yml ps` 结果正常
  - legacy 文件中的现场定制端口、卷、环境变量没有丢
- 对数据库额外检查：
  - `PG_VERSION` 与目标镜像 major 兼容
  - 冷备目录存在且记录到 rollback manifest
  - 若升级失败，runbook 中有明确的整目录回滚动作

## 影响范围
- runbook
- `it/README.md`

## 验证
- [ ] 有最小人工验收清单
- [ ] 验收项覆盖 legacy 和 PostgreSQL 两条关键风险线

## 完成标准
- [ ] 现场验收项完整可执行
