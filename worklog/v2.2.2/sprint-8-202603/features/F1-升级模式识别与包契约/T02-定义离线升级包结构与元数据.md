# T02: 定义离线升级包结构与元数据

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标
明确离线升级包必须包含哪些目录和元数据，以及 legacy/normal 共用哪些交付契约。

## 技术设计
- 固定升级包为 `dts-stack/ + images/ + extra/`
- `extra/` 至少包含：
  - `release-manifest.json`
  - `checksums.txt`
  - `rollback-manifest.json`
- 升级器只使用本地包，不允许远程下载

## 影响范围
- `builds/dts-build.sh`
- `bin/dts-upgrade`
- 升级说明文档

## 验证
- [x] 打包产物包含升级器与元数据
- [x] 缺失 manifest/checksums 时升级直接失败

## 完成标准
- [x] 离线升级包契约统一
- [x] legacy/normal 都使用同一套离线元数据
