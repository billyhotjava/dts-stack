# T03: 工作台大屏列表端到端验证

**优先级**: P1
**状态**: READY
**依赖**: F1/T05, F1/T06

## 目标

验证工作台"数据大屏"卡片列表在所有典型场景下行为正确，无跨机器不一致问题。

## 验证场景

### 场景一：创建者本机查看

1. opadmin 登录本机 Chrome（已有 session）
2. 创建新大屏 → 保存
3. 工作台刷新 → **期望**：新大屏出现在数据大屏卡片列表

### 场景二：被授权用户查看（本机 Chrome）

1. opadmin 授权 test230916 VIEWER
2. test230916 在本机 Chrome 刷新工作台
3. **期望**：新大屏出现（无需重新登录，无 session 依赖）

### 场景三：被授权用户查看（Win7 Chrome 95）

1. 同场景二，但在 Win7 Chrome 测试
2. **期望**：与场景二结果一致（跨机器行为一致）

### 场景四：撤权后消失

1. opadmin 撤销 test230916 的权限
2. test230916 刷新工作台
3. **期望**：大屏从列表中消失

### 场景五：superuser 全量可见

1. opadmin 登录（superuser=true）
2. 工作台刷新
3. **期望**：所有大屏均可见，不受权限表限制

### 场景六：MANAGER 权限

1. opadmin 授权 test230916 MANAGER
2. test230916 打开大屏
3. **期望**：可查看、可打开权限管理面板，但无法编辑大屏内容（编辑按钮禁用或不显示）

## 回归检查

- [ ] 大屏管理列表（`GET /bi/api/screens`）与工作台列表结果一致
- [ ] 权限校验不再依赖 `X-DTS-Roles` 头（roles 仅用于 ROLE 类型 grant 匹配）
- [ ] 无 `PlatformPermissionClient` 网络调用（可通过后端日志确认）

## 完成标准

- [ ] 场景一～六全部通过
- [ ] 本机 Chrome 与 Win7 Chrome 行为完全一致
- [ ] 后端日志无 platform API 调用（权限路径）
