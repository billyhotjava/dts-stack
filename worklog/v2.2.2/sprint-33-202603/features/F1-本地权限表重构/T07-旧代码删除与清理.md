# T07: 旧代码删除与清理

**优先级**: P0
**状态**: READY
**依赖**: T03, T04, T05

## 目标

彻底删除所有旧权限代码（analytics ACL 遗留 + Sprint-29/Sprint-26 过渡代码 + platform-webapp 合并遗留），不留死代码。

## 删除清单

### 后端 — `dts-analytics`

**类级别删除（若已无任何有效用途）：**
- `PlatformPermissionClient` 的权限查询方法：`check()`、`batchCheck()`、`listAccessibleAssetIds()`、`invalidateCache()`
  - 如果 `PlatformPermissionClient` 还有其他用途则保留类，仅删权限方法
  - 如已无用途则整个类删除
- `ScreenPermissionService` 旧实现中残留的方法：`invalidateCacheForUser`、`checkClassification`、`checkDataSourceAccess`、`isAllAccessible`

**方法级别删除（`ScreenResource.java`）：**
- `resolveGranteeUsername(String)` — ID 翻译逻辑
- `backfillGrants()` — 被 T06 新接口替代
- `PlatformContext context = PlatformContext.from(request)` — 所有权限路径中的调用

**字段/依赖删除（`ScreenResource.java`）：**
- `AnalyticsUserRepository userRepository` 字段（若仅用于 resolveGranteeUsername）
- 构造函数中对应参数

**过滤器/拦截器：**
- `PlatformPermissionFilter` 中针对 `SCREEN` 资产类型的专项处理（若存在）
- 确认 `PlatformSessionBridgeFilter` 无大屏权限相关代码（保留，用于 session 创建）

**Services：**
- `ScreenOwnershipService` 中 `RestTemplate`、`platformBaseUrl`、`registerOwnership`、`transferOwnership`
- `PlatformTrustedUserService.refreshKnownUserAttributes` — 评估是否仍需要（用于 session 用户的 platform_username 回填）；若 platform_username 不再用于权限判断则可删除此方法

### 前端 — `dts-platform-webapp`（platform-webapp 合并遗留）

需 review 以下位置，删除旧 ACL 相关代码：
- 任何在前端做角色硬编码权限判断的逻辑（如 `if (role === 'ROLE_OP_ADMIN') ...`）
- 旧的 `ScreenAclService` 或类似的前端权限 store/hook（若存在）
- `analytics/` 目录下与旧 ACL 相关的类型定义和 API 调用

**注意**：`ScreenSharePanel`、`ScreenAclPanel` 保留，功能是调用新的授权端点，不是旧 ACL。

## 检查方法

```bash
# 确认 PlatformPermissionClient 权限方法无残留调用
grep -r "listAccessibleAssetIds\|\.check(\|\.batchCheck\|invalidateCache" \
  src/main/java --include="*.java"

# 确认 resolveGranteeUsername 已删除
grep -r "resolveGranteeUsername\|PlatformContext\|invalidateCacheForUser" \
  src/main/java --include="*.java"

# 确认前端无角色名硬编码（superuser DB字段除外）
grep -r "ROLE_OP_ADMIN\|ROLE_INST\|ROLE_DEPT" \
  src/analytics --include="*.ts" --include="*.tsx"
```

## 完成标准

- [ ] 上述 grep 命令均无匹配结果（或匹配仅在注释/测试中）
- [ ] 编译通过，无 unused import 警告
- [ ] 前端构建通过，无 TypeScript 类型错误
- [ ] 旧 `ScreenAcl*` 相关代码（若有）在前端已删除
