# T02: 拆分任务查询与执行编排服务

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标
将“任务查询/日志查看”和“任务执行/重试/编排”从超大服务中分离，为后续资源层瘦身做准备。

## 技术设计

- 先识别只读查询方法和执行编排方法
- 抽出查询导向服务，不改对外 API
- 资源层逐步改为面向更窄的服务接口
