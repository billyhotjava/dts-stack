# T01: 诊断执行链与日志链重复实现

**优先级**: P1
**状态**: DONE
**依赖**: 无

## 目标
识别执行状态查询、最新执行轮询、日志回显链条中的重复实现，为后续统一契约做准备。

## 技术设计

- 前端创建页已经内置“创建成功 -> 解析任务 ID -> 轮询最新执行 -> 映射进度”的完整链
- 详情页、执行历史页和后端执行状态接口之间存在相似但不完全相同的语义映射
- 后端资源层同时承载最新执行、历史、日志、状态查询，契约分散

第一批优化不直接重写执行链，而是先在 sprint 内沉淀统一方向。
