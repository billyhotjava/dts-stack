# T02: 统一执行状态查询与日志回显契约

**优先级**: P1
**状态**: READY
**依赖**: T01

## 目标
收敛入湖执行状态和日志回显的契约，减少前端对后端细节的感知。

## 技术设计

- 收敛最新执行、历史执行和日志查询的返回语义
- 尽量让前端轮询视图基于同一套 DTO/字段
- 为异常反馈补明确状态与 message

## 影响范围

- 后端执行/日志接口
- 前端执行历史与详情页
- E2E 冒烟与异常回归

## 验证

- [ ] 执行状态相关测试通过
- [ ] 日志回显相关测试通过

## 完成标准

- [ ] 前后端执行状态语义更一致
- [ ] 页面异常提示更稳定
