# T02: 抽离创建页初始化加载与运行进度轮询

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T01

## 目标
把创建页的初始化异步加载和 run-now 异步执行进度逻辑从页面主组件中拆出去，降低组件复杂度并补齐针对性测试。

## 技术设计

- 提取独立 hook 或 helper，统一处理以下加载链：
  - 数据源列表
  - 连接器能力
  - 模板
  - 默认目标
  - SQL 模型
- 提取独立运行进度控制逻辑：
  - 提交成功后的任务 ID 解析
  - 最新执行记录轮询
  - 进度阶段和终态映射
- 保持页面现有交互和 API 契约不变
- 先用测试锁定抽离后的行为，再做最小实现

## 当前进展

- 已完成第一批切分：异步执行进度 helper 与 hook 独立落盘
- 已用模块级测试锁定任务 ID 解析、轮询提示、终态映射和 poll hint 解析
- 初始化加载链仍留在页面内，下一步继续切分
