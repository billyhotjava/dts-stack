# T03: 收敛草稿、模板和文件流状态边界

**优先级**: P1
**状态**: IN_PROGRESS
**依赖**: T02

## 目标
降低草稿恢复、模板应用、文件解析和 ODS 匹配之间的状态串扰，收紧表单状态边界。

## 技术设计

- 识别草稿、模板、文件上传三条链路的共享状态
- 将与步骤 UI 无关的转换逻辑下沉到 helper/hook
- 补齐关键异常路径测试，避免重复回归
