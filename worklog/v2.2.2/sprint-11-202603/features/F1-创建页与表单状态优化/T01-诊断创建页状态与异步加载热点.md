# T01: 诊断创建页状态与异步加载热点

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标
识别创建页中最值得优先切分的状态和异步逻辑，为第一批优化确定边界。

## 技术设计

本任务通过源码扫描和热点统计，识别出以下高风险区域：

- 页面主体 [TransformCreatePage.tsx](/opt/prod/s10/s10-stack/source/dts-platform-webapp/src/pages/explore/etl/TransformCreatePage.tsx) 超过 3000 行
- 多个 `useEffect` 同时负责数据源、能力、模板、默认目标、模型、编辑态任务加载
- 异步执行进度轮询与提交成功处理混在页面主组件中
- 草稿恢复、本地持久化、文件解析和 ODS 匹配穿插在表单编排逻辑中

第一批优化优先选择“初始化加载 + 运行进度轮询”作为切口，因为收益高且不改表单协议。
