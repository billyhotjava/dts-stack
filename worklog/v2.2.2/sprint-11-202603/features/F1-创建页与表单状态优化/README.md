# F1: 创建页与表单状态优化

**优先级**: P0
**状态**: IN_PROGRESS

## 目标
拆分创建页中耦合的初始化加载、运行进度和草稿/模板状态，让页面回到“编排 UI”职责，而不是承载全部业务流程。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | 诊断创建页状态与异步加载热点 | P0 | DONE | - |
| T02 | 抽离创建页初始化加载与运行进度轮询 | P0 | IN_PROGRESS | T01 |
| T03 | 收敛草稿、模板和文件流状态边界 | P1 | READY | T02 |
| T04 | 支持粘贴 ODS 字段列表自动映射 Excel 列 | P1 | IN_PROGRESS | T02 |

## 完成标准

- [ ] 创建页初始化加载逻辑有独立承载点
- [ ] 异步执行进度轮询不再与表单渲染强耦合
- [ ] 页面组件复杂度和副作用数量下降
