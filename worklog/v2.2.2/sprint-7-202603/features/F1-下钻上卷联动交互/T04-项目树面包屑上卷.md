# T04: 项目树面包屑上卷

**优先级**: P1
**状态**: READY
**依赖**: 无

## 目标
项目树选中节点后，详情面板顶部显示面包屑导航，支持点击上卷到父级汇总视图

## 技术设计

### 1. 面包屑生成
在 `majorProjectTreeView.helpers.ts` 中新增：
```typescript
function buildBreadcrumb(tree: TreeNode[], selectedId: string): BreadcrumbItem[]
// 返回: [重大项目, 子项目, 节点] 路径
```

### 2. ProjectTreeDetailPanel 增加面包屑
- 面板顶部渲染 antd `Breadcrumb` 组件
- 每个层级可点击：
  - 点击"重大项目" → `onSelect(majorProjectId)` → 面板显示重大项目汇总
  - 点击"子项目" → `onSelect(subProjectId)` → 面板显示子项目汇总
  - 当前节点不可点击（末级）

### 3. 汇总视图
- 父级节点选中时，详情面板显示汇总信息：
  - 子节点数、完成率、高风险数、平均延期天数
  - 子节点状态分布饼图（迷你）

## 影响范围
- `views/majorProjectTreeView.helpers.ts` — 新增 buildBreadcrumb
- `components/ProjectTreeDetailPanel.tsx` — 增加面包屑 + 汇总视图
- `views/MajorProjectTreeView.tsx` — 传递 tree 数据给面板
