# T03: 图表联动与归因矩阵追溯

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
实现趋势图点击联动全局筛选 + 归因矩阵 reason pill 点击追溯到延期任务列表

## 技术设计

### 1. 趋势图点击联动
在 `OverviewTrendView` 的 ApexCharts 配置中：
- 启用 `chart.events.dataPointSelection` 回调
- 点击数据点时，提取该周的起止日期
- 调用 `updateQueryState({ dateFrom, dateTo })` 缩窄全局筛选范围
- 其他 Tab/面板自动重新请求数据
- 图表上方增加"已聚焦: 2026-03-16周"提示 + 重置按钮

### 2. 归因矩阵追溯
在 `DelayReasonMatrix` 组件中：
- reason pill 增加 `onClick` → `setDrillState({ target: 'delay-reason', params: { dept, reason } })`
- 部门名称增加 `onClick` → `setDrillState({ target: 'delay-dept', params: { dept } })`
- DrillDownDrawer 按 dept+reason 展示延期任务明细

### 3. 排名表行点击
在 `OverviewTrendView` 的排名表中：
- 行点击 → `updateQueryState({ majorProjectId })` → 切换到该项目视角
- 或跳转到"重大项目树" Tab 并选中该项目

## 影响范围
- `views/OverviewTrendView.tsx` — ApexCharts 事件绑定 + 排名表行点击
- `components/DelayReasonMatrix.tsx` — reason pill / dept onClick
- `components/DrillDownDrawer.tsx` — 增加 delay-reason / delay-dept 内容
- `views/RiskAttributionView.tsx` — 矩阵追溯接入
