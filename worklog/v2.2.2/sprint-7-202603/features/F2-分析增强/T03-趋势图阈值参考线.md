# T03: 趋势图阈值参考线

**优先级**: P2
**状态**: READY
**依赖**: 无

## 目标
趋势图增加水平参考线（如完成率 80% 目标线），帮助用户判断指标是否达标

## 技术设计

### 1. ApexCharts annotations
使用 ApexCharts 内置的 `annotations.yaxis` 功能：
```typescript
annotations: {
  yaxis: [{
    y: 80,
    borderColor: '#FF4560',
    strokeDashArray: 4,
    label: {
      text: '目标 80%',
      style: { background: '#FF4560', color: '#fff' }
    }
  }]
}
```

### 2. 可配置阈值
- 从 summary API 的 `thresholds` 字段读取（若后端提供）
- 否则使用前端默认值：完成率 80%，高风险节点 0
- 阈值线样式：红色虚线 + 右侧标签

## 影响范围
- `views/OverviewTrendView.tsx` — 趋势图 annotations 配置
- `views/RiskAttributionView.tsx` — 延期趋势图 annotations

## 验证
- [ ] 完成率趋势图显示 80% 红色虚线目标线
- [ ] 标签文字不溢出图表边界
- [ ] 无阈值数据时不渲染参考线

## 完成标准
- [ ] 参考线在图表缩放时保持正确位置
