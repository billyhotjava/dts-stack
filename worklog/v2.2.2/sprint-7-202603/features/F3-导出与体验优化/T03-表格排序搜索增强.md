# T03: 表格排序搜索增强

**优先级**: P1
**状态**: READY
**依赖**: 无

## 目标
所有看板内的 antd Table 统一支持列排序和关键词搜索

## 技术设计

### 1. 列排序
为所有 Table columns 增加 `sorter` 配置：
- 数值列：`(a, b) => a.value - b.value`
- 文本列：`(a, b) => a.name.localeCompare(b.name, 'zh-CN')`
- 日期列：`(a, b) => new Date(a.date) - new Date(b.date)`

### 2. 关键词搜索
- 在每个 Table 上方增加 `Input.Search` 组件
- 输入关键词后，前端过滤所有文本列包含该关键词的行
- 搜索防抖 300ms

### 3. 受影响的表格
- OverviewTrendView: 项目排名表
- ExecutionView: 到期/延期列表、工作量表
- RiskAttributionView: 延期项目表
- DelayReasonMatrix: 矩阵表
- DrillDownDrawer: 下钻明细表

## 影响范围
- 各 View 文件中的 Table columns 定义
- `components/DelayReasonMatrix.tsx` — 增加排序

## 验证
- [ ] 点击列标题 → 升序/降序切换
- [ ] 输入搜索关键词 → 表格实时过滤
- [ ] 清空搜索 → 恢复全部数据

## 完成标准
- [ ] 所有表格均支持排序和搜索
- [ ] 搜索不影响分页（如有）
