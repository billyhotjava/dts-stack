# T02: 甘特图虚拟滚动

**优先级**: P2
**状态**: READY
**依赖**: 无

## 目标
移除甘特图 16 条硬限制，支持大数据量下的虚拟滚动渲染

## 技术设计

### 1. 移除截断逻辑
当前 `ProjectGanttBoard.tsx` 中 `tasks.slice(0, 16)` 硬截断，改为渲染全量数据。

### 2. 虚拟滚动
- 甘特图外层容器设固定高度（如 480px）
- 使用 CSS `overflow-y: auto` + 每行固定高度（48px）
- 大于 50 条时考虑使用 `react-window` 虚拟化
- 时间轴表头保持 sticky

### 3. 分组折叠
- 按重大项目分组，默认折叠
- 组标题行显示：项目名 + 任务数 + 整体进度条
- 点击展开/折叠

## 影响范围
- `components/ProjectGanttBoard.tsx` — 移除截断、增加虚拟滚动和分组

## 验证
- [ ] 50+ 任务时无明显卡顿
- [ ] 滚动时时间轴表头保持固定
- [ ] 分组折叠/展开正常工作

## 完成标准
- [ ] 移除 16 条限制
- [ ] 100 条任务时渲染性能 < 200ms
