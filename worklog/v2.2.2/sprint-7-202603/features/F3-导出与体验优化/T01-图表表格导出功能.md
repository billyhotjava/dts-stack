# T01: 图表/表格导出功能

**优先级**: P2
**状态**: READY
**依赖**: 无

## 目标
所有图表支持 PNG 导出，所有数据表格支持 CSV 导出

## 技术设计

### 1. 图表导出（ApexCharts 内置）
启用 ApexCharts toolbar：
```typescript
chart: {
  toolbar: {
    show: true,
    tools: {
      download: true,    // PNG/SVG 下载
      selection: false,
      zoom: false,
      pan: false,
    }
  }
}
```
- 默认导出 PNG
- 文件名格式：`{图表标题}_{日期}.png`

### 2. 表格导出（CSV 工具函数）
新建 `utils/csvExport.ts`：
```typescript
function exportTableToCsv(columns: Column[], data: any[], filename: string): void
```
- 在每个有 Table 的面板右上角增加"导出"按钮
- 支持中文列名 + BOM 头（Excel 兼容）

### 3. 导出按钮统一样式
- 使用 antd `Button` + `DownloadOutlined` 图标
- 放在 TrendPanel 的 action 区域

## 影响范围
- `utils/csvExport.ts` — 新建
- 所有 View 文件 — ApexCharts toolbar 配置
- `components/TrendPanel.tsx` — action 区域放导出按钮
- `components/DrillDownDrawer.tsx` — Drawer 内表格增加 CSV 导出
