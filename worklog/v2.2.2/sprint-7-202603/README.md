# Sprint-7: 项目看板 BI 分析能力增强

**时间**: 2026-03
**状态**: READY
**目标**: 为项目看板补齐下钻/上卷/联动/导出等 BI 分析基本操作，使看板从"只读展示"升级为"可交互分析"

## 背景

项目看板（project-cockpit）当前 5 个 Tab 视图均为静态只读展示：
- KPI 卡片不可点击，无法下钻到明细
- 图表之间无联动，5 个 Tab 完全隔离
- 项目树无上卷导航，归因矩阵无追溯
- 表格无排序/搜索，甘特图硬限 16 条
- 无任何导出能力（CSV/图片/PDF）

客户反馈看板"只能看不能用"，无法满足项目管理决策场景的分析需求。

## Feature 列表

| ID | Feature | Task 数 | 状态 |
|----|---------|---------|------|
| F1 | 下钻/上卷/联动交互 | 4 | READY |
| F2 | 分析增强（同环比/偏差/阈值） | 3 | READY |
| F3 | 导出与体验优化 | 3 | READY |

## 完成标准
- [ ] KPI 卡片点击可下钻到明细列表
- [ ] 趋势图点击某周可联动其他面板筛选
- [ ] 归因矩阵点击可追溯到延期任务
- [ ] 项目树支持面包屑上卷导航
- [ ] KPI 卡片显示环比趋势
- [ ] 甘特图支持 baseline overlay
- [ ] 图表支持 PNG 导出，表格支持 CSV 导出
- [ ] 甘特图移除 16 条硬限，支持虚拟滚动
