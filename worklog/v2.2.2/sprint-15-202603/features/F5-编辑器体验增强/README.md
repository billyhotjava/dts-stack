# F5: 编辑器体验增强

**优先级**: P1
**状态**: READY

## 目标
解决大屏编辑器的 UX 痛点：属性编辑器增强、网格可见性、工具箱分组、Table 编辑、格式刷、快捷操作

## 问题清单

### 已确认问题
1. **网格不明显** — 编辑时网格线几乎看不见，无法辅助对齐
2. **工具箱菜单太长** — 视图/版本导出/治理三个 tab 下的按钮扁平罗列，需要更好的分组
3. **快捷操作使用频率低** — 快捷键存在但不可见，缺少操作提示和快捷面板
4. **Table 编辑不完善** — 缺少列宽调整、单元格样式、排序配置等
5. **无格式刷** — 无法复制一个组件的样式到另一个组件
6. **主题切换不生效** — 已在 F2 中解决

### 可能存在的其他问题（待排查）
7. **PropertyPanel 6536 行巨石** — 属性面板代码量过大，编辑体验可优化
8. **组件对齐辅助线缺失** — 拖拽时无智能吸附/对齐参考线
9. **批量操作弱** — 多选组件后可用操作有限
10. **撤销/重做无可视反馈** — 操作后无 toast 提示
