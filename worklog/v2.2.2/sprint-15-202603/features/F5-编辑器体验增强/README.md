# F5: 编辑器体验增强

**优先级**: P1
**状态**: IN_PROGRESS

## 目标
解决大屏编辑器的 UX 痛点，对标 DataV/AvueData 编辑器体验

## 已完成改造

### 1. 右侧属性面板 Tab 重构 (Done)
- 从 2 Tab（属性/图层）改为 5 Tab：**样式/数据/交互/图层/高级**
- 样式Tab：快速定位、快捷操作、位置尺寸、组件配置、标注
- 数据Tab：数据源、字段映射、解释
- 交互Tab：下钻、联动、动作入口
- 高级Tab：其他设置、入场动画配置
- 快捷键 Ctrl+1~5 切换Tab
- 文件：`PropertyPanel.tsx`, `ScreenDesignerPage.tsx`, `screenDesignerLayoutState.ts`

### 2. Canvas 右键上下文菜单 (Done)
- 右键组件：复制/拷贝/删除/置顶/置底/锁定/解锁/显示/隐藏
- 右键空白区域：粘贴/撤销/重做/全选
- 支持暗色主题
- 文件：`DesignerCanvas.tsx`, `CanvasComponent.tsx`

### 3. 工具栏分组优化 (Done)
- 按钮紧凑化，按功能分组：历史/对齐/分布编组/视图/缩放/状态
- 添加分隔线 `toolbar-separator`
- 对齐按钮改为直接点击（不再需要先选+执行）
- 网格切换按钮
- 文件：`CanvasToolbar.tsx`

### 4. 组件库增强 (Done)
- 网格从2列改为3列，卡片样式增强（渐变hover、图标背景圆角）
- 分类标签快速过滤（图表/边框/装饰/数据展示/文本/筛选器/媒体/3D）
- 头部布局简化，搜索框置顶
- 文件：`ComponentLibraryPanel.tsx`

### 5. 入场动画配置 (Done)
- 高级Tab中8种入场动画：淡入/上滑/下滑/左滑/右滑/缩放/弹性/旋转
- 可配置时长、延迟、缓动函数
- 自动编排延迟（按位置从上到下、从左到右递增150ms）
- 预览模式自动应用动画（CSS keyframes）
- 文件：`PropertyPanel.tsx`, `ScreenPreviewPage.tsx`, `ScreenRuntimeShell.css`

### 6. 图层面板拖拽排序 (Done)
- 支持拖拽调整图层顺序
- 拖拽时显示蓝色指示线
- 保留原有的按钮排序功能
- 文件：`LayerPanel.tsx`
