# Sprint-9: 指挥大屏增强与看板联动

**时间**: 2026-03
**状态**: DONE
**目标**: 将“项目运营管理大屏”从早期 3 屏演进为 5 屏轮播，补齐总体态势、执行与里程碑、风险与变更、项目树与重点项目、指标对账，并实现大屏→项目看板联动与手动轮播控制

## 背景

1. 客户习惯传统 BI 大屏"投屏→指挥→下钻"模式，当前大屏只有展示无交互
2. project3.xlsx 定义了 4 维度 34 个指标，后端已实现大部分计算但大屏只展示了约 60%
3. 项目看板更偏管理页，客户需要更接近会议室场景的传统轮播大屏
4. 轮播默认自动、无暂停按钮，领导讲解时无法控制停留
