# T02: 第4屏模板布局与组件配置

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
在 `projectManagementCommandCenterTemplate.ts` 中新增第 4 屏 `buildMetricsPage()`，将 34 个指标按 4 维度分组展示

## 技术设计

### 布局 (1920×1080)
```
┌──────────────────────────────────────────────────┐
│ 标题栏 + 筛选器（复用现有 header 模式）           │ Y: 0-110
├─────────────────┬────────────────┬───────┬────────┤
│ 项目(含一般节点) │ 项目(除一般节点) │ 未完成 │ 本周期 │ Y: 126-1040
│ 13 个 card      │ 6 个 card      │ 5 card│ 10 card│
│ 2列×7行         │ 2列×3行        │ 1列×5 │ 2列×5行│
└─────────────────┴────────────────┴───────┴────────┘
```

### 组件配置
- 每个维度一个 `shape(rect)` 背景面板 + `title` 标题
- 34 个 `number-card` 组件，每个绑定 `/screen/metrics-overview` 的对应 path
- 例：`pmcc-metrics-kpi-0` → apiPath `kpis.0`, dataSource: `/analytics/api/project-cockpit/screen/metrics-overview`
- 百分比指标 suffix: `%`，个数指标 suffix: `个`

### 轮播注册
在 template 的 `pages[]` 数组中追加第 4 页：
```typescript
{ id: 'pmcc-page-metrics', name: '指标全览', cards: [...] }
```

## 影响范围
- `projectManagementCommandCenterTemplate.ts` — 新增 `buildMetricsPage()` + 注册到 pages

## 验证
- [ ] 大屏预览第 4 屏显示 34 个 number-card
- [ ] 4 个维度分组标题正确
- [ ] 筛选条件变化时数据刷新

## 完成标准
- [ ] 34 个指标全部可见，无溢出
