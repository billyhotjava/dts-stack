# T01: 轮播默认暂停+播放/暂停按钮

**优先级**: P0
**状态**: READY
**依赖**: 无

## 目标
修改大屏轮播组件，支持默认暂停、播放/暂停按钮、手动翻页自动暂停

## 技术设计

### 1. 定位轮播渲染组件
大屏 carousel 由 `useScreenCarousel.ts` hook 控制，需要找到：
- 自动翻页的 timer 逻辑
- 页码指示器渲染位置

### 2. 新增 `autoPlay` 配置
在 `carouselConfig` 类型中新增：
```typescript
autoPlay?: boolean; // 默认 false（改为手动模式）
```

### 3. useScreenCarousel hook 改造
- 新增 `isPlaying` state，初始值从 `carouselConfig.autoPlay ?? false` 读取
- `play()` / `pause()` / `toggle()` 方法
- timer 仅在 `isPlaying === true` 时启动
- 外部调用 `goToPage(n)` 时自动 `pause()`

### 4. 播放/暂停按钮 UI
在大屏预览页面的轮播控制栏中渲染：
- 播放状态：显示暂停图标 `⏸`
- 暂停状态：显示播放图标 `▶`
- 按钮位置：页码指示器旁边
- 样式：半透明背景，hover 高亮，不遮挡内容
- Chrome 95 兼容：使用 SVG 图标，不用 emoji

### 5. 页码点击联动
现有页码点击切换页面 → 同时调用 `pause()`

## 影响范围
- `hooks/useScreenCarousel.ts` — 核心逻辑改造
- `ScreenPreviewPage.tsx` 或轮播 UI 渲染组件 — 增加播放/暂停按钮
- `types.ts` — `CarouselConfig` 类型扩展 `autoPlay`

## 验证
