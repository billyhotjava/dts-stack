# T02: 上传弹窗集成 UploadedDataEditor

**状态**: READY
**文件**: `source/dts-platform-webapp/src/analytics/pages/DataPage.tsx` (弹窗逻辑)
**复用**: `source/dts-platform-webapp/src/analytics/components/UploadedDataEditor.tsx`

## 目标

在 DataPage "我的上传"区域添加上传弹窗，复用现有 UploadedDataEditor 组件。

## 弹窗触发

- "我的上传"标题栏右侧 [上传 Excel/CSV] 按钮
- 点击打开 Modal/Dialog

## 弹窗内容

复用 `UploadedDataEditor`，固定参数：
- `databaseId`: 自动获取（`is_system=true` 的数据湖 ID）
- `schema`: 固定 `upload`
- 用户无需选择目标库

## 上传成功回调

1. 关闭弹窗
2. 显示 toast: "已上传 {tableName}，共 {rowCount} 行"
3. 刷新"我的上传"表格
4. 同步数据湖 schema: `analyticsApi.syncDatabaseSchema(dataLakeId)`

## 实现要点

- 使用 antd `<Modal>` 包裹 UploadedDataEditor
- Modal 宽度 720px 以适配预览表格
- 上传中禁用关闭按钮
- UploadedDataEditor 可能需要小幅改造：接受外部传入的固定 databaseId 和 schema
