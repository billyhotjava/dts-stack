数据中台 V2 重构功能测试用例清单
1. 数据资源中心 (Airbyte 集成测试)
目标：验证异构数据源接入及入湖任务的准确性。
模块	用例名称	预置条件	测试步骤	预期结果
数据源管理	数据源连通性测试	准备一个可用的 MySQL 实例	1. 选择 MySQL 类型；2. 输入业务配置（Host/Port/User/Pwd）；3. 点击“连通性测试”。	提示“连接成功”，后台 Airbyte 成功创建 Source 实例。
数据入湖	全量/增量同步验证	定义好 Source，ODS 层存储就绪	1. 创建入湖任务；2. 选择同步模式为“全量”或“增量（按字段）”；3. 执行任务。	数据准确从源库搬运至 ODS 表，字段类型转换正确。
数据入湖	CDC 实时同步测试	源库已开启 Binlog	1. 配置入湖任务模式为 CDC；2. 在源库执行 INSERT/UPDATE 操作。	中台 ODS 表在设定的同步窗口内自动更新。
Schema Drift	字段漂移自动处理	入湖任务正常运行中	1. 在源表增加一个字段 new_col；2. 触发下一次同步；3. 查看 ODS 表结构。	若策略为“自动同步”，ODS 表自动增加该字段；若为“待办提醒”，工作台收到变更告警。
入湖对账	行数一致性核验	任务已完成一次运行	1. 修改对账规则为“行数强一致”；2. 人为在 ODS 表删除一行数据；3. 重新运行对账。	运维中心记录“对账异常”，告警通知负责人。
2. 数据开发中心 (dbt & Airflow 集成测试)
目标：验证 SQL 建模能力及可视化编排的生成能力。
模块	用例名称	预置条件	测试步骤	预期结果
逻辑建模	dbt 模型编译与预览	已完成入湖任务 A	1. 在 SQL IDE 使用 {{ source('ods', 'A') }}；2. 点击“预览”按钮。	后台调用 dbt compile 成功，界面展示查询出的前 100 条样板数据。
任务编排	DAG 自动生成测试	画布上有 A(同步) -> B(模型) 两个节点	1. 拖拽连线并保存；2. 点击“发布”任务流。	后台在 Airflow 目录自动生成对应的 Python DAG 文件，且依赖关系正确。
任务编排	跨节点参数传递	配置一个按 T-1 分区执行的任务	1. 触发手动执行，选择日期。	Airflow 将日期参数成功传递给 Airbyte (Sync) 和 dbt (Run --vars)。
即席查询	权限管控测试	用户 A 无表 T 的查看权限	1. 用户 A 在 Ad-hoc 界面对表 T 执行 SELECT。	系统拦截并提示“权限不足”，记录审计日志。
3. 数据治理中心 (dbt tests & 元数据测试)
目标：验证数据质量管控及血缘闭环。
模块	用例名称	预置条件	测试步骤	预期结果
质量管控	字段约束规则生效	某字段配置了“非空(Not Null)”规则	1. 源头插入一条该字段为空的数据；2. 运行编排任务。	任务运行到“校验节点”时报错或告警，展示质量不达标。
资产门户	全链路血缘追踪	入湖任务和模型加工任务已运行	1. 进入资产详情页 -> 查看血缘视图。	视图清晰展示：源库 -> 入湖任务 -> ODS 表 -> dbt 模型 -> 指标。
资产门户	元数据自动同步	OpenMetadata 采集任务已配置	1. 在源库修改表备注；2. 等待采集任务执行。	资产门户中对应表的“业务描述”字段自动更新。
4. 任务运维中心 (调度运行态测试)
目标：验证监控系统的“黑盒化”日志及运维能力。
模块	用例名称	预置条件	测试步骤	预期结果
运行监控	统一日志查看	任务流正在运行	1. 点击同步节点查看日志；2. 点击模型节点查看日志。	同步节点显示 Airbyte 的清洗后日志；模型节点显示 dbt run 的控制台输出。
故障运维	断点续传/重试	任务流因网络原因在入湖阶段失败	1. 修复网络；2. 点击“失败重试”。	Airflow 触发重试逻辑，入湖任务从失败位点继续或重新拉取。
补数管理	历史数据重跑	任务流按天分区	1. 选择日期范围（2023-01-01 至 2023-01-07）；2. 点击启动补数。	系统生成 7 个并行或串行的 Airflow 运行实例，补全 7 天数据。
5. 异常场景与资源隔离测试 (三员管理端联动)
目标：验证底层物理资源与业务逻辑的隔离。
模块	用例名称	预置条件	测试步骤	预期结果
资源隔离	并发任务上限限制	配置项目最大并发任务数为 2	1. 同时启动 5 个 JobFlow。	2 个任务正常运行，3 个任务处于“队列中（Queued）”等待资源释放。
安全性	密钥黑盒化验证	具有业务端“编辑”权限的用户	1. 打开数据源编辑页面。	数据库密码字段显示为 ******，且通过 API 无法获取明文密码。
容灾	Airbyte Pod 重启测试	正在进行大规模数据同步	1. 手动杀死底层 Airbyte Worker Pod。	Airflow 检测到失败，并根据配置的重试策略自动发起第二次同步尝试。
