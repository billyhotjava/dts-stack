# T02: 标准草稿在建模页的来源证据

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标

低代码和 SQL 建模页显示标准草稿来自哪里、包含哪些字段、哪些字段缺标准、下一步能做什么。

## 技术设计

- 继续完善 `standardDraftId` 在 `LowCodeDevelopmentPage` 和 `SqlModelingPage` 的展示。
- 展示来源：标准包、数据元列表、快照创建时间、字段数。
- 增加缺口状态：无字段、字段无标准编码、码表缺失、密级缺失。

## 影响范围

- `standardBindingDraft.ts`
- `LowCodeDevelopmentPage.tsx`
- `SqlModelingPage.tsx`
- `dataDevelopmentWorkbench.source-contract.test.ts`

## 验证

- [ ] source-contract 断言标准来源和缺口文案。
- [ ] 后端快照读取失败时 UI 使用本地草稿兜底并提示。
