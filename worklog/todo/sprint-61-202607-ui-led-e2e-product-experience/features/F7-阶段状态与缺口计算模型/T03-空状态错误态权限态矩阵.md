# T03: 空状态、错误态、权限态矩阵

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: T02

## 目标

为端到端旅程的关键页面补齐空状态、错误态、权限态、加载态，避免客户体验被“暂无数据”或静默失败打断。

## 技术设计

- 为每个阶段定义状态矩阵：default、loading、empty、blocked、error、permission、success。
- 页面只展示和当前阶段相关的最小状态，不增加解释型大段文字。
- 权限不足时提供申请或联系入口。
- API 错误时保留返回工作台和查看证据入口。

## 影响范围

- `JourneyContextBar`
- 工作台阶段卡
- 数据源、标准、建模、指标、服务、运维页面
- `assets/button-component-matrix.md`
