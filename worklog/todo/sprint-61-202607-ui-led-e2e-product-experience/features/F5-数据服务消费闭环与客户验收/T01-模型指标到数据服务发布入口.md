# T01: 模型/指标到数据服务发布入口

**优先级**: P1
**状态**: READY
**依赖**: F4/T01

## 目标

在模型和指标页面提供进入数据 API、报表数据集、数据产品的明确入口。

## 技术设计

- `SqlModelingPage.tsx` 发布成功态增加“创建数据 API/数据产品”按钮。
- `MetricWorkbenchPage.tsx` 增加“发布为服务”动作。
- 路由携带 `modelId`、`metricId`、`journey`。

## 影响范围

- `SqlModelingPage.tsx`
- `MetricWorkbenchPage.tsx`
- `ApiServicesPage.tsx`
- `DataProductsPage.tsx`

## 验证

- [ ] source-contract 断言模型/指标页面存在服务入口。
- [ ] 服务页面能读取 query context。

## 完成标准

- [ ] 用户不需要从服务菜单重新选择来源模型或指标。
