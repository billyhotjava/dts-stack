# T03: 阶段缺口与下一步动作收敛

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标

把“暂无数据”升级为“当前缺口 + 可执行下一步”，减少客户停在空页面的情况。

## 技术设计

- 为工作台阶段定义统一缺口模型：`missingSource`、`missingStandard`、`missingModel`、`missingMetric`、`missingService`、`missingEvidence`。
- 对每个缺口给出主按钮和修复页面。
- 后端暂不可判定时用 UI blocker 明示“需要补 API”，不显示假成功。

## 影响范围

- `DataManagementWorkbenchPage.tsx`
- `DataSourcesPage.tsx`
- `StandardPackagePage.tsx`
- `SqlModelingPage.tsx`
- `ApiServicesPage.tsx`

## 验证

- [x] source-contract 断言空状态包含下一步按钮。
- [ ] Playwright smoke 覆盖无数据场景。

## 完成标准

- [x] 每个阶段空态都能引导用户继续。
- [x] 权限/API 不足时显示 blocker 和下一步语义；页面级浏览器视觉复验归入 F9。
