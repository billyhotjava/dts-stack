# T03: 接入状态到建模就绪度提示

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

让用户看到接入任务是否足以进入建模，避免数据还没准备好就创建模型草稿。

## 技术设计

- 在旅程工作台或低代码页面显示接入状态：未接入、同步中、同步成功、失败、需要补数。
- 关联到 `TransformCreatePage`、`TransformDetailPage` 和运行历史。
- 建模按钮根据状态显示 enabled/disabled/retry。

## 影响范围

- `TransformCreatePage.tsx`
- `TransformDetailPage.tsx`
- `TransformExecutionHistoryPage.tsx`
- `LowCodeDevelopmentPage.tsx`

## 验证

- [x] source-contract 断言接入失败时显示修复入口。
- [ ] 浏览器 smoke 覆盖 disabled reason。

## 完成标准

- [x] 接入失败、同步中、无权限时 UI 明确阻断建模。

## 实施证据

- 低代码页根据 `sourceId`/`ingestionStatus` 展示未接入、同步中、同步成功、失败和待确认状态。
- 未达到同步成功时，模型候选动作 disabled 并给出原因；相关 source-contract 已通过。
