# T03: Chrome 95 与窄屏视觉回归基线

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

确认端到端旅程工作台和子页面上下文条在旧浏览器和窄屏下不出现空白、遮挡、按钮溢出或文本撑破。

## 技术设计

- 使用现有 Chrome 95 回归技能或脚本复验关键页面。
- 检查 1366x768、390x844 等视口。
- 对固定格式元素使用稳定尺寸约束，不依赖 container query 作为关键布局。
- 截图归档到 Sprint-61 `it/` 目录。

## 影响范围

- 工作台旅程轨道
- `JourneyContextBar`
- 标准草稿、发布门禁、验收包卡片
- CSS/Tailwind 类名

## 验证

- [ ] Chrome 95 页面非空白。
- [ ] 1366x768 下旅程主按钮可见。
- [ ] 窄屏下长文本换行，不遮挡后续按钮。
- [ ] 截图路径写入 `it/README.md`。

## 完成标准

- [ ] 旧浏览器和窄屏验证成为每次 UI 旅程改动的固定门禁。
- [ ] 视觉问题能定位到具体页面和组件。
