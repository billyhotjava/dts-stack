# T02: 证据链接聚合与缺口显示

**优先级**: P1
**状态**: DONE
**依赖**: T01

## 目标

把分散在模型、指标、服务、质量、权限、运行、审计页面的证据链接聚合到验收包，并明确缺失项。

## 技术设计

- 聚合 `modelId`、`metricId`、`serviceId`、`runId`、`auditId` 对应的页面链接。
- 对缺失证据展示 `missing` 状态和补齐入口。
- 证据链接保持 `journey=e2e-data-product`，便于返回验收包。
- 后端缺少聚合 API 时保留 UI blocker。

## 影响范围

- 工作台验收包区域
- `OpsInstancesPage`
- `AuditEvidencePage`
- `ApiServicesPage`

## 验证

- [x] source-contract 覆盖证据链接生成规则。
- [x] source-contract 覆盖缺失证据 blocker。
- [ ] Playwright 可登录环境截图验收包区域。

## 完成标准

- [x] 验收包不是静态说明，而是可点击证据集合。
- [x] 缺少质量、权限或运行证据时不会误报完成。
