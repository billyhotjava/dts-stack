1 数据集成      已选择数据源 / 缺接入任务

5 数据指标      指标口径待绑定
6 数据开发      dbt 运行未通过 / 查看日志

## 子页面顶部上下文条

```text
旅程: 首个数据产品交付  >  当前阶段: 数据标准  >  下一步: 维度建模

[返回工作台] [继续下一步] [查看缺口] [生成验收包]
```

## 页面间上下文参数

建议最小参数：

- `journey=e2e-data-product`
- `scenarioId`
- `sourceId`
- `standardDraftId`
- `modelId`
- `metricId`
- `serviceId`

## UI 不应出现的形态

- 只有菜单和模块列表，没有旅程状态。
- 只有“暂无数据”，没有下一步。
- 标准、模型、指标、服务之间通过 toast 暗示关联。
- 发布成功后没有运行、质量、审计证据入口。
