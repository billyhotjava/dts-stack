# T01: 旅程快照存储模块

**优先级**: P0
**状态**: DONE
**依赖**: 无

## 目标
提供旅程快照的读写内核：保存、读取、清除、版本迁移策略，存储介质可注入以便测试。

## 技术设计
- 新建 `src/components/journey/journeySnapshot.ts`：
  - `JOURNEY_SNAPSHOT_STORAGE_KEY = "dts.journey.e2e-data-product.v1"`。
  - `JourneySnapshot = { version: 1; journey: string; stage: DataProductJourneyStageKey; params: DataProductJourneyContextParams; savedAt: string }`。
  - `saveJourneySnapshot(snapshot, storage?)` / `loadJourneySnapshot(storage?)` / `clearJourneySnapshot(storage?)`：storage 默认 `window.localStorage`，接口收敛为 `Pick<Storage,"getItem"|"setItem"|"removeItem">` 便于注入内存实现。
  - 读取时 JSON 解析失败、version 不匹配、journey 不匹配 → 返回 null 并清除脏数据。
  - 所有 storage 调用包 try/catch，异常静默返回（隐私模式/配额场景），不抛错。
  - `buildSnapshotResumeUrl(snapshot)`：用现有 `buildJourneyUrl(stageRoute, params)` 生成恢复 URL。
- 后端旅程实例 API 缺口在模块头注释标注：`GET/PUT /api/journey/instances/{journey}`（不实现）。
