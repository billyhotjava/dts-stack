# T02: 上下文变化自动保存快照

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
用户在旅程内任一页面时，上下文参数一旦变化即自动保存快照，无需用户操作。

## 技术设计
- 扩展 `src/components/journey/useDataProductJourneyContext.ts`：
  - 当 `context.enabled` 为 true 时，在 effect 中调用 `saveJourneySnapshot({ stage, params, savedAt: new Date().toISOString(), ... })`。
  - 依赖数组用 params 的序列化键，避免每次 render 重写。
  - 不在 disabled（无 journey 参数）时写入，避免覆盖既有快照。

## 影响范围
- `src/components/journey/useDataProductJourneyContext.ts`
- `JourneySnapshot.source-contract.test.ts` 增补 hook 层用例（以纯函数抽取可测逻辑，React hook 只做接线）

## 验证
- [ ] 快照保存逻辑抽为纯函数 `shouldPersistSnapshot(context)` 并被测试覆盖：enabled 才存、参数变化才存。

## 完成标准
- [ ] 页面接入无需改动（hook 内收口）；测试 GREEN；build 通过。
