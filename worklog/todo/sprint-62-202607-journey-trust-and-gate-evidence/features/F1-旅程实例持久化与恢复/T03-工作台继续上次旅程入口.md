# T03: 工作台继续上次旅程入口

**优先级**: P0
**状态**: READY
**依赖**: T01

## 目标
工作台检测到快照时展示"继续上次旅程"卡片，一键恢复中断前的阶段与上下文。

## 技术设计
- `DataManagementWorkbenchPage.tsx` 旅程区域顶部：
  - 读取 `loadJourneySnapshot()`；有快照且当前 URL 未携带 journey 参数时渲染恢复卡。
  - 卡片内容：上次阶段名、上下文摘要（复用 PARAM_LABELS 标签对）、保存时间（相对时间，简单实现 N 分钟/小时/天前）、按钮"继续旅程"（跳 `buildSnapshotResumeUrl`）与"清除"（clearJourneySnapshot + 本地 state 隐藏）。
  - 当前 URL 已在旅程中时不显示恢复卡（避免与实时状态冲突）。
- 状态覆盖：无快照（不渲染）、有快照（default）、清除后（消失）、storage 异常（不渲染，不报错）。
