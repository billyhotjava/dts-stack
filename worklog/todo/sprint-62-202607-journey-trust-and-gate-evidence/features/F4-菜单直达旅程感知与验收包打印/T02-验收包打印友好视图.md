# T02: 验收包打印友好视图

**优先级**: P1
**状态**: DONE
**依赖**: 无

## 目标
验收包可直接浏览器打印成客户可归档的材料：分组表格、缺失项、门禁明细、签字栏、生成时间。

## 技术设计
- workbench 验收包区域新增"打印视图"按钮：打开打印布局（隐藏应用壳，仅渲染验收包内容）后调用 `window.print()`。
  - 实现取轻方案：验收包容器加 `data-print-root`，全局注入一段 `@media print` CSS（隐藏非 print-root 元素、表格边框、分页控制 page-break-inside: avoid），不开新路由不开弹窗，Chrome 95 兼容。
  - 打印头：标题、journey 上下文摘要、生成时间；打印尾：验收签字栏（数据管理办公室/业务科室/技术支持方三栏）。
- markdown/json 导出行为不变。

## 影响范围
- `DataManagementWorkbenchPage.tsx`（打印按钮与 print-root 标记）
- 新增打印样式（页面内 <style> 或全局样式文件，遵循仓库现有样式组织）

## 验证
- [ ] 打印视图结构判定（应含分组/签字栏/时间）以纯函数或字符串模板测试覆盖；Chrome 95 打印预览截图挂靠 F9。

## 完成标准
- [ ] 打印不带应用导航壳；测试 GREEN；build 通过。
