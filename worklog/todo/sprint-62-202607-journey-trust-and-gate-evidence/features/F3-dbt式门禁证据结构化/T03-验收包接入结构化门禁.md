# T03: 验收包接入结构化门禁

**优先级**: P0
**状态**: DONE
**依赖**: T01

## 目标
客户验收包从链接聚合升级为 checks 聚合：验收项=结构化门禁+证据链接，缺失项带 apiName。

## 技术设计
- `dataProductAcceptancePackage.ts`：
  - `buildDataProductAcceptancePackage(params)` 内部并入 `buildGateEvidence(params)`；验收分组新增"发布门禁"组，成员即四项 checks 映射为验收条目（ready→已具备/missing→缺失项/blocked→阻断项，保持现有三色语义）。
  - `buildAcceptancePackageMarkdown` 输出门禁明细表（check、状态、说明、证据链接/缺失 API）。
  - JSON 导出同步补 `gateEvidence` 字段。
- 修改前 GitNexus impact 确认调用方仅 workbench 与测试。
