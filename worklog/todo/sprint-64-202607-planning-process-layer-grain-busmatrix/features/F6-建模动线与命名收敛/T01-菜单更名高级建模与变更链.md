- 按 portalGoldenLineMenu 变更模式走全链：`dts-admin` portal-menu-seed.json 更名 → 新增 liquibase changelog（存量库菜单更新）→ zh_CN/en_US locale → role-menu-defaults 同步。
- 路由不变（仍 `/studio/sql-modeling`），仅菜单与展示名变更，避免断链。
- `portalGoldenLineMenu.source-contract.test.ts` 断言同步更新。
