# T04: 业务对象登记入口前移

**优先级**: P0
**状态**: READY
**依赖**: T02

## 目标

业务对象的创建从"藏在语义台账页"前移到规划链路：业务过程卡下直接登记，从属链（主题域⊃业务过程⊃业务对象）在创建时即可见。

## 技术设计

- SubjectAreasPage 业务过程卡增加"登记业务对象"动作：内嵌轻量创建（名称/描述），提交走既有 semantic objects API（`SemanticObjectsPage` 同一服务），自动带 processId。
- 创建成功后展示该过程下已登记对象列表（数量 + 名称 Tag），点击跳 `/modeling/semantic/objects?processId=...`。
- SemanticObjectsPage 空状态与"选择业务过程后新建"提示补充回规划页的引导链接（双向可达）。

## 影响范围

- `SubjectAreasPage.tsx`、`SemanticObjectsPage.tsx` 及各自 source-contract 测试
- 复用既有语义对象服务，不新增 API

## 验证

- [ ] 契约覆盖：过程卡登记动作、对象列表渲染、双向跳转带 processId。
- [ ] 无业务过程时登记动作 disabled 并给创建过程引导。
