# T03: 标准缺口与回退动作

**优先级**: P1  
**状态**: READY  
**依赖**: T01

## 目标

没有数据元、标准字段或权限时阻止进入维度模型候选，并指向可执行修复动作。

## 技术设计

- 区分无规划、无数据元、字段未落标、无治理权限四类状态。
- 维度建模按钮 disabled 时展示具体原因和回到数据元/规划的动作。

## 影响范围

- `ElementsPage.tsx`（blocker 呈现与 disabled 逻辑）
- 缺口判定抽纯函数入 `warehousePlanningContext.ts` 或独立 helper + 测试
