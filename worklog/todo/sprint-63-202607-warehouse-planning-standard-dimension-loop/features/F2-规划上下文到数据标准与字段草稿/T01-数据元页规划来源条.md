# T01: 数据元页规划来源条

**优先级**: P0  
**状态**: READY  
**依赖**: F1/T02

## 目标

让客户在数据元页面知道当前标准选择来自哪个主题域和规划。

## 技术设计

- `ElementsPage` 解析规划 query 并从 session 恢复上下文。
- 显示主题域、数仓层、建模模式和返回规划动作。**来源条仅展示来源，不过滤数据元列表**（数据元无主题域归属字段，过滤属后端规划实体阶段能力，见设计文档 4.2/第 9 节）。
- 无 planning context 时保持原有独立入口不受影响。

## 验证

- [ ] source-contract 覆盖有/无规划上下文两种状态。
- [ ] 返回规划路由保留 `planningId/domainId`。
