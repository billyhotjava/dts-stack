# T02: 标准草稿绑定规划元数据

**优先级**: P0  
**状态**: READY  
**依赖**: T01

## 目标

输出字段落标草稿时保留规划来源，供维度建模页展示和校验。

## 技术设计

- 扩展 `StandardBindingDraft` 的 metadata，不改变既有字段契约。
- 后端快照失败时，本地 session 草稿同样保留规划上下文。
- 建模路由从草稿和 query 合并上下文，**裁决规则：session/草稿为权威**——planningId 命中但 query 的 domainId/warehouseLayer/modelingMode 与草稿不一致时判 blocked，给"以草稿为准继续/重新创建规划"动作，不静默采信任一方（设计文档 3.2）。

## 验证

- [ ] source-contract 覆盖后端快照和本地草稿两条路径。
- [ ] 草稿摘要显示 planning id、主题域和建模模式。
