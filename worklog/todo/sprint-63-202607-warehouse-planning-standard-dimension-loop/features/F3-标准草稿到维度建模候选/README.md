# F3: 标准草稿到维度建模候选

**优先级**: P0  
**状态**: READY

## 目标

让低代码和 SQL 建模把规划和标准草稿转化为明确的维度模型候选，而不是通用模型入口。

## Task 列表

| ID | Task | 优先级 | 状态 | 依赖 |
|----|------|--------|------|------|
| T01 | 低代码页维度模式和来源证据 | P0 | READY | F2/T02 |
| T02 | SQL 建模页维度草稿和规划回跳 | P0 | READY | T01 |
| T03 | 维度候选前置门禁 | P0 | READY | T01 |

## 完成标准

- [ ] 建模页能区分维度模式和普通 SQL 模式。
- [ ] 模型草稿保留规划、主题域和标准字段来源。
- [ ] 缺少标准时不能生成误导性维度模型。
