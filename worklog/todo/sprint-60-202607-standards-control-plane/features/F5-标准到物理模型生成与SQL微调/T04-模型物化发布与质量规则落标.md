# T04: 模型物化发布与质量规则落标

**优先级**: P0
**状态**: READY
**依赖**: T03

## 目标

把通过标准门禁的模型发布到开发环境或受控目标环境，并自动生成质量规则、发布记录和可回溯证据。

## 技术设计

发布对象：

- 物理表。
- 视图。
- 物化视图。
- dbt table / view / incremental model。

发布记录需要包含：

- 模型规格版本。
- 标准包版本。
- DDL/dbt/schema.yml 快照。
- SQL 快照。
- 标准门禁结果。
- 质量规则清单。
- 发布环境和操作人。

质量规则落标：

- 主键字段生成唯一/非空规则。
- 码表字段生成 accepted values 或 relationships。
- 安全字段生成脱敏/权限检查提示。
- 分区字段生成分区完整性规则。

## 验证

- [ ] 发布成功后能看到发布记录和标准门禁快照。
- [ ] 质量规则由模型规格自动生成，不需要用户重复录入。
- [ ] 删除重建模式有显式高风险确认。
- [ ] 发布失败时保留失败日志和可重试入口。

## 完成标准

- [ ] 模型发布不是单纯保存 SQL，而是完成物理对象、质量规则和标准证据的闭环。
- [ ] 发布记录能支撑后续指标、报表和运维证据追踪。
