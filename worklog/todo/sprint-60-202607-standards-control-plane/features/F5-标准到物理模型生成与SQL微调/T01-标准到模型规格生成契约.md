# T01: 标准到模型规格生成契约

**优先级**: P0
**状态**: IN_PROGRESS
**依赖**: F1/T02

## 目标

定义标准包、数据元、公共码表、标准模板和来源表如何生成 ODS/DWD/DWS/ADS 模型规格草稿。

## 技术设计

模型规格作为中间事实源，不直接等同 SQL。建议字段：

| 字段 | 说明 |
|------|------|
| `modelCode` | 模型编码，按分层和主题域命名 |
| `layer` | ODS / DWD / DWS / ADS |
| `domain` | 主题域 |
| `businessProcess` | 业务过程 |
| `sourceRefs` | 来源系统、库表、接口、文件 |
| `standardRefs` | 业务术语、数据元、码表、模板 |
| `fields` | 字段契约、标准绑定、码表、安全级别 |
| `grain` | 明细或汇总粒度 |
| `materialization` | table / view / incremental / materialized_view |
| `refreshPolicy` | 全量、增量、分区重跑、回溯窗口 |
| `qualityRules` | 主键、非空、唯一、码值、关联、范围 |

ODS 需要区分：

- `ODS_RAW`: 来源结构保真，保留原始字段、抽取批次、源系统时间。
- `ODS_STANDARDIZED`: 字段命名、类型、码值、安全标识和分区归一，但不改变业务事实。

## 验证

- [ ] 从标准包生成模型规格草稿时，字段自动带出数据元、码表和安全级别。
- [ ] 从来源表生成 ODS 规格时，能区分 Raw 和 Standardized。
- [ ] DWD/DWS/ADS 草稿必须有主题域、业务过程和粒度说明。
- [ ] 标准缺失时生成 blocker，而不是静默生成空模型。
- [x] 数据元字段落标草稿可作为模型规格草稿的字段契约输入。
- [x] 字段契约草稿可持久化并通过 `standardDraftId` 被低代码/SQL 建模读取。

## 完成标准

- [ ] 模型规格可被前端预览、编辑和保存。
- [ ] 模型规格可追踪到标准包版本和来源表版本。
- [ ] 所有字段的标准绑定状态可统计。
