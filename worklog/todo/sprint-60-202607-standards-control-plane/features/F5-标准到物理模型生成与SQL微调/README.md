# F5: 标准到物理模型生成与 SQL 微调

**优先级**: P0
**状态**: IN_PROGRESS

## 目标

补齐数据标准与数据开发之间的模型生成层：标准包、数据元、公共码表和模板先生成 ODS/DWD/DWS/ADS 模型规格，再生成物理 DDL、dbt model、schema.yml 和 ETL/SQL 骨架，最后允许开发者受控微调并反校验标准契约。

## 完成标准

- [ ] 用户可以从标准包、标准模板、来源表选择入口生成 ODS/DWD/DWS/ADS 模型规格草稿。
- [ ] 模型规格明确分层、主题域、来源、字段、粒度、主键、分区、码表、安全级别和物化策略。
- [ ] 系统可以预览物理 DDL、dbt model、schema.yml 和 ETL/SQL 骨架。
- [ ] 人工微调 SQL 后，系统重新校验字段契约、标准契约、血缘契约和质量契约。
- [ ] 发布开发环境后生成质量规则、发布记录和下游可消费证据。
