# F1: 标准控制面与事实源收敛

**状态**: READY
**优先级**: P0
**目标**: 统一业务术语、数据元、公共码表、标准模板和标准包的产品边界，让标准管理成为建模、指标、发布的事实源入口。

## 任务列表

| Task | 名称 | 状态 |
|------|------|------|
| T01 | 标准管理事实源审计 | READY |

## 验收

- [ ] 标准管理各页面明确区分“维护标准”和“消费标准”的边界。
- [ ] 数据元、业务术语、码表、模板都有可解释的引用关系。
- [ ] 标准包导入后能看到创建/更新对象、阻断项和下一步使用建议。
- [ ] 标准控制面可以回答：哪些标准已经进入资产、模型、指标、报表。
