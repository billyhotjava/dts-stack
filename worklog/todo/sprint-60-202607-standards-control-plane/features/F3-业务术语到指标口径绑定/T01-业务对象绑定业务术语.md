# T01: 业务对象绑定业务术语

**状态**: READY
**优先级**: P0

## 目标

业务对象不再只是一个自由文本名称，而是绑定业务术语的可治理对象。

## 任务

- [ ] 为业务对象补充 `glossaryTermId` / `glossaryTermCode` / `glossaryTermVersion`。
- [ ] 低代码“业务对象确认”阶段展示术语候选和缺口。
- [ ] 业务对象详情展示术语定义、别名、domain、owner、状态。
- [ ] 术语未 ACTIVE 时，业务对象进入待确认状态。

## 验收

- [ ] 业务对象可以从业务术语生成或绑定。
- [ ] 术语变更能影响业务对象就绪状态。
- [ ] 页面文案仍使用业务语言，不要求用户理解底层 SQL。
