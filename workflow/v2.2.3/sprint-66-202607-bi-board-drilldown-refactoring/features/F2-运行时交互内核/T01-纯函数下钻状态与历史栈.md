# T01：纯函数下钻状态与历史栈

**优先级**：P0
**状态**：DONE
**依赖**：F1/T02

## 目标

将参数解析、上下文合并、面包屑和上卷计算从 React hook 中拆为可测试的通用纯函数。

## 技术设计

- `drillRuntime.ts` 提供层级归一化、映射解析、参数合并和 snapshot 计算。
- stack 只保存 label 与白名单参数，不保存业务对象。
- `inheritContext=true` 合并父层参数；同名参数以后层覆盖前层。
- 新配置没有有效映射时取消推进；旧配置只使用通用兼容取值顺序。
- `useDrillDown.ts` 只负责 stack 状态和调用纯函数。
