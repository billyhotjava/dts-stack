# DTS 标准内容离线包

本目录交付可通过 DTS“标准包导入”向导上传的离线内容源。内容采用 Manifest v2，CSV 使用 UTF-8，
包内 `source-register.json` 记录官方来源、取证日期、使用边界和许可结论。

## 包清单

| 包 | 用途 | 安装前置 |
|---|---|---|
| `dts-core-identity-cn` | 居民身份证登记项目与自然人身份基础数据元 | 先安装内置包 `gbt-2261-gender` |
| `dts-core-finance-accounting` | 会计期间、凭证、科目、借贷方向和常用金额数据元 | 无 |
| `dts-core-national-common` | DTS 通用枚举、审计数据元与国家法定计量单位基础集 | 无 |
| `dts-custom-project-management` | 项目进度、跟进闭环、质量、技术状态、风险、重要物料和预算执行 | 无 |

## 导入

1. 在任一“业务术语 / 数据元 / 公共码表 / 计量单位”页面点击“导入标准包”。
2. 先上传 `dist/` 下的 ZIP 并检查逐文件预检报告。
3. 身份证包若提示缺少 `gbt-2261-gender`，先在“内置标准包”中安装该依赖。
4. 确认来源、许可和客户字段责任后再“确认应用”；如需撤销，从导入历史执行整包回滚。

项目管理自定义包覆盖 10 张项目管理 ODS v2 表的 132 个去重业务字段。ODS 保持原始 `varchar`
落地方式，包内数据元类型表达的是 STG/DWD 层建议的逻辑类型；16 组 `PJM_` 码表为可评审的
通用初始值，不替代客户已批准的组织级口径。

## 内容边界

- 不包含国家标准全文，也不抓取或再分发完整币种、行政区划等受许可约束的大型码值集。
- 财务和身份术语采用 DTS 自有参考表达，默认状态为 `DRAFT`。
- 项目管理术语和码值同样采用 DTS 自有参考表达；更改类别、风险分级和质量归零口径须由客户确认。
- 数据元的 `source_system` 故意留空，由客户环境补充真实业务来源系统。
- Manifest 的 `licenseConclusion` 为 `REVIEW_REQUIRED`；正式随商业版本发布前仍需产品/法务确认。
