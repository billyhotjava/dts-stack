# 2.0.0 菜单体系（产品化分组）

说明：
- 菜单分组遵循：数据资产 / 模型与标准 / 治理与质量 / 数据开发 / 数据可视化 / 安全合规 / 运维。
- 仅做“可用业务闭环”的功能优先落地：**指标管理（指标字典/维度字典/发布）**；ETL 相关先保留菜单占位（以星环为主）。
- 可视化与门户已通过河图 + Metabase 落地（本次不扩展 Superset）。

## 数据资产（catalog）
- 数据资产目录：资产清单浏览/搜索/使用说明/标签/统计（现有）
- 元数据采集与维护：库表/字段/作业元数据采集、补录、审批、变更历史（占位）
- 血缘与影响分析：作业—表—字段级血缘展示、影响范围评估、变更提示（占位）
- 生命周期管理：创建/共享/归档/销毁流程、到期提醒与审批、留存期限（占位）

## 模型与标准（modeling）
- 数据规划管理：业务域/主题规划、评审、版本管理、发布与变更留痕（占位）
- 数据标准：标准定义/导入/校验、发布/废止、影响提示（现有）
- 口径与术语：术语库、口径版本、引用关系、责任人、审批发布（占位，后续与指标联动）
- 模型规范与模板：ODS/DWD/DWS/ADS 分层规范、命名模板、评审要点、变更记录（占位）

## 治理与质量（governance）
- 指标管理
  - 指标字典：指标定义/分类/口径/版本/责任人/密级/部门（2.0.0 重点落地）
  - 维度体系与字典：维度属性、层级、编码规则、字典维护（2.0.0 重点落地）
  - 计算规则：计算逻辑/公式、跨主题关联、版本回溯（占位或与指标字典合并实现）
  - 发布与一致性校验：发布审批、报表引用检查、口径变更提醒（占位或最小可用）
- 质量规则：完整性/一致性/唯一性/范围等规则（现有）
- 质量巡检计划：任务编排、执行窗口、监控、预警、闭环（占位）
- 问题闭环与工单：异常跟踪、指派、处理记录、复核（占位）
- 合规检查：安全/合规扫描与提示（现有/可扩展）

## 数据开发（explore）
- 数据查询和预览：自助查询、探索、收藏分享、审计留痕（现有）
- 结果集管理：保存查询、结果集复用（现有）
- ETL与作业编排（占位）
  - 多源集成适配器
  - 数据交换与文件接入
  - 数据加工与转换
  - 流程编排与作业管理
  - 数仓分层管理
  - 装载对账校验

## 数据可视化（visualization）
- 报表与大屏：河图分享链接 + Metabase 分析入口（现有）
- 报表链接管理：平台侧维护链接、按部门/类型过滤、点击审计（现有）

## 安全合规（security）
- 安全总览：敏感级别态势（现有示例页）
- 访问权限矩阵（行/列级）：按组织/密级的最小权限授权、影响提示（占位）
- 脱敏策略中心：静态/动态脱敏模板与例外规则、导出差异化（占位）
- 安全基线与加固：基线配置项、加固清单与整改记录（占位）
- 三员管理与职责分离：系统/安全/审计管理员职责隔离、关键操作复核（占位）
- 身份认证集成：PKI/USBKey 等对接（占位）
- 备份恢复与灾备：备份策略、恢复验证、演练记录（占位）
- 日志审计与报表：审计检索与导出、周报/月报模板（占位，当前审计在平台已有兜底日志）

## 运维（ops）
- 系统监控：资源/作业/日志监控（占位）
- 告警与通知：自定义告警规则、通知渠道（占位）
- 运行日志：日志汇总、检索、导出（占位）
- 部署与脚本：双环境部署/初始化清单/运维脚本（占位）
- 运维配置：关键参数与开关（占位）
