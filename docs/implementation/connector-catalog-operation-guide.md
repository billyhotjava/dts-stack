# DTS 连接器目录操作说明

## 1. 文档目的

本文说明 DTS 平台中“连接器目录”的工作原理和日常操作方法。连接器目录用于回答三个问题：

- 平台当前支持哪些数据接入类型。
- 每类连接器具备哪些接入能力和配置要求。
- 如何从连接器目录进入“创建数据源”，完成首张业务表接入前的准备。

本文先以 Markdown 形式编写，后续可在内容确认后统一转为 Word 格式。

## 2. 页面入口

在平台左侧菜单进入：

`数据集成 -> 连接器目录`

对应页面路径：

`/foundation/connectors`

页面标题显示为：

`数据接入基础 / 连接器目录`

连接器目录和“数据源管理”是连续的两步：

1. 在连接器目录确认要接入的数据类型和能力。
2. 点击“创建数据源”，进入数据源管理页填写真实连接参数。

## 3. 工作原理

连接器目录不是实际填写数据库地址、账号、文件路径或接口地址的地方。它是平台的数据接入能力清单。

页面展示的数据来自后端接口：

`GET /api/infra/connectors`

后端从 `infra_connector` 表读取连接器记录，并返回给前端。每条连接器记录包含：

| 字段 | 含义 |
|------|------|
| 连接器 Key | 平台内部识别连接器的唯一编码，例如 `postgresql`、`mysql`、`excel`、`http-api`。 |
| 名称 | 页面显示名称，例如 PostgreSQL、MySQL、Excel。 |
| 分类 | DATABASE、FILE、API、STREAM。 |
| 源类型 | 创建数据源时默认带出的系统类型，例如 postgres、mysql、excel。 |
| 默认引擎 | 平台默认使用的接入执行引擎，例如 ADDAX、API_RUNTIME、FILE、FUTURE。 |
| 能力矩阵 | 标识该连接器支持的能力，例如连接测试、Schema 探测、采样、全量、增量等。 |
| 配置要求 | 创建数据源时需要填写哪些字段、哪些是可选字段、哪些属于敏感字段。 |
| 部署兼容性 | 该连接器适配的部署方式、CPU 架构、驱动类等信息。 |
| 状态 | ACTIVE 表示当前可用；停用连接器默认不显示。 |

后端服务启动时会刷新一组内置连接器；页面上的“同步内置”按钮也会触发同样的刷新动作：

`POST /api/infra/connectors/seed`

这个动作会把内置连接器定义同步到目录中。它不是创建业务数据源，也不会测试客户数据库连接。

## 4. 页面结构

连接器目录页面分为三个区域。

### 4.1 顶部操作区

| 按钮 | 作用 | 说明 |
|------|------|------|
| 创建数据源 | 直接进入新增数据源弹窗 | 不指定连接器时，需要在弹窗内手动选择连接器。 |
| 刷新 | 重新读取连接器目录 | 用于查看最新目录状态。 |
| 同步内置 | 从系统内置定义刷新连接器清单 | 适合初始化后目录为空、升级后补齐新增连接器时使用。 |

### 4.2 筛选与统计区

页面右上角提供分类筛选：

- 全部
- 数据库
- 文件
- API
- 流式

页面还提供“停用”开关。该开关用于把停用状态的连接器也显示出来，便于核对状态。它不是停用操作本身。

统计标签会显示当前列表数量和各分类数量，例如：

- 共 18 个
- DATABASE 11
- FILE 5
- API 1
- STREAM 1

实际数量以当前环境同步后的目录为准。

### 4.3 连接器表格

表格列说明如下：

| 列名 | 说明 |
|------|------|
| 连接器 | 显示连接器名称和 Key。点击名称可打开详情抽屉。 |
| 分类 | 显示连接器类型。DATABASE 代表数据库，FILE 代表文件，API 代表接口，STREAM 代表流式。 |
| 源类型 | 创建数据源时默认带出的类型。 |
| 默认引擎 | 平台执行接入任务时默认使用的引擎。 |
| 能力 | 简要展示连接器支持的能力，表格中只展示部分标签，完整能力可在详情抽屉查看。 |
| 状态 | ACTIVE 表示可用。 |
| 更新时间 | 连接器记录最近更新时间。 |
| 操作 | 创建数据源、配置、查看模板、启用、停用。 |

## 5. 能力标签说明

连接器目录中的能力标签用于判断后续能否完成对应动作。

| 能力标签 | 含义 | 操作影响 |
|----------|------|----------|
| 连接测试 | 支持测试连接是否可达 | 数据源创建后可进行连接验证。 |
| Schema | 支持探测表、字段等结构信息 | 适合接入数据库表或文件字段。 |
| 采样 | 支持读取样例数据 | 用于确认字段和数据内容是否符合预期。 |
| 全量 | 支持一次性全量同步 | 适合首次接入或周期性全量更新。 |
| 追加 | 支持追加写入 | 适合文件追加、接口追加或日志类数据。 |
| 时间戳增量 | 支持按时间字段增量同步 | 适合有更新时间字段的业务表。 |
| 主键增量 | 支持按主键增量同步 | 适合具备稳定主键的业务表。 |
| CDC | 预留变更捕获能力 | 当前目录中多数连接器未开放该能力。 |
| ODS | 支持生成入湖层结构 | 面向后续数据入湖和治理链路。 |
| dbt source | 支持生成建模工程所需 source 定义 | 普通业务接入人员通常无需直接操作。 |

如果某个能力没有出现，表示该连接器在当前目录定义中不声明该能力，后续页面不应默认承诺该动作一定可用。

## 6. 连接器详情、配置和模板

每条连接器提供三个查看入口。

### 6.1 连接器名称

点击连接器名称，打开“详情”抽屉。

详情抽屉展示：

- 连接器 Key
- 状态
- 分类
- 源类型
- 默认引擎
- 排序
- 更新时间
- 说明
- 能力矩阵
- 配置 Schema
- 部署兼容性

### 6.2 配置

点击“配置”，打开“配置要求”抽屉。

该抽屉用于查看创建数据源时需要准备哪些信息，包括：

- 必填字段
- 可选字段
- 默认值
- 敏感字段
- 部署兼容性

注意：“配置”不是在连接器目录中直接保存连接参数。实际连接参数仍然在“数据源管理”的新增弹窗中录入。

### 6.3 查看模板

点击“查看模板”，打开“配置模板”抽屉。

模板主要帮助实施人员提前准备字段和默认值。适合在创建数据源前确认：

- 是否需要账号密码。
- 是否需要驱动类或驱动版本。
- 是否有接口鉴权字段。
- 是否有文件路径、Sheet、分隔符、目标表等字段。

## 7. 创建数据源流程

连接器目录最重要的闭环是“从连接器创建数据源”。

### 7.1 从表格行创建

操作步骤：

1. 在连接器目录中找到目标连接器，例如 PostgreSQL。
2. 点击该行“创建数据源”。
3. 平台跳转到数据源管理页，并自动打开“新增数据源”弹窗。
4. 弹窗中的“连接器”会自动选中刚才选择的连接器。
5. “源类型”等字段会按连接器默认值带出。
6. 继续填写名称、连接地址、账号、密码、部门等信息。
7. 保存数据源。

页面跳转时会携带：

`/foundation/data-sources?create=1&connectorKey={连接器Key}`

数据源页面消费该参数后，会清理地址栏参数，避免刷新页面时重复打开弹窗。

### 7.2 从抽屉创建

操作步骤：

1. 点击连接器名称、配置或查看模板。
2. 在抽屉中确认能力、必填字段和敏感字段。
3. 点击抽屉底部“创建数据源”。
4. 后续流程与表格行创建一致。

### 7.3 直接创建

如果点击页面顶部“创建数据源”，系统会进入新增数据源弹窗，但不会预选某个连接器。此方式适合已经明确知道要手动选择哪类连接器的用户。

## 8. 同步内置连接器

“同步内置”用于刷新平台自带连接器目录。

适用场景：

- 新环境初始化后目录为空。
- 平台升级后新增了内置连接器。
- 连接器目录记录异常，需要恢复内置定义。

同步后，平台会重新写入或更新内置连接器，包括数据库、文件、API 和流式类型。

注意事项：

- 同步内置不会创建数据源。
- 同步内置不会连接客户数据库。
- 同步内置会将内置连接器状态设置为 ACTIVE。
- 页面会记录“刷新内置连接器目录”的审计动作。

## 9. 启用和停用按钮

当前页面中“启用”和“停用”按钮是禁用状态。

原因是当前连接器目录接口只开放了查看、详情和同步内置，没有开放单独的启用/停用接口。页面通过禁用按钮和提示文字避免形成“看起来能点但实际无动作”的假操作。

如果需要核对停用连接器，可使用右上角“停用”开关显示停用记录。

## 10. 常见连接器类型

当前内置目录包含以下类型，实际以环境同步结果为准。

### 10.1 数据库连接器

常见数据库连接器包括：

- PostgreSQL
- MySQL
- Oracle
- SQL Server
- ClickHouse
- DM8 达梦
- 人大金仓
- GBase
- Hive
- Inceptor
- 通用 JDBC

数据库连接器通常支持连接测试、结构探测、采样、全量同步、增量同步和入湖结构生成。

### 10.2 文件连接器

常见文件连接器包括：

- Excel
- CSV
- JSON
- SFTP
- MinIO

文件连接器用于将文件类数据登记为数据源，并进入后续入湖或治理流程。不同文件类型对字段、分隔符、Sheet、路径等要求不同。

### 10.3 API 连接器

当前内置 API 连接器为：

- HTTP API

API 连接器用于接入 HTTP/REST 接口数据。创建数据源时通常需要准备接口地址、请求方法、路径、鉴权方式、分页方式和返回记录路径等信息。

### 10.4 流式连接器

当前内置流式连接器包括：

- Kafka

流式连接器当前更多体现为能力声明和预留入口，具体是否可执行取决于后续运行引擎和现场配置。

## 11. 权限和审计

连接器目录后端接口要求具备基础设施维护权限。没有权限时，页面可能无法加载目录或触发同步内置。

系统会记录以下审计动作：

| 动作 | 触发方式 |
|------|----------|
| 查看连接器目录 | 打开页面或刷新列表。 |
| 查看连接器详情 | 打开连接器详情、配置或模板抽屉。 |
| 刷新内置连接器目录 | 点击“同步内置”。 |

审计记录用于回溯谁查看或刷新了连接器目录。

## 12. 常见问题处理

### 12.1 页面没有数据

处理建议：

1. 确认当前账号是否具备基础设施维护权限。
2. 点击“刷新”重新读取目录。
3. 点击“同步内置”刷新内置连接器。
4. 如果仍为空，联系平台管理员检查后端服务和数据库表 `infra_connector`。

### 12.2 找不到某个连接器

处理建议：

1. 将分类筛选切换为“全部”。
2. 打开“停用”开关，确认连接器是否处于停用状态。
3. 点击“同步内置”刷新内置目录。
4. 如果是非内置连接器，需要确认是否已有对应注册记录。

### 12.3 点击“创建数据源”后没有预选连接器

处理建议：

1. 确认是从具体连接器行或抽屉底部点击“创建数据源”。
2. 如果从页面顶部点击“创建数据源”，属于直接创建，不会预选连接器。
3. 确认跳转地址是否包含 `connectorKey`。
4. 刷新连接器目录和数据源页面后重试。

### 12.4 启用和停用为什么不能点击

当前版本没有开放连接器启用/停用接口，因此按钮被禁用。需要调整状态时，应通过后续平台管理能力或管理员维护流程处理。

### 12.5 配置 Schema 中的敏感字段如何处理

敏感字段用于提醒用户哪些字段属于密码、令牌、密钥等信息。连接器目录只展示字段要求，真实敏感值应在创建数据源时录入，并由数据源保存流程处理。

## 13. 推荐操作路径

面向没有 SQL 经验的新用户，推荐路径如下：

1. 进入“连接器目录”。
2. 按数据来源选择分类，例如数据库或文件。
3. 找到目标连接器，例如 PostgreSQL 或 Excel。
4. 点击“配置”查看必填字段。
5. 点击“创建数据源”。
6. 在数据源弹窗中按提示填写连接信息。
7. 保存后回到数据源管理页执行连接测试、结构探测和后续入湖任务。

这条路径不要求用户先写 SQL，也不要求理解底层执行引擎。用户只需要先确认数据来源类型，再按表单完成连接登记。
