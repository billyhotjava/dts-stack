数据中台业务端功能菜单明细 (V3)
设计准则：
黑盒化底层：隐藏 dbt 命令、Airflow DAG、OpenMetadata API 等术语。
一站式体验：从接入数据到产出指标，流程在业务端完全闭环。
资源隔离：业务侧只负责数据逻辑配置，底层物理资源（K8s/存储）由三元管理端负责。
一、 菜单结构概览
一级菜单	核心定位	对应底层组件（用户不可见）
工作台	个人任务中心与效能看板	-
数据资源中心	数据源连接与元数据同步（业务运维）	OpenMetadata Ingestion / Data Connector
数据开发中心	模型定义、脚本编写与任务编排	dbt / Airflow / Spark / Flink
数据治理中心	质量规则、标准规范与指标定义	dbt test / OpenMetadata Profiler
数据资产门户	资产搜索、血缘追踪与权限申请	OpenMetadata Catalog & Lineage
任务运维中心	运行实例监控、告警与日志分析	Airflow Task Instance / Logs
数据服务中心	数据 API 化与数据分发消费	API Gateway / Reverse ETL
二、 详细二级菜单功能说明
1. 工作台 (Workbench)
我的概览：展示当前用户负责的资产数量、待处理告警、最近编辑的模型。
待办事项：资产权限审批申请、质量核查工单、任务失败认领。
我的收藏：快速进入常用的模型、表、指标。
2. 数据资源中心 (Resource Center)
数据源管理：配置 MySQL、ClickHouse、Kafka 等业务库连接（屏蔽 Connection String 细节）。
元数据采集：配置同步计划，自动发现业务库的表结构、备注、索引信息。
数据入湖配置：配置从业务源头到中台贴源层（ODS）的同步任务。
3. 数据开发中心 (Data Studio)
项目空间管理：配置项目成员、关联 Git 仓库、设置环境隔离（开发/生产）。
逻辑建模 (SQL)：基于 dbt。提供 IDE 界面，支持 SQL 编写、预览结果、自动解析上下游依赖。
脚本开发 (Python/Spark)：处理非 SQL 类的复杂逻辑，支持在线脚本编写。
任务编排：基于 Airflow。可视化拖拽“逻辑模型”和“脚本”，配置定时触发、依赖关系、失败重试。
即席查询 (Ad-hoc)：直接连接中台计算引擎，进行快速的数据探查。
4. 数据治理中心 (Governance Center)
标准管理：定义业务术语表（Glossary）、数据元规范、公共码表。
指标中心：规范定义原子指标、派生指标，统一计算口径。
质量管控：
规则配置：配置唯一性、空值校验、值域范围等规则（对应 dbt tests）。
质量报告：展示各主题域的数据评分、问题分布及趋势。
分级分类：根据敏感度对资产进行打标（L1-L4）。
5. 数据资产门户 (Data Portal)
资产地图：按业务主题（如销售、财务、库存）浏览数据资产。
数据搜索：支持表名、字段名、备注、指标名的全文本搜索。
资产详情与血缘：
详情页：查看字段定义、样例数据、用户评价。
血缘视图：查看数据从源头到 BI 报表的全链路流向（隐藏底层节点）。
权限申请：在线发起表级或字段级的读写访问申请。
6. 任务运维中心 (Ops Center)
运行概览：全局任务成功率看板、甘特图分析（识别长耗时任务）。
任务实例监控：查看每个任务的运行历史、执行日志（由 Airflow 日志清洗后展示）、重试记录。
告警记录：汇总所有任务失败、数据质量异常、SLA 超时告警。
补数管理：支持对历史数据进行重跑操作，自动处理依赖触发。
7. 数据服务中心 (Service Center)
数据 API 管理：将模型一键发布为 REST API 供前端应用调用。
数据推送 (Outbound)：配置将处理好的数据推送至第三方系统（如推送至 CRM 或外部消息队列）。
共享交换：数据导出审批、临时数据下载管理。
