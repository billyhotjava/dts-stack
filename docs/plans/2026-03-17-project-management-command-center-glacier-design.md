# Project Management Command Center Glacier Design

## 背景

`项目管理指挥大屏` 模板当前使用手写深色视觉常量，默认主题仍是 `legacy-dark`。这和客户要求的“冰川白科研风”不一致，也会让模板在后续浅色大屏体系里显得割裂。

本次改造只针对模板默认视觉，不调整：

- 三屏轮播结构
- 组件类型与布局
- API 数据源与字段映射
- 全屏运行、轮播、变量透传逻辑

## 目标

把 `project-management-command-center` 模板重绘为更明显的冰川白科研风，并满足 Chrome 95 可用性：

1. 默认主题切到 `glacier`
2. 画布、面板、筛选、KPI 卡、图表、表格整体从深色切到浅色
3. 保留“科研院所项目指挥”气质，但弱化霓虹蓝和夜景驾驶舱感
4. 不引入会影响 Chrome 95 的新 CSS/颜色语法

## 设计约束

### 1. 只改模板，不改运行时

本次不修改大屏运行时渲染规则，也不新增通用主题机制。改动集中在模板默认配置：

- `projectManagementCommandCenterTemplate.ts`
- 对应模板测试
- 设计与计划文档

### 2. 视觉优先通过模板常量收敛

模板里深色值集中在 helper 常量和组件构造函数上，因此采用“统一替换 token + 保持结构不变”的方式：

- 画布背景改为浅蓝冰白底色
- 面板统一白卡片
- 冷灰蓝边框
- 深蓝灰文字
- 冰蓝强调色
- 图表色板整体降饱和

### 3. Chrome 95 兼容优先

模板内仅使用稳定能力：

- `hex` / `rgba`
- `linear-gradient`
- `box-shadow`
- `border-radius`
- 普通字体、边框、阴影、透明度

不引入：

- `color-mix`
- `oklch`
- `:has`
- 把 `backdrop-filter` 作为必要视觉依赖

## 视觉方案

### 画布

- 主背景：`#eef5fb`
- 页面背景色统一浅蓝白，不再使用深色画布
- 通过轻微明暗层次和卡片阴影保持大屏纵深感

### 面板

- 面板填充：`rgba(255, 255, 255, 0.94)`
- 边框：`rgba(148, 163, 184, 0.24)`
- 圆角保留较大圆角，但取消暗色玻璃感

### 标题与说明文字

- 主标题：`#16324f`
- 副标题/标签：`#5b7088`
- 时间组件：`#3b82f6`

### 筛选区

- 白底输入框
- 冷灰蓝描边
- 深蓝灰输入文字
- 不做深色内发光或玻璃态

### KPI 卡

- 白色或近白卡片底
- 标题用次级文字色
- 数值用深蓝灰
- 保留低饱和冰蓝强调

### 图表

- 折线/柱图色板：蓝、青蓝、柔和金
- 饼图色板：冰蓝、柔青、暖金、浅红、冷紫，整体降低荧光感
- 表格改为浅蓝灰表头 + 白底/浅灰交替行

## 验证策略

先用模板测试锁住关键默认值，再改实现：

1. 模板默认 `theme` 必须为 `glacier`
2. 模板背景色必须切为浅色
3. 代表性组件要体现浅色化：
   - 面板 `shape`
   - 筛选组件
   - KPI `number-card`
   - 图表 `seriesColors`
   - 表格色板

随后执行：

- 模板目标测试
- `pnpm -C source/dts-analytics-webapp/modern typecheck`
- `pnpm -C source/dts-analytics-webapp/modern build`
