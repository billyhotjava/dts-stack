SQL IDE 整体布局方案

三种布局策略，对标不同竞品。点击选择你倾向的方案。

A

经典三栏 —— DataGrip / DBeaver 风格

左固定侧栏 + 中央编辑/结果上下分割 + 右侧属性面板（可折叠）

B

双栏 + 底部面板 —— VS Code / DataWorks 风格

左侧栏（Schema 树）+ 中央编辑区（多 Tab）+ 底部结果/日志面板（可拖拽高度）

C

全屏编辑 + 浮动面板 —— Notion / Linear 风格

编辑器全屏沉浸，Schema/结果/历史都是可召唤的浮动面板或抽屉

💡 推荐：方案 B

VS Code 式布局对你们的双角色用户最均衡——开发者天然熟悉，分析师也不会被三栏吓到。左侧 icon 栏天然是 AI Copilot 的入口位置。底部面板的 Results/Chart/Pivot/Plan 多 tab 设计，完美承载"深度分析"需求。
