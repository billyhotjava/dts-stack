指标列表展示方式

同样的指标数据，卡片 vs 表格 vs 混合模式

A

卡片模式（适合浏览发现）

视觉扫描快，适合业务用户浏览指标含义

节点按时完成率
pjm_prog_on_time_rate
节点按时完成数 / 已到时间节点总数
RATIO % 已发布
项目本周期节点总数
pjm_prog_total_nodes
plan_date 在统计区间内的节点总数
COUNT 个 已发布
进度健康度评分
pjm_prog_health_score
按时完成率×0.4 + 里程碑×0.3 + …
SCORE·二次 分

优点

  • 一眼看到定义说明
  • 原始/二次视觉差异明显
  • 适合非技术用户

缺点

  • 100+ 指标时页面很长
  • 不方便批量操作
  • 排序/对比不直观
B

表格模式（适合管理操作）

列精确，支持排序/筛选/批量，适合数据治理管理员

指标名称 代码 类型 聚合 单位 状态 操作
节点按时完成率 pjm_prog_on_time_rate 原始 RATIO % ●已发布 编辑
项目本周期节点总数 pjm_prog_total_nodes 原始 COUNT 个 ●已发布 编辑
进度健康度评分 pjm_prog_health_score 二次 SCORE 分 ●草稿 编辑

优点

  • 100+ 指标时密度高
  • 排序/批量操作自然
  • 管理员首选

缺点

  • 指标定义/说明看不到
  • 业务用户理解门槛高
C

混合模式（推荐）

右上角切换视图：默认表格，可切卡片。点击行展开详情抽屉

☰ 表格 ⊞ 卡片
指标名称 类型 聚合 状态
节点按时完成率 ▶ 原始 RATIO ●发布
项目本周期节点总数 原始 COUNT ●发布
进度健康度评分 二次 SCORE ●草稿
节点按时完成率
pjm_prog_on_time_rate
定义：节点按时完成数 / 已到时间节点总数
来源表：ods_project_subject_domain
依赖字段：plan_date, completion_status
阈值：≥ 80% 正常
方向：↑ 越高越好
编辑 发布

优点

  • 管理员用表格高效操作
  • 业务用户切卡片查含义
  • 点击展开抽屉看详情，不跳页

缺点

  • 需要实现两套视图
